# Frozen pilot: ask when stuck

Frozen 2026-11-24, before running held-out inference. This is a CPU screening test of the **retrieval-timing mechanism**, not a replication of the paper's full memory-update loop.

- **Setting.** Replay ALFWorld 0.4.2 TextWorld walkthroughs; agent controls one procedural bottleneck and can retry it once. Use all 134 official unseen instances, keeping variants of each full task directory (objective, entities, floorplan) together in five balanced paired blocks. Floorplans can recur across blocks. Each block independently samples 30 official training games per task family. Never write from evaluation. A scripted walkthrough handles the prefix and remaining suffix. The endpoint is simulator goal completion, not model self-report.
- **Decision.** Use the first heat/clean/cool/use command where present, otherwise the last move command. Randomize a four-command menu containing the reference action, a legal `look` no-op, and two invalid alternatives. The observed feedback for each possible menu action and final success after the scripted suffix are recorded from the simulator. Every arm has the same chance to retry after an unsuccessful attempt. Failure-triggered pull gets memory only if the first attempt returns the literal `Nothing happens.`; valid nonprogress is not a trigger.
- **Memory.** One procedural Q&A atom per verified training walkthrough. Retrieve top five by fixed word/character cosine on goal plus initial observation, with no held-out fitting. Use shared nested prefixes of 12, 36, 90 and 180 atoms. The stress sweep randomly corrupts half the later atoms in expectation, with the same question, scope and an incorrect instruction to delay the needed operation. At 180 also replace all bad answers with their clean counterparts, leaving keys and ranks fixed. These are injected faults, not claims about endogenous error reproduction.
- **Same-budget controls.** Use Qwen2.5-0.5B-Instruct Q4_K_M and greedy letter decoding. Every memory delivery is five fixed tokenizer slots; use equally sized neutral slots in other prompts. All arms use exactly the same items for any given query and store. Push delivers before the first attempt. The primary push control uses a seeded uniform subset of equal size to failure pull; always-push is a companion positive control. The FLARE-style arm gives the same number of slots to the lowest no-memory first-attempt choice confidences among episodes that reach the retry. It uses the same retry prompt and sees the same feedback as failure pull; its gate does not use feedback text. Both controls are granted the block-level failure arm's query count as an offline budget (no per-task outcome/trigger information for push). No-memory retries use neutral slots. Report actual memory, calls, and input tokens separately.
- **Decision rule.** Report paired block means and two-sided 95% Student t intervals (five independently seeded training draws paired with nonoverlapping test groups; conditional on one task suite and model); no per-step pseudoreplication. Primary stress contrast is 180 minus 12. Keep only if always-push and matched push both decline (upper 95% bound below zero), failure's change exceeds matched push's change (lower bound above zero), failure retains within 5 percentage points of its own 12-atom score (lower bound above −5 pp), and failure beats FLARE-style retrieval by at least 5 pp at 180 (point estimate ≥5 pp and lower bound above zero). A failure-minus-confidence CI contained inside ±5 pp supports practical equivalence; otherwise a failed gate kills allocation, not the general hypothesis. Report corrupt-atom exposure per task and per queried task to distinguish lower overall delivery from better targeting.

## Reviewer-requested temperature control

Added during the greedy run, before its output was inspected. A temperature shift cannot change the greedy action, so rerun the largest stressed condition with temperature-one categorical decoding for all memory arms and an unscaled no-memory reference. Use one fixed, shared uniform draw per task and attempt across arms. Add one no-memory arm that changes temperature only on retries with the same literal failure trigger as failure pull.

Fit one temperature on 48 official training tasks (eight per family), excluded from every memory index. Match the mean entropy of the 180-atom failure-pull retry distributions on those source tasks, weighting each literal-failure retry state by its no-memory first-action probability. Apply the fitted temperature unchanged to held-out retries. Compare each memory arm and the unscaled no-memory reference against this control with paired block CIs. Claim a memory benefit only if its paired lower bound against the entropy-matched control exceeds zero; this is separate from the frozen greedy mechanism gates.
