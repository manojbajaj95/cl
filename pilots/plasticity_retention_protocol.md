# Plasticity reserve: retention-matched follow-up protocol

The [PR #9 pilot](https://github.com/manojbajaj95/cl/pull/9) found a 4.90 pp next-task gain range across current-loss-matched candidates, but its unprojected Gramian failed to beat optimization readiness. The [review ledger](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/idea-ledger.md) limits that verdict to unconstrained adaptation. This follow-up tests whether candidate differences survive under jointly matched retention and constrained adaptation.

- Reuse PR #9's stream, MLP, write schedule, eight proposals, and 50-step gain assay. On a uniform-random matched trajectory, run the same five adaptation permutations for all candidates at each of 49 nonterminal writes. Assay rollouts are not committed. Sweep 512 predetermined stream seeds (101–612; the first three overlap PR #9).
- Start from PR #9's eight current-MSE-matched endpoints. Backtrack toward their lowest-current-loss endpoint until all eight lie within the same 2% relative MSE range for **each** current and preceding task, using the 32-pattern population panel for each context. Use the same panel for each past task even if contexts recur. This matches retention across candidates, not against the pre-write model; it does not guarantee that the write avoided forgetting. The comparison arm uses the original current-only endpoints at the same checkpoint.
- Store one average per-task MSE gradient on the exact task panel, evaluated once at the lowest-current-loss reference shared by the candidates. Include the just-written task in memory when evaluating the next task. Freeze the orthogonal complement of the span of stored gradients for every candidate and every adaptation step at this write, excluding numerical null directions. This protects linearized loss directions, not the exact old-task function or nonlinear loss.
- Before scoring, report the within-write range of repeat-averaged absolute next-task MSE reduction, with 95% stream-level t CIs, in both the original (current-only match, plain SGD) and new (joint match, projected SGD) settings. The 1.5-point absolute gate is 0.015 in raw MSE units, not a percent change: stop if either mean range is below that threshold. Also report the original and new relative range, the paired relative range change from the current-only projected comparison, and the crossed candidate × adaptation-order variance decomposition. Advance only if the lower 95% bound for the order-corrected absolute candidate signal variance is positive; stream-level uncertainty is estimated across independent seeds, not writes.
- If the gate passes, test whether the projected Gramian is a better predictor than both projected current-task optimization readiness and projected next-task readiness (an explicitly labeled, task-aligned oracle). Also test forecast-weighted write selection ([PR #10](https://github.com/manojbajaj95/cl/pull/10)): use a past-task-only forecast of future residual covariance to predict projected k-step gain and compare with projected readiness on the identical forecast. Compare paired within-write Spearman correlations with a stream-cluster bootstrap and compare each picker with the exact uniform random expected gain at the same write. Keep a score only if it beats its readiness control and random with positive lower 95% bounds; no further scale-up is part of this screen.
