# Memory-loop Lyapunov pilot: fixed protocol

**Question.** Does an early, same-stream memory perturbation forecast which update rules are most order-dependent, better than directly screening two short orders? This is a CPU kill screen for [C2](https://github.com/manojbajaj95/cl/pull/7), using the later [reviewer budget and gate](https://github.com/manojbajaj95/cl/pull/6).

## Simulator

- Four overlapping synthetic binary rule-induction tasks share a noisy context space. An entry stores a unit embedding, a soft action payload, and a retrieval utility. The loop retrieves a top-four weighted vote, samples an action, and uses noisy binary correctness feedback to update the memory used by subsequent queries. There is no LLM or token generation.
- Eight update policies: append only, FIFO, utility eviction, similarity merge, whole-bank summary/rewrite, retrieved-entry reflection, reward-triggered consolidation, and high-gain rewrite. Initial entries, data generation and probes are identical across designs within a seed. Design constants are fixed in `experiment.py` before running trajectories.
- Seeds 101, 202, 303; 200 distinct episodes per seed, 50 per task. In each 20-episode cycle, the four task blocks contain five episodes each. Four balanced block permutations are repeated for ten cycles. Orders permute the **same** episode IDs; loop random draws are indexed by episode ID, so changing order does not change an episode's exogenous draws. The seed-only arm uses identical initial memory and episodes but a separate independent stream of loop draws. Perturbation and reference use identical draws.
- Behavioral distance is root mean square difference in the predicted probability of action 1 on 128 fixed balanced probes disjoint from the stream and the convergence probes. The long target is mean behavioral distance over all six order pairs at update 200. Secondary outcome is max minus min expected clean accuracy across those orders, on the same probes. This tests endpoint order dependence, not persistence after common replay or convergence to an attractor.

## Early predictors (no trajectory information after update 20)

- **λ:** add +0.001 to the first initial payload, a small absolute action-probability change. Regress natural log of the full RMS-distance curve (initial state through update 20) on step, flooring distance at 1e-8 solely for logging. Units are per update; there is no rescaling or trajectory selection. This is a finite-time behavioral rate, not an asymptotic largest exponent. Exact recoupling can make the rate depend on the log floor; raw distances are retained.
- **Direct control:** distance at update 20 between the first two prescribed orders (same 20 episodes, two permutations, matched draws).
- **Growth/edit:** net entry count change per update; number of existing entries modified or deleted per update (appends are not edits).
- **Convergence:** [2611.01304 §3.1, §3.5 and Table 1](https://arxiv.org/abs/2611.01304) logs whether/when the model declares convergence, final prompt length, and rejected drafts. In this fixed-horizon simulation, a shadow evaluator compares each proposed post-update memory against its predecessor on a separate balanced set of 128 clean validation probes. A draft is accepted by the evaluator if expected accuracy improves by more than 0.002; three consecutive rejections trigger a declaration at the third rejection; no declaration by 20 is coded as 21. Report non-declaration, first declaration level, shadow draft rejection fraction, and entry count at 20 (length proxy; with fixed initial size this is rank-equivalent to growth). The shadow does not alter the real trajectory. This is not a replication of model self-reports or candidate conversations: test budget is fixed and testing intensity cannot rank policies. The paper's prompt-content and conversation analyses are not stopping criteria.

## Fixed analysis and stopping rule

- Primary: Spearman ρ across the eight design means. Secondary: pooled 24 paired design–seed units, and the clean-accuracy-spread outcome at both levels. Ties use average ranks; constants give undefined (`null`), not zero. Report each signed ρ and paired differences. Use 10,000 paired percentile bootstrap draws, resampling designs and seed blocks with replacement (share the same seed indices across all sampled designs); exclude degenerate draws and record the valid count. These are uncertainty summaries from eight designs and three seed blocks, not a guarantee of coverage on other designs.
- Noise-floor check: on each paired unit, take the mean over updates 1–20 of perturbed distance minus seed-only distance (report raw curves and the mean distances as well). Report 95% paired percentile intervals for each design (seed blocks only) and pooled over designs/seeds. Call it usable separation only if the pooled CI lies above zero; being below the seed-only floor is not detectable perturbation amplification. Design CIs are descriptive, not eight separate gates.
- **KEEP** only if primary ρλ − ρdirect is at least 0.30, ρλ is strictly greater than each defined growth/edit/convergence baseline's absolute ρ (a strong inverse baseline can also predict), and pooled perturbation separation clears the noise floor. Otherwise **KILL**. Undefined λ/direct correlation fails that gate; constant baselines cannot rank and are reported. The 0.30 comparison uses the point estimate per the reviewer; report its paired CI without adding a CI-width gate. No tuning or follow-up metric selection after seeing results.

[2610.28981](https://arxiv.org/abs/2610.28981) motivates matched perturbation controls: it measures how representation/design changes propagate in LLM social simulations, not an early sensitivity slope as a classifier of later order dependence across memory update rules.
