# Plasticity reserve: CPU pilot protocol

Frozen 2026-11-24 15:00 UTC, before evaluating seeds 101–103.
Runner SHA-256: `721d03d607af79d746f85d19e987040cba3a6a67fbfbd2784539cb2f4a15927d`.

- **Claim and counterexample.** For writes fitting the same current task equally well, preserving unlabeled output reachability should predict and improve learning the next task. A larger reachable probe volume can lie in directions unrelated to next-task residuals.
- **Stream.** 50 Slowly-Changing Regression tasks, 15 slow bits (one uniformly chosen flip per transition), 5 fresh fair bits and a constant input. A fixed 100-LTU teacher uses ±1 weights and output scaling by `1/sqrt(100)`. The student is a scalar-output 5×5 ReLU MLP. Task 1–10 vs. 41–50 random-policy gain is the exposure check; four independent stationary targets per seed are a secondary control against differences in adjacent-task difficulty.
- **Writes.** Use plain SGD (batch 4, 1,500 steps per task, learning rate 0.06, no regularization). Share the first 1,468 batches; form eight endpoints by permuting the same last 128 examples independently. Compare exact current-task MSE on all 32 equally probable input patterns (current context only). Backtrack each out-of-band endpoint toward the lowest-loss raw endpoint until the eight losses have at most 2% relative range. Expose the same task, proposal budget, and admissibility rule to all policies.
- **Choosers.** Uniform random; maximal probe Gramian log determinant (equivalent to minimal loss from the common pre-write checkpoint); maximal penultimate feature effective rank; maximal current-task optimization readiness (OR); and maximal next-task OR, an explicitly supervised lookahead oracle. Use 64 fixed random unlabeled binary probe inputs spanning slow contexts and ridge 0.001. Include trace-normalized Gramian effective rank as a prediction-only baseline. For OR, use the supervised estimator from [Wang et al., §4 and Appendix D.3](https://arxiv.org/abs/2605.09044), a 256-example labeled support draw and 128 size-four mini-batches sampled with replacement. The next-task support is not used by any deployable policy and is independent of the adaptation and evaluation draws.
- **Measurement.** Next-task speed is relative test MSE reduction after 50 fresh SGD steps (batch 4, learning rate 0.01), measured on 256 separately drawn examples. Use five different permutations of the same adaptation examples, common across candidates. Do not commit these diagnostic rollouts. For the candidate-level tests use the 49 nonterminal writes on each random trajectory. Fit a two-way candidate × batch-order variance decomposition. For each write rank candidate scores against mean next-task gain; constant ranks contribute zero and are counted. Average writes within each seed before calculating 95% CIs. Use stream-level Student t CIs as primary, and a paired circular block bootstrap (10,000 draws, block length 7, resampled streams) as a correlation sensitivity check. The policy-level endpoint is task-50 gain; task 41–50 mean gain and absolute test MSE are secondary. Pair all deltas by stream seed.
- **Decision.** Do not scale if random late-task gain does not decline, candidate signal variance does not exceed zero, the Gramian-vs-readiness correlation improvement is not supported (positive lower 95% bound; show both information-matched current OR and task-aligned next OR), or final-task Gramian gain is not higher than random with positive lower 95% bound. Wide intervals are not wins. The three-seed pilot is a screen, not a population estimate with high power.

Calibration used only seeds 1–4. Among seven small SGD settings (widths 3, 5, 10; 500 or 1,500 steps; learning rates 0.01, 0.03, 0.06), the chosen setting gave the largest mean early-to-late drop on the online stream among those tested. After switching the match panel from sampled to exhaustive, the development drop was 18.09 percentage points online and 3.29 points on the independent target control.
