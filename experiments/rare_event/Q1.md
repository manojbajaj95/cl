# Q1 pilot: kill at the variance gate

The ten-seed rerun of [PR #12](https://github.com/manojbajaj95/cl/pull/12)
failed the reviewer's gate for the [gradient-share front hypothesis](https://github.com/manojbajaj95/cl/pull/7).
Within-arm seed variance in old-jam recovery was **2.09×** across-arm variance
(paired-seed bootstrap 95% CI **[0.75, 2.85]**). The point estimate fails the
required within < across comparison even when the no-replay diagnostic is
excluded. The interval crosses 1: this is a stop decision for the pilot, not
evidence that gradient share cannot explain recovery in a less noisy setup.

| Arm set | Within (pp²) | Across (pp²) | Within minus across (pp²) | Within / across |
| --- | ---: | ---: | ---: | ---: |
| All seven arms | 16.37 [5.82, 23.51] | 7.85 [5.55, 17.62] | 8.52 [−2.62, 13.82] | 2.09 [0.75, 2.85] |
| Six replay arms only | 19.02 [6.75, 27.32] | 9.34 [6.26, 21.11] | 9.68 [−3.40, 15.87] | 2.04 [0.74, 2.84] |

Within is the mean of the arms' sample variances over the ten seeds. Across
is the sample variance of the arm means (no correction for noise in the means).
Intervals are 95% percentile intervals from 20,000 bootstrap draws of ten
seeds with replacement, using the same resampled seeds for every arm. Arms
are fixed; replay samples are not treated as independent replicates.

### Gradient traces and stopping rule

Each of the 60 replay arm–seed pairs logged 512 steps × 8 replay samples,
for 245,760 per-sample observations. Each trace stores the jam mask, the L2
norm of the sample's gradient on the 896 trainable adapter parameters, and
its weighted loss contribution. Both incorporate the sampler's importance
weight and the replay multiplier divided by batch size. The gradient norm
is the absolute derivative of the sample's loss with respect to its scalar
logit times the norm of its frozen feature vector. There are no replay
samples for the no-replay diagnostic. All 60 traces had finite values,
nonnegative norms, and jam totals matching the sampler's counters.

Because the reviewer required passing the noise gate before proceeding, we
did not fit the Pareto front, compare R² against jam count or loss share, or
run the held-out weight-4 test from [PR #13](https://github.com/manojbajaj95/cl/pull/13).
Those tests remain unperformed, not failed.

### Reproduce

Use the dependency versions in [the original pilot](README.md#reproduce).
These commands regenerate the per-step traces and full-precision outcomes
with the pinned Qwen2.5-0.5B revision on CPU:

```bash
out="$HOME/.cache/cl-q1"
mkdir -p "$out"
HF_HUB_DISABLE_XET=1 python experiments/rare_event/pilot.py --threads 8 \
  --cache "$out/features.pt" --features-only
python experiments/rare_event/pilot.py --threads 1 --cache "$out/features.pt" \
  --seed-count 10 --gradient-log "$out/gradients" --output "$out/runs.json"
python experiments/rare_event/q1_gate.py "$out/runs.json"
OMP_NUM_THREADS=1 python -m unittest discover -s experiments/rare_event -v
```
