# Agent proposer batch 1: inoculated memory, Baldwin vs Lamarck, time-travel memory

**Reviewer verdict: all three KILLED** (see the PR #6 ledger): A1 ties a skeptic instruction plus exemplars (inoculation prompting 2606.30252 exists); A2 is cross-episode meta-RL (2602.04089); A3's flat reacquisition holds by construction (Forget-Me-Not).

Angle: agents that keep learning after deployment. Prior-art checks via alphaXiv on 2026-11-24.

## A1. Memory inoculation: prebunk a lesson pool before the misleading experience arrives
**Claim.** Inoculation theory (McGuire 1961) says exposure to a weakened attack plus its refutation makes beliefs resist later full-strength attacks. For an agent whose memory is rewritten from experience, seed the pool with a few *weakened* false lessons each paired with the evidence that refutes it ("looked like X, was actually Y because Z"). The agent then rejects later misleading episodes (spurious correlations, poisoned feedback, a shift that only looks real) without a separate filter, while still accepting genuine rule changes. The inoculation should transfer across attack families that share the refutation *pattern*, not the content.
**Why it matters.** Current defenses are gatekeepers (falsification gates, paired-evidence routing, provenance checks) that sit outside memory and cost a verifier call per write. Inoculation is a property of the memory itself and is free at write time. It also gives a clean dose-response to measure: inoculation strength vs. later false-acceptance vs. true-change latency.
**Pilot.** Qwen2.5-1.5B (CPU GGUF) agent with a rewritten lesson memory on a rule-induction stream with (a) real rule changes and (b) decoy episodes that support a false rule. Arms: no defense, inoculated (3 weakened decoys + refutations, different content from the test decoys), verifier gate, inoculated + gate. Measure false-rule adoption, revision latency on real changes, tokens spent. **Kill** if inoculation does not cut false adoption by ≥30% relative at ≤10% added true-change latency, or if it only works when test decoys share content with the inoculation.
**Closest.** InjecMEM (2608.23471), MemoryDojo (2611.09721) are attacks/benchmarks; Accept Changes, Reject Attacks (2610.41056) and falsification-gated evolution (2611.14326) are external gates. No prebunking of agent memory found. Distinct from PR #4 (contamination spread rate), which measures spread, not resistance built into the pool.

## A2. Baldwin vs. Lamarck for agents: train weights for how well the memory loop learns, not for what it learned
**Claim.** Every "internalize experience" method (context/on-policy distillation of lessons into weights) is **Lamarckian**: acquired traits are written into the genome. Evolutionary theory (Hinton & Nowlan 1987; Sasaki & Tokoro 1997) predicts Lamarckian inheritance wins in stationary worlds and *loses* in changing ones, where **Baldwinian** selection, which rewards the capacity to learn during a lifetime, wins. The agent analogue: update the weights (small LoRA, via RL or ES) to maximize the *slope* of a memory-augmented agent's performance over an episode stream, never on the lessons themselves. Prediction: Baldwinian agents beat Lamarckian ones on held-out rule families after a shift, Lamarckian wins on the training rules, and the crossover is set by the environment's rate of change.
**Why it matters.** It reframes the memory→weights consolidation debate as a known evolutionary tradeoff with a predicted crossover, and gives a training objective (lifetime learning slope) that current self-evolving agents do not use.
**Pilot.** SmolLM-360M or Qwen2.5-0.5B with a LoRA, a text-memory loop, and synthetic rule families with controlled drift rate. Lamarckian: on-policy distill successful in-context trajectories into the LoRA. Baldwinian: ES/GRPO on the LoRA with reward = improvement from episode 1 to episode k with memory on. Equal update budget. Sweep drift rate. **Kill** if no crossover appears across ≥3 drift rates, or Baldwinian never beats Lamarckian on held-out families.
**Closest.** Meta-Learning by the Baldwin Effect (1806.07917) is for MAML-style init in small nets; COEVO (2609.33398) co-evolves context and parameters but optimizes the final score. On-policy context distillation (2610.07250, 2611.14009) is the Lamarckian arm. No test of the Baldwin/Lamarck crossover for LLM agents found.

## A3. Time-travel memory: switch among frozen past selves instead of overwriting one memory
**Claim.** A single evolving memory must re-learn a regime each time it recurs. Keep every k-th memory snapshot frozen and choose among them online with Fixed Share / switching experts on prequential loss. Online learning theory then gives a tracking-regret bound of O(S·log(N·T)) for S regime switches over N snapshots, so a recurring regime is reacquired in O(log N) steps instead of the re-learning time, while the live memory keeps learning. The novel prediction: reacquisition time on recurrence becomes *independent of how long the regime was absent*, which no overwrite-based memory achieves.
**Why it matters.** It turns agent memory versioning into a learner with a provable guarantee and a sharp measurable signature (flat reacquisition-vs-absence curve). Storage is cheap for text, so the usual objection to snapshot ensembles does not apply.
**Pilot.** Qwen2.5-1.5B agent on a stream with 4 rule regimes recurring after delays of 10–200 episodes. Arms: one rewritten memory, append-only + retrieval, snapshot pool + Fixed Share, snapshot pool + oracle selection. Plot reacquisition latency vs. absence length, plus tokens/storage. **Kill** if Fixed Share's reacquisition latency still grows with absence length, or retrieval over an append-only log matches it at equal tokens.
**Closest.** Where Should Learning Live? (2611.09701) gives regret for selecting prompts vs. adapters, not snapshots of an evolving memory; Recurrent Harness (2610.12668) and Lifelong Context Adaptation (2610.32295) use one evolving state. No snapshot-switching memory with recurrence guarantees found.
