## H1. Minority lessons from rare regimes: surprisingly-popular aggregation for fleet memory
**Claim.** When a fleet of agents pools lessons, every selection rule in use (frequency, majority vote, LLM-judge consensus, reputation) favours what most agents saw. A lesson about a rare regime (an API edge case, a minority user type) is learned only by the few agents that hit it, so consensus discards it, and the shared pool is systematically blind to the tail. The surprisingly-popular rule (Prelec, Seung & McCoy 2017) selects the answer whose actual endorsement exceeds the endorsement agents *predict* others will give. Agents that saw the rare case know the majority hasn't, so they predict low endorsement for their own lesson, and that gap is the signal. Prediction: SP selection keeps correct rare-regime lessons that majority discards, at equal pool size and no ground truth, and the gain grows as the regime gets rarer, until too few agents have seen it.
**Control that could tie, and why it should fail.** Majority/frequency vote, LLM-judge consensus, confidence-weighted voting, and dependence-aware truth discovery (2611.04805). These all weight by agreement or confidence. A correct minority lesson has low agreement, and its holders' confidence does not exceed that of a confidently wrong majority. Only the meta-prediction gap separates them. The real risk is the other direction: agents sharing one base model may predict others identically whatever they saw, which flattens the gap. The pilot measures that directly.
**Pilot.** Fleet of 32 Qwen2.5-1.5B agents (CPU, short episodes) on a synthetic API world where a fraction p ∈ {0.5, 0.2, 0.05} of agents encounter a rare regime whose true lesson contradicts the common-regime heuristic. Each agent proposes lessons, endorses candidates, and predicts the fleet's endorsement share. Select a pool of size K by each rule, then evaluate the whole fleet on common and rare tasks. **Kill** if SP does not beat the best control on rare-regime accuracy by ≥10 points at p = 0.2 without losing more than 2 points on common tasks, or if the agents' meta-predictions do not depend on their own experience (correlation of predicted share with own-observation < 0.2).
**Closest.** Truth discovery among correlated LLM agents (2611.04805) and wagering aggregation (2607.04389) aggregate answers, not memory. BTS has been used against sycophancy in training (2608.25267). Fleet memory systems (CoMem 2609.15009, reputation memory 2609.19502, Σ-Mem 2607.27958) weight by agreement or reliability. I found no SP or peer-prediction selection for shared agent memory, and no account of tail-regime blindness in pooled lessons.
