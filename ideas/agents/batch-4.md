# Agent proposer batch 4: implicit-update capacity and write-time poisoning detection

Both ideas build on the implicit-update proxy from B3 (passed review) but make separate claims. Dropped before sending: lesson obsolescence from the agent's own policy drift (Experience Rot 2611.20922 and StaleBench 2611.19752 cover it), and hidden-state-keyed memory retrieval (Neural Procedural Memory 2606.29824 and Memory Control Signals 2609.27286 cover it).

## D1. A context capacity law for lessons: the "more memory, worse agent" peak is set by the effective rank of implicit updates
**Claim.** Adding lessons first helps and then hurts (2610.27406, Experience Rot). If each lesson acts as an implicit update ΔW_i, the lessons superpose in a bounded subspace of the attention update. The accuracy peak N* is reached when the stacked {ΔW_i} stop adding effective rank, so later lessons mostly rotate or cancel earlier ones. Prediction: N* ≈ the point where the effective rank of [ΔW_1..ΔW_N] saturates, computable from lessons alone before any task is run. Rewriting lessons to raise effective rank (diversifying their implicit directions, not their topics) moves the peak right.
**Control that could tie, and why it should fail.** Token count, lesson count, and embedding diversity (effective rank of sentence embeddings) of the same pool. Embedding diversity measures topical spread. Two lessons on different topics can drive the same attention-update direction (both redirect one tool argument), and two lessons on one topic can be orthogonal. A length-matched dilution control (the B3 reviewer's control) separates capacity from plain context dilution.
**Pilot.** Qwen2.5-1.5B on a rule-induction or ALFWorld-text stream. Build 12 lesson pools with different topical and implicit-update diversity. For each, sweep N = 1–128 and find the accuracy peak. Compute the effective-rank saturation point from lesson-only forward passes. **Kill** if the predicted N* has rank correlation < 0.5 with the measured peak across pools, or embedding-rank saturation predicts as well (Δρ < 0.2), or the peak vanishes under the length-matched dilution control.
**Closest.** More Memory, Worse Agents (2610.27406) and Memory Tax (2610.34073) measure the peak behaviourally. ICL-as-implicit-GD papers do not connect rank to memory capacity. I found no pre-task predictor of the memory peak.

## D2. Poisoned memories are loud: detect injected lessons at write time by off-target implicit-update energy
**Claim.** A benign lesson's implicit update is concentrated on queries in its own domain. An injected or poisoned memory (InjecMEM-style, or a trigger planted to fire on unrelated tasks) has to change behaviour *off-domain* to work, so its implicit update has unusually large energy on random off-domain probe states. A label-free, single-forward-pass score (off-domain ΔW energy relative to on-domain) should flag poisoning at write time without a judge LLM, without task feedback, and without waiting for drift to show up downstream.
**Control that could tie, and why it should fail.** Perplexity filtering, an LLM-judge "is this memory suspicious?" at the same budget, and embedding outlier detection. Attacks phrased as plausible, on-topic advice pass all three because they read as normal. Their *effect* is off-target, and that is what the score measures. Adaptive attacks that minimise off-target energy have to give up attack success, which the pilot measures as a tradeoff curve.
**Pilot.** Qwen2.5-1.5B agent memory with 500 benign lessons and 50 poisoned ones from MemoryDojo (2611.09721) and InjecMEM (2608.23471) attack families, including plausible-wording variants. Report AUROC of the score vs. the three controls, plus an adaptive attack that adds an off-target-energy penalty. **Kill** if AUROC is not above the best control by ≥0.1 on plausible-wording attacks, or the adaptive attack drives AUROC to < 0.65 while keeping ≥ 70% of its success rate.
**Closest.** DriftGuard (2611.25583) detects drift after the fact via causal attribution, and the neuro-inspired repair work (2610.13267) and Accept Changes, Reject Attacks (2610.41056) use gates and audits. I found no write-time, label-free mechanistic detector.
