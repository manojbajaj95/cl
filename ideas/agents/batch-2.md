# Agent proposer batch 2: group-tested credit, vocabulary growth, in-context gradient alignment

Prior-art checks via alphaXiv on 2026-11-24.

## B1. Group testing for lesson credit: find the harmful lessons in O(k log N) evaluations
**Claim.** Lesson-level credit today is per-entry ablation (N evals), learned utility scores, or LLM judgment. If at most k of N lessons are harmful and effects are roughly additive or threshold-like, *non-adaptive combinatorial group testing* (random pooled ablations decoded with COMP/DD or sparse regression) identifies them with O(k log N) evaluation batches. The twist that makes it research and not engineering: lesson effects interact (one lesson only hurts in the presence of another). Group testing with a *pairwise* model recovers these interactions too, which ablation cannot see at all. That yields the first measurement of how sparse and how interactive lesson pools actually are.
**Why it matters.** Cuts memory-audit cost by roughly N/(k log N) and gives a structural fact about agent memory (sparsity and interaction order of lesson effects) that decides which credit-assignment methods can work.
**Pilot.** Qwen2.5-1.5B on a rule-induction or ALFWorld-text stream, N=64–256 lessons with k planted harmful ones (stale rules, wrong tips) plus naturally accumulated ones. Compare one-at-a-time ablation, Shapley sampling, and group testing at equal eval budget on recall of planted lessons and on downstream gain after pruning. **Kill** if group testing needs more than half the evals of single ablation for the same recall, or interactions are so dense that no sparse decoder works (that negative is itself a finding to report).
**Closest.** MemCredit (2611.15600) learns utility; MemoryDojo/MemHarmBench benchmark poisoning; Fisher-style counterfactual ablation (batch 2 #6 in PR #5) is one-at-a-time. No pooled/group-testing design for memory credit found.

## B2. Grow the vocabulary, not the weights: zero-forgetting skills as new tokens mined from experience
**Claim.** A deployed agent can mine recurring sub-trajectories (tool-call macros, reasoning moves) and add each as a *new token* whose input/output embeddings are the only trained parameters. The base model is untouched, so old behaviour is preserved exactly when the token is not emitted; forgetting is structurally zero. The surprising prediction is compositional: tokens learned separately can be used in sequence and as arguments of each other without joint training, because they live in the same frozen residual space. Skill capacity then scales with vocabulary size, with interference only through output-softmax competition, which is measurable and tunable.
**Why it matters.** It is a third place to put continual learning (beside context and weights) with an exact no-forgetting guarantee and near-zero inference cost, unlike growing context or adapter banks.
**Pilot.** Qwen2.5-0.5B on a text tool environment (ALFWorld-text or synthetic API tasks). Mine top-m macros from successful traces; train one embedding pair per macro by distillation on traces where the macro appears. Measure task success vs. m, base-task retention (should be exact), composition of macros never co-trained, and false-trigger rate. Baselines: in-context skill library, LoRA per skill, ToolkenGPT-style single-tool tokens. **Kill** if new tokens do not beat an in-context skill library at equal tokens on held-out tasks, or false triggering degrades base tasks by more than 1 point.
**Closest.** ToolkenGPT (2305.11554) and Toolken+ (2410.12004) learn tokens for given tools, not macros mined online; Factorized Skill Memory (2610.15492) and skill-internalization work update weights. No online vocabulary growth from experience as a CL mechanism found.

## B3. Lessons interfere like gradients: predict and remove in-context forgetting with implicit-update alignment
**Claim.** If ICL acts like an implicit weight update (Dai et al. 2023; von Oswald et al. 2023), each lesson in context induces an implicit ΔW (estimable from the shift in attention outputs it causes on probe queries). Adding lesson B then hurts behaviour that relied on lesson A in proportion to −⟨ΔW_A, ΔW_B⟩, the same rule GEM/OGD use for weights. If that holds, classical CL tools transfer to text memory: project a new lesson's wording until its implicit update is orthogonal to protected ones ("orthogonal lessons"), detected and fixed before any task is run.
**Why it matters.** It is a quantitative bridge between parametric CL theory and text-memory agents, giving a zero-shot interference predictor and a rewrite objective; current memory systems detect conflicts only semantically or by trial.
**Pilot.** Qwen2.5-1.5B (HF, CPU ok for short contexts). 200 lesson pairs from rule tasks; for each, compute the implicit-update proxy (hidden-state deltas at the last layers on 32 probe queries) and measure actual accuracy loss on A's tasks when B is added. Report rank correlation vs. baselines (embedding cosine, NLI contradiction score). Then rewrite B with an LLM guided by the proxy and measure interference reduction. **Kill** if the proxy's rank correlation with measured interference does not beat NLI contradiction by ≥0.15.
**Closest.** Controlled Memory Interference in Continual LLM Agents (2608.07622) measures interference behaviourally; ICL-as-gradient-descent papers do not apply it to memory interference. No implicit-update alignment predictor for lesson conflicts found.
