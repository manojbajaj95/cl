## B2. Grow the vocabulary, not the weights: zero-forgetting skills as new tokens mined from experience
**Claim.** A deployed agent can mine recurring sub-trajectories (tool-call macros, reasoning moves) and add each as a *new token* whose input/output embeddings are the only trained parameters. The base model is untouched, so old behaviour is preserved exactly when the token is not emitted; forgetting is structurally zero. The surprising prediction is compositional: tokens learned separately can be used in sequence and as arguments of each other without joint training, because they live in the same frozen residual space. Skill capacity then scales with vocabulary size, with interference only through output-softmax competition, which is measurable and tunable.
**Why it matters.** It is a third place to put continual learning (beside context and weights) with an exact no-forgetting guarantee and near-zero inference cost, unlike growing context or adapter banks.
**Pilot.** Qwen2.5-0.5B on a text tool environment (ALFWorld-text or synthetic API tasks). Mine top-m macros from successful traces; train one embedding pair per macro by distillation on traces where the macro appears. Measure task success vs. m, base-task retention (should be exact), composition of macros never co-trained, and false-trigger rate. Baselines: in-context skill library, LoRA per skill, ToolkenGPT-style single-tool tokens. **Control that could tie, and why it should fail.** Retrieval of top-k skill texts with short names at equal context. That ties at small libraries. The prediction is a divergence with library size: retrieval accuracy falls with library size (routing failures at scale, 2610.18522), while token skills stay flat, because selection happens in the output softmax over learned embeddings, not in a lexical/embedding retriever reading descriptions. **Kill** if token skills do not beat top-k retrieval by ≥5 points at a 1,000-skill library with equal context, or false triggering degrades base tasks by more than 1 point.
**Closest.** ToolkenGPT (2305.11554) and Toolken+ (2410.12004) learn tokens for given tools, not macros mined online; Factorized Skill Memory (2610.15492) and skill-internalization work update weights. No online vocabulary growth from experience as a CL mechanism found.

## B3. Lessons interfere like gradients: predict and remove in-context forgetting with implicit-update alignment
**Claim.** If ICL acts like an implicit weight update (Dai et al. 2023; von Oswald et al. 2023), each lesson in context induces an implicit ΔW (estimable from the shift in attention outputs it causes on probe queries). Adding lesson B then hurts behaviour that relied on lesson A in proportion to −⟨ΔW_A, ΔW_B⟩, the same rule GEM/OGD use for weights. If that holds, classical CL tools transfer to text memory: project a new lesson's wording until its implicit update is orthogonal to protected ones ("orthogonal lessons"), detected and fixed before any task is run.
**Why it matters.** It is a quantitative bridge between parametric CL theory and text-memory agents, giving a zero-shot interference predictor and a rewrite objective; current memory systems detect conflicts only semantically or by trial.
**Pilot.** Qwen2.5-1.5B (HF, CPU ok for short contexts). 200 lesson pairs from rule tasks; for each, compute the lesson-only implicit-update proxy (no task or probe forward passes) and measure actual accuracy loss on A's tasks when B is added. Report rank correlation vs. baselines (embedding cosine, NLI contradiction score). Then rewrite B with an LLM guided by the proxy and measure interference reduction. **Control that could tie, and why it should fail.** Embedding cosine or an NLI contradiction score between lessons. These see topical or logical conflict, but miss lessons that conflict through shared *procedure* with no shared wording (two tips that both redirect the same tool argument), which the implicit-update overlap captures. Running A's probes with B added ties trivially but costs the evaluation the proxy is meant to avoid, so it is the ceiling, not a competitor. **Kill** if the proxy's rank correlation with measured interference does not beat NLI contradiction by ≥0.15.
**Closest.** Controlled Memory Interference in Continual LLM Agents (2608.07622) measures interference behaviourally; ICL-as-gradient-descent papers do not apply it to memory interference. No implicit-update alignment predictor for lesson conflicts found.
