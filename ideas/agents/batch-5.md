# Agent proposer batch 5: predicting what survives consolidation, tuning memory loops to the edge of chaos

These ideas follow from the two survivors (B3 implicit updates, C2 memory-loop Lyapunov exponent) but make separate claims. Dropped before sending: critical-slowing-down early warnings for memory collapse (World-Model Collapse as a Phase Transition 2606.31399 and weak-chaos world models 2609.17419 are too close).

## E1. Which lessons survive consolidation into weights? Predict it from the lesson's implicit update before training
**Claim.** Context distillation (OPCD 2602.12275, Cortex 2610.20399, localized CD 2610.21427) moves lessons from context into a LoRA, but some lessons transfer and others vanish. If a lesson's in-context effect is an implicit update ΔW_i (B3), a rank-r LoRA trained by distillation can only absorb the part of ΔW_i that lies in the span its gradients reach at those layers. Prediction: per-lesson consolidation success ≈ ‖P_LoRA ΔW_i‖ / ‖ΔW_i‖, computable from one forward and one backward pass before distillation. Lessons below threshold should stay in context, and lessons above it should be consolidated. That routing gives a hybrid memory that beats both all-in-context and all-distilled at equal context budget.
**Control that could tie, and why it should fail.** The lesson's in-context effect size, lesson length, and the first-step distillation loss drop. Effect size measures how much a lesson matters, not whether the adapter can represent it. A large-effect lesson can live in a direction the LoRA cannot reach, and that is exactly where the projection score and the effect size disagree. The first-step loss drop is the closest competitor, so the pilot reports it head to head.
**Pilot.** Qwen2.5-0.5B/1.5B, 300 lessons from rule-induction and ALFWorld-text, LoRA ranks {4, 16, 64}. For each lesson, compute the projection score, then run OPCD and measure retained effect after context removal. **Kill** if the score's rank correlation with retained effect is not ≥0.15 above the best control at every rank, or if score-based routing does not beat effect-size routing on downstream accuracy at equal context.
**Closest.** Transfer-Stratified OPD (2610.05974) stratifies which teacher *improvements* transfer by outcome, after training. ENGRAM (2611.09472) verifies experience before consolidating. LoRA memory laws (2605.30260, 2603.01097) are about capacity in aggregate. I found no pre-training, per-lesson predictor.

## E2. The edge of chaos is where self-improving agents learn best, and λ finds it without task feedback
**Claim.** C2 measures a memory loop's Lyapunov exponent λ. The reservoir-computing result is that computation is best near λ ≈ 0: contracting loops (λ ≪ 0) forget new evidence too fast to accumulate skill, and chaotic loops (λ > 0) amplify noise into order-dependent junk. Prediction: across an update-strength knob (edit budget per update, update-prompt temperature, merge aggressiveness), long-run accuracy is an inverted U whose peak sits at λ ≈ 0. So a loop can be tuned *label-free* by driving the λ estimate to zero online.
**Control that could tie, and why it should fail.** Tuning the knob on a held-out validation stream (the ceiling, which needs labels), and label-free heuristics: memory growth rate, edit-acceptance rate, self-consistency. The heuristics track how much the memory changes, not whether perturbations grow or shrink. A loop can change a lot while contracting, and change little while diverging.
**Pilot.** Same agent and stream as the C2 pilot (Qwen2.5-1.5B, ACE-style update), with 6 settings of each of 2 knobs. Measure λ (20-step two-memory divergence, seed-only noise floor) and 200-episode accuracy. Then run an online controller that adjusts the knob to hold λ ≈ 0. **Kill** if the accuracy peak is not within one knob step of the λ = 0 crossing for both knobs, or if the λ controller does not beat the best label-free heuristic by ≥3 points at the end of the stream.
**Closest.** Edge-of-chaos results for RNNs and reservoirs (Bertschinger & Natschläger 2004; Legenstein & Maass 2007) are about weights, not text-memory loops. Weak chaos in LLM world models (2609.17419) is descriptive. I found no λ-based label-free tuning of agent self-improvement.
