# Agent proposer batch 11: mechanisms mined from pilot surprises

Source: raw results of PRs #4, #9, #11, #12 (not analogy). Each idea starts from a number the pilot's own hypothesis does not explain.

## P1. Utility eviction is a Pólya urn: reward-coupled memory is non-ergodic, so order sensitivity grows with time (from PR #11)
**Surprise.** In `pilots/lyapunov/results.json`, utility eviction's order divergence rises from 0.173 RMS at update 20 to 0.417 at update 200, while FIFO falls from 0.224 to 0.195. This holds on the same order pair (0.414 vs 0.190 at 200). The 20-step comparator (ρ 0.91 overall) misranks exactly this crossover.
**Mechanism.** When retention depends on past success, an entry that succeeds early is kept, gets used more, and succeeds more: reinforcement with no decay, a Pólya urn. Urns are non-ergodic. The limiting composition is random and set by early draws, so different orders lock in different memories, and the divergence *grows* (≈ log t) instead of mixing out. FIFO and recency rules have bounded memory of the past, so they are ergodic and contract. Prediction: order sensitivity at horizon T is set by one measurable number, the reinforcement coefficient κ = ∂P(retain)/∂(past success count). With κ = 0 divergence saturates, with κ > 0 it grows, and multiplying utility scores by a decay γ per update caps it at a level ∝ 1/(1−γ).
**Control that could tie, and why it should fail.** The 20-step two-order divergence. It measures divergence before the urn has locked in, so it underpredicts every κ > 0 design at long horizons, which is the observed crossover. κ is measurable from a single run's logs, with no second order needed. A common-suffix control (same last 50 episodes, different prefixes) separates urn lock-in from plain recency.
**Per-design check (PR #11 raw).** Utility eviction and gated consolidation are the only designs where success changes *which entries are admitted or evicted*. On the same order pair they are the only two whose divergence grew in all three seeds (+0.24 and +0.09 RMS), and they have the two largest accuracy spreads among non-rewrite designs (7.1 and 3.5 pp). FIFO shrank in all seeds, and every other design had mixed signs. All designs use success-weighted *retrieval*, so the urn is in admission and eviction specifically, not in retrieval weighting. High-gain rewrite is high but flat (0.345 → 0.350): chaotic from the start, not an urn.
**Pilot.** Reuse PR #11's simulator. Add a success-blind ablation of utility eviction and gated consolidation (same rules, success replaced by a coin with matched rate), a common 50-episode suffix, and utility rules with κ ∈ {0, 0.25, 0.5, 1} and decays γ ∈ {0.9, 0.99, 1}, and horizons 50–1,000. **Kill** if κ does not beat the 20-step comparator at predicting T = 1,000 divergence (Δρ ≥ 0.2), or divergence under κ > 0, γ = 1 does not keep growing past 200 updates.
**Closest.** PATH-Bench (2608.01149) benchmarks path dependence in lifelong agents without a mechanism; decay-driven memory (Oblivion 2604.00131) uses decay but not as an order-sensitivity control. **Ledger.** C2 (Lyapunov) is killed. This makes a different claim: a mechanism for *why* some loops are order-sensitive, plus a one-run predictor for horizons the cheap comparator misses.

## P2. Is the plasticity spread a denominator artifact? Decompose it, then explain what remains (from PR #9)
**Surprise.** Equal-loss writes (current MSE within 0.4%) differ by 4.9 pp in next-task relative gain (CI 3.75–6.05), with candidate variance 7.5× the order variance. Every cheap selector does no better than random (regret 2.3–2.7 pp). Even labeled readiness flips sign on the largest gaps (seed 103, write 10: ρ −0.19, range 18.0–30.7%).
**Mechanism (two-stage).** (a) Relative gain = (L₀ − L_final)/L₀. Candidates that transfer *worse* zero-shot (higher L₀ on the next task) show bigger relative gain for the same absolute learning, so part of the spread is a ratio effect, not plasticity. (b) What survives should be set by *where the ReLU kinks sit relative to the drifting input bits*. Slowly-Changing Regression flips a few input bits per task. A candidate whose units have breakpoints that straddle those bits can re-route with small weight changes. One whose units are saturated on them must move biases first. Score: the fraction of units whose pre-activation sign changes when only the slow-changing input bits are flipped (an activation-pattern sensitivity), computed on current data with no next-task labels.
**Control that could tie, and why it should fail.** Readiness, Gramian, effective rank, dormant-unit fraction (all in PR #9's control set) and next-task L₀ alone. These are averages over all inputs, while the score targets the specific input directions the task stream perturbs. Local Redundancy (2607.13432) and Predicting Plasticity (2605.09044) are the closest published plasticity predictors and join the control set. If L₀ alone explains the spread, stage (b) is moot and the plasticity-reserve claim needs re-scoring with absolute gain.
**Pilot.** Re-run PR #9 logging per-candidate initial and final future MSE. Report absolute vs relative gain spread, then the kink-sensitivity score's within-write ρ. **Kill** if absolute-gain spread is < 1.5 pp (artifact), or the score's ρ with absolute gain is not ≥0.15 above readiness.

## P3. Writing is more distractible than acting: separate the write path from the act path (from PR #4)
**Surprise.** In the Qwen2.5-1.5B unit-conversion challenge with no verifier, one bad distractor in context moved defective lesson writes from 12/32 to 17/28 while solve accuracy stayed near zero (0/32 vs 1/28) (`agents/llm_pilot/results/real/trials.jsonl`).
**Mechanism.** Acting is conditioned on the task, so irrelevant content gets little attention. Writing a lesson is summarisation of the whole context, which pulls in whatever is salient. So contamination enters through the write path even when behaviour is unaffected. Prediction: write defects scale with distractor salience and count at constant solve accuracy, so α_S in the PR #4 R law is a function of context composition, not a constant. A writer that sees only the context tokens whose removal changes the agent's own action log-probs (an exact action-relevance mask) should cut write defects without changing what it learns from relevant content.
**Control that could tie, and why it should fail.** A same-length neutral-filler swap (rules out length), a "write only about the task" instruction (same-token), and LLM-selected relevant context. The instruction and the LLM selector rely on judging what is relevant. The log-prob mask measures it directly from the acting policy, so they should fail on salient-but-irrelevant distractors.
**Pilot.** Paired same-target trials: 0/1/2/4 distractors vs length-matched filler, ×3 salience levels, 64 trials each. Arms: plain writer, instruction, LLM selector, log-prob mask. **Kill** if the distractor effect on write defects vanishes against length-matched filler, or the mask does not cut defects ≥30% below the instruction arm.
