# Fleet-memory proposer batch 1: posterior-sampled fleet memory, lift-alignment triage at model upgrade

Angle: memory shared across many agents or many copies of one agent (pooling, transfer across model versions, conflict, provenance, collective learning). I read the ledger (PR #6) and agent batches 1–11 (PR #7) first. H1/H1b (surprisingly-popular selection) are piloting, so nothing here is about *selecting* lessons by agreement. Prior-art checks were run on alphaXiv on 2026-11-24.

Lesson from the ledger I build on: survivors use exact quantities only an LLM exposes (log-probs) or signals that consensus discards. Kills come from ties with a simple same-budget baseline and from 2026 papers.

## Q1. Bootstrapped fleet memory: copies write from resampled evidence, act by posterior sampling, and re-adapt after a regime shift
**Claim.** A pooled fleet memory is a point estimate. Every copy reads the same consensus lessons, so the fleet stops collecting evidence against them. This is the stale-copy half of Rogers' paradox, and 2609.38516 measured it: LLM populations that copy skills "concentrate around fewer independent discoveries" and do no better than solo learners at equal cost. The fix that bandits use is posterior sampling, not more noise. Each of the N copies writes its memory from a **bootstrap resample (Poisson(1) weights) of the shared episode log**, not from the whole log. At each episode a copy acts with its own memory, which is Thompson sampling over memories (bootstrapped-DQN logic, Osband et al. 2016). Two predictions follow. (a) After a regime shift, the fleet re-adapts faster than a pooled memory, because minority hypotheses that some resamples support are already being acted on. (b) Exact disagreement among the N memories, the variance over copies of log P(a | x, M_i), is an epistemic-uncertainty signal that rises at the shift before success drops. Base-model sampling entropy cannot give this signal, because it measures model uncertainty, not uncertainty about the evidence.
**Strongest control, and why it should fail.** (1) Pooled memory plus a temperature tuned so action entropy matches the bootstrapped fleet. It adds diversity that is uncorrelated with the evidence, so it explores in the wrong places. (2) Random lesson subsets: each copy reads a random K-subset of the pooled lessons at equal context. This diversifies at the memory level, not the data level. If it ties, resampling the evidence adds nothing and the idea dies. (3) Independent agents with private memories (no sharing). (4) H1-style SP-selected pool, if its pilot survives. Same tokens, same writer calls, same episodes for all arms.
**Smallest falsifying test.** CPU sim first, the H1/PR #11 style synthetic API world. N = 16 Qwen2.5-1.5B copies (or a scripted lesson-writer for the sim stage). A 2-regime world switches regime at episode 150 of 400, so the correct lesson flips. Measure episodes-to-recover (fleet success back to 90% of the pre-shift level) and the AUROC of each disagreement signal for "the next episode fails", 3 seeds. **Kill** if bootstrapped memory does not recover ≥25% faster than the best of controls 1–3 (CI excluding zero), or if random lesson subsets (control 2) are within the seed CI of it, or if memory disagreement's AUROC for the post-shift failure is not ≥0.10 above temperature entropy. Report pre-shift success too: **kill** if pre-shift success drops by more than 2 pp against the pooled memory (the posterior-sampling exploration cost).
**Closest prior art.** Bootstrapped DQN / ensemble sampling (Osband 2016; 2609.13954, 2602.08026) do this for value networks, not for text memories written by an LLM. 2609.38516 (social learning concentrates discoveries) and 2611.06022 (Rogers' paradox for model lineages) diagnose the problem but propose no posterior over memories. RBC 2610.18427 randomizes lessons on practice tasks to *curate* one playbook, a point estimate again. Interaction tax 2608.23541 and sparse debate 2609.27150 keep diversity by limiting communication, which is control 3. CoMem 2609.15009, XferAgent 2610.19581, FoH 2610.24007 and EpiCon 2609.37923 all pool into one shared library. I found no fleet memory that writes each copy's memory from resampled evidence or uses memory disagreement as epistemic uncertainty.
**Ledger check.** It is not H1 (which selects lessons, not explores), not C2/P1 (order dependence), and not "fleet synchronization" (killed at proposal in PR #7, which was about when to sync, not what each copy holds).

## Q2. Lift-alignment triage: predict, before an upgrade, which stored lessons the new model no longer needs or will be hurt by
**Claim.** Operators reload the same memory onto a new base model (2611.10628). Memory portability varies by direction: NOTES shift +9.9 / −13.3 pp depending on the direction (2609.05339). Sample-level regressions have no universal predictor (2608.13607). One structural cause predicts which lessons go bad. Many lessons are **compensation lessons**: they patch a weakness of the old model M1. Define a lesson's lift on M1 over probe inputs x from the logged episodes as ℓ₁(x) = log P_M1(a*|x, L) − log P_M1(a*|x), where a* is the logged successful action. Define the upgrade's base change as u(x) = log P_M2(a*|x) − log P_M1(a*|x). Both are exact log-prob quantities on logged data, with no new rollouts. If cos(ℓ₁, u) is high, M2 already learned what L teaches, so L is redundant on M2 and spends context (the D1 dilution channel). If L's lift on M2, ℓ₂(x) = log P_M2(a*|x, L) − log P_M2(a*|x), is negative where u > 0, L overrides an M2 improvement and is harmful. Prediction: a score combining cos(ℓ₁, u) and the sign of ℓ₂ on the u > 0 inputs ranks lessons by their true per-lesson Δsuccess on M2. Dropping the predicted-redundant and harmful lessons beats both "reload everything" and "M2 rewrites every lesson" at equal context.
**Strongest control, and why it should fail.** (1) ℓ₂ alone: M2's likelihood gain from the lesson on logged successful trajectories. This is G1's unweighted control. It cannot tell "redundant" (ℓ₂ ≈ 0 because M2 already does it) from "useless". It also misses harm concentrated on the u > 0 inputs, where M1's logged actions were wrong and M2's are right. (2) The G1 IS/DR estimator re-run on M2, if G1 survives. (3) An M2 LLM judge of each lesson's relevance. (4) Fixed-schema KG memory, the portable format in 2609.05339. (5) Heirloom-style absolute matching (2611.00650): keep the lessons whose M2 behaviour best matches M1+L. This drags M2 back toward M1 on the inputs where M2 is better. Same probe set and token budget for all arms.
**Smallest falsifying test.** Two same-tokenizer version pairs on CPU (Qwen2.5-0.5B→1.5B and Qwen2→Qwen2.5 at 1.5B). Use 60 lessons from the PR #4/H1 synthetic API world, written by M1 over 300 logged episodes. Ground truth is per-lesson Δsuccess on M2 from 40 fresh rollouts with the lesson vs without. **Kill** if the triage score's Spearman with true Δsuccess is not ≥0.15 above ℓ₂ alone and the judge, or if pruning by it does not beat reload-everything by ≥3 pp on M2 at equal context. **Also kill** if fewer than 15% of lessons are true redundant-or-harmful on M2: then the phenomenon is too small to matter.
**Closest prior art.** 2609.05339 (portability study, no per-lesson predictor), 2611.10628 (identity drift under transition, empirical), 2608.13607 (sample-level regression signals: confidence, cross-version KL; they predict which samples regress, not which memory entries to drop), UpgradeBench 2608.20918 (adapter port/refresh decisions, not text memory), Heirloom 2611.00650 (distil old personalized model into new, absolute matching), DASH 2610.19712 (summarize history to curb weak-to-strong behaviour transfer), proxy-tuning and EFT (logit arithmetic of a tuning delta; our lift is the same arithmetic but used as a triage score, not for decoding). I found no lesson-level triage that uses the old-lift / upgrade-direction alignment.
**Ledger check.** Policy-drift obsolescence (killed at proposal in PR #7) predicted staleness from the environment drifting. This is about the *reader* changing while the world stays fixed. It needs G1's logged data but not G1's verdict.
