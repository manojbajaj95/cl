# Proposer idea batches

Wild continual-learning ideas for a separate reviewer to judge: [batch 1](batch-1.md), [batch 2](batch-2.md), [batch 3](batch-3.md). Each idea has a claim, a pilot that could kill it in under a day, a kill criterion and the closest work found. `pilots/` holds the CPU sanity checks (numpy only): `noether_memory.py` (batch 1 #1, positive) and `halflife*.py` (batch 2 #7, flawed setup, untested).

Run: `python3 ideas/pilots/noether_memory.py` (~3 min CPU).
