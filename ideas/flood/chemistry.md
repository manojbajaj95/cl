# Continual learning from chemistry, materials, and self-assembly

64 unranked bets. The chemistry is an analogy: every proposed substrate and first test is digital. **Primitive** means the proposed object or operation could support a family of learning methods; **improvement** means a change to an existing method. Neither tag is a claim of priority. I skimmed the [idea ledger and flood triage (PR #6)](https://github.com/manojbajaj95/cl/pull/6) and flag nearby work, including L1 (prompt-addressable checkpoints), N1 (round-trip consolidation), and SM1 (self-readable seed log).

For every test, A/B/C denote sequential tasks unless otherwise stated; score held-out examples from each task as soon as it is learned and after each subsequent write. Report new-task gain and each old-task change separately, including the worst old task. Match retained bytes and update/evaluation budget against the named control where applicable; any extra branch execution, probes or metadata count. No experiments have been run.

## Catalysts: storing how to learn, not what to answer

**01 · Path-only adapters (heterogeneous catalysis) — Primitive.** Train a small hypernetwork that maps pairs of before/after execution states to edit proposals for a frozen interpreter. On a new task it proposes a patch, checks the patch, then leaves the execution path; the stored object is a reusable transformation of the write process. **Novelty bet:** unlike a reusable task adapter, one catalyst can write into many independently editable skills without being mounted at inference; close to learned optimizers and meta-learning. **First test:** use tiny string programs with recurring indexing bugs; learn B fixes from two examples with and without a matched learned optimizer and rerun held-out A programs after installation.

**02 · Product-made catalysts (autocatalytic sets) — Primitive.** A successful new skill may emit a typed write rule whose inputs and outputs are other skills. Install rules only when their declared dependencies close a cycle and their generated children pass tests; a future observation can then bootstrap an entire family of edits. **Novelty bet:** what grows is the space of legal learning operators, not merely a recursive library of callable skills; close to library learning and chemical abstract machines. **First test:** seed a tiny table-transformation DSL with one parser and one printer rule; compare B family expansion to flat library induction, then retest the earlier A parser/printer variants including rare ones.

**03 · Recoverable catalyst poisoning (competitive adsorption) — Improvement.** Give each learned update rule a bounded cache of example signatures; a repeated misleading signature can occupy a slot and suppress that rule. A later discriminative example can evict just that occupant, without deleting the rule or restoring a whole optimizer. **Novelty bet:** puts a reversible failure state on the reusable *writer*, not a confidence penalty on its outputs. **First test:** alternate clean and mislabeled arithmetic-adapter batches; compare a slot eviction to a reset and a robust loss, measuring B recovery and held-out A arithmetic accuracy after the corrupt phase.

**04 · Transition-state bridges (transition-state stabilization) — Primitive.** Learn an auxiliary coordinate that exists only along a write: lift an update into a larger parameter space so two edits can jointly cross a narrow low-loss corridor, then contract back to the original architecture and discard the coordinate. **Novelty bet:** the temporary object is an edit scaffold, not a permanent expert or endpoint interpolation; close to mode connectivity and network morphism. **First test:** add a correlated feature to a tiny bottleneck classifier using one temporary neuron; compare with equal-compute endpoint distillation and widening-then-pruning, testing old A examples at intermediate steps and after contraction.

**05 · Tandem write handoff (substrate channeling) — Primitive.** A detector emits a typed residual plus provenance directly into a preallocated writer port on the downstream module that can repair it; no global reducer sees the intermediate. Multiple consumers chain writes by handing off the residual they could not absorb. **Novelty bet:** local write ports compose online across independently trained modules; unlike ordinary error backpropagation, intermediate *edits* are first-class routable values. **First test:** sequentially repair three coupled cells of a toy transducer; compare with local backprop and a global edit queue, checking held-out A and B sequences after C.

**06 · Catalyst inversion (switchable enantioselective catalysis) — Primitive.** Learn one writer with an explicit orientation bit that changes how a typed local discrepancy is resolved; the same edit evidence can train either a left-action or right-action module, without mirroring the installed weights. **Novelty bet:** places symmetry on the operator that writes, rather than merely augmenting inference data. **First test:** stream mirrored grid transitions with a few asymmetric anchors; compare with augmentation and two separate writers, then test old A transitions including those anchors after B.

**07 · Limiting-reagent commits (stoichiometry) — Primitive.** Every persistent update consumes typed units of independently measured evidence (such as distinct environment IDs and outcomes); a unit spent on one write is unavailable to support another. A committer solves a small allocation problem when competing writes rely on the same experience. **Novelty bet:** makes statistical evidence rivalrous across memory objects, rather than charging generic plasticity tokens or assigning independent confidence scores. **First test:** synthesize many correlated B rules from one faulty rollout; compare to thresholded writes and a global quota, rechecking A action accuracy and B generalization.

**08 · Mechanism-of-action probes (catalyst reaction fingerprints) — Improvement.** Compare writers by their rates of repairing specific seeded failure modes under matched loss and budget; when a bug recurs, select the writer by the intervention that made its output rate change, not by embedding similarity. **Novelty bet:** profiles *how* learners respond to interventions, not which examples they recall; close to probing optimizers on task suites. **First test:** inject sign flips, label swaps and input permutations into toy regression streams; compare to nearest-history writer selection and measure old A regression error after each B repair.

## Bonds and exchange: memory as a mutable graph

**09 · Conservation-law rewiring (vitrimer bond exchange) — Primitive.** Store skills as paths through a typed module graph. An exchange atomically swaps two edges, preserving port degree and passing old endpoint contracts, so new paths can form under a fixed wire budget without requiring old paths to stay frozen. **Novelty bet:** the basic write is a paired exchange of interfaces, not a sparse delete/grow pair chosen independently; close to dynamic sparsity and e-graphs. **First test:** add C compositions to an A/B affine-program graph at fixed edge count; compare independent prune/regrow and test held-out A/B compositions by their original calls.

**10 · Toehold edit cascades (symbolic strand displacement) — Primitive.** Represent a skill slot as a string of typed interfaces. A challenger with a matching exposed prefix displaces incumbent code one section at a time, but stalls at any section where it cannot meet the local contract. The resulting partial replacement exposes the next permissible edit. **Novelty bet:** edit authorization is discovered by traversal and can stop mid-module; not a whole-skill overwrite or physical strand design. **First test:** migrate a three-stage toy API with one unchanged legacy quirk; compare to whole-module replacement and fixed patch order, rerunning old A callers after every B displacement step.

**11 · Stress-bearing sacrificial bonds (tough hydrogels) — Primitive.** Wire residual capacity through cheap, replaceable links that can disconnect first when two tasks disagree, leaving a second load-bearing graph intact. Record which temporary link broke to offer the new task an alternative route while retaining the protected function. **Novelty bet:** an intentional failure becomes a routing operation on the redundant part of a skill, not an estimate of parameter importance. **First test:** introduce contradictory B rules into a two-path MLP; compare to EWC and sparse expert growth at the same capacity, scoring A before and after link breaks.

**12 · Valence-limited handles (coordination chemistry) — Primitive.** Each learned module exposes typed attachment ports with finite valence; a new module can request an occupied port only by arranging a bridge that preserves both current consumers. Compatibility is executable, not based on textual signatures alone. **Novelty bet:** a write negotiates a local graph rewrite when the right abstraction has no free interface; distinct from simply extending a skill DAG. **First test:** add a third caller to two shared toy codecs under a two-port budget; compare to wrappers or duplicated codecs and test old A/B callers on hidden inputs.

**13 · Exposure by unmasking (protecting-group chemistry) — Improvement.** Attach an edit-only mask to individual code or parameter ports when constructing a composition; only after the composed path passes end-to-end tests remove the mask so those ports can learn again. Inference continues through them while masked. **Novelty bet:** scopes protection to a construction step rather than permanently classifying old weights as important; close to temporary freezing and transactional changes. **First test:** compose arithmetic adapters before fine-tuning B; compare timed protection with static freezing and full tuning, then check A on inputs outside B’s domain.

**14 · Selective change capture (chelation) — Primitive.** Collect a correlated low-rank weight change together with its paired normalization and routing changes into one movable object; expose its functional ports only when all parts are mounted together. Use causal ablations, not parameter proximity, to decide what must bind. **Novelty bet:** the portable unit is a multi-locus dependency bundle rather than a weight vector, adapter or model-version transport map. **First test:** teach an MLP B through coupled scale and router changes; compare bundle mounting to flat delta addition and equal-size independent adapters, scoring A with several B bundles mounted.

**15 · Ambient bond turnover (dynamic combinatorial libraries) — Primitive.** Keep several interchangeable internal decompositions of a working program and let equivalent fragments exchange online during execution-free intervals. A new task captures a rare compatible decomposition by adding one binding constraint; old tests constrain the exchange itself. **Novelty bet:** stores a distribution of usable factorizations instead of a single point chosen for plasticity reserve; close to e-graphs and neutral drift (SM7). **First test:** maintain equivalent arithmetic circuits, then add B with one new operation; compare to on-demand e-graph search at equal expansions and retest A on exhaustive small integers.

**16 · Entanglement instead of locking (polymer reptation) — Primitive.** Represent several skills as overlapping sequences of latent operations with tied internal segments. New learning slides ties along sequences (with local equivalence checks) without allowing crossing ties to be cut; a legal long move is a chain of local slides. **Novelty bet:** protects shared structure through permissible moves, not numeric clamps or topological bits; close to program refactoring and constrained alignment. **First test:** stream string transductions with common subroutines; compare tie slides to frozen sharing and untie/retie at equal representation size, scoring old A/B after C and on unseen lengths.

## Growth and material history

**17 · Interface-first growth (epitaxy) — Primitive.** Train a new block around a small basis of boundary activations exported by an old block; enforce the shared coordinates only on the joining face and allow the interior to use a different width or architecture. Add skills by specifying compatible interfaces before seeing the new data. **Novelty bet:** the growth template is a functional interface, not a weight seed to regenerate history (SM1); close to progressive nets and stitching. **First test:** append an image transformation to a tiny shared encoder; compare to an ordinary new adapter and frozen encoder, measuring A under interleaved A/B use without an oracle task ID.

**18 · Defects that admit new skills (dislocation glide) — Primitive.** Introduce an explicit seam into a regularly reused layer or program grammar; an edit moves the seam while translating the operations on either side so that old routes still join. New computation occurs only at the moving seam. **Novelty bet:** a mobile discontinuity is the unit of growth, not added parameters at a fixed address. **First test:** extend a shared sequence rule from modulo 4 to a mixed-period C using one mobile seam; compare to fixed residual branches, checking original A/B periods on unseen lengths.

**19 · Discardable nucleation surfaces (heterogeneous nucleation) — Improvement.** Offer small hand-built or learned activation templates during the first B updates; after a coherent new feature forms, turn each template off and see whether the feature persists on B without reducing A. Keep only templates that speed acquisition under that constraint. **Novelty bet:** distinguishes reusable templates for *starting* a feature from inference prompts or permanent initialization seeds. **First test:** use three synthetic visual motifs across a tiny CNN stream; compare to learned initialization and curriculum, measuring B sample count to target and A accuracy after removal.

**20 · Trait selection by seeded polymorphs (polymorphic crystallization) — Primitive.** Seed several distinct implementations with identical current behavior but different exposed extension ports. When future evidence arrives, pick a form by the smallest legal edit that admits it, not by replay loss among replicas. **Novelty bet:** a memory has interchangeable structural forms with different future operations, not archived snapshots or an unlabeled Gramian forecast. **First test:** build equivalent stack and queue expressions for A, then introduce B that needs random access; compare to one canonical form plus bounded search and check A after the chosen form is edited.

**21 · Directional zone refining (zone melting) — Improvement.** Move a temporary editable window across blocks with local auxiliary losses. At each step, pass unresolved cross-task residuals forward instead of allowing them to contaminate blocks already re-solidified on old contracts. **Novelty bet:** the moving window transports a residual explicitly; merely cooling and reheating was not enough in the ledger. **First test:** alternate A/C constraints with B on a four-block MLP; compare same-update layer cycling with and without residual transport, measuring final performance and retention on A/C.

**22 · Ripen parts, not skills (Ostwald ripening) — Improvement.** Promote fragments from small niche adapters into a shared adapter only when their input/output interface is redundant; let the niche adapter retain a low-rank residual rather than deleting its whole behavior. **Novelty bet:** consolidation transfers reusable material while preserving small specialists' residuals; close to adapter fusion and low-rank distillation, not N1 code↔weights. **First test:** stream common arithmetic clauses and rare exceptions; compare to distill-or-delete at equal bytes and check the earlier rare exceptions as well as common A after C.

**23 · Fragment-seeded regrowth (self-healing composites) — Primitive.** Persist a repair fragment at an interface: it is a tiny constraint-solving program that can synthesize several compatible replacements, not a saved component. Trigger it only when that interface fails a probe, and let it choose the cheapest replacement compatible with the new surroundings. **Novelty bet:** repair is generative and environment-sensitive, not restoring L1 or replaying SM1. **First test:** replace a leaf function and change its downstream port in a toy DSL; compare to saved-patch restore and repair from the contract alone; test new B callers and held-out old A callers after the repair.

**24 · Stored form, new motion (two-way shape memory) — Primitive.** Write a reversible deformation field that maps between feature geometries in A/B, and train new heads to use coordinates that deform with the field. Query a point along the field to run a composition, not just select one past state. **Novelty bet:** unlike physics-math’s shape-memory weights or L1 checkpoints, this tries to preserve correspondences during deformation between behaviors, not restore endpoints. **First test:** fit two rotated keypoint domains and then a B-only relation; compare ordinary weight interpolation and conditional heads, checking A at its setting and old correspondences on unseen intermediate rotations.

## Compartments, transport, and shared resources

**25 · Memory droplets (associative liquid phase separation) — Primitive.** Let update fragments reversibly cluster by weak pairwise affinity; a fragment belongs to a write compartment only while the cluster has enough mutually stabilizing contacts. Credit trapped inside a cluster edits it preferentially, and an influx of a third fragment can split it. **Novelty bet:** compartment boundaries are set by joint membership dynamics rather than a frozen router or k-means. **First test:** stream overlapping synthetic skill triplets with a changing bridge task; compare soft MoE and online clustering, checking held-out A/B routes after B/C clusters reorganize.

**26 · Selectively permeable interfaces (coacervate partitioning) — Primitive.** Give each compartment a learned transfer function that admits some features as read-only signals and others as write credit. Train on interventions to keep prediction sharing while blocking unwanted gradient transport. **Novelty bet:** decouples informational from update permeability at the same interface, unlike routing a whole lesson or masking its KV visibility. **First test:** learn A from a stable feature, then B from that feature plus a shifting shortcut; compare to shared routing and fixed stop-gradient, testing old A across shortcut reversals.

**27 · Gradient dialysis (semipermeable membranes) — Improvement.** Swap only sufficiently small, reproducible residual directions across task blocks; threshold by rank and sign consistency rather than magnitude alone. Direction estimates that fail the transfer test remain usable locally. **Novelty bet:** a bidirectional sharing policy for residuals, not wholesale gradient projection within a single block. **First test:** learn related low-rank linear tasks with large nuisance gradients; compare projection, magnitude clipping and the transfer rule, checking old A/B error after C.

**28 · Chemical-potential balancing (Le Chatelier’s principle) — Improvement.** Settle competing memory claims by moving shared adapter rank from compartments with excess held-out accuracy to ones with the largest accuracy change per extra slot, while maintaining minimum coverage. Make a reversible trial before transferring rank. **Novelty bet:** pressure is measured at a proposed resource transfer, not attached to age or retrieval count; close to resource-allocation controllers. **First test:** skew a three-task stream 20:1 toward B and then C; compare static and frequency-based rank allocation, measuring A's rare slice after each transfer.

**29 · Error buffers (acid–base buffering) — Primitive.** Store a learned map from a compact residual code to a family of temporary corrections; apply it before a burst can write into the stable model. When the buffer saturates, refactor the shared representation and reset the map, counting each absorbed shock against a finite budget. **Novelty bet:** the reusable object neutralizes a class of perturbations rather than slowing every update or retaining an independent checkpoint. **First test:** alternate label-preserving covariate shifts and one genuine rule change; compare replay and an equally sized transient adapter, measuring A retention through both events and B/C acquisition after saturation.

**30 · Valence-driven partition inversion (surfactant phase inversion) — Primitive.** Give each adapter complementary inside/outside interface maps. When new task frequency reverses, invert which side sees the shared representation and which remains private, reusing learned interface maps rather than moving every skill. **Novelty bet:** ownership of the shared basis becomes a reversible operation, not a new clustering assignment. **First test:** switch from many A-shaped callers with sparse B to the reverse in a two-encoder toy, compare rebuilding experts at equal rank, and score the now-minority A callers after inversion.

**31 · Counterflow of old and new gradients (countercurrent exchange) — Improvement.** Pass a small bank of old-task residuals backward through the same chain in which fresh edits are passed forward. Let each block exchange only components that decrease both held-out local surrogate losses. **Novelty bet:** the order of encounters can enable distributed exchanges missed by one global gradient projection; close to OGD and pipeline training. **First test:** use a three-block linear network with overlapping A/B/C subspaces; compare sequential and simultaneous projected gradients, checking old A/B and C at matched gradient evaluations.

**32 · Adversarial migration fronts (ion exchange) — Primitive.** When a new skill displaces an occupied resource, pass the displaced skill as an input to the next slot instead of evicting it outright. Each slot checks a local retained contract and emits whatever it could not host, terminating at a real capacity limit. **Novelty bet:** cascading displacement preserves usable payloads during insertion; close to cuckoo hashing, but slot compatibility is behavior, not a fixed hash. **First test:** pack tiny low-rank arithmetic modules into fixed slots; compare one-hop eviction, cuckoo assignment and behavioral cascades, testing all old A/B inputs after C insertions.

## Selective recognition and context

**33 · Dual-input editing (allosteric regulation) — Primitive.** Add a write receptor on an adapter that binds an instruction about *which contract can change*, separately from the task evidence. Train it so the same gradient is routed to different edits under different instructions, while ordinary inference has no receptor input. **Novelty bet:** external control selects the writable transformation rather than an inference mode, past checkpoint (L1) or parameter address. **First test:** train a toy agent to update a parser or its scoring rule on identical failures; compare a task-ID writer and masks, verifying the untouched old A contract after each B edit.

**34 · Hidden side effects as selectivity (induced fit) — Primitive.** Before committing a candidate skill, adapt it on two steps of the current caller’s unlabeled activation statistics and then run several endpoint probes. Record the deformation needed to fit as a reusable interface object; reject static matches that require incompatible deformations across callers. **Novelty bet:** transient deformation reveals executable compatibility differently from retrieval similarity or static port signatures. **First test:** present two near-identical parsers that diverge on types; compare similarity and standard two-step adaptation with no shared fit record, checking old A/B callers after mounting C.

**35 · Memory imprints for unseen variants (molecularly imprinted polymers) — Primitive.** Train the *hole* left by an absent module: remove each known implementation in turn and learn to infer its admissible I/O constraints from the surrounding graph alone. Apply the imprinted holes to select or synthesize unseen implementations later. **Novelty bet:** what persists is a reusable recognition template for interchangeable modules, not the removed module or a generated replay set. **First test:** mask one stage of synthetic ETL programs, then add C with a new transform family; compare to a learned retrieval key and ordinary masked completion, checking old A/B pipelines after replacement.

**36 · Shape-sieved compositions (zeolite shape selectivity) — Primitive.** Enforce a small executable grammar at intermediate adapter ports so only compositions whose latent shapes satisfy the grammar can propagate. Learn the sieve online from examples where correct independent tools produce a wrong combined effect. **Novelty bet:** a reusable interface constrains *intermediates*, not just final tool choice or formal type checking. **First test:** use scalar tools with the same declared type but different units; compare type checks and end-to-end verifiers at equal calls; test earlier A/B compositions when C introduces a confusable tool.

**37 · Reciprocal footprint matching (lock-and-key versus induced fit) — Improvement.** Rank two candidate modules by the difference between the consumer's expected activation footprint and what the producer actually changes under a standardized intervention; require agreement in both directions before wiring. **Novelty bet:** pairs a causal producer footprint with a consumer tolerance, rather than using just activation cosine or contracts written after the fact. **First test:** wire tiny arithmetic experts with decoy outputs that agree on easy inputs; compare ordinary stitching and cosine matching, checking old A compositions after mounting B.

**38 · Sequential chirality checks (diastereomer resolution) — Primitive.** Preserve order-sensitive skills by attaching a tiny invariant that distinguishes two mirrored sequences that otherwise have identical local evidence; only the compatible orientation of a new fragment can bind. Let orientation compose under chaining. **Novelty bet:** records handedness of a composition, not an input transform label or a write rule (06); close to equivariant programming. **First test:** add B subroutines in mirrored grid environments sharing the same local tiles; compare position embeddings and symmetry augmentation, checking old A routes after chaining through B.

**39 · Competitive decoy slots (molecular sequestration) — Improvement.** Route a fragment that matches much of a stale lesson's signature into a decoy that consumes only the stale lesson’s activation budget, then test whether the new skill executes without losing the true old trigger. **Novelty bet:** suppresses a particular cross-trigger without lowering a global memory weight; close to hard negatives and retrieval masks, not margin-gated visibility. **First test:** introduce near-collision B identifiers in a key-value agent; compare hard-negative retrieval training, measuring B errors and A hit rate separately on original and paraphrased triggers.

**40 · A changed binding pocket, not a changed message (receptor desensitization) — Primitive.** When an agent can no longer distinguish fresh from stale lessons, write a temporary change to the retrieval query encoder with conserved lesson encodings. Translate the encoder delta into the few inverse views that still recover the genuinely needed old lessons. **Novelty bet:** treats a query adaptation and its compensating views as one memory operation; close to query-drift work, not ordinary stale-entry pruning. **First test:** rotate vocabulary halfway through nested tool tasks; compare refreshing all keys and a two-encoder cache, checking old A mappings under new paraphrases after B.

## Reaction pathways and history dependence

**41 · Procedure-derived weights (kinetic versus thermodynamic control) — Primitive.** Store a small transition graph among behavior-equivalent implementations with measured edit costs, letting the agent choose a fast approximation or a more stable endpoint given the same incoming task. The graph is not a time-stamped log and paths may never have been taken. **Novelty bet:** makes what can be built *from* a learner a queryable object distinct from its historical checkpoints (L1/SM1). **First test:** generate equivalent small Boolean circuits, add B under short and long edit budgets; compare best-current-loss beam search and retest A at each selected endpoint.

**42 · Operating-range memory (sorption hysteresis) — Primitive.** Store measured loading and unloading curves for a relay, representing which level of instruction changes its routing when approached from either side. Update the curves as a pair from repeated excursions rather than hand-setting a gate or putting weights in double wells. **Novelty bet:** the persistent object is a trajectory-dependent interface contract; close to physics-math hysteresis and benchmark margin work. **First test:** cycle rule reliability up and down in a toy agent; compare asymmetric fixed thresholds and a memoryless calibrator; test A decisions near both switching points after B changes the curves.

**43 · Trapped intermediates (quenched reaction intermediates) — Primitive.** Interrupt a multistep refactor at a typed intermediate representation, freeze that representation plus pending obligations, and let later tasks take parts of the unfinished refactor without committing the rest. **Novelty bet:** preserves independently useful unfinished edits, not deferred hypotheses awaiting labels or a checkpoint of the learner. **First test:** begin a parser refactor that needs two missing features, then offer B requiring only one; compare to full commit/rollback and save-and-branch, retesting untouched A grammar cases after B adopts the intermediate.

**44 · Parallel pathways with a shared bottleneck (branching reaction networks) — Primitive.** Retain several derivations of the same output up to a canonical shared intermediate. A new outcome can train the early pathway or the downstream transformation separately, with credit split by interventions that swap the intermediate. **Novelty bet:** the stored object partitions *how* a skill was reached from *what* downstream behavior uses it; close to causal interchange training, not merely multiple traces. **First test:** train two parse paths to one AST, then add a new runtime rule; compare end-to-end updating and a frozen AST interface, checking old A parse and execution separately after B.

**45 · Reaction extent as partial commit (reaction progress coordinates) — Primitive.** Encode a write as a vector of coupled operation counts subject to a balance matrix over interface obligations. Learn to vary write extent and complete only feasible coordinated subsets, rather than interpolating all weights uniformly. **Novelty bet:** permits structured fractional adoption of a learned update program and steers halfway states; close to transactions and partial deployment. **First test:** add related schema fields gradually in a toy tool agent; compare scalar blend and ordered patches, score held-out old A records at each feasible stage and new B at completion.

**46 · Make a path by removing product (driven nonequilibrium reactions) — Improvement.** In a working copy, deliberately drain newly solved B subcases from a live training queue into held-out tests, so the remaining gradient targets bottlenecks rather than letting easy products dominate. Put a drained case back only if it fails its test. **Novelty bet:** explicit sink and return flow for a continually changing training frontier; close to hard-example mining and prioritized replay. **First test:** train a tiny arithmetic model on easy/hard B mixes, compare difficulty replay at matched exposures and test A as well as drained early B.

**47 · Product inhibition as write idempotence (feedback inhibition) — Primitive.** An installed update exposes a tiny learned signature of its functional effect; later near-duplicate write proposals must be tested against that signature and turned into a no-op if their marginal effect is already present. Only install the missing remainder. **Novelty bet:** behavioral idempotence can survive paraphrases and truncated rewrites; close to O1 idempotent operators and not a study of literature-covered double dosing. **First test:** stream variants of the same arithmetic update plus one genuinely additive rule; compare hash dedup and similarity dedup, measuring duplicate drift on A and adoption of genuinely new B/C.

**48 · Lower one barrier at a time (activation-energy ordering) — Improvement.** Optimize the order of interface changes by measuring which single temporary relaxation makes an otherwise blocked multi-edit legal; then reorder the minimum set of relaxations to avoid simultaneous exposure. **Novelty bet:** selects sequencing from causal barriers rather than curriculum difficulty or cooling the whole model. **First test:** migrate a three-port toy interpreter with dependent constraints; compare random and static topological orders at equal trial count; log old A errors throughout and after successful B migration.

## Analysis, provenance, and separation

**49 · Behavior tracers (stable isotope labeling) — Primitive.** Add tiny, task-conditioned calibration perturbations only at designated module ports during a write. Later inject the same tracers to map *where* a behavior migrated by observing which downstream components now transmit the response; the tracer does not encode the old edit. **Novelty bet:** traces transit under interventions, not a sparse damage syndrome or seed history (SM1); near causal tracing. **First test:** relocate a skill between two modules during B training; compare hidden-state similarity and direct probe scans at matched calls; localize the old A route and check A accuracy after relocation.

**50 · Separate by function under perturbation (two-dimensional chromatography) — Primitive.** Fractionate a mixed edit by repeatedly applying selectors with different axes, such as locality of activation and sensitivity to context, and collect fractions that independently retain their effects. Load one without the others and refit only their joining interface. **Novelty bet:** separates post hoc learned behaviors by experimental selectivity, not matrix rank alone or reading the delta as text. **First test:** train a mixed B edit with synonym mapping and changed operator precedence; compare SVD and independent retraining, checking old A precedences after installing only the synonym fraction.

**51 · Origin by crossed labels (pulse–chase tracing) — Primitive.** Label successive streams with small synthetic activation perturbations, then selectively scramble their sources once they have merged. Use the surviving responses to derive portable dependencies for a later edit, not to reconstruct past weights. **Novelty bet:** follow the provenance of shared representations through compaction; SM1 records writes, whereas this tries to query what signal survived. **First test:** feed A/B correlated linear factors and consolidate into one bottleneck; compare tagged and leave-one-stream-out tracing at equal calls, then edit C and test A/B on decorrelated examples.

**52 · Titration curves for attachment (binding titration) — Improvement.** Measure how a candidate adapter behaves when exposed to increasing fractions of a specific old feature class. Use the change in crossover point across candidate mounting ports to detect where the adapter can integrate without evicting the incumbent behavior. **Novelty bet:** probes a response curve across input compositions rather than an endpoint similarity or generic confidence gate. **First test:** choose a mount for a B rank-one adapter in a small classifier; compare one-shot held-out selection and full curve selection at the same probe count, checking old A including the overlap slice.

**53 · One-pot attribution (combinatorial synthesis with split-and-pool tags) — Primitive.** Build partial wrappers in pools keyed by component identity, split them at each interface, and keep the tag with the partial wrapper so a successful final behavior identifies a reusable compatible path. Pool *construction work*, not just final mutation scores. **Novelty bet:** amortizes many compositional writes by reusing shared synthesis prefixes; close to search memoization, not multiplexed forward-only perturbations. **First test:** search toy tool chains with a shared prefix and several branches; compare a memoized beam at matched executions, then add C and test old A/B chains when the selected prefixes are reused.

**54 · Characteristic fracture surfaces (fractography) — Improvement.** Perturb a trained model along the same small set of stress directions before and after an update and record which pairs of tests start failing together. Use *differences* in those failure clusters to nominate interfaces for local repair. **Novelty bet:** diagnoses co-failure geometry under controlled stress rather than a pre-edit capacity law or a damage-energy sparsity assumption. **First test:** seed two kinds of interface failures in a modular arithmetic network; compare direct probing and gradient norm for repair selection, measuring old A accuracy after a one-block repair while holding B gain fixed.

**55 · Sensitivity spectra (lock-in detection in spectroscopy) — Improvement.** Periodically modulate allowed writes on several blocks at distinct digital frequencies while tasks stream. Correlate an old probe's response with these frequencies to find paths where *later writes* couple to old behavior; validate by blocking one path temporarily. **Novelty bet:** measures recurrent online coupling versus one-shot coded perturbations; risks reducing to finite-difference attribution. **First test:** alternate A/B over a tiny MLP with a coupled hidden block; compare isolated finite differences at the same perturbation budget and check A retention after selectively blocking the predicted coupling.

**56 · Wash before consolidation (selective extraction) — Improvement.** Run candidate memory through paired environments that preserve its intended operation but remove obvious incidental cues. Extract the portion that remains executable across the pair and only then consolidate it in the main model. **Novelty bet:** uses a pre-consolidation extraction step, not post hoc N1 round-trip decompilation; close to invariant learning and counterfactual augmentation. **First test:** teach a text agent B tool calls with a spurious field order, extract on randomized order, compare ordinary counterfactual fine-tuning, and rerun old A cases where field order really matters.

## Mechanical response and emergent assembly

**57 · Local yields as write permissions (elastoplastic yield surfaces) — Primitive.** Each module learns a *set* of allowable paired input/output changes from the skill interfaces it serves. A requested edit outside that set yields irreversibly at one contract and routes the remaining demand to a candidate new module. **Novelty bet:** learns an interface-level set of compatible changes and makes violation a constructive operation; close to projected learning and NB04 permeable scars. **First test:** introduce conflicting B and compatible C changes into an A affine router; compare EWC and hard projection, scoring A after both transitions and C transfer through the unchanged interface.

**58 · Auxetic representations (negative Poisson’s ratio) — Primitive.** Parameterize linked feature dimensions so that stretching the margin for one set of inputs automatically opens room in another *without* adding dimensions. Learn the linkage from local probes that separately identify margins and available directions. **Novelty bet:** couples deformations constructively rather than merely avoiding old subspaces or forecasting plasticity reserve from a Gramian. **First test:** add B clusters to a tiny metric learner; compare whitening and orthogonal projection at equal dimension, checking retrieval for tightly spaced old A clusters at matched B separation.

**59 · Interlocking rather than blending (mechanical metamaterials) — Primitive.** Assemble frozen micro-experts whose connections are programmable load paths: a readout routes activation through them, but under a new loss the load is assigned by a different, mechanically inspired graph of rigid and compliant interfaces. Mutate joints before rewriting cores. **Novelty bet:** a two-graph architecture lets inference connectivity and conflict propagation be learned separately; close to credit routing and NB06, but here joint state mediates discrete changes of both graphs. **First test:** train reusable logic experts, add contradictory B combinations and compare ordinary MoE and a fixed credit graph; retest old A circuits that share the joints.

**60 · Delayed recovery without replay (viscoelastic relaxation) — Primitive.** Let a module expose an internal relaxation law fit from the trajectory of its previous writes. After a new write, propagate that law to recover only transient portions of an old behavior, while retaining permanent changes. **Novelty bet:** can distinguish recoverable and committed components at the interface rather than average past model weights; unlike the ledger’s re-annealing, no extra training noise is meant to recover skills. **First test:** alternate brief covariate shifts with permanent exceptions in linear regression; compare EMA and momentum reset, testing old A after equal recovery time and B on permanent exceptions.

**61 · Time-encoded skill state (materials aging and rejuvenation) — Primitive.** Build a skill interface with a small hidden relaxation spectrum that integrates pulse spacing but ignores total count. Read it to choose a composition and train future pulses to alter one timescale without resetting the others. **Novelty bet:** inter-arrival cadence can write memory without changing stored weights or keeping timestamp logs (SM1), close to reservoir computing and synaptic metaplasticity. **First test:** give a toy agent two equal-count streams with different cadences, then learn C; compare to equal-bit recurrent state and time summaries, checking old A/B schedule-conditioned behavior after C.

**62 · Frustrated assembly as a branch generator (geometric frustration) — Primitive.** Let local edit constraints assemble a skill graph until a cycle is incompatible; preserve the minimal frustrated cycle as a structured distribution of alternative future writes. As new evidence arrives, resolve the cycle by relaxing the constraint new tasks can replace rather than choosing a complete hypothesis at first conflict. **Novelty bet:** stores conflict geometry, not deferred full candidates (D1) or a single inconsistency score; near constraint solvers and physics-math sheaf inconsistency. **First test:** stream overlapping toy navigation rules with one inevitable cycle, then add C that disambiguates two branches; compare a bounded version space and verify old A/B queries off the disputed cycle.

**63 · Grow the boundary rule (programmable tile self-assembly) — Primitive.** Encode local assembly rules that extend a partial graph from its exposed ports; new learning edits the rule for a class of boundary configurations rather than saving each completed graph. Already assembled interior ports stay inert until a deliberate disassembly exposes them. **Novelty bet:** learning writes the grammar of local growth, not a single new architecture or a replayable build log; close to graph grammars. **First test:** teach a toy agent to assemble families of arithmetic circuits of increasing length; compare library induction and a fixed grammar, testing old A/B short circuits and their unseen longer variants after C.

**64 · Disassembly as an assay (templated self-assembly) — Primitive.** Force an assembled skill to fall apart under an explicit protocol, then train the fragments so independent local joins rebuild an equivalent or improved skill; retain the joining rules as reusable memory. Permit an old program to return via a different assembly path. **Novelty bet:** close to N1 round-trip consolidation, but neither a code↔weights conversion nor an SM1 write-history replay: the proposed reusable object is a local reassembly protocol that generalizes to unseen fragments. **First test:** disassemble toy finite-state transducers at different cuts, then teach a novel B fragment; compare whole-program round-trip synthesis and exact saved assembly, checking held-out A transductions after reassembly with and without B.
