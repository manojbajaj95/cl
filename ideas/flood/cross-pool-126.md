Raw proposals for harmless synthetic simulations only.

**EBX1. Separate simulated wear, repair and task learning before rolling anything back.** Parts: EL01 wear clock, EL02 repair rollback, EL03 calibration ritual, EL04 body versus world writes, EL05 fast body state, EL14 body-version simulator, EL26 tool frames, EL27 ritual-gradient routing, NP2-05 retain later lessons, NP5-25 protected inverse, CR29 versioned recovery. *Mechanism:* Use matched virtual bodies to identify reversible load changes, progressive wear and task changes. Apply repairs to scratch simulator states, comparing the return of calibration traces with behavior on object tasks. Undo only the body-specific adaptation when the same task lesson survives in both body versions. *New:* A matching calibration trace is not sufficient evidence that rolling back an adaptation will preserve a new task lesson. *First test:* Cross simulated load, wear and repair independently; compare full rollback, no rollback and scoped rollback on held-out body–task cells.

**EBX2. Replace a virtual sensor only when its translated evidence still teaches the next lesson.** Parts: EL07 canonical body coordinates, EL08 overlap translator, EL09 sensor lineage, EL10 independent success receipts, EL11 sensor dependencies, EL29 contact anchors, NP07 update conjugacy, OE25 checker retention, L9W14 observable predicates. *Mechanism:* During virtual sensor overlap, compare old and translated observations on independently recorded simulator outcomes. Map each skill to the dependencies it actually uses, then check whether fresh lessons lead to the same observable changes under the old and new interfaces. Re-anchor the lineage after a failed check. *New:* A sensor translator may preserve today’s behavior while changing which event is credited by the next update. *First test:* Swap synthetic sensors with drift and missing channels; compare chained translation, re-anchoring and fresh training using independent simulator truth.

**EBX3. Choose rehearsal fidelity by what survives on a separate simulator.** Parts: EL12 gap-localized writes, EL13 simulator artifact removal, EL15 minimum rehearsal fidelity, EL16 reacquisition cost, EL18 wear-priced forgetting, EL28 shadow practice, EL30 mirror rehearsal, NP06 learning-equivalent substitution, OE4-19 bounded working set, D5-18 lawful substitutes, D5-26 retained teaching responses. *Mechanism:* Use a reference simulator separate from the rehearsal simulator to reject artifact-dependent behavior. Compare lower-fidelity, object-free and mirrored lessons only where they retain both behavior and the response to a later correction. Allocate rehearsal by simulated cost of recovery and check that savings do not merely shift work to reacquisition. *New:* The cheapest lesson is not equivalent if it preserves an easy motor trace but loses contact behavior or leaves a larger future repair bill. *First test:* Vary synthetic contact and symmetry laws; compare uniform rehearsal, fidelity thresholds and checked substitutions at equal simulated work.

**EBX4. Carry constraint evidence across virtual bodies without treating the old certificate as transferable.** Parts: EL06 reserve solutions, EL17 nonrepeatable event memory, EL19 intervention constraints, EL20 candidate safe-set transport, EL21 near-miss witnesses, OE28 selective retesting, PL5-10 held-out effects, L8W22 scratch round trip. *Mechanism:* Keep each simulated intervention with its body version and assumptions. Use modeled alternatives and synthetic near-misses only to propose candidate constraints for another virtual body. Independently check the new simulator before making any claim of valid transport; treat inconclusive cases as unsupported. *New:* Boundary evidence can suggest what to recheck but cannot certify a changed body by itself. *First test:* In toy physics only, change actuator availability and contact assumptions. Compare copying the old constraint, recertifying everything and assumption-triggered rechecking against an independent simulator oracle.

**EBX5. Keep a shared skill contract only where different virtual bodies can still realize it.** Parts: EL22 cross-body agreement, EL23 interpolation paths, EL24 effect contracts, EL25 interference kernel, EL31 controller profiles, EL32 body–task retention matrix, OE3-03 signed interference, L8W17 update-matched plasticity. *Mechanism:* Store observable task effects separately from each virtual body's realization. Use interpolation paths and an interference estimate to propose sharing, but compare held-out body–task cells and a later training update before accepting it. Separate a failing realization from a changed or underspecified contract. *New:* Agreement between two bodies does not establish that a third body can learn the same correction or that sharing frees training capacity. *First test:* Use simple simulated manipulators with different geometry and dynamics. Compare shared weights, independent realizers and effect contracts across matched updates and migration paths.

**EBX6. Audit embodied continual learning with separate histories for body, sensors, skills and constraints.** Parts: EL01 wear clock, EL02 repair rollback, EL03 calibration ritual, EL04 body versus world writes, EL05 fast body state, EL14 body-version simulator, EL26 tool frames, EL27 ritual-gradient routing, NP2-05 retain later lessons, NP5-25 protected inverse, CR29 versioned recovery, EL07 canonical body coordinates, EL08 overlap translator, EL09 sensor lineage, EL10 independent success receipts, EL11 sensor dependencies, EL29 contact anchors, NP07 update conjugacy, OE25 checker retention, L9W14 observable predicates, EL12 gap-localized writes, EL13 simulator artifact removal, EL15 minimum rehearsal fidelity, EL16 reacquisition cost, EL18 wear-priced forgetting, EL28 shadow practice, EL30 mirror rehearsal, NP06 learning-equivalent substitution, OE4-19 bounded working set, D5-18 lawful substitutes, D5-26 retained teaching responses, EL06 reserve solutions, EL17 nonrepeatable event memory, EL19 intervention constraints, EL20 candidate safe-set transport, EL21 near-miss witnesses, OE28 selective retesting, PL5-10 held-out effects, L8W22 scratch round trip, EL22 cross-body agreement, EL23 interpolation paths, EL24 effect contracts, EL25 interference kernel, EL31 controller profiles, EL32 body–task retention matrix, OE3-03 signed interference, L8W17 update-matched plasticity. *Mechanism:* Keep a versioned record of body state, sensor evidence and observable skill effects. Verify repair and translation on scratch simulators, price recovery before retiring rehearsal, and independently recheck any transported constraint. Evaluate the next lesson as well as current task performance. *New:* The same audit separates what a virtual body can still do, what it can learn after a change and what earlier evidence no longer supports. *First test:* Run a harmless simulation-only stream with virtual repairs, sensor swaps and task changes. Compare monolithic adaptation, complete retraining and scoped updates at matched simulation cost.
