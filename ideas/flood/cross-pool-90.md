**WCX1. Repair a dying witness without declaring the other answer correct.** Parts: D3-01 certified pivot, D3-02 survival slack, D3-04 retirement triggers, D3-05 asymmetric repair budget, D3-07 blocking certificate, D2-11 opposed pair, CR24 impossibility witness. *Mechanism:* Keep a small feasible repair neighborhood on the more fragile side and declare which incoming constraints invalidate either witness. On a hit, search the certified neighborhood first; if it is exhausted, escalate to the bounded exact solver. Close a side only on a checked contradiction, not because the stored representative disappeared. *New:* A learner could amortize the cost of preserving ambiguity without confusing a failed warm start with evidence of closure. *First test:* Use finite feasible sets where a correction invalidates the current representative but not its side, plus a true closure control. Compare full re-solving, a widest-separated pair, and slack-guided repair at equal bytes.

**WCX2. Transport a contrast by its predictions, not by its old name.** Parts: D3-03 shared decoder and contrast, D3-08 localize changed evidence, D3-09 reidentify by predictions, D3-10 finite memory scope, D2-19 compression bound, CE3-10 observable rebasing, CR29 versioned witness. *Mechanism:* Preserve a small prediction sketch under authorized validation interventions. After a representation change, accept replacement worlds only when their lawful predictions and opposite decision signs survive. Name the cut family covered by retained evidence, and return an explicit unknown for unsupported cuts rather than restoring a stale case. *New:* Opposed models can remain usable after feature changes without storing or recreating their original parameters. *First test:* Rotate or collapse one feature in a small synthetic decision table; plant an identical-ID wrong replacement and an out-of-scope cut. Compare raw-coordinate transport, full replay and scoped prediction sketches.

**WCX3. Budget the measurement error that a peer edit is allowed to introduce.** Parts: D3-06 shared noise model, D3-18 transcript slack, D3-24 presentation control, DF03 answer versus survey effect, CE4-24 bounded corruption. *Mechanism:* Select opposite worlds under the same declared response-noise process, and give a peer edit a checked bound on how much it may change the diagnostic transcript. If presentation changes what the pair means, preserve a matched control or stop claiming separation. Keep opposition that requires different noise models in a separate sensitivity report. *New:* A route can remain physically open yet cease to distinguish what the learner needs to know; a quantitative budget can reveal that failure before admission. *First test:* Construct two toy reporting channels with equal report counts but different false-alarm and power margins, plus a changed-presentation decoy. Compare nominal reachability, exact transcript diagnosis and a conservative slack budget.

**WCX4. Admit a family of peer writes with a checked frame and a reusable promise.** Parts: D3-11 weakest peer guarantee, D3-12 checked dependency frame, D3-13 compatible histories, D3-19 abstraction for unseen peers, D2-02 two-write contract, IP19 response collision. *Mechanism:* Export the remaining observations or transitions a peer must preserve and verify a dependency frame on the actual execution prefix. Intersect effects only on compatible histories. Admit unseen peers through a checked abstraction, refining it when a new concrete effect changes the conclusion. *New:* A reusable peer contract could cut verification work without letting optimistic independence or impossible joint worst cases dictate admissions. *First test:* Enumerate a finite family where harmful margins cannot co-occur on one history, plus a syntactically disjoint peer that breaks a dependency. Compare full pairwise verification and static footprints with reusable promises.

**WCX5. Choose an edit order using a real pre-write observation.** Parts: D3-14 observable order selector, D3-15 joint blocker, D3-16 local guarantee repair, D2-04 aliased context, L4-17 preserve the unrelated write, SD2-05 third-edit blocker. *Mechanism:* When neither unconditional order is safe, use a permitted pre-write observation only if it distinguishes the hidden histories on which legal orders differ. If no such observation is available, report a scoped combination of effects that closes all routes; allow its members individually and try a local repair that preserves both intended changes. *New:* The result can be a useful joint restriction instead of a blanket veto, without pretending a scheduler can see hidden state. *First test:* Build two aliased starts requiring opposite orders in a finite toy, then add or withhold a paid separator and a third write. Compare oracle scheduling, full joint checking and a sparse blocker with bounded repair.

**WCX6. Return to a belief state where an authorized successor can finish.** Parts: D3-17 phase checkpoint, D3-20 observable return, D3-23 spare contrast, D3-25 replacement controller transfer, D2-23 equivalent closure, CE4-13 successor opportunity, DF16 migration bridge. *Mechanism:* Specify return in terms of what a successor can still infer and test, not a hidden state or timer. Carry a spare contrast for a repaired opposing pair and validate a replacement controller under both historically compatible worlds before transferring the route obligation. *New:* An interface can return to safe service while losing its ability to resolve old work; an observable return contract distinguishes the two. *First test:* Interrupt a toy workflow across a hidden phase boundary, migrating only one control surface. Compare state-only checkpoints, exact belief-state diagnosis and a spare-contrast handoff; test a physically safe but uninformative return.

**WCX7. Use one counterexample to repair the witness and its route, but verify each separately.** Parts: D3-21 jointly diagnosable pair, D3-22 shared failure trace, D3-26 world versus route obstruction, D2-26 independent failures, CE4-21 survive unrelated writes, DF28 probe blind spot, L4-21 hit versus no-hit. *Mechanism:* Choose a reusable opposed pair together with a diagnostic contract. If a peer write breaks it, use the failing trace to locate the changed world assumption and the missing report, then recheck each claim independently. Pairwise diagnosability is never evidence that every possible world remains distinguishable. *New:* A repair could reuse one trace while still distinguishing whether to restore a route, replace an explanation, or concede that evidence is unavailable. *First test:* Cross a false pair and a cut route in a four-cell finite simulator with equal old scores. Compare independent full solves, checking the prospective pair jointly, and a shared-trace warm start; score false closure, missed routes and total validation work.

**WCX8. Keep unresolved decisions and their evidence paths alive across independent writes.** Parts: D3-01 certified pivot, D3-02 survival slack, D3-04 retirement triggers, D3-05 asymmetric repair budget, D3-07 blocking certificate, D2-11 opposed pair, CR24 impossibility witness, D3-03 shared decoder and contrast, D3-08 localize changed evidence, D3-09 reidentify by predictions, D3-10 finite memory scope, D2-19 compression bound, CE3-10 observable rebasing, CR29 versioned witness, D3-06 shared noise model, D3-18 transcript slack, D3-24 presentation control, DF03 answer versus survey effect, CE4-24 bounded corruption, D3-11 weakest peer guarantee, D3-12 checked dependency frame, D3-13 compatible histories, D3-19 abstraction for unseen peers, D2-02 two-write contract, IP19 response collision, D3-14 observable order selector, D3-15 joint blocker, D3-16 local guarantee repair, D2-04 aliased context, L4-17 preserve the unrelated write, SD2-05 third-edit blocker, D3-17 phase checkpoint, D3-20 observable return, D3-23 spare contrast, D3-25 replacement controller transfer, D2-23 equivalent closure, CE4-13 successor opportunity, DF16 migration bridge, D3-21 jointly diagnosable pair, D3-22 shared failure trace, D3-26 world versus route obstruction, D2-26 independent failures, CE4-21 survive unrelated writes, DF28 probe blind spot, L4-21 hit versus no-hit. *Mechanism:* Maintain bounded opposed witnesses, checked retirement conditions and a reusable peer contract for the observations that distinguish them. Admit writes only under reachable and informative histories; when a contract breaks, expose whether the failure is infeasible opposition or missing evidence. Repair locally only where a lawful substitute can still preserve old service. *New:* A learner could reuse diagnosis work across unrelated updates while making clear what its retained witnesses do and do not establish. *First test:* Enumerate finite synthetic revisions with fragile witnesses, aliased starts, correlated histories, noisy reports and lost evidence routes. Compare exact re-solving, full prospective pairwise checks, replay and equal-byte separate witness/route state; report coverage, false closure, and work at matched old service.
