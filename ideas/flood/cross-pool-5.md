New sources: `tree/self-describing-weights.md` (PR #53, SW#), `ideas/flood/info-coding.md` (PR #56, IC#), `tree/rl-discriminating-experiments.md` (PR #57, DE#), `ideas/flood/systems-db.md` (PR #58, SD#), `ideas/flood/logic-proofs.md` (PR #59, LP#), `tree/forward-trace-compile.md` (PR #60, TC#), `ideas/flood/cogsci.md` (PR #61, C##), `tree/harness-falsifying-probes.md` (PR #62, FP#), `tree/edit-simulator.md` (PR #63, ES#), `ideas/flood/chemistry.md` (PR #64, CH##), `tree/harness-self-testing-skills.md` (PR #65, ST#). Tree prefixes use the numbered raw ideas. These are raw and unfiltered.

**R1. Counterexample-driven write isolation.** Parts: SD3 write skew, TC5 bilateral trace links, FP9 retention refuter, LP17 certificate debt, Q1. *Mechanism:* Two learners can prepare writes against the same snapshot. During prepare each exports its negative scope and a case most likely to be changed by the other write. The committer tests only the joint collision frontier; a failed frontier test either serializes the pair or converts it into an explicit unresolved obligation. *New:* The isolation allowance is expressed in behavior, so disjoint parameter writes can still conflict and overlapping writes can pass. *First test:* Stage paired writes in the PR #60 trace world; compare joint failures caught per probe against coordinate locking and full sequential checks.

**R2. Skill passports with return tickets.** Parts: ST6 transfer the experiment, SW3 ABI stability, DE13 experiment templates, C01 redescription, Q5. *Mechanism:* Each skill carries a reader-independent experiment and two compiled realizations, one for actions and one for recovering the experiment from the reader's current representation. Failure of the return trip triggers re-derivation, not blanket deletion. *New:* Migration must preserve the ability to reconstruct evidence even when the new procedure is different. *First test:* Swap readers in A3 (PR #31/#33); compare experiment-retaining migration with procedure-only and experiment-only migration on reversed menus, with filler and entropy-matched no-lesson arms.

**R3. Rival-indexed rate-distortion.** Parts: IC12 successive refinement, DE11 debt ledger, LP2 interpolants, C09 schema accommodation. *Mechanism:* Store a coarse behavior plus refinement packets that each distinguish one surviving pair of explanations. Evict packets by the least consequential counterfactual disagreement they would make undecidable; when a later task supplies the witness, absorb the packet into the schema instead of replaying it. *New:* The codec preserves the ability to tell rival mechanisms apart, not merely to reconstruct old labels. *First test:* On the PR #57 CPU probe, sweep memory bytes and compare hidden-corner accuracy and old observed-cell accuracy against stratified witness replay and a label-distortion codec.

**R4. A refutation dividend for redundant writes.** Parts: FP5 redundancy probe, FP16 cheapest refutation, ES1 response tensor, CH11 sacrificial links. *Mechanism:* Simulate several cheap write routes, then each route pays its estimated cost to break the cheapest old-case counterexample. Use the lowest-risk route and reserve its alternate as a replaceable link only where independent probes show the original route has no cheap substitute. *New:* Redundancy allocation depends on how easily a route can be disproved, not activation magnitude or a global replay score. *First test:* In the PR #53 tanh probe, duplicate selected feature routes and apply a conflicting second edit; match write rank and compare losses against norm-based routing.

**R5. Spend evidence to borrow plasticity.** Parts: CH07 limiting reagents, C11 reconsolidation windows, ST2 internalization litmus, LP7 conservative extension, MX1 route-dependent correctability. *Mechanism:* Distinct applicability and retention witnesses buy a temporary editable window on the route the reader actually uses. If the unaided probe passes but contextual following fails, spend evidence on the contextual route rather than rewriting the consolidated answer. *New:* Plasticity rights expire and are charged to observations that can distinguish the repair route. *First test:* In a small A3-derived router, compare evidence-triggered route windows with random and recall-triggered windows at equal writes, same-length filler and entropy-matched no-lesson controls.

**R6. Branch-only edit corridors.** Parts: CH04 transition-state bridges, ES4 counterfactual edit replay, SD8 compensators, Q1. *Mechanism:* Fit a transient auxiliary coordinate from branch pairs where two competent writes interfere. Use it only inside the transaction, then fold back into the live substrate and attach a behavioral compensator learned from the reverse path. *New:* The remembered object is a low-loss path between behaviors, not a persistent adapter or an average of endpoints. *First test:* Train two overlapping writes on the PR #53 MLP and compare bridge, straight interpolation, and a persistent equal-training-budget adapter after folding and selective undo.

**R7. A compiler that learns from negative receipts.** Parts: TC8 witness-carrying rejection, SW10 typed writes, ES15 keep-set twins, LP17 certificate debt. *Mechanism:* When a write is rejected, the compiler returns the smallest input pair demonstrating whether it needs a new domain guard, a better address, or an independent retention measurement. Pool typed receipts across hosts as training data for repair routing. *New:* Failed writes supervise which interface to change, not just whether to re-try. *First test:* Plant key aliases and old-task collisions in the PR #60 probe; compare type-directed repair with a generic counterexample queue at equal forward budgets.

**R8. Burst protection by semantic interleaving.** Parts: IC3 interleaving, LP2 task interfaces, FP5 redundancy probes, CH11 sacrificial links. *Mechanism:* Partition a skill by independently testable entailments, then assign those fragments to write routes whose measured failure sets least overlap, leaving disposable fallback links for the easiest entailments to relearn. *New:* The interleaving unit is a semantic consequence and the channel model is measured behavioral co-failure, not layer adjacency. *First test:* Apply block erasures and unrelated training to a toy multi-route Boolean learner; compare equal-byte random and effect-guided interleavers on surviving entailments.

**R9. Header calibration from experiment-shaped negatives.** Parts: SW20 counterfactual rewind, DE4 minimal discriminators, TC1 boundary queries, ST13 probabilistic skills, ES1 response tensors. *Mechanism:* A stale address header suggests two rival effect predictions; a skill draws the cheapest boundary case that distinguishes them and pays for one virtual write. The answer refreshes the effect distribution, not the underlying task weights. *New:* Calibration data are generated by disagreement over the address's supported scope, not drawn uniformly around weights. *First test:* In the PR #53 MLP, vary support and edit size across checkpoints; compare effect-interval coverage against random forks and an equal-size external predictor.

**R10. A skill archive that can rebuild its own write interface.** Parts: SW3 ABI stability, SW10 typed writes, SW20 refresh, IC3 interleaving, IC12 refinements, DE4 minimal experiments, DE11 debt, DE13 templates, SD3 write skew, SD8 compensators, LP2 interpolants, LP17 certificate debt, TC5 trace linker, TC8 failure witnesses, C01 redescription, C11 reconsolidation, FP5 redundancy tests, FP9 retention refuter, ES1 effect tensor, CH07 evidence spend, CH11 sacrificial links, ST6 experiment transfer, Q4 obligations. *Mechanism:* Package a skill as an experiment plus coarse obligation, disputed refinements, and typed write receipts. The archive reconstructs a compatible write after a reader swap by re-running the experiment, reopening only affected refinements, and negotiating write skew against the old reader's live obligations. Repairable pieces are spread across behavioral failure domains. *New:* A retained skill is the ability to rebuild and check its own writable interface, including when part of the old interface has disappeared. *First test:* Add a renamed-slot checkpoint and a colliding write to the PR #60 toy; compare recovered behaviors and verification cost with restoring skill text, replaying witnesses, and full recompilation.
