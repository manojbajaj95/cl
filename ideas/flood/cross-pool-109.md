Raw proposals.

**TCX1. Promote a recurring correction only as far as its evidence supports.** Parts: T4-01 bidirectional promotion, T4-03 counterfactual naming, T4-05 preserve continuous skills, T4-10 shadow competition, T4-12 compact intermediate code, T4-14 context budget, T4-30 regional residual triage, T3-24 conflict-triggered promotion, REX4 conditional residual retention, D3-09 witness identity. *Mechanism:* For a recurring conflict, test a scoped edit of the existing residual, a compact code and an explicit description against the same held-out inputs. Only expose the behavior the description faithfully replaces; keep unrelated continuous effects. When returning a stable rule to weights, keep its approved correction witness and test that it still works. *New:* A rule can move out of text without losing its editable boundary, and a continuous effect need not become prose just because one region was contested. *First test:* Use harmless toy tasks with a categorical exception and a continuous calibration change, then compare always-tacit, always-text and reversible placement at equal context.

**TCX2. Separate shared habits from locally contradictory exceptions.** Parts: T4-02 cross-rule factoring, T4-04 split contradictory habits, T4-06 induce a shared condition, T4-09 domain branches, T4-13 causal scope, T2-20 negative-scope checks, D3-12 dependency frame, D5-18 authorized replacement lesson. *Mechanism:* Factor several approved corrections into one proposed rule only when it predicts a held-out correction and leaves nearby negatives untouched. If identical examples require different behavior in different scopes, preserve separate versioned branches with independent teaching fixtures rather than averaging them or assuming one global habit. *New:* A common explanation must buy reuse without consuming the affected scopes’ ability to learn different corrections later. *First test:* Train on benign ordering conventions with shared examples and opposite exceptions across two workspaces; compare independent patches, one global rule and a shared rule with scoped branches.

**TCX3. Keep only the interaction in context when the solo rules are ready.** Parts: T4-15 interaction deltas, T4-16 compact interaction contract, T4-17 overlap disagreement, T4-19 precedence order, T4-21 recurrence bridge, T4-27 generated interaction delta, T3-07 joint handoff, REX2 fragile continuations, D5-13 learning versus reading. *Mechanism:* After both solo rules pass, keep a short explicit interaction contract while comparing extra reasoning with a scratch interaction delta trained from the same approved examples. Retire the contract only after held-out joint continuations pass for all declared orders. If they do not, leave the solo compression intact and retain the contract. *New:* The memory choice can be made separately for the interaction, with compute-only reasoning as a control for a learned patch. *First test:* Use toy formatting rules with order-dependent outcomes. Compare retaining full context, retaining only the interaction and a learned interaction delta at matched work.

**TCX4. Check whether both rules actually contribute before deleting their shared support.** Parts: T4-18 depth-staged composition, T4-20 delayed handoff, T4-22 mediation checks, T4-26 emergent capability retention, T4-29 approved failure memory, T2-26 coupled calibration, SD2-09 distinguishing suffix. *Mechanism:* Require joint success on matched fixtures that vary one rule while holding the other fixed, then verify a continuation where both effects matter. Save a compact approved witness whenever output agreement hides a shortcut. A sudden score increase alone is not sufficient to delete support. *New:* A handoff can distinguish learned composition from guessing a familiar joint output, including when preserving each rule alone misses the loss. *First test:* Plant shortcuts that pass the usual joint validation set but fail under single-rule changes. Compare endpoint thresholds with ordered counterfactual and continuation checks.

**TCX5. Turn a joint failure into a scoped correction instead of rewriting all its rules.** Parts: T4-07 executable predicates, T4-08 upstream credit, T4-11 synthetic counterfactual rehearsal, T4-23 collision-triggered promotion, L9W14 observable inputs, D3-22 shared repair witness, CR29 versioned recovery. *Mechanism:* In a synthetic rule stream, replay approved intermediate-state fixtures to locate the earliest divergence, then propose an observable predicate only for the disputed overlap. Check versions and nearby negatives and require the original rules to still serve alone. If the cause remains ambiguous, keep the interaction explicit rather than committing a guessed repair. *New:* A compositional failure can make just one previously tacit precedence condition editable without rewriting either base rule. *First test:* Plant identical final failures caused by upstream ordering or late formatting. Compare final-output patches with scoped predicate repair using held-out continuations and a later approved revision.

**TCX6. Retain sparse interaction witnesses without treating untested combinations as safe.** Parts: T4-24 sparse higher-order tracking, T4-25 synthetic co-occurrence, T4-28 joint benchmark, D3-13 compatible histories, SD2-05 third-edit witness, D5-26 retained teaching response. *Mechanism:* Prioritize jointly reachable combinations for scratch tests and retain the smallest failing witness as a versioned record. Allow interactions of any arity; untested overlaps retain their contextual fallback. Before compressing records, verify that an approved later amendment still changes the intended joint behavior. *New:* A sparse ledger can guide attention without drawing guarantees from pairwise independence or deleting the evidence needed for the next repair. *First test:* Use benign streams with both pair and higher-order-only precedence conflicts. Compare pairwise logs, full context and witness-guided retention on cost, missed conflicts and later correction.

**TCX7. Let failures of rule composition decide which tacit behavior needs an explicit edit.** Parts: T4-01 bidirectional promotion, T4-03 counterfactual naming, T4-05 preserve continuous skills, T4-10 shadow competition, T4-12 compact intermediate code, T4-14 context budget, T4-30 regional residual triage, T3-24 conflict-triggered promotion, REX4 conditional residual retention, D3-09 witness identity, T4-02 cross-rule factoring, T4-04 split contradictory habits, T4-06 induce a shared condition, T4-09 domain branches, T4-13 causal scope, T2-20 negative-scope checks, D3-12 dependency frame, D5-18 authorized replacement lesson, T4-15 interaction deltas, T4-16 compact interaction contract, T4-17 overlap disagreement, T4-19 precedence order, T4-21 recurrence bridge, T4-27 generated interaction delta, T3-07 joint handoff, REX2 fragile continuations, D5-13 learning versus reading, T4-18 depth-staged composition, T4-20 delayed handoff, T4-22 mediation checks, T4-26 emergent capability retention, T4-29 approved failure memory, T2-26 coupled calibration, SD2-09 distinguishing suffix, T4-07 executable predicates, T4-08 upstream credit, T4-11 synthetic counterfactual rehearsal, T4-23 collision-triggered promotion, L9W14 observable inputs, D3-22 shared repair witness, CR29 versioned recovery, T4-24 sparse higher-order tracking, T4-25 synthetic co-occurrence, T4-28 joint benchmark, D3-13 compatible histories, SD2-05 third-edit witness, D5-26 retained teaching response. *Mechanism:* Transfer solo and joint behavior separately. When joint checks fail, keep the narrow interaction explicit, determine which tacit behavior actually needs correction, and promote only a checked scoped slice. Re-test joint continuations and later teachability before moving that slice back into weights. *New:* One loop can save context without confusing solo recall with joint competence or moving every recurring complaint into permanent text. *First test:* Use synthetic continual rules with scoped contradictions, continuous residuals and order-dependent higher-order overlaps. Compare always-text, unconditional consolidation and witness-driven promotion at matched inference and context costs.
