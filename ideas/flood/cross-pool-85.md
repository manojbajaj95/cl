**FET1. Commit the shared effect and reserve the disagreement.** Parts: CE2-05 common safe write, L2-16 opposite write port, R03 nonadditive control. *Mechanism:* Enumerate the bounded functional edits that improve every plausible reading and preserve old floors. Install a common action only if one exists; reserve a zero-effect port only when both future signed moves are feasible after that commit. The alternatives are not stored serving adapters. Later validated evidence selects a move; if none is warranted, the port stays inactive. *New:* A pending edit can make safe progress now without forcing the writer to precompute two skills or giving up opposite future corrections. *First test:* Enumerate a quantized two-output head with a shared improvement and opposite residuals; add no-common and one-sign-infeasible cases. Score old reads after either branch and after an unrelated write. *Stacked baseline:* Take the stronger of revised-evidence T2L/DnD plus distillation and routed children, and robust common fine-tuning plus a version space and fixed shared basis. Match bytes, observations and write work.

**FET2. Revalidate both reserved directions after a representation change.** Parts: CE2-05 common safe write, L2-16 opposite write port, CE2-02 no-clone contrast, CE2-13 proof obligation, D07 threshold refinement. *Mechanism:* Carry the functional constraint and an example that distinguishes the signed amendments rather than numerical orientations. If intervening training changes the representation, refit the bounded port on the new coordinates and rerun both directional tests before allowing selection. A failed sign retires the two-way reservation rather than silently extrapolating. *New:* The inherited object is an editable contract that can lose one direction under a genuine refinement, not a cached vector that happens to transfer. *First test:* In a two-feature toy model, rotate features or collapse one distinction before the deciding observation. Test both signed responses and unaffected cases. *Stacked baseline:* Regeneration and distillation with a routed adapter bank plus fitted adapter transfer and matched replay of the no-clone contrast; charge the translated port and evidence.

**FET3. Buy a resolving exercise only when it can select a lawful signed edit.** Parts: CE2-05 common safe write, L2-16 opposite write port, CE2-25 exercise completes a write, L2-02 discriminating comparison, CR24 impossibility witness. *Mechanism:* After installing only the unanimous effect, choose an ordinary comparison whose two possible outcomes each authorize a different feasible sign. If the comparison cannot arrive before the deadline, or neither sign clears retention, keep the common effect and leave the remainder pending. *New:* The exercise is valuable only insofar as it can select an executable future correction, not merely increase confidence about the desired answer. *First test:* Construct two toy streams with identical prefixes, one resolving comparison and one equally informative comparison that arrives too late. Match retained cases and number of observations. *Stacked baseline:* Active querying with robust partial commit, then frozen T2L/DnD regeneration, per-skill distillation and a charged routed library; allow a cue-conditioned shared adapter.

**FET4. Challenge a split with a path and rank search before buying a router.** Parts: L2-01 callable obstruction, L2-03 paired directional clustering, L2-04 shared detour, L2-05 rank ladder, L2-06 rater dropout, L2-07 observable intersection, L2-08 exposure control, L2-09 new cue, CE2-11 cost receipt, R05 noisy extrema, R13 worst-case check, LL17 birth witness. *Mechanism:* Fit shared and split feedback models on matched proposals, then enumerate retaining shared detours over a finite rank ladder. Issue an obstruction only for the declared horizon, exposure, and router-observable slice. Rerun the relevant bound if a new cue or independent evidence changes feasibility. *New:* The cost of sharing can be traced to a specific resource or missing observation rather than to a negative gradient cosine. *First test:* Enumerate a tiny lattice with curved detours, imbalanced exposure, one noisy rater and a late cue. Compare growth, active mixture selection and shared cue-conditioned rank expansion on equal resources.

**FET5. Transport relations between writes while forking only correction authority.** Parts: L2-10 future update contrast, L2-11 amend versus call, L2-12 shared and private inheritance, L2-13 negate versus undo, L2-14 stopping threshold, L2-15 recipient swap, CE2-01 aggregate promise, CE2-03 counterfactual relation, CE2-06 composition of edits, CE2-12 serial boundary, CE28 evidence versus decision, LL22 amendment fork. *Mechanism:* Keep serving shared while translating a queued relation about what a correction can affect. Replay the same feedback in a scratch state with the owner swapped; if a later legal correction reveals a genuine disagreement, allocate only the private write route and retain the old shared route for both. *New:* A relation between future writes can move across a refined scope without carrying either private policy. *First test:* In a toy formatter with one shared clause, insert an intervening edit before an undo and swap the claimant. Compare a common meta-writer, equal-byte symbolic route, and separately distilled adapters.

**FET6. Use a new witness to translate scope instead of guessing where a term moved.** Parts: CE2-04 descendant falsifier, CE2-07 reason versus map uncertainty, CE2-08 intervention query, CE2-09 lower-layer retarget, CE2-10 witness substitution, L2-18 proof expiry, CE07 translation clause, CR29 fresh version binding, R10 online identification. *Mechanism:* Translate a pending effect as a pair of behavioral interventions and a set of permitted implementation sites. Independently update the meaning hypothesis and the representation map. Only retarget to an earlier layer when the new head cannot realize the required distinction and the earlier write passes the original falsifier. *New:* A pending request could survive a representation change without letting a good fit on yesterday's predicate substitute for a current proof. *First test:* Collapse an old feature and expose a new witness in a tiny two-layer model. Compare coordinate transfer, re-distillation and intervention transport; include same-target wrong-scope negatives.

**FET7. Rejoin on two-way editability rather than pooled agreement.** Parts: L2-17 forward counterexample, L2-19 shared serving only, L2-20 two-way corrections, L2-21 exposure shift, L2-23 holding time, L2-24 third solution, L2-25 right to refuse, L2-26 later split moves, IP19 collision ledger, SD2-05 third-edit blocker, LE5-09 preserve next response, D11 recycle capacity. *Mechanism:* Search the common space, not just the line between the children, for a shared solution passing both cohort floors under fixed support. Try a legal correction from either side and then the other; retain separate amendment coordinates or refuse an ambiguous correction if this fails. *New:* A rejoin decision could recover live rank while preserving a measured ability to correct or split again. *First test:* Use a lattice with a non-interpolated common solution, a temporarily absent cohort and an order-dependent third edit. Compare averaging, replay-conditioned regeneration, keep-all, and exact finite search.

**FET8. Pass a diagnostic question rather than a child adapter.** Parts: L2-22 retain separating comparison, CE2-14 substitute intervention, CE2-15 choose ambiguity, CE2-16 interaction-induced loss, CE2-17 shortcut adversary, CE2-18 active separator, CE2-19 partial outcomes, R09 budgeted forgetting, LL23 merge and resplit, CE23 witness substitution. *Mechanism:* During compatible service discard redundant children but retain a compact recipe for the comparison that separated them. A successor realizes the diagnostic with its own actions and checks that partial observations still identify the relevant difference, rather than treating a past question as permanently diagnostic. *New:* Compression can preserve information about what to ask instead of preserving either answer. *First test:* Remove an action after a merge and introduce a shortcut correlated with the old question. Compare stored children, fresh exploration and an inherited comparison reconstructed from partial outcomes.

**FET9. Teach a fresh learner to rebuild the exercise under different affordances.** Parts: CE2-20 auxiliary concept, CE2-21 complementary enactments, CE2-22 action-removal rehearsal, CE2-23 verify compression on a blank student, CE2-24 nuisance-varied witnesses, CE2-26 teach a fresh compatible rule, LE5-22 independent reopening routes, CR22 substitute test, LL26 cheaper next correction, D06 scope-limited structural check. *Mechanism:* Keep two complementary realizations of a diagnostic and permit a smaller exercise only after a fresh student learns from it and teaches a related rule to another student. Losing an affordance should invalidate only the witness it supplied, not license keeping a hidden teacher solution. *New:* A rehearsal object could retain independently replaceable means of teaching after the original feature or action is retired. *First test:* In a three-generation finite toy stream remove one action and vary nuisance variables. Compare replay, fixed exercises, and independently verified compressed recipes under equal bytes and training observations.

## Prior-art check: PR #346 — LoRA Learner 2

Extends [round 84's review](cross-pool-84.md#prior-art-review-pr-344--a-lora-writing-learner). [Text-to-LoRA (arXiv:2506.06105)](https://arxiv.org/html/2506.06105), §§3–5, generates factors from a description and module/layer embeddings, learned by reconstruction or supervised fine-tuning. [Drag-and-Drop LLMs (arXiv:2506.16406)](https://arxiv.org/html/2506.16406), §§2.2–2.6 and 3, generates LoRA from unlabeled prompt batches at inference using a hyper-convolutional decoder trained to reconstruct tokenized checkpoints. Both show held-out adaptation; neither evaluates deriving, revoking, or rejoining a split from repeated feedback on one live skill. Below, a difference is relative to these papers, not a literature-wide novelty or performance verdict.

**Every row uses the stronger matched regeneration stack:** rerun frozen T2L and DnD from the revised evidence in their respective input formats, allow per-skill distillation and an equally budgeted routed library, and include a cue-conditioned shared adapter. Match the observable prefix, rank, live/peak bytes, inference/update compute, and query limits. Score old behavior after each write and after another ordinary amendment; after a split serve old requests through the current children, not a hidden parent.
