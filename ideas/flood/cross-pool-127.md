**BRX1. Undo a virtual repair by testing what the return loop leaves behind.** Parts: EB01 closed body loops, EB02 registered inverse, EB03 re-identification, EB04 factored deltas, EB05 detachable training, EB06 order effects, EB18 body-only rollback, EL02 repair rollback, NP2-05 retain intervening lessons, NP5-25 protected inverse. *Mechanism:* Stage a partial repair in a scratch simulator, compare removable deltas, trained inverses and trace-only reconstruction, and hold the new task lesson fixed across branches. Check the complete and partial return loops in both orders before treating the compensation as detachable. *New:* A repaired part can recover its calibration without undoing the effect it had on another part or the learning acquired during wear. *First test:* Use virtual manipulators with independently reversible and coupled parameter changes. Compare full restoration, no rollback and a checked body-only rollback on new and old tasks.

**BRX2. Grow a calibration probe only when another skill exposes a missing direction.** Parts: EB10 coverage certificate, EB14 skill-aware design, EB15 growing probe, EB19 loop-derived subspace, EB24 simulated perturbations, EB27 task-fragment probes, EB28 probe dimension, EL10 independent receipts, PL5-10 held-out effects. *Mechanism:* Estimate the directions visible to the simulated calibration routine and compare them with effects from controlled return loops and held-out skill outcomes. Add a segment only when it distinguishes an uncovered cause. Treat a match as evidence about tested perturbations, not as a general certificate. *New:* An adaptive probe needs to cover the body changes that matter to the skill set, rather than every parameter or only the changes it already detects. *First test:* Introduce indistinguishable calibration traces with different synthetic task effects. Compare fixed probes, fixed-length longer probes and targeted additions against independent simulator outcomes.

**BRX3. Separate body, sensor and world errors by whether the next lesson transfers.** Parts: EB08 remount rollback, EB11 two-sided projection, EB12 shared conjugator, EB13 leak migration, EB16 object probe, EB17 perception probe, EB20 plasticity gating, EL27 ritual-gradient routing, NP4-13 future response map. *Mechanism:* Use distinct simulator fixtures for body motion, virtual sensor alignment and object interaction. Propose routing from the probe responses, but defer assignment if they disagree or cannot distinguish causes. Before moving an accumulated correction between channels, test with a matched new lesson on scratch states. *New:* A projection that separates current probe errors can still send a later task lesson to the wrong store; testing the next write distinguishes the two. *First test:* Combine virtual remounts with friction and actuator shifts. Compare a hard mismatch gate, a shared body channel and checked multi-probe routing on held-out causes and subsequent task learning.

**BRX4. Transport replay through virtual bodies only where its effects survive.** Parts: EB07 wear manifold, EB09 sibling transplant, EB21 per-body channel, EB22 canonical replay, EB23 counterfactual replay, EB25 architecture transfer, EL24 observable contracts, L9W14 representation-independent predicates, D5-26 retained teaching responses. *Mechanism:* Use a shared effect contract to compare replay in canonical coordinates, transformed trajectories and fresh virtual demonstrations. Require valid observations and the same downstream update on held-out bodies and policy versions; keep unsupported portions separate instead of assuming old replay remains valid. *New:* A body or architecture translation is useful when it preserves what the lesson can teach, not just where it places an old trajectory. *First test:* Cross held-out simulated body differences with a policy migration. Compare replay reuse, checked reuse and full retraining at matched simulated steps.

**BRX5. Keep virtual constraint witnesses scoped to the simulator that supports them.** Parts: EB26 canonical constraint coordinates, EL20 candidate safe-set transport, L8W22 scratch round trip, CR29 versioned recovery. *Mechanism:* Retain the simulator assumptions alongside each constraint witness. Use a coordinate change to nominate where to recheck on a different virtual body, and independently verify the affected cases after a change or rollback. If results are ambiguous, keep the witness scoped to its original version. *New:* Restoring a coordinate frame does not restore the evidence behind an earlier constraint if either the simulated body or the simulated contact law changed. *First test:* Use toy physics with a reversible body change and a nonreversible change in contact assumptions; compare blind reuse, independent rechecking and complete recertification inside the simulator.

**BRX6. Make repair, routing and replay answerable to independent virtual-body tests.** Parts: EB01 closed body loops, EB02 registered inverse, EB03 re-identification, EB04 factored deltas, EB05 detachable training, EB06 order effects, EB18 body-only rollback, EL02 repair rollback, NP2-05 retain intervening lessons, NP5-25 protected inverse, EB10 coverage certificate, EB14 skill-aware design, EB15 growing probe, EB19 loop-derived subspace, EB24 simulated perturbations, EB27 task-fragment probes, EB28 probe dimension, EL10 independent receipts, PL5-10 held-out effects, EB08 remount rollback, EB11 two-sided projection, EB12 shared conjugator, EB13 leak migration, EB16 object probe, EB17 perception probe, EB20 plasticity gating, EL27 ritual-gradient routing, NP4-13 future response map, EB07 wear manifold, EB09 sibling transplant, EB21 per-body channel, EB22 canonical replay, EB23 counterfactual replay, EB25 architecture transfer, EL24 observable contracts, L9W14 representation-independent predicates, D5-26 retained teaching responses, EB26 canonical constraint coordinates, EL20 candidate safe-set transport, L8W22 scratch round trip, CR29 versioned recovery. *Mechanism:* Use virtual return loops to test whether body corrections detach, expand calibration only for missing skill-relevant effects, and verify transported lessons and constraints against independent simulator outcomes. Keep task learning separate when undoing a body-specific correction. *New:* A continuous learner can revise its virtual body model without assuming that matching the old probe restores its skills, future learning or constraints. *First test:* Run a harmless simulation-only stream with coupled repairs, remounts, changed contact assumptions and a policy migration. Compare monolithic adaptation, versioned rollback and checked routing at matched work.
