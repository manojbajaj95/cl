Keep the behavior's semantic contract separate from its stage-specific realization; a present-day match does not prove identical interactions, or equivalent behavior after future edits. The printed dilution and null-LoRA observations do not identify a mechanism. These are raw and unfiltered.

**W1. Behavioral identities with an expiration condition.** Parts: BF2 contract core and realization envelope, BF9 footprint counterfeits, MS19 priced suffix basis, SE16 relational refutations. *Mechanism:* Give a replacement implementation two distinct certificates: it meets the semantic contract now, and it can stand in for the current implementation for a declared set of future requests. An unseen suffix that separates two seemingly identical implementations shortens only the second certificate; pay to add a port when the suffix exposes a distinction shared by several behaviors. *New:* The same behavior name remains usable for current substitution even when the right to reuse a future-edit summary expires. *First test:* In a finite router, plant identical current behavior and singleton footprints but divergent behavior after a held-out two-write suffix. Compare byte-matched current-output fingerprints and full continuation tables on incorrect swaps and correction cost.

**W2. Retention credit that accrues interest only when a future read is reachable.** Parts: BF5 timed access, BF20 operating regions, MD1 retention debits, MS22 joint failure state, OK8 omission tickets. *Mechanism:* Maintain a joint slack ledger over stage-ordered read paths rather than one balance per note. A write spends only against routes it can currently reach, but reserves slack on dormant routes an admitted later request can reopen. Uncertain interactions freeze the relevant reserve without freezing unrelated writes. *New:* A margin budget prices future reachability and shared failure, not just the sum of present singleton effects. *First test:* On a synthetic routing stream, plant matched-load triples with either smooth additive threshold crossing or a genuine joint effect. Compare accepted useful writes and worst old margin against a count-only curve, pairwise guards and exhaustive subset checking.

**W3. Make an accepted update survive copied evidence without giving it unlimited priority.** Parts: BF16 boundary twins, MD3 binding versus authority, MD4 evidence ancestry, OK9 causal permission, DT planted-signature contrast. *Mechanism:* When a correction conflicts with repeated prior advice, bind the old and new values independently of their administrative priority. Use boundary interventions and lineage IDs to count independent evidence once each; permit the correction only where its causal scope is authorized. A same-looking repetition from a genuinely independent source can still change the decision. *New:* This protects revision authority against copied advice without treating recurrence itself as fake or making recent notes unconditionally supreme. *First test:* Use the fixed-position PR #103 routing template and a PR #37-style planted wrong rule. Cross duplicate ancestry, queue histogram and authority at constant token count; score legitimate correction and signature propagation with same-length filler and source-fitted entropy-matched no-lesson arms.

**W4. Fallback by replacing the smallest observable missing part.** Parts: BF6 common-path rescue, BF22 missing ports, MD9 probe-to-protocol escalation, MS17 repairable erasure, TD fixed-detector recovery. *Mechanism:* If several tool or substrate failures share a footprint residual, make the next diagnostic report the missing semantic value rather than regenerate the tool. Install a temporary replacement only for that port; until held-out reads agree, mark the port unresolved and block requests requiring it while unaffected ones continue. *New:* A repair operation restores a measured missing read in a live state summary instead of repairing every procedure that happened to alarm. *First test:* In the PR #101 simulator, make two silent API transforms share one stale return field and a third share only its symptom. Hold detection fixed; compare calls to stable recovery against procedure regeneration and per-repair tests.

**W5. An adapter ships the cost of leaving an old directive recoverable.** Parts: BF3 traced null, BF13 read-preserving distillation, MD12 counterfactual access cost, MS13 on-demand materialization, ISA2 swap consistency. *Mechanism:* Before accepting a weight write, test whether protected instructions are still effective when called directly and when recovered through a bounded query. If the adapter retains only the second route, charge its additional steps to the write contract and use a separate permission gate to decide whether that fallback is acceptable. *New:* Instruction preservation has a measurable access cost even when both implementations can eventually produce the same answer. *First test:* Extend the PR #100 swap matrix with instruction-triggered entity selection, fixed-prefix toggles, and EOS/default controls. Compare trained null, zero-update, same-norm random, and read-preserving adapters at matched standalone lift, with length-matched filler and entropy-matched no-instruction arms.

**W6. Compress a memory lane only if its alternatives fit the same persistent edit.** Parts: BF8 redundant read clauses, MD20 minimal separators, MD22 explicit join lanes, SE6 lossless joins, MS14 shared state for separate editors. *Mechanism:* Split a congested store into lanes that expose a minimal semantic join. Each lane exports alternative sufficient reads as a relation over a shared edit variable, not its own best repair. Recombine the lanes only if the join still supports all protected continuations; otherwise retain the small separator as live state. *New:* Independent reader lanes can trade proofs of which combined edits work without sharing full memory or mistaking individually valid repairs for one common fix. *First test:* Use a two-lane finite routing join with parity-correlated valid edits, including one case with full marginals and an empty intersection. Compare compression, joint false accepts and old joins against top-k retrieval, independent point repair and exact enumeration.

**W7. A reversible no-op becomes a probe instrument for load, position, and priority.** Parts: BF12 cancellation control, BF14 target-null write bank, MD14 no-binding sentinel, MD16 decision-local checkpoints, ISA1 measured footprints. *Mechanism:* Build pairs of rules whose isolated shifts on a fixed rival cancel at a shared port, but whose positions, ancestry or support can be independently perturbed. A pair with no applicable binding must also leave a checkpointed valid binding unchanged; a failure selects which future perturbation the reader's identity assay needs. *New:* Counterfactual no-ops can distinguish generic load from identity-sensitive collisions without adding a new attention-bias mechanism. *First test:* Run a fixed-length, balanced-queue PR #103 factorial crossing inert spans, active wrong-key rules and cancellation pairs at the same positions. Test predictions on disjoint rule identities, with filler and source-fitted no-lesson temperature, before attempting any mediator claim.

**W8. The editor can sell a future port only with a migration message.** Parts: BF10 append-only basis, BF15 moving-model units, MS1 minimum migration message, MS3 blocked re-entry, OK21 future-effect escrow, SE21 checked migration, ELB5 layered descriptions, ELB8 interactive repayment. *Mechanism:* When a new request family exposes a distinction missing from the live summary, retire the corresponding capability until a versioned migration message reconstructs the separating coordinate. Prepay a base message for all reachable hosts and request only the missing refinement when the old side information stops decoding it. Account for retained bits, authorized questions and preparatory edits separately; let unchanged clients keep using the old calibrated envelope. *New:* Adding an operation has a specified state price and cannot silently reacquire forgotten information through a wider interface. *First test:* Use the PR #104 affine closure oracle to choose a rank-increasing port; compare required state bits and later worst-group retention with checkpoint fallback, full intent and optimistic port admission at the same admitted coverage.

**W9. Turn a postprocessor into a feedback-aware continuation on purpose.** Parts: BF18 feedback lifting, BF23 stage-order tests, MD5 typed residual queries, MS5 old-script migration lenses, FA8 continuation seams (PR #99), TD. *Mechanism:* Version a tool wrapper together with the feedback edge that reads its output. The wrapper publishes a residual question for each output field newly read upstream; answer just those questions under paired old/new continuations, and translate old edit scripts only where the resulting state transitions commute. *New:* Two wrappers with the same current output can require different migration evidence because the next turn reads different parts of it. *First test:* Add one feedback edge to a PR #101 toy procedure while leaving its one-turn outputs identical. Hold the alarm fixed; compare stable recovery and protected suffixes with output-only migration and full history replay.

**W10. Hide an edit's target and verify the new state's fingerprint from its remaining obligations.** Parts: BF17 side-effect-only identity, BF24 indistinguishable readers, MD18 disagreement compaction, MS8 successor code length, SE20 proof-capped receipt retirement, ELB6 description dependency sets, ELB14 loan cascades. *Mechanism:* Among writes that achieve the same intended revision, choose the one whose successor has the shortest verified description after pricing how many later descriptions depend on facts this write makes unstable. Retire a stored receipt only when remaining proof dependencies imply it; where two compact states agree on all incumbent probes, select a suffix that distinguishes them or mark both unknown. *New:* Compression is an objective for choosing among equally good writes, and protected behavior—not target gain—must identify the compact successor. *First test:* In a small PR #104 affine world with actions that reach the same target but retain different latent correlations, compare successor state bits and held-out suffix failures against minimum-norm edits, an install-time code-length objective and equal-byte prefix replay.

**W11. A memory system that versions what it means to be the same behavior.** Parts: BF2 semantic core, BF5 stage access, BF8 alternative reads, BF9 counterfeits, BF13 read-preserving distillation, BF14 null instruments, BF18 feedback lifting, BF20 local envelopes, BF22 missing ports, MD1 debits, MD3 binding and authority, MD4 ancestry, MD5 residual queries, MD12 access cost, MD16 binding checkpoints, MD20 separators, MD22 read lanes, MS1 migration bits, MS3 blocked re-entry, MS5 script lenses, MS13 state materialization, MS17 erasure flags, MS19 priced suffixes, MS22 joint state, ELB5 layered intent, ELB6 decoding dependencies, ELB14 loan cascades, OK9 causal grants, OK21 escrow, SE6 lossless joins, SE21 migration, ISA2 swap consistency, TD fixed-detector repair, DT planted-signature readout. *Mechanism:* Give each learned behavior a semantic core, an implementation-specific read/write envelope, and a live state summary for the permitted request grammar. If an accepted note or adapter makes a reader forget an old effect, diagnose binding, authority and reachable feedback separately. Spend evidence only on the separating query, then recompile or temporarily close the affected port, preserving unrelated read paths and future repairs. Charge refresh to the descriptions whose decoding depended on that port, rather than rewriting all compressed intents after every shift. *New:* A behavior can keep its identity while its envelope or legal edit state changes; what expires is an explicit claim about substitution, not the entire memory. *First test:* Build a short CPU routing-and-retry stream combining matched-load distractors, a nominally neutral adapter, and a silent tool transform. At matched useful writes and a fixed detector, compare old-task margin, legitimate revision, held-out suffix correctness, and stable recovery per query against a stack of exact-key multi-hop retrieval, singleton footprint guards and full regeneration; include same-length filler and entropy-matched no-lesson arms.
