# Cross-pool merges, round 3

New source: `neuro-bio.md` (PR #46, NB#), combined with rounds 1–2 (X#, Y#) and the files in PRs #36/#39/#41–#45. They are raw and unfiltered; each has a mechanism, why it's new, and the cheapest first test.

**Z1. Write escrow with kinetic proofreading and delayed capture.** Parts: NB01 synaptic tagging and capture, Y4 kinetic proofreading, D2 gradient IOUs, SM1 seed log, contamination law R. *Mechanism:* an episode's updates are held as sparse tags (seed-logged, so they cost almost nothing). They are captured into weights only after n independent outcome confirmations arrive, and unconfirmed tags decay. *New:* learning is deferred until the evidence arrives, with an exponential defect-suppression law and an exact log. *First test:* challenge world, escrow with n = 1..3 vs immediate writes, measuring defect transmission and lag in gain.

**Z2. Permeable scars typed by override budget.** Parts: NB04 perineuronal nets, P28 surgical scar tissue, X1 override-typed weights, Y1 coercive wells, MX1 (passed). *Mechanism:* a stabilized skill deposits a sparse stencil that blocks only writes that would move its high-margin outputs. Writes to its low-margin (editable) outputs pass, so the scar's permeability is the skill's declared override type. *New:* protection is selective by margin, not all-or-nothing by parameter importance. *First test:* #24 harness, stencil vs EWC vs a frozen mask, measuring retention and editability (follow index) on the protected facts.

**Z3. Opponent ledgers for lessons.** Parts: NB12 mushroom-body valence channels, N2 prohibition rebound (ledger), F2-22 inverse lessons, Y8 Lindy/Chesterton retirement, E17 double-entry. *Mechanism:* adopt-evidence and avoid-evidence for each policy are stored in separate channels that never cancel in storage. They are read as a difference only at decision time, which avoids the rebound seen when prohibitions are written as text. *New:* a memory that keeps both sides of the evidence, so retiring a lesson doesn't erase the record of why it was learned. *First test:* N2 harness, opponent channels vs text prohibition vs positive rewrite, measuring rebound rate.

**Z4. Anti-memory immune graph with tolerance nursery and vaccination.** Parts: NB33 idiotypic anti-memories, NB34 tolerance nursery, NB37 alarm cascade, A4/MZ1 immune/vaccination, X4 Popperian memory, E28 clonal expansion. *Mechanism:* small detectors learn which memory fired on a failure and inhibit it in that context. A tolerance set of trusted self-generated states keeps the detectors from attacking good memories, and a contradiction propagates only along read-dependency edges. *New:* a full adaptive immune system for agent memory, with self-tolerance built in. *First test:* G1 router with injected bad lessons: immune graph vs LOO vs no defense, measuring regret and false-inhibition rate.

**Z5. Endosymbiotic consolidation: helpers absorbed op by op.** Parts: NB40 endosymbiotic handoff, SM16 JIT lessons, Y10 Baldwin/Coase boundary, N1 code↔weights round trip, X10 ellipsis annealing. *Mechanism:* an agent calls a separately learning helper (a tool, code or small model). Individual helper operations move into the host's weights only when the rest of the host's behavior is unchanged by the move, measured by a Liskov-style probe (X6). *New:* fine-grained, behavior-preserving absorption of external skills into weights. *First test:* 10 helper functions on 0.5B: op-by-op absorption vs all-at-once distillation, measuring retention of host skills.

**Z6. Cohort clocks for plasticity.** Parts: NB25 adult-neurogenesis cohorts, PH23 glassy aging, SM4 weight malloc, F1-21 targeted plasticity, E13 patent terms. *Mechanism:* new capacity is allocated in birth cohorts that are plastic while young and age on a shared clock: each cohort is patent-protected for T tasks, then released or recycled by malloc. *New:* time-structured capacity allocation instead of a static free list. *First test:* plasticity scripts on 10 tasks: cohorts vs ReDo vs a fixed LoRA per task, measuring next-task gain and retention.

**Z7. Bivalent poised edits.** Parts: NB17 poised chromatin, D5 safe-word anti-update, D1 deferred commitment, SM8 undo in weights, Y3 seed log. *Mechanism:* a planned change is stored with both an activation mark and a repression mark, so it stays poised. Context resolves which one applies, and each mark can be removed independently. *New:* reversible, context-resolved edits that wait for evidence. *First test:* synthetic churn world, poised vs committed vs no edit when the label resolves late.

**Z8. Ghost conduits + dormant bridges: cheap relearning.** Parts: NB28 slime-mold ghost routes, NB07 silent synapses, PH20 stochastic resonance recall, spurious forgetting (2610.08718), E35 language revival. *Mechanism:* when a route is pruned or forgotten, a low-cost trace of its connectivity is kept, and relearning re-grows along the trace with noise-aided recall. *New:* forgetting with a savings guarantee, measured as relearning speed. *First test:* #24 harness: prune vs prune+ghost, steps to relearn the forgotten facts.

**Z9. Efference-copy memory for agents.** Parts: NB09 efference copy, NB43 niche construction, F1-24 disagreement teacher, G1 router. *Mechanism:* an agent subtracts the predicted effects of its own actions from observations and writes memory only from the surprising remainder. This keeps it from learning lessons about its own causal footprint. *New:* separates self-caused from world-caused change in continual agent memory. *First test:* G1 world with action-dependent observations: efference-filtered lessons vs raw lessons, measuring the spurious-lesson rate.

**Z10. The organism stack (12-way).** Parts: Z1, Z2, Z4, Z6, Z8, Y1, Y7, Y8, X1, X5, X9, MX1. *Claim:* write escrow, permeable scars, immune memory, cohort capacity, ghost savings, coercive wells, boundary dreaming, Lindy retirement and paged substrates form one lifecycle. Each stage is controlled by the override budget b = shift − margin. A learner with the whole stack beats the best single stage and the stacked component baselines on a 20-task stream. *First test:* only after ≥ 3 component first tests pass; then M3 world, 20 tasks.
