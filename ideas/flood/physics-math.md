# Flood: continual-learning ideas from physics and mathematics

Raw pool for the novelty reviewer. Nothing here is filtered, pre-killed or literature-checked; the brief asked for volume. Each idea gives the mechanism, why it would be new, and the cheapest first test. Where an idea sits near a ledger kill ([reviews/idea-ledger.md, PR #6](https://github.com/manojbajaj95/cl/pull/6)) or a known method, that is named in one clause so the reviewer can judge the distance. "Old task" means anything learned earlier; "agent" ideas act on memory, prompts or skill stores rather than weights.

## Dynamical systems

**1. Coercive weights (hysteresis memory).** Give a chosen subset of parameters a double-well potential, so each sits in one of two basins and an update moves it only once the accumulated gradient pushes it past a coercive threshold; smaller pushes relax back. Knowledge is stored as basin choices, like magnetic domains, and new learning flows through the soft parameters until it truly needs to flip a domain. New because CL regularizers are quadratic around one point (EWC) or hard masks; a learned coercive field per parameter gives a write threshold that depends on how hard the stream pushes, not on how important the weight was. First test: MLP on permuted MNIST with 10% of weights given a quartic double well; compare retention against EWC and a hard-frozen 10% at equal accuracy on the new task.

**2. Critical slowing down as a forgetting alarm.** Before a dynamical system tips over, it recovers more slowly from small perturbations: lag-1 autocorrelation and variance rise. Track those statistics on the model's own outputs for a fixed set of unlabeled probe inputs during fine-tuning, and slow down or checkpoint when they rise. New because forgetting detectors use old-task labels or replay loss; this is label-free and predicts the timing of a collapse rather than its size. (The Lyapunov-exponent kill was about order dependence, not tipping time.) First test: sequential tasks on a small MLP with a known abrupt old-task collapse; check whether autocorrelation of probe logits rises at least 50 steps before the collapse, against a plain "probe output drift" control.

**3. Homotopy continuation with branch choice.** Deform the training objective continuously from old to new task, L(s) = (1−s)L_A + sL_B, and follow the solution with predictor-corrector steps. At folds and branch points (detected by a Hessian eigenvalue crossing zero) choose the branch that keeps the most old-task behaviour. New because curricula mix data blindly; this treats the task switch as a bifurcation problem and makes the branch choice the explicit CL decision. First test: 2-layer net, two conflicting regression tasks; count branch points along s and compare the chosen-branch endpoint with plain fine-tuning and a linear replay curriculum at equal steps.

**4. Gap-scheduled adiabatic task switching.** By analogy with the adiabatic theorem, a slow enough change of the objective keeps the system in its "ground state". Set the speed of the old→new interpolation by the local spectral gap of the Hessian (switch fast when the gap is large, crawl when it closes). New because no CL method adapts the speed of a task transition to curvature. First test: same toy as idea 3; compare a fixed linear mix, an abrupt switch and a gap-adaptive mix at the same total steps, measuring old/new Pareto.

**5. Koopman-mode consolidation.** Fit a linear Koopman (DMD) model to the sequence of checkpoints. Slow, nearly unit-modulus modes carry consolidated knowledge; fast decaying modes carry transient fitting. Restrict updates on a new task to be orthogonal to the slow modes of the old trajectory. New because projection methods (OGD, GPM) use gradient or activation subspaces; this uses the training dynamics' own modes, which needs neither old data nor old gradients. First test: DMD on 200 checkpoints of a small MLP trained on task A, then train task B with slow-mode projection versus OGD and GPM.

**6. Lie-bracket (BCH) correction for order effects.** Sequential training on A then B differs from joint training by commutators of the two gradient flows, [∇L_A, ∇L_B], computable from Hessian-vector products. Add the Baker-Campbell-Hausdorff correction term to B's updates so the sequential result matches joint training to second order. New because order effects are treated as noise to average out; this cancels them analytically at task level (the bounded-delay kill was about step reordering inside a window, which is O(η²) per step, not across tasks). First test: two-task MLP; compare sequential, sequential + BCH, and joint, measuring the distance to joint weights and old-task loss.

**7. Contractive memory updates for agents.** Design the agent's memory-rewrite operator so that it is a contraction in some metric (for example a damped merge of the old store and the proposed edit, with damping set by measured sensitivity). By Banach's theorem, any two orderings of the same experiences then converge to the same memory. New because agent memory work measures order dependence after the fact; this makes order independence a design guarantee. Near rewrite-attractor prior art (2603.11228). First test: LLM lesson store over a 50-episode stream in two orders; measure memory embedding distance and downstream accuracy over time, damped versus plain rewrite.

**8. Shape-memory weights.** Shape-memory alloys return to a trained shape when heated. Store an old solution as the minimum of a potential that is switched on only when a global "temperature" scalar is raised; at deployment, a short heat pulse (a few steps under that potential plus the current loss) restores the old task, then the model cools. New because it separates storage (a cheap low-rank potential) from activation (an explicit recovery operation) rather than regularizing constantly. Risk: near rewinding/EWC. First test: store the potential as a low-rank quadratic around the old solution; compare recovery-after-fine-tune against EWC applied throughout, at equal new-task accuracy.

**9. Self-organized-criticality optimizer.** Accumulate updates in a per-parameter buffer that "topples" (applies and passes a share to neighbours in the computation graph) only when it crosses a threshold, like a sandpile. Most new information causes small local avalanches; only rare large evidence triggers network-wide rewrites. New because it makes the size distribution of weight changes power-law by design, which may match how much new data should disturb old structure. First test: implement toppling on top of SGD for a small MLP on a task stream; compare retention and new-task speed with SGD and with gradient accumulation at equal update count.

**10. Many-body localization by quenched learning-rate disorder.** In disordered systems, information fails to spread (no thermalization). Give each unit a fixed random learning rate drawn log-uniformly over two decades. Updates for new tasks localize in the fast units and the slow units keep old knowledge, without any task boundaries. New because multi-timescale CL (Benna-Fusi) uses designed cascades; this claims random disorder alone suffices. Risk: near the power-law forgetting card #3. First test: per-unit log-uniform LR versus uniform LR at equal mean on permuted MNIST.

**11. Spin-echo refocusing of forgetting.** If old-task damage comes from diffusive drift in directions the new task does not care about, a "π-pulse" can undo it: after t steps on task B, reflect the weights in a function-preserving symmetry (for example sign-flip pairs of hidden units in a symmetric subspace) and train t more steps; drift that dephased the old task refocuses. New because it borrows dynamical decoupling, which has no CL analogue. First test: deep linear network where forgetting is diffusive by construction; check whether the echo recovers old loss at 2t, then try a ReLU MLP.

**12. Zeno and anti-Zeno consolidation.** Frequent "measurement" (project back onto the old-task low-loss manifold every k steps) freezes old knowledge (Zeno), but in quantum systems an intermediate measurement rate speeds transitions (anti-Zeno). Sweep k: the prediction is a k at which new-task learning is faster than with no projection at all, at no retention cost. New because periodic replay or projection is treated as a pure trade-off. First test: small MLP, projection every k ∈ {1, 4, 16, 64, 256, ∞} steps, plotting new-task speed and old-task loss.

**13. Cusp-catastrophe hysteresis map.** Model forgetting as a cusp catastrophe in two controls (learning rate, replay ratio). The prediction: there is a hysteresis loop, so the replay ratio needed to recover an old task is higher than the ratio needed to keep it. Map the loop, then plan control paths that go round the cusp instead of through it. New because it predicts a qualitative asymmetry in replay schedules. First test: sweep the replay ratio up and down on a two-task MLP and look for different recovery and maintenance thresholds.

## Thermodynamics and statistical physics

**14. Crooks irreversibility meter.** Run many short fine-tuning trajectories forward (A→B) and backward (B→A) from noisy starting points and record the "work" (change in the stream loss). The Crooks fluctuation theorem relates the asymmetry of the two work distributions to a free-energy gap; the asymmetry estimates how irreversible a forgetting event is, which should predict how much relearning it saves. New because forgetting is scored as one loss gap, not as an irreversibility. First test: MLP pairs of tasks; correlate the Crooks asymmetry with measured relearning savings, against an old-loss-gap control.

**15. Fluctuation-dissipation forgetting forecast.** Near equilibrium, the response to a perturbation equals the spontaneous fluctuations. Measure the variance of the model's outputs on unlabeled probes under continued SGD noise on the old task (fluctuation) and predict how much a new-task push will move them (dissipation) without old labels. New because FDT for SGD (Yaida 2018) has not been used to forecast forgetting. First test: small MLP at its old-task stationary state; Spearman between FDT-predicted and actual per-probe drift after task B, against gradient-cosine prediction.

**16. Onsager asymmetry as a non-equilibrium flag.** Near equilibrium, cross-task effects are reciprocal: training on A changes B's loss as much as training on B changes A's (at first order, both are gradient inner products). Measure the asymmetry of the influence matrix at realistic step sizes; large asymmetry marks pairs where forgetting is non-linear and permanent. New because interference matrices are taken as symmetric similarity scores. First test: 10 small tasks, full pairwise influence matrix, check whether asymmetry predicts permanent versus recoverable forgetting.

**17. Replica-overlap fracture detector.** Train K replicas with the same data but different noise and track their overlap distribution P(q). When a new task fragments the solution space (replica symmetry breaking), P(q) turns bimodal; use that signal to grow capacity or spawn an expert. New because expansion triggers in CL use loss or novelty, not the geometry of the solution space. First test: 8 replicas of a small MLP across a task switch; check whether bimodality appears only for conflicting tasks.

**18. Carnot-cycle training schedule.** Alternate a "hot" phase (high LR, new data) and a "cold" phase (low LR, consolidation on a mix), joined by slow "isentropic" ramps, and define efficiency as new-task gain per unit of old-task loss. The claim is an efficiency ceiling set by the two temperatures, so schedules can be compared against a bound. New because LR schedules in CL are tuned, not given a thermodynamic bound. First test: sweep hot/cold LR pairs on a two-task stream and test whether efficiency follows a 1 − T_c/T_h-style curve.

**19. Hopfield dreaming (anti-Hebbian unlearning).** Hopfield, Feinstein and Palmer (1983) raised network capacity by unlearning the network's own spurious attractors. For an LM: before learning a new task, sample free generations, find self-reinforcing high-probability outputs, and take tiny negative-likelihood steps on them to free capacity. New because LLM CL never unlearns the model's own attractors as preparation for writing. First test: SmolLM-scale model, two sequential fine-tunes with and without a dreaming phase; measure old-task retention at equal new-task loss.

**20. Stochastic resonance recall.** A sub-threshold signal can become detectable with the right amount of noise. After forgetting, add Gaussian weight noise at inference over a sweep of amplitudes; the prediction is a non-monotonic rise in old-task accuracy at some amplitude, revealing memories that are present but sub-threshold. If it works, a noise "recall knob" becomes a primitive. First test: an MLP after sequential training, old-task accuracy versus noise amplitude with 20 noise samples per point (seconds on CPU).

**21. Kinetic proofreading for memory writes.** Hopfield's kinetic proofreading gets exponential accuracy by passing a molecule through several irreversible, energy-consuming checks with delays. Make each agent lesson pass k delayed, independent verification stages (each on fresh episodes) before it becomes active; error rates should fall exponentially in k while one verifier with k× budget falls only linearly. New because memory write gates are single-shot. First test: synthetic lesson proposals with 30% wrong ones; compare k-stage proofreading with a single verifier at matched total verifier calls.

**22. Parallel tempering of agent memories.** Run several agent replicas whose memory-rewrite step has different exploration temperatures, and periodically swap whole memory stores between neighbouring temperatures by a Metropolis rule on reward. Good memories migrate to the cold (exploit) replica and the hot ones keep searching. New because memory search in agents is greedy or best-of-N. First test: 4 replicas on a small text-game stream; compare the cold replica's reward with best-of-4 at equal LLM calls.

**23. Glassy aging clocks.** Glasses age: the older a configuration, the slower it relaxes. Give each parameter a clock of time since its last large change and set its learning rate to fall with that age, so long-stable weights become stiff and recently changed ones stay plastic. New because importance-based CL scores how much a weight matters, not how long it has been stable. First test: aging-clock LR versus EWC and SI on a 10-task stream.

**24. Frustration loops in the task graph.** In a spin system, a triangle whose bond signs multiply to negative is frustrated: no assignment satisfies all three bonds. Compute the sign of gradient cosines between tasks and find frustrated cycles; tasks on such cycles cannot share one solution and should be routed to separate modules. New because interference is studied pairwise, while frustration is a property of cycles. First test: 10 small tasks, list frustrated triangles, test whether their triples fail joint training more often than unfrustrated triples with the same pairwise cosines.

**25. Percolation threshold for task subnetworks.** Treat a task's important weights (from a pruning mask) as a graph; forgetting may be a percolation transition, with accuracy collapsing once edits disconnect the giant component at a threshold predictable from the degree distribution (Molloy-Reed). New because it predicts collapse from graph structure rather than from loss. First test: random and fine-tune-driven edits on a pruned MLP; does accuracy collapse at the predicted p_c, against a constant-threshold baseline?

## Topology and geometry

**26. Winding-number bits.** Store a bit as a topological invariant, such as the winding number of a small head's 2D output over a circular family of inputs. Small continuous updates cannot change a winding number; only an update that closes the "gap" (output passing through zero) can. Primitive: topologically protected memory. Risk: like Noether memory, large steps may jump over the barrier, so it must beat a scalar-encoded bit at equal norm under SGD with momentum. First test: encode 16 such bits, fine-tune on unrelated data, measure flip rates against scalar bits.

**27. Holonomy writes.** Move the weights around a closed loop in a function-preserving symmetry (for example rotating Q and K by the same orthogonal R). The function is unchanged, but a geometric (Berry-like) phase builds up in the symmetric subspace and can encode a key. New because it writes information where the loss cannot see it. Risk: function-preserving rebalancing killed Noether memory, so it must survive realistic fine-tuning. First test: encode an R in one attention layer of a tiny transformer, fine-tune, and measure how much of R survives.

**28. Sublevel-set topology clamp.** Forgetting happens when the current weights leave the old task's low-loss sublevel set component. Probe the straight-line path of each proposed update with a few old-loss evaluations (or a proxy on probes) and reject or shorten updates that cross a barrier, i.e. that would change the persistent-homology class of the weights. New because mode connectivity in CL (Mirzadeh 2020) has been a diagnostic, not a per-update constraint. First test: 5-task MLP stream; clamp versus plain SGD at equal new-task accuracy.

**29. Ricci-curvature interference forecast.** Compute Ollivier-Ricci curvature on the k-NN graph of class representations. Negatively curved edges are bottlenecks; the prediction is that classes joined by negatively curved edges are forgotten first when new classes arrive. A discrete Ricci flow on representations could then even out curvature to make room for new classes without moving class centres. New because curvature has been used for GNN over-squashing, not CL. First test: Split CIFAR-10 small CNN; Spearman between edge curvature and per-class forgetting against a centroid-distance control.

**30. Persistent-homology curiosity for agents.** Embed every skill or solved task an agent has; holes (persistent H1 loops) in that cloud are skill gaps surrounded by competence. Generate practice tasks at hole centres. New because curiosity rewards novelty or learning progress, not the topology of the competence set. First test: on a procedurally generated task family, compare TDA-targeted curricula against novelty-based and random curricula at equal episodes.

**31. Sheaf cohomology of lesson stores.** Treat contexts as open sets and lessons as local sections; a lesson store is consistent when local sections glue. Nonzero H¹ of the sheaf Laplacian flags lessons that agree pairwise on overlaps but cannot be made globally consistent, which predicts failures where several lessons apply at once. New because memory conflict detection checks pairs. First test: a synthetic store of 50 rules over overlapping contexts; check whether H¹ obstructions predict triple-context failures beyond pairwise NLI contradiction.

**32. Hyperbolic skill space.** Place skills in a Poincaré ball, where volume grows exponentially with radius, so new skills can be added near the boundary without crowding old ones; the hierarchy depth sets capacity. New for skill libraries and adapter routing. Risk: hyperbolic embeddings for hierarchy are known. First test: route LoRA adapters by hyperbolic versus Euclidean keys as the library grows from 10 to 200 skills; measure routing accuracy.

**33. Ultrametric (p-adic) memory.** Organize parameters on a tree with an ultrametric distance, as in spin-glass state spaces; an update at depth d can only change its subtree, so new knowledge for a subdomain never touches unrelated branches, and "close" tasks share deep ancestors. New as a hard locality rule derived from ultrametricity rather than a learned router. First test: tree-structured adapters on a hierarchical task stream (CIFAR-100 superclasses) versus flat adapters.

**34. Parallel-transported Fisher.** EWC stores the old Fisher at the old point, but it goes stale as the weights move. Transport it along the training path with the Levi-Civita (or α-) connection of the Fisher metric, approximated in a low-rank basis. New because online EWC re-estimates or decays the Fisher; transport updates it geometrically without old data. First test: permuted MNIST, EWC with frozen F, with transported F, and with an oracle recomputed F.

## Information geometry and information theory

**35. α-projection consolidation.** Distillation-based CL (LwF) uses KL, which fixes one way of combining old and new predictive distributions. Replace it with an α-divergence projection: e-projections keep sharp modes, m-projections cover them. Choose α per input region from curvature, so the model keeps sharp old modes where they matter. New because α-geometry has not been used as the consolidation operator. First test: LwF with α ∈ {−1, 0, 1} and adaptive α on class-incremental CIFAR-10.

**36. Dual-coordinate accumulation.** In an exponential family, sufficient statistics add, so sequential and joint learning are identical in expectation (dual) coordinates. Push as much of the network as possible into exponential-family form (for example, moment-matched last layers and Gaussian feature heads) and learn in dual coordinates, so those parts never forget. Risk: streaming LDA does this for the last layer; the new part is pushing it deeper. First test: two-layer version on split tasks against streaming LDA and fine-tuning.

**37. Reverse water-filling of weight bits.** Treat weight storage as a rate-distortion problem: quantize the weights in the joint Fisher eigenbasis of all past tasks, and allocate a fixed bit budget across directions by reverse water-filling on the Fisher spectrum. New knowledge goes into the directions that are cheapest in distortion. New because CL never treats capacity as a bit budget. First test: small MLP, fixed total bits, water-filled versus uniform quantization of the updates.

**38. Kelly-sized updates.** Treat each update as a bet on how the future stream will look. Choose the step size that maximizes the expected log growth of performance rather than the expected performance; in non-ergodic streams, this avoids large steps that win on average but occasionally wipe out old skills. New because step sizes in CL are tuned for averages. First test: a nonstationary stream with rare reversals; compare Kelly-sized steps with fixed and Adam step sizes on the worst-case retention.

**39. Random-matrix spike preservation.** By random matrix theory, learned structure shows up as singular values above the Marchenko-Pastur bulk. Find those spikes in each weight matrix after each task and constrain later updates not to rotate or shrink them, leaving the bulk free. Data-free, unlike GPM. First test: track spikes across a 5-task stream; spike-preserving updates versus GPM and plain SGD.

## Algebra and category theory

**40. Lie-algebra closure for free generalization.** If a model learns symmetry generators X and Y continually (as explicit Lie-algebra elements), it gets [X, Y] for free, so learning two rotations yields the third. Make "add generator, close the algebra" the CL step. New as a CL primitive that turns two learned skills into a third by algebra. First test: 3D rotation data; learn x- and y-rotations as generators, check z-rotation generalization with and without bracket closure.

**41. Functorial memory transfer across model upgrades.** Treat skills as morphisms that compose. To carry skills from an old model to a new one, learn a functor on generator skills only and check that composites transfer for free. New because adapter transfer is done skill by skill. First test: compositional synthetic tasks with LoRA adapters on two small models; transfer generators through a learned map and test composites.

**42. Lens laws for agent memory edits.** Model each memory view and its update as a lens (get/put) and require the PutGet and GetPut laws. Violations flag edits that are inconsistent with the store. New as a formal consistency check for agent memory. First test: a structured agent memory with views; check whether the law-violation rate predicts later degradation.

**43. Chinese-remainder task storage.** In integer-weight networks with modular arithmetic layers, store task k in the weights' residues modulo prime p_k; an update for task k changes only the residue mod p_k, so other tasks are untouched by construction, and the CRT recombines them. New and crazy: arithmetic, not geometric, isolation. First test: a small modular-arithmetic network with 3 tasks on 3 primes; measure interference against a dense integer network.

**44. Tropical region-preserving updates.** A ReLU network is a tropical rational function; each input sits in a linear region. Constrain new-task updates to keep the activation pattern (linear region) of old-task inputs (or probes) unchanged, adding new regions only where old inputs are absent. New because it constrains the combinatorial structure, not the outputs. First test: measure the fraction of old inputs that change region per update, then constrain it and compare with OGD.

**45. Tensor-network task sectors.** Factor each weight matrix as a tensor train and give each task its own block of bond indices, so tasks are separated at the bonds and can be cut and swapped; entanglement entropy across a bond measures how much tasks share. New as a CL parameterization from tensor networks. First test: TT layers in an MLP with per-task bond sectors versus LoRA per task at equal parameters.

## Other physics

**46. Renormalization-group consolidation.** Periodically coarse-grain the network by merging correlated units (block-spin RG). Directions that survive the flow (relevant couplings) store consolidated knowledge at the coarse scale; new tasks learn at the fine scale, and consolidation is a coarse-graining step. New as a consolidation operator. First test: a 2-scale MLP where coarse weights change only through RG steps; compare retention against a fast/slow-weights baseline.

**47. Reversible optimizer and selective rewind.** With an exactly reversible optimizer (bit-exact leapfrog, as in Maclaurin et al. 2015), integrate backward with only one task's gradient sign flipped to remove that task's contribution while keeping others. Risk: a full rewind is exact by construction; the new part is partial, per-task reversal. First test: small MLP on A then B then C; remove B by partial reversal, compare with retraining on A and C.

**48. Kuramoto phase multiplexing.** Give each task a phase; weights are modulated by cos(φ − θ_task), and the network infers the phase by synchronizing to the input (Kuramoto coupling) instead of being given a task ID. New against superposition with fixed keys (Cheung et al. 2019) because the keys self-organize. First test: superposition of 5 tasks with learned phase locking versus fixed binary keys.

**49. Soliton edits.** Treat depth as time and the residual stream as a wave; write an edit as a localized, stable profile across layers (a soliton of a cubic residual update) that passes through other edits without interference. Crazy, borrows elastic soliton collisions. First test: a deep residual toy with a cubic nonlinearity; compare interference between two soliton-shaped edits and two generic edits at equal norm.

**50. Wasserstein-barycenter replay.** Keep a small set of particles whose empirical measure is the W2 barycenter of all past tasks' feature distributions, updated with entropic OT, and replay the particles. Risk: near coresets and dataset distillation; the new part is the barycenter objective across tasks. First test: compare with reservoir sampling and herding at equal buffer size on split CIFAR.

**51. Fractional-order optimizer memory.** Replace momentum with a Caputo fractional derivative, i.e. a power-law kernel over past gradients, so the optimizer keeps a long memory of old-task gradient directions. Risk: near the power-law forgetting card #3, but this acts on optimizer state, not weights. First test: fractional SGD versus momentum and Adam on a task stream.

**52. Free-energy budgeted fine-tuning (Jarzynski).** Use the Jarzynski equality on many short fine-tuning trajectories to estimate a free-energy gap between old and new task posteriors, and budget updates so that the dissipated work stays below a threshold. New as a budget for how far fine-tuning may move the posterior. First test: correlate the Jarzynski estimate with old-task loss increase on a small MLP across learning rates.
