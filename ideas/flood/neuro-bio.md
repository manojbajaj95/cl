# Neuro-biology idea flood

Unranked mechanisms for continual learning in models and agents. The biology is inspiration, not an implementation target. Each novelty bet names the proposed primitive, not a claim of priority; the toy tests are sketches, not results.

## Where an update lands

**NB01 · Write escrow (synaptic tagging and capture).** Leave short-lived, sparse eligibility tags on the paths used during an episode; when feedback arrives, synthesize an update payload and let only matching tags bind it, without rereading the episode. **Novelty bet:** write addresses can outlive the activations that created them and be bound to a payload not yet known at prediction time. **First test:** interleave two delayed-label XOR streams; measure credit misassignment and retention versus a same-byte gradient trace and delayed replay.

**NB02 · Transferable write territory (heterosynaptic competition).** Give overlapping circuits claims on shared parameter directions; an update can buy a direction from a neighbor only by moving the neighbor's contribution to a spare direction and restoring its output on a few boundary probes. **Novelty bet:** a learner trades write rights together with the obligation to relocate what was there, rather than assigning fixed masks or resisting motion. **First test:** run three overlapping linear tasks through a narrow shared bottleneck and compare the retention–adaptation curve to equal-rank gradient projection and fixed partitioning.

**NB03 · Compartment write veto (dendritic plateaus).** For a misprediction, briefly replace each candidate branch activation with its locally predicted alternative and allow a write behind the first branch whose replacement repairs the output; leave other equally active paths untouched. **Novelty bet:** a successful activation intervention grants permission to edit a compartment, independent of how much ordinary credit flowed through it. **First test:** in a two-branch MLP with correlated shortcuts, switch one generating factor and compare misplaced writes against gradient-norm branch selection with the same intervention budget.

**NB04 · Permeable scars (perineuronal nets).** After a skill stabilizes, deposit a sparse permeability stencil that blocks only writes moving its hidden states across observed decision boundaries; compatible writes can still change those same parameters. **Novelty bet:** freeze a set of representation transitions, not weights or entire subspaces; future learners can grow through a scar along permitted directions. **First test:** alternate rotations that do and do not change a standing XOR rule; compare fixed-byte stencils with parameter freezing and projected updates at matched initial retention.

**NB05 · Delay-addressed skills (adaptive myelination).** Keep a recurrent graph's edge weights fixed and learn integer propagation delays so the same edges implement different circuits depending on which inputs arrive together; write a new skill by moving a route in time. **Novelty bet:** latency becomes a writable memory address, distinct from adding an expert or modifying connection strengths. **First test:** fit two conflicting three-symbol transductions in a tiny recurrent graph; compare a delay register with equal-bit edge switches and equal-budget learned routing.

**NB06 · Geometry of future effort (astrocyte microdomains).** Maintain a slow, directed conductance graph over update blocks; each attempted weight write sends a fixed plasticity budget through that graph to nearby blocks that can substitute for saturated ones. **Novelty bet:** the model learns a transport layer for future writes that does not participate in inference, so changing a block's future editability need not change its present behavior. **First test:** train a redundant linear dictionary on a stream with shifting support and compare adaptation after saturation to a full-matrix preconditioner and static plasticity routing at matched state cost.

**NB07 · Dormant bridge synapses (silent synapses).** When two useful circuits coactivate, reserve a sparse set of zero-output edges between them; later feedback can open one bridge without relearning the endpoint circuits. **Novelty bet:** past experience can allocate candidate *connectivity* for a future capability without storing a working version of that capability. **First test:** train independent shape and motion skills, introduce one conjunction, and compare few-shot transfer to random dormant edges and equal-budget sparse regrowth; score the untouched skills too.

**NB08 · Circuit scavenging (microglial engulfment).** Mark an edge as reclaimable only when a short suppression test leaves the local output intact *and* downstream users have adopted a substitute; recycle its slot into a nearby circuit. **Novelty bet:** forgetting can be a two-sided transfer of responsibility, not pruning inferred from weight size or raw usage. **First test:** stream tasks through a fixed-size sparse DAG with delayed downstream reuse; compare slot reclamation to magnitude pruning and activation-only salience at matched probe cost.

## What counts as a teaching signal

**NB09 · Efference-copy subtraction.** For each agent action, predict the observation shift caused by the agent itself and give persistent memory only the residual plus its uncertainty; keep the unmodified observation available for immediate control. **Novelty bet:** install an explicit subtraction operator on *writes*, making ordinary perception and what the agent learns from that perception different interfaces. **First test:** use a gridworld where the agent changes the lighting and the world independently changes the reward map; compare wrong persistent revisions to raw prediction-error gating and an action-conditioned world model.

**NB10 · Phase-locked credit packets (olivocerebellar teaching).** Give recurring latent computations short phase codes; a delayed error packet selects the code of the implicated computation rather than all activations within its lookback window. **Novelty bet:** timestamps are a multiplexed credit bus, not a recency weight, so overlapping computations can leave different teaching addresses in the same state. **First test:** interleave two counting processes with identical visible states and variable delays; compare cross-process credit leakage with equal-size eligibility traces and timestamp-keyed buffers.

**NB11 · Engram overlap graft.** Jointly reactivate an old and a new skill, find the smallest shared path whose transplant preserves a common behavior, and swap only that path into the old circuit; never reopen the remainder of the memory. **Novelty bet:** reconsolidation becomes a directed graft with a testable interface, not a global learning-rate increase on retrieval. **First test:** give two small sequence transducers a shared suffix that changes and distinct prefixes that must not; compare shared-rule transfer and collateral error to matched joint fine-tuning and module reuse.

**NB12 · Opponent write ledgers (mushroom-body valence channels).** Store evidence for adopting a policy and evidence for avoiding it in independently updated channels; action choice combines them, but cancellation never consumes either channel, so changing outcome priorities doesn't require reconstructing past experience. **Novelty bet:** an apparently neutral action can retain two independently reusable teaching histories rather than a single net value. **First test:** switch reward–cost tradeoffs in a bandit with delayed outcomes; compare revaluation and retention to equal-byte scalar critics and a standard two-head successor-feature control.

**NB13 · Coordinate-loop obligations (grid-cell remapping).** Store the translation between representations when contexts share landmarks, and require translations learned on different visits to compose consistently around a loop; repair the inconsistent transition before rewriting stored skills. **Novelty bet:** the durable object is a system of compatible reference-frame transitions, not a context vector that selects a whole skill. **First test:** stream rotated and relabeled mazes with only pairwise landmark overlap; compare transfer to an unseen rotation and loop inconsistency against equal-size context embeddings and pairwise alignment without closure.

**NB14 · Exploratory write noise (songbird vocal learning).** Give each repeated subroutine a paired positive and negative parameter dither; keep dithers whose effects cancel on practiced contexts but separate reward on a new one, and use the winning dither as the write direction. **Novelty bet:** prior skills determine the *shape of exploration* before gradients exist, rather than serving as replay targets after exploration. **First test:** train overlapping motor patterns in a tiny sequence controller, then adapt from scalar reward; compare to equal-rollout isotropic search and gradient null-space exploration.

**NB15 · Answer–predict wiring (reciprocal sensory pathways).** Store a skill as a pair of forward and backward maps and give each map an independent writer; when they disagree, route the write to whichever side fails an independently available intervention, not to both sides based on reconstruction error. **Novelty bet:** cycle inconsistency opens a targeted repair channel rather than adding a symmetric regularizer or flagging a whole inverse tool model as stale. **First test:** independently permute inputs and outputs in a toy transducer with sparse one-sided anchors; compare repair attribution and invariant accuracy to symmetric cycle training at equal data cost.

**NB16 · Cross-modal credit transplant (sensory substitution).** When two sensor streams overlap, learn a transport map for *gradients* between the sensory pathways; later feedback received through one sensor can edit representations in the absent sensor without synthesizing its missing observations. **Novelty bet:** transfer a teaching operation across modalities, not examples, predictions, or complete weights. **First test:** alternate paired and unpaired views of a latent four-state system and compare absent-view learning against output distillation and tied latents, charging every paired example and stored parameter.

## Grow, split and rebuild

**NB17 · Bivalent edit marks (poised chromatin).** Put independent activation and repression marks on a dormant change: either one can be present alone, but together they keep the change poised without letting it execute until later evidence resolves one mark. **Novelty bet:** this defines a writable third state with path-dependent resolution, not uncertainty encoded as a small update. **First test:** use delayed evidence on a stream of agent rule reversals; compare premature changes and recovery latency to a same-byte signed score with hysteresis and to separate positive/negative evidence counters.

**NB18 · Spliceable skill programs (alternative splicing).** Train patch fragments with typed entry and exit states, and let new episodes edit the grammar that connects fragment exits to entries while keeping underlying fragments fixed. **Novelty bet:** the writable object is the structure of a patch, including what can be skipped or reordered, rather than which complete adapter to load. **First test:** introduce new orders of the same string-transform primitives to a tiny sequence model; compare fixed-fragment splicing to equal-size expert routing and linear adapter composition on held-out orders.

**NB19 · Homologous patch crossover.** Give independently trained models stable boundary coordinates and let them exchange contiguous patches at homologous boundaries while swapping only the local interface transforms needed to align them. **Novelty bet:** write by inheriting an intact operation from another learner without averaging it into the recipient. **First test:** specialize two tiny modular networks on different combinations of arithmetic operators; compare on unseen combinations to equal-rank aligned weight averaging and whole-module swaps.

**NB20 · Reciprocal degeneration (duplicate-gene subfunctionalization).** Duplicate a shared unit without changing output, then force the two copies to give up complementary parts of their original input support as later tasks arrive; jointly they must cover the old skill. **Novelty bet:** manufacture independently editable parts by complementary losses, not by adding a new task expert on top of an untouched old one. **First test:** start two related tasks sharing a capacity-limited feature, then make only one need a conflicting revision; compare interference and eventual parameter count to equal-size ordinary split-and-grow.

**NB21 · Boundary-conditioned regrowth (planarian regeneration).** Store sparse interface conditions and a reusable growth program instead of saving the internal weights of every old module; if a module is overwritten or removed, regrow a compatible replacement against those conditions. **Novelty bet:** retained memory is a recipe for rebuilding a class of interchangeable circuits, not parity data for recovering the original weights. **First test:** delete a hidden block from a modular Boolean network after several task changes; compare held-out composition after regrowth to same-byte low-rank repair, a saved subnetwork, and generic generator initialization.

**NB22 · Moving plasticity domains (reaction–diffusion patterning).** Let successful edits emit a short-range write attractor and a slower, longer-range inhibitor across a layer's connectivity graph; later writes move the boundaries instead of receiving a task-specific slot. **Novelty bet:** the location and spacing of plastic zones can emerge from how writes interact, with no preallocated experts or task labels. **First test:** stream overlapping input families through a small graph network and test recovery after drift against equal-active-size learned masks and nearest-slot allocation, including shuffled graph topology.

**NB23 · Functional cell extrusion (epithelial turnover).** Before retiring a unit, negotiate transfer of its incoming and outgoing roles with immediate neighbors using local input–output perturbations, then remove the source and open a new slot. **Novelty bet:** make circuit retirement a composable, local handoff rather than global compression or post-deletion repair; a skill can survive multiple generations of replaceable units. **First test:** force periodic unit turnover in an MLP during rotating regression and compare retention to matched prune-and-distill and random replacement under equal retraining compute.

**NB24 · Axes before modules (morphogen gradients).** Learn a bounded set of continuous developmental coordinates across a model; install a new operation by depositing a field in those coordinates that changes connection rules wherever the field is expressed, including newly grown units. **Novelty bet:** a write can target a *location rule* that outlives the present parameter inventory. **First test:** learn a modification on small message-passing networks, grow them, and compare its generalization to unseen nodes with a coordinate-conditioned adapter and a node-wise patch at matched sizes.

## What survives a regime change

**NB25 · Cohort clocks (adult neurogenesis).** Recruit units into short-lived birth cohorts with a shared position in a learned temporal calendar; later recurrence can reactivate a relation between cohorts without consulting tasks named at training time. **Novelty bet:** the learned address of an event is its relation to other allocation windows, not an absolute timestamp or a stored task ID. **First test:** vary speed and skip phases in recurring symbol streams; compare recurrence transfer to equal-state time embeddings, rolling masks, and an age-blind cohort allocator.

**NB26 · Heritable locks with reset (plant vernalization).** Let accumulated evidence switch on a durable lock that persists across resets of an agent's fast state, while an explicit generation boundary resets locks without erasing the rules that can rebuild them. **Novelty bet:** persistence has a resettable inheritance contract rather than a learned decay rate; candidate policy and permission to express it have distinct lifetimes. **First test:** train on variable-length seasonal bandits with a recurring but imperfect cue; compare premature switching and cross-generation carryover to a same-state hysteretic gate and regime filter.

**NB27 · State lotteries (microbial bet hedging).** Store multiple viable parameter states at fixed capacity, but learn the transition law among them to minimize repeated regret when regime changes are unobservable, rather than predicting which state is right at each episode. **Novelty bet:** write a persistent *distribution over trajectories of learners*, not just mixture weights over their current predictions. **First test:** use a bandit with aliased brief reversals and asymmetric switching costs; compare cumulative regret to matched posterior-sampling experts and an ensemble with fixed switch rates.

**NB28 · Ghost conduits (slime-mold transport).** A disused compute route loses throughput but leaves a low-cost trace of how its edges connected; recurring error can expand the entire route in a single operation even if no individual edge has enough local evidence. **Novelty bet:** retain the *connectivity of a dormant path* as an object that can reclaim capacity, without storing the previous patch or a task checkpoint. **First test:** build a bottleneck router that alternates shortcuts and long detours; compare reacquisition against magnitude-based regrowth and an equal-byte cache of retired edges.

**NB29 · Learning-tensor molt (arthropod molts).** Periodically replace a model's coordinate system with one calibrated to its recent environment, while transferring a few old skills as typed constraints on the inference map rather than transferring their parameter values. **Novelty bet:** the learner can discard a whole obsolete representation basis without declaring a fresh model or carrying over all old features. **First test:** rotate the dominant factors in a synthetic stream with conserved logical rules; compare relearning cost to progressive fine-tuning, whitening, and equal-resource periodic distillation.

**NB30 · Repair by autotomy.** When a subgraph accumulates irreconcilable policies, cut it out and replace it with a small interface that carries forward only the commitments the rest of the system actually uses; allow the detached branch to remain available as offline evidence, not an active expert. **Novelty bet:** structural forgetting targets a dependency cut with an explicit residual contract rather than deleting items or restoring an old version. **First test:** revise tool schemas in a symbolic workflow agent; measure collateral breakage and recovery time versus equal-budget dependency invalidation and subtree refresh.

**NB31 · Cofactor escrow (metabolic salvage).** An aging skill can be rebuilt from reusable parts if the learner has retained the scarce cofactor that connects them, such as an alignment map; the memory allocator can discard skill weights and preserve the cofactor instead. **Novelty bet:** retention can allocate bytes to *reconstructibility* rather than current utility or compressibility of individual skills. **First test:** in a stream of linear tasks sharing low-rank factors, charge the full dictionary and compare bytes versus recovery samples to per-task sketches and a factor bank with usage-based eviction.

**NB32 · Counterfactual exposure dependencies (epitope masking).** When a familiar circuit already explains part of an episode, mask only the consequences it can still predict under interventions and write the exposed residual into a new circuit, with a dependency on the old explanation. **Novelty bet:** a later edit of the old circuit invalidates the residuals it defined, rather than letting two independently valid-looking updates silently overlap. **First test:** change shared and private rules in a toy causal world; compare joint revision and rare-skill retention to residual adapters without dependency tracking and duplicate-sample downweighting.

## Memories that act on memories

**NB33 · Anti-memory graph (immune idiotypic networks).** Store small detectors that recognize *which memory fired* and can inhibit that memory on an incompatible branch of reasoning, without multiplying exceptions in the original query space. **Novelty bet:** memories become addressable inputs to other memories; an acquired exception can target a behavior-producing memory across all its paraphrases. **First test:** stream nested exceptions into a symbolic rules agent and compare byte-scaled error on unseen aliases to equal-size priority rules and retrieval-score gating.

**NB34 · Tolerance nursery (central immune tolerance).** Generate a protected set of synthetic states by composing the agent's own trusted subskills; before admitting a newly learned interrupt, test for triggers on those internal states and narrow the interrupt's detector, not its action. **Novelty bet:** the learner maintains a moving specification of *self-generated computation* against which future memory triggers are shaped. **First test:** build a toy compositional workflow with gradually increasing valid branches; compare mistaken interrupts versus fixed negative probes and ordinary replay with equal generated-state budgets.

**NB35 · Recombining counterexample detectors (combinatorial recognition).** Keep a small library of predicate fragments; after an agent failure, select and bind a new failure detector from multiple fragments using positive and counterfactual near-miss traces, leaving the policy itself unchanged until the detector later fires. **Novelty bet:** the unit of continual learning is an installable detector assembled from fragments and decoupled from repair, not a written lesson with a precondition. **First test:** introduce compositional error families to a symbolic agent; compare sample efficiency and false alarms to a growing decision tree and whole-pattern retrieval at equal storage.

**NB36 · Spatial quorum for writes (quorum sensing).** Let agent workers broadcast compact update families within a task graph; crossing an agreement threshold at one boundary changes which neighboring workers are permitted to propose follow-on edits, not whether the original update is globally adopted. **Novelty bet:** local agreement schedules the expansion of write access, not the ranking or publication of candidate memories. **First test:** simulate workers facing a spatially advancing schema change; compare diffusion speed and false propagation to an equal-message global vote and fixed neighborhood propagation.

**NB37 · Memory alarm cascade (complement amplification).** Let a detected contradiction propagate only through the specific read-dependency edges that consumed the disputed claim; each hop reversibly disables that path until a local check either clears or forwards the alarm. **Novelty bet:** memory can enter a temporary, contagious suspect state without rewriting content or indiscriminately invalidating downstream artifacts. **First test:** inject false and real revisions into a synthetic workflow DAG; compare stale actions versus blocked valid actions against eager invalidation and TTL expiry, matching available checks.

**NB38 · Parent-of-origin writes (genomic imprinting).** Give composed skills separate read and write provenance: a borrowed patch may execute in the recipient, but later correction attaches to whichever ancestor defined the affected interface, not whichever agent last invoked it. **Novelty bet:** the version ancestry of a computation can determine edit authority independently of where that computation runs. **First test:** merge two toy toolkits with overlapping names and shared descendants, revise one interface, and compare unintended behavior changes to namespacing and last-writer-wins under held-out compositions.

## Transfer without merging everything

**NB39 · Compatibility grafts (plant grafting).** Train a bridge at the seam between two learners to transport activations forward and write signals backward while the grafted module and its host continue adapting locally. **Novelty bet:** the exchanged object is a live bidirectional training interface rather than a static adapter or exported model. **First test:** connect two small encoders with independently rotating domains; compare old skills and novel cross-model compositions to equal-size one-way adapters and periodic end-to-end joint fine-tuning.

**NB40 · Endosymbiotic handoff.** Let an agent call a separately learning helper; move individual helper operations into its host only when the rest of the helper can still run against aliases to the moved operations and use them during its own learning. **Novelty bet:** memory ownership can migrate in pieces without ending the donor's learning loop or copying its full state. **First test:** split a changing symbolic toolkit between two agents, migrate one subroutine, and compare cross-agent adaptation and total state against full distillation and ordinary RPC with a static cache.

**NB41 · Shared cytoplasm, separate nuclei (fungal heterokaryons).** Run multiple parameter lineages against a common short-lived activation substrate, letting them secrete intermediate work into it while routing gradient writes back only to the lineage that produced the work. **Novelty bet:** learners can share computations and inherit their consequences without pooling persistent weights or broadcasting raw examples. **First test:** put three small models on partially overlapping subproblems and compare sample efficiency and lineage interference to same-compute ensembles, a shared encoder, and activation sharing with unrestricted credit.

**NB42 · Pose-bearing updates (honeybee waggle dance).** Represent a successful policy change relative to the discovering agent's landmarks and action coordinates; transmit the patch plus its frame so another agent can re-express the same edit in its own policy. **Novelty bet:** a learned update is a transportable coordinate object, not a textual account of successful behavior or a copied weight delta. **First test:** let tabular navigation agents with privately rotated action labels share edits once; compare zero-shot reuse on unseen orientations to landmark-conditioned demonstrations and action-remapped policy copying at matched bandwidth.

**NB43 · Function-altering niche construction (ecosystem engineering).** Let a learning agent spend part of its budget restructuring the observation interface available to its later self: add durable landmarks that make previously confusable regimes distinguishable instead of adding memory slots for each regime. **Novelty bet:** a continual write can change the future addressability of experience outside the model, rather than retrain a detector or rewrite a past observation. **First test:** give a toy agent two visually aliased routes and a budget of reversible markers; compare future credit assignment with an equal-bit internal memory and a fixed-landmark control, charging marking actions.

**NB44 · Inherited error channels (cultural song transmission).** Transmit selected errors produced while learning a skill, together with the narrow correction signal that repaired them; descendants use those coupled events to tune how they update, not to imitate the final demonstrations. **Novelty bet:** teach the next learner a correction operator by passing on failure–repair structure rather than iterating ordinary lesson transmission. **First test:** run three generations of tiny sequence learners on related tasks; compare new-error repair and persistent bad habits to same-token final demonstrations and standard meta-learning on the same training tasks.
