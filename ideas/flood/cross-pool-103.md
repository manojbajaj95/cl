# Cross-pool merges, round 103

Focal source: `tree/learner-world-coevolution-7.md` (PR #370, L7W#). PR #369 changes only experiment results. Older sources: `tree/learner-world-coevolution-6.md` (PR #368, L6W#; focal in round 102), learner–world co-evolution IV (PR #366, L4W#), III (PR #365, L3W#), II (PR #364, L2W#), and root (PR #363, LW#), learning from other models (PR #358, LM#), deployment feedback 5 (PR #357, D5-#), deployment feedback 3 (PR #354, D3-#), cultural evolution IV (PR #351, CE4-#), and relearnability as memory (PR #336, CR#). Raw proposals; no live safeguards are withdrawn for a drill.

**WMX1. Place a skill by the time it takes to recover, not just by its storage cost.** Parts: L7W01 retention tiers, L7W09 adaptive placement, L7W13 shared wake dictionary, L7W14 recovery deadlines, L6W13 joint wake constraints, D5-26 bounded response sketch. *Mechanism:* Keep urgent skills active or backed by a checked fast wake route; allow slower reconstruction only when the obligation permits it. Compress wake traces only if the residual error and joint updates preserve the protected responses. Test relocation from current state rather than relying on an old placement label. *New:* A storage policy can price a deadline and update interference, not just bytes per skill. *First test:* Fit a small synthetic learner with overlapping wake directions and unequal deadlines. Compare fixed tiers, equal-byte replay and deadline-conditioned placement.

**WMX2. Refresh shared safeguards without making drills the only thing they know.** Parts: L7W02 refresh scheduling, L7W10 diverse drill distribution, L7W11 shared dependency counts, L7W16 transparent delegation, L3W10 harmless heartbeat, CE4-13 successor opportunity. *Mechanism:* Refresh using authorized varied exercises and genuine authorized handoffs, never missed live prevention. Record which consumers still rely on a guard and whether it handles new cases, not just rehearsed ones. Do not reduce shared refresh until the remaining consumers have checked alternatives. *New:* External retention can be maintained as a joint duty without shifting the cost or losing competence on rare cases. *First test:* Use mock reviewer queues with learning, fatigue and two consumers; test narrow repetition against diverse and dependency-aware refreshing at equal review time.

**WMX3. Update a wake trace only when the external rule has actually changed.** Parts: L7W04 reference versus rule payload, L7W05 version coherence, L7W06 safe retirement, L7W12 environment inventory, L7W25 independent invariant checks, L2W05 causal extinction, CR29 versioned relearning. *Mechanism:* Bind each external rule reference to its scope, authority and a small independent behavioral witness. On change, distinguish an approved revision, a missed response and an unsupported version. Rebuild the trace only after verifying the new contract, and require separate evidence of retirement before deleting an obligation. *New:* A changing external store can teach new rules without automatically overwriting the old meaning from an unverified response. *First test:* In a finite workflow cross a legitimate version change, intermittent unavailability and a buggy mock guard response. Compare blind sync, immutable references and scoped verification.

**WMX4. Treat fallback activation as a joint load test, not a successful singleton wake.** Parts: L7W03 demand activation, L7W08 independent redundancy, L7W18 checked delegation failover, L7W19 timeout signal, L7W21 early activation, L7W22 correlated outage triage, L4W22 common reviewers, D3-13 compatible histories. *Mechanism:* Test which guard outages are independent and which affect the same queue or infrastructure. Verify the actual native wake update against simultaneous deadlines and available capacity. When response state is ambiguous or capacity is exhausted, pause the affected work rather than assuming a timeout proves the guard is gone or the wake is ready. *New:* Several individually viable recovery paths become a useful portfolio only when independently valid under shared load. *First test:* Simulate a common outage and equal-size independent outages with hidden response delays. Compare duplicate guards, singleton wake tests and joint scheduling against an exact small oracle.

**WMX5. Transfer a guard contract to a new model without inheriting untested assumptions.** Parts: L7W07 compile a rule into an authorized guard, L7W20 checked re-offload, L7W24 model migration, L4W21 escrowed release, LW32 world lineage, LM26 capability handshake. *Mechanism:* Compile only a verified, scoped invariant into an authorized external checker. Require both the checker and the new model's fallback to pass an independent end-to-end handoff test. After an outage, retain the internal repair until restored external coverage meets the original obligation under the declared load. *New:* External rules could reduce rebuild work across architectures without making migration or re-offload automatically safe. *First test:* Swap two synthetic recipient architectures, then vary rule compatibility and guard stability. Compare full replay, direct reference reuse and a staged contract check.

**WMX6. Count outside work when comparing world memory with replay.** Parts: L7W15 matched-byte phase audit, L7W17 harmless cap versus delegation control, L7W23 full break-even accounting, L7W26 synthetic benchmark, L6W25 external retention, L6W19 wake coupling. *Mechanism:* Charge guard maintenance, queue load, updates, training exposure and failure costs alongside model memory. Treat a competence cap only as a synthetic control on harmless formatting tasks, and compare it to transparent delegation with equal coverage. Report which trade-offs persist when the guard's ongoing work is not free. *New:* The test can separate a genuine retention advantage from moving memory and compute into an uncounted external service. *First test:* Sweep task count, rule size, guard decay and common-outage frequency in a harmless simulator. Compare matched internal replay, verified delegation with ordinary rehearsal and a deadline-tiered wake policy.

**WMX7. Treat outside guards as versioned memory with a tested route back to internal coverage.** Parts: L7W01 retention tiers, L7W09 adaptive placement, L7W13 shared wake dictionary, L7W14 recovery deadlines, L6W13 joint wake constraints, D5-26 bounded response sketch, L7W02 refresh scheduling, L7W10 diverse drill distribution, L7W11 shared dependency counts, L7W16 transparent delegation, L3W10 harmless heartbeat, CE4-13 successor opportunity, L7W04 reference versus rule payload, L7W05 version coherence, L7W06 safe retirement, L7W12 environment inventory, L7W25 independent invariant checks, L2W05 causal extinction, CR29 versioned relearning, L7W03 demand activation, L7W08 independent redundancy, L7W18 checked delegation failover, L7W19 timeout signal, L7W21 early activation, L7W22 correlated outage triage, L4W22 common reviewers, D3-13 compatible histories, L7W07 compile a rule into an authorized guard, L7W20 checked re-offload, L7W24 model migration, L4W21 escrowed release, LW32 world lineage, LM26 capability handshake, L7W15 matched-byte phase audit, L7W17 harmless cap versus delegation control, L7W23 full break-even accounting, L7W26 synthetic benchmark, L6W25 external retention, L6W19 wake coupling. *Mechanism:* Assign each skill a current owner, external rule version, expiry and checked recovery deadline. Verify what external guards actually retain under shared load; rebuild or wake only on supported evidence, and keep current safeguards until their replacements work. Compare against internal replay with all external work priced. *New:* A reusable retention policy can account for freshness, dependencies and common outages instead of assuming that external memory is free or durable. *First test:* Run a synthetic multi-skill stream with approved rule changes, shared queues, architecture migration and correlated outages. Measure service, wake deadlines, plasticity, total costs and false retirements against replay and separately managed delegation plus wake-up.
