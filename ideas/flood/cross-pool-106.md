Raw proposals.

**TFX1. A scratch weight frame must repay its cost before it can survive the branch.** Parts: TT01 decay bands, TT02 reversible frames, TT04 typed weight bus, TT20 shadow updates, TT22 propose-freeze-revert actions, TT25 commitment ladder, L8W22 scratch round trip, SD2-09 distinguishing continuations. *Mechanism:* Give each candidate update a typed scope and lifetime. A shadow frame gets promoted only after it improves a held-out continuation from the same checkpoint and preserves required old behavior. Discard the rest together with any state derived from their provisional predictions. *New:* An inference branch can borrow plasticity without leaving a persistent hypothesis behind or confusing a state rewind with a weight rewind. *First test:* Use synthetic nested puzzles with false detours and recurring conventions. Compare one persistent fast buffer and context-only branching with scoped shadow frames under matched latency.

**TFX2. Preserve the next correction as well as the old answer.** Parts: TT03 projected delta rule, TT05 local predictive updates, TT06 targeted contradiction correction, TT23 conflict preflight, TT26 layer routing, TT27 stopping criterion, TT32 anchor-preserving coordinates, D4-04 native update metric, D4-24 future update witness. *Mechanism:* Before latching a fast update, check old outputs and a small authorized amendment on a scratch copy. Pick a write site and stop point by the useful change obtained after the native optimizer step, not by similarity between gradients alone. Keep disputed corrections tentative. *New:* A low-conflict current write can be rejected if it would make a later valid lesson unlearnable. *First test:* On compositional toy tasks compare output anchoring, gradient projection and amendment-aware checking with the same number of updates, then teach the held-out legitimate exception.

**TFX3. Move repeatable context into weights without counting it twice.** Parts: TT08 closed-form context transfer, TT09 KV eviction transfer, TT10 cancel duplicated context, TT11 structural and episodic split, TT13 repeated trace compression, TT14 editable decompilation, L9W14 observable input boundary, D5-26 retained teaching responses. *Mechanism:* Propose a fast patch from a reusable rule, leaving one-off facts in context. Test the context-only, patch-only and handoff states independently, then require an editable rule or fixture that can support a later correction after the original context is gone. *New:* Compression is accepted only when it preserves calibration and a way to amend the internalized rule, not just the current answer. *First test:* Feed recurring benign formatting conventions mixed with unique per-episode facts. Compare KV trimming, immediate weight transfer and a checked handoff by calibration, episode isolation and recovery after a rule change.

**TFX4. Make thinking and writing compete on the same continuation.** Parts: TT15 marginal compute router, TT16 amortized update cost, TT17 verify before learning, TT18 update-assisted search, TT19 recurrence versus writes, TT21 stalled reasoning, TT24 learnable surprise, TT28 no-update shadow, TT31 discrete verifier feedback, D5-13 learning versus reading, L8W17 update-matched audit. *Mechanism:* At a shared checkpoint allocate matched compute to extra search, a tentative update or reading the verified evidence without writing. Estimate future reuse only from held-out continuations with independent feedback; noisy feedback may justify more checking but not committing the write. *New:* A learner can tell whether a write is worthwhile over repeated calls rather than attributing gains from more search or better evidence to changed weights. *First test:* Cross recurrence frequency and label noise in toy puzzle streams with a deterministic verifier. Measure immediate and amortized benefit of the three arms at matched work.

**TFX5. Cache fast deltas with a behavioral contract instead of a merge promise.** Parts: TT07 reusable delta cache, TT12 compositional delta generation, TT34 joint fast-weight sandbox, L9W25 joint wake, L8W08 combined recovery, D3-22 joint repair witness. *Mechanism:* Attach a versioned behavioral contract to each cached delta and test candidate combinations in scratch state. If a combination fails when its parts pass, retain a small witness for that interaction and repair or route only the conflicting combination. Use no fixed arity cap, but measure the cost of checking configurations. *New:* A valid individual delta is not mistaken for evidence that a whole mix can serve together or be corrected jointly. *First test:* Build synthetic streams with independent rule pairs and one three-rule incompatibility, then compare individual checks, pairwise checks and continuation-based joint checks.

**TFX6. Consolidate shared structure without transferring private episode state.** Parts: TT29 fast-to-slow consolidation, TT30 stream-isolated fast state, TT33 checkpointed benchmark, L9W05 sequential witnesses, LM32 transfer lineage, CR29 versioned relearning. *Mechanism:* Keep provisional fast weights isolated. Promote only authorized reusable rules that pass independent sequence tests over synthetic or explicitly shareable fixtures. At checkpoints audit retention under stream reset and refuse to carry an obsolete scope into the next version. *New:* Continual inference can share reusable procedures without treating facts learned inside one stream as global memory. *First test:* Interleave synthetic streams with one common rule, contradictory private conventions and a shared rule revision. Compare isolated-only buffers, blind pooling and verified promotion using future streams and reset probes.

**TFX7. Treat inference-time learning as a verified transaction that can earn persistence.** Parts: TT01 decay bands, TT02 reversible frames, TT04 typed weight bus, TT20 shadow updates, TT22 propose-freeze-revert actions, TT25 commitment ladder, L8W22 scratch round trip, SD2-09 distinguishing continuations, TT03 projected delta rule, TT05 local predictive updates, TT06 targeted contradiction correction, TT23 conflict preflight, TT26 layer routing, TT27 stopping criterion, TT32 anchor-preserving coordinates, D4-04 native update metric, D4-24 future update witness, TT08 closed-form context transfer, TT09 KV eviction transfer, TT10 cancel duplicated context, TT11 structural and episodic split, TT13 repeated trace compression, TT14 editable decompilation, L9W14 observable input boundary, D5-26 retained teaching responses, TT15 marginal compute router, TT16 amortized update cost, TT17 verify before learning, TT18 update-assisted search, TT19 recurrence versus writes, TT21 stalled reasoning, TT24 learnable surprise, TT28 no-update shadow, TT31 discrete verifier feedback, D5-13 learning versus reading, L8W17 update-matched audit, TT07 reusable delta cache, TT12 compositional delta generation, TT34 joint fast-weight sandbox, L9W25 joint wake, L8W08 combined recovery, D3-22 joint repair witness, TT29 fast-to-slow consolidation, TT30 stream-isolated fast state, TT33 checkpointed benchmark, L9W05 sequential witnesses, LM32 transfer lineage, CR29 versioned relearning. *Mechanism:* Keep inference writes inside reversible frames, match their cost against extra thinking and context, and test both joint activation and future corrections before persisting the reusable rule. Carry authorized behavioral witnesses across consolidation and separate the current session's state from shared knowledge. *New:* A single continual inference loop can distinguish spending compute from learning, provisional success from durable value, and a valid local patch from a safe global commit. *First test:* Use benign synthetic streams crossing task reuse, nested detours, interacting rules, context pressure and contradictory private conventions. Compare frozen inference, compute-matched context-only search, unconditional fast updates and verified staged writes on present accuracy, total work, retention and later correction.
