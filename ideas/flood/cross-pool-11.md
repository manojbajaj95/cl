# Cross-pool merges, round 11

Focal sources: the rate–drift law (reviewer top-10 #4, PR #6; `tree/edit-description-lower-bound.md`, PR #105, ELB#), `tree/training-invariant-edit-content.md` (PR #106, TI#), `tree/footprint-counterfeits.md` (PR #107, FC#), and `tree/synchronizing-consolidation.md` (PR #108, SC#). The law prices the bits needed to decode stored intent as a learner's state changes. For zero-error fixed messages with receiver state as side information, the trajectory-union confusion graph gives a lower bound of log₂ of its chromatic number; persistent savings can come from receiver invariants. The table toy is evidence, not a general SGD law. These are raw and unfiltered.

**RD1. Forecast repayment from what drift can distinguish.** Parts: ELB2 rate–drift curve, ELB6 decoding dependencies, TI1 read–write rank, FC8 missing rank near a boundary, BF2 contract/envelope (PR #102). *Mechanism:* Project measured drift onto the request family's dependency directions and update a sparse confusion graph only where current margins allow a split. Fit the rate forecaster on one set of trajectories and reserve entire drift directions for checking where it misses. *New:* Equal functional distance need not imply equal description cost; the predictor measures drift along directions that separate intents rather than averaging motion everywhere. *First test:* In the PR #105 table toy, match edited-cell counts but rotate drift onto and away from request dependencies. Then use a width-8 modular learner with matched functional distances; compare held-out rate error to steps, global KL and drift across the full output vector.

**RD2. Put the unpayable part of an edit in its own packet.** Parts: ELB5 layered descriptions, TI9 mixed-difference writes, TI16 unstable residual, MS13 on-demand state (PR #104), W8. *Mechanism:* Factor a request into a readable contrast whose lift survives the declared updates and a residual valid only near installation. Store and decode them separately. When the residual fails its check, ask for just the bits needed to resolve it, making no claims about coordinates for which the invariant was never writable. *New:* The durable layer is an installed effect, not just a base description; escrow pays for semantic residue without refreshing the whole edit. *First test:* Use a two-factor linear learner with later updates to main effects and a held-out interaction shift. Compare retained effects and total persistent plus queried bits to full intent, null-space projection and equal-byte replay.

**RD3. A writer can buy a lower rate by certifying what its update law will leave alone.** Parts: ELB11 loan-preserving training, TI2 lift or no-go witness, TI14 minimum change to update law, FC3 unreachable hidden exits, SE22 next-write reserve (PR #98). *Mechanism:* Assign borrowing requests to candidate invariant readouts and ask for the least training-rule change needed to keep their lifts readable. Accept the deal only if a held-out continuation still has at least one useful admissible write; if not, store the intent instead of silently shrinking future plasticity. *New:* Memory rate and available training updates can be traded explicitly without calling a frozen slot free. *First test:* In a two-task affine learner with controllable future subspaces, sweep the budget for altering the update law and report a frontier of bits, old retention and new-task gain against OGD and full-intent replay.

**RD4. Pay a compression loan before the decoder notices it is wrong.** Parts: ELB7 checksums, ELB14 loan cascades, TI6 adversarial legal batches, FC2 separators across a family, V10. *Mechanism:* Keep a reverse dependency graph from declared decoder invariants to compressed descriptions. Periodically try a legal training sequence that separates a shared assumption, even if all current checksums agree. If it succeeds, buy one distinguishing observation and refinance only descriptions whose decode classes actually split. *New:* The audit predicts cascades hidden by present-day decoder agreement, and spends on shared causes instead of refreshing every affected record by age. *First test:* Plant shared and independent decoding dependencies in PR #105's lookup receiver. Compare total repayment bits, false alarms and early wrong decodes against periodic refresh, direct checksum monitoring and adaptive audits chosen one description at a time.

**RD5. Reset preambles that reduce future rate without erasing intent.** Parts: ELB19 fork-union rate, SC17 portable reset preambles, SC16 protected residual, TI19 merger certificates, MS7 synchronizing consolidation (PR #104). *Mechanism:* Before shipping one short description to many hosts, apply a shared legal preamble that coalesces continuation-visible nuisance registers while preserving every protected residual that distinguishes live requests. Code against the reachable states after the preamble and charge the reset cost. Reject a reset that only improves compression by merging different authorized intents. *New:* Intervene on the decoder's future state set to improve its rate rather than just learn a more aggressive encoder. *First test:* Use the PR #108 register toy with an independently set protected bit. Enumerate confusion graphs before and after reset, then compare fleet bits and update cost against per-host anchors, canonical full intent and the same reset that ignores old-task checks.

**RD6. Count the same contrast twice only if future training can make it mean two things.** Parts: ELB22 trajectory quotient, TI7 moving-baseline offsets, TI12 closed-cycle effects, FC13 representation bridge, FA17 paired bridges (PR #99). *Mechanism:* For relative requests, encode paired edited/control trajectories rather than absolute targets. Admit a bridge between training charts only when it preserves the relation through a held-out closed cycle, including after returning to a state with the same unedited outputs. Otherwise split the rate estimate across the two charts. *New:* Rate can be measured for persistent effects even where no individual output is invariant; path failures reveal when an apparently common code needs extra bits. *First test:* Compare common-shift, rotating and asymmetric drift in a paired linear toy. Match final absolute scores where possible; test whether contrast codes predict retained effects better than absolute anchors and whether cycle witnesses explain the residual bits.

**RD7. A lower-bound receipt that says whether to buy a probe, bits, or a new write port.** Parts: ELB2 rate–drift curve, TI2 no-go witness, TI20 protected capacity, FC19 inaccessible versus unmeasured, OK24 failure triad (PR #93), T1. *Mechanism:* Generate two matched-trajectory requests and two matching-footprint writers. Separate a decoder collision from an unmeasured writer effect and from a provable lack of safe lift. Route each failure to a different purchase: intent bits, a legal measurement, or newly justified capacity. *New:* An observed failure to preserve an edit no longer gets charged automatically to memory size; the mechanism identifies which resource can actually change the outcome. *First test:* Enumerate a finite learner with one missing intent bit, one missing assay direction, and one infeasible invariant lift in independent conditions. Compare correct resource purchases per budget with always adding bits, replay or probes.

**RD8. Train two future selves to require the same memory, not the same weights.** Parts: ELB4 coding for possible future models, TI13 conserved total, SC22 synchronize trace laws, FC23 erase unused dimensions, Y5 replica overlap. *Mechanism:* Continue two replicas under different samples while enforcing agreement on the distributions of decoded live requests, not on latent weights. Apply a shared consolidation step only to disagreement regions that predict materially different request outcomes; preserve the protected readout and check the actual worst-group divergence separately from averaged laws. *New:* Compression across stochastic learners is controlled by predictability of semantic decode, with the rare histories that force extra rate made visible. *First test:* In a noisy finite editor, compare shared consolidation, tied-seed replay and average-only alignment while holding marginal task accuracy fixed. Report both zero-error rates on reachable states and empirical rates at equal tolerated decode error.

**RD9. A scheduled memory refresh can spend a recurring task instead of asking the teacher.** Parts: ELB10 decodability horizon, TI18 alternate invariant carrier, SC10 paid return visits, MD12 counterfactual access cost (PR #103), W4. *Mechanism:* At each expected return visit, check whether the returning task can expose the old and new decoding carriers together. When their overlap provides a checked bridge, move the descriptor to the newer carrier; otherwise retain its old scope and schedule a priced query or full-intent fallback. *New:* Renewal can use a naturally recurring computation to migrate decoder side information, rather than copying anchors or assuming recurrence alone refreshes memory. *First test:* Use a cyclic routing stream with known and missing return visits. Compare useful writes, recovery time and total bits/queries against fixed-interval backfilling and always storing raw anchors.

**RD10. Make the assay lease expire at the first invisible phase change.** Parts: FC7 probe validity leases, FC17 strength ladders, TI21 minibatch counterexamples, SC24 held-out distinguishing suffixes, ELB15 gauge-aware requests. *Mechanism:* Tie a retention assay's lease to a sequence of legal write doses and future updates. If two writers match on every sampled dose yet a later suffix separates them, the lease ends at the earliest certified separating context, not an arbitrary clock tick. Preserve the old behavior while revoking the assay's claim about it. *New:* One invalidation signal applies both to a compressed descriptor's decode scope and to the footprint that justified using that descriptor. *First test:* Start with the PR #107 linear twins, then add a hidden delayed register. Compare expiry accuracy and safety/coverage against fixed TTL, wider static assay and a present-margin threshold.

**RD11. A learner that can refinance its memory without rewriting what it meant.** Parts: ELB2 rate–drift, ELB4 future decoder coding, ELB5 layered descriptions, ELB6 decoder dependencies, ELB7 checksums, ELB10 horizon scheduling, ELB14 cascades, ELB19 fleet rate, TI1 read–write rank, TI2 no-go lift, TI6 adversarial batches, TI9 mixed differences, TI14 edit the update law, TI16 residuals, TI18 carrier changes, TI19 merger witnesses, FC2 shared separators, FC3 unavailable exits, FC7 leases, FC8 boundary rank, FC19 missing observations, SC10 return visits, SC16 protected residual, SC17 reset preambles, SC22 stochastic trace laws, SC24 hidden suffixes, OK24 failure triage, MS13 materialization, W8, W10. *Mechanism:* Install an invariant effect where a safe lift exists and fund an expiring semantic residue with a layered message. Predict repayment from separating drift directions, audit common decoder dependencies before they fail, and either buy a missing measurement, migrate to another carrier, or synchronize nuisance state. Never call a reset a saving if it erases an authorized difference; report durable bytes, temporary queries, lost plasticity and working coverage separately. *New:* The rate–drift curve becomes a budget for an online editor that can choose how much to store, learn, measure or safely reset as the stream unfolds. *First test:* Extend the reviewer’s modular-arithmetic CPU gate with a planted invariant, a matched-distance drift that breaks it, and one shared decoder dependency. Use the table and affine oracles first; compare held-out rate forecasts, wrong decodes and old-task retention with stacked full intent, raw anchors, uniform refresh and standard projection at matched coverage.
