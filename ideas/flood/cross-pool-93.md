# Cross-pool merges, round 93

Focal source: `tree/root-learning-from-other-models.md` (PR #358, LM#). Older sources: `tree/deployment-feedback-5.md` (PR #357, D5-#; focal in round 92), `tree/deployment-feedback-4.md` (PR #355, D4-#), `tree/deployment-feedback-3.md` (PR #354, D3-#), `tree/deployment-feedback-2.md` (PR #353, D2-#), deployment feedback root (PR #352, DF#), cultural evolution IV (PR #351, CE4-#), LoRA Learner 4 (PR #350, L4-#), and sleep and dreaming II (PR #334, SD2-#). Raw proposals for synthetic learners and authorized donor artifacts.

**PAX1. Import only the donor difference that survives a change of host.** Parts: LM01 relative donor delta, LM04 causal sparse features, LM06 residual retrieval, LM18 shared anchors, LM20 active subspace, D4-08 one-factor unsharing, D3-09 lawful prediction matching. *Mechanism:* Compare the donor and its ancestor on minimal pairs, retrieve only a delta relevant to the learner's error, and translate it through anchors. Use feature interventions to check the proposed write; reject it if the imported effect tracks the donor's architecture rather than the intended distinction. *New:* A residual archive could retrieve a useful change without requiring reuse of either donor model or alignment of the whole learner. *First test:* Use two synthetic donor families with equal target accuracy and different nuisance features. Compare full distillation, residual retrieval alone and scoped causal installation; test old behavior and a later correction.

**PAX2. Learn from failed donors without adopting their prohibitions wholesale.** Parts: LM02 negative checkpoints, LM07 bottleneck control, LM09 failure-boundary compilation, LM14 executable regression spec, D3-15 joint blocker, DF28 proof blind spot. *Mechanism:* Extract a replayable failure transition from a failed checkpoint, then contrast it with a smaller sibling and a successful case. Admit only a scoped guard that covers the verified failure; store the first valid trajectory that refutes broader application. *New:* Failure can supply a boundary and a regression check without teaching either the failed policy or an indiscriminate veto. *First test:* Use a toy planning domain where two actions appear in failed logs but only their composition violates an invariant. Compare negative distillation, guard induction and exact transition checks.

**PAX3. Compile a donor trajectory into a curriculum that survives replay in the learner.** Parts: LM03 emergence order, LM08 counterfactual decision points, LM10 state skeleton, LM12 environment replay, SD2-05 third-step obstruction, D4-20 next lesson. *Mechanism:* Recover candidate prerequisite edges only where replaying alternative actions changes the result under matched environmental conditions. Train on the verified state transitions rather than the donor narration, and preserve a later lesson that can distinguish a true prerequisite from a donor habit. *New:* A curriculum can retain why its ordering matters even if the learner acts in a different environment. *First test:* Use symbolic tasks where a donor masters a shortcut before a real prerequisite because of a lucky tool response. Compare chronological replay, skeleton distillation and intervention-based ordering.

**PAX4. Spend verification on disagreements that could change the write.** Parts: LM11 deferral boundary, LM13 silent disagreement, LM21 counterfactual peer queries, LM22 invariant gating, LM23 cross-lineage falsification, CE4-24 bounded corruption, D3-18 diagnostic margin. *Mechanism:* Use disagreements to propose minimal separating questions, rank them by whether all possible reports would still permit the same write, and spend independent verification only on consequential cases. Calibrate deferral locally and count correlated peers as one source until counterexamples distinguish their errors. *New:* Peer disagreement can allocate a finite verification budget without allowing peer votes to replace old guarantees. *First test:* Mix correlated and independent toy peers with overlapping confidence and a fixed query budget. Compare confidence arbitration, uniform audit and decision-sensitive verification on wrong writes and needless deferrals.

**PAX5. Consolidate a temporary bridge only after it can be removed and the skill can still be edited.** Parts: LM05 neutral-channel control, LM15 cache translation, LM16 detachable scaffold, LM17 tokenizer boundary, LM19 composable modules, L4-17 protect peer effect, D5-13 update versus read. *Mechanism:* Use the donor bridge temporarily in a sandbox and distill only effects attributable to the target task. Compare cache, span and module carriers on the same observable boundary, using neutral examples to detect unrelated transfer. Detach the bridge only after the native learner preserves both current performance and a bounded future edit. *New:* Matching donor outputs after detachment is not enough if the learner has lost the ability to correct the imported skill. *First test:* Translate a permitted synthetic skill between two encodings with a neutral-carrier confound. Compare direct distillation, reversible scaffolding and staged consolidation; test donor removal and a held-out amendment.

**PAX6. Let a clean donor help remove an obsolete rule without erasing a new composition.** Parts: LM24 complementary peers, LM25 clean-model anchor, LM26 capability handshake, D3-19 abstraction for unseen peers, D2-15 overlap proof, D5-18 substitute lesson. *Mechanism:* Compile locally verified substeps from partial specialists, and consult the clean donor only in the proved overlap with the obsolete scope. Require a capability packet with positive, negative and boundary probes. Keep uncertain composition edges outside the write and permit a substitute lesson only if it validates the same boundary. *New:* An import and a localized unlearning operation can share the same admission evidence without treating a clean donor as globally correct. *First test:* Use two toy specialists and a naive donor that differs on an unrelated exception. Compare independent unlearning plus composition, global restoration and overlap-scoped joint admission.

**PAX7. Pass on a teaching packet, not the predecessor's whole behavior.** Parts: LM27 tandem oversight, LM28 portable bequest, LM29 explicit capability gap, LM30 delta triage, LM31 reverse back-port, LM32 lineage contract, D4-26 counterexample to veto, D5-26 teaching-response sketch, DF16 migration bridge. *Mechanism:* Partition old obligations into already met, recoverable from a small packet, excluded, and unsupported at the new capacity. During temporary tandem service, require successor-native output and next-lesson checks before removing each old route. Back-port only verified corrections the legacy learner can actually support. *New:* Replacement becomes a reversible transfer of specific obligations rather than a claim that higher average capability absorbs the predecessor. *First test:* Run a synthetic upgrade with a stronger new base that already knows an old skill, misses one rare correction, and cannot host a timing-sensitive exception. Compare full distillation, behavioral-contract-only gating and packet-based handoff with explicit gaps.

**PAX8. Import useful changes without inheriting the donor's shortcuts or losing the next lesson.** Parts: LM01 relative donor delta, LM04 causal sparse features, LM06 residual retrieval, LM18 shared anchors, LM20 active subspace, D4-08 one-factor unsharing, D3-09 lawful prediction matching, LM02 negative checkpoints, LM07 bottleneck control, LM09 failure-boundary compilation, LM14 executable regression spec, D3-15 joint blocker, DF28 proof blind spot, LM03 emergence order, LM08 counterfactual decision points, LM10 state skeleton, LM12 environment replay, SD2-05 third-step obstruction, D4-20 next lesson, LM11 deferral boundary, LM13 silent disagreement, LM21 counterfactual peer queries, LM22 invariant gating, LM23 cross-lineage falsification, CE4-24 bounded corruption, D3-18 diagnostic margin, LM05 neutral-channel control, LM15 cache translation, LM16 detachable scaffold, LM17 tokenizer boundary, LM19 composable modules, L4-17 protect peer effect, D5-13 update versus read, LM24 complementary peers, LM25 clean-model anchor, LM26 capability handshake, D3-19 abstraction for unseen peers, D2-15 overlap proof, D5-18 substitute lesson, LM27 tandem oversight, LM28 portable bequest, LM29 explicit capability gap, LM30 delta triage, LM31 reverse back-port, LM32 lineage contract, D4-26 counterexample to veto, D5-26 teaching-response sketch, DF16 migration bridge. *Mechanism:* Treat peer artifacts as scoped candidate evidence, not authority. Separate architecture-independent capability differences from nuisance transfer, verify disagreements and compositions, and commit only the imported changes that preserve old obligations and next-lesson feasibility. Carry a compact contract and a teaching packet across model replacement; leave unsupported cases explicit. *New:* The same import workflow could handle live peers, failed checkpoints and retired predecessors while preserving an independently verifiable ability to correct what was transferred. *First test:* Use synthetic heterogeneous learners, frozen donor variants, controlled failure logs and a limited-capacity upgrade. Compare full distillation, modular import and stacked filtering plus regression replay at matched data, queries and work; score transferable gain, negative transfer, old obligations and future amendment.
