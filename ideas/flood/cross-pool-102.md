Raw proposals; live coverage is not withheld for any rehearsal or oversight test.

**HWX1. Measure oversight readiness without degrading prevention.** Parts: L6W01 benign vigilance fixtures, L6W03 cliff versus slope, L6W05 fatigue bounds, L6W06 shared-guard canary, L6W07 unpredictable audit schedule, L6W09 changing readiness, L3W10 harmless heartbeat, CE4-24 corruption tolerance. *Mechanism:* Run authorized harmless drills on isolated surfaces, varying audit timing and workload. Estimate whether independent coverage declines abruptly or gradually, with uncertainty and explicit fatigue limits. Treat a passed heartbeat as evidence only for the handling exercised, never as license to let real failures through. *New:* This tests the guard-cliff premise without making oversight depend on deliberately worse service. *First test:* Use an offline simulator with steep and smooth readiness curves and common guards. Compare fixed drills, passive monitoring and feedback-limited auditing at equal burden.

**HWX2. Separate what the model knows from what it is authorized to do.** Parts: L6W02 positive-transfer monitoring, L6W04 separate competence and deployment, L6W08 architectural authority boundary, L6W21 dormant transfer, L5W14 transparent handoff, LW18 independent fallback. *Mechanism:* Keep capability gains intact while routing decisions through explicit authorization and dependable review. Test that unrelated learning cannot silently expand deployment authority. If authority changes or a reviewer loses capacity, keep the existing safe default or pause the scoped action rather than unlearning useful features. *New:* Positive transfer can increase internal knowledge without silently taking over an independent duty. *First test:* Train a synthetic shared model on one task that improves another unexpectedly. Compare weight caps, unrestricted transfer and boundary-checked delegation.

**HWX3. Verify a wake-up update after the representation has moved.** Parts: L6W10 collateral control, L6W11 single authorized signal, L6W12 co-rotated features, L6W15 first-order screen, L6W16 layer placement, L6W17 shifted recurrence, L5W03 one-step dormancy, D4-04 optimizer metric, D5-18 equivalent lesson. *Mechanism:* Match the dormant skill by its behavioral effect, then test whether a lawful fresh signal reaches that effect after a feature rotation. Use cheap geometry only to screen candidate layers; require the actual optimizer step and held-out checks on new and old behavior. A noisy recurrence does not by itself authorize a live update. *New:* A small update may recover a skill across representation drift without needing old weights, but only where the new signal and update remain valid. *First test:* Cross a rotation, an optimizer-state change and a stale trigger in a tiny synthetic network. Compare frozen anchors, matched-compute replay and scoped native-step wake-up.

**HWX4. Budget joint wake-ups and make re-hibernation safe.** Parts: L6W13 parallel wake constraints, L6W14 temporary wake reversal, L6W18 dormancy saturation, L4W22 shared oversight, D3-13 compatible histories, CR29 versioned relearning. *Mechanism:* Test simultaneous wake-ups for compatible guard outages instead of certifying each alone. Measure how reserving more wake directions slows other learning, and move a skill to slower recovery only when its verified deadline allows it. Recheck the current external guard before withdrawing a temporary internal repair. *New:* A small one-step reserve can be allocated to duties that need it most without mistaking a set of successful singleton drills for a working joint recovery plan. *First test:* Use overlapping dormant directions and correlated outages in a finite task stream. Compare permanent pins, independent wake tests and a deadline-based joint reserve.

**HWX5. Tie a deployment mode change to a real witness and an independently safe fallback.** Parts: L6W19 guarded mode with checked wake, L6W20 reversible rehearsal, L6W22 calm versus burst regimes, L6W23 independent backup for drills, L6W24 three-mode choice, L6W25 external retention, L6W26 crossed falsification, L5W19 recoverability cost, L2W26 probation, D3-20 observable return. *Mechanism:* Choose verified delegation, bounded dormancy or active internal coverage for each duty. Change mode only after an authorized rehearsal demonstrates a safe transition under the relevant load and deadlines; stop affected work if neither path is ready. Use harmless simulator fixtures rather than inducing failures in operations. *New:* The controller can distinguish a recoverable temporary duty transfer from a hidden dependence on a guard whose return was never demonstrated. *First test:* Cross steep versus gradual guard response, representation rotation and shared outages in a synthetic benchmark. Compare fixed consolidation, ordinary deferral and verified mode changes at equal coverage floors.

**HWX6. Keep independent oversight and a dormant recovery path without sacrificing current prevention.** Parts: L6W01 benign vigilance fixtures, L6W03 cliff versus slope, L6W05 fatigue bounds, L6W06 shared-guard canary, L6W07 unpredictable audit schedule, L6W09 changing readiness, L3W10 harmless heartbeat, CE4-24 corruption tolerance, L6W02 positive-transfer monitoring, L6W04 separate competence and deployment, L6W08 architectural authority boundary, L6W21 dormant transfer, L5W14 transparent handoff, LW18 independent fallback, L6W10 collateral control, L6W11 single authorized signal, L6W12 co-rotated features, L6W15 first-order screen, L6W16 layer placement, L6W17 shifted recurrence, L5W03 one-step dormancy, D4-04 optimizer metric, D5-18 equivalent lesson, L6W13 parallel wake constraints, L6W14 temporary wake reversal, L6W18 dormancy saturation, L4W22 shared oversight, D3-13 compatible histories, CR29 versioned relearning, L6W19 guarded mode with checked wake, L6W20 reversible rehearsal, L6W22 calm versus burst regimes, L6W23 independent backup for drills, L6W24 three-mode choice, L6W25 external retention, L6W26 crossed falsification, L5W19 recoverability cost, L2W26 probation, D3-20 observable return. *Mechanism:* Measure oversight with harmless fixtures, separate capability from authority, and preserve a native wake-up test for duties currently covered elsewhere. Account for joint demand and guarded deadlines before changing the service mode; make all unsupported transitions explicit. *New:* One contract can price shared oversight and rapid relearning without needing deliberate underperformance to keep independent safeguards in place. *First test:* Run the crossed synthetic benchmark with authorization boundaries and matched service floors. Compare fixed pins, deferral plus ordinary rehearsal and the joint policy on oversight burden, successful wake-ups, update interference and invalid handoffs.
