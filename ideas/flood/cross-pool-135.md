## Merge proposals

**ACC1. Check the source of a toy error before correcting its destination.** Parts: AL2-01 crossed source and sink, AL2-02 causal response difference, AL2-03 remote-read cost, AL2-04 route attribution, AL2-05 dose validation, AL2-07 missing-edge falsifier, AL2-08 redundant routes, AL2-10 input identity, AL11 dependency-specific correction, HC13 concentration assay. *Mechanism:* Plant a decoy route in a toy circuit. Match activation magnitudes from legitimate and nuisance routes and hold out swaps that distinguish their provenance. Drop the correction if bypassing the nominated nuisance route does not remove its benefit; verify any proposed second route independently. *New:* A localized correction must track which route caused an error, not simply a convenient correlate at the destination. *First test:* Compare remote and sink-local reads, an irrelevant read control and equal-rank whole-feature correction. Score both decisions on crossed held-out cases and charge the remote tap's extra state.

**ACC2. Keep a correction only as long as its witnesses still apply.** Parts: AL2-06 re-estimate the source read, AL2-09 signed witnesses, AL2-11 future consumer, AL2-12 re-estimate the sink write, AL2-13 nonlinear collision, AL2-14 calibrated scope, AL2-15 attribution retraction, NP4-13 future learning response, NP5-01 lesson interaction, NP3-22 source withdrawal. *Mechanism:* Keep source and destination witnesses separately. When a benign schema or downstream rule changes, reuse only the side that still predicts its effect. Check two corrections together on witnessed overlaps and suspend them outside calibrated scope. Rebuild from new witnesses if an attribution is withdrawn. *New:* Local reuse is valuable only if it preserves what a later skill can learn and avoids silently inheriting a disproved attribution. *First test:* Change the input encoding and the toy destination rule independently before teaching a new consumer. Compare partial revision, full refits and an unchanged correction at matched evidence and report retention and coverage.

**ACC3. Separate better sampling from better teaching.** Parts: AL2-16 sampling-by-writing factorial, AL2-17 timing windows, AL2-18 prefix allocation, AL2-19 solution classes, AL2-21 clean re-encoding, AL2-22 matched accepted examples, AL2-23 independent verification, AL2-24 clean discovery rate, AL28 exploration-only intervention, PL5-10 held-out effect families. *Mechanism:* Temporarily downweight a planted shortcut during candidate sampling for benign toy transformations, without modifying the verifier. Discard the temporary intervention and its internal state, verify candidates independently and teach from a clean restart. Measure yield and solution diversity separately from later learning. *New:* More verified answers do not necessarily make better training data; clean transfer at fixed accepted count and difficulty tests for a change in evidence quality. *First test:* Compare equal-call clean sampling and temperature controls against temporary assistance. Stratify by executable solution class and evaluate learners on new problem families with no assistance.

**ACC4. Promote a verified operation only when the task requests it.** Parts: AL2-20 verified fork, AL2-25 shortcut-independent promotion, AL2-26 one-shot reward contrast, AL2-27 routine versus new skill, AL2-28 requested-scope promotion, AL2-29 gradient comparison assay, AL2-30 trustworthy-pair gate, AL31 evidence for abstention, NP4-13 future learning response. *Mechanism:* Use clean, verified pairs to distinguish an already available routine from a new composition or a genuinely new toy operator. Test whether the write follows the task request when the decoy is absent, and abstain if independent pairs are too sparse or the effect is not reproducible. *New:* A scoped positive update earns credit for teaching only if it helps independently of the decoy, without applying the rule to requests where it does not belong. *First test:* Cross requested operation and decoy presence on a held-out toy stream. Compare one-shot contrasts, matched-data distillation and gradient-based learning at equal verifier budget; report scope errors and performance by initial solution coverage.

**ACC5. Keep evidence collection, scoped correction and learning as separate interventions.** Parts: AL2-01 crossed source and sink, AL2-02 causal response difference, AL2-03 remote-read cost, AL2-04 route attribution, AL2-05 dose validation, AL2-07 missing-edge falsifier, AL2-08 redundant routes, AL2-10 input identity, AL11 dependency-specific correction, HC13 concentration assay, AL2-06 re-estimate the source read, AL2-09 signed witnesses, AL2-11 future consumer, AL2-12 re-estimate the sink write, AL2-13 nonlinear collision, AL2-14 calibrated scope, AL2-15 attribution retraction, NP4-13 future learning response, NP5-01 lesson interaction, NP3-22 source withdrawal, AL2-16 sampling-by-writing factorial, AL2-17 timing windows, AL2-18 prefix allocation, AL2-19 solution classes, AL2-21 clean re-encoding, AL2-22 matched accepted examples, AL2-23 independent verification, AL2-24 clean discovery rate, AL28 exploration-only intervention, PL5-10 held-out effect families, AL2-20 verified fork, AL2-25 shortcut-independent promotion, AL2-26 one-shot reward contrast, AL2-27 routine versus new skill, AL2-28 requested-scope promotion, AL2-29 gradient comparison assay, AL2-30 trustworthy-pair gate, AL31 evidence for abstention. *Mechanism:* Record which synthetic route caused an error, which verified examples improved a clean learner and which scope tests protect legitimate behavior. Keep the transient sampler intervention separate from the learned rule and from any retained correction. If scope or attribution fails, abstain or rebuild the affected part. *New:* The benefit should survive two independent changes: a revision of the synthetic route that formerly caused the shortcut and a new benign task that needs the taught operation without that route. *First test:* Run a proposed toy stream with a schema revision, a held-out operator and an independently withdrawn witness. Compare full refits and clean sampling plus distillation at equal calls and state, scoring route specificity, new-rule transfer and untouched-task retention.
