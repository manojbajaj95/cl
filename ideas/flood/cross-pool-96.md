Raw proposals; track both transfer cost and the old obligations that stay editable.

**NRX1. Kill the compensation, not the private rule it carried.** Parts: L4-01 signed overshoot, L4-02 injected old bug, L4-03 private-core peeling, L4-22 no-op substitution test, L3-16 compensation coupling, CE3-18 negative control. *Mechanism:* Compare native fixed outputs with replayed old buggy outputs in scratch copies, crossing each with the candidate rule on and off. Peel only the component whose beneficial effect depends on the old bug. Verify that an independent private exception still makes the same transformation in head-to-head probes. *New:* An upstream fix can cancel one purpose of a mixed rule without establishing that its other purpose is obsolete. *First test:* Use a synthetic calibration bug with an offset and a genuine exception. Compare whole-rule retirement, signed filtering alone and crossed private-core peeling.

**NRX2. Retire a workaround only where the new base actually wins.** Parts: L4-04 unnecessary deferral, L4-07 regional gates, L4-08 calibration hack, L4-09 historical screening, L4-10 disjoint stress set, DF08 transport boundary, CE4-24 report power. *Mechanism:* Use historical covariance to prioritize audits, then test current decision cost, calibration and rare-cohort outcomes on a disjoint set. Retire on verified fixed regions only; leave an explicit uncertainty case when current evidence cannot resolve the tail. *New:* A base upgrade can reduce unnecessary retries without sacrificing protection where its fix is incomplete. *First test:* Make a synthetic base fix that improves confidence and latency on common cases but not a rare cohort. Compare accuracy-only purging, full replay and scoped retirement.

**NRX3. Unwind workaround stacks before distilling native behavior.** Parts: L4-05 selective backward compatibility, L4-06 iterative unwinding, L4-21 purge then rebuild, L4-24 private-rule lock, D3-13 compatible histories, SD2-05 third-edit obstruction. *Mechanism:* Schedule retirement before regeneration on each causally verified dependency chain. Recheck downstream rules after each removal, preserve verified private behavior, and stop on a cycle or newly ambiguous slice rather than repeatedly stripping rules based on nominal order. *New:* The upgrade can avoid reinstalling a bug through a downstream teaching example generated too early. *First test:* Use an old base bug with two layers of compensation and a legitimate branch. Compare global compatibility, rebuild-first transfer and bounded staged purging on held-out compositions.

**NRX4. Re-ground only where the new upstream state still carries the needed distinction.** Parts: L4-11 semantic invariants, L4-12 latent re-grounding, L4-16 diverse native continuations, L4-17 semantic slots, L4-19 information sufficiency, LM17 tokenizer boundaries, D3-09 lawful prediction identity. *Mechanism:* Regenerate native upstream states through explicit semantic slots or a measured latent interface. Accept only samples that retain the downstream decision's required facts. Use matched contrasts to detect collisions; a failed cheap decoder triggers stronger checks, not an automatic claim of information loss. *New:* A richer native style is safe to teach from only if the downstream learner can still see the difference that licenses its action. *First test:* Vary tokenizer, surface form and latent information independently. Compare single canonical examples, native sampling alone and sufficiency-screened rebuilding.

**NRX5. Prove the downstream rebuild did not spend the upstream improvement.** Parts: L4-13 topological waves, L4-15 anchor native prior, L4-18 fresh amendment, L3-13 native witnesses, D4-24 useful next gradient, D5-13 teaching beyond reading. *Mechanism:* Rebuild a chain in dependency order, rechecking upstream invariants after each committed wave. Validate with a new permitted amendment and a read-only control: a rebuilt slice must be correct now and still improve under the ordinary learner update without eroding the upstream skill. *New:* A native-compatible packet may appear correct after migration while leaving its successor unable to respond to a new correction. *First test:* Use a three-stage grammar with a common upstream improvement and a rare downstream lesson. Compare joint retraining, static anchoring and staged rebuild with amendment checks.

**NRX6. Use a temporary bridge only while a checked native exit is available.** Parts: L4-14 bridge debt, L4-20 cold-slice bridge, L4-23 multi-hop debt accounting, L4-25 factored witnesses, LM16 detachable scaffold, DF16 migration bridge. *Mechanism:* Install a temporary seam bridge only for delayed slices with a declared native exit test. Record factored witnesses and debt in latency, state, validation work and stale dependencies; compare bridge stacking with repeated native reconstruction without assuming either cost is monotone. *New:* A cheap cutover can keep rare service live without hiding debt in bridges that no later successor can remove. *First test:* Compare cutovers across four synthetic base versions with a rare slice and shifting conventions. Vary whether factored slots remain valid; measure steady-state and migration work separately.

**NRX7. Repack the native skills without letting cold rollback revive stale behavior.** Parts: L4-26 clean native packet, L4-27 cold quarantine, L2-28 granular re-admission, L3-27 rehearsal feedback, CR29 versioned reinstatement, D4-26 retain counterexamples. *Mechanism:* Generate the next packet from verified native behavior and retain only permitted old witnesses with an explicit reopening condition. Revalidate a narrowly recovered obligation against current evidence; turn verified migration failures into future rehearsal cases rather than unconditionally restoring whichever rule was archived. *New:* Future generations can learn from mistaken retirement without carrying every obsolete workaround in their live teaching data. *First test:* Induce a regression after a second upgrade while leaving the original bug fixed. Compare full old packets, deletion with no recovery and versioned scoped readmission.

**NRX8. Preserve the rule, replace its old inputs, and leave the workaround behind.** Parts: L4-01 signed overshoot, L4-02 injected old bug, L4-03 private-core peeling, L4-22 no-op substitution test, L3-16 compensation coupling, CE3-18 negative control, L4-04 unnecessary deferral, L4-07 regional gates, L4-08 calibration hack, L4-09 historical screening, L4-10 disjoint stress set, DF08 transport boundary, CE4-24 report power, L4-05 selective backward compatibility, L4-06 iterative unwinding, L4-21 purge then rebuild, L4-24 private-rule lock, D3-13 compatible histories, SD2-05 third-edit obstruction, L4-11 semantic invariants, L4-12 latent re-grounding, L4-16 diverse native continuations, L4-17 semantic slots, L4-19 information sufficiency, LM17 tokenizer boundaries, D3-09 lawful prediction identity, L4-13 topological waves, L4-15 anchor native prior, L4-18 fresh amendment, L3-13 native witnesses, D4-24 useful next gradient, D5-13 teaching beyond reading, L4-14 bridge debt, L4-20 cold-slice bridge, L4-23 multi-hop debt accounting, L4-25 factored witnesses, LM16 detachable scaffold, DF16 migration bridge, L4-26 clean native packet, L4-27 cold quarantine, L2-28 granular re-admission, L3-27 rehearsal feedback, CR29 versioned reinstatement, D4-26 retain counterexamples. *Mechanism:* Separate real requirements from old-base compensation before regenerating dependent lessons. Check the native successor's information, upstream gains and future editability, then use bounded bridges or scoped rollback only where native reconstruction is not yet supported. Feed tested exceptions into the next handoff instead of importing the predecessor wholesale. *New:* A migration plan can preserve service without requiring all predecessor behavior to recur, and without assuming reuse of a native interface makes later learning safe. *First test:* Run a finite upgrade ladder with partly fixed bugs, heterogeneous native representations, rare dependencies and a fresh authorized amendment. Compare full compatibility, purge plus untested rebuilding and checked causal migration at matched service and costs.
