**GCX1. Measure curvature before making it a reason to change the learner.** Parts: EC01 learn Gamma, EC02 small-loop measurement, EC07 informative loops, EC10 hysteretic state, EC11 failed return, EC21 forgetting assay, EC26 curvature-spectrum gate, EB01 loop residual, NP24 hysteresis, PL5-10 held-out effects. *Mechanism:* Fit one connection Γ on virtual calibration motion. In no-learning loops, compare reversed paths and repeated trials on held-out skills and body directions. Track hidden simulator state to separate an open physical path from curvature, and measure fitting error against an independent simulator oracle. *New:* EC26 gates every curvature-dependent extension in this round. If residual curvature is within noise, use the single-conjugator baseline and retain only EC01 and EC12 as focal mechanisms. EC21 is a diagnostic, not a second primitive. *First test:* On harmless virtual bodies, vary path order and hysteresis independently. Compare Γ with a single conjugator, which should suffice on regions that are flat and empirically path-independent.

**GCX2. Test whether one compensation map preserves the next lesson.** Parts: EC12 gradient-level invariance, EC15 canonical world model, EC16 transported demonstrations, EC18 decoded action chunks, EC23 varying action spaces, EC24 ordinary-motion fitting, EB12 shared conjugator, NP07 update conjugacy, NP4-13 future response map, EL24 effect contracts. *Mechanism:* Compare learn-then-transport with transport-then-learn on held-out task effects, not raw gradients expressed in different coordinates. Use a shared effect contract to compare virtual morphologies and retain a simple conjugator where it works. Treat the replay and architecture variants as extensions, not survivors of a null EC26 result. *New:* Agreement on today’s behavior does not establish that replay from another virtual body teaches the same next lesson. *First test:* Compare ordinary-motion and calibration fits on held-out virtual demonstrations and a frozen toy policy, with a common observable readout across embodiments.

**GCX3. Credit loop residuals only after accounting for path effects.** Parts: EC04 residual decomposition, EC05 loop descriptors, EC06 invariant writes, EC08 transfer round trip, EC09 cross-body residual, EC19 loop consolidation, EC25 shared residuals, EB11 projected routing, NP5-01 interaction of reversible lessons, D5-26 future teaching responses. *Mechanism:* Only after EC26 detects reproducible curvature, subtract a matched no-learning loop from a learned loop and test the remaining effect on independent skill outcomes and a fresh lesson. Use two simulator variants in place of physical transfer. Hold consolidation and shared credit if the correction fails across paths. *New:* A residual may reflect skill, compensation error or their interaction; subtraction is a hypothesis to test, not a guarantee. *First test:* Cross learning on/off with path order in virtual bodies. Compare raw loop credit, curvature-corrected credit and direct held-out skill gains.

**GCX4. Let verified composition errors limit where a shared skill applies.** Parts: EC03 flatness test, EC13 composing changes, EC14 body-region variants, EC17 confidence-based hardening, EC20 visit order, EC22 curvature and constraints, EB26 constraint coordinates, EL20 candidate transport, EL10 independent receipts, L8W22 scratch round trip. *Mechanism:* Only after EC26 detects reproducible curvature, compare paths with the same endpoints and test whether composition error predicts failure on independently checked tasks. Relax shared routing only where that prediction holds. Use curvature solely to select virtual constraint cases for independent rechecking, never as a certificate. *New:* Path dependence can help decide where sharing fails and where to recheck a virtual constraint, but cannot establish a safe set by itself. *First test:* In toy physics, compare soft routing, a hard shared conjugator and checked local variants under path-order changes; independently score simulated constraint witnesses.

**GCX5. Use one learned body connection to separate compensation from lasting skill learning.** Parts: EC01 learn Gamma, EC02 small-loop measurement, EC07 informative loops, EC10 hysteretic state, EC11 failed return, EC21 forgetting assay, EC26 curvature-spectrum gate, EB01 loop residual, NP24 hysteresis, PL5-10 held-out effects, EC12 gradient-level invariance, EC15 canonical world model, EC16 transported demonstrations, EC18 decoded action chunks, EC23 varying action spaces, EC24 ordinary-motion fitting, EB12 shared conjugator, NP07 update conjugacy, NP4-13 future response map, EL24 effect contracts, EC04 residual decomposition, EC05 loop descriptors, EC06 invariant writes, EC08 transfer round trip, EC09 cross-body residual, EC19 loop consolidation, EC25 shared residuals, EB11 projected routing, NP5-01 interaction of reversible lessons, D5-26 future teaching responses, EC03 flatness test, EC13 composing changes, EC14 body-region variants, EC17 confidence-based hardening, EC20 visit order, EC22 curvature and constraints, EB26 constraint coordinates, EL20 candidate transport, EL10 independent receipts, L8W22 scratch round trip. *Mechanism:* Fit Γ from virtual body changes. Flatness is the hypothesis behind body-blind learning over tested paths; curvature is the proposed obstruction. Test whether the loop residual decomposes into lasting skill gain and enclosed curvature. Gate every curvature-dependent use on EC26 and use EC21 only as an assay. *New:* One transport primitive links rollback and body-blindness without making curvature correction compulsory. If EC26 is null, keep EC01 and EC12 and use the single conjugator. *First test:* Use simulation only. Compare a single conjugator, learned transport and EC26-gated curvature corrections on held-out virtual body loops and later lessons.
