# Cross-pool merges, round 4

New sources: `tree/agent-harness.md` (PR #47, AH#), `ideas/flood/cl-bench.md` (PR #48, B#), `tree/model-guided-edits.md` (PR #49, GE#), `tree/model-forward-only.md` (PR #50, FO#), `tree/model-rl-ood.md` (PR #51, RL#), `tree/harness-discrete-backprop.md` (PR #52, DB#). These are combined with rounds 1–3 (X/Y/Z#) and the earlier flood files. They are raw and unfiltered; each has a mechanism, why it's new, and the cheapest first test.

**Q1. Commutator calculus for writes, across every substrate.** Parts: AH7 rebasing by noncommutation, RL13 patch commutator calculus, FO6 patch homomorphism, Y2 BCH correction, X3 learning algebra, O2, the two-order comparator (PR #11/#17). *Mechanism:* every write, whether a text lesson, a harness edit, a LoRA or a weight edit, is an operator. The comparator measures its commutator with every other live write in forward passes only. Writes that commute are applied in any order, and noncommuting pairs are rebased or corrected by the half-commutator. *New:* one order-effect algebra shared across text, code and weights. *First test:* A3 world plus a toy LoRA: commutator estimates predict the order effect across substrates (ρ > 0.7).

**Q2. Self-describing, gauge-fixed weights with an edit address space.** Parts: GE3 gauge-fixed canonical weights, GE8 manifests at birth, GE9/X5 edit address pages, M4 self-describing deltas, P17 symbol tables, FO2 credit-address book, B6 edge-addressable weights. *Mechanism:* train the model so each block exports a manifest (what it reads and writes) in a canonical gauge, and reserves key-addressed writable pages. An editor (human, big model or forward-only search) writes to an address instead of searching weight space. *New:* weights that are readable and writable by design; PR #49 says where-to-edit has little headroom, and this changes the substrate instead. *First test:* small transformer trained with the manifest head and pages, comparing an LLM editor's success with and without manifests at equal queries.

**Q3. Forward-only learning compiled from verified forks.** Parts: RL "verified-fork learning", RL1 fork tapes, FO1 counterfactual write compiler, FO3 question barcodes, FO11/NB01/Z1 eligibility escrow, B7 counterfactual-gated writes, F2-5 twin. *Mechanism:* at a decision point, a teacher nominates an alternative action. The fork is verified by rollout, and the verified pair is compiled into a write by a forward-only coded perturbation search (several credit channels per batch via orthogonal barcodes). The write is escrowed until a second fork confirms it. *New:* a complete gradient-free continual learner with verification at every step. *First test:* the PR #50 probe world: barcoded forward search vs MeZO vs SFT on fork pairs, measuring held-out transfer per forward pass.

**Q4. Executable obligations as the universal memory format.** Parts: DB "repair variables as wires", DB10 refutation-carrying compilation, DB14 library of failed inverses, AH3 failed rollout → obligation, RL15 mutant verifiers as specs, B18 executable facts, X4 Popperian memory, Y4 proofreading. *Mechanism:* every learned thing is stored as an obligation: a predicate over behavior, plus a certificate saying it can be realized under some write language, plus any known impossibility results. Compilation can target text, a harness edit or weights. Memory retires when its obligation is refuted. *New:* a memory format that does not depend on the substrate and carries its own proof and refutation status. *First test:* the PR #52 probe world: obligation memory vs text lessons vs direct edits, measuring retention under substrate swaps.

**Q5. Memory schema migrations with up/down functions + environment transport.** Parts: B1 schema migrations, B20 environment-version transport, P6/P19 decompile-recompile and stable ABI, A2 testaments, X10 round trip, SM38 prompt–weight swap. *Mechanism:* agent memory is a typed database. Every environment or model upgrade ships an up/down migration, learned from paired runs, that transforms memories rather than discarding them. Unmigratable memories are reset to `...` stubs. *New:* database migration semantics for continual-learning memory across model and environment versions. *First test:* cl-bench task with an env-version shift: migrated memory vs fresh vs stale, measuring the score.

**Q6. Stigmergic, channel-attributed fleet learning.** Parts: B15 stigmergic memory, B16 channel attribution, B29 file system as weight space, Y6 plasticity economy, X8 fleet economy, E20 quadratic funding. *Mechanism:* agents write into the shared environment (files, git notes). Each carrier's gain is attributed by ablation (B16) and priced, and fleet slots are funded quadratically. *New:* an economy over learning *channels*, not only lessons. *First test:* cl-bench run-all with a shared fs: attribution-priced vs uniform channel use.

**Q7. Teacher-as-experimentalist for continual learning.** Parts: AH4 causal query planner, RL2 teacher as experimental designer, FO10 calibrated disagreement teacher, GE18 student points/teacher writes, AH13 litmus-test synthesis, RL18 learn the experimenter. *Mechanism:* a big model does not teach answers. It designs the smallest experiment, a pair of task instances, that tells apart hypotheses about what the small learner is missing. Then it writes to the address the student points at, and it is trained across checkpoints to design better experiments. *New:* a teacher whose output is experiments, so supervision cost scales with the bits the student actually needs. *First test:* symbolic DSL from PR #51: experiment-designer teacher vs answer teacher at equal teacher tokens, measuring OOD transfer.

**Q8. Learned partial resets + survival functions + reachability GC.** Parts: B33 learned partial resets, B27 survival functions, N3/P33 reachability GC, Y8 Lindy/Chesterton, Z8 ghost conduits, E24 effective population size. *Mechanism:* every memory item has a fitted hazard. A reset gate removes items whose hazard-weighted value, given reachability from live goals, is below the cost of storing them, and leaves a ghost trace for cheap relearning. *New:* the forgetting policy is learned from survival analysis and comes with a savings guarantee. *First test:* cl-bench: learned resets vs full memory vs reset(), across 5 permuted orders.

**Q9. Score-vector tomography as the universal probe.** Parts: FO14 score-vector tomography, RL11 weight-effect tomography, GE21 forward-only experiments, AH2 steering tomography, Y5 replica overlap, MY3 correctability meter. *Mechanism:* apply coded combinations of candidate interventions (text, prefix, code, weights) and recover each one's behavior-effect vector from outputs already computed. The correctability meter is one coordinate of this vector. *New:* a single measurement that makes interventions across substrates comparable and composable. *First test:* the PR #50 probe: tomography-recovered effects vs one-at-a-time A/B at equal forwards, measuring recovery error.

**Q10. The self-editing scientist (25-way).** Parts: Q1–Q9, X2 weight git, Y3 seed log, Z4 immune graph, MX1 (passed). *Claim:* a continual learner that (a) stores obligations (Q4) in self-describing addressed weights (Q2), (b) learns from verified forks forward-only (Q3), with teacher-designed experiments (Q7), (c) orders writes by commutators (Q1), (d) versions everything (X2/Y3), and (e) forgets by survival (Q8) can run an unbounded task stream without retraining. Each piece has its own first test above, and the stack is tested only after three of them pass.
