Raw proposals for one continuously pretrained lineage in harmless synthetic streams.

**PWX1. Carry a write across tokenizers only where the same effect is realizable.** Parts: NP2-01 lift byte effects, NP2-02 hidden writer state, NP2-04 contrast fibers, NP2-09 explicit refusal, NP2-11 protected reads, NP07 byte update conjugacy, PL5-10 held-out effects, D5-26 future teaching responses. *Mechanism:* Describe a write by its byte-event effects and protected sibling reads. Keep a small residual only when a contrast missing from the merged chart later changes a shared read. If the chart cannot realize the write without violating protection, defer it or split the relevant token locally. *New:* A small present-day error is not evidence that a write transported correctly: the decisive test is whether the same contrasts remain teachable. *First test:* Use synthetic ambiguous spans with one shared read and two contrasting continuations. Compare direct row transfer, byte effects with no residual and residual-aware transport on a held-out lesson.

**PWX2. Finish a byte transaction without changing its dose at a tokenizer boundary.** Parts: NP2-06 partial-token supervision, NP2-07 raw-span accumulation, NP2-08 shared optimizer, NP2-10 tied read maps, NP2-12 suspended prefix, NP10 occurrence credit, PL4-17 separate moment state, TT10 avoid double dosing. *Mechanism:* Define a training transaction by raw target bytes, carry unfinished prefix evidence across the boundary and aggregate unpreconditioned contributions before advancing shared moments. Keep chart-local residuals separate and ensure the objective never consults bytes after the subscribed endpoint. *New:* A migration can look correct on complete examples while charging part of an example twice or advancing the nonlinear optimizer an extra time. *First test:* Replay the same raw stream while changing tokenizers, worker assignments and microbatch boundaries mid-prefix. Compare final common byte effects and moment state against a no-migration control.

**PWX3. Undo a tokenizer change without undoing the training done under it.** Parts: NP2-03 order-dependent repair, NP2-05 retained byte lessons, NP2-26 correction across alphabets, NP12 reversible tokenizer pulse, NP20 interacting edits, OE5-09 order checks, L8W22 scratch round trip. *Mechanism:* Compare edits in both orders with identical bytes and final vocabularies. Store compatible lessons as byte effects and record incompatible residuals separately. Before committing a rollback, test whether it preserves a scoped temporal correction and a subsequent ordinary lesson without reintroducing a protected sibling change. *New:* Exact rollback of a chart is different from preserving learning acquired inside it; the test distinguishes which changes can survive the return. *First test:* Use toy date and value tokens that overlap after a merge. Compare checkpoint rollback, naive delta transport and checked effect replay with and without intervening corrections.

**PWX4. Withdraw one report without changing what could have been known before it.** Parts: NP2-13 rectangular writes, NP2-14 targeted withdrawal, NP2-15 atomic publication, NP2-16 report versus truth, NP2-17 frozen evidence horizon, NP2-18 out-of-order ingest, NP2-21 distinct provenance roots, NP28 bitemporal corrections, PL32 preserve independent support, CR29 versioned relearning. *Mechanism:* Stage a report's scoped changes, publish them as a unit and distinguish the historical assertion from authoritative support. Normalize repeated reports to their provenance roots and make withdrawal cancel only the relevant contribution at subsequent horizons. Audit the result under different ingest orders. *New:* A withdrawal can narrow current support without erasing the fact that one source previously asserted something or removing another source's independent evidence. *First test:* Feed a synthetic lineage repeated and independent reports, late arrivals and a partial withdrawal. Compare overwrite, chronological replay and provenance-scoped cancellation against a reference answer surface.

**PWX5. Edit a rule's scope without manufacturing certainty in its conclusions.** Parts: NP2-19 rule support, NP2-20 relation definitions, NP2-22 widened answer set, NP2-23 horizon deltas, NP2-24 temporal refinement, NP2-25 scoped authority, NP30 coherent joins, NP34 derived adoption, OE25 independent verifier, L9W14 observable predicates. *Mechanism:* Intersect premise, rule and authority scopes on both time axes. Preserve unresolved coarse cells when evidence splits a period and allow a correction to widen the valid answer set. Check derived conclusions on independently generated joins and distinguish a changed definition from a changed fact. *New:* A local patch can retire a conclusion without installing a replacement, while preserving old relation meanings and unaffected joins. *First test:* Use synthetic calendars with changing definitions, authority splits and a failed measurement. Compare per-answer edits, single-axis dating and scoped rule patches on unseen consequences and queries at multiple granularities.

**PWX6. Write one ledger for effects that must survive both alphabet changes and corrections.** Parts: NP2-01 lift byte effects, NP2-02 hidden writer state, NP2-04 contrast fibers, NP2-09 explicit refusal, NP2-11 protected reads, NP07 byte update conjugacy, PL5-10 held-out effects, D5-26 future teaching responses, NP2-06 partial-token supervision, NP2-07 raw-span accumulation, NP2-08 shared optimizer, NP2-10 tied read maps, NP2-12 suspended prefix, NP10 occurrence credit, PL4-17 separate moment state, TT10 avoid double dosing, NP2-03 order-dependent repair, NP2-05 retained byte lessons, NP2-26 correction across alphabets, NP12 reversible tokenizer pulse, NP20 interacting edits, OE5-09 order checks, L8W22 scratch round trip, NP2-13 rectangular writes, NP2-14 targeted withdrawal, NP2-15 atomic publication, NP2-16 report versus truth, NP2-17 frozen evidence horizon, NP2-18 out-of-order ingest, NP2-21 distinct provenance roots, NP28 bitemporal corrections, PL32 preserve independent support, CR29 versioned relearning, NP2-19 rule support, NP2-20 relation definitions, NP2-22 widened answer set, NP2-23 horizon deltas, NP2-24 temporal refinement, NP2-25 scoped authority, NP30 coherent joins, NP34 derived adoption, OE25 independent verifier, L9W14 observable predicates. *Mechanism:* Keep training transactions in raw bytes and corrections in scoped evidence units. Check which writes survive a tokenizer round trip, refuse effects that cannot be preserved and independently verify which dated conclusions changed after publication or withdrawal. *New:* The combined test separates changed encoding, changed learning and changed evidence without treating any one as a proxy for the others. *First test:* Run one synthetic next-token lineage through staggered tokenizer changes, late reports and partial withdrawals. Compare ordinary training, portable writes alone and the combined checked writer using shadow branches only as controls.
