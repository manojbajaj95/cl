**UWR1. Give one unchanged write a window even when the diagnostic answer differs.** Parts: UO01 pre-report intersection, UO16 common feature, BF11 spendable rank, FS09 public menu, CC13 common opening, RR01 repair and reveal, RR09 joint admissions. *Mechanism:* Choose a useful opener whose executed update opens the same later batch across the entire sealed alias set. Use its report only to clear the audit or select a separately backed fallback. Let the due opener repair a suspect fallback, while its report distinguishes which other requests can be granted together; separate grants need not compose. Certify the first sensitive native update and the served old reads on counterfactual aliases with different reports. *New:* Learning can create a common action rather than merely identify which specialized action to take. *First test:* Compare per-alias routing and exact conformant planning with masked reports, at equal old retention and useful work.

**UWR2. Borrow one old derivative and use another opened direction to repay it.** Parts: BF01 useful handback, BF02 old update law, BF19 separately spendable directions, UO05 native packet, RW04 annihilator, PX11 joint closure. *Mechanism:* Certify a useful prefix that opens two independently spendable native directions. Use one for the unchanged edit and the other for an already-owed return batch. Verify the old update law on a blind successor and retain useful edit gain rather than restoring old outputs alone. *New:* Useful work can open a route and keep a credible way to close it without a saved state. *First test:* Compare a rank-matched frozen-feature host and independent replay; plant a handback that preserves answers but corrupts old momentum.

**UWR3. Let the same useful batch brake one pocket and carry another.** Parts: BP09 dual roles, BP13 native moments, BP14 equal public read, GR04 executed Adam, WG21 clipping branch, CP13 joint adaptive image. *Mechanism:* Freeze the batch before learning which pocket is occupied. Prove its native displacement spends inward motion in one pocket and uses it to learn in the other while all served readers remain safe. Check the batch's actual numerator and denominator together, rather than averaging signed effects. *New:* An apparent incompatibility in raw slot signs may support one common useful write in serving coordinates. *First test:* Compare a reset, pocket-conditioned planning and equal-norm controls; include a threshold tie with divergent native updates.

**UWR4. Make a due batch build the bridge it needs for public clear.** Parts: BP01 due bridge, BP08 public certificate, BP17 carry versus bridge, UO13 release on expiry, DP15 overlapping service, PX04 backed return. *Mechanism:* Use one truthful edit batch to install a substitute that a live old reader actually uses. Certify a reachable bridge and a single clear across both pockets while carry remains covered. When the bridge expires, release capacity only after the next owner can serve from it. *New:* A blind edit might pay for its own clear without synchronizing hidden optimizer state. *First test:* Compare separate bridge preparation and rollback-free standby clear under a late batch and a substitute that matches scores but cannot sustain the next old update.

**UWR5. Reject any branch whose actual successor turns the gap into reader-visible error. *New:* Direction and arrival coverage can be more valuable than a smaller raw residual at entry. *First test:* Compare same-gap openers and independent contraction at matched C gain; hold out an order and a successor with adverse cross-curvature.

**UWR6. Give readiness a remaining-work budget rather than a timestamp.** Parts: UO09 legal update horizon, UO11 work drains window, UO12 repeated opening, GR13 expiring landing, IS02 moving limits, RM08 clock cost. *Mechanism:* Certify the set of allowed intervening words that preserve the same subsequent write, including ordinary old service. **UWR7. **UWR8. **UWR9. **UWR10.
