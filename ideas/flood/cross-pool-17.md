# Cross-pool merges, round 17

Focal sources: `tree/learning-without-gradients-at-inference.md` (PR #118, FG#) and `tree/agent-self-curriculum-forgetting.md` (PR #119, CU#). Crosses with forward-only and RL-OOD (#50–51), agent harnesses (#47/#52), CL-bench (#48), and older work on self-modification, neuro-inspired learning, fleet economics, and interface changes. The question is which observations the learner can acquire and reuse, not whether gradients are universally inferior. Match off-path outcomes and charge all additional forward calls. A gain on the practiced task can just recover old loss; the curriculum must also see effects on tasks it did not choose. These are raw and unfiltered.

**FCU1. Teach the agent an experiment that amortizes across skills.** Parts: FG1 experiment unlock, FG4 diagnostic cofactor, CU3 cross-task practice responses, AH4 causal query planner (PR #47), RL2 teacher experiments (PR #51), FO3 question barcodes (PR #50), Q7. *Mechanism:* Install a diagnostic tool only after measuring saved future queries for estimating cross-task effects on diverse held-out tasks. The tool can expose combinations of observations, but cannot directly alter predictions or receive a task answer. Charge its installation and compare on later tasks for which no individual probe identifies the useful edit. *New:* Experiments themselves become reusable acquired capabilities rather than merely actions selected from a fixed menu. *First test:* Use a sealed XOR-style gate stream with reusable but initially unavailable paired tests. Match observation access with a first-order host and compare to fixed diagnostics, cached answers and greedy single-probe selection.

**FCU2. Treat a one-shot observation as leased, not renewable.** Parts: FG2 renewability, FG13 event insurance, FG16 sandbox fidelity, AH8 reversible tapes (PR #47), E10 insurance (PR #45), B8 intervention budgets (PR #48). *Mechanism:* Learn which checkpoints support genuine counterfactual copies before accepting an experiment's evidence. For a nonresettable trial, pre-install an incumbent handoff on a safe prefix and buy a real calibration trial only when cheap simulation cannot determine whether that handoff still works. *New:* The learner prices lost future observations separately from trial calls and can decline a cheap experiment that cannot be safely repeated. *First test:* Use an irreversible toy workflow with deceptively replayable traces. Compare fidelity-gated probes to reset-assuming lookahead, a no-exploration baseline and fixed safe-prefix rules.

**FCU3. Transport which edits a judge can justify, not its raw scores.** Parts: FG6 probe substitution, FG7 judge bridge, FG8 contradiction docket, RL3 verifier twins and RL6 equal-value gauge (PR #51), DB7 common proof (PR #52), BR4. *Mechanism:* Before an evaluator swap, learn a small set of common intervention pairs on which both generations of judge make the same admissibility decision. Keep explicit nontransportable clauses, and use the smallest observed rank reversal to block an invalid substitution instead of refitting scores globally. *New:* A persistent learned bridge can reuse a question across judge versions without importing an incompatible ranking into a new curriculum. *First test:* Use two sealed judges related by a monotone scale change on one task and a true preference reversal on another. Compare edit errors and paid queries against score equating, fresh evaluation and unconstrained probe reuse.

**FCU4. When delayed feedback arrives, credit the experiment that made it possible.** Parts: FG14 interleaved credit, FG15 inter-call rendezvous, NB01 synaptic tagging (PR #46), SM1 seed-log autobiography (PR #43), DB1 repair wires (PR #52), Z1. *Mechanism:* Emit a reusable handle tying an intervention, its observation permission and the currently installed experimental tool to a later outcome. Crossed releases let a learner distinguish stale feedback, genuine interference and an obsolete tool. Update the capability that exposed the evidence only when a matched route without it would not expose the same credit. *New:* Delay-tolerant learning acts on the provenance of an observation channel, not the latest writer or a replayed undifferentiated reward. *First test:* Interleave three toy agent workflows and reverse feedback delays. Compare correctly assigned tool and skill credit with timestamp attribution, last-writer attribution and static replay.

**FCU5. Protect a skill by reserving the smallest joint experiment that can test its replacement.** Parts: FG17 scoped writes, FG18 atomic swap, AH9 side-effect types (PR #47), DB13 counterfactual joins (PR #52), X6, FP9. *Mechanism:* When changing two coupled ports, search for a joint write whose intermediate states would be unsafe in production. Test the full atomic candidate on an authorized copy with a fixed, independent old-harness verifier, then install it together or refuse. Distinguish tests that justify a shared commit from those that authorize only local experiments. *New:* The agent learns a minimal unit of safe experimentation and commit rather than adding a generic transaction wrapper around independent writes. *First test:* Use an object-typed simulator with two mutually dependent workflow settings. Compare joint commit, single-port gating, and conservative no-write at identical validation calls.

**FCU6. Distill a learner's inspection tool into a host that does not share its actuators.** Parts: FG19 read-only audit, FG22 smooth consolidation, FG24 alternate actuator, FO1 counterfactual compiler (PR #50), AH11 failure-preserving compilation (PR #47), P6 recompile across versions (PR #39), Q3. *Mechanism:* During distillation use the pairs that distinguish a useful experiment from an ordinary prediction. Test the compiled capability with mutations disabled before enabling writes; if the new host lacks a port, route a compatible probe through another actuator and report the lost observation coverage. Retain the source implementation only until paired transfer passes. *New:* What migrates is the ability to acquire a diagnostic contrast, not just the candidate policy or its habitual responses. *First test:* Compile a symbolic probe into a tiny model with a smaller callable tool vocabulary. Compare with normal-output distillation and direct fitting at the same test calls and storage.

**FCU7. Buy evidence before buying a backup learner.** Parts: FG10 ambiguity-priced write, FG20 fault-swappable synthesis, FG23 exclusion stencil, CU20 endogenous practice, E10 insurance (PR #45), NB20 subfunctionalization (PR #46), BR7, FP4. *Mechanism:* When a skill falters, use a low-cost forward test to separate a broken policy from a missing observation channel. Allocate independent backups only when a checked substitute can still see the evidence or use another actuator. Otherwise restore the observation path or keep an explicit gap rather than doubling the same inaccessible expert. *New:* The controller can spend budget on observable training opportunities instead of automatically treating a lack of evidence as damaged weights. *First test:* Use two cheap agents in a return-traffic world and plant independent shared-data outages and policy regressions. Compare live skill recovery and adaptation against fixed redundancy and propensity-weighted replay alone.

**FCU8. Learn which two practice lessons can safely follow each other.** Parts: CU3 practice-response matrix, CU11 excursions, CU14 interleave granularity, FG4 joint diagnostic, CD4 input shaping (PR #74), RL1 executable fork tapes (PR #51). *Mechanism:* Use fixed forward forks to estimate the additional old-task effect of ordered pairs of practice episodes after subtracting the two isolated effects. Track uncertainty on untested pairs; use the estimate to design safer blocks without changing the marginal practice mixture. *New:* Identifies sequencing harm that would be invisible to both task-frequency weighting and a one-step influence matrix. *First test:* In a tiny nonlinear extension of PR #119, plant order-sensitive pairs. Match the task histogram and compare worst excursions against shuffled order, first-order lookahead and the same pair budget selected randomly.

**FCU9. Make the task generator prove that it can still ask the old question.** Parts: CU15 proposer coverage, CU18 goal-code anchoring, FG1 experiment unlock, FG12 verifier split, RL3 verifier twins (PR #51), B4 spec-to-schema (PR #48), SM10 disagreement frontier (PR #43). *Mechanism:* Build a frozen executable goal witness and independently check the current proposer and solver using matched probes. If the proposer can no longer emit a valid old question, teach it the missing grammar production even if the solver succeeds on supplied questions; if only the solver fails, practice that skill instead. *New:* Maintenance distinguishes forgetting a skill from losing access to its training distribution, so spending all capacity on the solver need not look like success. *First test:* Use an autotelic toy where generator and solver drift independently. Compare failure localization and old-goal exposure to uniform archive prompts, ALP and proposer diversity without executable goal checks.

**FCU10. Buy a pop quiz only when it can change the practice block.** Parts: CU2 net progress, CU8 odometry, CU10 pop-quiz adversary, FG10 ambiguity-priced writes, AH4 experimental planning (PR #47), E14 commons (PR #45), BR7. *Mechanism:* Maintain a set of plausible cross-task practice responses. Let a separate examiner propose a canary whose answer might change which next block stays within every old service floor. Reserve occasional randomized audits so an unqueried slice cannot silently disappear from the uncertainty set. *New:* Sparse exams provide decision-relevant supervision across inactive tasks rather than paying curiosity for repeatedly repairing whichever task is visible. *First test:* On PR #119's conflicting teacher stream, charge canary calls and test on separate untouched assessments. Compare total-cost old retention with uniform audits, random pop quizzes, replay-on-demand and the all-loss lookahead ceiling.

**FCU11. Replace a vanished task with a practice bundle that preserves its executable obligations.** Parts: CU4 surrogate practice, CU5 drop certificates, CU13 covering composites, FG6 observation-preserving substitution, DB7 common proofs (PR #52), CF1 clause-indexed forks (PR #79), NB32 exposure masking (PR #46). *Mechanism:* Before retiring a practice environment, keep independent old-task probes and search for a combination of available practice episodes that preserves each verifier clause after an allowed sequence, not just aggregate reward. If a clause remains observable but no legal bundle maintains it, reserve explicit fallback capacity; if it cannot be observed, report uncertainty. *New:* A surrogate can maintain an inaccessible training opportunity without pretending it is a semantic replica or using positive average transfer as a certificate. *First test:* Remove one practice tool from a compositional workflow while retaining its read-only evaluator. Compare minimum-clause service against affinity-based one-task surrogates, a fixed mixture and the same forward tests without sequence search.

**FCU12. An agent that learns which questions and lessons keep each other alive.** Parts: FG1 unlock experiments, FG2 renewability, FG4 joint evidence, FG6 probe substitution, FG7 evaluator bridge, FG10 ambiguity-priced tests, FG13 handoff, FG14 delayed credit, FG18 atomic commit, FG19 read-only audit, FG22 paired consolidation, FG23 exclusion, CU1 practice measure, CU2 net progress, CU3 practice responses, CU4 surrogates, CU5 drop certificates, CU8 odometry, CU10 exams, CU11 excursions, CU13 composites, CU14 interleave, CU15 proposer coverage, CU18 goals, CU20 traffic, AH4, AH8, FO3, RL3, DB7, NB01, E14, B8, BR7, FP4. *Mechanism:* Keep a verified menu of experiments and a separate feasible set of practice plans. Acquire new experiments when they reduce the cost of choosing safe practice blocks; score practice by cross-task effects and sequencing, not gross gains on the selected task. Guard unobserved obligations with independent audits; compile useful experiments into a smaller host only after their decision boundaries survive an evaluator change. *New:* A deployed learner can improve the observation interface that supports its curriculum instead of treating the task menu and feedback stream as fixed resources. *First test:* Combine the sealed gate stream of PR #118 with conflicting practice and a drifting proposer from PR #119. Compare equal-call first-order learning given the same outcomes, uniform and round-robin practice, ALP, replay-on-demand, and the equal-budget stack of fixed diagnostics and practice-response lookahead. Report untouched old floors, new progress, sequencing excursions, and the cost of acquiring diagnostics.
