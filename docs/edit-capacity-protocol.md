# Sequential edit capacity: CPU pilot protocol

The test is whether unedited edit-key covariance predicts collapse time better than early edited-weight norm growth. Abrupt failure itself is not new ([Norm Anchors](https://arxiv.org/abs/2602.02543), [REVIVE](https://arxiv.org/abs/2601.11042)).

- **Editor:** GPT-2 small, CounterFact, one distinct subject per incoming fact, 768 facts per stream. CPU MEMIT adaptation: subject-last MLP keys, two sequential residual writes at blocks 4 and 5, and joint batched value optimization at block 5 (eight Adam steps, LR 0.5, 0.75 relative clamp, original KL and delta penalties). One canonical context per edit; second moments from a separate 2,048 CounterFact prompts with 1% diagonal shrinkage. Moment weight 256 is deliberately small for a short stress test, not the published GPT-2-XL default. All other model weights are frozen. Batch sizes 8, 16, 32.
- **Calibration and transfer:** seeds 0–2 at batch size 16 calibrate; seeds 3–8 at both 8 and 32 test transfer, with the same ordered stream at both sizes and no shared subjects between streams. Evaluate held-out predictions without refitting. Checkpoints are at multiples of 32 facts. Collapse is the first of two consecutive checkpoints where mean token NLL (equal weight per fact) on 128 separate CounterFact original-object completions rises at least ln(2) above the unedited model (2× perplexity). This is a collateral factual probe, not a broad capability benchmark. No sustained crossing by budget is right-censored at 768, not a collapse at 768. Check initial edit success (new vs. old target mean log probability on the first 32 edits at checkpoint 32); mark any run below 70% or less than 15 points over base as invalid.
- **Pre-edit law:** compute centered covariance of the full ordered stream's unedited keys at each site; set kappa = d_ff / participation rank, where participation rank is (tr C)^2 / tr(C^2). Use mean participation rank across sites, then predict c times that rank. Fit the one multiplicative constant as the median of observed calibration collapse count divided by rank. Save test forecasts before their first edit. Consequently the forecast cannot distinguish two batch sizes applied to the same stream; that invariance is part of the transfer test.
- **Norm control:** measure the joint edited weights' Frobenius norm relative to its initial value. Fit the shared log-norm threshold to the median log relative norm at observed calibration collapses. For each run fit log-norm slope through the origin using only batch-end counts within its first 10% (at most 76 facts), then solve for the threshold crossing. With no positive slope/threshold, predict no crossing. Norm is the only run-specific input to this control after the edit count, and a threshold cannot be identified from the 10% prefix alone without any collapse labels; both methods have the same calibration labels. A collapse at or before the prefix ends is an invalid forecast for the primary comparison.
- **Decision:** absolute log-count prediction error; report capacity minus norm mean error, and 95% percentile intervals from 10,000 paired bootstrap resamples of test streams (resample whole seeds, not individual batches). Report per-size transfer as well. Keep only if all planned runs are valid with observed endpoints, pooled upper CI is below 0, and capacity has lower mean error at both held-out sizes. Otherwise kill for GPU escalation. Report invalid/censored runs separately; if endpoints are missing, a budget-truncated error comparison may be descriptive but does not estimate true collapse-count error. Require at least two valid observed calibration collapses for fitting either predictor. Do not retune the editor or outcome definition on test runs.

## Calibration-only amendment

The first short calibration run had no sustained crossing by 768, but its final point first exceeded the threshold. Before running any held-out edits, extend the budget to 1,920 facts and refit both constants from fresh calibration runs at that budget. Append distinct subjects from the unused pool to each original stream. The norm prefix is now 192 facts and the law's covariance uses the full 1,920-fact unedited stream. The model, editor hyperparameters, endpoint, seeds, batch sizes, and verdict rule are unchanged.
