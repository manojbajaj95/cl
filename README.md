# Continual learning research playground

This repository is for testing how learning systems can acquire new capabilities without losing old ones. Keep hypotheses, baseline comparisons, and negative results reproducible.

- **Shared:** [frontier scan](docs/frontier-scan.md) and [research playbook](docs/research-process.md).
- **Models:** [frontier survey](models/survey.md), [research proposal](models/proposal.md), and [CPU pilot](models/pilot/README.md).
