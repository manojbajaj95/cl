# Adaptive-default escrow renewal

**Parent:** [Rolling escrow across defaults](rolling-escrow.md) ([PR #226][parent]). **Status:** Ideas only; no pilot or GPU work. [Flood triage, row 339][triage] flags parent cards **22** (certified adaptive renewal) and **21** (teach renewability) as promising directions, not established primitives. The [idea ledger][ledger] requires an old-task retention check in every first test and the best stack of the parts as a joint control.

**Verdict:** A trace-by-trace repair is not a renewal strategy, and C accuracy alone is not evidence that C finances renewal. The strongest bet is that ordinary successor training moves the learner into the *same small, service-bearing interface* from multiple reachable post-default states. That interface must let one blind controller repeatedly recover and use released backing. If independent cleanup plus ordinary order planning matches it, call this a composition; if a fixed adapter or inert spare supplies it, do not credit C.

## Contract and comparison

- **One public policy, fixed before evaluation.** Fix the host, optimizer, public observation schema, lawful actions, order-synthesis rule, offline/held-out split, and deadline and budget model before revealing blind leases. A deterministic policy maps each lawful public history to one action, the same across its reachable hidden aliases; it may change actions as public events arrive, not after inspecting a hidden slot or future default. A bounded implementation must account for its policy memory. The adversary sees the public history and can select the next allowed event after observing the public move, but cannot choose an unreachable hidden state. Batch words use only already-held truthful C batches, with the parent's matched same-history default-order endpoint tolerance, precedence and clocks. No injected cleanup steps, payload-derived supervision, donor state, hidden feedback, or reset in the candidate.
- **Ready is a service guarantee, not an empty ledger.** Fix a nonempty public menu of compatible blind pairs and arrival windows *before* synthesis. An offered compatible pair whose partners arrive on time must get useful paired service by its deadline, not just permission to reserve. If its declared window allows arrival during recovery, that obligation still applies. At an allowed default cut, preserve the live useful first write, revoke the abandoned right and start a bounded return to ready. Specify who orders simultaneous events and exactly which ordinary C opportunities and intervening default cuts are allowed during recovery; a guarantee needing a protected recovery window is conditional on that window, and default-free intervals cannot be assumed silently. Require closure under successful service as well as default. Count refused opportunities, half-use, and paired service separately.
- **What would constitute a proof.** Track sets of reachable full states consistent with the public history, refining on allowed observations after each move. In a finite abstraction, find a ready set closed under the service-and-return obligations. For each default out of that set, exhibit one public recovery choice at each step whose *every* admissible outcome is safe and decreases a bounded recovery rank (in elapsed ticks under the declared clock model) or lands in ready. Include arrivals within the stated service windows and verify resource and retention invariants at intermediate cuts. Induct on successive service/default episodes; three rounds are a minimum stress trace, not the induction. A solver must not change the action by alias, or splice incompatible hidden paths into an alleged counterexample without checking reachability.
- **Same small interface every round.** Reuse a fixed projection/schema, transition and witness contract, and proof template; values and legitimate public lease bindings may change, but not the feature map, number of registers, error allowances, or proof language per round. Test common enabled continuations and useful outputs, not raw state equality; preserve the parent's expiration and revocation accounting. Bound policy/proof bytes, token freshness, idle backing, scratch and work; report task representation separately. Use a jointly representable old-task family at fixed capacity, not indefinitely many independent bits stored for free.
- **Controls and scorecard.** Strategy controls: [#214 card 18][paired] on fixed defaults, per-trace hindsight (privileged ceiling), fresh reservations, two-phase commit, exact same-information synthesis, and an adaptive adversary targeting a non-uniform rule. Host controls: one-period tuning, [successor-funded returns][funded], [#196 card 21][handoff], random hosts at matched held-out C accuracy, and a held-out C stream that genuinely learns but breaks the interface. Cross host × controller and include the best independent stack, same-budget replay/checkpoints, and a lawful paid query/reset if available. Match truthful examples, training steps, margins, and budgets, including offline design compute, elapsed recovery, bytes, and actual use of released backing. On held-out streams, measure incoming C utility separately and check original tasks **A**, every installed write **Bᵢ**, and prior **C** tasks, with predeclared floors including rare slices. “Retention” below means this full panel at named cuts and after a common ordinary suffix, never a pooled average. Stress at least three consecutive defaults with alternating first partners, actual C progress in every round, and then a fresh blind pair.

## Paper check: two private proofs do not make one public policy

At ready `R`, a timely pair finishes before its deadline and returns to `R`. On default, assume two reachable aliases `D₀,D₁` with the same public history and one recovery move before the next service window. The live B stays above its floor in all cells of the table; failure here is a missed service window, not forgetting. Treat actions as abstract words of equal cost, not yet realizable minibatch orders.

| Recovery word | From D₀ | From D₁ |
|---|---|---|
| `left` | R | miss |
| `right` | miss | R |
| `teach` | R | R |

Without `teach`, every complete trace can be repaired in hindsight; a policy trained on default pattern 0 also appears perfect. If either alias may be selected by a reachable pre-default branch, an adversary knowing the public deterministic policy can select a branch on which its next public choice misses. This does not require inspecting the controller's future private randomness, nor changing an alias after the fact. With `teach`, the common choice returns to ready in one step after any sequence of allowed defaults, and the ready service edge closes the induction. Now add a reachable alias `D₂` with the same observations and outcomes `R, miss, miss` for `left, right, teach` respectively: the common set is empty again. The fixture tests the quantifier and counterexample checker only; it does not show that `teach` learns C, that old tasks survive real updates, or that the interface can be rebuilt. A substantive fixture must derive the transitions and aliases from real task updates in a shared host.

## Idea cards

### 01. Certify one recurring public strategy — inherited candidate (#226 card 22)
**Mechanism.** Compile a finite belief-state safety-and-return game into one public policy, with a service-and-return certificate at each ready class. **Novelty vs nearest prior art.** [Imperfect-information games][games] already supply uniform strategies and sure winning; the inherited bet is learner-generated recovery edges producing reusable ready states that preserve installed writes. **Cheapest first test.** Enumerate a two-entitlement game against the fixed-pattern #214 control, hindsight certificates, two-phase commit and fresh reservations; then admit the paper check's D₂ branch. **Old-task retention check.** Put A/Bᵢ/prior C floors on every edge, including three adaptive defaults and actual reuse by a new pair.

### 02. Make the same quotient relearnable — inherited candidate (#226 card 21)
**Mechanism.** On separate design streams, choose shared host parameters and one compact interface so real C updates repeatedly take reachable default beliefs back into a useful continuation cell. Freeze the host initialization, interface and synthesis rule before blind runs; ordinary online C updates continue. **Novelty vs nearest prior art.** [OML][oml] learns representations for sequential learning and [successor-funded returns][funded] credits useful learning for recovery; the inherited bet is induction through the *same* small ready interface with no per-round redesign. **Cheapest first test.** Enumerate order words in a tiny shared smooth host after offline fit; compare a one-period host, random hosts at matched C accuracy, #206 and #196 card 21, and a blind C stream with good accuracy that breaks closure. **Old-task retention check.** Test A/Bᵢ/prior C after each incoming C round and at the blind service cut, not only on the final host.

### 03. Give renewal a deadline-valued rank — improvement
**Mechanism.** Synthesize recovery ranks in remaining wall-clock ticks, debiting verification and longest permitted wait, not just number of optimizer steps. **Novelty vs nearest prior art.** Game attractor ranks are standard; the improvement distinguishes a verified eventual return from one that still has time to launch a pair. **Cheapest first test.** Give an identical post-default belief fast and slow return words, and vary the verifier clock until the winning set changes; compare exact timed synthesis. **Old-task retention check.** Check A/Bᵢ/prior C at both word prefixes and on the longest legal wait.

### 04. Find the weakest recovery-window promise — improvement
**Mechanism.** Vary the public arrival-of-C and overlapping-default assumptions, returning a minimal sufficient promise together with the shortest reachable spoiling trace below it. **Novelty vs nearest prior art.** Assume–guarantee games already synthesize environment assumptions; the useful output here is the priced training availability that an escrow guarantee actually needs. **Cheapest first test.** Sweep the spacing of two truthful batches and the cuts where a second pending lease can default; compare a declared tick bound with a hidden fairness premise. **Old-task retention check.** On both sides of the boundary, check the prior C skills and A/Bᵢ even where paired service is impossible.

### 05. Admit a second pair only with a recovery proof for both orders — primitive candidate
**Mechanism.** Let two leases overlap only if a single certificate covers both orders of exposed defaults and still reserves an on-time C word for a surviving pair. **Novelty vs nearest prior art.** The [parent][parent] bounds overlap and proof cycles; the candidate is an admission witness for future *interleavings*, not just a simultaneous resource count. **Cheapest first test.** Enumerate overlapping windows with one held C batch that can be spent only once; compare serial, independent reservations and exact joint synthesis. **Old-task retention check.** Check A/Bᵢ/prior C after the first default of either lease and again at the survivor's actual dispatch.

### 06. Price a smaller public controller — improvement
**Mechanism.** Minimize the finite controller on reachable beliefs while preserving all choices needed for return and timely service, and count its registers as live escrow bytes. **Novelty vs nearest prior art.** [Imperfect-information games][games] already track knowledge and strategy memory; this isolates the cost of remembering which renewal obligations remain, independent of the physical backing. **Cheapest first test.** Plant two aliased current summaries whose public default histories require different words; compare a stateless rule, bounded controller and full public log. **Old-task retention check.** Compare the compressed controller and history-aware ceiling at the first merged cut and after the next ordinary C update.

### 07. Preserve the option, not a canonical internal path — primitive candidate
**Mechanism.** Expose a fixed table of usable service options: which pairs can be served within each remaining clock class, plus their public action and return proof. Let different hosts or rounds use distinct internal trajectories behind the same options. **Novelty vs nearest prior art.** [Approximate bisimulation][bisim] relates dynamics; this candidate equates certified external service options while allowing internally distinct recovery trajectories. **Cheapest first test.** Build two renewal paths with different private momentum traces but identical public timed options; introduce a near-identical alias missing one option. Compare full transition matching and exact same-information planning. **Old-task retention check.** Run A/Bᵢ/prior C on each path and on the option lost by the decoy.

### 08. Make counterexamples executable in the learner — improvement
**Mechanism.** Replay a spoiling belief path as a tree of lawful histories, each with concrete batch IDs, clocks and old-task outcomes; refine only spurious aliases. **Novelty vs nearest prior art.** Counterexample-guided abstraction refinement already checks feasibility; here it prevents declaring either recovery or impossibility from optimizer states assembled from contradictory histories. **Cheapest first test.** Mask a public data cursor and plant an impossible mixed-prefix path alongside a reachable missed deadline. **Old-task retention check.** Verify A/Bᵢ/prior C on each realizable branch, not on a fabricated combined state.

### 09. Compose default recovery with successful service — primitive candidate
**Mechanism.** A lease receipt proves both exits re-enter the same successor contract: a successful pair must renew even if the eventual default lands in the round immediately after a success. **Novelty vs nearest prior art.** [Paired escrow][paired] and the [parent][parent] prove individual exits; the candidate is a cross-exit induction premise that prevents success from spending the next default's last recovery option. **Cheapest first test.** Compare a default-only proof with a complete game in which three defaults pass but success → default exhausts one carrier. **Old-task retention check.** Protect both newly installed B writes as well as A/earlier Bᵢ/prior C through the mixed sequence.

### 10. Teach the recovery basin, not the endpoint — primitive candidate
**Mechanism.** Offline train on reachable post-default beliefs and penalize missing certified routes into the ready interface, even when endpoint C losses tie. **Novelty vs nearest prior art.** [ANML][anml] meta-learns plasticity; the different objective is universal route availability under a fixed public action language and a deadline, not average expected retention or a Gramian forecast. **Cheapest first test.** Fit equal-width quadratic or tiny smooth hosts on varied default cuts, then compare exact out-of-design winning sets against retention-matched OML and one-period tuning. **Old-task retention check.** Match A/Bᵢ/prior C at installation and test them throughout the worst winning route, not only inside the basin.

### 11. Swap in equally useful C updates that do not renew — improvement
**Mechanism.** Compare two orders of the exact truthful batch multiset with the same endpoint tolerance and matched C progress but different effects on the verified continuation; intervene on order, not a guessed latent “progress” score. **Novelty vs nearest prior art.** [Successor-funded returns][funded] already compares useful training and substitutes; this assay repeats the substitution after adaptive defaults and checks that the *same* interface and released carrier are affected each time. **Cheapest first test.** Seek a matched order pair at two separate default cuts; count a no-progress/no-op comparator only as a negative, not the strongest baseline. **Old-task retention check.** Match A/Bᵢ/prior C at every intermediate cut for both orders; reject an apparent financing gain funded by forgetting.

### 12. Require two different kinds of C to fund one interface — primitive candidate
**Mechanism.** Fit the host so two distinct successor task families each have lawful updates that rebuild the same ready registers and paired witness contract, without seeing a task-family tag at dispatch. **Novelty vs nearest prior art.** [OML][oml] transfers representations; this asks for transfer of a certified future action interface, holding reordering and memory contracts fixed. **Cheapest first test.** Train on mixtures of two feature rotations, hold out a third composition and randomize stage lengths; compare a task-ID oracle and matched separate adapters. **Old-task retention check.** Retest both historical C families and A/Bᵢ after switching directions and after the next lease uses the carrier.

### 13. Move private slot differences into a useful shared feature — primitive candidate
**Mechanism.** Let C update a shared representation so hidden-slot differences need not shrink but their effect on permitted service moves into the fixed renewal equivalence. Require that the feature actually carries incoming C and a later B witness. **Novelty vs nearest prior art.** [OGD][ogd] avoids changes that harm old outputs, and the [parent][parent] prepares a blind cell; here the candidate is restoring a reusable equivalence with a feature whose useful predictive content is exercised by both live jobs. **Cheapest first test.** Search a two-feature shared host with no permanently isolated slot; ablate the shared feature and compare projected updates and an always-masked spare at matched width. **Old-task retention check.** Test support-sensitive A/Bᵢ/prior C at every prep prefix and after a normal slot-coupled suffix.

### 14. Make the interface outlive a change in phase — primitive candidate
**Mechanism.** Train against cut-and-splice design streams: resume from lawful intermediate C clocks, change successor length, and require the same interface without a learned round-index lookup. **Novelty vs nearest prior art.** The [parent][parent] already considers nonstationary quotients; the distinct test is whether *one frozen learned map* rebuilds without the fixed phase used during offline optimization. **Cheapest first test.** Hold out irregular interleavings of short and long C tasks; compare phase-tagged, single-period and adversarially mixed training at equal offline compute. **Old-task retention check.** Retest A/Bᵢ/prior C before and just after splicing, after recovery and after the next ordinary suffix.

### 15. Expose the minimum amount of C that can pay for return — improvement
**Mechanism.** Enumerate lawful prefixes at a fixed clock and test their actual incoming C gain and readiness; report the first prefix that satisfies both, including irreducible gaps. **Novelty vs nearest prior art.** [Successor-funded returns][funded] charges recovery and C work; this draws a per-cut feasibility frontier rather than predicting future plasticity from norm or rank. **Cheapest first test.** Compare equal-work prefixes on two C streams, one with real early progress but no ready interface until after the service deadline. **Old-task retention check.** Record A/Bᵢ/prior C floors on each prefix, particularly the first timely candidate and the rejected late option.

### 16. Require C to repurchase approximation slack — primitive candidate
**Mechanism.** Keep a bounded public error budget in the fixed interface. A C word can replenish slack only if a verified map contracts *all* reachable aliases enough to pay for error growth through the next lease. **Novelty vs nearest prior art.** [Approximate bisimulation][bisim] supplies error bounds and the [parent][parent] proposes nonrenewable error; the candidate is a truthful C-funded replenishment proof, not resetting measured error at round boundaries. **Cheapest first test.** Compute reachable intervals in a scalar output with a C contraction and a normal expanding step; compare no contraction, observed-error reset and exact reachability. **Old-task retention check.** Check worst-case A/Bᵢ/prior C at maximal expansion, not just average error at ready.

### 17. Separate learned safety from a fixed retention shield — improvement
**Mechanism.** Freeze a shield that enforces old-task floors and check whether the offline-trained host still expands the renewably serviceable region behind that same shield. **Novelty vs nearest prior art.** [Safe RL via shielding][shield] enforces safety; the comparison asks whether C adds *liveness*, not whether a stricter guard can make failures disappear. **Cheapest first test.** Cross random/learned host with shield-only/renewal controller, and require logging of refusals against the frozen service menu. **Old-task retention check.** Apply the identical A/Bᵢ/prior C panel to refused, accepted and post-default states including rare protected slices.

### 18. Release a carrier only after proof of cold reuse — primitive candidate
**Mechanism.** Bind the ready certificate to one or more predeclared resource footprints, then require a blind successor pair to spend the liberated backing rather than a spare. **Novelty vs nearest prior art.** The [parent][parent] demands usable reserves; this proposal binds its release to a recurring C-generated interface plus observed cold consumption, distinguishing reclaim from reclassification. **Cheapest first test.** Fill both carriers; compare coupled training with garbage collection plus independent prep under the same scratch ceiling, and plant one live old reader. **Old-task retention check.** Exercise that reader and all A/Bᵢ/prior C before release, after the new write, and after a normal update probes the reused carrier.

### 19. Make a late message an adaptive test of the same interface — improvement
**Mechanism.** Include an allowed stale arrival as an adversary move at each legal publication cut, including after C has rebuilt readiness. **Novelty vs nearest prior art.** Freshness/ABA defenses and the [parent][parent]'s wrapping-token check already reject stale rights; this is a joint stress test that a later learned ready state can't silently reuse an old grant. **Cheapest first test.** Use a deliberately tiny generation field with a declared delivery bound, test both sides of expiry, then drop the bound and demand a counterexample. **Old-task retention check.** Run A/Bᵢ/prior C with the late message present before and after the rightful new pair consumes backing.

### 20. Find the cheapest adversarial C shift that breaks renewal — improvement
**Mechanism.** Search a predeclared held-out task family for the least distributional or sequence change that preserves ordinary C utility but defeats the fixed interface. Do not patch evaluation failures by retraining or narrowing coverage. **Novelty vs nearest prior art.** Robustness stress tests are standard; the contrast isolates renewable service from ordinary generalization and can disprove the second reviewer bet without a forgetting confound. **Cheapest first test.** Enumerate feature rotations and precedence permutations within a held-out family, and compare a small-interface host with a wider same-budget controller. **Old-task retention check.** Report whether A/Bᵢ/prior C still pass on the exact first breaking history; label joint failures as such.

### 21. Learn the host on strategy switches, not on a winning trace — primitive candidate
**Mechanism.** Alternate offline host updates with solving the same public game over reachable default branches; optimize for a winning policy on each design game, not repeated imitation of the oracle move on each private trace. At deployment use the frozen synthesis rule and observable inputs only. **Novelty vs nearest prior art.** [OML][oml] and adversarial training optimize hosts against task variation, and [games][games] synthesizes strategies on given transitions; the bet is shaping actual C transitions so previously incompatible recovery choices gain a common public word. **Cheapest first test.** Use a four-word tiny learner; contrast training against full belief obstructions versus hindsight labels, fixed adversary patterns and independently stacked meta-training plus synthesis. **Old-task retention check.** Enforce the A/Bᵢ/prior C floors on all aliases where the newly common word becomes available.

### 22. Try to compile away the coupling — improvement
**Mechanism.** Give independent cleanup and order synthesis the same learned training budget, observations and verifier, and ask whether separate host and controller objectives can reproduce the coupled certificate. **Novelty vs nearest prior art.** The [parent][parent] already proposes compiling away coupling; this comparison isolates transfer to adaptive defaults and unseen C in a host × controller ablation. No primitive claim if matched independent components reproduce it. **Cheapest first test.** Exhaust the small game's action sets for each host, including random and one-period arms, and locate the first reachable state where only the coupled arm can offer more timely service or spend less budget. **Old-task retention check.** Match A/Bᵢ/prior C on that separating branch, through three rounds and after the common ordinary suffix.

## Ranked deeper questions

1. **Can the same truthful C work buy a genuinely new winning branch?** Start with 01/02/11/18/22. Derive live aliases from ordinary updates; require C progress to restore the same ready interface and an actual blind pair to spend the released backing. Refute the joint claim if the best equally resourced independent stack does the same, or if a matched useful C update makes no difference to renewal.
2. **What is the weakest public contract under which one policy really serves?** Use 03–06/08/09. Prove response bounds and return/serve closure over the exact adaptive move order and legal cuts. Show the first reachable counterstrategy after weakening a recovery-window promise; use hindsight only as an oracle control.
3. **Can one small frozen interface transfer beyond a learned cycle?** Use 07/10/12–14/20/21. Hold out the round lengths, C mechanisms and default patterns; require the same map and proof template to certify unequal raw states, useful paired service and per-skill floors. Treat a C-accurate held-out stream that fails closure as a real negative.
4. **What pays the bill over repeated defaults?** Use 15–19. Bound interface error, token freshness and proof/policy/learner memory under actual use, not after benign garbage collection. Find the earliest boundary where a legitimate overlap, stale arrival or high-error suffix makes ready unattainable without more resources.
