# Self-invented vocabulary for continual learning

**Parent:** the vocabulary branch of [breadth outside edit theory (PR #115)](https://github.com/manojbajaj95/cl/pull/115). **Node question:** Can a learner notice a distinction it cannot express economically, coin a word or code for it, teach its future self and its peers to use it, and still understand and act on what its old words meant?

**Claim to test:** A growing lexicon can be a substrate for continual learning, not just cheaper tokenization. A successful coinage makes a newly grounded distinction usable in unseen cases after the teaching context is gone. A stronger result is **grammaticalization**: a word for a thing or procedure becomes an operator on other meanings, while its literal use remains available. The object being learned is a convention for talking about and acting in the world, not an equivalence class of weight edits. All cards below are hypotheses; no new probe was run.

## What prior work rules out

- **Frozen weights are not a retention guarantee.** In [PR #115](https://github.com/manojbajaj95/cl/pull/115), adding five shared-softmax output rows and training only those rows reduced old-task accuracy from **95.6% to 81.8%** in a toy softmax regression. Penalizing drift in the log partition on unlabeled old anchors kept **94.1%** old accuracy and **98.0%** new accuracy; the separate-head selector kept **82.3%** old accuracy. With fixed old logits the old-token NLL change is exactly the log-partition change, but the accuracy result is empirical. Treat this as a required control, not evidence that adding or conserving tokens teaches new concepts. In a neural implementation also check input resegmentation; the same raw old prompt need not produce the same token sequence.
- **An extra embedding, macro or private code is not the novelty.** The [idea ledger (PR #6)](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/idea-ledger.md) killed B2 (frozen prompt pools and ToolkenGPT cover it), shelves jointly learned private memory shorthand as a moonshot, and requires an equal-compute single-refiner control for iterated lessons. It also found no self-writer advantage for self-quizzing replay. The [cognitive-science flood](https://github.com/manojbajaj95/cl/blob/devin/1795539368-cogsci-flood/ideas/flood/cogsci.md) already proposes chunking with boundaries (C18) and a vocabulary spurt (C38); [PR #122](https://github.com/manojbajaj95/cl/pull/122) covers conservative grammar changes and overload checks. Do not count renaming a stored routine, exact save/restore, or blocking a new code everywhere as a win.
- **The closest external controls already coin, ground or transmit words.** [Neologism Learning](https://arxiv.org/abs/2510.08506) fits new embeddings in a frozen model on supplied concept examples, tests self-verbalization, and jointly learns multiple neologisms. [Convention Formation](https://arxiv.org/abs/2508.06482) post-trains models to form shorter in-context references. [NeLLCom-Lex](https://arxiv.org/abs/2509.22479) starts with an existing language and changes communicative demand to study lifetime shifts in color naming. [DreamCoder](https://arxiv.org/abs/2006.08381) already learns reusable abstractions and generates practice. The proposed differences are the **specific interventions in the cards**, tested on sequential concept arrival, delayed use, and old-task retention together. This is a targeted overlap check, not a claim that the whole space is new.

## One cheap arena and one gate

Start with a Python reference-and-action game. Two agents see different views of small worlds and use messages to select objects or act. Early rounds establish an ordinary vocabulary and a set of old tasks. Later, the environment makes previously irrelevant relations matter: e.g. pick the object that will remain reachable after a gate shuts, then apply the same distinction to a held-out route or container. Supply observations and action feedback, not names, definition templates for the arriving concept, change points, or new concept IDs. The learner must choose **what** to name and generate the teaching events; the environment can score or reject a teaching claim. Keep evaluator labels and sealed probe contexts out of training. Update only after each scored event. Hold out world families and compositions, and interleave old tasks, long gaps, and no-change streams. Small table learners, finite-state interpreters or tabular agents suffice for most first tests.

Compare against fixed-language paraphrase/retrieval, a frequency-matched phrase compressor or macro library, and supplied names or definitions as separate diagnostic oracles. Where a card names a baseline, include it even if it beats these defaults. Match model capacity, observations, and permitted feedback; count lexicon storage, context/transmitted bits, practice and environment calls, recipient adaptation, and any additional inference. If budgets trade off, show the frontier. Score prequential decisions on held-out concepts and **bidirectional** use (produce the code from a novel situation, understand it in a novel instruction); require autonomous use after dropping the teaching transcript. Intervention tests should compare removing or swapping a code to a length- and frequency-matched placebo. If either fixed-language retrieval or a phrase macro ties the claimed gain, report it as retrieval or compression, not new concept learning.

For every first test, score **normal old tasks** from unchanged raw inputs with the ordinary decoder/router, not a forced old head. Separately score old references and actions in both old-only and mixed old/new contexts; where a sense legitimately changes, test the old meaning in its original setting, not against the new truth. Report the weakest old cohort, old-output NLL or false-new emissions where applicable, and first-return success after a gap. A useful pilot would predeclare a small retention allowance (e.g. at most two percentage points lost per old cohort), a positive matched-budget effect on the named new endpoint, and use at least five paired independent streams before interpreting a seed-sensitive gain. The allowance is a proposed gate, not a result.

## 22 idea cards

### A. What deserves a word?

1. **Name the decision boundary.** **Mechanism:** Propose a symbol from near-identical states where the same old description leads to opposite successful actions; teach it on the smallest state contrast found by intervention. **Why it might be new:** The birth criterion is a repeatable failure of the old language to support a decision, not span frequency or a supplied class. **Cheapest first test:** In 32 gate worlds, compare against equal-feedback supervised predicate induction with ordinary paraphrase and against phrase mining; score transfer to a different visual layout. **Old-task retention:** Re-run routine route and object commands, especially on the mined contrast states where the legacy action does not depend on the gate.
2. **Pay rent in future teaching.** **Mechanism:** Grant a temporary word a permanent slot only if learners using it need fewer demonstrations to learn later tasks; estimate savings on online successor tasks compared to a same-length alias. **Why it might be new:** Admission buys sample efficiency for other knowledge, not compression or reward on the task that minted the word. **Cheapest first test:** Stream three families over shared predicates; compare delayed-benefit admission with conventional minimum-description-length admission at equal stored bits, then hold out the fourth family. **Old-task retention:** Re-run first-family tasks and literal descriptions after the slot budget forces a choice.
3. **Coin an intervention-invariant kind.** **Mechanism:** Give the same word to different observations only when intervening on each instantiates the same downstream change across mechanisms; train a reader to predict that change from the word. **Why it might be new:** The symbol names a transferable causal role, not an observed cluster or a cached execution trace. **Cheapest first test:** Introduce two unrelated mechanisms that block a route; randomize their visual correlates and hold out a third mechanism. Compare causal-feature induction with and without the coined name, using equal interventions and message bits. **Old-task retention:** Check ordinary navigation and old causal commands in worlds where the new role is absent or deceptively correlated.
4. **Coin the hole, not its answer.** **Mechanism:** When different cases fail under the same missing piece of information, mint an interrogative code with a learned answer type; future selves use it to request the cheapest discriminating observation. **Why it might be new:** The new lexical item denotes what the learner needs to know, not a fact it already retrieved. **Cheapest first test:** On a partially observed tabletop game compare learned question words with equal-length fixed uncertainty tags and a generic active query policy with the same information budget; hold out a new object family. **Old-task retention:** Score familiar questions and normal actions without follow-up, including how often the learner wrongly stops to ask.
5. **Mint an exception word before splitting the parent.** **Mechanism:** Learn an exception concept from cases that violate a productive default, then let the exception generalize across several defaults only if its operational consequence repeats. **Why it might be new:** Unlike PR #115's token split, the child is a reusable cross-category override, not a second embedding for one old sense. **Cheapest first test:** In a symbolic packing task, introduce one failure mode across two item families; compare with a per-class split plus a shared exception rule and test a third family. **Old-task retention:** Score unexceptional base cases with and without the new exception cue, and old families with their existing exceptions.
6. **Split naming signals across observers.** **Mechanism:** Two learners with complementary observations propose partial names; keep a joint code only when neither observer's view suffices and successive users can infer the combining rule. **Why it might be new:** The collocated fragments express a relational concept no single learner could propose from its own samples, rather than voting on prewritten labels. **Cheapest first test:** Use paired binary cues whose interaction determines a feasible route; compare raw cue exchange plus centralized rule learning at the same bit and feedback budgets and test held-out cue layouts. **Old-task retention:** Check each observer's independent tasks and legacy two-party instructions when the other observer is unavailable.

### B. How can a learner teach itself the meaning?

7. **Teach with meaning collisions.** **Mechanism:** Ask a student initialized from a pre-coinage snapshot to interpret the code; choose minimal pairs that separate its top competing meanings and obtain outcome feedback before practice. **Why it might be new:** The curriculum is targeted at ambiguities of a specific recipient, not a claim that self-authored QA is better. **Cheapest first test:** Use finite hypothesis classes with correlated shape and affordance; compare uncertainty sampling and a teacher choosing pairs without student predictions, with equal queries. **Old-task retention:** Test the recipient on its original shape and affordance tasks after it adopts the code.
8. **Exchange roles before admitting a word.** **Mechanism:** Alternate producer and consumer, each seeing only its own view, and accept a word only when both roles succeed after the transcript is cleared. Include word-swap failures as feedback against private shortcuts. **Why it might be new:** Reciprocal use during continual admission is the proposed lever; ordinary sender–receiver reward admits brittle one-directional codes. **Cheapest first test:** In a small partially observed reference game, compare tied bidirectional training with and without role exchange, matching feedback and training steps; evaluate new partners and roles. **Old-task retention:** Evaluate both roles on old instructions with the new code live and distractors that could trigger it.
9. **Teach from reachable consequences, not plausible paraphrases.** **Mechanism:** Generate practice by searching for cases where substituting an old expression for the new word changes what the listener can do; score that contrast in the environment before training. **Why it might be new:** DreamCoder-style practice supplies solvable cases; the proposed selection signal is divergent consequences of competing linguistic expressions. **Cheapest first test:** In finite-state planning, compare consequence-targeted generation with rollout-verified random practice and retrieval of the same number of hard examples. **Old-task retention:** Replay normal old instructions and measure spurious action changes on cases where the expressions remain interchangeable.
10. **Give each word a teachable counterexample.** **Mechanism:** Store a compact, playable negative example with each word, chosen to make its closest wrong interpretation fail; regenerate positive practice from the entry and a simulator. **Why it might be new:** A lexical entry has a runnable non-example rather than just a definition, and the hypothesis is delayed disambiguation per stored bit. **Cheapest first test:** Remove all transcripts after introducing new predicates; compare a definition plus a boundary counterexample with the same bytes spent on positive examples or contrast retrieval. **Old-task retention:** Score archived ordinary instructions and old-versus-new minimal pairs, not just reconstruction of the stored examples.
11. **Keep the lesson, forget the local code.** **Mechanism:** Distill several independently coined dialects into a learner that can infer the common concept from a handful of cross-dialect contrasts without storing their word mappings. **Why it might be new:** The consolidation target is how to infer a concept from convention variation, not majority agreement on a code. **Cheapest first test:** Compare independently grounded dialects, permuted duplicate dialects, and single-dialect refinement at equal total data and interactions; test fast induction in a fifth, unseen dialect. **Old-task retention:** Measure old plain-language tasks and old dialect comprehension before and after the meta-update, without granting an oracle dialect ID.

### C. Can words develop grammar without losing their original senses?

12. **Promote a noun to an operator.** **Mechanism:** When a concrete word repeatedly occupies a slot in a construction, hypothesize a typed operator whose argument is the rest of the utterance. Teach the distinction with situations where the literal and operator readings prescribe different actions. **Why it might be new:** The bet is that a grounded literal meaning bootstraps a productive operator faster than learning the same operator from scratch, not that adding a grammar production is new. **Cheapest first test:** Start with a word for a physical shield, then let it become a modifier requiring the action to preserve one resource; compare a coined operator from scratch and DreamCoder-style abstraction with the same literal data and search budget. Test held-out verbs and objects. **Old-task retention:** Test picking up the physical shield, literal uses inside mixed utterances, and ordinary actions without the modifier.
13. **Invent a marker for the source of a belief.** **Mechanism:** Induce a reusable affix for claims supported by indirect evidence when the distinction changes how a recipient should act. Teach it across grounded predicates, not as a fixed confidence score. **Why it might be new:** The marker is productive evidence provenance, not a calibrated confidence scalar or a free-standing label for one outcome. **Cheapest first test:** Put agents in worlds where directly seen and inferred facts have the same confidence but different action costs; compare fixed provenance tags and verbal evidence summaries at equal message budgets on held-out predicates. **Old-task retention:** Recheck bare factual reports and the old distinction between uncertainty and denial, including confidence-matched examples.
14. **Let repair sequences fossilize into syntax.** **Mechanism:** Mine recurring corrections where an ambiguous multi-action message takes the wrong scope, then conventionalize the shortest recurrent repair as a scope marker generic across verbs. **Why it might be new:** Syntax induction is driven by observed failed interpretations and repairs, not by frequent surface substrings or a supplied grammar. **Cheapest first test:** Run a two-operator action game where operator order matters; compare repair-driven grammar induction, frequency-driven grammar induction with the same logs, and explicit parentheses. Test unseen three-operator nests. **Old-task retention:** Re-run old single-operator and previously unambiguous multi-step commands with no markers.
15. **Form a productive family from near-misses.** **Mechanism:** When separately grounded words vary regularly along a feature, propose a stem and affix only if swapping the affix changes the intended feature while leaving the others intact. **Why it might be new:** Promotion to a morpheme depends on outcome interventions, not compressibility of the word forms or a predefined factorization. **Cheapest first test:** Stream independent and spuriously correlated object features; compare BPE, a flat learned lexicon, and standard compositional-code learning with the same feedback. Test missing stem–affix cells. **Old-task retention:** Decode original full words, including irregular exceptions, and perform old actions after the factorization.
16. **Learn a reusable construction from an initially fixed phrase.** **Mechanism:** Treat a coined multiword expression as fixed until operand substitutions repeatedly preserve its effect; then promote the supported slot to a construction and teach contrasting substitutions outside its domain. **Why it might be new:** The claim is delayed slot opening helps under shifting evidence, relative to library induction that can generalize the original phrase immediately. **Cheapest first test:** Use a stream where held-out operand types arrive in two waves, one misleading; compare fixed macros and equal-budget grammar induction allowed to open slots at any step. **Old-task retention:** Test original idiomatic uses and old literal readings of the same phrase in independent contexts.

### D. Can words travel across agents and time?

17. **Ship a micro-world instead of a glossary.** **Mechanism:** Package a few interactive states and outcome contrasts as the onboarding payload for a foreign learner to infer how to use a word in its own language. **Why it might be new:** Portability is measured by correct action using a portable experience, not paraphrase agreement or transfer of a token embedding. **Cheapest first test:** Give strangers a word with either an interactive micro-world, an explicit definition, or static positive/negative pairs at equal transmitted bytes and environment-call budgets; test translation into differently observed worlds. **Old-task retention:** Measure recipients' old task success and whether they still correctly interpret any pre-existing homonym after onboarding.
18. **Let a newcomer force a shared abstraction.** **Mechanism:** A newcomer with a third observation view mediates two dialects and may invent a bridge word whose grounding works in all three; adoption requires independent task success, not direct name matching. **Why it might be new:** A new participant can reveal a shared causal role missed by bilateral translation. **Cheapest first test:** Compare three-view bridge invention with pairwise bilingual dictionaries and a centralized learner given the union of views and the same communication budget; test a fourth view. **Old-task retention:** Score each pair's old local conventions without the mediator and check old/new code-switching.
19. **Learn when not to use jargon.** **Mechanism:** Train a speaker to offer a code, paraphrase, or request confirmation based on a model of what the specific listener has learned; update from repair outcomes rather than explicit proficiency flags. **Why it might be new:** This is primarily an improvement to convention use; the discriminant is calibrated audience-specific production over repeated growth and partner turnover, not shorthand adoption in one conversation. **Cheapest first test:** Rotate peers with unknown histories; compare full paraphrases and standard listener-belief tracking over supplied codes at equal message/repair budgets. **Old-task retention:** Score ordinary instruction following with novice, returning, and mixed-proficiency peers, including the first utterance after turnover.
20. **Decide which old sense needs an explicit marker.** **Mechanism:** Keep literal and drifting uses available, but learn to add a public disambiguator only in contexts where mixing listeners' histories changes execution. Learn the marker from successful repairs rather than providing version IDs at inference. **Why it might be new:** The hypothesis is that ambiguity itself teaches where marking belongs; an explicit version or context-routed token split is the control, not the result. **Cheapest first test:** Alternate two conventions for an old word, then interleave both; compare always-on version tags and a context split plus clarification at equal cumulative communication cost. **Old-task retention:** Score unmodified archived utterances with their original visible context; report the irreducibly ambiguous subset separately and score successful clarification there.
21. **Retire the word but retain the ability to relearn it.** **Mechanism:** Spend a fixed archival budget on a few grounding contrasts and preserve a shared inference procedure instead of keeping a full old code row for each dormant word. **Why it might be new:** Unlike tombstones or redirecting keys, remaining capacity is intended to support reconstruction of actionable meaning during recurrence, not exact lookup. **Cheapest first test:** Evict half the words in a ten-regime stream; compare same-byte episodic retrieval, tombstones where affordable, and fresh induction, while charging any delay and queries. **Old-task retention:** Score old tasks before and after eviction, first unaided return separately from reacquisition, and failure to recover rare senses.
22. **Make the unit of storage a family of translatable dialects.** **Mechanism:** Maintain a grounded root and compact learned transformations for local daughter words; shared concepts can change in different directions without rewriting other branches. **Why it might be new:** This is a primitive only if unseen cross-dialect tasks can compose translations from the transformations at lower total cost than independent dictionaries or a global language. **Cheapest first test:** Simulate branching dialects with partially shared semantic changes; compare flat tables, a learned global interlingua, and a factored dictionary with the same bytes and feedback. **Old-task retention:** Evaluate both the original tasks and later branch-local tasks after new branches form, including an old branch encountered through an unfamiliar route.

## Deeper sub-questions (ranked)

1. **When does inventing a word make a new distinction learnable, rather than merely cheaper to write?** Cards 1–3 contrast a causally grounded new symbol with ordinary paraphrase, matched aliases, and concept learners that already found the same feature. Look for a teaching- or transfer-efficiency gain after charging the whole lifecycle and swapping the code as a causal control. This is the strongest test of whether lexicon growth is learning at all.
2. **Can literal knowledge bootstrap genuinely productive grammar?** Cards 12–16 ask whether a grounded word can become an operator that works with unseen operands earlier than equally informed grammar induction. A clean discriminator is the interaction between prior literal exposure and new-syntax learning, with both literal and new uses tested on the same live system.
3. **What is the minimum teaching interaction for a code to survive its inventor?** Cards 7–11 and 17 compare role exchange, targeted negative examples, and portable micro-worlds against the same amount of static teaching. A decisive failure would be success only with the original partner, on self-generated practice, or while the teaching transcript remains in context.
4. **Which old distinctions can survive without a second copy of the old language?** Cards 19–22 ask how much history, contextual marking, or repair is necessary under incompatible usage. If the same observable utterance and context require different actions, no deterministic reader can keep both without extra information. The research target is how to acquire and spend that information selectively, not to beat the bound.
