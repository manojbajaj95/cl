# Learner–world co-evolution (depth 7): payload-in-world / pointer-in-weights & compile-and-evict plasticity recovery

Child node (depth 7) of [PR #370](https://github.com/manojbajaj95/cl/pull/370) (`L7W04` + `L7W07`) · 26 concrete mechanism cards (no metaphors) · Ideas only; no experiments run

**Parent triage.** In `reviews/flood-triage.md` (row 512, PR #370 / `tree/learner-world-coevolution-7.md`), two score-3 mechanisms were kept while OS/hardware analogies (`L7W01`–`L7W03`, `L7W05`, `L7W08`, `L7W14`, `L7W19`–`L7W22`) were pruned:
1. **`L7W04` — keep the payload in the world and a pointer in the weights:** the external guard holds a skill's high-entropy operational logic while the weights retain only a compact wake pointer that reconstructs the behavior from the guard in one step—the concrete mechanism that can beat both *equal-byte replay* and *equal-byte stored rule-text retrieval*.
2. **`L7W07` — compile a learned skill out of the weights into a deterministic external check, then evict it to recover plasticity:** once a crisp prevention rule is learned in weights, synthesize it into an external deterministic artifact (validator, unit test, AST/regex check), *actively evict its parameter subspace* to reclaim capacity for new tasks, and keep only a 1-step fallback trace—coupling tool creation directly with deliberate weight eviction.

**Why this node focuses on concrete mechanisms, not analogies.** Two sharp technical barriers separate `L7W04` and `L7W07` from existing work:
- **Against LATM / Voyager skill libraries:** existing tool-making agents ([LATM](https://arxiv.org/abs/2305.17126), [Joint Tool Creation](https://arxiv.org/abs/2608.24571), [Dynamic Agent Skills](https://arxiv.org/abs/2607.10113)) write external tools *without evicting the skill from model weights*, so they never recover parameter plasticity. Meanwhile, naive continual machine unlearning *causes* plasticity collapse ([Plasticity Collapse in Continual Machine Unlearning](https://arxiv.org/abs/2608.29513)) rather than curing it! Thus `L7W07` requires a **plasticity-restoring eviction operator** (null-space reinitialization, synaptic role partitioning, equivalence verification).
- **Against equal-byte replay & rule-text retrieval:** a static text prompt or replay buffer must store the rule's payload internally. `L7W04` exploits an *executable external guard* $G(x)$ plus *small Forget-Retain Alignment Gap* ([Distance Is Not Enough](https://arxiv.org/abs/2608.25429), inverted constructively!) so $O(d)$ pointer floats reconstruct arbitrarily high-entropy rules in 1 step.

## Section A · Payload in the World, Pointer in the Weights (`L8W01`–`L8W09`, deepening `L7W04`)

### L8W01 · Executable-oracle boundary probing (1-step rebuild from a live guard vs. static rule text)
- **Mechanism:** Storing a rule as static text fails when rule entropy $H(G)$ exceeds the byte/context budget; storing a pointer to a *live executable guard* $G(x)$ exploits oracle access. Store a compact $m$-float *boundary-probe generator seed* $z_F$ in weights; when reconstructing $F$, sample $b$ high-uncertainty inputs around $\theta_t$'s current features, query $G(x_i)$ (or replay $G$'s recent boundary logs), and run 1 distilled gradient step—rebuilding arbitrarily high-entropy rules from $O(1)$ internal bytes.
- **Nearest prior / gap:** Static prompt/RAG rule retrieval (`2610.19068`) scales linearly in internal bytes with rule description length $H(G)$; oracle-query boundary reconstruction decouples internal pointer size from $H(G)$.
- **Cheapest first test:** Synthetic 20-rule world sweeping rule entropy $H(G) \in \{10, 100, 1000\}$ clauses at fixed internal byte cap. Compare equal-byte replay, equal-byte stored rule-text retrieval, EWC, `L6W25` without the split, and oracle-probe `L8W01`. Kill if equal-byte stored rule-text retrieval or replay matches `L8W01` at $H(G)=1000$ clauses.
- **Old-task retention:** Verify post-wake accuracy across all 20 high-entropy rules and unimpaired learning speed on new tasks $C_1 \dots C_{20}$.

### L8W02 · Constructive Forget-Retain Alignment (inverting `2608.25429` into a 1-step pointer)
- **Mechanism:** [Distance Is Not Enough](https://arxiv.org/abs/2608.25429) shows that an unlearned skill re-emerges in 1 fine-tuning step whenever the *Forget-Retain Alignment Gap* (alignment between the forgotten task's gradient and the retained feature manifold) stays small. Invert that vulnerability into a pointer mechanism: evict $F$'s active classifier weights while adding a tiny alignment regularizer keeping $\phi_{\theta_t}$'s top-$r$ singular subspace aligned with $G$'s boundary normal—requiring **zero stored examples** for 1-step rebuild from $G$'s labels!
- **Nearest prior / gap:** Machine unlearning (`2608.25429`) treats small Forget-Retain Alignment Gap as a security failure to maximize; `L8W02` minimizes it intentionally to turn the retained representation itself into a zero-byte wake pointer.
- **Cheapest first test:** 20-skill continual stream comparing equal-byte replay, equal-byte rule-text retrieval, EWC, unaligned eviction, and alignment-gap pointer `L8W02`. Kill if unaligned eviction or equal-byte replay recovers $F$ equally accurately in 1 step from $G$'s labels.
- **Old-task retention:** Verify 1-step rebuild fidelity across 20 skills, zero extra example bytes, and intact $C_1 \dots C_{20}$ + $A/B$ accuracy.

### L8W03 · Shared hypernetwork wake-decoder (mapping live guard traces directly to weight deltas)
- **Mechanism:** Train a single shared lightweight hypernetwork $H_\psi(\tau_G, \phi_{\theta_t}) \to \Delta W_F$ (low-rank weight patch) that takes a short input–verdict trace $\tau_G = \{(x_i, G(x_i))\}_{i=1}^k$ from *any* external guard $G$ plus a summary of $\theta_t$'s current layer statistics and outputs a 1-step weight delta directly in $\theta_t$'s current coordinate frame. Per-skill internal storage drops to a single skill ID / query key (constant bytes as $K \to 100$!).
- **Nearest prior / gap:** Standard hypernetworks in CL generate weights from static task embeddings (still memorizing the payload inside $H_\psi$); `L8W03` conditions $H_\psi$ on *live external guard verdicts*, offloading the rule payload to the world while amortizing the wake operator.
- **Cheapest first test:** 30-skill stream where 20 rules are unseen by $H_\psi$ during meta-training, under a strict total-byte budget (including $\psi$). Compare equal-byte replay, equal-byte rule-text retrieval, `L6W25` without split, EWC, and hypernetwork decoder `L8W03`. Kill if equal-byte replay or rule-text retrieval beats `L8W03` (counting $\psi$'s bytes!) at $K=30$.
- **Old-task retention:** Verify zero-shot 1-step wake-up on unseen guards, constant per-skill internal bytes, and intact $C_1 \dots C_{20}$.

### L8W04 · Rank-1 input-Jacobian key pointer (constrained 1-step gradient projection)
- **Mechanism:** Represent each offloaded skill's internal pointer as a single unit direction $k_F \in \mathbb{R}^d$ (the principal singular vector of $\nabla_x G$ in hidden representation space). During normal operation, $k_F$ is passive (zero constraint on $C_1 \dots C_{20}$). On wake-up, restrict the 1-step reconstruction gradient from $G$ strictly to the rank-1 subspace $\text{span}(k_F)$ (plus the output bias)—requiring only $d$ floats per skill and preventing wake-up from perturbing orthogonal tasks $C_1 \dots C_{20}$!
- **Nearest prior / gap:** Unlike full task vectors or OGD subspaces, a rank-1 Jacobian key stores no payload and imposes zero training-time constraint during $C$, acting solely as a wake-time surgical mask.
- **Cheapest first test:** 20-skill stream with fixed byte budget ($20 d$ floats) vs. equal-byte replay, equal-byte rule-text retrieval, unconstrained 1-step wake, and rank-1 Jacobian pointer `L8W04`. Kill if unconstrained 1-step wake or equal-byte replay matches both post-wake $F$-accuracy and post-wake $C$-preservation.
- **Old-task retention:** Verify $\le 0.5\%$ $C$-degradation upon 1-step wake-up across 20 skills, with intact $A/B$.

### L8W05 · Deterministic-core / neural-residual payload split
- **Mechanism:** Decompose a complex skill $F$ into a high-entropy deterministic core $G_{\text{core}}(x)$ (e.g., 200 crisp schema/logic clauses kept in the world) plus a low-entropy fuzzy exception residual $r_F(x) = F(x) \oplus G_{\text{core}}(x)$ (e.g., 5% edge cases). Keep $G_{\text{core}}$ exclusively in the world and store a tiny pointer *only* for $r_F$—so the neural weights never waste capacity encoding high-entropy boolean clauses that deterministic code handles natively.
- **Nearest prior / gap:** Neuro-symbolic systems (`1603.06318`, `2304.01665`) assume the logic rules are hand-written and static; `L8W05` uses the residual split specifically to shrink the continual-learning byte footprint of `L7W04` pointers.
- **Cheapest first test:** 20 hybrid rules (each = 100-clause deterministic core + 5% fuzzy neural exceptions) at fixed internal byte budget. Compare full-neural replay at equal bytes, full-rule-text retrieval, EWC, and residual-pointer `L8W05`. Kill if equal-byte replay or rule-text retrieval matches accuracy on both the 100-clause core and 5% fuzzy exceptions.
- **Old-task retention:** Verify 100% core retention (in world) + 1-step residual recovery, leaving $>90\%$ weight capacity free for $C_1 \dots C_{20}$.

### L8W06 · Adversarial-margin probe synthesis for 1-step guard extraction
- **Mechanism:** When reconstructing $F$ from an external guard $G(x)$ in 1 gradient step, random inputs carry almost zero bits of boundary information (most inputs are far from the decision surface). Generate $b$ *minimal-perturbation counterfactual pairs* $(x^+, x^-)$ straddling $G$'s boundary ($G(x^+) \neq G(x^-)$, $\|x^+ - x^-\| \le \delta$) using 2 steps of black-box/zeroth-order search against $G$; a single gradient step on those $b$ pairs recovers $G$'s exact local hyperplane!
- **Nearest prior / gap:** Model-extraction / active boundary querying is usually studied as an attack; here it is a constructive *1-step wake-up amplifier* that lets `L7W04` recover high-entropy guards from tiny query budgets.
- **Cheapest first test:** 20 high-entropy nonlinear guards under a strict wake-up query cap of $b=16$ calls to $G$. Compare random-query 1-step wake, equal-byte replay, rule-text retrieval, and boundary-pair wake `L8W06`. Kill if random-query wake or equal-byte replay matches 1-step post-wake accuracy at $b=16$.
- **Old-task retention:** Verify $\ge 95\%$ guard recovery in 1 step from 16 boundary pairs, with zero stored payload and intact $C$ + $A/B$.

### L8W07 · Orthogonal Procrustes pointer tracking across representation rotation
- **Mechanism:** When new tasks $C_1 \dots C_{20}$ rotate internal hidden representations $\phi_{\theta_t}(x)$, static weight pointers $p_F$ lose alignment with $\phi_{\theta_t}$ and fail 1-step wake-up. Maintain a tiny shared 32-point *coordinate frame anchor* (unlabeled inputs); after each task $C_t$, solve the closed-form orthogonal Procrustes map $R_t = \arg\min_{R^\top R = I} \|R \phi_{t-1} - \phi_t\|_F$ and rotate all $K$ pointers in place ($p_F \leftarrow R_t p_F$) in $O(Kd)$ time—keeping pointers valid across arbitrary feature rotation without ever querying the external guards!
- **Nearest prior / gap:** Solves pointer staleness under representation drift mathematically (closed-form Procrustes transport), rather than freezing the backbone like OML/EWC.
- **Cheapest first test:** 20-skill stream where $C_1 \dots C_{10}$ induce strong hidden-layer rotations. Compare static-pointer `L7W04`, EWC, equal-byte replay, and Procrustes-tracked `L8W07`. Kill if static pointers survive representation rotation equally well without Procrustes transport.
- **Old-task retention:** Verify 1-step wake accuracy remains flat across 10 representation-rotating tasks while $C_1 \dots C_{10}$ train with zero backbone freeze.

### L8W08 · Compositional pointer algebra for $2^K$ guard intersections
- **Mechanism:** When an environment enforces $K$ independent external guards $G_1 \dots G_K$, downstream operations often require waking arbitrary *conjunctions* ($G_i \land G_j \land G_k$) simultaneously. Constrain pointers $p_{F_1} \dots p_{F_K}$ to live in mutually orthogonal low-rank subspaces so their 1-step wake deltas *add linearly without interference* ($\Delta \theta_{i \land j} = \Delta \theta_i + \Delta \theta_j$)—reconstructing $O(2^K)$ composite policies from $O(K)$ pointers (which equal-byte rule-text retrieval cannot fit in context!).
- **Nearest prior / gap:** Task arithmetic / vector addition assumes full task vectors are stored; `L8W08` achieves linear composition directly from *1-step guard-reconstructed deltas*.
- **Cheapest first test:** $K=16$ guards with random 4-way simultaneous conjunction queries. Compare equal-byte rule-text retrieval (context overflow!), equal-byte replay, non-orthogonal `L7W04`, and orthogonal-algebra `L8W08`. Kill if equal-byte rule-text retrieval or non-orthogonal pointers match 4-way conjunction accuracy.
- **Old-task retention:** Verify linear 1-step composition across all 4-way conjunctions with intact $C_1 \dots C_{20}$ and $A/B$.

### L8W09 · Information-theoretic byte-scaling certificate (when pointer + guard strictly beats replay & rule-text)
- **Mechanism:** Derive and test the exact quantitative crossover inequality between `L7W04` and row 512's two byte-matched baselines: let $B_{\text{ptr}}$ be internal pointer bytes, $H(G)$ be guard rule entropy, and $B_{\text{rep}}$ be replay/rule-text bytes. `L7W04` strictly dominates iff $B_{\text{ptr}} \ll \min(B_{\text{rep}}(H(G)),\, B_{\text{text}}(H(G)))$ while 1-step reconstruction error $\epsilon_{\text{wake}}(B_{\text{ptr}}, G) \le \epsilon_{\text{max}}$. Automatically route low-entropy skills ($H(G) < B_{\text{ptr}}$) to direct rule-text/replay and high-entropy skills ($H(G) \gg B_{\text{ptr}}$) to `L7W04` pointers!
- **Nearest prior / gap:** Eliminates blind application of `L7W04` on trivial 2-byte rules where stored rule text obviously wins.
- **Cheapest first test:** Sweep $H(G) \in [10^1, 10^4]$ bits $\times K \in \{5, 20, 50\}$ comparing equal-byte replay, equal-byte rule-text retrieval, pure `L7W04`, and crossover-routed `L8W09`. Kill if pure rule-text retrieval beats `L7W04` even at $H(G) = 10^4$ bits and $K=50$.
- **Old-task retention:** Verify strictly optimal retention-per-byte across the full $(H(G), K)$ plane, with preserved $C_1 \dots C_{20}$.

## Section B · Compile Out of Weights, Evict to Recover Plasticity (`L8W10`–`L8W18`, deepening `L7W07`)

### L8W10 · Null-space reinitialization eviction (recovering plasticity without `2608.29513` unlearning collapse)
- **Mechanism:** Standard continual machine unlearning (gradient ascent / negative preference optimization) inflates weight norms and *causes plasticity collapse* ([2608.29513](https://arxiv.org/abs/2608.29513)). After compiling learned skill $F$ into a verified external deterministic check $A_F$ (`SymTorch` `2602.21307` / `NN2Rules` `2207.12271`), evict $F$ by **null-space reinitialization**: compute $F$'s exclusive parameter subspace $U_F = \text{span}(\mathcal{F}_F) \cap \text{span}(\mathcal{F}_{\text{retain}})^\perp$, zero out $\theta$'s projection onto $U_F$, and reinitialize *only* $U_F$ with fresh small-norm isotropic weights (`2607.24996`)—provably increasing effective rank and new-task learning speed!
- **Nearest prior / gap:** [LATM](https://arxiv.org/abs/2305.17126) and [Joint Tool Creation](https://arxiv.org/abs/2608.24571) create tools *without* touching weights; [2608.29513](https://arxiv.org/abs/2608.29513) proves naive unlearning *harms* plasticity. Null-space reinitialization is the exact eviction operator that turns tool compilation into net plasticity gain.
- **Cheapest first test:** 20-skill + 20-task MLP stream under fixed width. Compare LATM/Voyager (compile $A_F$ *without* eviction), gradient-ascent unlearning eviction, eviction *without* $A_F$, equal-byte replay, and null-space reinit `L8W10`. Kill if LATM (no eviction) matches task-20 learning speed, or if `L8W10` fails to beat gradient-ascent unlearning on plasticity.
- **Old-task retention:** Verify 100% $F$-retention via $A_F$, zero damage to retained tasks $A, B$, and strictly faster learning on $C_1 \dots C_{20}$.

### L8W11 · Adversarial equivalence-checking eviction gate (certifying $A_F \equiv f_\theta$ before eviction)
- **Mechanism:** Compiling a neural skill into an external Python/AST check $A_F$ can silently drop rare edge cases; evicting weights before catching those gaps causes permanent regression! Before authorizing `L8W10` eviction, run *adversarial disagreement search*: optimize inputs $x^* = \arg\max_x \mathbb{I}[f_\theta(x) \neq A_F(x)]$ over the live data manifold (and refine $A_F$ with counterexamples in a CEGIS loop). Authorize weight eviction *only* when counterexample disagreement falls below $\epsilon_{\text{eq}}$!
- **Nearest prior / gap:** [SymTorch](https://arxiv.org/abs/2602.21307) and [NN2Rules](https://arxiv.org/abs/2207.12271) measure average test fidelity; CEGIS equivalence gating guarantees zero silent boundary loss before irreversible weight eviction.
- **Cheapest first test:** 15 learned neural rules where naive rule extraction misses 5% corner cases. Compare unverified compile-and-evict, LATM without eviction, equal-byte replay, and CEGIS-gated `L8W11`. Kill if unverified compile-and-evict achieves equal worst-slice retention without adversarial equivalence search.
- **Old-task retention:** Verify worst-slice fidelity $\ge 99.5\%$ after eviction, zero regression on $A/B$, and full plasticity gain on $C_1 \dots C_{20}$.

### L8W12 · Crystallization-regularized training (making crisp skills natively compilable out of weights)
- **Mechanism:** Dense distributed neural circuits resist clean extraction into deterministic code (`NN2Rules` explodes in tree depth). Inspired by [Łukasiewicz Crystallization](https://arxiv.org/abs/2609.33028), attach a lightweight sparse/piecewise-linear *crystallization regularizer* to newly admitted prevention sub-networks so crisp logical rules naturally converge to low-depth, axis-aligned predicates that compile into compact $O(1)$-line external checks $A_F$ with zero CEGIS retries, maximizing eviction yield!
- **Nearest prior / gap:** [2609.33028](https://arxiv.org/abs/2609.33028) crystallizes whole networks for interpretability (hurting general expressivity); applying crystallization *selectively* to off-loadable rule sub-networks keeps the main backbone fully dense while making rule compilation effortless.
- **Cheapest first test:** 12 logical-rule skills learned alongside 10 dense perceptual tasks $C_1 \dots C_{10}$. Compare dense training + `NN2Rules` + eviction, LATM without eviction, and selective crystallization `L8W12`. Kill if dense training compiles into equally compact, high-fidelity checks $A_F$ without crystallization.
- **Old-task retention:** Verify $\ge 3\times$ smaller compiled checks $A_F$, higher CEGIS pass rate, and untouched dense accuracy on $C_1 \dots C_{10}$ + $A/B$.

### L8W13 · Partial neural-to-code peeling (compile the deterministic 80%, evict its subspace, keep the 20% fuzzy tail)
- **Mechanism:** Waiting for a skill to be 100% deterministic blocks `L7W07` on messy real-world tasks. Extract a *partial* deterministic external check $A_F^{\text{part}}$ that certifies 100% precision on the crisp 80% of $F$'s domain (abstaining on the fuzzy 20%), deploy $A_F^{\text{part}}$ externally, and run `L8W10` eviction *strictly on the $A_F^{\text{part}}$-covered input slice's parameter subspace*—shrinking $F$'s neural footprint by ~80% while retaining neural generalization on the 20% fuzzy boundary!
- **Nearest prior / gap:** Bridges deterministic tool synthesis (`2305.17126`, `2602.21307`) with messy continual learning: you never need 100% symbolic expressibility to reclaim most of a skill's weight capacity.
- **Cheapest first test:** 15 hybrid skills (80% crisp boolean core + 20% fuzzy boundary). Compare all-or-nothing `L7W07` (fails CEGIS on all 15!), LATM without eviction, equal-byte replay, and partial peeling `L8W13`. Kill if all-or-nothing `L7W07` or LATM matches plasticity recovery on hybrid skills.
- **Old-task retention:** Verify 100% accuracy on both crisp 80% (in $A_F^{\text{part}}$) and fuzzy 20% (in weights), with major plasticity recovery on $C_1 \dots C_{20}$.

### L8W14 · Synaptic role partitioning for zero-collateral compilation & eviction
- **Mechanism:** Extending [Learning with Unlearning: Synaptic Role Partitioning](https://arxiv.org/abs/2611.24205), dynamically partition weights during learning into *shared-feature synapses* (reused across tasks, never evicted) and *rule-execution synapses* (skill-specific routing/logic, tagged for compilation + eviction). When $A_F$ passes CEGIS (`L8W11`), evict *only* the rule-execution synapses—preventing eviction from accidentally carving holes in shared representations needed by $A, B, C$.
- **Nearest prior / gap:** [2611.24205](https://arxiv.org/abs/2611.24205) partitions synapses for privacy unlearning; `L8W14` adapts synaptic partitioning specifically to *post-compilation plasticity reclamation*.
- **Cheapest first test:** 20-skill continual stream where skills heavily share early features with retained tasks $A, B$. Compare unpartitioned `L8W10`, LATM without eviction, EWC, and role-partitioned `L8W14`. Kill if unpartitioned `L8W10` achieves equal zero-drop retention on $A, B$ and equal plasticity gain on $C_1 \dots C_{20}$.
- **Old-task retention:** Verify 0% collateral drop on $A, B$ after 20 consecutive evictions, plus strictly faster learning on $C_1 \dots C_{20}$.

### L8W15 · Interference-weighted compilation scheduler (evict *bottleneck* skills first)
- **Mechanism:** Compiling and verifying every learned skill wastes compute and bloats the external check registry ([Can Agents Design Libraries for Agents?](https://arxiv.org/abs/2609.36730)). Score each learned skill $F$ by its **plasticity bottleneck score**: $\text{Score}(F) = \frac{\|\Pi_{U_F} \nabla \mathcal{L}_{\text{stream}}\|^2 \cdot \text{EffRank}(U_F)}{\text{CompileCost}(F)}$. Compile-and-evict *only* the top skills whose subspaces actively collide with incoming tasks $C$, leaving orthogonal skills cheaply in weights!
- **Nearest prior / gap:** Turns `L7W07` from an indiscriminate "compile everything" rule into a *gradient-interference-driven plasticity allocator*.
- **Cheapest first test:** 20-skill stream where 5 skills strongly collide with upcoming tasks $C_1 \dots C_{10}$ and 15 are orthogonal, under a budget of 5 compilations. Compare compile-all, random-5 compilation, LATM without eviction, and interference-scheduled `L8W15`. Kill if random-5 compilation or LATM matches $C_1 \dots C_{10}$ learning speed at 5 compilations.
- **Old-task retention:** Verify $4\times$ lower compilation compute and smaller external library with identical task-10 plasticity and 100% 20-skill retention.

### L8W16 · Canonicalized external check factoring (preventing tool-library bloat during continual eviction)
- **Mechanism:** [Can Agents Design Libraries for Agents?](https://arxiv.org/abs/2609.36730) shows agents repeatedly write near-duplicate tools instead of factoring shared abstractions. Before emitting $A_{F_{\text{new}}}$ and evicting $U_{F_{\text{new}}}$, run an AST anti-unification / parameterization pass against existing compiled checks $\{A_{F_1}, \dots, A_{F_k}\}$: merge $A_{F_{\text{new}}}$ as a new parameter config of an existing check whenever it shares $\ge 70\%$ AST structure, keeping external check maintenance sublinear in $K$.
- **Nearest prior / gap:** Directly addresses the external-side scaling failure of `L7W07` (trading weight bloat for unmaintainable code bloat).
- **Cheapest first test:** 30 related rule skills (grouped into 6 parameterized families) compiled sequentially. Compare unfactored `L7W07` (30 standalone scripts), LATM without eviction, and AST-factored `L8W16`. Kill if unfactored `L7W07` maintains equal external-library size and verification latency at $K=30$.
- **Old-task retention:** Verify $5\times$ smaller external check library, 100% equivalence across all 30 skills, and full plasticity recovery.

### L8W17 · Update-matched plasticity-delta audit (verifying eviction actually increased plasticity)
- **Mechanism:** Extending [Update-Matched Unlearning](https://arxiv.org/abs/2610.21230), treat every post-compilation eviction as a *falsifiable plasticity intervention*: immediately before and after `L8W10` eviction, measure (i) effective feature rank, (ii) dormant neuron ratio, and (iii) 10-step loss reduction on a held-out orthogonal probe task. Commit the eviction *only* if plasticity strictly increases over the pre-eviction LATM baseline (zero-eviction control); otherwise roll back weights and keep $A_F$ as a redundant check only.
- **Nearest prior / gap:** Directly guards against silent `2608.29513` plasticity collapse by verifying positive plasticity yield on every single eviction.
- **Cheapest first test:** 20-eviction stream mixing clean orthogonal subspaces (eviction helps) and deeply entangled subspaces (eviction hurts). Compare blind eviction, LATM without eviction, and plasticity-audited `L8W17`. Kill if blind eviction matches `L8W17` on task-20 learning speed and $A/B$ retention.
- **Old-task retention:** Verify monotonic plasticity improvement across 20 evictions, zero collapse events, and intact $A/B$.

### L8W18 · Exception-triggered neural re-absorption & re-compilation (when a compiled check breaks on shifted inputs)
- **Mechanism:** Deterministic external checks $A_F$ are brittle when input schemas or distributions shift outside their compiled AST predicates. Monitor $A_F$'s live exception / out-of-domain rate; if $A_F$ starts failing on shifted inputs, use `L7W07`'s retained 1-step fallback trace to *re-absorb* $F$ into weights, fine-tune the neural boundary on the shifted inputs (where neural nets generalize!), re-run CEGIS compilation (`L8W11`) to emit $A'_F$, and re-evict!
- **Nearest prior / gap:** Closes the primary fragility of compiled code vs. neural weights (`2609.39018`), giving `L7W07` a self-healing neural $\leftrightarrow$ symbolic lifecycle.
- **Cheapest first test:** 15 compiled skills where 4 suffer mid-stream input-schema drift that breaks their deterministic checks $A_F$. Compare static `L7W07` (no re-absorption), LATM without eviction, equal-byte replay, and self-healing `L8W18`. Kill if static `L7W07` or replay recovers accuracy on the 4 drifted skills equally fast.
- **Old-task retention:** Verify rapid recovery on all 4 drifted skills, re-eviction restores plasticity, and $C_1 \dots C_{20}$ + $A/B$ stay intact.

## Section C · Closed-Loop `L7W04 × L7W07` Mechanisms: Compile $\to$ Evict to Pointer $\to$ Reconstruct (`L8W19`–`L8W26`)

### L8W19 · Closed-loop Compile-to-Payload / Evict-to-Pointer cycle (the exact `L7W04 × L7W07` synthesis)
- **Mechanism:** Unify both row-512 primitives into one end-to-end continual-learning operator:
  1. Learn skill $F$ in weights;
  2. Compile $F$'s high-entropy rule payload out into deterministic external check $A_F$ (`L8W11` CEGIS-verified);
  3. Evict $F$'s bulk parameter subspace $U_F$ via null-space reinitialization (`L8W10`) while preserving *only* a compact `L7W04` wake pointer $p_F$ (`L8W02`/`L8W04`) aligned to $A_F$;
  4. Train new tasks $C_1 \dots C_{20}$ in the reclaimed plasticity;
  5. If $A_F$ is ever lost or broken, reconstruct $F$ in 1 step from $p_F$ + boundary trace (`L8W01`/`L8W06`).
- **Nearest prior / gap:** `L7W04` alone requires pre-existing external guards; `L7W07` alone needs a principled minimal fallback trace. Together, the learner *manufactures its own external world-memory payloads* and shrinks its internal footprint down to 1-step pointers!
- **Cheapest first test:** 20-skill + 20-task stream starting with **zero** pre-existing external guards, plus 3 simulated artifact-loss events mid-stream. Compare LATM/Voyager (compile without eviction), eviction without artifact, `L6W25` (pre-existing guards only—fails!), equal-byte replay, equal-byte rule-text retrieval, and closed-loop `L8W19`. Kill if LATM (no eviction) or equal-byte replay matches both task-20 plasticity and post-artifact-loss 1-step recovery.
- **Old-task retention:** Verify 100% retention across all 20 skills (including the 3 lost artifacts after 1-step wake) and strictly higher task-20 learning speed.

### L8W20 · Compiler-emitted wake pointers (extracting minimal boundary keys *during* AST synthesis)
- **Mechanism:** Instead of running a separate post-eviction search to build `L7W04`'s wake pointer $p_F$, emit $p_F$ *as a direct byproduct of `L7W07` compilation*: the symbolic compiler (`SymTorch`/`NN2Rules` + CEGIS `L8W11`) already discovers the exact minimal split hyperplanes / counterexample pairs defining $A_F$'s decision boundary; serialize those exact boundary normals as the rank-$r$ pointer $p_F$ at zero extra compute!
- **Nearest prior / gap:** Tightly couples neural-to-code compilation (`L7W07`) with pointer construction (`L7W04`), eliminating separate pointer-discovery overhead.
- **Cheapest first test:** 20-skill compile-and-evict stream comparing separate post-hoc pointer search vs. compiler-emitted pointers `L8W20` at equal byte budget. Kill if post-hoc pointer search matches 1-step wake accuracy at equal total compile + pointer FLOPs.
- **Old-task retention:** Verify equal or better 1-step wake fidelity at $\ge 2\times$ lower pointer-construction compute, with intact $C_1 \dots C_{20}$.

### L8W21 · Post-eviction loss-masking against forgetting reversal (`2604.19108`)
- **Mechanism:** [Robust Continual Unlearning against Forgetting Reversal](https://arxiv.org/abs/2604.19108) shows that evicted skills silently re-emerge in weights if future training batches still contain $F$-examples—undoing `L8W10`'s plasticity recovery! Once $A_F$ is deployed externally and $U_F$ is evicted, *mask out $A_F$-handled inputs from the main network's training loss* (routing them directly to $A_F$) so the reclaimed subspace $U_F$ stays dedicated to genuinely new tasks $C_1 \dots C_{20}$ instead of re-memorizing $A_F$!
- **Nearest prior / gap:** Prevents silent re-internalization of compiled external checks, preserving the plasticity gain of `L7W07` over long streams.
- **Cheapest first test:** 20-skill + 20-task stream where $F$-examples continue appearing in the live stream after compilation and eviction. Compare unmasked `L8W10` (re-learns $F$!), LATM without eviction, equal-byte replay, and loss-masked `L8W21`. Kill if unmasked `L8W10` retains the same reclaimed plasticity over 50 epochs of mixed live data.
- **Old-task retention:** Verify $A_F$ handles 100% of recurring $F$-inputs, weights never waste capacity re-learning $F$, and $C_1 \dots C_{20}$ stay fast.

### L8W22 · Scratch-copy round-trip reversibility test (certifying 1-step rebuild *before* committing eviction)
- **Mechanism:** Evicting $U_F$ is dangerous if the retained pointer $p_F$ fails to reconstruct $F$ when $A_F$ is later lost. Before committing `L8W10` eviction on the live model, run a 1-second *round-trip reversibility test* on a scratch copy: (1) apply `L8W10` eviction to $\theta_{\text{scratch}}$, (2) simulate loss of $A_F$, (3) run 1-step wake reconstruction from $p_F$ (`L8W01`/`L8W04`), and (4) commit live eviction *only* if reconstructed accuracy $\ge 98\%$ and $A/B$ retention drop $\le 0.5\%$.
- **Nearest prior / gap:** Guarantees that `L7W07` weight eviction is *provably reversible* via `L7W04` before any live weight is reset.
- **Cheapest first test:** 20-skill stream where 4 skills have fragile pointers that fail 1-step rebuild after eviction. Compare unchecked `L8W19`, LATM without eviction, and round-trip-certified `L8W22`. Kill if unchecked `L8W19` suffers zero artifact-loss recovery failures on the 4 fragile skills.
- **Old-task retention:** Verify 100% guaranteed 1-step recovery on every evicted skill, keeping the 4 non-reversible skills safely in weights.

### L8W23 · Batched block-orthogonal subspace eviction (avoiding fragmented rank holes)
- **Mechanism:** Evicting one rank-2 skill at a time via `L8W10` leaves scattered low-rank updates that quickly lose isotropy during interleaved SGD. Buffer $m$ verified compiled checks $\{A_{F_1}, \dots, A_{F_m}\}$, compute their *joint* exclusive subspace $U_{1..m} = \text{span}(\bigcup_{i=1}^m U_{F_i}) \cap U_{\text{retain}}^\perp$, and execute one clean *block-orthogonal reinitialization*—restoring a contiguous, well-conditioned plastic subspace for upcoming tasks $C$!
- **Nearest prior / gap:** Optimizes the spectral conditioning of `L8W10` eviction across long multi-skill streams, directly countering spectral collapse (`2509.22335`).
- **Cheapest first test:** 30-skill stream comparing per-skill incremental `L8W10`, batched block-orthogonal `L8W23` ($m=5$), LATM without eviction, and equal-byte replay. Kill if per-skill incremental `L8W10` achieves equal spectral conditioning and task-30 learning speed.
- **Old-task retention:** Verify higher effective feature rank, faster task-30 convergence, and intact $A/B$ + all 30 compiled skills.

### L8W24 · MDL-to-rank compilation gate (deciding mathematically when a skill is worth compiling & evicting)
- **Mechanism:** Compiling a fuzzy perceptual skill into a massive 500-line heuristic tree (`NN2Rules`) yields fragile code and poor compression; compiling a crisp 10-line invariant frees huge neural rank at tiny code cost. Gate `L7W07` on the **minimum description length ratio**: compile-and-evict $F$ iff $\text{MDL}(A_F) / \text{EffRank}(U_F) \le \tau_{\text{comp}}$ *and* CEGIS fidelity $\ge 1 - \epsilon_{\text{eq}}$—keeping genuinely non-symbolic skills in weights/replay while cleanly offloading symbolic ones!
- **Nearest prior / gap:** Prevents `L7W07` from degrading into brittle rule extraction on inherently neural tasks.
- **Cheapest first test:** Mixed 20-skill stream (10 crisp symbolic rules + 10 fuzzy perceptual skills) + 20 tasks $C_1 \dots C_{20}$. Compare always-compile `L7W07`, never-compile EWC, LATM without eviction, and MDL-gated `L8W24`. Kill if always-compile or never-compile beats `L8W24` across the mixed stream.
- **Old-task retention:** Verify crisp rules offload cleanly for maximum plasticity while fuzzy skills retain full neural accuracy.

### L8W25 · Human-edit pointer resynchronization (updating $p_F$ when engineers edit a compiled check $A_F$)
- **Mechanism:** Because `L7W07` emits human-readable deterministic artifacts $A_F$ (tests, validators, linters) into the live workspace, *human engineers will edit $A_F$ as requirements evolve!* Detect file/AST diffs on $A_F$, run `L8W01`/`L8W06` boundary probing on the edited $A'_F$ to update *only* the compact pointer $p_F$ (zero L1 weight training!), so if $A'_F$ is ever unavailable, 1-step reconstruction automatically recovers the *human-edited* rule!

- **Cheapest first test:** 15 compiled skills where humans modify 5 checks $A_F \to A'_F$ mid-stream, followed by simulated loss of 2 edited checks. Compare static-pointer `L8W19`, equal-byte replay (frozen old data!), and edit-resynced `L8W25`. Kill if static-pointer `L8W19` or replay recovers the *edited* rule $A'_F$ in 1 step.
- **Old-task retention:** Verify 1-step recovery tracks human edits to $A'_F$ with zero L1 weight disruption and intact $C_1 \dots C_{20}$.
