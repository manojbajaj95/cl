# Agent harness → what makes a successful edit reusable?

**Root cause hypothesis: the agent can discover a fix without acquiring an independently writable skill.** The feedback says that a whole rollout succeeded under one harness version. The write surface is commonly shared (one prompt, one reader/ranker, one set of hooks), and the same change can induce different actions on old, new, or reordered tasks. This gives two distinct bottlenecks: (1) the permitted interface may not admit an edit that changes the desired behavior without changing protected behavior; (2) even where such an edit exists, current-task outcomes do not identify it. Longer memory increases storage, not necessarily independent control. A frozen LLM is *not* a bound on the whole agent: executable tools, external state, and orchestration can implement policy outside the LLM. Compare those as separate write interfaces at matched cost, not as longer prompts.

## Evidence and a disconfirmation

At step 100 on the compound stream, GEPA and Meta-Harness are **−6.8 / −4.8 points** on BFCL-Miss *before any BFCL-Miss training task*. The authors inspect the actual global system prompts and find mandatory SQLite exploration and verification carried over from BIRD; those prompts are used on the BFCL rollouts. In ReasoningBank the mean cross-workflow nearest-match cosine is **0.835–0.840**, overlapping within-workflow **0.834–0.837**; both workflows use the same tools but disagree about when to ask. | Shared writes and aliased addresses are reachable failure routes: no irrelevant memory need be forgotten for a new task to get worse. Prompt inspection does not isolate how much each instruction caused; compare targeted rewrites or tagged retrieval to establish that. Terminal gains average **+3.7 / +1.4 / +2.5 points** for GEPA / Meta-Harness / ReasoningBank: the claim is about *retained compounding*, not absence of gain. |
| [Can Coding Agents Sustain Continual Evolution without Forgetting? [Harness-Delta Attribution (2610.22466)](https://arxiv.org/abs/2610.22466) attributes, on average, **54%** of search-set gain to detected overfitting and **14%** to test-time scaling across **21** settings with significant gains. | A high selected score is weak evidence for independently retained skills. [LifelongAgentBench (2505.11942)](https://arxiv.org/abs/2505.11942), Table 2: as successful replay histories increase **0 → 4 → 32 → 64**, Llama-3.1-8B OS success goes **.43 → .50 → .42 → .44**, whereas DB goes **.19 → .73 → .77 → .78**. | Destructive writing is one mechanism, not a universal prerequisite: even keeping histories can saturate or hurt. None of those numbers is a retention curve on a drifting task stream. |

Their reported gains do not show that the *same* deployed agent retains independently switchable behaviors across a drifting stream. |

**Disconfirmation of the narrow temperature/margin story.** In the repo's [A3 router](https://github.com/manojbajaj95/cl/pull/29), source-fit entropy-matched no-lesson temperature predicts Qwen2.5-1.5B held-out lesson effects at R² **.916 [.872, .956]**; rule text beats the match by only **0.94 pp**, and equal-length filler alone adds **2.69 pp**. But the base chose A on every one of the 36 states; at 0.5B R² is **−.12**. [Swap pairs](https://github.com/manojbajaj95/cl/pull/31) suggest a **0.6–1.0 logit** named-action lead in that setup, not a universal budget. In the [margin follow-up](https://github.com/manojbajaj95/cl/pull/33), small positive margins induced by a post-scoring offset give a **10.42 pp [0, 25.56]** follow index vs **90.97 pp [79.17, 99.38]** for natural relabeling/reordering. This rejects a model-size-only story and undercuts a scalar-margin-only explanation; token identity, action identity, bin mix and order changed together, so it doesn't isolate prior anchoring. The [ledger closes the broad A3 claim](https://github.com/manojbajaj95/cl/pull/6); carry forward filler, source-fit temperature and correct flips on wrong-base states, not “text is temperature.”

## What would bound improvement?

**Retention-constrained headroom.** At a checkpoint, fix the executor, permitted write interface and total resource budget. For each candidate edit `e`, measure the paired causal effect `Δ_j(e) = V_j(h ⊕ e) − V_j(h)` on a named task cohort `j`, where `V` averages fresh closed-loop returns from the same distribution. Include a no-op. For a target cohort `c`, define `Hε = max_e Δ_c(e) subject to Δ_j(e) ≥ −ε_j for every protected j`. Any update in the permitted family that respects the same retention constraints gains at most `Hε` at that checkpoint; this is an operational oracle bound, not a token-capacity law or a bound on delayed gains. Protect unchanged and recurring requirements, not superseded answers; measure delayed probes and order effects separately. An oracle over a finite tested catalogue bounds selection *within that catalogue*, not a larger unsearched space.

**Separate writeability from credit.** If a richly covered catalogue has small `Hε` but high unconstrained gain, edits are coupled; if a validation oracle selects a reliably helpful compatible edit from the *same* candidates the online writer saw but the writer misses it, selection/credit is limiting. Report both unconstrained and constrained frontiers and the gap from the actual writer, with uncertainty; don't infer capacity from a low empirical maximum if the candidate family is weak. A secondary quantity is the number of held-out behavioral targets whose independent on/off combinations can be realized with protection at fixed cost. That tests addressability and composition directly; a high-rank matrix of action-logit shifts, or a large store of prompts, need not realize even two of the required combinations.

**Cheapest discriminating experiment.** Use a CPU symbolic tool world with two recurrent modes sharing surface wording but differing on a visible precondition; hold out goal compositions and vary the delay before recurrence. Use the same small executor and equal-cost text edits, typed tool-call overrides, and low-rank writes; include a no-op, length-matched filler, source-fit entropy-matched temperature, raw replay, and a plain typed guard. Randomize candidate toggles with paired seeds; compare single edits *and* composed edits in both orders on fixed probes and fresh rollouts. Select the diagnostic oracle on an independent development probe panel and confirm its frontier on an untouched panel; report coverage and an oracle-router ceiling separately. Score unseen streams prequentially, probe without updating, charge all search, tool, and probe cost, and resample independent streams. If the text oracle matches the other surfaces but online writers trail it, drop the channel bottleneck in that setting; if context-only writers also keep the frontier as new protected targets accumulate, drop the proposed mechanism there. If a typed guard ties the most elaborate candidate, credit the guard.

## Raw mechanisms for the reviewer

These are proposed primitives, not novelty verdicts. Each test includes a same-budget control; report tradeoff curves if bytes, forwards, or environment interactions cannot all be matched.

1. **Behavioral object files.** Mechanism: compile a harness edit into a small delta that can target text, an activation write or an adapter; include a causal read/write signature with an explicit protected behavior contract. Why new: [Hypter (2101.00420)](https://arxiv.org/abs/2101.00420) generates adapters, and repo [P17/P19](https://github.com/manojbajaj95/cl/pull/39) propose a weight linker/ABI; here the same compiled object can be lowered to different substrates and its declared composition is tested on hidden behavior, not just a weight layout. First test: compile two reusable changes to a tiny rule router; test held-out conjunctions and no-regression under substrate swap vs matched per-task LoRA or plain typed guards.
2. **Steering tomography.** Mechanism: sweep budget-matched text, soft-prefix, executable and weight interventions and estimate the protected behavioral frontier and the largest independently togglable task set per surface. Why new: [ClashEval (2404.10198)](https://arxiv.org/abs/2404.10198) measures input-vs-prior adoption; the target here is attainable *joint combinations* under protection, not a per-state margin law or a rank fit to collapse time (ledger D1). First test: exhaust all 16 labelings of four cross-cutting goals under finite edit libraries; compare with a scalar-margin predictor and greedy single-edit composition.
3. **Counterbalanced forward-writing instructions.** Mechanism: use seeded ± weight perturbations and paired rollouts to accumulate a reusable signed response table over tool-state variables, then allocate new forwards to resolve collisions in that table; score writes with retained-mode constraints rather than averaging all reward into a zeroth-order gradient. Why new: [MeZO (2305.17333)](https://arxiv.org/abs/2305.17333) already learns with two forward passes; the proposed persistent output is a task-conditional write operator that amortizes mass A/B rollouts over future tasks. First test: start at tiny-transformer rank-one edits and sweep forward budgets; compare with MeZO-LoRA plus old replay and equal-budget random-coordinate search before considering millions of rollouts.
4. **Teacher as causal query planner.** Mechanism: give a large model a part map and the outcomes of a small model's prior interventions, not gradients; it asks which layer/weight group or harness instruction to counterfactually replace next and outputs a write address plus the strongest disconfirming probe. Why new: [ROME (2202.05262)](https://arxiv.org/abs/2202.05262) traces a fixed intervention plan for facts and [MEND (2110.11309)](https://arxiv.org/abs/2110.11309) transforms gradients; the proposed object is a transferable *experiment policy* that distinguishes alternative failing mechanisms. First test: hide a broken retrieval branch or small-model circuit in otherwise identical tool tasks; compare to ranked causal tracing, random interventions and a scripted binary search at equal queries and teacher cost.
5. **Harness with typed adjoints.** Mechanism: instrument typed nodes (retrieve, plan, execute, verify) to send a reverse message of the form “a replacement satisfying predicate P would change my verified result,” composing obligations through branches; use exact adjoints for numeric nodes and executable predicates for discrete ones. Why new: [TextGrad (2406.07496)](https://arxiv.org/abs/2406.07496) and ReHarness pass language feedback backward; here the reverse pass builds replayable counterfactual obligations, not revisions inferred from a shared terminal score. First test: plant two defects in a three-stage symbolic tool graph; compare localization and repair on new graphs to TextGrad and exhaustive node replacement at matched verifier calls.
6. **Interchange-addressed skill cells.** Mechanism: an editable address is the causal state variable verified by cross-task interchange, not a vector key; call the cell only when moving that variable between trajectories preserves the other task consequences. Why new: [causal abstraction (2301.04709)](https://arxiv.org/abs/2301.04709) checks interchange for interpretation, and 2610.25858 shows embedding collision; use interchange equivalence itself as the write/read API for an online library. First test: run two nearly identically phrased workflows with different preconditions; beat a simple precondition guard or show transfer when that guard's syntax changes.
7. **Skill rebasing by measured noncommutation.** Mechanism: if executing two edits in opposite orders changes protected outcomes, synthesize a context-specific corrective operation from order-swap witnesses; carry that operation forward when rebasing either edit. Why new: [Task Arithmetic (2212.04089)](https://arxiv.org/abs/2212.04089) merges deltas and [GEPA](https://arxiv.org/abs/2507.19457) merges text, but here the *order residual* is a behavior in its own right, not delta cosine (ledger B3) or a fitted pairwise score surrogate (HK5). First test: build a simulator with unchanged single-edit gains but order-sensitive paired side effects; compare compensation against fixed ordering, independent branch replay and task-vector merging at equal search cost.
8. **Reversible execution tapes.** Mechanism: instrument a harness interpreter so every persistent edit carries an inverse on its downstream store mutations; replay dependent writes after retracting it while preserving unrelated state. Why new: DGM archives recover snapshots and repo's [frontier scan](../docs/frontier-scan.md) calls for clean-world retraction; here a write is transactional across learned prompts, index and tool state, with a replayable dependency tape. First test: retract one false rule from a symbolic agent after five derived writes; compare to same-byte snapshots + full replay on clean-history equivalence and unaffected skills.
9. **Behavioral side-effect types.** Mechanism: infer effects such as “may change clarification but may not change tool argument binding” from intervention traces, and permit later linking only where those inferred effects can be masked or discharged. Why new: Voyager skills have executable composition and [OO-Harness (2610.28380)](https://arxiv.org/abs/2610.28380) grows class hierarchies; effect types describe observable interference, not ownership or a collection of SAGE per-item tests. First test: freeze a toy graph with interchangeable tools, hide one shared side effect and compare against independent unit tests and randomized old-task gates at equal probe count.
10. **Counterfactual perception port.** Mechanism: teach the harness a cheap *experiment* that distinguishes when a skill applies, storing its predicted outcome distribution under each rival latent state rather than a trigger phrase. Why new: [the repo's probe-before-write](../docs/frontier-scan.md#1-probe-before-writing-identify-the-shift-then-update-only-the-affected-mechanism) uses anchor pulses to locate a shift; here the experiment is learned and travels with a skill, so it can be run at read time by another agent lacking the writer's observations. First test: transfer a learned experiment for an aliased API mode to a held-out tool schema; compare to a fixed anchor, confidence-triggered retrieval and a hand-written precondition at equal exploratory actions.
11. **Failure-preserving compilation.** Mechanism: compile a skill into weights from paired successes *and the exact contrasts on which it must yield or abstain*, exposing a runtime veto shared with its text version. Why new: Harness Annealing ([2610.01235](https://arxiv.org/abs/2610.01235)) internalizes scaffold gains, and repo MX1 measures layer-dependent override; the new contract is portability of both effects and exceptions, not training dropout or choosing a LoRA layer. First test: compile two opposing rules sharing vocabulary, then teach a new rule without changing old exceptions; compare to distillation with the same labeled contrasts but no artifact-level veto.
12. **Writable disagreement between teachers.** Mechanism: when a text tutor and a weight teacher disagree on matched trajectories, store their predicted *consequences under future interventions* separately and use a deliberate probe to choose which update to consolidate; distill only the resolved consequence. Why new: [HyperTuning (2211.12485)](https://arxiv.org/abs/2211.12485) emits task-conditioned weights, and MOPD distills from an evolving model; here unresolved disagreement itself is a persistent experimental object, not just extra replay or double dosing. First test: give both teachers equal current accuracy but distinct wrong latent rules; compare compute-matched ensemble, ordinary on-policy distillation, and equal-count random probes on held-out compositions.
13. **Causal litmus-test synthesis.** Mechanism: generate task pairs constrained to agree on all currently logged behavior except at a contested harness decision; train the updater on those contrast classes rather than on more variants of its successful tasks. Why new: PromptPex ([2503.05070](https://arxiv.org/abs/2503.05070)) generates prompt tests; this is active hypothesis discrimination over rival *write destinations*, not edit-generated regression witnesses (HK2). First test: give two candidate edits identical training scores, require a synthesized task pair to decide whether retrieval or action binding is at fault; compare to random held-out replay and a generic test-generation model.
14. **Capability quarantine with typed release.** Mechanism: keep a novel behavior in a sandbox port callable only with a learned, testable applicability proof; broaden the proof by composing it with demonstrated invariants rather than promoting the behavior globally. Why new: [GUARD (2611.23476)](https://arxiv.org/abs/2611.23476) protects mastered rules and repo HW1 promotes rediscovered edits; here the write is never promoted, only its executable release predicate is generalized. First test: in a synthetic workflow with one shared valid case and one look-alike invalid case per new family, compare to per-family routing, similarity thresholds and an oracle precondition; reuse the same skills and cost cap.
15. **Policy duals that trade resources for control.** Mechanism: let the agent compile a named behavior into interchangeable text, tool and weight implementations and retain a per-behavior Pareto set over transfer, control and invocation cost; choose a backend after the available resource budget is known. Why new: [HDA](https://arxiv.org/abs/2610.22466) measures ex-post compute and [Hypter](https://arxiv.org/abs/2101.00420) outputs a single substrate; the artifact is a semantics-preserving substitution rule under live resource constraints, not backend ensemble averaging. First test: alternate token-limited and tool-limited toy episodes with the same goals; compare to static best backend and a budget-aware router over whole-agent variants.
16. **Skill discovery by conservation counterexamples.** Mechanism: propose an invariant over paired trajectories that should survive any valid skill write, then search for a counterexample; factor recurring counterexample classes into new independently addressable ports. Do not assume any neural weight norm is conserved. Why new: HDA neutralizes shortcuts and the repo's Noether-memory pilot tested weight invariants; this constructs an interface from violations of user-visible task semantics, not a conserved storage medium or a sparse damage assumption. First test: intentionally entangle two toy tool procedures that share a resource, discover a missing port from conservation violations, and compare to a generic tool API split and random refactoring at equal interaction budget.
17. **Portable repair by mechanism transplantation.** Mechanism: move a local fix between agents by matching the *causal observations that license it*; when the receiver lacks an abstraction, synthesize an adapter from its traces rather than reusing the donor's activation coordinates. Why new: [Model Stitching](https://arxiv.org/abs/2106.07682) tests representational compatibility and repo [P27](https://github.com/manojbajaj95/cl/pull/39) asks about transplant rejection; this seeks a repair portable across different code/tool graphs, via behavioral interchange before weights are touched. First test: transplant a routing fix between two tiny agents with differently factored parsers; compare to re-synthesizing from donor examples, same-budget adapter training and a known-interface hand port.

## Ranked next nodes

1. **Can two learned behaviors be independently written, swapped, and composed across text, executable, and weight interfaces under one behavioral contract?** A positive result yields a cross-substrate instruction set; a negative one localizes which operator or interface is missing.
2. **Can a large model learn to choose *where to intervene* on a small agent using only paired forwards and disconfirming probes?** A transferable read/write discovery policy would turn Manoj's mass A/B rollouts into an alternative to local gradient credit, not just cheaper evaluation.
3. **Can a failed rollout be inverted into an executable obligation on one learned component, and can those obligations compose through a tool loop?** This would supply an adjoint for discrete learners; compare it against raw replay and natural-language revision before scaling.
4. **Can a skill carry an experiment that recovers its own applicability when task cues alias, including after a tool or model swap?** This would make causal addresses transferable objects rather than brittle retrieval keys.
