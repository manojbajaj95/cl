# Phase-cancelling protection cycles

**Status:** Ideas only; no training runs, code, or GPU work. **Parent:** [Job-absorbing stable cycles](absorbing-cycles.md) ([PR #202](https://github.com/manojbajaj95/cl/pull/202)), cards 15 and 14. **Review seed:** [Flood triage, row 311](https://github.com/manojbajaj95/cl/blob/6ef1c276e4d5dee68faab273beba979831cc5d68/reviews/flood-triage.md#L311) gives both cards a 3: cancel old-task disturbances across phases without projecting them away, and absorb a job write while an equal-norm nuisance fades. **Read first:** [Idea ledger](https://github.com/manojbajaj95/cl/blob/6ef1c276e4d5dee68faab273beba979831cc5d68/reviews/idea-ledger.md): match margins, stack the controls, reject wins built into the simulator, and check ordinary old tasks in every first test.

## Can a cycle spend old-task margin to admit writes it could not otherwise keep?

**Verdict: a safe excursion or a selective basin alone is not new.** [OGD][ogd] and [GPM][gpm] protect old outputs or features by removing update components; [EWC][ewc] penalizes changes without imposing a hard nullspace. [Switched-systems stability][switching] and [Hamilton–Jacobi reachability][reach] already describe returns and safe basins. [Hopfield networks][hopfield] already keep state by choosing an attractor and denoise cues. The candidate is a shared learner whose truthful write **needs** directions a per-step protector would suppress: old decisions survive every exposed phase, the disturbance from the write cancels when the cycle returns, and one held-out write selects another attracting orbit of the same frozen map. The new orbit must still do the job after the source is retired. Test whether the combination admits more useful writes than the best protection and storage controls used together, not whether it draws a loop.

## Two hand checks before proposing a first test

**W5 — return cancellation is not a phase-wise nullspace.** In local coordinates relative to a no-write trace, let the old margin be `m + x` at both phases, and let the two disturbance maps be `A(x,y)=(x/2−3y,y/2)` and `B(x,y)=(x/2+2y,y/2)`. A write `(2s,s)` gives old-margin changes `2s, −2s, 0` at entry, halfway and first return, with `y=s/4` left on return. If `0 < 2|s| < m`, none of those reads flips. The return map is `BA(x,y)=(x/4−y/2,y/4)`: the next return has `x=−s/8`, so exact first-return balance does not imply exact balance forever. In contrast, projecting the entry write onto `x=0` leaves `s` intact but now gives a half-step margin change of `−3s`. This is only an algebraic check, not a trained host or a comparison against optimal projection. Both modes decay; it earns no persistent-job credit.

**W6 — no basin can read the label “nuisance” off an identical state.** If an honest job and a nuisance lead to the same *complete* post-write state at the same phase, the same frozen deterministic continuation gives exactly the same future. With stochastic continuation the conditional future law is still the same. Test exact collision as an impossibility control, near-collinear equal-norm writes as a discrimination test, and same-direction writes from different pre-write histories as a test of lawful state dependence. A job tag, a new clock, an optimizer slot or a fact cache that disambiguates the collision counts as extra state; it is not free selectivity. Inside one unchanged contracting chart, the parent's W4 also rules out persistent one-shot displacement.

### Shared contract for first tests

- Freeze the host, truthful training batch, optimizer, step budget and readout before blind jobs and nuisance generation. The one admitted off-phase update may see the new job; no later step may see that job or its identity. A **job** must improve held-out task service; a **nuisance** is an admissible write with no such utility (e.g. a stale update from another stream). Use both truthful nuisances and synthetic direction probes, without counting the probes as job data. Match applied write norms at the same phase, with a metric fixed in advance; report preconditioned as well as raw parameter norms when using optimizer state.
- Compare matched no-write and write traces at the **same** phase, not absolute drift of an already oscillating model. For each fixed old class pair, record the signed change in its logit gap relative to that trace, plus the true-label gap to the strongest rival. Require nonzero within-phase disturbance on an old reader, reduced signed residual on return, and positive margins at every exposed read; do not average opposite mistakes. Score **A**, ordinary old tasks including phase-sensitive and near-boundary items, and **C**, previously acquired jobs. Match pre-write margins per item, and compare at matched new-job service (or report the full service–retention frontier).
- Record entry, both phases throughout the first excursion, and returns 1, 8 and 64. The target is a distinct attracting orbit of the same map with held-out job service, verified against a second small perturbation; nuisance trajectories should return to the original orbit. Include W1's coordinate-swap null, W4's common-chart decay, W6's collision, and deliberately incomplete cancellation. A task miss between returns counts even if the model restores perfectly. Boundaries fitted using hidden test labels are not admissible.
- Give [OGD][ogd], [GPM][gpm], [EWC][ewc], a stable single-phase host, clipping, plain fine-tuning, robust reachability and equal-norm random plus job-aligned nuisance writes their best shot. For the joint claim stack the best protector **with** the best selective admission or size-matched residual/cache; count examples, gradients, online search, phase latency, optimizer state and audit cost. A margin trigger alone revives the killed MX2 idea; a return-rate forecast alone revives the failed plasticity-reserve line. Neither is the mechanism here.

## Idea cards

### 01. Spend the directions projection would remove — primitive candidate (parent seed)
**Mechanism.** Train a frozen phase pair so job gradients use old-sensitive directions at entry, but transported contributions to old logit gaps oppose each other on return. **Novelty / control.** Unlike [OGD][ogd], [GPM][gpm] or [EWC][ewc], ask whether the full directions are useful *because* the dynamics pay back the disturbance; an exactly cancelling return after suppressed writes does not count. **Cheapest first test.** Enumerate rational two-unit ReLU batches and held-out truthful binary jobs; compare the service–retention frontier against projection, a stable host and a matched partially cancelling pair. **Old-task retention.** Report absolute A and C margins and errors at entry, each half and 64 returns, including examples the write actually moves.

### 02. Put a selective ridge next to a contracting tube — primitive candidate (parent seed)
**Mechanism.** Shape one boundary of the original orbit's basin so a blind job gradient crosses into a translated orbit while equally large nuisance gradients return to the original one. **Novelty / control.** [Hopfield][hopfield] already rejects noisy cues and [reachability][reach] separates input sets. The claim is useful service from an ordinary gradient, with no prototype or router containing the held-out answer; compare clipping, projected learning, robust reachability and equal-norm random and aligned nuisance. **Cheapest first test.** Search tiny piecewise-linear hosts for two attracting itineraries, then map their equal-norm write circle with unseen job and nuisance gradients placed on it before unblinding results. **Old-task retention.** Score matched-margin A and C on both orbits and on trajectories grazing the ridge, not only on clean crossings.

### 03. Let the same excursion open the gate and fund the refund — primitive candidate (merge)
**Mechanism.** Use one shared activation crossing to both enter a useful basin and turn on the phase term that reverses old-task drift. **Novelty / control.** A hybrid system can encode this by hand ([Liberzon][switching]); the claim is a learned shared carrier that costs less than a separate selective gate plus [OGD][ogd] or a cache. **Cheapest first test.** Clone a two-mask learner, independently disable the switching effect on the return and on the basin boundary, and compare all four arms with the stacked control at equal service, state and search. **Old-task retention.** Require the combined arm's apparent gain to survive worst-phase A/C including writes just on either side of the boundary.

### 04. Learn a detour no legal projected path can take — primitive candidate
**Mechanism.** Spend a little old margin to visit an intermediate activation region, then return to the original old-output band from a different side of the routing boundary. **Novelty / control.** [Reach-avoid](https://arxiv.org/abs/1410.6445) already plans detours; the CL claim needs a compact frozen batch that executes one for held-out gradients without solving a new plan. **Cheapest first test.** Exhaust a two-dimensional mask grid to find a job reachable with bounded excursion but unreachable by any allowed per-step nullspace update; compare the learned batch with exact reach-avoid, charging online work. **Old-task retention.** Test early exits and unscheduled reads on low-margin A and C along the entire detour.

### 05. Cancel each rival separately when the strongest rival changes — improvement
**Mechanism.** Balance signed gap changes against a changing set of rival classes, not a scalar true-logit or loss trace; allow the highest wrong logit to switch if the true label stays ahead. **Novelty / control.** [GEM][gem] constrains old loss and [CROWN][crown] bounds class differences. The improvement would be admitting useful directions that a single worst-gap surrogate rejects, without replacing exact margin checks. **Cheapest first test.** Enumerate three-class, two-feature heads with two competing rival crossings, compare phase-vector balance to GEM and per-phase gap constraints, and check against exact enumeration. **Old-task retention.** Require every old true–rival gap on A and C to stay positive, including near ties.

### 06. Let groups borrow margin at different times — primitive candidate
**Mechanism.** Route a shared write through three phases so different groups of old items each take a reversible excursion when their own margins have slack; do not allocate one private phase or parameter block per task. **Novelty / control.** [PCGrad][pcgrad] resolves gradient conflicts locally; periodic scheduling alone is switched control. The candidate is a learned reuse of the same coordinates that expands the admitted write set versus per-step joint constraints. **Cheapest first test.** Use a three-reader toy with all write directions forbidden by at least one strict nullspace; compare against PCGrad, a task-specific schedule and a joint margin-constrained optimizer. **Old-task retention.** Check each A/C group at all three phases, with balanced counts and matched low quantiles of pre-write margin.

### 07. Learn cancellation that survives rounding, not exact arithmetic — improvement
**Mechanism.** Train phase terms to leave a range of safe return residuals under independent rounding and small step-size errors, rather than one fragile zero. **Novelty / control.** [Tube MPC][tube] treats bounded perturbations; the improvement must be the width of the useful deployment range versus baseline robust synthesis, not a robustness theorem. **Cheapest first test.** Quantize a tiny two-phase host at several precisions and enumerate signed one-bin perturbations of both updates; compare to a high-precision design and a robust single-phase protector at matched service. **Old-task retention.** Score worst A/C gap in the quantized tail and report the first bit width at which any old decision fails.

### 08. Require the cancellation to pay for a genuinely shared new feature — primitive candidate
**Mechanism.** Make the old-sensitive half-write form a feature needed on unseen combinations of old and new inputs, while its partner offsets old gap drift without erasing that feature. **Novelty / control.** [Progressive Neural Networks][progressive] separate capacity, and [Net2Net][net] preserves outputs while changing representation. The candidate must realize a feature that survives in shared weights after source retirement and costs less than an isolated branch. **Cheapest first test.** Use a tiny compositional regression or classification stream with held-out feature conjunctions; remove the first half-write and compare with a parameter-matched adapter plus exact preservation. **Old-task retention.** Use A/C on both original and recombined inputs, with margins matched before the write.

### 09. Distinguish aligned nuisance by history, not a request tag — primitive candidate
**Mechanism.** Let naturally accumulated curvature or momentum alter which basin an equal-norm, same-direction update reaches after two different histories; use neither a job label nor a freshly written selector. **Novelty / control.** [Adam][adam] already uses history and [Hopfield][hopfield] already stores state-dependent responses. The candidate is useful discrimination by dynamics using the optimizer budget both baselines get. **Cheapest first test.** Construct truthful histories with equal weights but different slots; use aligned job and stale gradients, swap the slots, add an exact full-state collision, and compare to a slot-aware gate and a moment reset. **Old-task retention.** Test A and C under normal, exchanged and reset slots even if the immediate new-task score ties.

### 10. Learn a useful boundary that follows a curved gradient family — improvement
**Mechanism.** Use the first phase to unfold a curved family of useful write directions, then use a second activation boundary to select it without admitting nearby nuisance. **Novelty / control.** [Hamilton–Jacobi reachability][reach] already describes curved sets; show a service gain over a static nonlinear gate given the same probes and model size, not a win on preassigned labels. **Cheapest first test.** Generate job gradients from an unseen arc of a two-feature parameterized target family and adversarially choose near-angle equal-norm stale gradients; compare learned boundaries to linear, quadratic and exact reachability controls. **Old-task retention.** Plot worst A/C margin by distance from the boundary, including false admissions.

### 11. Make rejection resilient to a burst of individually harmless writes — primitive candidate
**Mechanism.** Shape a contracting region that undoes accumulated nuisance between writes without washing out a single comparably sized useful impulse. **Novelty / control.** Disturbance-invariant tubes are standard in [Tube MPC][tube]; the candidate needs a repeatable learned recovery that keeps admitting blind jobs without extra shielding or replay. **Cheapest first test.** Compare one honest gradient with a burst of stale gradients matched on vector sum and cumulative norm where possible; enumerate order and spacing in a two-basin host and compare against a tube filter plus residual store. **Old-task retention.** Measure A/C at the worst burst prefix and after subsequent honest jobs, with missed reads counted.

### 12. Make the undo phase also expand the next safe job set — primitive candidate
**Mechanism.** Learn a return that repays current old-output drift and relocates a shared boundary so a *different* truthful gradient can enter next, without increasing the nuisance catchment. **Novelty / control.** [Optimizing for Online Adaptation][oml] and [meta-experience replay][mer] already shape future gradient utility. The candidate must show a causal expansion of reachable safe jobs due to the compensating phase, not a readiness forecast or lower loss. **Cheapest first test.** Enumerate blind second writes before and after an exact first return; replace the compensating phase with a same-cost one that matches current A and job service, and compare second-job coverage against OML and matched replay. **Old-task retention.** Score A and previously served C before and after both writes, including the first job after the second settles.

### 13. Accept a revision without reopening all earlier commitments — primitive candidate
**Mechanism.** A truthful correction crosses a boundary out of one translated orbit, using the same phase balance to keep unrelated old jobs while changing the one contradicted service. **Novelty / control.** [GRACE][grace] already makes editable local patches, and the parent's card 12 already reverses with counterexamples. The distinct claim is selective *coexistence* after revision with shared phase directions, against GRACE plus protected fine-tuning. **Cheapest first test.** Install two blind rule corrections, revise just one from a new example and search for a move that a per-step protector cannot make at the same budget; include the parent reversal as a one-job baseline. **Old-task retention.** Separate legitimately superseded labels from A and non-target C, checking the latter at every phase and after another unrelated write.

### 14. Absorb two individually weak job writes without integrating matched junk — primitive candidate
**Mechanism.** Keep a decaying phase-local trace so two independently truthful examples jointly cross a useful boundary before the trace fades; uncorroborated writes return to the original tube. After selection, retire both examples. **Novelty / control.** [Modern Hopfield Networks][modern] aggregate cues and momentum accumulates aligned writes. Demand a gain over those controls plus a gate on the same two examples, not a planted rule that always rewards the second write. **Cheapest first test.** Enumerate true/true, stale/stale and mixed pairs with matched norm, angle and spacing on unseen jobs; exact full-state collisions should tie. This explicitly relaxes the one-write contract for this card. **Old-task retention.** Check A/C between writes, on time-out and after the translated orbit settles.

### 15. Reuse one cancellation word across different job basins — primitive candidate
**Mechanism.** A frozen batch sequence cancels old-gap drift for a family of translated orbits despite different activation itineraries, reducing the need for job-specific repair. **Novelty / control.** [Trajectory Matching][mtt] can fit a sequence and [Liberzon][switching] describes common switched certificates. The object must transfer blind across basins with fewer examples or cheaper checks than trajectory fitting per basin. **Cheapest first test.** Fit on two basins, hold out a third, and compare against retraining, pooled MTT and a common robust bound at equal budget; require the held-out orbit to serve an unseen job. **Old-task retention.** Probe phase-sensitive A/C in each basin, especially old examples not used in fitting the word.

### 16. Audit when first-order cancellation leaks into a rare old failure — improvement
**Mechanism.** Include second-order gap changes or a reachable mask switch in the first-test acceptance rule, so a zero linear residual cannot hide a reproducible tail failure. **Novelty / control.** [CROWN][crown] bounds nonlinear networks and the parent already checks mask margins. This is an audit improvement, not a Hessian or Gramian reserve estimator; compare directly with robust bounds and sampled trajectories. **Cheapest first test.** Use two toy hosts with identical phase Jacobians at the nominal orbit but different nearby ReLU kinks; see which check predicts failure with the fewest model calls. **Old-task retention.** Count actual rare A/C label flips in exhaustive finite-radius trajectories, not only certificate rejections.

### 17. Keep cancellation safe if the reader asks at the worst time — improvement
**Mechanism.** Synthesize a period with prefixes that stay inside the old decision region even when a read arrives just after an update, or when the next update is delayed. **Novelty / control.** [Simplex runtime assurance][simplex] and reach-avoid already protect intermediate states. The improvement would be more useful jobs without delaying queries or falling back to a stored model. **Cheapest first test.** Insert every legal read and one missed phase in a finite stream; compare against worst-case shielding and a two-phase scheme audited only at return. **Old-task retention.** Score old service at each exposure rather than crediting a delayed answer as retained.

### 18. Repair the cancellation after an unmodeled write without remembering it — primitive candidate
**Mechanism.** Use one fixed lawful probe to reveal enough of the live phase response to restore balance, even when several unobserved writes are consistent with the weights that can be inspected. **Novelty / control.** [Dual control][dual] already acts to learn; [GRACE][grace] can remember the edit. The candidate is a small reusable compensator that works for an entire probe-equivalence class without a write log. **Cheapest first test.** Make two hidden slot states agree on initial observations but differ after one probe; compare to blind repair, a generic information-gain probe and bounded search, with an indistinguishable pair requiring opposite actions as the negative. **Old-task retention.** Require A and C to survive the diagnostic step itself as well as the repaired tail.

### 19. Make the useful basin survive a change of phase convention — improvement
**Mechanism.** Learn readout and update conditions that identify an orbit from its state rather than an external clock and still preserve the intended job under a phase relabeling. **Novelty / control.** The parent's either-phase trigger is the nearest tree control; [switched-systems stability][switching] already handles phase indexing. Test whether cancellation plus selective nuisance rejection survives an unknown start phase, not merely whether both starts work separately. **Cheapest first test.** Blind the start phase for a single fixed step policy on a two-orbit host; compare with the parent's trigger and an explicit one-bit clock at charged state cost. **Old-task retention.** Check A/C from both possible phases and during all misaligned nuisance returns.

### 20. Measure the price of making two job basins jointly accessible — primitive candidate
**Mechanism.** Find a boundary arrangement where two job types can each be admitted after the other with the same shared coordinates, but only if phase compensation releases room for their two paths. **Novelty / control.** [Hopfield][hopfield] stores multiple attractors, and [GEM][gem] measures sequential interference. Here each terminal orbit must serve **both** jobs after both sources retire; two isolated single-job attractors are not storage. **Cheapest first test.** Enumerate both orders of two blind gradients and both matched nuisance substitutions; compare a size-matched multi-attractor net and GEM plus a residual bank, counting all candidate probes. **Old-task retention.** Score A and both jobs at every read after their acquisition, not the better of the two orders.

### 21. Prove when cancellation cannot buy any extra room — improvement
**Mechanism.** Given the allowed write family and a certified tube, separate directions that require transient old drift from those that any viable projector or static gate can already keep. Return a finite counterexample or equivalence when the candidate buys nothing. **Novelty / control.** [Reachability][reach] can compute feasible sets already; this is a cheap falsifier, not a new verifier or an edit-capacity predictor. **Cheapest first test.** Enumerate small piecewise-affine systems where projected and dynamic admissible sets are known to coincide, then a counterexample with a detour as in card 04; compare the test's decisions and cost to exact enumeration. **Old-task retention.** Include A/C constraints at exposed steps in both sets, so apparent separated directions that only work by missing old reads get no credit.

### 22. Make the phase contribution reusable when the write coordinates change — primitive candidate
**Mechanism.** After learning a new shared representation, reuse a small phase-transport map that preserves cancellation and useful-versus-nuisance admissions, instead of fitting separate repairs in the new coordinates. **Novelty / control.** [Net2Net][net] preserves functions and [Git Re-Basin][rebasin] aligns parameters; neither a pure basis relabeling nor an exactly recovered old host counts. The test is continued service after a real representational change. **Cheapest first test.** Replace one shared feature after installing a job, keep a pure permutation as positive control and an aliasing compression as negative, and compare a bounded transport map with re-basin alignment and full recertification at equal budget. **Old-task retention.** Recheck absolute A/C across both phases and after a new blind job and its equal-norm nuisance.

## Ranked deeper questions

1. **Can phase cancellation and basin selectivity jointly admit a truthful blind write that the best protector plus store cannot retain at equal cost?** Start with 01–04. Demand nonzero old-output motion, safe reads at every phase, a causal loss of admitted service when compensation is removed, and distinct attracting job and nuisance destinations in the same frozen host. If the stacked baseline ties or the gain depends on reading only on return, drop the joint primitive.
2. **What lawful information separates near-aligned useful and nuisance writes?** Start with 02, 09 and 11. Measure overlap as norms and angles are matched, then swap histories or force complete collisions. If all separation disappears without an external selector or is just amplitude thresholding, keep the impossibility result rather than claiming semantic selectivity.
3. **How much phase slack remains when protection must work for actual readers?** Start with 05–07, 16 and 17. Use unseen rivals, rounding and worst-time queries at matched old margins. If the gain fits only an exact two-step clock or a wide-margin subset, report that restricted service regime.
4. **Can the same compensating dynamics survive more than one useful change under a fixed budget?** Start with 12, 13, 15 and 20. Compare both acquisition orders, then one revision and an unrelated write, against protected replay and a size-matched edit bank. If old commitments fall away at the same rate as plain fine-tuning, keep only the single-write result.

These are nearest comparisons, not exhaustive novelty claims. The first gate is an exact or enumerated CPU case with held-out job service and ordinary old-task retention, not additional oscillation or an oracle-labelled basin.
