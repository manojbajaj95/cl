# Harness → can a large model learn *where to intervene* from paired forwards plus falsifying probes?

Parent: [agent-harness node, PR #47](https://github.com/manojbajaj95/cl/pull/47), ranked next node #2. Ideation only: no experiments were run for this node.

**Question.** Can a large model (the *locator*) learn where to intervene on a small agent (weights, activations, harness slots) from paired forward passes plus probes that try to disprove its guess, and so replace gradient credit?

## Root cause: forward evidence locates where a behavior is *read*, credit for learning needs where a write is *sufficient, stable and non-interfering*; probes written from the guesser's own prior cannot close that gap

Gradient credit gives, in one backward pass, a dense, signed, local quantity per parameter, *tied to the write operator* (an SGD step at that address changes loss by about −η‖g‖²). Paired forward passes give something different, and four documented failures follow from the difference:

| Failure | Evidence | What it means for a locator |
|---|---|---|
| **The patching estimand is not per-site credit.** | [Curse of Multiple Mediators (2606.27510)](https://arxiv.org/abs/2606.27510): the activation-patching NIE contains interaction terms (INT); the residual stream makes every component a recanting-witness case by construction; IOI backup name movers are invisible or inflated; INT variance explains faithfulness-score instability; INT is negligible only when the model is locally affine. | A single "the fault is at X" guess is ill-posed when INT is large. The locator must output a *set with interactions*, and one paired forward per site cannot estimate that set. |
| **Localization does not predict editability.** | [Hase et al. (2301.04213)](https://arxiv.org/abs/2301.04213): Causal Tracing peaks are uncorrelated with ROME/MEMIT/Adam edit success on CounterFact (ρ slightly negative); edit layer is a better predictor than tracing. [Localization ≠ Steerability (2611.07478)](https://arxiv.org/abs/2611.07478): the same late-MLP sign circuit flips 13/14 held-out errors on Llama-3.3-70B but almost nothing on Phi-4, where the sign is written redundantly across ~15 layers with a median margin of 17.8 logits. [MechSparse (2609.18961)](https://arxiv.org/abs/2609.18961): patch-recovery-selected LoRA sites never win the primary metric; they trail activation-norm by 0.028 F1 on IE, and all selectors tie within 0.30 BLEU on MT. | Forward evidence is about the *read path*; whether a write sticks depends on redundancy, margin and the write operator. The repo's [model-guided-edits node (PR #49)](https://github.com/manojbajaj95/cl/pull/49) already found that a covariance-aware operator cuts random-site regret from 16.7 to 0.38, so choosing a site has little headroom once the operator is good. |
| **Self-written probes are self-sealing.** | [InterpAgent (2605.01555)](https://arxiv.org/abs/2605.01555) and MAIA-style agents propose hypotheses and test them with their own contrastive prompts; [Who&When Pro (2607.09996)](https://arxiv.org/abs/2607.09996) shows LLM failure attribution stays weak as failures get subtle; [REFLECT (2606.09071)](https://arxiv.org/abs/2606.09071) needs explicit interventions to attribute silent failures. [Objectives inflate subspace interventions (2611.05033)](https://arxiv.org/abs/2611.05033) and the [subspace-patching illusion (2311.17030)](https://arxiv.org/abs/2311.17030) show that an optimized intervention can "work" through a dormant pathway. | If the same model writes the guess and the probes, the probes sample where it already believes the mechanism lives. Surviving refutation then measures probe weakness, not guess correctness. Nothing in current systems prices probe *power*. |
| **No amortization and no retention term.** | Auto-interp agents and patch-based circuit finders ([attribution-patching correction 2610.27393](https://arxiv.org/abs/2610.27393), [gradient-spectral circuits 2611.30939](https://arxiv.org/abs/2611.30939)) solve each question from scratch and score explanations, not downstream writes. [Prior or Feedback? (2610.12325)](https://arxiv.org/abs/2610.12325) shows an LLM tuning loop does respond to feedback, but over a 20-trial config space, not an address space. Attribution-guided CL ([2605.05285](https://arxiv.org/abs/2605.05285), [CRAFT 2605.05732](https://arxiv.org/abs/2605.05732)) uses gradient/attribution scores, not a learned locator. | The locator never gets a learning signal of the form "your address was written, then the stream moved on, and this is what survived". So it cannot learn what gradient credit gives for free: consistency between *where* and *what happens when you write there*. |

Already-covered neighbours (from memory and the ledger): self weight-space programming where a big model picks edits (Self-WSP 2611.28833, SelfWrite 2611.29513) ties random search; ES at scale (2509.24372, EGGROLL 2511.16652) already does forward-only post-training; counterfactual message credit (2609.30734 etc.) was killed at proposal; [harness-discrete-backprop (PR #52)](https://github.com/manojbajaj95/cl/pull/52) found that a failure yields a *repair set*, not a write address. The ideas below therefore treat the locator's output as a **set plus a write, scored by refutation power and later retention**, and each must beat **random site + data-aware operator** and **activation-norm site choice** at equal forward budget.

**One-line hypothesis for the node.** The missing primitive is not a better guesser; it is a *priced adversary*: a separate refuter whose probes are rewarded for overturning the locator's claim *about the write outcome* (including retention), so that survival under refutation becomes a credit signal with known power.

## Raw ideas (no self-filtering)

Each card: mechanism · why new · cheapest first test (with retention check) · tie-risk control.

1. **Refuter-priced credit.** Locator emits (site set S, write w, predicted effect on target and on protected probes). A separate refuter model is rewarded for finding probes where the prediction fails. Credit for S = refuter budget spent before first refutation. *New:* falsification power becomes a scalar credit with a cost, like a p-value from a stopping time. *Test:* 2-layer MLP agent on a 4-regime toy stream, 64 candidate sites; compare sites ranked by survival time vs gradient magnitude vs activation norm; retention = accuracy on regime-1 probes after regimes 2–4. *Tie risk:* random site + ROME-style operator.
2. **Survival-time distillation into a locator.** Log (pair, guess, refutation time) tuples across many tasks; fine-tune a small locator to predict long-surviving sites from the pair alone. *New:* amortizes falsification across tasks; current agents restart per question. *Test:* same toy stream, 200 tasks, held-out task family; retention as above. *Tie:* activation-norm site choice.
3. **Interaction-aware guesses (INT-sets).** Locator must name a set and its predicted pairwise interaction signs; refuter attacks the interaction claims via joint patches. *New:* uses 2606.27510's INT as the hypothesis object rather than a nuisance. *Test:* IOI-style toy with planted backup units; check that the set found has fewer hidden backups than greedy NIE; retention: unplanted behaviour preserved after writing at the set. *Tie:* greedy NIE plus one combinatorial pass.
4. **Write-outcome falsification (not read-path).** The refuter's target is the claim "a write of norm ε at S fixes the target and leaves protected behaviour within δ", tested by *actually applying* tiny writes in forward-only mode (perturb, forward, revert). *New:* closes the Hase gap by making the hypothesis about edit success, not storage. *Test:* GPT-2 small, 200 CounterFact facts; compare to Causal Tracing site choice; retention: 500 unrelated facts. *Tie:* fixed best layer (Hase's predictor).
5. **Redundancy probes as first-class.** Before any write, the refuter tries to show the behavior is redundantly written (ablate S, check recovery elsewhere); a locator claim must include a redundancy estimate. *New:* prices the Phi-4 failure up front. *Test:* toy nets trained with dropout (redundant) vs without; does the redundancy estimate predict edit failure? *Tie:* margin alone.
6. **Margin-conditioned site choice.** Locator predicts the logit margin a write at S must overturn; refuter seeks inputs where margin exceeds the write budget. *New:* turns 2611.07478's margin finding into a refutable precondition. *Test:* constrained-action router from PR #14 at 0.5B; retention: off-target state accuracy. *Tie:* margin-ranked random site.
7. **Paired forwards as a sparse Jacobian sketch, LLM only for set proposal.** Use k random-direction forward differences to get a compressed Jacobian; the LLM chooses which subspaces to sketch next given failed refutations. *New:* combines ES-style forward estimation with hypothesis-driven measurement allocation. *Test:* MLP toy; compare equal-forward-budget ES; retention as #1. *Tie:* ES with antithetic sampling.
8. **Disagreement-maximizing probe generation.** Two locators with different priors; probes chosen to maximize their disagreement on predicted write outcomes (BALD over hypotheses). *New:* probe power comes from model disagreement, not self-consistency. *Test:* 2 small LLM locators on the toy; measure bits per probe. *Tie:* random probes from task distribution.
9. **Retention-refuter.** A refuter that only gets reward for finding *old* behaviors broken by the proposed write. Credit for S = (target gain) × (refuter failure rate on old behaviors). *New:* retention enters credit before the write, not after. *Test:* 4-regime stream; compare to EWC importance at equal compute. *Tie:* EWC / Fisher masking.
10. **Harness-slot locator.** Same refuter game over a harness (prompt sections, tool wrappers, memory slots), with paired rollouts where one slot is swapped. *New:* treats harness slots like circuit nodes with INT; PR #52 says a failure gives a repair set—this ranks members of that set by refutation survival. *Test:* PR #14 router with 6 harness slots; retention: success on earlier task families. *Tie:* leave-one-slot-out ablation.
11. **Counterfactual twin streams.** Run the small agent on two streams differing in one fact; locator names where the divergence is stored; refuter must construct a third stream where the named site is unchanged but behaviour diverges. *New:* the refutation target is a stream, not a prompt. *Test:* toy RNN agent on gridworld with a moved goal. *Tie:* representation-diff norm per site.
12. **Proof-carrying addresses.** A site claim ships with the probe set that failed to refute it; later writes at the same site must re-pass that set. *New:* addresses become objects carrying their own falsification history (cf. PR #47 idea of a skill carrying its experiment). *Test:* sequential edits on GPT-2 small; does re-passing predict which edits survive later edits? *Tie:* re-running the edit's own efficacy prompts.
13. **Popperian bandit over sites.** Sites are arms; pulling an arm = one refutation attempt; reward = survival; regret is measured against an oracle that knows the true sufficient set. *New:* gives falsification a regret bound, which gradient credit does not need but a forward-only locator does. *Test:* planted-circuit MLP; regret curve vs UCB on patch effect. *Tie:* UCB on NIE.
14. **Locator trained by write consequences (hindsight credit).** After each write and k stream steps, label the site with realised retention and gain; train the locator on these labels only. *New:* the locator's training target is delayed write outcome, not interpretability faithfulness. *Test:* 50-task slowly-changing regression (as in the plasticity pilots). *Tie:* first-order gradient-magnitude ranking — note prior kills there; must show target variance gate first.
15. **Adversarial coordinate change.** Refuter applies function-preserving reparameterizations (rescales, permutations) and checks whether the locator's claim moves. *New:* gauge-invariance becomes a falsification test (PR #49 found raw-weight choosers gauge-dependent). *Test:* MLP with ReLU rescale symmetry. *Tie:* canonicalized gradient.
16. **Credit from the *cheapest refutation*.** Instead of survival, credit = minimum perturbation size needed to refute the claim, found by the refuter (like a robustness radius). *New:* gives a continuous, signed quantity comparable to gradient magnitude. *Test:* compare its rank correlation with true edit benefit vs |g|. *Tie:* |g·Δ| attribution patching.
17. **Locator–refuter self-play curriculum.** Alternate training: locator learns from survived claims, refuter learns from broken ones; track an Elo. *New:* AlphaZero-style self-play applied to credit assignment. *Test:* toy MLP family with planted circuits of varying redundancy. *Tie:* fixed refuter.
18. **Probe-set compression into a "test-time gradient".** Distil the refuter's probe distribution into a small set whose paired-forward differences approximate the gradient direction for the write. *New:* makes falsifying probes literally a gradient surrogate; checkable against true gradients. *Test:* cosine to true gradient vs random-probe ES at equal forwards. *Tie:* ES.
19. **Cross-model locator transfer.** Train the locator on many small agents (different seeds/architectures); test on a new architecture with only paired forwards. *New:* a portable "where to write" prior independent of the target's internals. *Test:* train on 20 MLP seeds, test on a held-out width. *Tie:* activation-norm.
20. **Refutation over futures, not inputs.** The refuter samples plausible future stream segments (from a world model) and checks whether the write survives them. *New:* retention becomes a property the refuter attacks before the write. *Test:* regime stream with known future generator. *Tie:* replay of past regimes at equal budget.
21. **Negative addresses.** The locator also names where *not* to write (sites whose perturbation breaks protected probes); refuter tests these "no-write" claims. *New:* a mask learned by falsification instead of Fisher. *Test:* vs EWC Fisher top-k mask. *Tie:* Fisher mask.
22. **Interventional typing of sites.** The refuter classifies each site by response type (stamp, amplifier, rescue, per 2611.07478) using paired forwards; writes are allowed only at stamp-type sites. *New:* a site *type system* derived from falsification. *Test:* planted toy with all three types. *Tie:* layer-depth heuristic.
23. **Locator as compressor of refutation logs.** Score a locator by the MDL of the refutation log it explains. *New:* model selection over locators without ground truth. *Test:* compare MDL rank of 3 locators to their true edit regret. *Tie:* held-out patch accuracy.
24. **Harness-to-weights handoff via refuted claims.** When a harness-slot claim survives K refuters, compile it into a weight write at the site the locator names; otherwise keep it in context. *New:* refutation survival gates substrate transfer. *Test:* router with LoRA option; retention on earlier families. *Tie:* always-consolidate.

## Ranked sub-questions (most likely to yield a new primitive first)

1. **Can refutation survival, with a separately trained refuter, be a credit signal with measurable power that ranks write sites better than random + data-aware operator and activation-norm at equal forwards?** (ideas 1, 4, 9, 16). If yes, "priced falsification" is a credit primitive usable where gradients are unavailable (harnesses, black-box agents).
2. **Can a locator be amortized across tasks from write-outcome labels (gain and later retention), and does it transfer to unseen agents or architectures?** (2, 14, 19). A transferable "where-to-write" prior is a new object; the risk is the low headroom PR #49 measured.
3. **Is the right hypothesis object an interaction set with a redundancy and margin certificate, rather than a site?** (3, 5, 6, 22). This addresses the two strongest documented failures (INT and redundancy) directly.
4. **Can falsifying probes be distilled into a gradient surrogate whose cosine to the true gradient beats ES at equal forwards?** (7, 18). Most checkable, but closest to existing ES/zeroth-order work, so more likely an improvement.
5. **Do the same refuter games work over harness slots, so a failure's repair set (PR #52) can be ranked without gradient credit?** (10, 12, 24). Practical for agents; novelty depends on beating leave-one-out.
