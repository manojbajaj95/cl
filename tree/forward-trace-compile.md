# Can a counterfactual trace compile into a reusable weight write?

Depth 2 of [forward-only learning](https://github.com/manojbajaj95/cl/blob/devin/1795538492-model-forward-only/tree/model-forward-only.md) ([PR #50](https://github.com/manojbajaj95/cl/pull/50)). A trace is more useful than a score: it identifies an activation worth testing. But **a witness that an intervention works on one input is not an address for where it should work, and a list of addresses is not a rule for combining edits.** The target primitive is to discover and install a *selectively executable* causal intervention, not just to fit an update from examples.

## Root cause: the trace observes a value, not its domain

Take an MLP output projection at layer L. Let k(x,t) be its input at token t and v the residual difference with vs. without a fact in context at one final token. A rank-one write ΔW = v aᵀ delivers v(aᵀk(x,t)) at **every** position. The trace gives one requested equality aᵀk₀ = 1. Any vector u orthogonal to k₀ can be added to a without affecting that equality, yet can change the effect anywhere keys have a component along u. Neither the intended paraphrase set nor the set where the edit should do nothing is identified. A covariance penalty chooses a low-energy extension under its background distribution; it does not label semantic positives or negatives. Multiple positive keys add constraints but do not determine unseen scores or prevent near-neighbor activations. If two inputs have identical keys and need different effects, **no** write to this projection can distinguish them.

Even a correct final-token address isn't sufficient. The context contrast can include syntax, positions and copying, and downstream effects of the vector depend on the rest of the residual stream. A weight edit also moves earlier positions, unlike a final-token patch. Two same-layer writes add linearly *at the projection*, because its input is unchanged by these writes; cross-firing there adds the wrong value, and downstream processing need not preserve either logit effect. Across layers one edit can also change another's keys, which this probe does not test.

| Precedent | What it buys, and what it leaves open |
|---|---|
| [ROME](https://arxiv.org/abs/2202.05262), [MEMIT](https://arxiv.org/abs/2210.07229), [EMMET](https://arxiv.org/abs/2403.14236) | Causal localization plus key/value editing, covariance-preserving objectives, multi-edit and multilayer variants, and equality-constrained batched editing already exist. Fitting more keys or solving exactly isn't a new primitive. The open question is discovering the applicability domain from forward evidence and predicting interference on situations absent from fitting. |
| [Activation patching best practices](https://arxiv.org/html/2309.16042), [does localization inform editing?](https://arxiv.org/abs/2301.04213) | What gets localized depends on corruption and readout; Hase et al. found little or no relationship between their causal-tracing localization and the best layer to edit in their setting. A useful local intervention needn't be the right parameter interface for a reusable intervention. |
| [Weight-Space Programming Writes In-Context Learning](https://arxiv.org/html/2611.26841) | Already synthesizes weight programs to imitate an ICL trace, with three unseen wordings, other-task interference and WikiText/ARC checks, plus short compositional tasks. It often writes both when a unit fires and what it adds. Open target: infer an applicability contract and link independently compiled writes for unpredictable rules, rather than fitting one behavior and checking transfer afterward. |
| [SERAC](https://arxiv.org/abs/2206.06520), [GRACE](https://arxiv.org/abs/2211.11031) | Explicit scope and routing are established controls: external retrieval and counterfactual prediction (SERAC) or a key/value codebook with coverage radii (GRACE). A compiled domain must beat these on transfer or composition at matched state/cost, or justify installation into ordinary weights rather than storing a gate and value. |
| [ROME multi-hop limits (2601.04600)](https://arxiv.org/abs/2601.04600), [DMLE (2604.08284)](https://arxiv.org/abs/2604.08284) | Late-layer ROME writes lose paraphrase generalization and "hop too late" for two-hop questions; redundant multi-layer copies buy +15.5 pp 2-hop accuracy at a specificity cost. Rule knowledge is form-specific across depth (formulas/descriptions early, instances mid), so one key site misses forms; DMLE's two-site write gains +13.91 pp instance portability. Both pick sites by tracing; neither infers the consumer side. |
| [Doc-to-LoRA analysis (2611.30825)](https://arxiv.org/abs/2611.30825), [ACE context encoding (2610.17686)](https://arxiv.org/abs/2610.17686) | Compiled-context adapters lack a selector: 46% of D2L's wrong answers are another answer from the same passage, and summed adapters collapse (Gemma K=16, F1 .111 when the full bank is applied below layer 8). ACE restores a context's role only by binding it to an explicit identifier recalled at inference. Domain and routing, not payload, are the bottleneck in both. |

- **Addressing contributed to the transfer miss.** The same payload raised the single trace query from 0.42% to 46.51% with a direct patch, and the single-key write reached 47.19% (random did nothing). Fitting more keys reduced mean held-out absolute firing error from 0.547 to 0.263 and improved held-out target probability from 1.30% [95% bootstrap interval 1.02–1.60] to 4.54% [3.68–5.40]. However, correct activation delivery alone did **not** restore the trace-query effect on paraphrases: the unit-amplitude final-position patch only reached 6.02% [4.88–7.18]. The hypothesis that addressing is the *only* problem fails this check. The value or intervention site is also context-dependent; the probe doesn't separate syntax, position, downstream dependence and missing sites. Even on *train* paraphrases the exact LS fit gave 9.01% mean probability vs. 12.48% for the mean key: reproducing a final-position coefficient needn't optimize behavior.
- **Positive keys learned broad wording sensitivity, not subject selectivity.** The LS write fired at unit coefficient on its six fitted keys but at mean absolute coefficient 0.951 on the wrong subject using the same query wording (single key: 0.945). The +34.69 pp wrong-subject target leakage shows this is behaviorally consequential despite low WikiText KL. Installing a second LS write dropped the target probability on the *unchanged* trace query by 8.94 pp [4.10–13.64 drop]. These are direct measurements of cross-firing and harm; they don't isolate how much of the drop is due to final-token cross-firing versus earlier positions or downstream interaction. The unconditionally summed patch also interfered. Asking for the right city with both names in context is harder routing, not transitive or multi-step reasoning over both learned values.

This is a one-model, one-relation, two-write probe with templated English and a small general-retention sample. Factors such as subject-token addressing, matched context controls, other layers, richer payloads and negative-fit keys were not tested. It establishes an identifiability gap for the isolated trace, not an impossibility of compilation with richer forward evidence.

## Raw ideas (unfiltered)

These are candidate objects or operations, not novelty verdicts. The contrasts say what each would have to add. The [idea ledger](https://github.com/manojbajaj95/cl/pull/6/files) ([PR #6](https://github.com/manojbajaj95/cl/pull/6)) makes the bars concrete: don't rebrand a weight ISA, sparse-syndrome repair, or generic composition contracts; compare to the prompt-addressable checkpoint, round-trip consolidation and self-readable seed-log survivors where relevant. Each first test includes an old-behavior check; compare retention at matched acquisition.

1. **Counterfactual boundary query.** Change exactly one relation, role or subject and ask whether the fact-on/fact-off effect persists. Compile the nearest disagreeing traces into a signed domain. The candidate operation is a boundary oracle for writes, not a denser paraphrase set or retrieval score. **First test:** train on nonce cities and held-out roles; compare equal-token positive-only and text nearest negatives. Check unaffected biographies and different relations for the edited subjects.
2. **Trace equivalence transport.** Learn whether a syntactic rewrite transports an address, a payload or both. Compose transports and require two rewrite paths giving the same query to give equivalent interventions. Unlike paraphrase augmentation, the transport applies to the next unseen payload. **First test:** learn active↔passive and Q↔A separately; test their untrained combination against matched augmented regression. Check old rules and lexical near misses.
3. **Collision-triggered feature split.** Find keys the projection can't distinguish but that need opposite treatment; test an upstream split and absorb it into unused channels. Unlike broader routing or a higher-rank edit, add a distinction only on a witnessed alias. **First test:** rotated synthetic MLP with deliberately merged role bit, versus increased rank at equal bytes. Check other decisions made by the original shared feature.
4. **Slot-relocatable trace.** Represent source role, destination role and value separately; place the payload at a token selected by a learned binding operation. The address travels with a role, not a subject string or absolute index. **First test:** nonce two-slot tuples with reordered slots and clauses, against GRACE. Check old tuples and the unaffected slot of edited tuples.
5. **Trace linker with bilateral probes.** Compile each write with forward tests distinguishing necessary key directions from incidental ones; link writes by satisfying both probe sets, allocating a direction on conflict. The object is a relocatable dependency interface, not joint MEMIT over raw examples. **First test:** independent writes on toy overlapping predicates; compare joint retraining and Gram/sketch matching at equal state and queries. Check a third untouched predicate.
6. **Directional write commutator.** Use local interventions to measure the effect of routing-then-writing vs. writing-then-routing; keep a cross-term only if it restores both responders. This is an operation for a specific interaction, not a claim that same-layer matrix additions don't commute. **First test:** two layers on a toy lookup where one write moves the other's key; compare isolated and joint low-rank edits. Check old pairs with neither edit and with exactly one.
7. **Difference-of-differences payload.** Factor contrasts from a correct context and a matched wrong-answer context, retaining components that swap with the value across nonce names. The candidate object is a payload that can be relabeled, not merely a more salient direction. **First test:** switch four city tokens and context templates in GPT-2; compare patches to the raw contrast. Check unrelated completions and queries about a different relation.
8. **Witness-carrying rejection.** Return a concrete counterexample to an edit's admissibility (e.g., identical activations needing different deltas), not a confidence score. Another compiler could choose an upstream split or abstain without installation history. **First test:** hide aliases in an MLP; compare with thresholding editor confidence at matched coverage. Check old facts on both rejected and accepted edits.
9. **Many-to-one trace unification.** Find token-role interventions that give different successful chains equivalent effects, then compile one rewrite. Unlike averaging traces, the abstraction is a rule with substitutable input roles. **First test:** unify the traces for x + 2 + 3 and x + 3 + 2; test unseen inputs versus activation averaging. Check subtraction and the original additions.
10. **Branch compression into in-weight guards.** Learn a piecewise edit from mutually exclusive traces, fuse selection and payload into a pre-existing MLP, and recover the branch index with a diagnostic intervention. What could be new is bidirectional compilation of branches, not adapter routing. **First test:** contradictory rules under nonce mode bits versus prompt routing and a small gated adapter. Check behavior when mode is absent and on the base rule.
11. **Counterexample-driven address allocator.** Use a fixed-width space; add an address only when a searched collision changes an old response, and relocate earlier writes with a validated change of basis. Unlike a static reserve, allocation and relocation are triggered by behavior. **First test:** stream overlapping facts through a 32-wide model versus fixed banks and online orthogonalization. Check old facts and unrelated probes after each relocation.
12. **Causal guard extraction at two scales.** Find where a write generally works and where an opposite perturbation cancels it. Install the exception as an override with precedence learned from swaps. Unlike a radius lookup, move the exception across different payloads without relearning it. **First test:** synthetic exception rules with shifted means versus multi-radius codebooks. Check old defaults and third rules sharing the exception cue.
13. **Write demultiplexer.** Encode two payloads in a shared transient direction and learn which to decode from separate contextual traces. The object is a shared channel preserving independent address/value meanings, not a PCA of deltas. **First test:** inject independent values for two roles into a tiny transformer versus separate rank-one writes at equal state. Check simultaneous queries and pre-existing roles sharing the channel.
14. **Counterfactual inverse test for installability.** Patch the post-write state toward the no-fact trace; use failure to infer missing position, layer or address conditions. This borrows round-trip consolidation but tests behavioral inverses, not numerical weight reversibility. **First test:** compare one-position and multi-position teachers with identical final vectors on some inputs. Check old outputs on non-target roles after install and counter-intervention.
15. **Context-free trace program induction.** Remove demonstrations in chunks, trace which intermediate operation disappeared, and compile interchangeable operators. The novelty would be operators that remain callable under unseen compositions; matching ICL alone is done. **First test:** three toy rules with planted operators against WSP-style trace regression. Check previously installed operators and unrelated ICL tasks.
16. **Scope transfer across checkpoints.** Use only old intervention witnesses and new forward passes to re-establish scope under drift, without replaying answers. Unlike restoring a checkpoint, install a causal domain in a different basis. **First test:** rotate or mildly fine-tune a toy model; compare aligned probes, raw transplant and recompilation from examples. Check original tasks and new tasks acquired before transplant.
17. **Value-dependent negative-space probe.** Search for off-domain positions where the payload changes behavior, not just where the key fires. Expose those constraints so future payloads can query whether they trigger old boundaries; unlike a global veto, audit specific address/value interactions. **First test:** tiny transformer with planted sensitive directions versus random retention, nearest-key search and replay. Check private off-domain tasks with separate sensitivities.
18. **Proof by commuting paraphrase and installation.** Ask whether querying a rewrite after installation has the same effect as transporting the edit and then querying. Refine equivalence classes with counterexamples. Novelty would be a portable invariance specification, not equal answers on two known strings. **First test:** linearized network with planted invariances and nonlinear exceptions versus paired consistency regularization. Check protected, distinguishable intents remain distinct.


### Second batch (independent proposer pass)

Same format target: mechanism, closest prior art, first test, retention check. Overlaps with batch one and with ledger kills (e.g. idea 26 is near the killed weight-ISA framing) are left in for the reviewer.

19. **Quantified traces (∀-patching) — primitive.** Instead of one trace, run the counterfactual on a *generated family* of inputs (paraphrases, distractor contexts, compositions) and fit the write to the family's key manifold with an explicit *negative* family (inputs where the write must be silent). The compiled object is a pair (domain classifier on keys, value map), written as a gated MLP unit. **New vs ROME/MEMIT/WSP-ICL:** those take the key from one or a few templates; nobody treats the domain as a first-class learned object fitted from forward-only positives *and* negatives. **First test:** arm (c) of the probe plus a negative-key set; target ≥ +20 pp held-out paraphrase over single-key ROME at equal wikitext KL. **Retention:** wikitext KL, other-subject leakage.
20. **Trace types / weight-space interfaces — primitive.** Each compiled write declares an input type (the subspace it reads) and output type (the subspace it writes), measured by patching which downstream components consume its value. Composition is allowed only when type(out_A) ⊆ type(in_B); otherwise the compiler inserts an adapter. **New vs task arithmetic / TIES:** those sum deltas blind; here composition is checked like a function signature. **First test:** two-hop nonce chains (A's object is B's subject); compare type-checked placement (B's key layer ≥ A's write layer) against ROME-at-causal-trace-layer and redundant editing (2601.04600). **Retention:** single-hop A, B accuracy and wikitext KL.
21. **Counterfactual linking (the "linker" for writes) — primitive.** Treat each write as an object file with unresolved symbols: the downstream heads that must attend to its output. A link step runs forward passes with the write active, finds heads whose attention to the edited position does not change (unresolved), and adds minimal QK edits so they do. **New vs DMLE (2604.08284):** DMLE picks two layers by causal tracing; nobody resolves the *consumer* side explicitly. **First test:** nonce fact + multi-hop and "reverse" questions (object→subject); linked vs unlinked writes. **Retention:** attention-pattern KL on unrelated text.
22. **Paraphrase-orbit canonicalization — primitive.** Learn (forward only, from paraphrase pairs) a projection P that maps every surface form of a query to a canonical key; compile writes in P-space once, so every future write inherits paraphrase invariance. **New:** a shared, reusable key canonicalizer amortized across writes, vs per-edit key averaging. **First test:** fit P by least squares on 200 paraphrase pairs of *other* facts; compile nonce writes in P-space with a single template; held-out paraphrase vs arm (a)/(c). **Retention:** wikitext KL; check P does not merge distinct subjects (leakage).
23. **Contrastive-pair compiler (trace diffs, not traces) — primitive.** Compile from pairs of counterfactuals that differ in exactly one variable (subject swapped, relation swapped) so the write captures the *variable binding* rather than the surface; the value map is solved as a bilinear (key ⊗ variable) write. **New vs CAA/RepE contrastive steering:** those yield one vector; this yields a variable-indexed tensor write that generalizes to unseen bindings. **First test:** 10 nonce subjects × 3 relations, compile from 60% of cells, test 40% held-out cells. **Retention:** real-fact accuracy for the same relations.
24. **Self-paraphrase immune check (write must survive its own adversary) — improvement.** After compiling, the model itself generates paraphrases most likely to break the write (lowest target prob), and those are folded back into the domain fit; iterate. **New vs active learning:** the adversary searches the key domain of a weight write, generated by the edited model. **First test:** 3 rounds; held-out human-written paraphrase accuracy vs random paraphrase augmentation at equal forward passes. **Retention:** leakage onto adversarial near-miss subjects.
25. **Write algebra via commutator traces — primitive.** Measure [A,B] = f(A∘B) − f(B∘A) on forward traces; writes with near-zero commutator are summed, non-commuting ones are compiled jointly into one block-solve. A library of writes carries its commutator graph. **New vs model merging:** an explicit, measured composition law per write pair instead of a global merge heuristic. **First test:** 20 writes, predict which pairs interfere from commutators vs from key cosine; joint-solve those. **Retention:** per-write efficacy after all 20, wikitext KL.
26. **Gated near-silent units as a write ISA — primitive.** WSP-ICL editors spontaneously write into "near-silent MLP units keyed to the prompt format" (2611.26841). Make this the instruction set: allocate dead units, set their input weights to a domain key (idea 1), output to the trace value, with a learned threshold. Writes become addressable, removable, countable. **New:** a standard, allocator-managed write format rather than editor-improvised ones. **First test:** compile 50 nonce facts into 50 dead units of GPT-2 layer L; compare to MEMIT batch at equal parameter count. **Retention:** wikitext KL and capacity curve (efficacy vs #writes).
27. **Trace-to-write via the model's own ICL as teacher at every depth — improvement.** Instead of matching the final-token residual at one layer, match the in-context forward pass at all layers' residuals on the fact-bearing positions (layer-wise context distillation solved in closed form per layer, no backprop). **New vs Cortex/D2L:** closed-form per-layer least squares from forward activations, no hypernetwork. **First test:** compare to single-layer ROME and to D2L-style summed rank-8 adapters on the probe. **Retention:** wikitext KL; D2L-style K=8 composition collapse (2611.30825).
28. **Identifier-addressed writes with soft recall — primitive.** Following 2610.17686, bind every write to an internal identifier key (a learned token-free direction) and teach a single routing write that maps query content → identifier. Compiling a new trace only adds one identifier entry, so composition is a lookup, not a sum. **New:** identifier space lives in weights and is shared across writes; prior work prompts with the identifier explicitly. **First test:** 50 writes; measure interference vs number of writes compared to summed rank-1 writes. **Retention:** wikitext KL, leakage.
29. **Causal-scrubbing-certified writes — primitive.** A write is accepted only with a forward-only certificate: resample-ablating every component except the claimed path preserves the new behavior on the domain family. The certificate is stored with the write and re-checked after later writes (a regression test in weight space). **New:** certificates as persistent objects attached to writes; scrubbing has only been an analysis tool. **First test:** after 20 sequential writes, does certificate failure predict which writes broke? AUROC vs key-cosine predictor. **Retention:** certified writes' efficacy over the sequence.
30. **Counterfactual distillation of the activation steerer into a hypernetwork-free write — improvement.** Activation addition (probe arm d) generalizes better than weight writes; compile it by fitting the rank-r weight change whose first-order effect equals the steering vector over the domain (inverse of First-Order Steering, 2610.04283). **New:** the steering→weights direction with a domain-restricted fit. **First test:** recover ≥ 80% of arm (d)'s held-out paraphrase gain with a rank-4 write. **Retention:** wikitext KL vs arm (d) (which is not local).
31. **Trace programs instead of trace values — primitive.** Compile not the Δh but the *program* that produced it: the attention heads that moved the in-context fact into the query position. Write a static KV-like entry into those heads' value/output path (a "frozen context token" baked into weights). **New vs prefix tuning:** the write reproduces only the heads the trace shows used the context, so it stays inactive elsewhere. **First test:** identify fact-moving heads by patching; bake a virtual key/value into them; compare to prefix tuning of same size. **Retention:** wikitext KL, other-subject leakage.
32. **Composition-by-construction curricula: compile the join, not the parts — primitive.** When two writes must compose (A then B), generate the counterfactual trace of the *joint* context (both facts in context, two-hop question) and compile the difference between the joint trace and the sum of single traces as a third "glue" write. **New:** explicit glue writes measured from the gap between joint and additive traces. **First test:** two-hop nonce chains; glue vs no glue vs redundant editing. **Retention:** single-hop accuracy and wikitext KL.
33. **Write half-life tracking with sentinel probes — improvement.** Each compiled write ships with 3 sentinel prompts; later writes are rejected or re-linked when a sentinel drops. Cheap forward-only retention. **New vs replay:** sentinels are chosen as the domain boundary points (min-margin from idea 1). **First test:** 100 sequential writes; sentinel-gated vs ungated vs random sentinels. **Retention:** is the test itself.
34. **Multi-model consensus keys — primitive.** Compute traces in two different-size models of the same family, align their key spaces with a forward-only Procrustes map, and keep only the key subspace both agree on as the domain. Hypothesis: shared subspace = semantic, model-specific = surface. **New:** cross-model agreement as a paraphrase-invariance filter for writes. **First test:** GPT-2 small/medium; held-out paraphrase of consensus-key writes vs single-model keys. **Retention:** wikitext KL.
35. **Spectral domain growth — primitive.** Start a write with a narrow domain (one key) and widen it along the top eigenvectors of the key covariance *of the paraphrase family*, one direction at a time, accepting each widening only if leakage stays below budget. The result is a Pareto front of generalization vs locality per write. **New:** an explicit generalization–locality dial per write; ROME fixes it implicitly via C⁻¹. **First test:** plot held-out paraphrase vs leakage for k = 0..5 directions vs ROME's single point. **Retention:** the leakage axis.
36. **Write as a function of the trace (meta-compiler trained on forward data only) — primitive.** Train a tiny ridge-regression map from (trace Δh, key-family stats) → rank-1 write, using as targets closed-form writes on past facts; new traces compile in one shot. **New vs D2L/SHINE hypernetworks:** linear, forward-only, trained on the model's own previous writes, so it updates continually. **First test:** train on 100 compiled facts, apply to 20 new; efficacy and paraphrase vs per-fact closed form. **Retention:** wikitext KL, and how the meta-map drifts over a stream.
37. **Negation/contrast writes for rules — improvement.** For procedural rules (nonce operator), compile both the rule trace and its "near-miss" counterfactual (where the rule must not apply), making the domain boundary explicit for rules, where single-key methods fail (2604.08284). **First test:** nonce string rule; apply-rate on in-domain held-out strings vs false-apply on near-miss strings. **Retention:** base-task accuracy on similar real string operations.
38. **Trace compression to a code word, then decode per layer — primitive.** Compress a trace into a short code (e.g. 16 dims via PCA over past traces) and have a fixed, pre-installed decoder write in each layer expand codes into layer-specific deltas. New writes only set a code entry for a new key. **New:** a shared pre-installed decoder makes writes small, comparable and composable as codes. **First test:** decoder fit on 100 facts, new facts written as codes; efficacy vs full rank-1 at matched bytes. **Retention:** wikitext KL.

## Ranked deeper questions

1. **Can matched interventions identify a semantic write domain with few negatives per fact?** Learn role/subject/relation guards shared across payloads, then install a domain without test templates. This is the nearest path because ordinary LS can interpolate known keys but has no interface for asking where a value is valid. Decisive: beat equal-query SERAC/GRACE and WSP/rank-one fitting on concealed assignments at matched off-domain retention; a nearest-neighbor router itself has not cleared the bar.
2. **Can a forward counterexample certify an address collision and nominate a new routing distinction?** Hide collisions at different depths and demand that the compiler falsify a projection-only write before altering upstream routing; then reuse the distinction for an independent rule. Compare against more rank and equal-byte adapter growth, with protected distinctions held out.
3. **Can two trace programs link without re-reading either program's examples?** Give each editor signed domain probes and interventions; measure whether linking alone predicts and repairs cross-talk under held-out, same-prompt rule composition. Compare same-state raw replay, joint MEMIT and direct composition distillation. A negative result would bound the useful compression of the interface, not establish that rules cannot compose.
4. **Can one infer a reusable payload separately from the selector that delivers it?** Use context-matched swaps and role relocation, then test unseen output tokens and a new downstream rule using the same selector. This could turn traces into parameterized operators; the hurdle is beating tuned activation addition and short-context distillation, not simply improving a trace point.

The next benchmark should use unpredictable facts **and** new rules, concealed lexical near misses, questions requiring both installed rules to compute the answer, held-out retention tasks, and increasing numbers of writes. Match evidence, queries and persistent bytes across compilers, routers and baselines; report acquisition, selectivity, forgetting over time, and abstention.
