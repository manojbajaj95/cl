# Fixed-budget repeated handoffs

**Status:** Ideas only; no experiments, code, or GPU work. **Parent:** [Successor-skill recovery](successor-recovery.md) ([PR #196](https://github.com/manojbajaj95/cl/pull/196)), cards 21 and 22. **Review seed:** [Flood triage, row 303](https://github.com/manojbajaj95/cl/blob/8519dfe8db3f179a309a26f593e9356dd5d8c0d3/reviews/flood-triage.md#L303) scored two directions 3: (#21) hand off again without a growing recovery bank, retiring and reusing the previous replacement's storage so each later truthful C acquisition supplies the next binding under one fixed global budget; (#22) compile one recovery map per lawful observation class that restores the same witness for every state consistent with that class, without decoding the erased ancestor. **Read first:** [Idea ledger](https://github.com/manojbajaj95/cl/blob/f3dbc1cf3d7dc26e99fc657d0f2d19079e521dd6/reviews/idea-ledger.md).

## Can recovery be a renewable service rather than a growing archive?

**Verdict: a candidate primitive only if (a) a stream of ordinary C acquisitions keeps one frozen witness runnable across at least three spends inside a budget that never grows, and (b) the recovery for an aliased spend is a single checked operation whose correctness does not depend on knowing which spend happened, and neither collapses to projected gradient descent on the witness loss.** The ingredients are known. Fixed-capacity CL already frees and reallocates parameters ([PackNet][packnet], [continual backprop][cbp], [ReDo][redo], recyclable unit gating [2609.38356][rug], subspace reallocation as memory management [2606.30067][nsr], adapter reuse/merging [SARAM][saram]); storage reuse after last use is register allocation and liveness analysis ([linear scan][linscan]); one action valid for several hidden states is conformant planning ([2512.23324][conformant]), synchronizing (reset) words in automata ([open problems survey][sync]), co-/simultaneous stabilization ([2609.23692][costab]) and uniform strategies in partial-information games ([games]). Sequential recovery updates that preserve successful trajectories also exist for controllers ([2611.02555][seqrec]). The distinct target is narrower: the **next truthful skill pays for the storage** that the previous replacement vacates, the witness stays the same frozen object across spends, and the class map preserves every installed newer skill on its declared domain in **every** aliased state. The two bets fail separately: a ring of handoffs can work with full spend identification, and a class map can work once without being renewable.

## Contract for the CPU first tests

- **Timeline and budget.** A = original tasks; B_1, B_2, … = useful admissions, each genuinely spending the current carrier; C_1, C_2, … = truthful acquisitions between spends, all still installed. Fix before B_1: witness payload, interface, legal bindings, finite input and continuation domains, utility criteria, and one global budget `K` counting **persistent** bytes (replacement storage, adapters, receipts, proof logs, class tables, masks) plus a separate peak cap for transient buffers. The budget never grows; a handoff that needs more is a refusal, reported as such. Shelving a live C, compressing it lossily, or moving it outside the counted store never frees budget.
- **Handoff.** At spend `k`, retire the storage of replacement `k−1` only after a liveness proof that no installed skill other than the witness reads it, or after an exact proof that C_k now supplies the same binding. Then bind the witness to C_k's feature. No reset of parameters or optimizer, no ancestor checkpoint, teacher or old source examples; retained witness metadata is charged to `K` and may not encode a restorable carrier.
- **Observation classes.** Declare the lawful observables `O(s)` before the spend (e.g. outputs on the declared domains, public counters, the witness's own launch test). Two post-spend states are aliased if `O` agrees. A class map `R_Q` is accepted only if, for **every** state in class `Q` that the declared spend menu can produce, the witness runs and `F_i(R_Q(s), x) = F_i(s, x)` for every installed newer skill `i` and every `x` in its promised domain (paired transition invariants for stateful skills, as in [#196](successor-recovery.md)). Report the class sizes, the number of maps stored and their bytes against `K`.
- **Mandatory vacuity controls.** (1) Projected Newton/gradient steps on the witness loss inside the null space of the protected C reads (see hand check): if they already restore every aliased state, the class map adds nothing beyond [GPM][gpm]-style projection. (2) Decode-then-recover with an oracle spend label (upper bound) and with a purchased revealing probe ([#179][examples]). (3) An accumulating bank (GRACE adapters, per-spend maps) at the same total bytes as `K`, and the same bank uncapped. (4) Rollback plus replay of all later C. (5) A C stream with no shared feature. (6) Exact joint search over the legal menu on tiny instances.
- **Ledger stop signs.** Exact restore and flat reacquisition win by construction; replay and save/restore get the same budget. Gramian/spare-rank forecasts already died ([#9](https://github.com/manojbajaj95/cl/pull/9), [#21](https://github.com/manojbajaj95/cl/pull/21)); don't sell "budget headroom" as a predictor. Diffuse damage ([#24](https://github.com/manojbajaj95/cl/pull/24)) means aliasing directions need not be sparse. The Landauer erasure-budget kill (bits erased say nothing about accessibility) applies: count service, not bits.

**Hand check (numpy, 6-dim exact linear host, not a training result).** Two newer C reads `c_1, c_2`, witness launch `r·w = t`, three lawful observables `P`. Two spend states `w_1, w_2 = w_1 + d` with `d ∈ ker P` are aliased (`Pw_1 = Pw_2`) but read the witness differently (`r·w_1 = −0.32`, `r·w_2 = −2.57`). (i) **Open loop fails:** the common constant move computed from `w_1` leaves `w_2` at `r·w = −1.25 ≠ 1`; a constant class map exists iff `r·d = 0` after projecting out the C reads. (ii) **Closed loop succeeds trivially:** one Newton step on `(r·w − t)²` restricted to `ker[c_1; c_2]` lands both states at `r·w = 1` with C change ≤ 1.1e-16, without identifying the spend. (iii) **Blocked case:** if `r ∈ span(c_1, c_2)` the projected direction is zero (‖g‖ ≈ 7e-16) and no C-preserving recovery exists for either state. So in linear hosts the class-map seed (#22) is projected gradient descent unless the witness target is not available as a differentiable loss, the host is nonlinear across the alias, or the map must fit a byte budget smaller than one step's working state. Cards 03, 06 and 12 take those three exits.

## Idea cards

### 01. Ring handoff: each successor inherits the vacated slot — primitive candidate
**Mechanism.** Keep exactly one replacement region of fixed size. At spend `k`, prove C_k supplies the binding the witness needs from its own feature, then retire replacement `k−1`'s region and hand it to C_{k+1}'s acquisition as ordinary trainable capacity. **Novelty / control.** PackNet and continual backprop free capacity; [#177][carriers] regenerates carriers; the claim here is that **learning C_k is what makes the old region dead**, so the budget is constant across spends. Compare a capped GRACE bank + regeneration, continual backprop renewal, progressive nets (uncharged growth), [#188][carrier] card 03 single-shot, and rollback/replay. **Cheapest first test.** Three-spend linear-ReLU stream with a shared latent factor per C, budget of one 2-unit region; a fourth C with no shared factor must cause a refusal, not a silent C loss. **Old-task retention.** After each retirement check every installed C on its full declared domain, A/B held-out floors, and B_k's own admission.

### 02. One recovery map per observation class — primitive candidate
**Mechanism.** Partition the post-spend states the declared spend menu can produce by lawful observables; for each class synthesize one bounded map and prove witness service plus newer-skill preservation for every member. Never decode or recreate the erased ancestor. **Novelty / control.** Uniform strategies in partial-information games and conformant planning compute exactly this kind of object; the CL claim is that the common C-derived replacement makes uniform recovery feasible where a probe would otherwise be bought. Controls: decode-then-recover (oracle label), per-spend maps, [#179][examples] revealing probes priced, [#173][indist] shared replies, and the projected-Newton vacuity control. **Cheapest first test.** Enumerate the hand-check host with three spends forming two classes: one class with a common map, one planted pair needing opposite moves. **Old-task retention.** Every installed A/B/C trace in every class member, not only the member that supplied the positive run.

### 03. Recover when the witness target is executable but not differentiable — primitive candidate
**Mechanism.** The witness only exposes a pass/fail launch test (a program that runs or doesn't), so projected gradient steps (hand check ii) are unavailable. Search a fixed finite grammar of C-preserving moves for one move sequence that passes the test in every aliased state. **Novelty / control.** This is conformant planning over a learned host; the gain over the vacuity control is real only when the loss is unavailable. Compare zeroth-order projected search with the same evaluation budget, decode-then-recover, and exact belief-space search. **Cheapest first test.** A tiny ReLU host where the launch test is a threshold on a hidden unit's sign pattern; two aliased spends straddle the threshold. **Old-task retention.** Exact C equality on declared domains after every accepted move prefix, plus A/B after an ordinary suffix.

### 04. Liveness analysis decides what storage a handoff may retire — improvement
**Mechanism.** Track live ranges of each replacement over the stream: a region is dead once no installed skill's declared computation reads it under any legal input, proved by exact enumeration or a sound abstraction. Retire only dead regions; refuse otherwise. **Novelty / control.** Register allocation by liveness is decades old; Shapley/importance scores ([2605.15877][shapley]) and pruning masks estimate usage. The improvement is a sound retirement rule that never deletes a rare-input reader. Compare magnitude, Shapley and activation-frequency retirement at the same budget. **Cheapest first test.** A region read only on a 1/1000 input slice by C_1; importance scores retire it, liveness refuses. **Old-task retention.** C_1 on the rare slice, full A/B/C domains.

### 05. Successor-chained bindings with no gap — primitive candidate
**Mechanism.** Require C_{k+1}'s acquisition to reproduce C_k's binding feature **as a byproduct of its own job** before spend `k+1`, so the witness binding passes forward along the chain and the budget holds only one live replacement at any time. **Novelty / control.** Net2Net + distillation can copy a feature into new storage; the claim is that the copy is paid by C_{k+1}'s utility, not by a separate transfer fit. Controls: explicit distillation of the binding into C_{k+1} at equal examples, a C stream whose features are unrelated, #196 card 01. **Cheapest first test.** Three C tasks sharing a rotating latent (each reads factor `k` and `k+1`); measure binding error at each spend with and without the overlap. **Old-task retention.** Each C_k after C_{k+1} acquisition, and the witness's earlier admissions B_1…B_k.

### 06. A synchronizing batch that merges aliased spend states — primitive candidate
**Mechanism.** Find a short sequence of truthful ordinary training batches (on C data, no witness targets) whose composed update maps every state of an alias class to states sharing the same witness read, after which one constant binding works. The learner's own dynamics play the role of a reset word. **Novelty / control.** Synchronizing automata and the Černý conjecture give the combinatorial object; contraction of SGD toward a minimizer is its continuous analogue. The CL claim is a batch that synchronizes the witness interface while staying lawful C training. Controls: plain extra C training of equal length, the projected-Newton step, decode-then-recover. **Cheapest first test.** Two-layer ReLU host, four aliased spend states, enumerate batch sequences up to length 4 from a fixed truthful pool; report shortest synchronizing length vs a random-pool null. **Old-task retention.** C utility at every prefix (the batches are C training, so C must not drop), A/B floors after the sequence.

### 07. Budget-exhaustion certificate before the handoff — improvement (audit)
**Mechanism.** Before spend `k`, compute a dual certificate (LP/rank obstruction over the legal move menu) that no assignment of bindings to the fixed budget preserves all live C and restores the witness, so the learner refuses up front. **Novelty / control.** Farkas duals and unsatisfiable cores are standard; the gain is separating genuine budget exhaustion from a weak synthesizer. Compare exact search on tiny instances. **Cheapest first test.** Three linear C reads plus witness in a 3-dim region: a 4th independent read is infeasible; a dependent one is feasible. **Old-task retention.** On refusal, unchanged full suite; on the feasible fork, all C after the handoff.

### 08. Compacting handoff: defragment live bindings at each spend — improvement
**Mechanism.** At each spend, move live bindings into a contiguous prefix of the budget with an exact function-preserving permutation/rescaling (copying-collector style), so the freed tail is usable by the next C. **Novelty / control.** Copying garbage collection, Git Re-Basin permutations and Neuron Merging. The improvement is fragmentation-free reuse; compare with leaving holes and with PackNet masks. **Cheapest first test.** Five spends with interleaved retirements; measure largest free block and next-C utility at fixed width. **Old-task retention.** Exact output equality of every live C across the compaction, optimizer moments permuted consistently.

### 09. Refine an alias class only where the common map fails — improvement
**Mechanism.** Start with the coarsest class; when synthesis fails, extract a counterexample pair needing incompatible moves and split only that class, by buying the cheapest distinguishing observation. **Novelty / control.** CEGAR and active diagnosis do this; compare to buying all distinguishing probes up front and to oracle decoding. **Cheapest first test.** Six spend states, two incompatible pairs; count probes bought vs full identification. **Old-task retention.** Probes must be lawful reads only; verify C/A/B unchanged by probing and after each class map.

### 10. Let C's own outputs define the alias classes — primitive candidate
**Mechanism.** Use the installed C skills' outputs on their declared domain as the only observables. Then the class structure is a function of what C learned: richer C acquisitions shrink classes for free, and the question becomes whether ordinary C learning separates exactly the spends that need different maps. **Novelty / control.** Observation equivalence and bisimulation quotients are known; the claim is that the quotient is learned, not designed. Control: random fixed observables of equal dimension, and a C trained on unrelated features. **Cheapest first test.** Two C fits of equal utility, one whose features happen to separate the incompatible spend pair; compare probe purchases needed. **Old-task retention.** Reading C outputs must not alter C; check all installed C after recovery.

### 11. Time-multiplex one slot between two frozen witnesses — primitive candidate
**Mechanism.** Two frozen witnesses whose launch windows never overlap share one replacement region: hand the slot to witness 2 after witness 1's last launch and back after witness 2's, each time via the current C. **Novelty / control.** Time-sharing and [split-timed deadlines][deadlines]; the claim is that a fixed budget serves more witnesses than slots when windows are disjoint. Compare two dedicated regions and a single region with forced refusal. **Cheapest first test.** Linear host, two witnesses with alternating windows across four spends. **Old-task retention.** Both witnesses' earlier admissions, every C after each swap.

### 12. Train the successor so aliasing is witness-invisible — primitive candidate
**Mechanism.** The hand check shows a constant class map exists iff the alias direction `d` satisfies `r·d = 0` after the C projection. Choose, among C fits of equal utility, the one whose updates make the reachable alias directions orthogonal to the witness read, so recovery needs no state read at all and costs one stored vector per class. **Novelty / control.** Projected updates (GPM, OGD) control interference directions; the claim is shaping **future alias geometry** during acquisition. Controls: equal-utility unconstrained C, projected-Newton per state (which needs a forward pass on the hidden state), the acquisition premium. **Cheapest first test.** Enumerate two C fits in the linear host, one with `r·d = 0` and one without; compare stored bytes and recovery work. **Old-task retention.** C utility match at sealing; A/B and C after recovery in all class members.

### 13. Overwritable recovery receipts with a bounded proof log — primitive candidate
**Mechanism.** Each handoff's preservation proof is stated against the current installed set only, so receipt `k` replaces receipt `k−1` in place; a checker can validate the current state without the history. **Novelty / control.** Proof-carrying code and incremental verification; the claim is a constant-size receipt that remains sound after its predecessors are deleted. Control: an accumulating log, full recertification each spend. **Cheapest first test.** Five spends, compare receipt bytes and check time; plant a C that only an older receipt covered. **Old-task retention.** The planted C must be caught and rechecked, never silently dropped.

### 14. When the budget runs out, drop the witness by declared value, not by accident — improvement
**Mechanism.** If a handoff is infeasible, choose which obligation to relinquish by a declared service value and announce it, rather than letting interference choose. **Novelty / control.** Graceful degradation and value-aware eviction; compare LRU and importance-weighted eviction. **Cheapest first test.** Budget for two of three witnesses; report value retained. **Old-task retention.** Every non-relinquished obligation exactly; A/B floors.

### 15. A class map that stays valid after the next C acquisition — improvement
**Mechanism.** Store the class map with explicit premises on consumer functions ([#196][parent] card 11); after C_{k+1}, check the premises instead of resynthesizing. **Novelty / control.** Inherits #196#11 and [Pacti][pacti]. Compare resynthesis and per-skill adapters. **Cheapest first test.** One C_{k+1} in the premise family, one agreeing on training data but violating it elsewhere. **Old-task retention.** Refuse the second without touching any installed skill.

### 16. Hand off through optimizer-state storage — improvement (variant)
**Mechanism.** Count moments as budget and let the replacement live in a slot the next C's optimizer reads; retire it by an ordinary update. **Novelty / control.** Inherits [#178][splits] and #185 slot splices; must beat a direct slot write and a reset. **Cheapest first test.** Heavy-ball host, two spends, matched endpoint weights. **Old-task retention.** C traces at the witness step and after the next ordinary batch.

### 17. Adversarial spends: the class map against a spend chosen after the map — improvement (audit)
**Mechanism.** Treat the spend as an adversary choosing any member of the class after the map is published; certify worst-case witness service and C preservation. **Novelty / control.** Minimax planning and robust control; the audit separates average-case alias luck from a real uniform map. **Cheapest first test.** Enumerate classes in the hand-check host; compare worst-case vs average service. **Old-task retention.** Worst-case C deviation must be exactly zero, not small on average.

### 18. Measure the handoff horizon of a C stream — improvement (measurement)
**Mechanism.** For a fixed budget, count spends served before the first forced refusal as a function of how much successive C tasks share; report the horizon, not indefinite renewal. **Novelty / control.** Capacity curves for fixed-capacity CL exist (PackNet, NSR); the new axis is spends of a frozen witness. Compare an accumulating bank at the same bytes. **Cheapest first test.** Streams with sharing 0, 0.5, 1 across ten spends. **Old-task retention.** All C at the horizon and A/B floors.

### 19. Recover the witness while provably not recovering the erased ancestor — primitive candidate
**Mechanism.** When the spend was a deliberate erasure (e.g. an unlearning request), require the class map to restore witness service while membership/reconstruction attacks on the erased ancestor stay at the post-spend level. Uniform maps help: a map independent of which ancestor was erased cannot encode it. **Novelty / control.** Machine unlearning ([SISA][sisa]) and certified removal; the claim is recovery of a service compatible with an erasure guarantee. Controls: decode-then-recover (leaks the label by construction), rollback (restores the ancestor). **Cheapest first test.** Two aliased erasures of different training points; membership inference on each before and after recovery. **Old-task retention.** C/A/B plus the erased-point attack metric.

### 20. Expected-service class maps under a spend prior — improvement
**Mechanism.** With a declared prior over class members, maximize expected witness service subject to **hard** C preservation for all members. **Novelty / control.** Chance-constrained planning; compare the worst-case map of card 17. **Cheapest first test.** Skewed prior in the hand-check host. **Old-task retention.** C equality for every member regardless of prior weight.

### 21. Overlapping handoff: retire storage while a fading C still reads it — improvement
**Mechanism.** Allow a two-phase handoff where the old region stays readable to a C whose reader is being migrated, with the budget charged for the overlap peak. **Novelty / control.** Two-phase commit and blue-green deploys; compare atomic handoff with buffer. **Cheapest first test.** One C migrating its read across two ordinary updates. **Old-task retention.** C outputs at each intermediate state (no visible gap).

### 22. Choose the witness binding to minimize alias sensitivity — improvement
**Mechanism.** Among legal witness bindings, pick the one whose read is least sensitive to the reachable alias directions, so most classes admit constant maps. **Novelty / control.** Robust sensor/actuator selection; must beat binding chosen by C utility alone. **Cheapest first test.** Three legal bindings in the hand-check host; count classes with constant maps. **Old-task retention.** Binding choice must not alter C; A/B/C after each recovery.

## Ranked deeper questions

1. **Does C learning, not spare capacity, keep the budget constant?** Run card 01 against a capped bank of equal bytes, continual backprop renewal and an unshared C stream over at least three spends. If a free spare region or the capped bank ties, the ring handoff is bookkeeping, not a primitive.
2. **Is a class map ever more than projected gradient descent?** The hand check shows it is not in linear hosts with a differentiable witness loss. Test the three exits (non-differentiable launch test, nonlinear alias crossing a kink, byte budget smaller than one step's working state) and keep only those where the vacuity control fails and the class map succeeds.
3. **Can ordinary C training synchronize aliased spends?** Card 06: find the shortest truthful batch sequence merging the witness interface, against equal-length plain C training and a random-pool null. A positive result makes the learner's dynamics the decoder, with no probe bought.
4. **Where does the handoff horizon end, and is the refusal true?** Use card 07's certificate with exact search to separate budget exhaustion from synthesizer weakness, and card 18 to report the horizon as a function of C sharing. A finite horizon is a result; indefinite renewal is not claimed.
