# Deployment feedback 2: Keep the question open and keep an answer reachable

Child of [PR #352](https://github.com/manojbajaj95/cl/pull/352) ([root](root-deployment-feedback.md)) · Depth 1 · 26 candidate primitives · Ideas only; no experiments run

**Thesis.** Two learners can preserve the same answers on every old scored task yet lose different freedoms: one starts treating an unanswered comparison as settled, and the other no longer gives users any feasible way to settle it. Make both failures visible at write time. A persistent comparison should say what is still open, what evidence can close it, and whether that evidence remains obtainable under the serving policy after another update.

**Scope.** Develop only DF10 (reachability floor for disconfirming feedback) and DF32 (retention of old open comparisons), the two directions kept in [flood-triage row 482](https://github.com/manojbajaj95/cl/blob/67f9c54f9e85a5b8786e0c67d64b147eff410588/reviews/flood-triage.md#L482); the reviewer did not advance either to the top ten. Do not count another elicitation heuristic, safety constraint, or robust partial commit as a new primitive. [CE3-21](https://github.com/manojbajaj95/cl/pull/349) already picks a write that preserves a particular future experiment; [CE2-05](https://github.com/manojbajaj95/cl/pull/347) already commits a common effect and keeps a residual proposal. This node tests what survives multiple writes, including obligations inherited from *older* work rather than created by the current proposal.

## Literature check

Targeted searches checked primary-source abstracts and relevant sections on bounded diagnosis, protected exploration, partial identification, and continual learning. The gaps below are hypotheses, not claims of priority. Each card gives a closer comparator if one was found.

| Closest line | What this node must show beyond it |

| [Conservative Dueling Bandits](https://arxiv.org/abs/2610.36708) protect the cumulative score of the better displayed item relative to a trusted baseline, including an informative fallback partner; [SafeMDP](https://arxiv.org/abs/1606.04753) uses safety and returnability to explore a finite MDP. | A serving action can be safe and near-optimal immediately while stranding a contingent, scope-specific correction route. Match service cost and ordinary regret, not just fallback frequency. |
| [Active Diagnosis with Observable Quiescence](https://home.lmf.cnrs.fr/downloads/SergeHaddad/A15-CDC.pdf) synthesizes control that forces faults to be detected; [Dynamic Observers](https://arxiv.org/abs/1004.2810) optimize when to activate sensors; [property-enforcing supervisors](https://xiangyin.sjtu.edu.cn/Paper/16TACuniform.pdf) can enforce diagnosability permissively in partially observed plants. | These are serious nulls: on a fixed known plant, product-state diagnosis may already give the exact answer. Require a gain from reusable obligations through successive learned changes, or a new property not reducible to testing the same fixed fault on the same plant. |
| [EWC](https://arxiv.org/abs/1612.00796) protects parameters important to earlier tasks; [tiny episodic replay](https://arxiv.org/abs/1902.10486) rehearses old examples; [Dark Experience Replay](https://arxiv.org/abs/2004.07211) matches stored logits. | Compare at matched old labeled scores. Replay old queries with the old `open` behavior as a strong control, not just labeled answers. Output replay may preserve abstention, but can it preserve *which* lawful evidence lifts it after a shift? |
| [Skalse et al.](https://proceedings.mlr.press/v202/skalse23a.html) characterize reward ambiguity for given feedback and downstream decisions; [robust ordinal regression](https://link.springer.com/article/10.1007/s10994-013-5365-4) distinguishes possible from necessary preferences; [Semantic Identifiability Frontier](https://arxiv.org/abs/2610.20450) characterizes what repeat and abstention channels identify. | A static set of feasible rewards, an indifference label, and a confidence threshold are different nulls. Show a benefit from preserving, transforming, and selectively resolving particular old decision contrasts across successive live writes. |

**Common first test and gates.** Start with an enumerable policy or a tiny learned head: old cohorts/tasks A and B agree on scored decisions, but lack evidence on a held-out comparison; C and D introduce successive changes on other scopes. Then give one old scope a lawful witness (in a separate assay if necessary; do not count injected evidence as proof of reachability). Pair streams with identical committed old-task accuracy and immediate C/D utility; include a lucky write that guesses the correct old answer without evidence. Count that guess as unauthorized commitment, not retention. Record held-out A/B success after both C and D, and score two independent axes: whether a comparison is correctly marked open or identified, and whether a lawful distinguishing test is reachable. Test correct resolution on the witnessed scope without resolving its unwitnessed twin. Open means admissible worlds support opposing choices, not that the user is indifferent or that no reversible default may be served. Record a reversible default separately from a learned preference. Unreachable means no allowed acquisition policy meets the floor under the stated model; it never authorizes a guess. Use an impossible-to-detect reversal and report infeasibility rather than calling it retention. For detection, fix a false-alarm limit under the no-reversal world and measure the probability of a *correct* diagnosis within the horizon in each protected context under the reversal worlds, not just the probability of eliciting any feedback.

Each card's named control is **in addition to** the applicable common controls: unconstrained writes; EWC or replay, including open-status replay, at matched labeled A/B scores and storage; and a once-computed Skalse-style feasible set for comparison claims. For route claims include conservative dueling at equal service cost, epsilon-greedy at matched regret, and fresh active diagnosis or post-update active learning with the same observations and interactions. Compare to exact re-solving on tiny graphs where possible; equal outputs are a useful oracle check, not novelty by themselves. Charge write-time compute, state, exposed interventions, and user burden separately. Use only consented hypothetical routes; never treat silence as permission. None of these tests has been run.

## A · Preserve the route to contradiction through another write

### D2-01 · Preserve an experiment family, not an experiment
- **Primitive:** A write carries a set of observation-conditioned correction plans that remain admissible, expressed as replaceable components, and may delete a component only when every affected old scope retains a plan. The serving learner need not know which plan will be cheapest next.
- **Nearest prior / gap:** [Permissive probabilistic controllers](https://arxiv.org/abs/1504.04662) permit multiple strategies satisfying a property. Here component-level substitutes are retained for old contrasts whose relevant observations and costs can change independently with later writes.
- **Cheapest first test / control:** In a six-state graph let C make the cheapest plan redundant and D remove it. Compare one cached plan per scope and incremental permissive controller synthesis given the same state budget. Kill if decomposing plans never reduces needless blocked writes or re-synthesis.
- **Old-task retention:** Test A/B ordinary tasks and both old scoped correction paths after C and D, not just the path used.

### D2-02 · A route contract for two individually safe edits
- **Primitive:** Give an edit a conditional promise over another edit's touched transitions: it certifies alternate routes that survive each possible second write, rather than relying on a single current backup.
- **Nearest prior / gap:** [Safe returnable exploration](https://arxiv.org/abs/1606.04753) preserves returnability in one evolving safety estimate; [CE3-21](https://github.com/manojbajaj95/cl/pull/349) selects a first write that leaves a test available. This contract is about conflicts between independently selected writes, not a second observation in the experiment.
- **Cheapest first test / control:** Two edits independently leave opposite routes intact but jointly close both. Compare re-solving after each commit and exact depth-two synthesis, then charge unnecessary blocking on unrelated pairs. Kill if a constant-size contract cannot approach the joint oracle while costing less than fresh search.
- **Old-task retention:** Check old tasks through each route after the first write and after both, including an ordinary task that depends on the cheaper path.

### D2-03 · Put a price on removing a cut, not on taking an action
- **Primitive:** Attach a cut certificate to a failed correction floor: a set of disabled transitions that intersects every candidate distinguishing plan. Return one minimal lawful repair sufficient to restore a plan, or report that none exists, instead of taxing every low-support action.
- **Nearest prior / gap:** [Property-enforcing supervisors](https://xiangyin.sjtu.edu.cn/Paper/16TACuniform.pdf) restrict system behavior to enforce diagnosability. Here the artifact returned is a scoped repair request for a candidate edit, portable across edits sharing the same cut, not a new supervisory objective.
- **Cheapest first test / control:** Build two edits that remove the same bottleneck but preserve different actions elsewhere. Compare rejected-write penalties and bounded exhaustive edit repair; fail if cut reuse cannot transfer to a fresh edit better than a cached rejected-edit classifier.
- **Old-task retention:** Check A/B task success and the repair's effect on both source and unrelated old correction scopes.

### D2-04 · Preserve a diagnosis policy under hidden context
- **Primitive:** A reachability certificate carries pairs of candidate starting states that are observationally aliased. It is invalid if reaching a witness would require selecting a branch using the unobserved state. Only a plan whose branch conditions are observable can discharge the certificate.
- **Nearest prior / gap:** [Contingent planning](https://doi.org/10.1609/aaai.v28i1.9049) already plans in belief space. The candidate is an alias condition carried across versions to invalidate previously feasible corrections when a deployment merges formerly distinct observations.
- **Cheapest first test / control:** C removes a mode indicator; D changes the correct comparison in one mode. Compare per-state reachability and a full contingent planner warm-started from its old plan; kill if the alias condition cannot improve invalidation cost or catch a real difference in allowed writes.
- **Old-task retention:** Test A/B with modes mixed; score old-mode correction at a fixed false-alarm limit, not just merged-mode service accuracy.

### D2-05 · Keep disagreement detectable when reports arrive but lose their meaning
- **Primitive:** Replace a route's “observable” flag by a lower bound on discrimination between two possible report laws, conditioned on its allowed prefix. Renew the bound only for prefixes touched by a write; a high-response but uninformative route does not count.
- **Nearest prior / gap:** [Partial monitoring](https://doi.org/10.1287/moor.2014.0663) classifies observability from signal matrices, and [active diagnosis](https://home.lmf.cnrs.fr/downloads/SergeHaddad/A15-CDC.pdf) distinguishes event histories. The candidate preserves a validated finite-horizon discrimination claim across changes to serving and response, not just signal rank.
- **Cheapest first test / control:** Change a noisy comparison's answer distribution from distinguishable to overlapping below the fixed power target while keeping turnout constant. Compare shortest route, full sequential design, and a fresh power calculation from all sampled prefixes. Reject if local renewal isn't accurate or cheaper.
- **Old-task retention:** Check A/B under the original channel and under the changed channel, with per-scope detection power held to the same target.

### D2-06 · Keep the option to ask after the cost changes
- **Primitive:** Track nondominated plans in a small vector of service disruption, interaction burden and detection time, rather than one scalar budget. At deployment a consent or cost change can retire a plan without manufacturing a new preference.
- **Nearest prior / gap:** [Dynamic observers](https://arxiv.org/abs/1004.2810) minimize observation cost while preserving diagnosis. Here the learner carries a frontier for separate constraints that can change independently of the plant; the frontier must pay its storage and compute.
- **Cheapest first test / control:** Compare three routes, one fast, one low interruption, one low respondent burden. Change the permitted interruption and then the time budget. Compare re-solving multiobjective diagnosis from scratch and storing one plan per prior weight. Reject if the frontier ties either at equal bytes and recomputation.
- **Old-task retention:** Check old quiet-cohort and ordinary workflows after both budget changes; report burden by cohort rather than averaging it.

### D2-07 · Distinguish a reusable bridge from a single-use invitation
- **Primitive:** A permitted invitation that can be used only once is a consumable state variable, not a stationary exploration probability. A write must leave a plan for one future reversal *without* reusing resources consumed by the current revision.
- **Nearest prior / gap:** [Budgeted RL](https://arxiv.org/abs/1903.01004) conditions decisions on remaining cost budget. Here the state variable belongs to a specific witness family and has an old-scope conservation obligation rather than being fungible across reward-seeking actions.
- **Cheapest first test / control:** Two overlapping scopes share one opt-in invitation; a cheap orthogonal comparison can resolve C instead. Compare budgeted exploration with a common credit and exact planning with per-invitation tokens. Reject if a reusable token-allocation rule has no advantage over storing a full planner.
- **Old-task retention:** Check ordinary A/B and ability to contradict each after C has used its invitation and D begins.

### D2-08 · Hand off a correction route between authorized surfaces
- **Primitive:** When scope A's correction surface disappears, certify a replacement route by mapping the *distinguishing reports* as well as actions; the transfer counts only if the matched old respondent can still consent and the translated report induces the same closure rule.
- **Nearest prior / gap:** [Predictive state representations](https://proceedings.neurips.cc/paper_files/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf) describe state through predictions of observable tests; [causal transportability](https://doi.org/10.1214/14-sts486) formalizes transferring evidence across populations. The candidate transfers an obligation with a verified report interpretation, not just numerical reachability in the new interface.
- **Cheapest first test / control:** Replace a comparison widget with an opt-in edit surface with permuted meanings for some reports. Compare old-controller reuse and active re-synthesis with transport estimation. Fail if the handoff cannot reject a reachable but semantically wrong replacement at the same interventions.
- **Old-task retention:** Check both old tasks on their remaining surfaces and the intended A/B corrections received on the replacement.

### D2-09 · Reserve paths after the first successful correction
- **Primitive:** A route must finish in a state from which the next old-scope challenge is still diagnosable; terminal “evidence received” alone is insufficient. Learn which reachable witnesses leave incompatible successor states.
- **Nearest prior / gap:** [Permissive probabilistic synthesis](https://arxiv.org/abs/1504.04662) handles temporal goals; [SafeMDP](https://arxiv.org/abs/1606.04753) preserves return to safe states. The candidate obligation recurs after an authorized answer changes the serving learner itself, so returning to the original physical state need not restore the next test.
- **Cheapest first test / control:** Two first witnesses have equal disambiguation but one triggers an automatic policy change that closes B's only route. Compare myopic diagnosis and joint recurrent-goal synthesis. Reject if the successor certificate cannot generalize across held-out C/D outcomes without repeating full joint synthesis.
- **Old-task retention:** Test A and B after the first closure and again after the attempted second closure, including a never-revised old task.

### D2-10 · Admit a cheap surrogate only with an independent cross-check
- **Primitive:** A cheap proxy route may replace an expensive direct route only with an overlapping audit identifying the proxy's failure region. Future edits that expand exposure in that region automatically reopen the obligation to the direct route.
- **Nearest prior / gap:** [Limited-feedback partial monitoring](https://proceedings.mlr.press/v83/ensign18a.html) exploits observable proxy losses; [covariate-shift robust policy evaluation](https://arxiv.org/abs/2401.11353) handles context shift. The operation retains a falsifiable replacement condition that changes whether a route is admissible, rather than presuming a proxy is valid indefinitely.
- **Cheapest first test / control:** Proxy ratings agree with direct comparisons except at a quiet older intersection that D starts serving. Compare ordinary discrepancy monitoring and a static proxy bound. Kill if preserving the failure region doesn't predict when the old comparison ceases to be learnable.
- **Old-task retention:** Check direct success and independent reversals in both the old agreement and disagreement regions.

## B · Make an unanswered comparison a retained object

### D2-11 · Preserve two opposed witnesses, not a flat logit
- **Primitive:** Save the smallest pair of admissible explanations that recommend opposite old decisions. After an unrelated update, revalidate both against authorized data and apply the same served default to both if needed; a narrow score margin is neither necessary nor sufficient for being open.
- **Nearest prior / gap:** [Skalse et al.](https://proceedings.mlr.press/v202/skalse23a.html) characterize equivalence classes of reward functions. The hypothesis is that a continually repaired pair can preserve the relevant bit of an old class with much less state than the full class, without preserving arbitrary uncertainty on settled tasks.
- **Cheapest first test / control:** Use a six-coordinate linear reward with two equally scoring old worlds. Compare snapshot logits, static feasible sets, and an exact incremental set; kill if the witness pair loses soundness or requires effectively storing the whole set.
- **Old-task retention:** Score A/B and opposedness of each still-open comparison after C and D, followed by exact resolution for the one witnessed query.

### D2-12 · Preserve the disagreement over a decision, not a choice of coordinates
- **Primitive:** Represent an unanswered comparison as a contrast of reachable outcomes. When feature definitions rotate or are replaced, reconstruct opposite feasible outcome orders without requiring the original parameter directions to survive.
- **Nearest prior / gap:** [Invariance and Partial Identifiability](https://proceedings.mlr.press/v202/skalse23a.html) studies feedback-preserving reward transformations; [EWC](https://arxiv.org/abs/1612.00796) preserves parameters. The proposed operation transports an unfinished decision through a noninvertible feature revision, explicitly rejecting merges that destroy the distinction.
- **Cheapest first test / control:** Compare an invertible rotation with a compression that merges two action outcomes. Compare functional replay of old margins and exact reward-set projection. Reject if a contrast descriptor cannot retain the decision under the rotation and report loss under the merge.
- **Old-task retention:** Check old labeled A/B outputs, then attempt resolution on an old remaining contrast and on the genuinely collapsed contrast.

### D2-13 · Keep alternative proofs of closure live
- **Primitive:** Record independent evidence chains for a settled comparison and its previous open witnesses. If an inference assumption becomes invalid, remove only chains using it; reopen the comparison iff the remaining chains no longer force one decision.
- **Nearest prior / gap:** [Assumption-based truth maintenance](https://www.dekleer.org/Publications/An%20Assumption-Based%20TMS.pdf) already tracks proofs under different assumption sets; [NS-DPO](https://arxiv.org/abs/2407.18676) reweights evidence under drift. The candidate tests whether compact decision proofs can be maintained in a learned preference model with changing scopes, not whether a known logical graph can handle retraction.
- **Cheapest first test / control:** Give A two supporting chains and B one; C invalidates a link used in one chain for each. Compare a truth-maintenance system with an exact symbolic graph, time decay, and exact fit on surviving evidence. Reject if compact proofs offer no savings at matched correct reopening.
- **Old-task retention:** Retest unaffected A/B, preserve A's settled comparison and B's renewed openness after D, and close B only with the new scoped witness.

### D2-14 · Preserve which unanswered comparisons share a world
- **Primitive:** Keep a joint feasibility relation over old comparisons rather than one open flag per pair. Close linked comparisons only when a new witness eliminates all joint worlds supporting the alternative, not by multiplying marginal confidence.
- **Nearest prior / gap:** [Robust ordinal regression](https://link.springer.com/article/10.1007/s10994-013-5365-4) computes possible and necessary relations over compatible models. This candidate maintains sparse dependencies between old contrasts under new evidence scopes across writes; exact incremental ordinal regression is a null, not a weak baseline to omit.
- **Cheapest first test / control:** Use two sets with the same per-pair margins but different joint sign constraints. Observe the same pair in both. Compare independent masks and exact incremental regression; kill if the sparse relation cannot reproduce correct cascading closure at a meaningful state or latency gain.
- **Old-task retention:** Test A/B labeled cases, then the legitimately implied comparison and a marginally identical but independent held-out comparison.

### D2-15 · Require a proof of overlap, not an embedding match
- **Primitive:** A witness comes with explicit prerequisites for what it can resolve: equality of some decision variables or a validated transport relation for the rest. Similar-looking C data may update shared features without authorizing a settled answer on A.
- **Nearest prior / gap:** [Causal transportability](https://doi.org/10.1214/14-sts486) checks when effects transfer across populations. Here a transport condition is part of the closure operation for each old comparison; it is evaluated on the claim the learner wants to make, not only on a transfer accuracy estimate.
- **Cheapest first test / control:** Construct two paraphrases and a lexical twin from another scope sharing the same words but differing in admissible evidence. Compare learned similarity gating, manual scope tags, and a derivation from exact transport assumptions. Reject if a learned overlap rule cannot match the exact closure decisions.
- **Old-task retention:** Check original A/B tasks after C and D; resolve only the paraphrase-supported A comparison, not the irrelevant lookalike.

### D2-16 · Keep a proof of indifference separate from a lack of proof
- **Primitive:** Use distinct update operators for an identified equivalence (both outcomes acceptable) and unresolved direction (which outcome is acceptable depends on the unknown world). Preserve the evidence supporting equivalence even when both cases induce the same reversible default.
- **Nearest prior / gap:** [Semantic Identifiability Frontier](https://arxiv.org/abs/2610.20450) separates hidden nonbinary responses from persistent disagreement; [selective classification](https://www.jmlr.org/papers/v11/el-yaniv10a.html) trades coverage for error. The candidate distinguishes which new observations should change a *retained decision*, not just how to fit preferences with a neutral class.
- **Cheapest first test / control:** Equal output rates on an explicitly indifferent and an unresolved old pair. Modify only one outcome in C. Compare a three-way classifier plus open-status rehearsal and exact comparison inference. Fail if retaining the equivalence witness doesn't predict which pair needs re-elicitation.
- **Old-task retention:** Test A/B labeled tasks, preserve explicit indifference on the unchanged copy, and verify that unknown is never reported as a tie.

### D2-17 · Reopen a disputed comparison without reopening all its neighbors
- **Primitive:** Store a boundary partition of contexts on which prior evidence did and did not license closure. A scope-splitting update moves only the partition piece that lost its inference basis back to open; it must not copy the old closure into every child.
- **Nearest prior / gap:** [Learning Personalized Agents](https://arxiv.org/abs/2602.16173) updates preference memory under partial observability and drift; [TRACE](https://arxiv.org/abs/2610.09107) tests refinements of latent constraints. The repair target here is the old evidence boundary of a *partially* settled comparison, not a learned replacement preference.
- **Cheapest first test / control:** Split an audience into two subcontexts, only one matching prior evidence. Compare scope-tagged replay and full re-inference on hierarchical contexts. Reject if retaining a reusable boundary cannot improve selective closure after two splits at equal memory.
- **Old-task retention:** Measure A/B ordinary tasks and the old decision in the unaffected subcontext after each split; check openness only in the unsupported subcontext.

### D2-18 · Compose scoped writes without deciding by arrival order
- **Primitive:** Give comparisons an authorization-aware join: combine only independently licensed evidence constraints; keep contexts separate if their supports do not overlap. The learner must give the same open/closed result under reordered commuting writes, but conflicting same-scope evidence should force review, not a timestamp winner.
- **Nearest prior / gap:** [Provenance semirings](https://doi.org/10.1145/1265530.1265535) compose dependencies of query answers; [robust ordinal regression](https://link.springer.com/article/10.1007/s10994-013-5365-4) models compatible preferences. The question is whether the operation can remain order-insensitive for licensed old comparisons while learned feature updates themselves need not commute.
- **Cheapest first test / control:** Feed two disjoint-scope updates in both orders plus one genuine contradictory pair. Compare source-tagged replay and exact evidence-set recomputation. Kill if the evidence join yields no behavioral advantage over the simplest explicit scope tags.
- **Old-task retention:** Compare A/B scores and unresolved pairs after every ordering, and verify that a later valid witness closes the correct pair in both.

### D2-19 · Bound how much uncertainty compression may manufacture
- **Primitive:** For each compressed old comparison retain an outer bound on feasible signs and a certificate of any sign that is truly possible. Compression may temporarily widen a bound only with a marked loss of evidence; a learning write may not cite the enlarged set as evidence of disagreement.
- **Nearest prior / gap:** [Online set-membership identification](https://arxiv.org/abs/2107.01714) updates feasible sets under bounded error; [Conformal Risk Control](https://arxiv.org/abs/2208.02814) calibrates sets for a population loss. Here the aim is to distinguish uncertainty that was already present from uncertainty introduced by deleting information about particular old decisions.
- **Cheapest first test / control:** Compress a polytope so tight and loose old pairs acquire the same outer bound. Compare an equal-byte polytope approximation, open-status replay, and exact sets. Kill if the inner certificates do not improve selective abstention without hidden extra memory.
- **Old-task retention:** Check both old settled pairs and truly open pairs after compression plus D; a lost proof must not be reported as genuine ambiguity.

### D2-20 · Make resolution conditional on a witness, not a model version
- **Primitive:** Store a rule that consumes an overlapping witness to release a noncommitment constraint. Test it by exchanging lawful witnesses between copies with identical serving answers; closure should follow the witness even after a representation update, not the old copy's logits or identity.
- **Nearest prior / gap:** [Dark Experience Replay](https://arxiv.org/abs/2004.07211) preserves old logits; [CE2-05](https://github.com/manojbajaj95/cl/pull/347) keeps a residual proposal to narrow later. This release rule is attached to an inherited unresolved *decision*, independent of the set of possible edits currently being considered.
- **Cheapest first test / control:** Two learners agree on A/B and open status, but C tilts their hidden logits in opposite directions. Give them swapped—and then wrong-scope—witnesses. Compare an explicit lookup rule and an exact version-space learner at equal bytes; reject if the learned release rule is no more reusable across held-out scopes.
- **Old-task retention:** Recheck A/B with correct, swapped, and wrong-scope witnesses; only the intended old comparison may close.

## C · Couple reachability to the question it is supposed to answer

### D2-21 · Preserve access in both possible worlds
- **Primitive:** Bind each unresolved direction to a route whose attainable power holds under both opposed worlds. A route usable only by users whose views already match the default does not satisfy the obligation, even if its average probability is high.
- **Nearest prior / gap:** [Robust dynamic programming](https://doi.org/10.1287/moor.1040.0129) plans under transition uncertainty; [CE3-21](https://github.com/manojbajaj95/cl/pull/349) preserves an experiment for every plausible intent. The maintained object links *old* opposite-world witnesses to reachability so evidence can retire only the constraints it actually resolves.
- **Cheapest first test / control:** One route works only in the true-current-preference world and one works in both, with matched average service. Compare CE3-21 plus a static register and an exact robust product-state controller. Reject if retaining old witness-indexed obligations never changes the permitted edits or reduces verification cost.
- **Old-task retention:** Check A/B after C and D and measure detection in each possible world under the same false-alarm bound.

### D2-22 · Reopen the floor when a resolved question can become contested again
- **Primitive:** Closing a question releases its immediate elicitation burden but leaves a dormant reversal obligation for contexts where the old evidence might cease to apply. Reactivate the bound on an independently defined scope change, not after the already-unreachable users complain.
- **Nearest prior / gap:** [NS-DPO](https://arxiv.org/abs/2407.18676) downweights stale preferences and [active diagnosis](https://home.lmf.cnrs.fr/downloads/SergeHaddad/A15-CDC.pdf) enforces fault detection. The candidate links release and reactivation to the scope of the old closure proof, instead of maintaining every full-time test indefinitely.
- **Cheapest first test / control:** Resolve A, then change one context feature that invalidates its evidence but not B's. Compare always-on diagnosis and drift-triggered querying; reject if scoped reactivation doesn't retain matched detection at lower burden.
- **Old-task retention:** Test A/B before closure, after closure, and after D triggers reactivation, including an old unchanged scope that must remain settled.

### D2-23 · Swap a route only if it can close the same next question
- **Primitive:** Check equivalence at the level of *future authorized decisions*: two routes with equal current detection power are substitutes only if all relevant next closure outcomes can be distinguished, up to a stated error. Keep the route covering a rare outcome that would supersede the old default.
- **Nearest prior / gap:** [Blackwell/Le Cam comparison](https://maxim.ece.illinois.edu/pubs/raginsky_ISIT11.pdf) compares statistical experiments; [decision-region active learning](https://proceedings.mlr.press/v33/javdani14.html) targets sets of hypotheses with a common decision. Here the comparison is restricted to an evolving set of lawful closure operations after successive writes, not universal experiment dominance.
- **Cheapest first test / control:** Two three-outcome experiments tie on current error but only one separates a future reversal that D makes decision-relevant. Compare a power-matched substitution and Blackwell dominance with identical experiments. Kill if selective equivalence offers no permissible savings without false closures.
- **Old-task retention:** After the swap, test A/B classifications and actual ability to resolve the held-out rare old outcome, not just the common one.

### D2-24 · Preserve possible answers when an opt-in expires
- **Primitive:** If the last lawful route closes when consent or a channel expires, separate the undecided comparison from the now-unavailable permission. Preserve opposed worlds without reserving or implying a right to reacquire; restoration requires new authorization and a revalidated route.
- **Nearest prior / gap:** [GateMem](https://arxiv.org/abs/2606.18829) tests access and forgetting in multi-principal agents; [dynamic observers](https://arxiv.org/abs/1004.2810) select sensors under diagnosis requirements. The candidate retains a noncommitment invariant across removal of the only permitted sensor, and treats infeasibility as a real state rather than selecting a nonconsensual workaround.
- **Cheapest first test / control:** An old unresolved pair loses permission while an unrelated scope gains a valid witness. Compare hard abstention after sensor loss and a full permission-filtered planner. Reject if the combined state cannot restore resolution on a later opt-in without bias or premature closure.
- **Old-task retention:** Score unaffected old A/B outputs, old open status after expiry, and correct resolution only after fresh authorization.

### D2-25 · Retain one route that can serve more than one old question, without over-crediting it
- **Primitive:** Share the costly prefix of an elicitation workflow while retaining separate evidence suffixes that discharge different comparison obligations. A report can close one scope while the unused branch remains reachable for another.
- **Nearest prior / gap:** [Deep Adaptive Design](https://arxiv.org/abs/2103.02438) amortizes sequential design; [dynamic observers](https://arxiv.org/abs/1004.2810) optimize sensor use. The candidate composes independently scoped obligations over a common path without converting shared acquisition into permission to close both.
- **Cheapest first test / control:** Two correction plans have a common consented setup and disjoint decisive queries; C kills one suffix but not the prefix. Compare independent diagnosis plans and joint DAD with the same scope rules. Reject if factoring doesn't reduce burden or revalidation cost at matched correct closure.
- **Old-task retention:** Test A/B habitual workflows and both old contrasts after C/D, and confirm one authorized report doesn't resolve the other.

### D2-26 · Give an approver two independent failure witnesses for the same write
