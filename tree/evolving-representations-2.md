# Evolving Representations 2: Future-Equivalent Token Merges and Action-Indexed Fiber Splits

Child of [root-evolving-representations.md](root-evolving-representations.md) (depth 1) · 27 candidate primitives and boundary probes · Ideas only; no experiments run

**Why this node exists.** The reviewer's triage of the root ([PR #325](https://github.com/manojbajaj95/cl/pull/325), [flood-triage row 443](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-triage.md#L443)) promoted two cards to score 3 and treated the rest as representation-change operations that still need a retention-matched growth baseline:
1. **ER01 · Retire a token from the model itself:** map the old emission machine and its live state onto a smaller machine over the new alphabet, merging partial parses only when their laws over *all* future bytes agree. The reviewer noted that ER01 is a concrete testbed for the top-10 **Nerode-quotient** idea ([flood-top10](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-top10.md)), not a separate primitive, and required controls: sampler-side token merging, vocabulary re-tokenization with embedding re-init, a quotient by next-byte agreement only, a parse pair that agrees short-term but splits later, and old-text perplexity retention.
2. **ER11 · Split a state only along the action that breaks it:** refine a learned state class with an action-indexed fiber that holds the lost distinction for that action, while old actions keep reading the coarse class. Required controls: a full state split, bisimulation-metric refinement, adding a separate state variable at equal size, a distinction needed by several actions, and old-action retention.

**Thesis.** ER01 and ER11 are the two halves of a single continual-learning algebra: **selective behavioral coarsening** (merging representation distinctions whose future continuations agree, while charging every unresolved distinction to an explicit residual state and deleting the retired symbol) and **selective behavioral refinement** (opening a distinction *only* along the specific action or edit that breaks equivalence, leaving all other consumers on the coarse quotient and making that fiber portable across base states). A live continual learner needs both operators—and needs to know when they commute, when they collide, and where present-output equivalence hides future-training divergence.

**Constraints inherited from the ledger and tree.** The [idea ledger](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/idea-ledger.md) and [flood-top10](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-top10.md) bind every card below:
- **Present-output agreement is not future-training agreement.** [PR #104](https://github.com/manojbajaj95/cl/pull/104) showed function-identical states (`uv` with `(1,1)` vs `(2, 1/2)`) diverge after one gradient step, and [Fiber Fingerprints of Hidden Learning-State Dynamics (2608.15976)][fiber] formalizes the same gap for execution states: present-behavior equivalence classes still carry non-trivial future-training fibers. Any ER01 token merge that checks only future bytes can silently alias states that diverge when task C trains.
- **Classes merge only at singular steps.** [PR #108](https://github.com/manojbajaj95/cl/pull/108) predicts that Nerode classes collapse only at singular steps (rank drop, weight decay to zero, dead units), never under invertible SGD; [PR #111](https://github.com/manojbajaj95/cl/pull/111) showed span projection leaves a gauge residual unless gauge is fixed first.
- **No recycled kills.** Not proposed again here: frozen-backbone skill embeddings (killed as B2 / prompt-pool CL + Toolken), read-pinning adapter ABIs (killed in [PR #117](https://github.com/manojbajaj95/cl/pull/117)), replay/append-and-retrieve/exact-restore shortcuts, plasticity-reserve Gramians (killed in PR #9/#21), optimizer-state / Noether memory, or margin-only lesson effects.

**Literature check.** AlphaXiv searches (November 2026) covered vocabulary reduction and token pruning, cross-tokenizer distillation, Myhill-Nerode / PDFA extraction, action-conditioned bisimulation, adaptive state-action abstraction, and learning-state fibers. Primary texts inspected:
- [Lossless Vocabulary Reduction (2510.08102, ICLR 2026)][lossless]: exact sub-vocabulary sequence distribution at inference, but keeps and runs the original LM rather than compiling the token out of the weights.
- [LiteToken (2602.04706)][litetoken]: deletes low-frequency BPE intermediate merge residues without retraining; relies on rarity rather than continuation equivalence and does not migrate live states.
- [Event-Set Completion Distillation, ESCD (2609.34738)][escd] and [Dual-Vocabulary LM, DVLM (2609.33816)][dvlm]: align cross-tokenizer distillation via completion-set mass or parallel teacher sequences, keeping the old-tokenizer teacher alive.
- [PDFA Distillation via String Probability Queries (2406.18328)][pdfa] and [Congruence-based Learning of PDFAs (2412.09760)][congruence]: extract minimal automata from LMs over a fixed alphabet, without destructive alphabet retirement or continued learning on C.
- [Action-Conditioned Bisimulation for GUI Agent Memory (2609.38778)][acbisim]: merges states only when *all* tried shared actions agree—producing a global partition (full split on any breaking action), not a per-action fiber that leaves unaffected actions on the coarse quotient.
- [Compositional Behavioral Semantics for State Abstraction (2606.25357, ICML 2026)][compsem] and [Adaptive State-Action Abstractions via Rate-Distortion (2606.06123)][rdabs]: formalize global abstraction transfer and temperature-controlled global refinement, not portable single-action fibers.
- [Fiber Fingerprints of Hidden Learning-State Dynamics (2608.15976)][fiber]: formalizes predictive quotients and present-behavior fibers under future training, without token/alphabet retirement or action-indexed MDP state splits.

**Shared first-test protocol (adds to the root's).** Every card stages **A → B → C** on CPU only: fit A, apply the merge or split on B, then learn fresh C on the rewritten model. Delete the retired token row / old head / old split path before scoring. Equalize total stored bits (including residual states, fibers, routing tables, and transport maps), training examples, and search budget. No task IDs at test time. Score A immediately after the edit and again after C on held-out raw inputs; score B again after C.

**Three exact CPU fixtures reused across cards:**
- **F-tok (for ER01 cards).** A rational weighted automaton (and a 2-layer GRU / 2-layer Transformer) over alphabet `{a, b, c, ab}` with a planted decoy pair of partial parses that match on next-byte probabilities (`h=1`) to `1e-4` but diverge at `h=2` or `h=3`. B retires `ab`; C introduces a new continuation rule over `aba` or `abc`.
- **F-fiber (for ER11 cards).** A tabular MDP (and a 2-layer MLP world model) with aliased base states `{s_0, s_1}` that share identical transition and reward laws under 4 old navigation actions `{N, S, E, W}` but differ under a 5th action `reset` introduced in B; C introduces a new base state `s_2` with a different navigation graph that shares the same `reset` distinction.
- **F-dual (for ER01 × ER11 cards).** A coupled token-and-action environment: an agent reads tokenized observations over `{a, b, ab}` and executes actions `{act_1, act_2, act_3}` where retiring `ab` is future-equivalent for text prediction and `{act_1, act_2}` but breaks `act_3` on 5% of prefixes.

## A · ER01 deepened: Future-equivalent token merges and destructive compilation

### ER2-01 · Bi-Nerode token merge: require both future-byte and future-training equivalence
- **Mechanism:** Extend ER01's merge rule from output-only Nerode equivalence to *bi-Nerode* equivalence: merge two partial-parse states when retiring token `ab` only if (i) their conditional laws over future bytes agree within `ε_out` AND (ii) their first-order parameter-update responses on a declared probe family of future tasks agree within `ε_train`. When (i) holds but (ii) fails, keep a zero-at-inference, training-only residual coordinate so inference runs on the collapsed state while task C's gradient still separates the two parses. Delete `ab`'s embedding and output row.
- **Novelty vs nearest prior art:** [Lossless Vocabulary Reduction (2510.08102)][lossless] preserves only the static text distribution at inference; [Fiber Fingerprints (2608.15976)][fiber] defines future-training fibers for frozen execution states but never couples them to destructive token retirement or alphabet compilation. Gap: using future-training equivalence as a gate on token-level state merging so retirement does not silently erase C-task plasticity.
- **Cheapest first test:** F-tok on a 2-layer GRU where two `ab`-containing prefixes have identical future-byte distributions on A (matched via gauge-equivalent hidden encodings, mirroring [PR #104](https://github.com/manojbajaj95/cl/pull/104)) but opposite target labels in C. Compare output-only ER01, sampler-side reduction ([2510.08102][lossless]), embedding re-init, and bi-Nerode merge at equal stored bits. **Kill:** if bi-Nerode does not beat output-only ER01 on C adaptation steps by ≥ 20% while matching its inference state size, or if a random extra hidden unit ties it.
- **Old-task retention:** Exact byte-prefix perplexity and stop probability on held-out A text immediately after deleting `ab` and after C converges, verifying zero drift from the training-only coordinate during A inference.

### ER2-02 · Witness-bounded horizon retirement: certify the exact suffix depth where a merge breaks
- **Mechanism:** Exact infinite-horizon Nerode equivalence is undecidable in neural LMs. Instead, for every candidate merge of partial parses produced by retiring token `t`, search for the shortest *separating suffix* `w*` where `TV(p(·|h_1), p(·|h_2)) > ε`. Retire `t` only with an explicit horizon certificate `k* = |w*|` (or `∞` when bounded-rank Hankel closure holds) and attach a cheap online monitor that re-splits the state if B/C traffic hits suffix patterns at depth ≥ `k*`.
- **Novelty vs nearest prior art:** [PDFA Distillation (2406.18328)][pdfa] uses a fixed error threshold `μ` during observation-tree merging over a static alphabet; [LiteToken (2602.04706)][litetoken] prunes by frequency with no horizon guarantee. Gap: explicit per-merge depth certificates `k*` that distinguish safe finite-horizon merges from deferred-split traps in a live stream.
- **Cheapest first test:** F-tok with planted parse pairs separating at depths `k ∈ {1, 2, 4, 8}`. Compare next-byte-only quotient (`k=1`), witness-bounded retirement, full unmerged split, and [2510.08102][lossless] sampler reduction at equal memory. **Kill:** if the certificate `k*` fails to rank actual post-retirement perplexity blowups above next-byte TV (`ρ < 0.7`), or if `k=1` already catches ≥ 90% of the damage on the decoy family.
- **Old-task retention:** Held-out old-text NLL stratified by suffix length `1..8`, ensuring long-range dependencies beyond `k*` are not silently corrupted after `t` is deleted and C is trained.

### ER2-03 · Joint Hankel-rank quotient of the multi-token ambiguity buffer
- **Mechanism:** Retiring `m` tokens sequentially under naive ER01 accumulates `O(m)` separate partial-parse ambiguity states. Instead, construct the empirical prefix × suffix Hankel matrix restricted to all boundary states touched by the `m` retired tokens, factor it via SVD/spectral realization to its numerical rank `r ≪ m`, and compile one shared `r`-dimensional predictive state buffer that replaces all per-token ambiguity states before deleting the `m` token rows.
- **Novelty vs nearest prior art:** Spectral learning of weighted automata ([2010.10029][spectral]) learns a single automaton from scratch over a fixed alphabet; [TokAlign++ (2605.13429)][tokalign] aligns individual token embeddings independently. Gap: joint spectral compression of *cross-token retirement residuals* so retiring correlated subwords shares one minimal ambiguity subspace.
- **Cheapest first test:** Weighted automaton and 2-layer GRU over a 32-token synthetic BPE vocabulary where 12 correlated subwords are retired in B, followed by a new compositional rule in C. Compare sequential per-token ER01, joint Hankel-rank quotient, embedding re-init, and [2510.08102][lossless] sampler reduction at equal bit budget. **Kill:** if joint rank `r` is ≥ 0.8 of the sequential state count, or if old-text perplexity is worse than sequential ER01 at matched bits.
- **Old-task retention:** Per-family held-out byte perplexity across all 12 retired subword families plus 20 unretired families, before and after C.

### ER2-04 · In-place KV-cache quotienting across a live token retirement
- **Mechanism:** Retiring a token from model weights breaks any in-flight agent whose KV cache still holds keys and values computed from the deleted token. Learn a low-rank *KV-quotient operator* `Q_t` that maps cached `(K, V)` slices at positions where `t` appeared into equivalent reduced-alphabet `(K', V')` slots—merging two cached prefixes iff their post-retirement attention-weighted future laws agree—so live sessions survive retirement without re-prefilling from raw bytes or keeping `t`'s embedding row.
- **Novelty vs nearest prior art:** [In-Place Tokenizer Expansion (2607.15232)][inplace] and [DVLM (2609.33816)][dvlm] operate on fresh forward passes or parallel teacher sequences; neither migrates an *already-materialized* KV cache destructively across a vocabulary contraction.
- **Cheapest first test:** 2-layer Transformer on F-tok with cached prefixes of length 32–128 containing `ab`; retire `ab` mid-sequence, apply `Q_t` to the cache, and continue generating into C. Compare full byte re-prefill (ceiling), zero-masking the retired KV slot, sampler-side reduction, and `Q_t` at matched latency/memory. **Kill:** if `Q_t` loses > 2% byte-level KL to full re-prefill on held-out prefixes, or if naive re-encoding of the last 4 tokens ties it.
- **Old-task retention:** Match conditional completion distributions from mid-sequence cached states on old A prompts after deleting `ab` and training C.

### ER2-05 · Compile a retired merge-residue into a rank-1 transition bias, not an embedding average
- **Mechanism:** When retiring a merged token `ab` into `a, b`, standard vocabulary pruning ([LiteToken][litetoken]) drops the row and embedding re-init averages `e_a, e_b`, losing the conditional boost `P(b | context, a)` that `ab` carried. Instead, compile the retired token's excess log-odds into a *rank-1 transition bias* on the `(a → b)` edge in the first attention/recurrent block, active only when `a` was just emitted, then delete `ab` from both input and output tables.
- **Novelty vs nearest prior art:** [LiteToken (2602.04706)][litetoken] deletes BPE merge residues assuming rarity makes the error negligible; [TokAlign++ (2605.13429)][tokalign] transfers static embeddings without adding a conditional transition term. Gap: exact first-order absorption of a retired merge's bigram probability mass into an edge-specific transition operator.
- **Cheapest first test:** F-tok plus a tiny BPE-trained 2-layer Transformer on synthetic structured logs where `ab` occurs at 0.5%–5% frequency (both rare-residue and non-rare regimes). Compare LiteToken deletion, embedding re-init, rank-1 transition-bias compilation, and [2510.08102][lossless] sampler reduction. **Kill:** if embedding re-init + 5 steps of fine-tuning ties the compiled transition bias at matched compute, or if `a → c` probabilities drift > 0.5% KL.
- **Old-task retention:** Separate perplexity on contexts containing `ab`, contexts containing `a` followed by `c ≠ b` (non-interference check), and unrelated old text, after retirement and after C.

### ER2-06 · 1-bit anti-aliasing provenance flag for retired-merge parse collisions
- **Mechanism:** Retiring `ab` creates a *parse collision*: `a, b` produced by splitting a former `ab` now looks identical to `a, b` that was originally emitted unmerged (e.g., across a word or syntactic boundary). Rather than expanding the full hidden state, attach a 1-bit provenance flag *only* on retired tokens whose merged vs unmerged histories have statistically distinct future-byte distributions, and automatically prune the bit once the two histories' continuations reconverge within `k` steps.
- **Novelty vs nearest prior art:** [Lossless Vocabulary Reduction (2510.08102)][lossless] tracks the full posterior over original tokenizations at inference; [Event-Set Completion Distillation (2609.34738)][escd] supervises completion sets without modeling merged-vs-unmerged boundary aliasing inside a retired student. Gap: minimal 1-bit transient provenance that pays state cost strictly where parse aliasing actually changes future laws.
- **Cheapest first test:** Synthetic grammar with two distinct contexts producing bytes `ab` (one formerly tokenized `[ab]`, one `[a][b]` with different continuations after 2 bytes), plus a decoy pair whose continuations match. Compare unflagged ER01, full history tracking, and 1-bit selective provenance at equal bits. **Kill:** if the learner cannot identify which retired tokens need the bit from B data without hand-labeling, or if unflagged ER01 ties on the decoy-free split.
- **Old-task retention:** Exact next-byte KL on both the formerly-merged and formerly-unmerged `ab` contexts (evaluated separately so rare unmerged cases are not masked), before and after C.

### ER2-07 · Order-independent batch retirement via commuting quotient operators
- **Mechanism:** Retiring overlapping tokens `t_1` (`ab`) then `t_2` (`bc`) can produce a different reduced state machine and worse old-text perplexity than retiring `t_2` then `t_1`, because the first quotient alters which partial parses exist when the second runs. Formalize the commutator `[Q_{t_1}, Q_{t_2}]` on the prefix transition graph, detect non-commuting overlap cliques, and compile a *simultaneous clique quotient* that minimizes total residual states over all sequential retirement orders.
- **Novelty vs nearest prior art:** [In-Place Tokenizer Expansion (2607.15232)][inplace] and [LiteToken (2602.04706)][litetoken] apply token edits greedily or independently; [Does Learning Order Explain Forgetting? (2611.20087)][orderforget] studies gradient-field commutators, not alphabet-quotient commutators. Gap: an explicit non-commutativity detector and simultaneous compiler for overlapping token retirements.
- **Cheapest first test:** Weighted automaton and 2-layer GRU over `{a, b, c, ab, bc, abc}` retiring `{ab, bc}` in both orders vs simultaneously, then learning C on `abca`. Compare order 1→2, order 2→1, simultaneous clique quotient, and sampler-side reduction. **Kill:** if sequential order never changes final state count or old-text perplexity by > 1% across 20 random overlapping grammars.
- **Old-task retention:** Worst-case held-out NLL across all overlap patterns (`ab`, `bc`, `abc`, `aba`) after retirement and after C.

### ER2-08 · Distill-free self-completion transport into a contracted output head
- **Mechanism:** Before deleting retired token rows from the output head, run a one-shot *self-completion transport*: for each retired token `t`, enumerate its valid reduced-alphabet completion paths `c_1…c_m` (as in ESCD), project `t`'s pre-retirement logit mass onto the completion-set boundary, solve a closed-form / few-step convex fit for the minimal state-conditioned logit correction on the surviving head, and permanently delete the old head—requiring zero teacher retention during C.
- **Novelty vs nearest prior art:** [ESCD (2609.34738)][escd] and [DVLM (2609.33816)][dvlm] require keeping the old-tokenizer teacher alive across training rollouts to supervise the student. Gap: one-shot destructive compilation of completion-set mass into the reduced head itself, with the old head deleted before C begins.
- **Cheapest first test:** 2-layer Transformer on F-tok retiring 8 tokens in B and adapting to C. Compare ESCD with teacher kept (ceiling), re-initialized reduced head + equal-compute SFT, next-byte-only projection, and self-completion transport. **Kill:** if embedding/head re-init + equal-compute SFT matches self-completion transport on old-text perplexity and C convergence.
- **Old-task retention:** Old-text perplexity and rare-token completion probability (exact match on multi-step completions of all 8 retired tokens) immediately after head deletion and after C.

## B · ER11 deepened: Action-indexed fiber splits and portable local distinctions

### ER2-09 · Transition-preserving fiber transport across dissimilar base states
- **Mechanism:** ER11 proposes recombining an action-indexed fiber `F_{a*}` with a new base state `s_new` in task C without duplicating the world model. Define an explicit *fiber transport map* `T: s_new → F_{a*}` learned strictly from `a*` transitions on `s_new`, constrained so that for every non-breaking old action `a ≠ a*`, the composite policy `π(a | s_new)` is invariant to `T`. Thus a single fiber geometry transfers across base states whose navigation graphs differ completely.
- **Novelty vs nearest prior art:** [Action-Conditioned Bisimulation (2609.38778)][acbisim] builds a static global partition per task with no cross-base transport; [Compositional Behavioral Semantics (2606.25357)][compsem] transfers properties across global abstraction homomorphisms rather than transporting a single action's local fiber between non-isomorphic base graphs.
- **Cheapest first test:** F-fiber (tabular + 2-layer MLP): learn the `reset` fiber on `{s_0, s_1}` in B; in C introduce `s_2` with a brand-new 4-action navigation topology but the same binary `reset` hazard. Compare full state split, bisimulation-metric refinement, adding an unconstrained state variable at equal bits, and fiber transport. **Kill:** if learning `T` requires as many `reset` samples on `s_2` as splitting `s_2` from scratch, or if an unconstrained shared state variable ties it.
- **Old-task retention:** Old navigation rollouts (`{N, S, E, W}`, length ≤ 4) from both `{s_0, s_1}` and `s_2` after transport and C training, checking zero drift on old actions.

### ER2-10 · Lazy zero-initialized fiber materialization on first action contradiction
- **Mechanism:** Never pre-allocate fibers or run global partition refinement. Keep all actions consuming the coarse quotient `q(o)` until a single action `a*` observes contradictory outcomes (exceeding a variance/KL threshold) from the same coarse class `q`. Only then materialize a zero-initialized residual fiber `f_{a*}(o)` gated strictly by `a*`, so old actions remain bitwise identical at the moment of creation and capacity is spent strictly where equivalence breaks.
- **Novelty vs nearest prior art:** [Adaptive State-Action Abstractions via Rate-Distortion (2606.06123)][rdabs] lowers a global rate-distortion temperature whenever Bellman residual reaches abstraction error, refining unrelated actions simultaneously; [Representational Empowerment (2609.02322)][empower] refactors concepts globally by intervention gain. Gap: contradiction-triggered, single-action lazy materialization with bitwise invariance of unaffected actions.
- **Cheapest first test:** F-fiber with 8 actions where only 1 action (`a*`) breaks aliasing in B and a second unrelated action breaks aliasing in C; include a decoy stream where no action breaks aliasing. Compare full split, rate-distortion temperature refinement ([2606.06123][rdabs]), separate state variable, and lazy fiber. **Kill:** if lazy fiber fails to beat rate-distortion refinement on sample efficiency + old-action stability by ≥ 10 pp, or spawns spurious fibers on the decoy stream.
- **Old-task retention:** Bitwise-exact action distributions for the 7 non-breaking actions immediately after materialization, and ≤ 0.5 pp accuracy drop after B and C finish training.

### ER2-11 · Fiber-to-base promotion rule: collapse redundant action fibers into a base split
- **Mechanism:** Directly handles the reviewer's adversarial control for ER11 ("a distinction needed by several actions"). Maintain a cross-fiber redundancy meter: compute the pairwise mutual information (or linear CCA / cosine) between active fibers `{f_{a_1}, …, f_{a_k}}` attached to the same coarse base class `q`. When `k ≥ m*` actions independently demand the same latent bit (surpassing a bit-cost threshold where one base split is cheaper than `k` separate fibers), promote that shared bit into the base state `q` and delete the redundant per-action fibers.
- **Novelty vs nearest prior art:** Classical MDP minimization ([mdp]) always splits the base state; [ER11][root] always keeps an action fiber. Neither gives a dynamic *promotion criterion* that switches between local fibers and global base splits as the number of affected actions grows.
- **Cheapest first test:** F-fiber swept over `k ∈ {1, 2, 4, 8}` actions sharing a hidden distinction across stages A → B → C. Compare always-fiber (ER11), always-full-split, separate state variable, and dynamic fiber-to-base promotion at matched total bits. **Kill:** if dynamic promotion fails to track the lower envelope of (always-fiber, always-full-split) across `k = 1..8`, or loses to always-full-split already at `k = 2`.
- **Old-task retention:** After promoting fibers into a base split, verify that the remaining `|A| - k` unaffected old actions keep identical rollouts (mapping both halves of the promoted base back to the same old-action logits).

### ER2-12 · Action-fiber interference barrier: isolate coarse-encoder gradients from single-action splits
- **Mechanism:** In a neural world model (unlike a tabular lookup), training an action-indexed fiber `f_{a*}` end-to-end backpropagates gradients into the shared coarse encoder `q_θ(o)`, silently distorting `q_θ` for old actions `a ≠ a*`. Place a hard stop-gradient (or null-space projection orthogonal to old-action Jacobians) between `f_{a*}` and `q_θ`, allowing `q_θ` to move only on multi-action consensus while `f_{a*}` reads raw/frozen early features.
- **Novelty vs nearest prior art:** Read-pinning adapter ABIs ([PR #117](https://github.com/manojbajaj95/cl/pull/117)) failed because base updates moved into downstream layers; here the *reverse* direction is isolated—preventing a newly spawned downstream action fiber from corrupting the shared coarse base encoder.
- **Cheapest first test:** 2-layer MLP on F-fiber where B's `reset` distinction requires high-frequency features that conflict with A's coarse navigation encoder. Compare unconstrained end-to-end ER11, stop-gradient fiber barrier, full split, and replay-protected full split at equal parameters. **Kill:** if unconstrained end-to-end ER11 already retains old actions within 1 pp of the barrier, or if freezing `q_θ` from `f_{a*}` makes `reset` unlearnable.
- **Old-task retention:** Old navigation action accuracy and rollout KL over all 4 old actions after B and C, without replay of old navigation trajectories.

### ER2-13 · Hierarchical conditional fiber stacking without Cartesian state blowup
- **Mechanism:** When action `a_1` splits base class `q` via fiber `f_1` in B, and later action `a_2` in C breaks equivalence *only inside one branch* of `f_1` (e.g., `f_1 = 1`), attach a conditional sub-fiber `f_2 | (q, f_1 = 1)` rather than taking the full product `q × f_1 × f_2`. Old actions still consume `q`; `a_1` consumes `(q, f_1)`; only `a_2` consumes `(q, f_1, f_2)`.
- **Novelty vs nearest prior art:** Factored MDPs and decision-tree state abstractions (U-Tree) build global trees shared by all actions; [ER11][root] defines only a flat 1-level fiber. Gap: action-indexed *conditional* fibers whose depth varies per action and per branch.
- **Cheapest first test:** Extended F-fiber: `a_1` splits `q` into 2 branches in B; `a_2` splits only branch 1 into 2 sub-branches in C while branch 0 stays unified; 4 old actions remain on `q`. Compare Cartesian full split (4 states), flat ER11 (two independent fibers), U-Tree global refinement, and conditional fiber stacking at equal bits. **Kill:** if flat ER11 ties conditional stacking on sample cost and bits, or if `a_2` leaks into `a_1`'s predictions on branch 0.
- **Old-task retention:** Check old 4-action navigation (must stay on `q`) AND `a_1`'s B behavior on both branches after C attaches `f_2`.

### ER2-14 · Epistemic-vs-aleatoric fiber gate: block spurious splits on stochastic actions
- **Mechanism:** Naive action-conditioned splitting allocates a fiber whenever an action's outcome has high variance—turning irreducible stochasticity (aleatoric noise) into memorized overfitting. Gate fiber allocation on *predictable* residual variance: allocate `f_{a*}` only if a cross-validated probe over raw observation/history beats the coarse-class outcome marginal by a certified conditional mutual information margin `ΔI > τ`.
- **Novelty vs nearest prior art:** [Action-Conditioned Bisimulation (2609.38778)][acbisim] tests empirical transition distribution differences between observed states, which splits on finite-sample noise if counts are small; [Adaptive Rate-Distortion (2606.06123)][rdabs] relies on Bellman residual without separating reducible aliasing from irreducible transition noise.
- **Cheapest first test:** F-fiber with two new actions in B: `reset_aliased` (deterministic but depends on hidden bit) and `reset_noisy` (genuinely 50/50 random, no hidden bit). Compare ungated ER11, bisimulation-metric refinement, and CMI-gated ER11 across 10 seeds. **Kill:** if ungated ER11 does not over-split `reset_noisy`, or if the CMI gate rejects `reset_aliased` > 10% of the time at matched sample size.
- **Old-task retention:** Old navigation actions plus calibration error (Brier/KL) on `reset_noisy` (must stay at 50/50, not overfit to spurious fiber splits) after B and C.

### ER2-15 · Surgical action-fiber unlearning: retire an obsolete distinction without refitting the base
- **Mechanism:** Because ER11 isolates a single action's distinction in its indexed fiber `f_{a*}`, retiring or deprecating action `a*` (or correcting a poisoned action rule) simply deletes `f_{a*}` and collapses back to the coarse base `q` with zero gradient steps on old actions. When `a*` is later replaced by a revised rule in C, a fresh fiber attaches cleanly with zero residual contamination from the deleted rule.
- **Novelty vs nearest prior art:** Unlearning in globally split MDPs or neural world models requires retraining or influence-based scrubbing that risks collateral damage to shared states; [Owned Edits (2611.15917)][owned] gates weight edits by task/fact rather than by action-indexed behavioral fibers. Gap: structural reversibility of single-action representation splits.
- **Cheapest first test:** F-fiber: train A (4 nav actions) → B (add `reset_v1` fiber) → retire `reset_v1` → C (add contradictory `reset_v2`). Compare full-split + fine-tune unlearning, separate state variable + zeroing, and ER11 fiber deletion. **Kill:** if deleting `f_{a*}` leaves any drift on A, or if full-split + fine-tuning on `reset_v2` matches C convergence speed and A retention.
- **Old-task retention:** Exact pre-B accuracy on all 4 old navigation actions immediately after `reset_v1` deletion and after `reset_v2` converges, plus zero leakage of `reset_v1` predictions on held-out probes.

## C · The ER01 × ER11 duality: Coarsening and refining as one algebra

### ER2-16 · Quotient-then-fiber round-trip: retire a token globally and quarantine its one breaking context in a fiber
- **Mechanism:** Often retiring token `ab` is future-equivalent on 95%+ of text (old task A) but breaks *one* specialized downstream task or tool action `a*` (e.g., exact delimiter parsing in code). Rather than aborting retirement or inflating the global state machine, execute the aggressive ER01 quotient globally (deleting `ab`) and compile the one breaking parse distinction into an ER11 fiber indexed strictly by `a*`.
- **Novelty vs nearest prior art:** [Lossless Vocabulary Reduction (2510.08102)][lossless] is all-or-nothing over the whole language; [ER01][root] keeps unresolved parse distinctions inside the *global* state machine. Gap: factoring a lossy global token retirement into a lossless global quotient on non-breaking tasks plus a localized action fiber on the breaking task.
- **Cheapest first test:** F-dual: retire `ab` in B where `ab` is future-equivalent for text modeling and `{act_1, act_2}` but distinguishes two meanings under `act_3`; C adds `act_4` that reuses `act_3`'s fiber. Compare global ER01 (keeps ambiguity globally), [2510.08102][lossless] sampler wrapper, full split, and quotient-then-fiber at equal total bits. **Kill:** if quotient-then-fiber does not beat global ER01 on total bits × old-task perplexity while matching `act_3` accuracy.
- **Old-task retention:** Held-out text perplexity and `{act_1, act_2}` accuracy after `ab` deletion and C, plus `act_3` accuracy on the 5% breaking prefixes.

### ER2-17 · Action-masked Nerode equivalence: merge tokens that agree outside a protected action set
- **Mechanism:** Generalize ER01's congruence from "agree on all future bytes" to *action-masked congruence*: two partial parses `h_1, h_2` merge iff their future distributions agree on every continuation *outside* a declared action subset `A_prot` (e.g., irreversible tool calls or safety-critical actions). Distinctions visible only inside `A_prot` are routed into an `A_prot`-indexed fiber instead of blocking vocabulary contraction.
- **Novelty vs nearest prior art:** Standard Myhill-Nerode ([pdfa][pdfa], [congruence][congruence]) quantifies universally over all suffixes `Σ*`; [Action-Conditioned Bisimulation (2609.38778)][acbisim] quantifies over all tried actions globally. Gap: a *relativized* Nerode congruence that separates vocabulary compression from protected-action fidelity.
- **Cheapest first test:** F-dual with 16 candidate token merges: 10 are universally equivalent, 4 differ only on `act_3` (protected), 2 differ on all actions (decoys). Compare universal ER01, next-byte quotient, and action-masked ER01+fiber at equal bits. **Kill:** if action-masked ER01 fails to retire the 4 `act_3`-only tokens without hurting `act_3`, or wrongly merges the 2 decoys.
- **Old-task retention:** Universal old-text perplexity, `{act_1, act_2}` accuracy, and zero regression on `act_3` safety/exact-match probes after retirement and C.

### ER2-18 · Zero-sum split-merge conservation: fund every new fiber by retiring an equivalent token or redundant fiber
- **Mechanism:** Unbounded ER11 splits grow state forever; unguided ER01 merges alias needed distinctions. Couple them under a strict *representation bit budget* `B_max`: every time task B or C requests a new ER11 fiber of `Δb` bits, the learner must first reclaim `≥ Δb` bits by executing an ER01 future-equivalent token merge (or collapsing a converged ER11 fiber whose actions no longer disagree). Representation evolution becomes a bounded-memory allocation loop.
- **Novelty vs nearest prior art:** Dynamic architecture growth ([FlowGenesis][flow], [SoftModel][soft]) grows capacity monotonically or prunes by weight magnitude without behavioral-equivalence guarantees. Gap: coupling behavioral-equivalence retirement (ER01) directly as the capacity source for behavioral-contradiction refinement (ER11).
- **Cheapest first test:** 5-stage stream on F-dual under fixed bit budget `B_max` where each stage introduces 1 new breaking action and makes 2 old compound tokens redundant. Compare fixed-budget full retraining, magnitude pruning + growth, ER11-only (hits budget cap), and coupled split-merge conservation. **Kill:** if magnitude pruning + growth ties coupled split-merge on cumulative retention and C accuracy at equal `B_max`.
- **Old-task retention:** Track per-stage retention of all earlier tasks (1..t-1) across all 5 stages, reporting worst-family drop rather than average.

### ER2-19 · Dual-clock evolution: fast action-fiber splits, slow alphabet quotients with fiber transport
- **Mechanism:** Directly instantiates root question #5 on ER01+ER11: allow ER11 fibers to spawn online at every step as new action contradictions arrive (fast clock), while running ER01 token retirement only at periodic consolidation boundaries (slow clock). At each slow-clock boundary, transport every live ER11 fiber through the new ER01 quotient map so fast-clock distinctions survive slow-clock alphabet contraction.
- **Novelty vs nearest prior art:** Multi-timescale CL (fast/slow weights, Benna–Fusi) varies learning rates on fixed coordinates; here the *coordinates themselves* (alphabet vs action fibers) evolve on separate clocks with an explicit boundary transport operator.
- **Cheapest first test:** 4-epoch F-dual stream: fast-clock ER11 splits in episodes 1–50, slow-clock ER01 token retirement at episode 50, fresh C task in episodes 51–100. Compare simultaneous per-step ER01+ER11, independent ER01 and ER11 without fiber transport (must break on transported fibers), and dual-clock with transport. **Kill:** if independent ER01+ER11 without transport retains fiber accuracy within 1 pp, or if per-step joint updates tie at equal compute.
- **Old-task retention:** Accuracy of both old base actions AND all fast-clock fibers spawned before episode 50, scored immediately after the episode-50 alphabet retirement and again at episode 100.

### ER2-20 · Fiber-preserving quotient morphism: block any token merge that collapses an active action fiber
- **Mechanism:** Combining ER01 and ER11 introduces a subtle hazard: a token merge can be nearly lossless on text perplexity (old task A) while erasing the exact prefix cue read by an active ER11 action fiber (task B). Enforce a *fiber-preserving congruence check*: before retiring token `t`, verify that the induced quotient map `q_t` does not collapse any pair of prefixes separated by any active fiber `f_a` (`MI(f_a; h) - MI(f_a; q_t(h)) ≤ δ`). If it does, either veto the merge or lift the missing bit into `f_a` first.
- **Novelty vs nearest prior art:** [Lossless Vocabulary Reduction (2510.08102)][lossless] and [LiteToken (2602.04706)][litetoken] evaluate token removal solely on language-modeling loss/frequency, ignoring downstream action-specific representations. Gap: an explicit mutual-information preservation invariant coupling vocabulary contraction to live action fibers.
- **Cheapest first test:** F-dual with a planted *trap token* `ab` whose removal changes text perplexity by < 0.01 nats (passing standard ER01) yet destroys 100% of `act_3`'s fiber signal. Compare unguarded ER01, LiteToken, and fiber-preserving ER01 (both veto and lift-then-merge arms). **Kill:** if unguarded ER01 catches the trap via text perplexity alone, or if lift-then-merge loses to veto at matched bits.
- **Old-task retention:** Zero drop on `act_3` fiber accuracy AND old-text perplexity across all non-trap merges, before and after C.

### ER2-21 · Counterfactual merge-vs-split arbitrage: choose between alphabet rewrite and state-fiber split at equal bits
- **Mechanism:** When task B reveals an aliased error on a shared prefix, the learner can resolve it in two structurally different ways: (i) split the latent state along the breaking action (ER11) or (ii) modify the token boundary (un-merging or re-segmenting the colliding prefix, ER01-style). Define a cheap one-step *bit-cost arbitrageur* that estimates the total description length (stored bits + expected C transfer cost) of both edits and commits the cheaper structural primitive.
- **Novelty vs nearest prior art:** Existing work treats tokenizer adaptation ([2607.15232][inplace], [2605.13429][tokalign]) and state abstraction ([2606.25357][compsem], [2609.38778][acbisim]) as disjoint subfields. Gap: a unified decision rule selecting between an input-alphabet edit and a latent-state fiber split on the same stream.
- **Cheapest first test:** Two paired F-dual worlds with identical old task A: World 1 has a *lexical* aliasing bug (cheaper to fix by alphabet edit); World 2 has a *behavioral* action bug (cheaper to fix by ER11 fiber). Compare always-alphabet-edit, always-ER11-fiber, and the MDL arbitrageur at equal bits. **Kill:** if the arbitrageur fails to pick the cheaper primitive in ≥ 80% of instances, or if always-ER11-fiber ties it in World 1.
- **Old-task retention:** Old-task A perplexity and old-action rollouts in both worlds after the chosen edit and after C.

### ER2-22 · Quotient-residual fiber initialization: seed an ER11 fiber from an imperfect ER01 merge's discrepancy
- **Mechanism:** When an ER01 token merge is *almost* future-equivalent (failing only on a small slice of histories), the empirical discrepancy vector `Δ_h = p_old(suffix | h) - p_merged(suffix | q(h))` directly isolates the exact information discarded by the merge. Instead of discarding `Δ_h` or learning an ER11 fiber from scratch when task B breaks on those histories, compress the top singular vectors of `Δ_h` as the *initial coordinates* of B's action fiber.
- **Novelty vs nearest prior art:** [ESCD (2609.34738)][escd] treats cross-tokenizer mismatch purely as a distillation loss to minimize; here the *residual* of a lossy vocabulary quotient is repurposed as a structured feature initializer for downstream action-specific refinement.
- **Cheapest first test:** F-dual where retiring `ab` causes a localized 3% suffix discrepancy that happens to correlate with `act_3`'s breaking condition in B. Compare random-init ER11 fiber, full-observation probe fiber, and quotient-residual-initialized fiber at matched B sample counts. **Kill:** if quotient-residual init does not cut B samples to 95% `act_3` accuracy by ≥ 30% over random-init ER11, or if it hurts when the discrepancy is uncorrelated with B (decoy world).
- **Old-task retention:** Verify that in the decoy world (uncorrelated discrepancy), the residual initializer does not degrade A or B compared to random init, and old actions remain untouched.

## D · Hard boundaries, falsification probes, and negative-result guards

### ER2-23 · The Neural Nerode Gap: can finite-horizon byte equivalence reliably detect neural state divergence? *(Boundary probe)*
- **Mechanism:** A direct falsification test of ER01's core premise in neural models. Train a 2-layer GRU and 2-layer Transformer on F-tok; harvest parse pairs `(h_1, h_2)` whose next-`L` byte distributions match within `1e-3` TV (`L ∈ {1, 2, 4, 8}`), then measure (i) hidden-state divergence at depth `L+1..32` and (ii) post-update divergence after 10 SGD steps on C (connecting directly to [2608.15976][fiber] and [PR #104](https://github.com/manojbajaj95/cl/pull/104)). Quantifies the exact horizon `L*` where empirical Nerode merging stops being a mirage.
- **Novelty vs nearest prior art:** [PDFA Distillation (2406.18328)][pdfa] and [Sequential Neural Networks as Automata (1906.01615)][snn] measure static extraction fidelity; [Fiber Fingerprints (2608.15976)][fiber] tests training-state fibers on LoRA checkpoints. Neither maps the *finite-horizon suffix-matching vs post-retirement C-divergence* curve for token merges.
- **Cheapest first test:** CPU sweep over `L ∈ {1, 2, 4, 8, 16}` on F-tok (both weighted automaton oracle and 2-layer GRU/Transformer, 5 seeds). Compare next-byte (`L=1`) against `L=4, 8, 16` and exact Hankel rank. **Kill (for ER01's neural scalability):** if even `L=16` byte-matched pairs still show > 30% hidden-state or C-update divergence, then finite-horizon output sampling cannot safely drive neural token merges without a training-fiber check (ER2-01).
- **Old-task retention:** Report held-out old-text perplexity jump as a function of `L` after merging all pairs within `ε` at horizon `L`.

### ER2-24 · Compilation vs wrapper crossover: when does deleting a token actually beat inference-only reduction? *(Boundary probe)*
- **Mechanism:** The reviewer explicitly demanded that ER01 beat sampler-side token merging ([Lossless Vocabulary Reduction, 2510.08102][lossless]). Map the exact resource frontier—total stored bits (weights + tables), per-token decode FLOPs, and C-task adaptation sample efficiency—comparing (a) keeping the old LM + exact `2510.08102` inference wrapper + LoRA on C versus (b) destructively compiling the token out of the model via ER01 and fine-tuning on C. Include a regime where the wrapper provably wins (1 retired rare token, zero C interaction) and a regime where compilation must win (retiring 30% of a domain vocabulary before C reuses the freed capacity).
- **Novelty vs nearest prior art:** [Lossless Vocabulary Reduction (2510.08102)][lossless] never compares against destructive model compilation under continual task C; [LiteToken (2602.04706)][litetoken] never compares against exact lossless inference wrappers.
- **Cheapest first test:** 2-layer Transformer on F-tok sweeping retired vocabulary fraction `f ∈ {2%, 10%, 30%, 50%}` at fixed total parameter+wrapper bit budget. **Kill (for ER01 as a practical primitive):** if the exact `2510.08102` wrapper + LoRA dominates destructive ER01 compilation on *both* old-text perplexity and C accuracy across all `f ≤ 50%`.
- **Old-task retention:** Exact old-text perplexity and stop-probability calibration at every `f`, ensuring compilation does not buy C speed by silently breaking A.

### ER2-25 · Singularity-gated token merges: do smooth SGD updates ever truly collapse partial parses? *(Boundary probe)*
- **Mechanism:** Tests [PR #108](https://github.com/manojbajaj95/cl/pull/108)'s singularity prediction directly inside ER01. After retiring `ab`, compare two ways of merging future-equivalent partial parses in a neural sequence model: (a) smooth distillation/SGD toward the reduced-alphabet distribution (invertible updates) versus (b) an explicit rank-dropping / gauge-fixed projection step ([PR #111](https://github.com/manojbajaj95/cl/pull/111)) that forces the two parses onto identical hidden coordinates before C trains. Measure whether smooth SGD leaves a hidden gauge residual that re-expands under C.
- **Novelty vs nearest prior art:** [PR #108](https://github.com/manojbajaj95/cl/pull/108) and [PR #111](https://github.com/manojbajaj95/cl/pull/111) studied edit-history Nerode classes on toy factorized models; [Fiber Fingerprints (2608.15976)][fiber] documented non-closing hidden fibers under AdamW. Gap: testing whether *token-retirement* merges require an explicit singular projection step to remain collapsed during subsequent continual learning.
- **Cheapest first test:** 2-layer GRU on F-tok: retire `ab` via smooth distillation vs explicit SVD/gauge-fixed projection, then train C for 100 steps and probe whether formerly merged parses re-separate in hidden state and output logits. **Kill:** if smooth distillation keeps merged parses within `1e-3` after C with no gauge residual, then explicit singular projection is unnecessary.
- **Old-task retention:** Old-text perplexity and prefix-law KL before and after the singular projection step and after C.

### ER2-26 · The ER11 crossover law: at what fraction of breaking actions does an action fiber lose to a full state split? *(Boundary probe)*
- **Mechanism:** Operationalizes the reviewer's adversarial control for ER11 ("a distinction needed by several actions"). Sweep the fraction `ρ = k / |A|` of actions that depend on a hidden state distinction from `1/16` to `16/16`, measuring (i) total stored bits, (ii) B+C sample complexity, and (iii) old-action retention for ER11 action fibers vs full partition refinement vs bisimulation-metric refinement vs adding a separate global state variable. Empirically locate the sharp crossover `ρ*` (and test whether it matches the theoretical bit-cost crossover).
- **Novelty vs nearest prior art:** [Action-Conditioned Bisimulation (2609.38778)][acbisim] and [MDP Model Minimization][mdp] never measure the sparsity crossover `ρ*` between per-action fibers and global partitions.
- **Cheapest first test:** Tabular + 2-layer MLP on F-fiber with `|A| = 16` actions, sweeping `k ∈ {1, 2, 4, 8, 12, 16}` across 5 seeds. **Kill (for ER11's generality):** if ER11 loses to a separate global state variable or full split already at `k = 2` (`ρ = 1/8`), narrowing ER11 to strictly single-action exceptions.
- **Old-task retention:** Worst-action retention across the `16 - k` unaffected old actions at every `k`.

### ER2-27 · Minimal non-commutative witness: a 6-state automaton where ER01 and ER11 fail to commute *(Audit / exact fixture)*
- **Mechanism:** Construct the smallest deterministic finite-state machine (6 states, 3 input tokens `{a, b, ab}`, 2 actions `{act_1, act_2}`) where executing **ER01 (retire `ab`) → ER11 (split `act_2`)** yields a strictly different minimal representation size and C-task transferability than executing **ER11 (split `act_2`) → ER01 (retire `ab`)**. Use this exact, zero-noise witness as a mandatory unit test for any continual representation compiler claiming order-independent evolution.
- **Novelty vs nearest prior art:** [Does Learning Order Explain Forgetting? (2611.20087)][orderforget] studies order dependence in gradient steps; `F-order` in [learning-economics-2 (PR #326)](https://github.com/manojbajaj95/cl/pull/326) gives a 2-step scalar witness for weight updates. Gap: an exact finite-state non-commutativity witness for *structural* representation edits (alphabet quotient × action-fiber split).
- **Cheapest first test:** Exact enumeration on CPU (< 1 second): verify both edit orders on the 6-state witness, check exact state+fiber bit counts, and test whether a joint product-quotient compiler recovers the smaller representation regardless of arrival order. **Kill:** if every 6-state machine over `{a, b, ab} × {act_1, act_2}` commutes up to isomorphism (requiring a larger counterexample or disproving non-commutativity).
- **Old-task retention:** Exact deterministic trace agreement on all strings of length ≤ 6 for both `act_1` and `act_2` under both edit orders.

## Ranked deeper questions

1. **Does output-only Nerode equivalence survive continual learning, or must token retirement always check future-training fibers?** *(ER2-01, ER2-23, ER2-25)*
   ER01 merges partial parses whose future *byte* laws agree; [PR #104](https://github.com/manojbajaj95/cl/pull/104) and [Fiber Fingerprints (2608.15976)][fiber] prove that present-output-identical states can still diverge under future training. Is there a sharp, measurable regime where output-only ER01 breaks C adaptation (or silently re-splits after C) while bi-Nerode / singular-projected merges hold—or does standard SGD on C wash out the gap?

2. **Where is the real crossover where destructive token compilation beats an exact inference wrapper?** *(ER2-04, ER2-08, ER2-24)*
   [Lossless Vocabulary Reduction (2510.08102)][lossless] already gives exact sub-vocabulary generation without touching the weights. Unless compiling a token *out* of the model beats `2510.08102` + LoRA on a concrete Pareto axis (memory bits, mid-sequence KV latency, or C-task sample efficiency at fixed budget), ER01 is only a compression trick rather than a continual-learning primitive. What is the smallest vocabulary-retirement fraction `f*` where destructive compilation strictly wins?

3. **When is an action-indexed fiber genuinely better than a global state split or an extra latent variable?** *(ER2-09, ER2-11, ER2-12, ER2-26)*
   Every ER11 card faces the reviewer's multi-action control: if a hidden distinction soon matters to `k ≥ 2` or `k ≥ 3` actions, a full base split or shared latent variable wins. Can we establish both (a) a clean sparsity crossover `ρ*` where fibers win and (b) genuine zero-shot or few-shot *fiber transport* to a dissimilar base state (ER2-09) that a full state split cannot match?

4. **Do quotienting (ER01) and fiber splitting (ER11) compose into a single bounded-memory representation algebra, or do they fight each other?** *(ER2-16, ER2-18, ER2-20, ER2-27)*
   In a long-lived agent, retiring tokens risks collapsing cues that active action fibers rely on (ER2-20), while spawning fibers without retiring redundancies causes state blowup (ER2-18), and the two operations may not commute (ER2-27). Does coupling them via a fiber-preserving congruence and a zero-sum bit budget beat independent tokenizer pruning + state growth?

5. **Can a learner tell—at equal bits—whether an aliased failure belongs in the alphabet or in the state space?** *(ER2-17, ER2-21, ER2-22)*
   In real continual agents, lexical ambiguity (token boundaries) and behavioral ambiguity (action-dependent hidden state) produce indistinguishable surface errors on a single episode. What minimal stream evidence lets a learner arbitrate between an ER01 alphabet edit and an ER11 state-fiber split without hand-labeled task structure?
