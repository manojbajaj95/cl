# Confirmable margin loans

**Status:** Ideas only; no training runs or GPU work. **Parent:** [Margin-borrowing write phases](margin-borrowing-phases.md) ([PR #221](https://github.com/manojbajaj95/cl/pull/221)), cards 10 and 19. **Review seed:** [Flood triage, row 333](https://github.com/manojbajaj95/cl/blob/23271faa8a1124d95b2abad457a3835cff0fa099/reviews/flood-triage.md#L333) scores both ideas 3: hold a first write on one old group's slack until the cycle repays it or independent corroboration converts it into a permanent zero-margin change; lend distance from a hidden ReLU kink instead of output margin. **Read first:** [Idea ledger](https://github.com/manojbajaj95/cl/blob/23271faa8a1124d95b2abad457a3835cff0fa099/reviews/idea-ledger.md).

## Can one live write be both the evidence and the thing that must be repaid?

**Verdict: a candidate operation, not a new counter or nullspace.** [Fast weights][fastw], [Lookahead][lookahead] and [synaptic tagging and capture][stc] already separate transient and persistent changes. [GEM][gem] and [COLD][cold] constrain interference, [OGD][ogd] protects old output directions, [GPM][gpm] and [feature-covariance nullspaces][nsp] protect old features, and [CROWN][crown] can certify activation regions and output bounds. The claim worth testing is that **one reversible excursion through shared weights does two jobs**: it enables a useful in-window action and carries the evidence needed to confirm a persistent write. Removing just the excursion should remove both, and natural expiry should repay the loan without a compensating replay or saved pre-write copy. A hidden-unit lender is a stricter version: its old gaps never change, even while selected preactivations move. Distance from a kink preserves the ReLU mask, not the old output; the movement must also cancel at every relevant old read.

### Contract for the first tests

- Freeze the host, its autonomous return map, the learner's lawful inputs, A/C evaluation sets, lender groups, and resource budgets before drawing blind jobs. Measure against the same-phase no-write orbit. A loan charges one declared lender's slack, not whichever group looks safest after the fact. An output loan can temporarily spend only the lender's surplus above the old floor; a hidden loan must consume a positive amount of certified sign headroom while leaving its gaps unchanged. All other old obligations stay protected. For mixed-layer changes, require a bound on the whole read, not a frozen-mask Jacobian treated as exact.
- **A** is ordinary old-task success, **C** is success on previously acquired jobs. Record both at every exposed phase, at repayment or conversion, and at returns 1, 8 and 64 against acquisition-anchored floors; also compare per-item signed gaps to matched no-write traces and match starting gaps between arms. For **zero-margin** conversion, every declared A/C true-vs-rival gap follows its no-write counterpart after conversion (exact in a finite fixture, within a preregistered numerical tolerance otherwise); matching only the winning label or mean gap does not count. Check held-out old items, including near-kink and near-decision-boundary cases, separately from any certificate set. Test for latent residue with common intervening updates, not just the first return.
- Confirm with two truthful examples from independently sampled contexts of the same blind job, with no supplied same-job bit or provenance oracle. After conversion retire both examples and measure useful service on held-out contexts. Run duplicate, true-plus-junk, and junk-pair controls at matched update norms, angles, timing and access costs; look for the cheapest pair that also matches the learner's actual observable evidence. Run late confirmations on both sides of repayment and compare an expired singleton followed by a new example with that new example alone. Identical lawful observation histories must get identical decisions: report collisions and abstentions rather than crediting a perfect latch. No pending IDs, timestamps, features, optimizer slots or cached certificates are free; report peak as well as amortized bytes.
- Stack phase-indexed GEM or certified hidden-cell protection with a tuned waiting buffer or fast trace and constrained permanent fit. Give the stack the same exposure permissions, lawful evidence, relievable state, compute, bytes and write menu, including a buffer that is allowed a useful provisional write. Also compare the parent's fading trace and staggered loans separately, SGD, momentum, OGD/GPM and an exact fixed-cell **output**-nullspace solver. Keep an exact joint solver with the same information and moves as a ceiling. Report mid-window and post-retirement service separately, matched for false confirmations, retention, latency and coverage; a gain in just one metric does not establish dominance. Reject threshold-built wins, static read pinning, and kink distance as a generic plasticity predictor (both warnings from the ledger).

### W9 — hidden slack pays for a shared write, but a solver can already find it

Take a single-layer, two-unit ReLU model with one fixed read `f(x) = [w1·x]+ + [w2·x]+` and a fixed zero rival. Let `w1 = (2,2,0)`, `w2 = (2,−1,0)`, A read `x = (1,0,0)`, C read `x = (1,0,1)`, and B read `x = (−1,1,0)`. The pending write adds `(−1,0,0)` to w1 and `(1,0,0)` to w2. For both A and C the preactivations move from `(2,2)` to `(1,3)` so their gaps stay 4; for B they move from `(0,−3)` to `(1,−4)` so its gap rises from 0 to 1. An exact protector of the old input span would reject the write (it moves both old activations); an exact output-nullspace solver accepts it. An alternative permanent write, adding only `(0,1,0)` to w1 with the loan removed, gives the same three gaps without using old headroom.

For a margin-matched negative, replace the initial vectors by `(1/2,1/2,0)` and `(7/2,1/2,0)`. The initial old and new gaps are unchanged, but that same loan sends the old preactivations to `(−1/2,9/2)` and the old gaps jump to `9/2`: crossing the kink breaks cancellation. This arithmetic checks the geometry and exposes the solver null, not a learning result. In particular, it supplies no autonomous return, no corroboration and no generalization evidence; the permanent alternative even exists from the start. A protocol that simply ships a hard-coded transition between these states has demonstrated neither seed.

## Idea cards

### 01. Confirm the write by using it — seed / primitive candidate
**Mechanism.** Admit one example through a lender's slack. Require the second example's ordinary update to depend on the first example's live shared-weight displacement. That joint update enters a persistent zero-margin orbit; without it the frozen cycle returns to the baseline. **Novelty / control.** The parent's card 10 and [synaptic tagging][stc] are the nearest ideas; the proposed object uses the same state to serve and to remember, not a tag beside a provisional write. Compare the full stack, with its provisional-write arm. **Cheapest first test.** Use a tiny recurrent ReLU regressor, draw two-view jobs after freezing it, and compare the complete state, the state with just the loan projected out, and the projected state with only the loan restored. **Old-task retention.** Check A/C for all three interventions and through good confirmation, timeout and false confirmation.

### 02. Borrow a cell, not a smaller positive gap — seed / primitive candidate
**Mechanism.** Charge distance to the lender's activation boundary; choose an update in the fixed-cell kernel of all its old gap reads, not the kernel of each old activation. Use the newly available direction to make a provisional B prediction. **Novelty / control.** The parent's card 19, [GPM][gpm], [OGD][ogd] and [CROWN][crown] cover the pieces; W9 says a joint cell-and-output solve already covers the static case. The candidate is a useful reversible route tied to the host's phase, not a better static repair. **Cheapest first test.** Repeat W9 across staggered, constant and coincident headroom traces; compare projected writes, the exact phase-indexed cell solver and output loans at matched B gain. **Old-task retention.** Check signed A/C gaps at every phase, including held-out old readers whose activations approach a kink at the peak loan.

### 03. Bind the loan with an update commutator — primitive candidate
**Mechanism.** In a fixed cycle, two different example updates perturb complementary directions so their order interaction leaves an old-silent residue; repetitions of the same vector field have no commutator. Demand that a normal stream, not an inserted inverse training example, supplies the return legs. **Novelty / control.** The parent's cancelling cycles use composition for return; this would use the noncommuting residue for consolidation. Compare gradient accumulation, momentum, and a buffered joint second-order update with access to the same examples. **Cheapest first test.** Enumerate two-step honest and matched-junk streams in a two-parameter nonlinear learner and a linear/additive null; sweep step size to see whether the useful residue is just a negligible second-order effect. **Old-task retention.** Read A/C during the individual update legs and after the first unpaired continuation.

### 04. Require a second view to change a live prediction — primitive candidate
**Mechanism.** The first view's loan changes how the learner predicts a second view without revealing its label. Consolidate only if the arriving label validates that new prediction and distinguishes it from the no-loan read; the second view cannot be chosen using the answer. **Novelty / control.** The parent's two-view latch and co-training already use complementary evidence; the claim is reuse of the live prediction as the confirmation signal without retaining an example or a second predictor. Compare fast weights plus co-training with an equally priced no-loan read. **Cheapest first test.** Use two contexts of a latent binary rule with nuisance correlations reversed at test time; give both arms an equally charged counterfactual read and include a junk match that preserves the provisional prediction. **Old-task retention.** A/C under both reads, and after a corroborator with an old-task-like context.

### 05. Commit the common part of two possible writes — primitive candidate
**Mechanism.** A first example steers the state onto a transient face of several useful continuations. A corroborating context retains only the direction common to both evidence sets, discarding the first view's unsupported degrees of freedom during repayment. **Novelty / control.** Set-membership estimation and buffered constrained fitting also intersect feasible sets; the proposed carrier is a live face of the return map rather than a stored feasible-set description. **Cheapest first test.** Enumerate tiny linear constraint menus with one-point, one-line and empty intersections; compare service on fresh inputs at equal bytes to a rank-matched sufficient statistic. **Old-task retention.** A/C on each unresolved branch and after an empty intersection forces full repayment.

### 06. Give repayment priority over confirmation — primitive candidate
**Mechanism.** Shape the first write so the same old-space component that funds it points back to the baseline on the cycle's next leg. Confirmation can redirect the orthogonal B component but cannot delay this return, even on the last admissible step. **Novelty / control.** Lookahead pulls back fast weights and safety filters can force a fallback; here the paired dynamics are meant to repay in either branch without consulting a saved state. Compare fixed timeout plus save/restore and the exact safety filter. **Cheapest first test.** Enumerate both orders of a second update and the return leg near expiry, with identical initial observations and a one-step-late negative. **Old-task retention.** A/C at the last live read and immediately after the boundary in either order.

### 07. Turn a pair into a different physical representation — primitive candidate
**Mechanism.** Use a first write in a plastic hidden direction for in-window service, but let corroboration transfer just the common behavior into a disjoint old-silent direction; retire or reuse the original carrier. **Novelty / control.** Fast/slow consolidation and [Net2Net][net] already transfer behavior; the narrower claim is a frozen, confirmation-conditioned handoff without teacher queries or a second fit. Compare fast weights plus matched-cost constrained distillation and a static output-nullspace write. **Cheapest first test.** At repayment fork a two-layer host, swap the candidate permanent directions between jobs, then reuse the transient direction for an unrelated loan; measure whether only the correctly bound job survives. **Old-task retention.** A/C after the handoff and after carrier reuse while the newly installed job joins C.

### 08. Route on slack that changes within one cycle — primitive candidate
**Mechanism.** Use a single signed shared-weight displacement whose feasible direction rotates with the lender's hidden activation pattern, but keep each exposed read in its own certified cell. Drive the rotation by the host state rather than a phase ID. **Novelty / control.** Switched control and the parent's staggered output loans already time-share; compare a phase-table cell solver and the best static intersection of phase kernels. The candidate reuses the same physical displacement without a stored timetable. **Cheapest first test.** On a four-phase toy, shift the initial phase without telling the learner; include equal headroom with no kernel rotation and rotation without headroom. **Old-task retention.** A/C at the rotating path's least-safe phase and at a certifiably safe return from each start.

### 09. Repay across a kink without a discontinuous gap — primitive candidate
**Mechanism.** Connect two old-output-flat segments at a ReLU face where gains and losses cancel continuously. Require an explicit certificate for both sides and for the face; do not call the crossing sign-stable. **Novelty / control.** Piecewise-linear verification already checks such paths. The candidate is a reusable, corroboration-enabled exit from a reversible loan that admits a persistent route no single-cell solver can reach. **Cheapest first test.** Enumerate a two-unit path graph whose end gap is reachable through paired crossings, then stagger the crossings so an intermediate old error appears; compare exact multi-cell search. **Old-task retention.** Evaluate A/C at the face and between any staggered crossings, not just at endpoints.

### 10. Cancel in function space, not just at the paired units — improvement
**Mechanism.** Choose an update by intersecting the exact gap kernels of all downstream readers, then test whether the hidden sign slack admitted useful cancellation at the same B gain. **Novelty / control.** Jacobian-matching distillation is already the surviving control for killed read pinning (ledger P19); compare it with an exact all-reader solver, not an activation-pinning strawman. **Cheapest first test.** Add a second readout to W9 that sees the units with unequal weights; include both an extra null direction and a full-rank case that must refuse. **Old-task retention.** Score A and the worst individual C reader while the shared units move.

### 11. Borrow from units that are off for the lender — primitive candidate
**Mechanism.** Move units strictly below the kink on lender inputs but active on some B contexts; condition conversion on fresh B contexts that actually use those units. Require the shared units to have genuine readers elsewhere, rather than dedicating a spare block to B. **Novelty / control.** Masking and fixed feature-subspace protection already exploit inactivity; the candidate is reversible reuse of a feature that will turn back on for somebody else. Compare a static mask, a detector with a waiting buffer and a fully paid extra unit. **Cheapest first test.** Use an old C input that turns the unit back on before return and vary its arrival time; count refused writes as well as successes. **Old-task retention.** A/C at C's earliest activation, including rare inputs on the lender's inactive side.

### 12. Make the confirmable direction invariant to unit rescaling — improvement
**Mechanism.** Certify each hidden displacement relative to its actual preactivation headroom and use downstream weights to evaluate cancellation. Use a normalized perturbation metric so rescaling a unit cannot create extra borrowing capacity. **Novelty / control.** ReLU rescaling and [Net2Net][net] already preserve functions; the test looks for a loan law that does not mistake a larger coordinate for a safer update. **Cheapest first test.** Rescale W9's hidden units with inverse readout scales and transform the same function-space moves; compare raw kink distance and normalized certificates. **Old-task retention.** The rescaled and original arms must have the same A/C gaps, including where each reaches its first kink.

### 13. Hand the pending state to another lender without fetching the first example — primitive candidate
**Mechanism.** After the first lender is repaid, a phase's ordinary map transports the still-unconfirmed displacement to a second lender only if the two representations have overlapping old-safe reads. At most one lender is in debt at each exposed state; no transfer can extend the predeclared outer expiry. **Novelty / control.** The parent's scheduling and loan ledgers already route slack; the candidate moves the evidence itself, not a buffer entry or deadline. Compare a rotating escrow buffer and a fixed single-lender trace. **Cheapest first test.** Enumerate two lender orders, block the overlap, then transplant just the proposed transported displacement; test early, in-transfer and late second examples. **Old-task retention.** Both lender groups plus C at the handoff and during each repayment, with no aggregate hiding a brief double spend.

### 14. Spend no label to ask which corroboration matters — primitive candidate
**Mechanism.** Before a second label arrives, use the live provisional state to select one lawful input from a fixed unlabeled pool whose possible answers best distinguish a useful commit from a false one. Debit each request against a fixed query budget. **Novelty / control.** Active learning already selects informative inputs; the proposed reuse is a transient write replacing the separately stored hypothesis state. Compare a buffered query-by-disagreement arm with identical query access and delayed answers. **Cheapest first test.** Enumerate a four-query pool with one uninformative high-disagreement input and one actionable query, plus delayed and refused labels. **Old-task retention.** A/C while waiting for the label and under both replies, including the abort.

### 15. Refuse a second example whose evidence is only a new amplitude — improvement
**Mechanism.** Audit whether the second update adds a distinguishable feature direction after projecting out the first loan's nuisance span. Treat collinear lawful observations as repeats regardless of norm unless some additional lawful view separates them. **Novelty / control.** Orthogonalization and rank tests already find new directions; this is a falsifier for W8-like counters, not proof of evidence independence. **Cheapest first test.** Enumerate scaled or augmented duplicates, genuinely new but collinear views, and cheap noncollinear junk. Compare precision/coverage to a buffered verifier and two-view replay. **Old-task retention.** A/C after the worst accepted synthetic collision and after rejected truthful pairs that must repay.

### 16. Ask what survives two different repayments — primitive candidate
**Mechanism.** Run two possible autonomous suffixes from clones after corroboration and retain a component only if the same B behavior persists after both loan returns. Use the test offline to shape a single frozen map, not to select the easier branch online. **Novelty / control.** Robust control and constrained distillation already optimize over suffixes; the candidate is a commit defined by invariance to which return occurs, not by endpoint agreement at one phase. **Cheapest first test.** Train nothing initially: enumerate a tiny library of return maps and distinguish a true persistent displacement from one that survives only the nominal suffix; compare to joint robust projection. **Old-task retention.** A/C under every suffix, including one whose optimizer state exposes a previously hidden reader.

### 17. Let a failed second view accelerate repayment without writing a negative memory — improvement
**Mechanism.** If the second lawful update is incompatible with the provisional feature, let that update contract the loan toward baseline but refuse a persistent negative write. **Novelty / control.** The parent's contradiction cancellation and buffered invalidation already cover the decision; only a cheaper contraction is in scope. **Cheapest first test.** Compare truthful–contradiction–fresh and truthful–junk–fresh streams with matched norms against waiting-buffer deletion and plain timeout; test a disturbance with opposite sign but the same evidence. **Old-task retention.** A/C during accelerated repayment, after overshoot candidates, and after the fresh loan.

### 18. Treat surviving optimizer state as an unpaid loan — improvement
**Mechanism.** Define repayment against both live gaps and the continuation on a declared menu of ordinary updates. Certify a contraction or a null read of slots, and charge any persistent slot that can restore the first example's effect. **Novelty / control.** Full-state rollback and the parent's momentum audit already flag this; the test asks whether the frozen cycle can repay at comparable cost without reset. **Cheapest first test.** Give expired weights two distinct momentum histories, then take the same legal update; compare weight-only return, full restore and the proposed slot-aware return. **Old-task retention.** A/C after that update and under a late second example that should now act as a singleton.

### 19. Commit only what can survive unrelated confirmations — primitive candidate
**Mechanism.** Put one corroborated change into a behavior class preserved by subsequent lawful repayments and commits, so two jobs may share the same lending directions without sharing an address or erasing one another. **Novelty / control.** OGD and replay already protect installed jobs; distinguish a zero-margin **composition rule** from repeatedly solving a static protection problem. Compare joint nullspace plus a waiting buffer and a cached adapter per job. **Cheapest first test.** Enumerate two genuinely interfering B jobs in both commit orders and a third unconfirmed job; test a pair for which no protected composition is possible. **Old-task retention.** Treat the first confirmed B as C immediately and test it at the second loan's maximum exposure.

### 20. Price collision by the cheapest lawful imitation — improvement
**Mechanism.** Search the permitted example menu for the lowest-cost wrong-rule pair whose live trajectory matches a truthful pair at all read points available to the latch. If such a collision exists, set a refusal region rather than using unverifiable provenance. **Novelty / control.** Indistinguishability and sequential tests already give the lower bound; the improvement is a concrete control for the claimed in-weight carrier. **Cheapest first test.** For a discrete two-view menu, enumerate trace twins with identical or near-identical observations; compare cost to fool buffered, fast-trace and loan arms at matched genuine acceptance. **Old-task retention.** A/C at false-latch peaks and across the refusal path; count lost new-job coverage separately.

### 21. Identify when the smooth null explains the gain — improvement
**Mechanism.** Replace ReLU with softplus and bound the second-order old-gap residual after canceling the first-order term. Vary smoothness and compare against a smooth path that is exactly output-silent by symmetry. **Novelty / control.** Verification bounds and nullspace projection already handle local cancellation; an equal smooth gain would narrow the claim to nonlinear shared-weight routing, not kink slack. **Cheapest first test.** Match W9's starting gaps and B gain in ReLU and softplus arms; measure worst gap residual versus the perturbation bound and the symmetry control. **Old-task retention.** Check A/C on nearly linear old readers and old readers with large curvature; report strict zero-gap failures even if accuracy stays flat.

### 22. Make capacity fail before hidden slack silently vanishes — primitive candidate
**Mechanism.** Define a finite admission bound from the signed path headroom left after earlier commits. Reject an otherwise corroborated write if the converted orbit would remove all known lawful exit routes for a remaining old obligation. **Novelty / control.** Robust viability and the parent's pending-write bounds already cover admission; the proposed invariant couples permanent commits to the supply of future reversible routes rather than to the number of open traces. Compare exact lookahead, fixed quotas and recomputed output-nullspace capacity. **Cheapest first test.** Enumerate three unseen-job arrivals on two equal-width hosts with the same counts of inactive units but different certified exit paths. Include a stream where a quota ties the viability rule. **Old-task retention.** A/C after each commit and throughout the last admissible loan; certify that refusal leaves both suites unchanged.

## Ranked deeper questions

1. **Is the loan itself necessary and sufficient for pending evidence?** Start with 01, 04, 15 and 20. Demand causal removal/restoration, cheap matched imitations, no useful singleton after expiry, and useful blind B after retirement. If provisional write + waiting buffer ties at equal budgets with the same evidence and exposure, do not call the loan a new operation.
2. **Does hidden slack buy a new route or just expose an existing kernel?** Start with W9 and 02, 09, 10, 12 and 21. Match old output gaps and new utility; compare the best exact cell/output solve and smooth hosts. If only GPM loses, report a looser constraint, not evidence for a distinct mechanism.
3. **Can one frozen return map pay for both branches at the boundary?** Start with 06, 07, 16 and 18. Require live A/C safety, exact clearance of exploitable singleton residue, and confirmed B after unrelated lawful updates without a restore, clock or optimizer reset. Separate return failure, false corroboration and failure of the committed representation.
4. **Can a committed job become a protected reader before the next loan?** Start with 13, 19 and 22. Test orders, peak live state and cases with genuine exit scarcity. If recursive service requires paid per-job storage or turns off an old reader, keep the result single-write.

These are nearest comparisons from the ledger, the parent and a targeted literature check, not exhaustive novelty claims. The first gate is an exact finite CPU test of a learned or otherwise non-oracular carrier with held-out B utility and ordinary A/C retention; W9 alone does not pass it.
