# Two-address teaching cycles

**Status:** Ideas only; no experiments, code, or GPU work. **Parent:** [Self-seeding repairs](self-seeding-repairs.md) ([PR #184](https://github.com/manojbajaj95/cl/pull/184)), cards 11 and 06. **Review seed:** [Flood triage, row 291](https://github.com/manojbajaj95/cl/blob/bc3eec66d70728cb7f696673b6498874cb1b3421/reviews/flood-triage.md#L291) scored two ideas 3: “close a period-two teaching orbit” (a frozen witness alternates between two predeclared compatible addresses, and running it at each address writes the feature the other needs, so no new batch enters at the switch) and “an invariant read through complementary overwrites” (either admissible repair may overwrite a different part of the seed, but the ordinary repair batch is chosen so both successors show the same relational contrast to one fixed small probe). **Read first:** [Idea ledger](https://github.com/manojbajaj95/cl/blob/bc3eec66d70728cb7f696673b6498874cb1b3421/reviews/idea-ledger.md): beat stacked controls, rule out wins by construction, match margins, and check ordinary old tasks in every first test.

## Are a self-renewing two-address cycle and an overwrite-invariant contrast new continual-learning objects?

**Verdict: neither is new as a mathematical object; both are worth testing only as learned, checkable contracts that save work on unseen jobs.** A periodic orbit of a training map is ordinary dynamics: gradient descent at the [edge of stability][eos] already oscillates with period two along the top curvature direction, [game dynamics][cycles] have limit cycles, and [reachability][hj] finds controlled cycles. Two models or modules that alternately teach each other are [deep mutual learning][dml], [co-distillation between peers][tutor] and co-training. A probe that reads the same thing after an update is [backward-compatible training][bct], [stationary representations][stationary], [relative representations][relrep], and the [activation-monitor staleness][staleness] problem; protecting a read through updates is [OGD][ogd]/[GPM][gpm]. Choosing data for the update it induces is [iterative machine teaching][teaching] and [trajectory matching][mtt].

The candidate for seed A is a **frozen batch plus two addresses whose ordinary execution is a closed, attracting cycle that serves a job each half-period**: the cycle renews its own carrier with no batch, teacher, or scheduler entering at the switch, and the cycle's return map is a certificate a new editor can check. The candidate for seed B is a **repair batch chosen against a known menu of admissible overwrites so that one fixed probe reads the same contrast after any of them**, where the overwrites are allowed to depend on the seed. The two exact witnesses below show the vacuous forms each seed collapses to; every card must beat those, plus the stacked parent controls, at matched utility, margins and A/C retention.

[Self-seeding repairs (PR #184)](https://github.com/manojbajaj95/cl/pull/184) asks whether one spend seeds the next carrier. Here the claim is periodic: the seed must come back in finite time without outside work, and its phase must be legible. [Return corridors (PR #168)](https://github.com/manojbajaj95/cl/pull/168) proves entry into a region once; a cycle has to prove re-entry forever. [Teaching bundles (PR #186)](https://github.com/manojbajaj95/cl/pull/186) and [examples versus probes (PR #179)](https://github.com/manojbajaj95/cl/pull/179) shape a reply so a fixed probe separates hidden editors; seed B asks for the same read under a *set* of successor overwrites we do not pick. These distinctions are not evidence of gains.

## Two exact witnesses (rational, by hand)

**W1: an edge-of-stability reflection is a free period-two orbit.** Host `f(x) = w·x`, `w = (w_u, w_v)`, with addresses `u` and `v`. Frozen batch: one example `x = (1, −1)`, label `y = 0`, squared loss, plain GD with `η = 1`. The update is `w ← w − η (x·w) x = P w` with `P = I − x xᵀ = [[0, 1], [1, 0]]`, the swap. So `(1, 0) → (0, 1) → (1, 0)`: running the batch at address `u` writes the feature to `v` and back, exactly, with no new data. The curvature is `|x|² = 2`, so `ηλ = 2`: this is the stability boundary, and the witness loss stays at 1/2 forever. The label is truthful only if the target has `w*_u = w*_v`. **Lessons.** (i) A period-two orbit from an ordinary truthful step exists for free and learns nothing: `P` is an isometry, so renewal is guaranteed by construction. (ii) Every old reader `q` with `q_u ≠ q_v` flips between `q_u` and `q_v` each half-cycle, so only readers in the invariant direction `(1, 1)` keep their output; alternating forgetting is exact and total off that subspace. (iii) The orbit is neutrally stable (eigenvalues ±1): any foreign write in `(1, −1)` persists forever, and nothing pulls the cycle back. Every seed-A card must show a cycle that does useful work per half, is attracting, and keeps non-invariant old readers, which W1 fails.

**W2: an invariant contrast through either of two overwrites.** Host features `h = (h₁, h₂, h₃)`, hidden continuation `c ∈ {+1, −1}`. The ordinary repair batch writes a seed `h = (a c, b c, 0)`; the batch choice sets `(a, b)`. Two admissible overwrites: `R₁` sets `h₁ ← r₁ + α₁ c`, `R₂` sets `h₂ ← r₂ + α₂ c`, where `α_i` measures how much the overwriting repair's own write depends on the seed it reads. Fixed probe `p = (½, ½, 0)`. The contrast `Δ = p·h(+1) − p·h(−1)` is `a + b` before, `α₁ + b` after `R₁`, and `a + α₂` after `R₂`. **Same contrast after either overwrite iff `a − b = α₁ − α₂`.** If the overwrites ignore the seed (`α₁ = α₂ = 0`), the only solution is the balanced copy `a = b`, i.e., two copies read by an averaging probe at half gain: the redundancy null. If `α₁ ≠ α₂`, a deliberately unbalanced seed compensates and keeps `Δ = α₁ + b` on both branches; this is the only regime where seed B is more than redundancy. `Δ = 0` on both branches if `b = −α₁`: an erasing pair exists for some batch, and the batch search must avoid it. **Lessons.** (i) Seed B is the redundancy null unless the admissible overwrites read the seed. (ii) The condition is linear in the batch-controlled `(a, b)` given the menu's `(α₁, α₂)`, so in linear hosts it is exact invariant enforcement, not a learning claim. (iii) Old readers of `h₁` alone or `h₂` alone lose their value on one branch; checking only the probe hides that.

## What must survive

- **Fix the operation before the stream.** Freeze the batch, loss, optimizer, step size, both addresses and the admissible-overwrite menu before deployment. No scheduler, phase target, invariance loss or hidden teacher at run time. An explicit swap move, an auxiliary cycle loss or a stored copy is a control, not the strong mechanism.
- **Work per half-period.** A cycle counts only if each half serves a held-out job that a single-address refill at the same budget cannot, and only if it is attracting (return-map Jacobian with spectral radius `< 1` on the declared domain) so blind foreign writes decay. W1 is the null for both conditions.
- **Phase is a cost.** Whoever reads the cycle must know which address is live. Either the phase is lawfully observable from the host at charged cost, or the probe must read a phase-invariant quantity. A free phase bit is a hidden scheduler.
- **Contrast is a decision, not a number.** For seed B, a preserved `Δ` counts only if, on **each** overwrite branch, the fixed probe selects a different verified affordable reply for the hidden continuations than the best no-probe reply or abstention. Include a common-safe-reply null where the probe is redundant, and the erasing pair of W2.

### Shared contract for the CPU first tests

Start with exact enumeration in tiny linear and piecewise-linear hosts (W1/W2 sizes) to check the protocol, then a trained small ReLU host. Freeze blind editors, held-out jobs and held-out old inputs before choosing batches. Compare (i) per-job repair, (ii) the stacked parent control: external scheduler + ReDo/continual-backprop resupply + Net2Net binding + exact cost-sensitive diagnosis, (iii) [MTT][mtt] targeting the same finite sequence, (iv) for seed B, two stored copies with an averaging probe, a per-branch recalibrated probe, and OGD/GPM protection of the seed. Cross real versus sham cycles and correct versus permuted addresses. Score useful blind admissions per unit of work over many cycles after source retirement, with unknowns and refusals reported separately. **Retention notation:** `A` is the unchanged old-task suite with held-out rare cases, read at **both phases** of every cycle and on **both** overwrite branches; `C` is all prior edits not explicitly superseded. Old readers must include ones aligned with each address alone (W1's `q_u ≠ q_v`, W2's single-coordinate readers).

## Idea cards

### 01. An attracting period-two teaching cycle — primitive candidate
**Mechanism.** Choose a frozen truthful batch and two addresses so that the gradient map `T` at the live address writes the feature the other address needs and also reduces a job loss, and `T∘T` has a fixed point with spectral radius below 1. Each half serves one recurring job type; the cycle renews itself without any input at the switch. **Novelty / control.** Restates row 291 #11. [Edge-of-stability][eos] oscillation and [game limit cycles][cycles] are known dynamics; [HJ reachability][hj] finds controlled cycles. The candidate is a *learned* cycle chosen by batch search that keeps serving held-out jobs. **Cheapest first test.** Enumerate batches of up to three examples over a 2-address linear host plus one shared trunk weight; keep those with an attracting 2-cycle and nonzero per-half job gain. Compare against W1 (isometric swap), an external scheduler with refill and MTT on the same sequence over 50 cycles. **Old-task retention.** Read A at both phases; include readers of each address alone and of the trunk.

### 02. Use W1 as the mandatory vacuity control — improvement (audit)
**Mechanism.** For every proposed cycle, compute the closest isometric cycle (the reflection at `ηλ = 2` along the same direction) and report the cycle's gain over it in job service, contraction rate and A retention. **Novelty / control.** Edge-of-stability period doubling ([2103.00065][eos]) already explains period two from one direction; the audit separates teaching from oscillation. **Cheapest first test.** On every enumerated cycle from card 01, project out the isometric component and re-run; a cycle whose service survives only in the isometric part is reported vacuous. **Old-task retention.** Compare W1's exact flip of `q_u ≠ q_v` readers to the candidate's; a candidate that flips the same readers has not earned a retention claim.

### 03. Certify the cycle by its return map, not by its trajectory — primitive candidate
**Mechanism.** Publish only the two-step return map's fixed point and a contraction bound `ρ < 1` over a declared ball. A new editor checks that its write lands inside the ball and then trusts the cycle to absorb it, without replaying the trajectory. **Novelty / control.** Floquet multipliers and Lyapunov certificates are textbook; [certificate entry ports (PR #171)](https://github.com/manojbajaj95/cl/pull/171) inherit proofs by entry. The candidate is a cycle-specific entry proof whose ball is earned by the batch. **Cheapest first test.** For card 01's survivors, compute `ρ` and the ball exactly; plant foreign writes inside, on and just outside the ball; compare against re-verifying the full cycle per write. **Old-task retention.** Check A after the cycle re-absorbs each write, including writes that decay in the cycle but transiently cross an old reader's margin.

### 04. A cycle that absorbs a blind job and returns — primitive candidate
**Mechanism.** A held-out job is served by leaving the cycle for one off-phase step and the attraction returns the host to the orbit with the job's effect stored in the contracting directions' fixed offset. **Novelty / control.** [Return corridors (PR #168)](https://github.com/manojbajaj95/cl/pull/168) proves one re-entry; [GRACE][grace] caches repairs. The gain must be that the cycle carries new commitments without a growing cache. **Cheapest first test.** Three-address linear host; serve five blind jobs in sequence; compare cycle offsets against a growing GRACE cache and per-job repair at equal state bytes. **Old-task retention.** C: re-run each earlier blind job after every later one; A at both phases.

### 05. Phase must be read lawfully or made irrelevant — improvement (audit)
**Mechanism.** Charge every reader for learning which address is live: either a lawful activation test or a phase-invariant probe (card 22). Report the cost and failure rate of each. **Novelty / control.** A phase log is a one-bit memory; [partial-information games][games] already price such bits. The audit stops a free phase bit from acting as a hidden scheduler. **Cheapest first test.** In W1 and card 01's cycles, compare an oracle phase bit, a charged activation test and the invariant probe on blind service. **Old-task retention.** Score A with the phase read wrong once per cycle; a design whose old tasks fail on one wrong phase is fragile.

### 06. Period-k cycles and the minimal period — improvement
**Mechanism.** Generalize to `k` addresses whose frozen batch induces a permutation-like attracting `k`-cycle; ask whether the minimal period that serves `m` recurring job types is `m` or can be shorter by sharing addresses. **Novelty / control.** Cyclic task orders and recurring-task CL ([class-incremental learning with repetition][repeat]) study repeated streams; minimal period is a scheduling question. **Cheapest first test.** Enumerate `k ∈ {2,3,4}` with `m = 3` job types in a linear host; compare minimal cycles with a round-robin external scheduler. **Old-task retention.** Read A at each of the `k` phases.

### 07. Two learners as the two addresses — primitive candidate (conditional)
**Mechanism.** Each address is a separate small learner; running the frozen batch on learner U produces outputs that are the targets learner V needs next, and vice versa, so the pair cycles without a teacher. **Novelty / control.** [Deep mutual learning][dml], [peer co-distillation][tutor] and co-training already exchange targets. The candidate is a frozen exchange that is attracting and serves held-out jobs, not mutual improvement on a fixed task. **Cheapest first test.** Two linear learners, frozen batch, alternate distillation steps; enumerate batches for an attracting 2-cycle; compare against continued mutual learning and a fixed external teacher at equal calls. **Old-task retention.** A for each learner at every phase; detect collusive drift where both agree but lose old truth (cf. [co-cheating][cocheat]).

### 08. Source retirement test for cycles — improvement (audit)
**Mechanism.** After the cycle is chosen, delete the source data and any teacher; run 100 cycles and blind jobs with only the frozen batch. **Novelty / control.** Parent card 09's intervened clone. The audit separates self-renewal from slow decay that a long horizon hides. **Cheapest first test.** Track per-cycle job service and feature norm; ablate the seed at one phase and check whether the cycle restores it (necessity) and whether seed-only restoration resumes service (sufficiency). **Old-task retention.** A at both phases at cycle 1, 10 and 100.

### 09. Phase-locked old tasks: keep old readers on the cycle-invariant subspace — improvement
**Mechanism.** Constrain the cycle so its non-trivial action lies only in directions no old reader uses; old readers live on the fixed subspace (W1's `(1, 1)`). **Novelty / control.** This is [OGD][ogd]/[GPM][gpm] null-space protection applied to the cycle; improvement unless it admits more useful jobs. **Cheapest first test.** In card 01's host, project the cycle off the old readers' span; compare service lost against unprojected cycles and GPM training. **Old-task retention.** Include old readers that span the cycle's moving direction; they define the price.

### 10. A broken cycle is an alarm — improvement
**Mechanism.** Monitor the return error `|T∘T(w) − w|`; a foreign write that pushes the host outside the attraction ball shows up as a non-returning cycle before any old task is queried. **Novelty / control.** Drift detectors and [counterexample-guided repair][cegis] already flag failures. Improvement only if return error detects old-task damage earlier or cheaper than probing A directly. **Cheapest first test.** Plant writes of graded size; compare alarm latency and false alarms against a fixed A-probe at equal compute. **Old-task retention.** Report A damage at alarm time and after repair.

### 11. Optimizer slots as the two addresses — improvement
**Mechanism.** The two addresses are a weight and its momentum slot; the frozen batch cycles the feature between them. **Novelty / control.** Inherits [optimizer-slot splits (PR #178)](https://github.com/manojbajaj95/cl/pull/178), [slot splices (PR #185)](https://github.com/manojbajaj95/cl/pull/185) and parent card 10. **Cheapest first test.** Heavy-ball on two coordinates; enumerate momentum and step for an attracting 2-cycle with a job served at the weight phase; compare momentum reset and paid state copy. **Old-task retention.** Test A after the first update from the cycle, when output-equivalent weight copies diverge.

### 12. Lift the cycle into a nonlinear host where gates switch per phase — primitive candidate
**Mechanism.** In a ReLU host, the live address sits in a different activation region at each phase, so the two halves are different linear maps; the batch is chosen so the composed map is attracting even though neither half is. **Novelty / control.** Switched-system stability is known; the candidate is a batch that exploits region switching to renew a carrier a linear host cannot. **Cheapest first test.** Two-unit ReLU host; enumerate small batches; find cycles whose halves are individually expanding but whose composition contracts; compare to the best linear cycle. **Old-task retention.** Sweep old inputs near both region boundaries.

### 13. Choose the seed against a known overwrite menu (W2's compensation) — primitive candidate
**Mechanism.** Given the admissible overwrites' seed dependence `(α₁, α₂)`, pick the repair batch whose seed layout satisfies `a − b = α₁ − α₂`, so one fixed probe reads the same contrast on either branch with `α₁ ≠ α₂`. Restates row 291 #06. **Novelty / control.** [Backward-compatible training][bct] makes new features usable by an old probe for one update; here the batch is chosen before a menu of successors. W2's balanced copy is the null. **Cheapest first test.** Three-feature linear host with menus of two and three seed-dependent overwrites; enumerate batches; compare exact compensation against two copies, OGD protection and per-branch probe recalibration at equal state. **Old-task retention.** Keep old readers of each single coordinate; report which branch each loses.

### 14. Redundancy null and its price — improvement (audit)
**Mechanism.** For every seed-B candidate, report the gain over two stored copies read by an averaging probe (W2 with `α = 0`), including the copy's halved contrast and doubled slot use. **Novelty / control.** Redundancy and repetition codes are the obvious baseline. **Cheapest first test.** Same hosts as card 13; equal slots; score decision quality on both branches. **Old-task retention.** Copies occupy slots old tasks could use; charge the displacement.

### 15. Read a ratio, not a difference — improvement
**Mechanism.** Make the probe read the contrast relative to a co-written reference, so overwrites that rescale the seed leave the decoded distinction unchanged. **Novelty / control.** [Relative representations][relrep] read similarities to anchors and are invariant to isometries and scaling. Improvement only if a learned reference survives overwrites that anchor methods do not. **Cheapest first test.** Add a scale overwrite to W2's menu; compare difference and ratio probes and anchor-based relative reads. **Old-task retention.** Hold out old near-zero reference cases.

### 16. Certify contrast over a convex set of overwrites — primitive candidate
**Mechanism.** Another editor picks the overwrite from a declared convex set of seed dependences; the batch is chosen so the probe's decision is the same over the whole set, not just at two points. In W2 that is a region of `(α₁, α₂)` for which the sign and threshold of `Δ` hold. **Novelty / control.** Robust optimization and [Pacti][pacti] contract alternatives; [stopping proofs (PR #182)](https://github.com/manojbajaj95/cl/pull/182) certify a price region. **Cheapest first test.** Linear host; compute the exact certified region per batch; test overwrites inside, on the boundary and outside. **Old-task retention.** A on overwrites at the region's corners.

### 17. Let the overwrite carry the contrast — primitive candidate
**Mechanism.** Choose the seed so that any admissible repair, by reading it, writes the contrast into its own overwrite (`α_i ≈ 1`); the seed's information survives in the successor's new state rather than in a protected slot. **Novelty / control.** [Self-seeding repairs (PR #184)](https://github.com/manojbajaj95/cl/pull/184) card 01 uses repair to seed a carrier; here repair preserves a diagnostic. Distinct only if this beats OGD protection at matched retention. **Cheapest first test.** Small ReLU host where overwrites are real gradient repairs on blind jobs; measure `α_i` per repair and the probe's decision on both branches. **Old-task retention.** C on the blind repairs' own jobs; the contrast must not degrade them.

### 18. Compare against compatibility and monitor-staleness methods — improvement (audit)
**Mechanism.** Run seed B against [BCT][bct], [stationary representations][stationary] and monitor repair from [activation-monitor staleness][staleness] on the same overwrite menu. **Novelty / control.** These are the nearest prior art for "a fixed probe survives updates". **Cheapest first test.** Same tiny hosts; equal probe size; score decisions on both branches. **Old-task retention.** All arms at matched A.

### 19. Seed B in a ReLU host: contrast per activation region — primitive candidate
**Mechanism.** Seed dependence `α_i` varies by activation region; certify the compensation on a finite set of regions reachable under each overwrite. **Novelty / control.** Region-wise certification is [APRNN][aprnn]-style; candidate is batch selection against an overwrite menu. **Cheapest first test.** Two-layer ReLU host, two overwrites, enumerate regions; report where compensation holds or fails. **Old-task retention.** Old inputs in each region, especially boundary cases.

### 20. Price the fixed probe against recalibration — improvement (audit)
**Mechanism.** Compare one fixed probe with per-branch recalibration that needs labelled examples after the overwrite; report the break-even number of labels. **Novelty / control.** Activation-monitor repair recalibrates; [decision-relevant queries (PR #174)](https://github.com/manojbajaj95/cl/pull/174) prices information. **Cheapest first test.** Vary labels 0–8 per branch; find where recalibration ties the fixed probe. **Old-task retention.** Recalibration data must not be drawn from A.

### 21. A cycle whose two halves are the two overwrites — primitive candidate (merge)
**Mechanism.** Join the seeds: the attracting 2-cycle's halves are the two admissible overwrites, and the batch is chosen so one fixed probe reads the same contrast at both phases. The probe needs no phase bit, and the cycle renews the contrast. **Novelty / control.** Must beat the stacked parts: card 01's best cycle plus card 13's best compensation plus a phase bit, at equal state and compute (ledger merge rule). **Cheapest first test.** W1 host extended with a third coordinate; enumerate batches where `T` alternates `R₁`/`R₂` and `Δ` is phase-invariant; compare with the stack. **Old-task retention.** A and C at both phases.

### 22. A phase-invariant probe for any cycle — improvement
**Mechanism.** Read only the cycle's fixed subspace (W1's `(1, 1)`), which is the same at both phases, so no phase is needed. **Novelty / control.** Invariant readout is [IRM][irm]-style and the relative-read idea; improvement unless the fixed subspace carries decision-relevant information. **Cheapest first test.** In card 01 cycles, measure how much decision quality the invariant read keeps against an oracle-phase read. **Old-task retention.** Readers on the moving subspace are where A is lost.

### 23. Hand the cycle and its probe to an independent editor — primitive candidate
**Mechanism.** Publish the frozen batch, addresses, return-map ball (card 03) and probe contract; a separate editor proposes unseen jobs and overwrites using only this contract. **Novelty / control.** Inherits parent card 22 and [nonparametric teaching for multiple learners][multiteach]. **Cheapest first test.** Choose the cycle with one family of linear editors; test with a held-out family; compare data-matched teaching and a planner given the same information. **Old-task retention.** Old tasks from both editor families.

### 24. Certify when no cycle or no compensation exists — improvement (audit)
**Mechanism.** Return an impossibility witness: for seed A, no batch in the menu gives an attracting cycle with positive service (finite exhaustion); for seed B, `a − b = α₁ − α₂` is infeasible under the batch's reachable layouts, or every solution has `Δ = 0`. **Novelty / control.** Finite exhaustion and linear infeasibility are not new; the audit stops the search from reporting a near miss as a win. **Cheapest first test.** Shrink the batch menu until the W1/W2 conditions fail; check the certificate is exact. **Old-task retention.** On infeasible menus, compare no-write retention against forcing the best near miss.

## Ranked deeper questions

1. **Can a learned batch give an attracting two-address cycle that does useful work each half, beyond the edge-of-stability reflection?** Start with 01, 02, 03 and 08. W1 shows that a period-two orbit is free and empty. The first real result is a cycle with `ρ < 1`, positive held-out service per half after source retirement, and A retention for readers off the invariant subspace, beating external scheduling + refill and MTT at equal cost. If no such cycle exists in small ReLU hosts (card 12), drop seed A.
2. **Do admissible overwrites read the seed enough for compensation to beat redundancy?** Start with 13, 14, 17 and 19. W2 shows seed B is two copies unless overwrites have unequal seed dependence. Measure `α_i` for real gradient repairs on blind jobs; if they are near 0, seed B collapses to redundancy and should stop.
3. **Does the probe's decision survive a region of overwrites chosen by another editor?** Start with 16, 18 and 20. Compare against BCT, stationary representations and per-branch recalibration at matched labels. A certified region that a blind editor stays inside is the reusable object; a point solution is not.
4. **Does joining the seeds (card 21) give something neither does alone?** Only after questions 1 and 2 pass. The merge must beat the stacked best cycle, best compensation and a phase bit; otherwise report the parts.

These are nearest comparisons, not an exhaustive novelty clearance. The first two questions must show useful service or lower decision cost at matched A/C retention before either object claim is worth pursuing.
