# Test-time continual learners (depth 2): Per-query measured-absorption handoff & verbalizable-vs-residual weight decompilation

Depth 2 child of [PR #374](https://github.com/manojbajaj95/cl/pull/374) (`tree/test-time-learners-2.md`, deepening `T2-02` and `T2-10`, and folding in cross-pool round 107 `HEX4` and `HEX5`, stacked on [PR #373](https://github.com/manojbajaj95/cl/pull/373)) · 30 candidate primitives (`T3-01`–`T3-30`) · All tagged **Ambitious but doable (P)** · Ideas only; no experiments run

**Thesis.** PR #374 narrowed inference-time KV↔weight transport to two tier-3 survivors: **(a) per-query handoff scaled by measured absorption (`T2-02`)**, recognizing that weights absorb canonical prompts far faster than paraphrases or compositions so a single global handoff factor $\alpha$ simultaneously double-fires canonical queries and under-fires paraphrases; and **(b) verbalizable-vs-residual decompilation (`T2-10`)**, recognizing that natural-language decompilation is inevitably lossy, so only the verbalizable component $\Delta W_{\text{verb}}(s)$ should be lifted to text for editing while the unverbalizable residual $\Delta W_{\text{resid}}$ (implicit calibration, output formatting, unstated sub-cases) stays in weights.

Both hit sharp second-order failure modes when pushed to real mechanisms:
1. **Why naive per-query $\alpha(x)$ fails:** Measuring true per-query absorption by running both with-KV and without-KV forward passes doubles inference compute, defeating the point of handoff; over-estimating $\hat{\alpha}(x)$ on a paraphrase silently drops the rule (asymmetric error cost vs. bounded double-firing); surface-key matching lets $\hat{\alpha}(x)$ saturate on canonical wording while paraphrases and multi-rule compositions lag indefinitely; and raw logit-shift meters conflate semantic rule absorption with length/entropy shifts (PR #29/#31 confounds).
2. **Why naive $\Delta W = \Delta W_{\text{verb}}(s) + \Delta W_{\text{resid}}$ fails:** Parameter-space orthogonality does *not* guarantee functional orthogonality in bilinear LoRA/MLP updates ([Bilinear Optimization Divergence](https://arxiv.org/abs/2609.23594)); $\Delta W_{\text{resid}}$ is not one homogeneous blob—it mixes *implicit calibration*, *output formatting*, and *unstated semantic sub-cases*, and an exception edit can contradict a tacit sub-case hiding inside $\Delta W_{\text{resid}}$ while needing calibration and formatting untouched; and re-absorbing $s'$ without projecting away from $\Delta W_{\text{resid}}$'s functional subspace quietly erodes implicit calibration over multi-wave edits.

The 30 primitives below dissect single-pass per-query absorption meters (Section A), closing the canonical-vs-paraphrase absorption gap (Section B), functional verbalizable-vs-residual decomposition (Section C), and residual-safe editing coupled with per-query handoff plus cross-pool round-107 `HEX4` (minimal write-record slice verified by swap-in while the rest stays serving) and `HEX5` (editability-gated exception compression) (Section D).

## Section A — Single-pass per-query absorption estimators

### T3-01 · Dual-head key-projection absorption meter — Ambitious but doable (P)
- **Mechanism:** Avoid double-forward overhead by estimating $\hat{\alpha}(x) \in [0, 1]$ inside one forward pass from the geometric alignment of the query hidden state $h_\ell(x)$ with the weight delta's input row-space $U_{\Delta W}$ (top-$r$ right singular vectors of $\Delta W$, weighted by singular values $\sigma_i$) relative to the KV rule-span attention energy. Canonical queries land squarely inside $\text{span}(U_{\Delta W})$ (high $\hat{\alpha}(x)$, strong KV value-vector attenuation), while paraphrases and compositions fall partly orthogonal to $U_{\Delta W}$ (low $\hat{\alpha}(x)$, KV stays live).
- **Nearest prior / gap:** [Select-TTT](https://arxiv.org/abs/2610.36794) uses query-conditioned gating for *writing* fast weights; using the *SVD input row-space projection* of an already-written $\Delta W$ to attenuate *KV value vectors* per query in one pass is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules, each tested on canonical prompts, lexical paraphrases, and 2-rule compositions mid-handoff. Compare against global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls at matched FLOPs. Kill if global-factor handoff matches peak ECE and paraphrase accuracy.
- **Old-task retention:** Score untouched old rules $A/B$ (accuracy and ECE) before and after handoff to verify zero interference from the row-space meter.

### T3-02 · Early-layer parametric-recall probe for late-layer KV attenuation — Ambitious but doable (P)
- **Mechanism:** Exploiting Transformer depth, measure whether $\Delta W$ has actually fired on query $x$ at an early-to-mid layer $\ell_0$ via the norm and cosine alignment of the parametric shift $\Delta W_{\ell_0} h_{\ell_0}(x)$ against the canonical rule-effect direction, then set $(1-\hat{\alpha}(x))$ on KV value vectors for all remaining layers $\ell > \ell_0$ in the *same* forward pass—zero extra passes, causally tied to actual weight firing.
- **Nearest prior / gap:** [How Do LMs Choose Between Context and Memory?](https://arxiv.org/abs/2609.00753) identifies mid-layer arbitration between context and memory statically. Using early-layer parametric activation as a *within-pass causal controller* for late-layer KV attenuation is untested.
- **Cheapest first test:** Qwen2.5-0.5B with rule updates in layers 6–18: probe $\Delta W$ firing at layer 10 to gate KV attenuation on layers 11–24 across canonical, paraphrase, and compositional slices vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if early-layer firing fails to predict late-layer rule absorption on paraphrases.
- **Old-task retention:** Verify zero degradation on untouched old rules $A/B$ whose layers 11–24 are not attenuated when $\Delta W_{\ell_0}$ does not fire.

### T3-03 · Prefix-calibrated per-query absorption via speculative draft check — Ambitious but doable (P)
- **Mechanism:** On multi-token generations, run a 2-token parallel batch check (weights-only vs. weights+KV) on only the *first 1–2 decision tokens* of the response (amortized cost $<5\%$ of generation), directly measuring exact logit-level absorption $\alpha_{\text{prefix}}(x)$, then lock $(1-\alpha_{\text{prefix}}(x))$ for the remaining tokens of that query.
- **Nearest prior / gap:** Speculative decoding verifies drafts cheaply in parallel; using a 2-token parallel KV-on/KV-off probe to calibrate *per-query handoff attenuation* for the rest of the sequence is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 30-token structured rule outputs across canonical, paraphrase, and compositional prompts; compare peak ECE, paraphrase accuracy, and total FLOPs against global-factor handoff, full double-forward $\alpha(x)$, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if 2-token prefix absorption does not correlate ($r < 0.7$) with full-sequence absorption.
- **Old-task retention:** Confirm untouched old rules $A/B$ retain baseline accuracy and ECE with zero persistent weight change from the prefix probe.

### T3-04 · Mahalanobis paraphrase-distance gate — Ambitious but doable (P)
- **Mechanism:** Track the running empirical mean $\mu_R$ and low-rank covariance $\Sigma_R$ of query representations $h(x)$ on which $\Delta W_R$ was distilled. For any incoming query $x$, map its Mahalanobis distance $d_M(x; \mu_R, \Sigma_R)$ monotonically to $\hat{\alpha}(x) = \alpha_{\text{base}} \exp(-d_M^2 / 2\tau^2)$: in-distribution canonical queries get full attenuation, while OOD paraphrases and novel compositions smoothly fall back to KV support.
- **Nearest prior / gap:** Mahalanobis OOD detection is classic for classification abstention; repurposing it as a *continuous per-query KV-vs-weight conservation gate* during live context-to-weights handoff is untested.
- **Cheapest first test:** Qwen2.5-0.5B distilling 10 rules from canonical examples only, then evaluating on canonical, paraphrase, and compositional queries against global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if Euclidean/cosine distance or global-factor handoff achieves the same paraphrase accuracy and canonical ECE.
- **Old-task retention:** Score untouched old rules $A/B$ (whose $d_M$ to new rule $R$ is large) to confirm no spurious attenuation of unrelated rules.

### T3-05 · Asymmetric conformal lower-bound gate on $\hat{\alpha}(x)$ — Ambitious but doable (P)
- **Mechanism:** Over-estimating $\hat{\alpha}(x)$ on a paraphrase drops the rule completely (high loss), whereas under-estimating $\hat{\alpha}(x)$ on a canonical prompt causes mild double-firing (bounded ECE cost). Maintain a tiny rolling conformal calibration buffer of $(\hat{\alpha}(x_i), \alpha^*(x_i))$ residuals and apply the lower confidence bound $\hat{\alpha}_{\text{LCB}}(x) = \max(0, \hat{\alpha}(x) - q_{1-\delta})$ to KV attenuation, giving a finite-sample guarantee that paraphrase rule-miss rate stays $\le \delta$.
- **Nearest prior / gap:** Conformal prediction bounds classification error; applying *asymmetric conformal lower-bounding* to live per-query KV attenuation during weight handoff is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B with noisy single-pass $\hat{\alpha}(x)$ (`T3-01`) on canonical + paraphrase + compositional streams; compare point-estimate $\hat{\alpha}(x)$ vs. conformal $\hat{\alpha}_{\text{LCB}}(x)$ vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls on worst-case paraphrase drop and peak ECE. Kill if point-estimate $\hat{\alpha}(x)$ already has $<1\%$ paraphrase miss rate without conformalization.
- **Old-task retention:** Track untouched old rules $A/B$ across the calibration window to confirm zero retention loss.

### T3-06 · Token-level dynamic $\alpha(x, t)$ along a generation trajectory — Ambitious but doable (P)
- **Mechanism:** Within a single answer, rule-critical decision tokens (e.g., applying a formatting or transformation rule) exhibit sharp weight-vs-KV overlap, whereas generic syntactic/filler tokens do not. Update $\hat{\alpha}(x, t)$ *at every generation step $t$* from the instantaneous parametric-vs-KV attention ratio so KV attenuation fires only on rule-governed tokens and leaves generic continuation tokens unperturbed.
- **Nearest prior / gap:** [Localized Context Distillation](https://arxiv.org/abs/2610.21427) localizes distillation to salient tokens offline; modulating *live KV value attenuation per generated token* $t$ during inference-time handoff is untested.
- **Cheapest first test:** Qwen2.5-0.5B on multi-sentence answers where only 20% of tokens are rule-governed (e.g., entity redaction or unit conversion); compare query-constant $\alpha(x)$ vs. token-dynamic $\alpha(x, t)$ vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls on token-level ECE and rule accuracy. Kill if query-constant $\alpha(x)$ matches token-level ECE.
- **Old-task retention:** Measure untouched old rules $A/B$ on both rule-governed and generic tokens to confirm zero fluency or retention drift.

### T3-07 · Compositional minimum-absorption bottleneck gate — Ambitious but doable (P)
- **Mechanism:** When a query $x$ composes two rules $R_1$ and $R_2$ simultaneously, weights often absorb $R_1$ and $R_2$ solo while failing their *interaction* $R_1 \wedge R_2$. Compute both solo absorption estimates $\hat{\alpha}_1(x), \hat{\alpha}_2(x)$ and a cross-delta interference check $\hat{\alpha}_{1\wedge 2}(x)$ (measuring non-commutation of $\Delta W_1, \Delta W_2$ on $h(x)$), and cap attenuation of *both* KV spans by $\min(\hat{\alpha}_1, \hat{\alpha}_2, \hat{\alpha}_{1\wedge 2})$ so compositions keep KV backing until joint absorption succeeds.
- **Nearest prior / gap:** [When Do Task Vectors Interfere?](https://arxiv.org/abs/2608.09490) maps static weight-composition boundaries; gating *live per-query KV handoff* by a compositional minimum-absorption bottleneck is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 6 rule pairs where solo canonical prompts are 90% absorbed but 2-rule compositions are only 35% absorbed; compare independent per-rule $\hat{\alpha}_i(x)$ vs. min-bottleneck gating vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if independent per-rule $\hat{\alpha}_i(x)$ already prevents compositional collapse.
- **Old-task retention:** Verify solo accuracy on $R_1, R_2$ and untouched old rules $A/B$ stays intact while compositions retain KV support.

### T3-08 · Entropy- and filler-invariant absorption ratio — Ambitious but doable (P)
- **Mechanism:** Adding or removing *any* context span shifts output entropy and token length statistics (PR #29/#31 confound), fooling naive logit-shift absorption meters into reading entropy change as semantic absorption. Project the measured shift onto the *semantic rule-contrast direction* (orthogonalized against the empirical filler-token shift vector and temperature-scaling direction) before computing $\hat{\alpha}(x)$.
- **Nearest prior / gap:** [Dissecting On-Policy Self-Distillation](https://arxiv.org/abs/2608.09228) separates privileged-solution transfer from context-induced teacher shifts; orthogonalizing a *live per-query absorption meter* against filler and temperature directions is untested.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules paired with length-matched filler spans and temperature-matched controls; measure false-positive $\hat{\alpha}(x)$ on filler spans and canonical/paraphrase peak ECE against raw logit-shift $\hat{\alpha}(x)$, global-factor handoff, NCA, localized context distillation, and keep/delete context. Kill if raw $\hat{\alpha}(x)$ already scores $<0.05$ on filler controls without orthogonalization.
- **Old-task retention:** Check untouched old rules $A/B$ for zero calibration shift across filler-augmented and clean prompts.

## Section B — Closing the canonical-vs-paraphrase absorption gap

### T3-09 · Low-$\hat{\alpha}(x)$ paraphrase-triggered micro-TTT curriculum — Ambitious but doable (P)
- **Mechanism:** Turn the per-query absorption meter $\hat{\alpha}(x)$ from a passive gate into an active learning trigger: canonical queries with $\hat{\alpha}(x) > 0.85$ run inference-only (zero gradient steps, zero weight churn), while paraphrases and compositions with $\hat{\alpha}(x) < \tau$ trigger a single-step, KV-supervised micro-TTT update on $\Delta W_R$, rapidly pulling paraphrase absorption up to canonical levels without overfitting canonical forms.
- **Nearest prior / gap:** [OPCD](https://arxiv.org/abs/2602.12275) and [Select-TTT](https://arxiv.org/abs/2610.36794) update on every step or via static selectors; using *low measured per-query absorption $\hat{\alpha}(x)$* to drive targeted paraphrase consolidation is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on a 60-query stream mixing canonical (50%), paraphrase (30%), and compositional (20%) queries; compare uniform-step handoff vs. low-$\hat{\alpha}(x)$ selective micro-TTT vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls at matched total gradient steps. Kill if uniform-step distillation reaches equal paraphrase absorption per gradient step.
- **Old-task retention:** Score untouched old rules $A/B$ after the 60-query stream; selective updates should reduce old-task forgetting by skipping redundant canonical updates.

### T3-10 · Canonical-to-paraphrase representation-alignment distillation — Ambitious but doable (P)
- **Mechanism:** Weights absorb canonical prompts before paraphrases because $\Delta W$ latches onto surface-key features. During handoff, add a lightweight representation-alignment regularizer forcing $\Delta W h(x_{\text{para}})$ (generated via 2 cheap self-paraphrases of the query trigger) to match the direction of $\Delta W h(x_{\text{canon}})$, compressing the canonical-vs-paraphrase absorption gap before KV eviction.
- **Nearest prior / gap:** [Instruct, Not Answer](https://arxiv.org/abs/2609.32201) shows instruction-privileged teachers generalize better than answer-privileged teachers in OPCD; aligning *weight-delta activation directions* across canonical and paraphrased triggers during live handoff is untested.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules evaluated on unseen paraphrases and 2-rule compositions; compare standard handoff vs. representation-aligned handoff vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls at matched compute. Kill if adding 2 paraphrases to standard SFT/OPCD matches unseen-paraphrase absorption equally well.
- **Old-task retention:** Measure untouched old rules $A/B$ to ensure alignment regularization does not broaden $\Delta W$ onto unrelated inputs.

### T3-11 · Quantile-gated progressive KV compression driven by $\hat{\alpha}(x)$ — Ambitious but doable (P)
- **Mechanism:** Evicting a rule from KV as soon as *mean* $\hat{\alpha}(x) > 0.9$ breaks paraphrases and compositions (which sit in the lower tail). Instead, track the empirical 10th-percentile absorption $\hat{\alpha}_{p10}$ across recent queries and step the KV span through three compression tiers: full rule + examples ($\hat{\alpha}_{p10} < 0.4$) → compact symbolic trigger ($\hat{\alpha}_{p10} \in [0.4, 0.85)$) → full eviction ($\hat{\alpha}_{p10} \ge 0.85$), keeping tail paraphrases safe while reclaiming context budget early.
- **Nearest prior / gap:** [Context Distillation as Latent Memory Management](https://arxiv.org/abs/2605.28889) manages discrete distilled memories; *lower-tail quantile-gated progressive KV compression* coupled to per-query $\hat{\alpha}(x)$ is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on a 10-rule stream with tight KV budget, measuring context tokens saved, paraphrase/compositional accuracy, and peak ECE against mean-$\alpha$ eviction, global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if binary eviction at a higher mean threshold matches token savings and tail paraphrase accuracy.
- **Old-task retention:** Verify untouched old rules $A/B$ suffer zero accuracy or ECE drop across tier transitions.

### T3-12 · Shadow KV-dropout self-audit for meter recalibration — Ambitious but doable (P)
- **Mechanism:** A single-pass absorption meter $\hat{\alpha}(x)$ can drift silently when query distribution shifts toward harder compositions. On a random 5% of queries where $\hat{\alpha}(x) > 0.8$, run a background shadow check comparing weights-only vs. weights+KV logits; if true absorption falls $>0.2$ below $\hat{\alpha}(x)$, recalibrate the meter's temperature/threshold online and re-trigger `T3-09` consolidation on that query cluster.
- **Nearest prior / gap:** Active calibration monitors exist for classifiers; *low-rate shadow KV-dropout auditing* specifically to catch silent over-estimation of per-query handoff absorption is untested.
- **Cheapest first test:** Qwen2.5-0.5B on a 100-query stream with a planted distribution shift from canonical (queries 1–50) to compositional paraphrases (queries 51–100); compare static $\hat{\alpha}(x)$ vs. 5%-audited $\hat{\alpha}(x)$ vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if static $\hat{\alpha}(x)$ maintains $<0.03$ ECE shift across the regime boundary.
- **Old-task retention:** Confirm audit recalibration does not degrade accuracy or ECE on untouched old rules $A/B$.

### T3-13 · Head-role-split per-query handoff (induction/copy vs. semantic heads) — Ambitious but doable (P)
- **Mechanism:** Canonical prompts rely heavily on induction/copy attention heads to retrieve the rule from KV, whereas paraphrases and compositions rely on semantic-routing heads. Partition attention heads into copy vs. semantic roles (via one-time induction-score profiling) and apply a faster per-query attenuation schedule $\hat{\alpha}_{\text{copy}}(x)$ to copy heads while keeping semantic heads backed by KV until compositional $\hat{\alpha}_{\text{sem}}(x)$ saturates.
- **Nearest prior / gap:** Mechanistic interpretability separates induction heads from semantic heads; driving *asymmetric per-query KV handoff schedules* by head role is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules across canonical, paraphrase, and compositional prompts; compare uniform-head $\hat{\alpha}(x)$ vs. head-role-split $\hat{\alpha}(x)$ vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if uniform-head $\hat{\alpha}(x)$ matches paraphrase accuracy and canonical ECE.
- **Old-task retention:** Verify untouched old rules $A/B$ are unaffected by head-role attenuation on the new rule span.

### T3-14 · `ParaHandoff-CL`: four-slice per-query absorption benchmark — Ambitious but doable (P)
- **Mechanism:** Standardize a CPU-runnable, multi-seed evaluation protocol for (a) that separates four mandatory query slices for every rule: (1) *canonical* (same template as distillation), (2) *lexical paraphrase* (reworded trigger), (3) *compositional* (negation or 2-rule conjunction), and (4) *untouched old rules $A/B$*, reporting worst-slice accuracy, peak ECE across the handoff trajectory, and KV tokens freed against all seven mandatory controls.
- **Nearest prior / gap:** Existing context-distillation benchmarks report average post-removal accuracy only; no benchmark scores *per-slice canonical-vs-paraphrase-vs-composition calibration parity* during live handoff against filler and entropy-matched controls.
- **Cheapest first test:** Implement on Qwen2.5-0.5B (10 rules, 3 seeds) and verify it cleanly separates global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls with non-overlapping confidence intervals. Kill if global-factor handoff already matches or beats oracle per-query $\alpha^*(x)$ on all four slices.
- **Old-task retention:** Slice (4) enforces a mandatory zero-reset old-rule $A/B$ accuracy and ECE floor on every step.

## Section C — Functional verbalizable-vs-residual weight decomposition

### T3-15 · Functional-Jacobian verbalizable projection (fixing bilinear parameter-orthogonality failure) — Ambitious but doable (P)
- **Mechanism:** [Bilinear Optimization Divergence](https://arxiv.org/abs/2609.23594) proves that naive parameter-space orthogonality in LoRA/MLP updates does not guarantee functional separation. Instead of projecting $\Delta W$ in weight coordinates, define $\Delta W_{\text{verb}}(s)$ as the minimum-norm weight update whose *functional output* $f_{W+\Delta W_{\text{verb}}(s)}(x)$ matches the verbalized text in context $f_W(s; x)$ across a probe set $X_R$, then define the residual strictly by subtraction $\Delta W_{\text{resid}} = \Delta W - \Delta W_{\text{verb}}(s)$—guaranteeing $\Delta W_{\text{resid}}$ captures the exact functional gap between the weights and the words $s$.
- **Nearest prior / gap:** [Bilinear Optimization Divergence](https://arxiv.org/abs/2609.23594) diagnoses factor-orthogonality failure in LoRA CL; using *functional output-matching subtraction* to isolate $\Delta W_{\text{verb}}(s)$ from $\Delta W_{\text{resid}}$ before editing is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules that have both a stated symbolic rule and planted implicit calibration + JSON formatting quirks; apply 1 exception edit and compare parameter-orthogonal splitting vs. functional-Jacobian splitting vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if parameter-orthogonal splitting preserves calibration and formatting equally well.
- **Old-task retention:** Score untouched old rules $A/B$ (accuracy + ECE) alongside non-excepted base-rule accuracy and formatting compliance.

### T3-16 · Three-way residual taxonomy split (calibration vs. formatting vs. tacit sub-cases) — Ambitious but doable (P)
- **Mechanism:** $\Delta W_{\text{resid}}$ is not one monolithic object: decompose it into three measurable subspaces using targeted probes: (1) **$\Delta W_{\text{cal}}$** (logit temperature / confidence scaling on the rule's answer tokens), (2) **$\Delta W_{\text{fmt}}$** (structural delimiters, JSON/markdown syntax, register tokens), and (3) **$\Delta W_{\text{tacit}}$** (unstated semantic sub-cases/edge behaviors). When an exception edit $s \to s'$ arrives, freeze $\Delta W_{\text{cal}}$ and $\Delta W_{\text{fmt}}$ unconditionally and audit *only* $\Delta W_{\text{tacit}}$ for conflict with $s'$.
- **Nearest prior / gap:** [One-Shot Calibration via Model Editing](https://arxiv.org/abs/2611.20562) edits confidence distributions separately from single answers, and [Weight-Delta Audit](https://arxiv.org/abs/2608.20768) shows domain deltas mix calibration/style with knowledge; factoring $\Delta W_{\text{resid}}$ into *calibration / formatting / tacit sub-cases* to govern selective weight retention during decompilation is untested.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules where each rule has a verbalizable core, a calibrated abstention threshold, a strict output format, and 1 unstated edge case that conflicts with the new exception; compare monolithic $\Delta W_{\text{resid}}$ retention vs. three-way split vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if monolithic $\Delta W_{\text{resid}}$ retention matches exception accuracy and calibration/format preservation.
- **Old-task retention:** Measure untouched old rules $A/B$ plus base-rule calibration ECE and formatting compliance.

### T3-17 · MDL information-bottleneck verbalization budget — Ambitious but doable (P)
- **Mechanism:** Over-verbalizing a weight delta into a 500-token essay bloats context and hallucinates brittle prose for continuous calibration behaviors; under-verbalizing leaves core symbolic logic trapped in $\Delta W_{\text{resid}}$ where the edit misses it. Select the decompiled text $s^*$ by minimizing $\mathcal{L}(s) = \text{KL}(f_{W+\Delta W} \,\|\, f_W(s; \cdot)) + \lambda |s|$ on the *conflict-local* distribution: symbolic rule logic compresses cheaply (small $|s|$, huge KL drop) and lifts to text, while high-entropy implicit calibration/style stays in $\Delta W_{\text{resid}}$.
- **Nearest prior / gap:** [How Much Can a LoRA Adapter Memorize?](https://arxiv.org/abs/2607.21351) measures adapter information in bits; using an *MDL bit-rate bottleneck* to decide the exact boundary between verbalized text $s$ and retained weight residual $\Delta W_{\text{resid}}$ is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B sweeping verbalization budgets (20 / 60 / 200 tokens vs. MDL-selected $s^*$) on rules with mixed symbolic logic and continuous calibration; compare against whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if a fixed short summary (e.g., 50 tokens) matches MDL-selected $s^*$ on exception accuracy and residual retention.
- **Old-task retention:** Score untouched old rules $A/B$ and verify MDL-bounded edits minimize parameter norm drift.

### T3-18 · PRISM + SAE dark-matter residual isolation — Ambitious but doable (P)
- **Mechanism:** Run PRISM-style instruction recovery only over the *interpretable sparse-autoencoder (SAE) feature projection* of $\Delta W$'s activations to synthesize $s$ and $\Delta W_{\text{verb}}(s)$, while routing the SAE reconstruction residual ("dark matter" features that lack clean natural-language labels—typically implicit calibration, pacing, and formatting) strictly into $\Delta W_{\text{resid}}$ untouched by editing.
- **Nearest prior / gap:** [PRISM](https://arxiv.org/abs/2606.09563) recovers instructions from activations and [Weights Read and Write Features](https://arxiv.org/abs/2609.37731) decomposes weights via activation features; treating the *SAE dark-matter residual* as the protected unverbalizable weight component during decompile–edit–reabsorb is untested.
- **Cheapest first test:** Qwen2.5-0.5B with a lightweight pretrained/local SAE on mid-layer MLP activations; compare raw PRISM whole-change decompilation vs. PRISM+SAE dark-matter split vs. offline round trip, TTT overwrite, ROME/MEMIT, and AlphaEdit on exception accuracy and calibration/formatting retention. Kill if raw PRISM + functional subtraction (`T3-15`) matches SAE dark-matter isolation without needing an SAE.
- **Old-task retention:** Verify untouched old rules $A/B$ suffer zero SAE-reconstruction distortion.

### T3-19 · Input-manifold-scoped residual gating — Ambitious but doable (P)
- **Mechanism:** Even after splitting $\Delta W = \Delta W_{\text{verb}}(s) + \Delta W_{\text{resid}}$, leaving $\Delta W_{\text{resid}}$ active *inside* the newly carved-out exception region $\mathcal{D}_{\text{exc}}$ can bias exception answers toward stale unstated sub-cases. Attach a lightweight input gate $g_{\text{exc}}(x) \in [0, 1]$ (learned from the exception trigger) so $\Delta W_{\text{resid}}$ stays at $1.0$ on all non-excepted base inputs and attenuates selectively on $\mathcal{D}_{\text{exc}}$.
- **Nearest prior / gap:** Guarded exception patches (`T2-16`) gate the *new* exception delta; inversely gating the *retained residual* $\Delta W_{\text{resid}}$ away from $\mathcal{D}_{\text{exc}}$ so it preserves base-domain calibration/formatting without fighting the exception is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules where the exception changes both the answer and the implicit confidence/format on $\mathcal{D}_{\text{exc}}$ while keeping base inputs unchanged; compare ungated $\Delta W_{\text{resid}}$ vs. manifold-gated $\Delta W_{\text{resid}}$ vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if ungated $\Delta W_{\text{resid}}$ achieves equal exception accuracy and base calibration.
- **Old-task retention:** Measure untouched old rules $A/B$ to ensure $g_{\text{exc}}(x)$ stays $0$ outside $\mathcal{D}_{\text{exc}}$.

### T3-20 · Calibration-locked unembedding / norm-direction freeze — Ambitious but doable (P)
- **Mechanism:** Implicit calibration in LLMs concentrates in low-dimensional logit-norm, LayerNorm-gain, and unembedding-aligned directions of $\Delta W$ (cf. [Spectral & Subspace Dynamics of LoRA](https://arxiv.org/abs/2611.08414)). Explicitly pin those calibration-aligned singular directions into $\Delta W_{\text{resid}}$ with zero-gradient masks prior to decompilation and re-absorption, guaranteeing that editing the semantic rule text $s \to s'$ cannot distort model confidence scaling.
- **Nearest prior / gap:** [One-Shot Calibration via Model Editing](https://arxiv.org/abs/2611.20562) edits calibration explicitly; *freezing* calibration-aligned weight directions inside $\Delta W_{\text{resid}}$ during semantic decompile–edit–reabsorb is untested.
- **Cheapest first test:** Qwen2.5-0.5B on 10 calibrated rules (evaluated with ECE and Brier score) undergoing 3 sequential exception edits; compare unconstrained re-absorption vs. calibration-locked $\Delta W_{\text{resid}}$ vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if standard differential re-absorption already keeps ECE drift $<0.01$.
- **Old-task retention:** Score ECE and accuracy on untouched old rules $A/B$ across all 3 edit waves.

### T3-21 · Counterfactual residual-necessity certificate — Ambitious but doable (P)
- **Mechanism:** Before executing an edit, run a 2-point counterfactual ablation check on $\Delta W_{\text{resid}}$ over a tiny diagnostic set (base calibration/formatting probes + exception probes): certify that (i) ablating $\Delta W_{\text{resid}}$ degrades implicit calibration/formatting by $\ge \epsilon_{\text{keep}}$ (proving the residual is genuinely carrying unverbalized behavior, not leftover verbalizable rule mass) and (ii) $\Delta W_{\text{resid}}$ alone does *not* fire the old base rule on exception probes (proving $s$ captured the full verbalizable core). If (ii) fails, expand $s$ before editing.
- **Nearest prior / gap:** No existing decompilation method (PRISM, Weight Oracles, offline round trip) verifies *both* residual necessity and verbalization completeness before committing an edit.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules with intentionally noisy/incomplete initial verbalizers; measure how often the certificate catches under-verbalized splits and improves post-edit exception accuracy + residual retention over uncertified splitting, whole-change decompilation, PRISM, offline round trip, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if uncertified `T3-15` already passes both criteria on $>95\%$ of rules.
- **Old-task retention:** Score untouched old rules $A/B$ to verify zero side effects from the diagnostic probe.

## Section D — Residual-safe editing & unified coupling with per-query handoff

### T3-22 · Residual-conflict surgical rank-1 pruning — Ambitious but doable (P)
- **Mechanism:** When re-absorbing edited text $s'$ as $\Delta W_{\text{verb}}(s')$, measure activation-space opposition $\langle \Delta W_{\text{verb}}(s') h(x), \Delta W_{\text{resid}} h(x) \rangle < 0$ on exception probes $x \in \mathcal{D}_{\text{exc}}$. Instead of wiping $\Delta W_{\text{resid}}$, compute the top conflicting singular direction $u_c v_c^\top$ of $\Delta W_{\text{resid}}$ on $\mathcal{D}_{\text{exc}}$ and subtract *only* that rank-1 component—resolving tacit-sub-case collisions while preserving $>90\%$ of implicit calibration and formatting.
- **Nearest prior / gap:** [Geometry-Aware Editing](https://arxiv.org/abs/2611.06185) regularizes new edits against old knowledge; *surgically pruning only the rank-1 direction of a preserved residual $\Delta W_{\text{resid}}$ that opposes a new exception* is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 10 rules with planted tacit sub-case conflicts inside $\Delta W_{\text{resid}}$ plus planted formatting/calibration quirks; compare full residual retention vs. rank-1 conflict pruning vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if full residual retention or whole-change decompilation matches both exception accuracy and formatting/calibration retention.
- **Old-task retention:** Measure untouched old rules $A/B$ and non-conflicting base-rule calibration/formatting after pruning.

### T3-23 · Dual-null-space re-absorption (protecting old tasks AND $\Delta W_{\text{resid}}$) — Ambitious but doable (P)
- **Mechanism:** Extend AlphaEdit's null-space projection to a *dual* constraint: when compiling edited text $s'$ into $\Delta W_{\text{verb}}(s')$, project the gradient update onto the intersection of (1) the null space of untouched old tasks $A/B$ and (2) the null space of $\Delta W_{\text{resid}}$'s calibration/formatting probe activations, guaranteeing mathematically that re-absorbing $s'$ cannot overwrite either old rules or the preserved residual.
- **Nearest prior / gap:** [AlphaEdit](https://arxiv.org/abs/2410.02355) and [FisherEdit](https://arxiv.org/abs/2610.25914) protect old-task keys only; *dual null-space projection* protecting both old tasks and the *same rule's unverbalizable residual* during re-absorption is untested.
- **Cheapest first test:** Qwen2.5-0.5B across 4 sequential exception edits on 10 rules; compare AlphaEdit (old-task null space only) vs. dual-null-space re-absorption vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, and ROME/MEMIT on exception accuracy, calibration/format retention, and old-task $A/B$ retention. Kill if standard AlphaEdit preserves calibration/formatting equally well across 4 waves.
- **Old-task retention:** Explicitly enforced by constraint (1) and verified on untouched old rules $A/B$ (accuracy + ECE).

### T3-24 · Conflict-driven tacit-to-verbalized promotion — Ambitious but doable (P)
- **Mechanism:** Some behaviors begin as unverbalized residuals in $\Delta W_{\text{resid}}$ (e.g., an implicit edge-case heuristic) but later become the target of explicit user exceptions. Track per-direction conflict counts inside $\Delta W_{\text{resid}}$; once a tacit residual direction triggers $\ge 2$ conflicts, selectively decompile *that single residual direction* into explicit text appended to $s$ and remove it from $\Delta W_{\text{resid}}$—gradually crystallizing contested tacit behavior into editable rules while leaving uncontested calibration/formatting in weights.
- **Nearest prior / gap:** [Adapters as Data](https://arxiv.org/abs/2611.07775) studies latent LoRA manifolds statically; *conflict-driven promotion of contested residual directions from weights into editable text* is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 8 rules where 2 implicit edge cases in $\Delta W_{\text{resid}}$ are hit by repeated user corrections while calibration/formatting remain uncontested; compare static $\Delta W_{\text{resid}}$ vs. conflict-driven promotion vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit. Kill if rank-1 pruning (`T3-22`) alone handles repeated tacit conflicts without verbalization.
- **Old-task retention:** Score untouched old rules $A/B$ and uncontested calibration/formatting directions before and after promotion.

### T3-25 · Multi-edit residual-drift watchdog & re-anchoring — Ambitious but doable (P)
- **Mechanism:** Across 5+ sequential exception edits, small approximation errors in $\Delta W_{\text{verb}}(s_k')$ accumulate and erode the unverbalized calibration/formatting stored in $\Delta W_{\text{resid}}$. Snapshot a compact 16-example calibration/format fingerprint of $\Delta W_{\text{resid}}$ when the rule is first absorbed; after each edit, check fingerprint drift and run a 2-step residual re-anchoring pass (constrained to old-task null space) only when ECE or format compliance drifts past a threshold $\delta$.
- **Nearest prior / gap:** [Learning Dynamics of Continual Learning](https://arxiv.org/abs/2609.33620) tracks forgetting across sequential updates; *fingerprint-triggered residual re-anchoring* specifically for unverbalized calibration/formatting across repeated decompile–edit cycles is untested.
- **Cheapest first test:** Qwen2.5-0.5B over 5 sequential exception waves on 10 rules; compare unmonitored edits vs. watchdog re-anchoring vs. whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit on wave-5 ECE, format compliance, and exception accuracy. Kill if `T3-23` alone keeps wave-5 residual drift flat without re-anchoring.
- **Old-task retention:** Verify zero-reset accuracy and ECE on untouched old rules $A/B$ after every re-anchoring trigger.

### T3-26 · Residual-aware per-query handoff (coupling (a) and (b)) — Ambitious but doable (P)
- **Mechanism:** Directly unifies (a) and (b): when re-absorbing edited text $s'$ back into weights via per-query handoff (`T3-01`–`T3-08`), $\Delta W_{\text{resid}}$ is *already active* in weights and shifts logits/entropy on every query. Condition the per-query absorption meter $\hat{\alpha}(x \mid \Delta W_{\text{resid}})$ on the baseline $W + \Delta W_{\text{resid}}$ (not bare $W$) so residual calibration/formatting is never miscounted as absorption of the new verbalized edit $s'$—eliminating premature KV attenuation on paraphrases of $s'$.
- **Nearest prior / gap:** Neither per-query handoff (`T2-02`) nor residual-preserving decompilation (`T2-10`) accounts for how a live $\Delta W_{\text{resid}}$ biases the absorption meter during re-absorption; baseline-shifted per-query metering is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B re-absorbing an edited rule $s'$ alongside a live $\Delta W_{\text{resid}}$ on canonical, paraphrase, and compositional exception queries; compare bare-$W$ $\hat{\alpha}(x)$ vs. residual-conditioned $\hat{\alpha}(x \mid \Delta W_{\text{resid}})$ vs. global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls. Kill if bare-$W$ $\hat{\alpha}(x)$ shows $<0.02$ bias in the presence of $\Delta W_{\text{resid}}$.
- **Old-task retention:** Score untouched old rules $A/B$ and non-excepted base-rule calibration/formatting throughout re-absorption.

### T3-27 · Residual-preserving reverse handoff during live editing — Ambitious but doable (P)
- **Mechanism:** The exact inverse of `T3-26`: when lifting $\Delta W_{\text{verb}}(s)$ into context as text $s$ so the model can draft an exception edit $s'$, mute *only* $\Delta W_{\text{verb}}(s)$ by $(1-\beta(x))$ while keeping $\Delta W_{\text{resid}}$ at full scale $1.0$. The model therefore edits $s \to s'$ with zero stale-rule double-firing bias while retaining its full learned domain formatting and calibration during the editing chain-of-thought.
- **Nearest prior / gap:** `T2-22` proposed reverse handoff on the whole delta $\Delta W$; *selective reverse handoff* that mutes only $\Delta W_{\text{verb}}(s)$ while leaving $\Delta W_{\text{resid}}$ live during editing is untested.
- **Cheapest first test:** Qwen2.5-0.5B drafting 20 exception edits on rules with strict domain formatting and calibrated confidence; compare full-$\Delta W$ muting vs. $\Delta W_{\text{verb}}$-only muting vs. no muting, whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit on edit validity and format retention. Kill if full-$\Delta W$ muting produces equally valid, well-formatted edits.
- **Old-task retention:** Confirm untouched old rules $A/B$ remain active at scale $1.0$ throughout editing.

### T3-28 · `VerbalResid-CL`: unified assay for per-query handoff & residual-preserving decompilation — Ambitious but doable (P)
- **Mechanism:** A single CPU-runnable, multi-seed benchmark testing both (a) and (b) end-to-end: 12 rules each constructed with (i) a verbalizable symbolic core, (ii) a planted implicit calibration target, (iii) a strict output format, and (iv) 1 unstated edge case. Each rule enters in context, undergoes per-query handoff evaluated across canonical / lexical-paraphrase / compositional slices, and then undergoes 3 sequential exception waves (including 1 wave that collides with the unstated edge case). Scores peak handoff ECE, worst-slice paraphrase accuracy, exception accuracy, base-rule + calibration/formatting retention, and untouched old-rule $A/B$ retention against all mandatory controls for both (a) and (b).
- **Nearest prior / gap:** No benchmark simultaneously tests canonical-vs-paraphrase per-query handoff calibration and verbalizable-vs-residual preservation under sequential exception editing against PRISM, AlphaEdit, NCA, and filler/entropy controls.
- **Cheapest first test:** Run on Qwen2.5-0.5B across 3 seeds and verify that naive global-factor handoff fails the paraphrase-vs-canonical ECE tradeoff while whole-change decompilation / TTT overwrite / AlphaEdit fail either exception accuracy or unverbalized calibration/formatting retention. Kill if a single baseline (e.g., NCA or AlphaEdit) dominates all metrics simultaneously.
- **Old-task retention:** Mandatory zero-reset $A/B$ accuracy and ECE floor logged at every handoff and edit wave.

### T3-29 · Write-record minimal editable slice with swap-in verification (`HEX4`) — Ambitious but doable (P)
- **Mechanism:** Deepens cross-pool round 107's `HEX4` inside our verbalizable-vs-residual split (`T3-15`, `T3-21`, `T3-27`): use the compact write record (`T2-15`) to select the *smallest* candidate sub-slice $\Delta W_{\text{slice}} \subseteq \Delta W_{\text{verb}}$ implicated by a live conflict, decompile *only* that slice into editable text $s_{\text{slice}}$, and **verify faithfulness by swap-in** (muting $\Delta W_{\text{slice}}$ while injecting $s_{\text{slice}}$ into KV must reproduce the conflict behavior within $\epsilon$ while the rest of $\Delta W$—including $\Delta W_{\text{resid}}$ and unrelated sub-rules—keeps serving uninterrupted). Only if swap-in fails does the slice expand one provenance hop.
- **Nearest prior / gap:** `HEX4` (cross-pool round 107), [PRISM](https://arxiv.org/abs/2606.09563), and [Weights Read and Write Features](https://arxiv.org/abs/2609.37731) recover full instruction sets or static features offline. Selecting the *minimum provenance-indexed slice* verified by live *swap-in parity* while the remainder stays serving is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B on 10 multi-clause rules with planted calibration/formatting residuals; inject 1 localized clause conflict and compare minimal write-record swap-in slice vs. full-rule verbalizable decompilation, whole-change decompilation, offline round trip, PRISM, TTT overwrite, ROME/MEMIT, and AlphaEdit on serving downtime, swap-in fidelity, exception accuracy, and residual retention. Kill if full-rule verbalizable decompilation matches serving fidelity and residual preservation at equal context tokens.
- **Old-task retention:** Measure untouched old rules $A/B$ and non-conflicting clauses of the *same* rule while $\Delta W_{\text{slice}}$ is swapped out for editing.

### T3-30 · Editability-gated exception compression (`HEX5`) — Ambitious but doable (P)
- **Mechanism:** Deepens cross-pool round 107's `HEX5` inside our multi-edit residual stability loop (`T2-19`, `T3-23`, `T3-25`): compressing a stack of sequential exceptions into a cleaner single weight patch can accidentally entangle their subspaces and make the *next* future exception harder or more destructive to land. Gate every compression pass on a **held-out next-exception probe**: commit the compressed weights *only if* a synthetic held-out future exception still lands as cheaply (same gradient steps / rank budget) and as locally (same zero-interference score on base rule + $\Delta W_{\text{resid}}$) as before compression; otherwise keep the uncompressed guarded patches.
- **Nearest prior / gap:** `HEX5` (cross-pool round 107), [AlphaEdit](https://arxiv.org/abs/2410.02355), and [Learning Dynamics of Continual Learning](https://arxiv.org/abs/2609.33620) evaluate *past* retention after consolidation, never *future editability* (plasticity-locality of the next unseen exception). Gating exception compression on a held-out next-exception locality/cost test is the candidate primitive.
- **Cheapest first test:** Qwen2.5-0.5B over 5 sequential overlapping exceptions per rule (with exception 5 held out to test post-compression editability); compare editability-gated compression vs. no compression, unchecked compression (`T2-19`), guarded patches (`T2-16`), and sequential AlphaEdit on wave-5 edit cost, locality, base-rule + residual calibration retention, and old-task retention. Kill if unchecked compression or sequential AlphaEdit lands wave-5 exceptions equally cheaply and locally.
- **Old-task retention:** Score untouched old rules $A/B$ (accuracy + ECE) and preserved $\Delta W_{\text{resid}}$ calibration/formatting after both compression and the wave-5 exception.

## Ranked deeper questions

1. **Can a single-pass per-query absorption meter (`T3-01`, `T3-02`, `T3-04`, `T3-05`, `T3-08`) match oracle double-forward $\alpha^*(x)$ on canonical vs. paraphrase vs. compositional peak ECE—and strictly beat global-factor handoff, NCA, localized context distillation, keep/delete context, filler, and entropy-matched controls?**
   This is the make-or-break gate for (a). If single-pass row-space/early-layer/Mahalanobis meters cannot predict paraphrase under-absorption without running two forward passes (or if global-factor handoff + filler/entropy matching already closes the gap), per-query handoff is compute-negative. Test directly on `T3-14` (`ParaHandoff-CL`).

2. **Does functional-Jacobian splitting (`T3-15`) + three-way residual factorization (`T3-16`) preserve implicit calibration and formatting under exception edits where whole-change decompilation, PRISM, offline round trip, TTT overwrite, ROME/MEMIT, and AlphaEdit degrade them?**
   Directly tests whether leaving $\Delta W_{\text{resid}}$ in weights is a genuine continual-learning primitive or whether parameter/functional entanglement forces either residual destruction (whole-change wipe) or stale-behavior interference. Test directly on `T3-28` (`VerbalResid-CL`), including the planted tacit-sub-case conflict (`T3-22`).

3. **Does low-$\hat{\alpha}(x)$ paraphrase-triggered micro-TTT (`T3-09`) + quantile-gated KV compression (`T3-11`) actually let KV spans be evicted without sacrificing compositional paraphrases—and at lower old-task forgetting than uniform distillation?**
   Per-query handoff only pays off long-term if paraphrases eventually catch up to canonical absorption so KV memory can be reclaimed. Testing whether $\hat{\alpha}(x)$-routed consolidation closes the canonical-vs-paraphrase gap faster per gradient step than uniform OPCD/TTT directly measures its memory-efficiency payoff.

4. **When (a) and (b) compose across multi-wave edits (`T3-26`, `T3-27`, `T3-29`/`HEX4`, `T3-30`/`HEX5`), does an active residual $\Delta W_{\text{resid}}$ bias single-pass absorption meters—and do swap-in minimal slicing, dual-null-space re-absorption (`T3-23`), and editability-gated exception compression (`T3-30`) keep both calibration and future-edit locality flat over 5 waves?**
   Tests whether (a) and (b) compose cleanly across multi-wave continual editing without cumulative residual drift or plasticity collapse: specifically whether `HEX4`'s swap-in minimal slice keeps the rest serving cleanly and whether `HEX5`'s held-out next-exception gate beats no compression, unchecked compression, guarded patches, and sequential AlphaEdit on wave-5 locality while keeping old rules $A/B$ intact.
