# Gated merge, then reopen

**Status:** Ideas only; no training runs or GPU work. **Parent:** [Synchronizing training batches](synchronizing-batches.md) ([PR #213][parent]), cards 04 and 13. **Review seed:** [Flood triage, row 324][triage] scored 3 for both a truthful two-batch gate-and-reopen word and a recovery procedure applied identically to the certified post-deletion learner and its retrain-from-scratch reference. **Read first:** [Idea ledger][ledger].

## Can we reopen service without reopening the nuisance?

**Verdict: the gate-and-reopen word is a candidate primitive; post-processing is an established theorem, not a discovery.** The joint research bet is a service-restoring two-batch word whose nuisance path stays inactive on a promised domain, selected and bound without an extra channel from deleted data. A strict negative gate can synchronize a *read* even when the underlying states remain different. It is not itself deletion. And a valid deletion certificate can survive recovery that is useless, or one that teaches a deleted fact from a genuinely independent source. Utility, deletion influence and absolute disclosure are separate checks. Nominate a pilot only if the joint word beats the stacked gate/replay and certified-recovery baselines at matched budgets.

**Nearest prior art.** [ReDo][redo] recycles dormant units and [continual backprop][cbp] maintains plasticity through replacement; here the nuisance must stay inactive while an already shared path learns, without explicit masking or reinitialization. [Multi-learner machine teaching][teaching] and [synchronizing words][sync] already optimize shared instruction across states; the extra constraint is a certified phase boundary where the nuisance contributes zero throughout service acquisition. [Reluplex][reluplex] and [DeepPoly][deeppoly] provide tools for reasoning about activation regions; certification alone is not the contribution. [Git Re-Basin][rebasin] aligns separate models before merging weights, unlike one word run separately on each possible state. [Certified removal][guo], [SISA][sisa], [Descent-to-Delete][dtd], and the [DP post-processing theorem][dp] set the deletion baselines and release boundary. [Benign relearning][jog] motivates checking service and disclosure during later training, not just at deletion. This is a scoped literature check (including HF Papers queries), not evidence that all card variants are novel.

## Contract and falsifiers

- **Gate.** A and B are retained old tasks and earlier admissions, C includes installed and incoming successor skills. Before any spend, fix the lawful observations, full reachable alias class (including optimizer slots), frozen witness and permitted bindings, truthful C pool, finite or bounded input domains, and A/B/C utility floors. Choose one open-loop word per lawful class. For all states in that class, batch 1 must land in a common nuisance-inactive region with strict slack over the promised domain; batch 2 must train a shared active service path, launch the frozen witness under one binding, and keep the nuisance inactive through every observable prefix. Score agreement and correctness separately. No witness targets, pseudo-labels, ancestor snapshot, state-specific reset, mask or decoded branch ID in the proposed word. A masked branch is a control, not evidence. A flat held-out read alone does not prove gate inactivity, and a count of inactive units does not prove removal.
- **Controls.** Compare both orders, repetitions and best C replay/teaching at matched truthful examples, optimizer, step count, retained bytes and C utility. Charge word search, proofs, refusal logs, and working space. Include [#203's linear merge][linear], explicit gate reset and ReDo/continual-backprop recycling, [#202 switched branches][switched], and a stacked direct-gate-plus-best-C-replay control. Include one linear host or alias class where no admitted word works, a point that reactivates the nuisance, and an always-dormant nuisance with no useful service gain. Protected A/B and installed C get per-task floors and worst-case reads before, between and after the batches and after a predeclared ordinary continuation; no averaging away one broken task. Exclude deletion-covered items, not unaffected old tasks.
- **Certified fork.** Let `U` be the certified post-deletion artifact and `R` the release from a fresh train without the deleted records. The comparison is `K(U)` versus `K(R)`, not `K(U)` versus bare `R`. Fix the same `K` (including rules, randomization, admissibility checks, words, bindings, refusals and what is published) in both arms. C data and random seeds come from the same law independent of the deleted records and of the two artifacts given fixed public metadata. The guarantee must hold in that metadata context; do not smuggle in a private receipt, pretrained teacher, deleted-data statistic or private tuning history. The procedure can adapt to the covered artifact using the same rule in both arms; it may not inspect uncovered optimizer slots or query an uncovered snapshot. For any output event `E`, integrate the bounded function `K(z,E)` against the two artifact laws: a certified `(ε,δ)` event inequality carries over in every direction in which it held originally. This applies to the full recovery transcript when the full transcript is a function of those same allowed inputs; it does not retroactively protect prior releases or separately accessed state. If only label queries are covered, do not silently claim a weight- or trajectory-level certificate.
- **Disclosure and service.** Compare deletion-only, fresh retraining with/without the same recovery, SISA with/without recovery (not presumed certified), and rollback plus replay. Test a forbidden binding chosen using a deleted-data receipt as a separate negative control. On held-out deletion cohorts, give attackers equal access, compute and query budgets at both snapshots, allow refitting, and report paired bounds for membership advantage, TPR at a fixed low FPR and exact/near reconstruction; inspect timing, refusals, certificates and bindings when visible. Compare against deletion-only *and* the transformed retrain reference. Post-processing bounds the two distributions relative to each other, not the absolute attack rate or its change from deletion-only at a fixed query budget. Test an independently learnable witness and one whose success criterion itself reveals the deleted value; refuse the latter if it violates the disclosure policy even when the formal comparison passes.

## Exact two-batch sanity check

Take `f(x) = ReLU(u x_n) + ReLU(v x_s) + a x_A + b x_B`, squared loss divided by two, step `3/4`, no momentum. The two aliases start at `(u,v) = (1,1),(2,1)`; the declared planning observations are the reads on the old axes, which do not distinguish them. Use truthful labels from `y = 6 x_s − x_n` on the C plane `x_A = x_B = 0`. Predeclare a zero-old-coordinate witness at `(x_n,x_s) = (1,1/2)` with required read 2, held out from the word and not a planning observation.

1. Batch `G = ((1,0),−1)` sends the two nuisance weights to `−1/2,−1/4`, leaving `v=1`. The nuisance is strictly inactive on `1 ≤ x_n ≤ 2` with preactivation at most `−1/4` in both states.
2. Batch `S = ((1,1),5)` has zero gradient into that nuisance and takes both service weights from 1 to 4. The witness now reads 2 in both states, up from `3/2,5/2` at entry. The nuisance parameters still differ. In reverse order, the witness reads `27/16,11/8`, with positive nuisance preactivations.

Batch 1 improves its own loss but cannot fit its negative label in this positive-output toy; batch 2 improves but does not fit its label either. Old probes on the separate A/B axes are unchanged by construction. This is a feasibility witness for order-dependent functional merging and active service learning, not evidence of retention with shared features, sustained C utility or deletion. In particular, anyone who reads the nuisance weight can still distinguish these two histories.

## Idea cards

**Labels:** A primitive candidate introduces a reusable operation or contract; an improvement is a control, audit or optimization of known machinery, not a pilot nomination. Tests below are paper or tiny CPU proposals, not results. Each inherits the controls above.

### 01. Turn off one path to train another — primitive candidate
**Mechanism.** Compile two truthful batches into a reusable gate-entry/service operation with one binding. The service gradient must improve only after the nuisance becomes silent. **Novelty / control.** Unlike [ReDo][redo], no neuron is replaced or woken; unlike the [parent's][parent] linear agreement, every nuisance contribution disappears over a domain. Compare best fixed reset plus S and a linear host. **Cheapest first test.** Enumerate all two-batch words on a tiny shared-trunk ReLU with two hidden histories; freeze the witness before seeing the pool and include a gate-infeasible class. **Old-task retention.** Check A/B and installed C after G and S, including probes that also use the shared trunk.

### 02. Certify the whole recovery program — improvement
**Mechanism.** Package planner, word, binding, abort and public log as one kernel over the certified artifact. **Novelty / control.** Standard [post-processing][dp], specialized to service recovery; compare an output-only wrapper and fresh retraining with the same wrapper. **Cheapest first test.** Enumerate two finite artifact laws and their exact pushforwards, then add an erased-record bit to binding selection and exhibit a separating event. **Old-task retention.** Measure unaffected A/B/C in deletion-only and both wrapped arms, counting refusals as failures to serve.

### 03. Make closure improve the service gradient — primitive candidate
**Mechanism.** Use a truthful G that removes an alias-dependent residual in S so the *same service direction* becomes useful for every member, even though the service and nuisance share a trunk. **Novelty / control.** [Multi-learner teaching][teaching] can choose the word; the proposed reusable object is a gate whose entry changes the sign or alignment of another batch's write. Compare best replay after a direct stop-gradient gate and match initial margins. **Cheapest first test.** On a two-feature shared trunk, calculate service gradients for both aliases before and after G; reject if the apparent gain disappears with matched residuals or if replay plus stop-gradient ties the end result at equal access. **Old-task retention.** Check old reads aligned with and opposed to the common service direction, plus installed C.

### 04. Pay for dormancy with C utility — primitive candidate
**Mechanism.** Let G be a required real C acquisition whose gradient both fits that skill and establishes the nuisance invariant, with neither extra samples nor a spare block. **Novelty / control.** Unlike separate recycle-then-train in [continual backprop][cbp], one useful write buys both obligations; compare independently optimized C fit followed by explicit gating plus service. **Cheapest first test.** Pick a tiny successor dataset with alternate equally predictive features; test generalization where the nuisance correlation flips, including a pool where no dual-use G exists. **Old-task retention.** Require the same A/B/C floors before S, so gate purchase cannot be funded by lost old service.

### 05. Certify a gate over combinations no batch sees — improvement
**Mechanism.** Bound nuisance preactivation over a declared polytope using [Reluplex][reluplex] or [DeepPoly][deeppoly], accounting for the S update. **Novelty / control.** A verification application, not new reachability machinery; compare exact activation-cell enumeration and held-out corners. **Cheapest first test.** Give a small network with quiet training points but an active interior point; compare sound refusals with false accepts from sample-only testing. **Old-task retention.** Use the same domain granularity for A/B/C, reporting unsupported cells rather than hiding them in an average.

### 06. Separate function dormancy from update dormancy — primitive candidate
**Mechanism.** Compile G to place both nuisance preactivation and the residual optimizer velocity into a region invariant over S; permit nonzero slots if they cannot wake the path. **Novelty / control.** Related to [#178's optimizer-state splits][slots]; the proposed object is a gate-entry certificate jointly constraining parameters and velocity, not a slot reset. **Cheapest first test.** Propagate two same-weight/different-momentum states through G and S; compare SGD without momentum, explicit slot reset and equal-cost replay. **Old-task retention.** Probe old tasks that benefit from momentum, including after the first ordinary post-binding update.

### 07. Spend gate slack on service updates — primitive candidate
**Mechanism.** Treat the negative preactivation margin as a consumable budget for later writes through shared parameters; after G, admit S only if every prefix leaves slack. **Novelty / control.** [DeepPoly][deeppoly] supplies bounds and [GPM][gpm] constrains writes; the proposed operation explicitly exchanges a *prior truthful write* for more permissible service learning. **Cheapest first test.** Map allowed step sizes for S against exact nuisance bounds in two dimensions; compare projected C-GD at equal C gain and require refusal when G cannot buy slack. **Old-task retention.** Track each protected read's margin at every accepted prefix, not just final accuracy.

### 08. Translate the gate across ReLU symmetries — improvement
**Mechanism.** Name the nuisance by a functional contribution to a read rather than a neuron index, and test the same word on permuted and rescaled implementations. **Novelty / control.** [Git Re-Basin][rebasin] handles permutation and functional equivalence does not generally imply equal SGD dynamics; compare aligned weights and a fixed-index gate. **Cheapest first test.** Try a hidden-unit swap and then positive rescaling that leaves the function unchanged but changes the gradient step. **Old-task retention.** Test the same old inputs across representations; report mismatches after S rather than only checking initial equivalence.

### 09. Keep the gate closed under truthful corrections — primitive candidate
**Mechanism.** Attach to the binding a class of ordinary C corrections under which the service may adapt but the nuisance remains inactive; withdraw service outside that envelope. **Novelty / control.** [#202's switched dynamics][switched] is the stability baseline; here the interface promises safe *edits* to the reopened service. **Cheapest first test.** Enumerate two possible next batches, one preserving and one crossing the gate; compare a static margin bound and freezing the nuisance block. **Old-task retention.** Test unaffected A/B and installed C both after an allowed correction and after refusing a crossing correction.

### 10. Use a gate that moves with the input domain — primitive candidate
**Mechanism.** Find one word that silences a nuisance across several lawful successor domains even if no globally dead unit can be tolerated by old tasks. **Novelty / control.** [PackNet][packnet] partitions parameters; this would retire a read-domain contribution without allocating a per-task mask or sacrificing uses of that unit outside the domain. **Cheapest first test.** Give old and service inputs on opposite sides of a ReLU boundary; require hard nuisance silence on service inputs and report failure if the required domains overlap incompatibly. **Old-task retention.** Evaluate boundary and interior probes on the old side after both batches, with matched initial margins.

### 11. Prove when no gate is possible — improvement
**Mechanism.** Return a certificate that every legal G either misses the inactive region for some alias or crosses an old-task floor. **Novelty / control.** [Reluplex][reluplex] and exact reset-word search already solve tiny feasibility problems; the value is a diagnostic against hidden resets or target leakage. **Cheapest first test.** Enumerate a batch pool whose gradients are orthogonal to a positive nuisance feature, then add one truthful counterexample batch and verify the obstruction vanishes. **Old-task retention.** Exhibit the old-task counterexample for every candidate that moves the gate but fails retention.

### 12. Compile gates with no history-bearing planner state — primitive candidate
**Mechanism.** Produce a reusable service compiler whose only private input is the certified artifact; all pool construction, proof search and binding can be replayed from the allowed inputs. **Novelty / control.** The [post-processing rule][dp] is routine; the research object is a deployable artifact interface that constrains what a useful gate compiler can inspect. Compare a fixed word, certified model-only C fine-tuning and a privileged planner with uncensored state. **Cheapest first test.** Enumerate paired U/R worlds with different raw checkpoints but the same covered view; check that planner outputs have the same law given the view and that at least one useful gate remains. **Old-task retention.** Compare worst-task retention under artifact-only planning and the privileged ceiling.

### 13. Reopen using an API-only artifact — primitive candidate
**Mechanism.** Fit a small exposed service path from independent C examples and allowed API answers without reading hidden slots; demand a separate externally supported gate invariant or make no gate claim. **Novelty / control.** Ordinary distillation is the baseline; the proposed interface couples a query-only recovery to a separately checkable gate obligation, not a certificate inferred from a fitted student. **Cheapest first test.** In a finite black-box world, contrast a public architectural invariant with two identical APIs whose hidden nuisance paths differ. Compare plain allowed-output distillation. **Old-task retention.** Run old API regression queries with the overlay both present and absent.

### 14. Prove that the witness is permitted to exist — improvement
**Mechanism.** Classify a witness by whether its promised service implies a deleted value given public side information; refuse incompatible witnesses even under a valid U/R certificate. **Novelty / control.** Extends the service check from [benign relearning][jog], not the deletion theorem. Compare deletion-only, transformed retrain and an independently reintroduced fact. **Cheapest first test.** Use a two-bit finite world with one retained aggregate and one output which, combined with public metadata, uniquely determines the removed bit. **Old-task retention.** Retain the nonrevealing aggregate and unrelated skills; count refusal of a contradictory witness separately.

### 15. Bind without publishing a history receipt — improvement
**Mechanism.** Emit the same witness API in both arms, with any published proof or handle a function of the covered inputs, not a tag from the original spend. **Novelty / control.** Standard [post-processing][dp]; compare a fixed canonical ID and a receipt-bearing implementation. **Cheapest first test.** Make two states agree on all predictions but diverge by one visible handle or refusal reason; test whether a planted erased-data receipt makes the transformed laws separate. **Old-task retention.** Dereference the unchanged A/B/C handles before and after recovery to detect a broken old interface.

### 16. Budget privacy over repeated handoffs — improvement
**Mechanism.** Carry a release manifest distinguishing repeated views of a single covered state from a new deletion/update that requires a joint guarantee. **Novelty / control.** [Descent-to-Delete][dtd] and [DP composition][dp] are the baselines; avoid falsely composing post-processing as new releases with independent guarantees. **Cheapest first test.** Enumerate three handoffs, first from one covered artifact, then with one unconstrained checkpoint read; show that checking only endpoint marginals misses a joint leak. **Old-task retention.** After each handoff run every previously installed unaffected A/B/C task and report the first failure or refusal.

### 17. Make randomized gate search safe to publish — improvement
**Mechanism.** Sample from a declared C pool with independent randomness and publish the chosen word, proof and attempt count only through the same kernel. **Novelty / control.** [DP post-processing][dp] already covers this; the question is whether practical search can preserve the stated input boundary without a private ranker. **Cheapest first test.** Enumerate seed-to-word outcomes, then substitute a private feasibility oracle as a negative control; compare deterministic selection and private tuning at matched runtime. **Old-task retention.** Include all seeds and aborted searches when reporting worst-task performance and service availability.

### 18. Recover with independent C even when it teaches the same fact — improvement
**Mechanism.** Separate an authorized independent C stream from a stream selected using the deleted record; test the same useful recovery with both under explicit disclosure rules. **Novelty / control.** [Certified removal][guo] is a comparison to retraining, not a guarantee the answer is unknowable; [benign relearning][jog] is the closest empirical control. **Cheapest first test.** Run a finite example where an independent C sample raises absolute reconstruction in both U/R arms; contrast an unallowed C selector whose choice is itself a copy of the removed bit. **Old-task retention.** Check whether an independently relearned skill helps one old task but damages another; report absolute disclosure separately.

### 19. Try to wake the gate without touching it directly — improvement
**Mechanism.** Test whether normal S steps wake the nuisance via trunk drift, normalization statistics, weight decay or optimizer moments despite zero direct gradient. **Novelty / control.** Dormancy in [ReDo][redo] and activation verification in [DeepPoly][deeppoly] supply the diagnostics; compare a frozen-trunk and frozen-stats control. **Cheapest first test.** Construct a shared trunk where the service gradient moves a shared coordinate across the nuisance boundary; distinguish nonzero post-update activation from a stale-cache read. **Old-task retention.** Include old inputs dependent on those same normalization statistics, especially rare boundary cases.

### 20. Trade a reused gate for a fixed storage slot — primitive candidate
**Mechanism.** Use G to make a nuisance carrier unneeded by the public service, then let S serve through an existing active path; reuse the retired carrier only if liveness and later nuisance-inactivity proofs still hold. **Novelty / control.** Builds on [#203's bounded handoffs][linear] and [PackNet][packnet]; the operation must renew capacity through ordinary acquisition, not archive or restore prior carriers. **Cheapest first test.** Run three finite handoffs under one cap, comparing replay plus direct masking and a capped adapter bank; include an old read that prevents retirement. **Old-task retention.** Check every previously installed task at every retirement, including hidden consumers of the nominally dormant carrier.

### 21. Search for a gate and a deletion boundary jointly — primitive candidate
**Mechanism.** Require a *pair* of proofs for the same word and binding: universal inactivity/service over the declared class, and lawful observability of every input the selector and verifier consume under U and R. **Novelty / control.** Combines [activation verification][reluplex] and [certified removal][guo]; the interaction must reject a cheap full-state gate and find a useful legal word whose proof the model-only wrapper alone would miss. Compare verified gate plus plain certified C replay as the strongest stacked control. **Cheapest first test.** Exhaust a tiny pool with three regimes: a legal gated word, a word requiring forbidden history, and an instance with no useful legal word. **Old-task retention.** Verify the same old-task floors over both U/R supports; report explicit fail/refuse cases separately from silent regressions.

### 22. Measure what a closed gate can still disclose — improvement
**Mechanism.** Treat the closed nuisance as a probe surface: final weights, released slots, public certificates and ordinary continuations can reveal differences invisible at the service endpoint. **Novelty / control.** The [parent][parent] already distinguishes witness alignment from privacy; compare endpoint-only attacks with matched transcript access and transformed retraining. **Cheapest first test.** Reuse the sanity check with a weight-release attacker, then limit access to the certified API and show which distinguishing test is no longer available. **Old-task retention.** Keep normal retained-task queries in the attack interface; withholding old service is not a legitimate way to improve the attack result.

## Ranked deeper questions

1. **Can a two-batch word beat explicit gating plus replay when the paths share features?** Start with 01/03/04. Freeze the witness before searching truthful batches; match C gain, retention margin and access. Look for an order-specific G/S interaction that survives comparison to the stacked reset/recycle and replay controls. Reject a witness that only works on a disjoint toy, or a gate that wakes on a promised input.
2. **Is there a useful common word under the actual certified release boundary?** Pair 02/12/21. Audit the planner inputs and push the same kernel over U and R, including refusals and proofs. Ask what service is lost when forbidden slots and receipts are removed, and compare to plain certified replay. Include absolute membership/reconstruction tests rather than treating inheritance as an empirical disclosure certificate.
3. **What breaks first when the service receives a normal correction?** Use 06/07/09/19 to distinguish optimizer carryover, shared-trunk drift and insufficient gate slack. Contrast an impossible gate, a one-step success that reactivates immediately, and a durable gate at matched A/B/C utility.
4. **Can the useful but nonrevealing service repeat inside one fixed cap?** Combine 14/16/20. Give the learner one permitted witness and one which necessarily outs the deleted value. Compare three spends against capped replay plus fixed gating, and check that certificate and binding storage do not grow or contain the old receipt.
