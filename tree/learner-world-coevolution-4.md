# Learner–world co-evolution (depth 3): world-redundancy weight protection & pinning-budget plasticity control

Child node (depth 3) of [PR #365](https://github.com/manojbajaj95/cl/pull/365) (`L3W12` + `L3W24`) · 26 candidate primitives · Ideas only; no experiments run

**Parent triage.** In `reviews/flood-triage.md` (latest row, PR #365 / `tree/learner-world-coevolution-3.md`), two score-3 primitives were kept:
1. **`L3W12` — protect weights in proportion to missing external guards:** set consolidation stiffness on the prevention subspace (EWC, OGD, or adapter freeze) from measured external guard readiness $g_t(F)$—high when downstream guards are gone, relaxed as they re-arm—so parameter importance comes from the *world's redundancy* rather than internal Fisher information alone.
2. **`L3W24` — cap world-induced plasticity loss with a pinning budget:** if each prevented failure strips an external guard and each stripped guard pins an internal subspace, a long-lived learner ossifies; keep a global pinning budget and spend it on re-arming the cheapest external guards (with `L3W14` friction) instead of pinning more weights, making plasticity loss caused by the world a measured, governed quantity.

**Why this node is primitive-level (and not a repackaging of EWC or shrink-and-perturb).** Classical continual-learning consolidation (EWC, OGD, null-space projection) computes parameter importance strictly from *internal* loss curvature (Fisher / Hessian / activation SVD), assuming the world's safety redundancy is static. Classical plasticity-loss work (continual backpropagation, shrink-and-perturb, spectral clipping, partial resets) treats loss of plasticity as an *intrinsic optimization pathology* (dormant units, spectral collapse, weight growth). Under learner–world co-evolution, both assumptions fail: (i) parameter importance is *exogenously modulated* by whether external human/tool guards still exist, and (ii) a learner can suffer *co-evolutionary ossification* even with perfectly conditioned weights, simply because its own competence stripped external guards and forced internal pinning—while naive weight resets would immediately un-suppress those failures.

## Section A · World-redundancy-proportional weight protection (`L4W01`–`L4W09`, deepening `L3W12`)

### L4W01 · Uncertainty-pessimistic Fisher-redundancy product
- **Mechanism:** Plugging a noisy decoy estimate $\hat{g}_t(F)$ directly into `L3W12`'s stiffness $\lambda_F = \lambda_0 (1 - \hat{g}_t(F))$ risks under-protecting weights whenever sparse decoys overestimate guard readiness. Set effective consolidation importance to $\Omega_{\text{eff}} = \sum_F (1 - \underline{g}_t(F))^\gamma \mathcal{F}_F$, where $\underline{g}_t(F)$ is the lower confidence bound on external guard readiness (fast to drop on a single missed decoy, slow to rise until multiple decoys pass).
- **Nearest prior / gap:** [Elastic Weight Consolidation Done Right](https://arxiv.org/abs/2603.18596) and [Fisher-Shaped EWC](https://arxiv.org/abs/2610.37145) refine internal Fisher estimation $\mathcal{F}_F$ but treat task importance as certain and world-independent. Weighting $\mathcal{F}_F$ by a *lower confidence bound* on external guard redundancy couples epistemic guard uncertainty directly into parameter consolidation.
- **Cheapest first test:** 4-failure continual world where external guard readiness is estimated from noisy low-rate decoys ($\le 1\%$ rate) and new tasks $C, D$ conflict with prevention subspaces. Compare Fisher-only EWC, fixed freeze, binary `L2W22`, plug-in `L3W12`, and LCB-weighted `L4W01` across endogenous and exogenous guard loss. Kill if plug-in `L3W12` or Fisher-only EWC achieves equal zero-escape prevention and $C/D$ accuracy under noisy decoys.
- **Old-task retention:** Verify zero unguarded $F$-escapes during $C, D$ training and full $A/B$ retention once guards re-arm.

### L4W02 · Soft-nullspace OGD with readiness-modulated projection gain
- **Mechanism:** Standard OGD and null-space projection (`2602.21919`, `2508.17169`) apply a *hard* binary projection $g_{\text{upd}} = (I - P_F) g$, permanently burning subspace dimensions even when external guards are intact. Replace binary projection with a continuous readiness-modulated projection $g_{\text{upd}} = (I - (1 - g_t(F)) P_F) g$: when $g_t \to 0$, gradients are strictly orthogonalized against $V_F$; as external guards re-arm ($g_t \to 1$), gradient components along $V_F$ pass freely to support new tasks $C, D$.
- **Nearest prior / gap:** [Learning in the Null Space](https://arxiv.org/abs/2602.21919), [ONG](https://arxiv.org/abs/2508.17169), and [Muon-OGD](https://arxiv.org/abs/2605.08949) vary projection thresholds by singular value magnitude (internal geometry), never by live external guard readiness $g_t(F)$.
- **Cheapest first test:** Linear-probe and 2-layer MLP stream with 8 sequential tasks where 4 failure-prevention subspaces overlap task $C$'s gradient and external guards toggle between $g_t=0$ and $g_t=1$. Compare hard OGD, Fisher EWC, fixed freeze, binary `L2W22`, and soft-nullspace `L4W02`. Kill if hard OGD or EWC with tuned scalar $\lambda$ matches both $C$ convergence speed (when $g_t=1$) and $F$-prevention (when $g_t=0$).
- **Old-task retention:** Measure $F$-prevention error during $g_t=0$ phases, $C/D$ learning speed during $g_t=1$ phases, and old-task $A/B$ accuracy across both.

### L4W03 · Guard-conditioned anchor-point re-anchoring (breaking EWC's stale-anchor trap)
- **Mechanism:** Classical EWC anchors weights to a frozen historical point $\theta^*_F$. Under `L3W12`, if $g_t(F)$ rises to $1.0$ (relaxing stiffness so the learner adapts to new task $C$ at $\theta_{\text{new}}$) and later drops back to $0.0$, re-activating stiffness around the *stale* anchor $\theta^*_F$ pulls weights backward and catastrophically destroys $C$. Whenever $g_t(F)$ transitions downward, verify whether $\theta_t$ still prevents $F$; if so, re-anchor $\theta^*_F \leftarrow \theta_t$ (updating $\mathcal{F}_F$ locally) before raising stiffness.
- **Nearest prior / gap:** [Improved EWC as an Optimization Constraint](https://arxiv.org/abs/2611.16039) enforces fixed-anchor constraints; online EWC decays old Fisher terms monotonically. Neither handles *non-monotonic* stiffness cycling caused by external guards dropping, re-arming, and dropping again.
- **Cheapest first test:** Cyclic-guard world ($g_t: 0 \to 1 \to 0$) where task $C$ is learned during the $g_t=1$ window without breaking $F$-prevention, followed by task $D$ during the second $g_t=0$ window. Compare stale-anchor `L3W12`, Fisher EWC, fixed freeze, and re-anchored `L4W03`. Kill if stale-anchor `L3W12` retains $C$ equally well after the second $g_t \to 0$ transition.
- **Old-task retention:** Verify $C$ is not erased when $F$-stiffness re-engages, while $F$-prevention and $A/B$ accuracy stay above floor during $D$.

### L4W04 · Endogenous-vs-exogenous guard-loss causal stiffness router
- **Mechanism:** External guards disappear for two distinct reasons: *endogenous* (removed by users/tools because the learner's own prevention induced complacency) vs. *exogenous* (removed for outside reasons, e.g. upstream library deprecation or budget cuts). Classify each guard drop via staggered-cohort / counterfactual attribution (`L3W11`): route endogenous drops to *temporary* `L3W12` stiffness paired with `L3W24` re-arming spend, and route exogenous drops to *permanent* internal consolidation (or capacity growth `L4W14`) so re-arming friction is never wasted on an un-rearmable guard.
- **Nearest prior / gap:** Row 504 explicitly requires distinguishing learner-caused vs. outside-caused guard removal. [DRAP](https://arxiv.org/abs/2611.05029) adapts plasticity to environment dynamics risk without distinguishing whether the learner caused the risk or can reverse it.
- **Cheapest first test:** Mixed world with 4 endogenously dropped guards (restorable via friction) and 4 exogenously deleted guards (non-restorable). Compare causal-routed `L4W04`, undifferentiated `L3W12`, `L3W14` friction-on-all, Fisher EWC, and `RCX5`. Kill if undifferentiated `L3W12 + L3W14` achieves the same new-task speed and friction overhead without causal classification.
- **Old-task retention:** Verify 100% prevention on both endogenous and exogenous failures, zero wasted friction on exogenous ones, and preserved $C/D$ plasticity.

### L4W05 · Severity-stratified spectral stiffness (direction-level redundancy)
- **Mechanism:** A single failure class $F$ often has a coarse external guard that catches catastrophic tails ($g_t^{\text{severe}} \approx 1$) while missing subtle mild variants ($g_t^{\text{mild}} \approx 0$), or vice versa. Decompose the prevention subspace $V_F$ by severity strata and assign per-direction stiffness $\lambda_{F,k} = \sigma_k \cdot s_k \cdot (1 - g_t(F, k))$, keeping directions whose specific severity tail is still externally guarded completely plastic.
- **Nearest prior / gap:** [Layer-Adaptive CL Regularization](https://arxiv.org/abs/2608.15901) adapts stiffness by network depth; [SPACE-LoRA](https://arxiv.org/abs/2609.34453) allocates subspace protection by internal activation energy. Neither stratifies subspace stiffness by *which severity tail the external guard still covers*.
- **Cheapest first test:** Two-tail failure world (mild vs. severe $F$) where the external guard drops mild checks ($g_t^{\text{mild}}=0$) but keeps a hard severe-tail circuit breaker ($g_t^{\text{severe}}=1$), while new task $C$ overlaps the severe-tail direction. Compare scalar `L3W12`, Fisher EWC, fixed freeze, and direction-stratified `L4W05`. Kill if scalar `L3W12` matches $C$-learning speed without increasing mild or severe escapes.
- **Old-task retention:** Verify zero mild escapes, zero severe escapes (via external breaker), and higher $C$ accuracy with intact $A/B$.

### L4W06 · Hysteretic asymmetric-rate stiffness controller (anti-guard-flapping)
- **Mechanism:** If a noisy external guard oscillates near a threshold ($g_t$ flapping between $0.2$ and $0.8$), instantaneously tracking $1 - g_t$ causes stiffness to pulse on and off, repeatedly leaking gradient updates into $V_F$ during brief false-high spikes. Apply a hysteretic asymmetric filter: stiffness ramps *up* immediately on any $g_t$ drop ($\tau_{\text{attack}} = 1$ step) and relaxes *down* only after $g_t$ stays above an upper threshold for $K$ consecutive decoy checks ($\tau_{\text{release}} \gg \tau_{\text{attack}}$).
- **Nearest prior / gap:** [The Handover Problem](https://arxiv.org/abs/2610.10352) warns against rapid autonomy oscillations in human-AI control; applying asymmetric attack/release hysteresis specifically to continual-learning weight consolidation prevents flapping-induced forgetting.
- **Cheapest first test:** Flapping-guard simulator where $g_t$ oscillates with period 5 steps while task $C$ trains continuously. Compare instantaneous `L3W12`, binary `L2W22`, Fisher EWC, and hysteretic `L4W06`. Kill if instantaneous `L3W12` with simple moving-average smoothing of $g_t$ achieves equal zero-escape prevention and $C$ speed.
- **Old-task retention:** Verify zero $F$-forgetting during flapping windows and full stiffness release (recovering $C$ speed) once $g_t$ genuinely stabilizes at $1.0$.

### L4W07 · Shared-subspace conflict arbitration across multi-guard failures
- **Mechanism:** When two failure preventions $F_1, F_2$ share an overlapping parameter direction $v$, with $g_t(F_1) = 1.0$ (guarded) and $g_t(F_2) = 0.0$ (unguarded), additive stiffness $\sum_F (1-g_t(F))\mathcal{F}_F$ over-stiffens directions where multiple guarded failures sum up, while per-failure unfreezing risks unprotecting $v$ for $F_2$. Arbitrate shared directions via a spectral envelope $\Omega_{\text{env}} = \max_F^{\text{psd}} \big((1 - g_t(F)) \mathcal{F}_F\big)$ (Loewner upper bound / per-eigenmode max), protecting shared directions at the highest missing-guard need while keeping $F_1$-exclusive directions fully free.
- **Nearest prior / gap:** Standard multi-task EWC sums Fisher matrices linearly ($\sum_i \mathcal{F}_i$), causing monotonic stiffness accumulation across tasks. Using a readiness-weighted *max-envelope* over overlapping prevention subspaces prevents additive ossification while guaranteeing the unguarded failure $F_2$ stays protected.
- **Cheapest first test:** 6-failure world with 50% pairwise subspace overlap where 4 guards remain intact ($g_t=0.9$) and 2 drop ($g_t=0.0$). Compare additive `L3W12`, Fisher-sum EWC, fixed freeze, and max-envelope `L4W07`. Kill if additive `L3W12` matches $C$-plasticity and $F_2$-retention at equal total stiffness norm.
- **Old-task retention:** Verify zero $F_2$ escapes, intact $A/B$ accuracy, and strictly faster $C/D$ convergence on $F_1$-only directions.

### L4W08 · Shadow recovery-witness for relaxed prevention subspaces
- **Mechanism:** When an external guard re-arms ($g_t(F) \to 1$) and `L3W12` relaxes stiffness on $V_F$, subsequent training on task $C$ may legitimately overwrite $F$-prevention in the weights (because the world now catches $F$). Keep a tiny compressed *shadow witness* (4–8 failure trigger–recovery pairs from `LW02`) tagged to $F$; if $g_t(F)$ later begins to dip, immediately test the live weights against the witness—and if $F$ was overwritten, trigger fast micro-rehearsal *before* re-stiffening, so `L3W12` never freezes a broken prevention subspace.
- **Nearest prior / gap:** `L3W12` alone assumes re-stiffening restores protection, which fails if weights drifted during the unpinned window. Pairing stiffness relaxation with a dormant witness closes the unpin-overwrite-repin failure mode.
- **Cheapest first test:** World where $g_t(F)$ goes $0 \to 1$ (task $C$ overwrites $F$ in weights) $\to 0.3$ (guard begins decaying again). Compare `L3W12` alone, fixed freeze, Fisher EWC, and shadow-witness `L4W08` (at equal total memory). Kill if `L3W12` alone without witness re-testing avoids freezing broken weights or matches recovery speed.
- **Old-task retention:** Verify $F$-prevention is restored *before* $g_t$ reaches 0, without losing $C$ or $A/B$.

### L4W09 · Redundancy-aware LoRA rank shedding & reclamation
- **Mechanism:** In modular continual learning, represent each prevention behavior as a dedicated low-rank adapter $A_F B_F$ whose active rank $r_F(t) = \lceil r_{\max}(1 - g_t(F)) \rceil$ scales continuously with missing external redundancy. As external guards re-arm ($g_t \to 1$), shed the trailing singular components of $A_F B_F$ and recycle those rank slots directly into the plastic adapter pool available for new tasks $C, D$.
- **Nearest prior / gap:** [SPACE-LoRA](https://arxiv.org/abs/2609.34453) allocates static activation-subspace protection across LoRA adapters without reclaiming rank when external world redundancy returns. Rank shedding turns external guard re-arming into immediate, exact parameter-budget reclamation.
- **Cheapest first test:** Fixed total LoRA rank budget $R = 16$ across 8 sequential tasks + 6 guard-shifting failures. Compare static `SPACE-LoRA`, fixed-rank adapter freeze, Fisher EWC, and rank-shedding `L4W09`. Kill if static `SPACE-LoRA` or EWC achieves the same task-8 accuracy and $F$-prevention under the $R=16$ rank cap.
- **Old-task retention:** Verify zero $F$-escapes while $g_t=0$, reclaimed rank speeds up tasks 5–8, and old tasks $A/B$ stay within floor.

## Section B · Capping world-induced plasticity loss with a pinning budget (`L4W10`–`L4W18`, deepening `L3W24`)

### L4W10 · Effective pinned-dimension meter (measuring world-caused ossification)
- **Mechanism:** Counting the number of pinned failures $|S_{\text{pin}}|$ mismeasures plasticity loss because 10 failures sharing a 2-D invariant cost far less capacity than 2 orthogonal high-rank failures. Define the *world-induced plasticity consumption* at layer $\ell$ as $P_{\text{world}}(\ell) = \text{EffRank}\!\left(\sum_F (1 - g_t(F)) \mathcal{F}_{F,\ell}\right) / d_\ell \in [0, 1]$, and trigger `L3W24`'s pinning budget $B_{\text{pin}}$ strictly on $P_{\text{world}}$ rather than raw pin count.
- **Nearest prior / gap:** [Barriers for Learning in an Evolving World](https://arxiv.org/abs/2510.00304) and [Spectral Collapse](https://arxiv.org/abs/2509.22335) measure *intrinsic* effective rank collapse of hidden features. `L4W10` defines the orthogonal *extrinsic* quantity: effective rank locked away by missing external guards.
- **Cheapest first test:** Long stream with 20 guard-removal events (half sharing a low-rank subspace, half orthogonal) under a fixed budget threshold. Compare raw-count `L3W24`, unbounded `L3W12`, shrink-and-perturb, and effective-rank-metered `L4W10`. Kill if raw pin-count budgeting achieves the same new-task learning speed and friction spend on mixed correlated/orthogonal streams.
- **Old-task retention:** Verify new-task learning velocity stays above floor across all 20 events while all unguarded failures remain prevented.

### L4W11 · Marginal plasticity-per-rearming-cost knapsack allocator
- **Mechanism:** When $P_{\text{world}}$ exceeds the pinning budget $B_{\text{pin}}$, different external guards have vastly different re-arming costs $\kappa_F$ (re-enabling a deterministic regex/schema validator costs $\approx 0$; retraining human reviewers via friction costs high UX debt) and free different amounts of effective rank $\Delta P_{\text{world}}(F)$. Solve the marginal knapsack $\arg\max_F \Delta P_{\text{world}}(F) / \kappa_F$ to re-arm the highest plasticity-per-cost guards first instead of FIFO or uniform friction.
- **Nearest prior / gap:** [Careful Judge](https://arxiv.org/abs/2610.09043) optimizes human review cost per prevented unsafe decision; `L4W11` optimizes external guard re-arming cost per *unit of recovered continual-learning plasticity*.
- **Cheapest first test:** 15-failure long stream with heterogeneous guards (5 cheap software guards, 5 medium-cost human checklists, 5 expensive specialist audits) and heterogeneous subspace ranks. Compare FIFO `L3W24`, uniform `L3W14` friction, unbounded `L3W12`, shrink-and-perturb, and knapsack `L4W11`. Kill if FIFO or uniform friction matches the plasticity-vs-friction Pareto curve.
- **Old-task retention:** Verify zero unguarded failure escapes, lower total re-arming cost, and sustained new-task learning speed across tasks $T_1 \dots T_{20}$.

### L4W12 · Guard-exempt shrink-and-perturb & continual backpropagation
- **Mechanism:** Classical plasticity-loss fixes—shrink-and-perturb, [Continual Backpropagation](https://arxiv.org/abs/2306.13812), [Calibrated Partial Resets](https://arxiv.org/abs/2607.24996), and [Load Balancing Neurons](https://arxiv.org/abs/2611.32691)—reinitialize low-utility weights or shrink all weights toward zero. In a co-evolving world, they catastrophically erase *pinned* preventions whose external guards are gone (causing immediate un-suppression shock!). Project every shrink/perturb/reset operator onto the *orthogonal complement* $(I - P_{\text{pin}})$ of active high-$(1-g_t)$ prevention subspaces so intrinsic plasticity is restored strictly in unpinned capacity.
- **Nearest prior / gap:** [Reinitializing Weights vs Units](https://arxiv.org/abs/2508.00212) and [Calibrated Partial Resets](https://arxiv.org/abs/2607.24996) protect high-utility *current-task* units; self-suppressed preventions have *zero* live gradient utility because the failure no longer appears in the stream, so standard utility-based resets destroy them first! Guard-exempt projection fixes that exact blind spot.
- **Cheapest first test:** 30-task non-stationary stream with both dormant-unit plasticity loss *and* 6 self-suppressed failures with stripped external guards. Compare naive shrink-and-perturb, Continual Backpropagation (`2306.13812`), unbounded `L3W12`, no pinning, and guard-exempt `L4W12`. Kill if Continual Backpropagation or naive shrink-and-perturb preserves all 6 self-suppressed preventions without guard-exempt projection.
- **Old-task retention:** Verify zero un-suppression of all 6 self-suppressed failures across 30 tasks *and* sustained plasticity matching unconstrained continual backprop on tasks 20–30.

### L4W13 · Pinning-compression distillation (consolidating fragmented pins internally)
- **Mechanism:** Sequential guard removals over 20 tasks pin 20 separate, slightly rotated prevention subspaces, exhausting $B_{\text{pin}}$ even when the underlying safety behaviors could live in a much smaller joint subspace. Before paying external human friction to re-arm guards, run an offline *pinning-compression pass*: distill the active pinned prevention behaviors into a single compact low-rank subspace $V_{\text{core}}$ (using stored `LW02` trigger witnesses) and release the fragmented legacy pins, freeing pinning budget internally.
- **Nearest prior / gap:** Distinct from `L3W24`'s external re-arming and from replay compression: it tests how much world-induced ossification can be reclaimed *purely internally* before external world intervention is necessary.
- **Cheapest first test:** 12-failure stream whose preventions share a 3-D latent safety invariant but arrive sequentially across tasks. Compare `L3W24` (re-arming only), unbounded `L3W12`, shrink-and-perturb, and compression-first `L4W13` (compress before re-arming). Kill if `L3W24` without compression achieves equal plasticity at equal external friction cost.
- **Old-task retention:** Verify all 12 preventions hold after compression (tested on trigger witnesses), $P_{\text{world}}$ drops below $B_{\text{pin}}$, and $A/B$ utility is preserved.

### L4W14 · Exogenous-pinning-triggered elastic capacity growth
- **Mechanism:** Growing/elastic networks (`2608.01475`) expand capacity whenever loss stalls, which bloats model size indefinitely if every complacently dropped guard triggers growth. Couple elastic growth strictly to `L4W04` + `L3W24`: *never* grow capacity for endogenously dropped guards (re-arm them via `L3W24`), and allocate new neurons/adapters *only* when irreducible *exogenously* lost guards push $P_{\text{world}}$ past $B_{\text{pin}}$.
- **Nearest prior / gap:** [Plasticity of Growing and Elastic Neural Networks](https://arxiv.org/abs/2608.01475) grows based on internal training-error heuristics; gating structural growth on *non-rearmable external guard loss* prevents unbounded parameter bloat while guaranteeing plasticity when the world permanently removes safety infrastructure.
- **Cheapest first test:** Long stream with 8 endogenous guard drops (re-armable) and 4 permanent exogenous guard deletions. Compare always-grow elastic network (`2608.01475`), fixed-size `L3W24`, unbounded `L3W12`, and exogenous-gated `L4W14`. Kill if fixed-size `L3W24` maintains equal new-task speed after all 4 exogenous deletions, or if always-grow matches parameter efficiency.
- **Old-task retention:** Verify bounded parameter count (growth only on the 4 exogenous events), zero unguarded escapes, and sustained new-task plasticity.

### L4W15 · Prospective pinning-debt pricing at prevention-admission time
- **Mechanism:** Learning to prevent a new low-severity failure $F_{\text{new}}$ is not free if succeeding at $F_{\text{new}}$ will cause downstream teams to delete their own checker, permanently taxing the learner's pinning budget $B_{\text{pin}}$. Before committing a new prevention update, price its expected *co-evolutionary pinning debt* $\text{Debt}(F_{\text{new}}) = \text{rank}(V_{F_{\text{new}}}) \cdot \mathbb{P}(\text{guard drops} \mid \text{prevented})$. If remaining budget cannot absorb the debt, either decline full suppression (keep a bounded rate so external guards stay active, cf. `2607.21547`) or require a co-signed guard-retention contract before deploying.
- **Nearest prior / gap:** [The Boundaries of Automation](https://arxiv.org/abs/2607.21547) argues theoretically for persistent human participation; `L4W15` operationalizes that boundary as a *prospective continual-learning admission price* against a finite plasticity budget.
- **Cheapest first test:** Stream of 10 candidate preventions (5 high-value, 5 low-value/high-rank that trigger fast downstream guard deletion) under a tight $B_{\text{pin}}$. Compare greedy-prevent-all + `L3W24`, unbounded `L3W12`, and debt-priced admission `L4W15`. Kill if greedy-prevent-all + post-hoc `L3W24` achieves higher cumulative utility across all tasks and safety events.
- **Old-task retention:** Verify high-value preventions never lose budget to low-value high-rank preventions, and old tasks $A/B$ remain intact.

### L4W16 · Intrinsic-spectral-collapse vs. extrinsic-pinning diagnostic separator
- **Mechanism:** When new-task learning speed $\dot{\mathcal{L}}_C$ slows down in a long-lived continual learner, the cause could be *intrinsic* optimization pathology (spectral collapse `2509.22335`, dormant neurons `2611.32691`) OR *extrinsic* world-induced pinning (`L3W24`). Decompose each new-task gradient step into (i) norm lost inside the unpinned subspace (intrinsic rank deficiency) vs. (ii) norm blocked by active $(1-g_t)$ pins (extrinsic pin blockage). Route to [SingularClip](https://arxiv.org/abs/2608.18319) / guard-exempt resets (`L4W12`) when (i) dominates, and to external guard re-arming (`L3W24`) when (ii) dominates.
- **Nearest prior / gap:** [SingularClip](https://arxiv.org/abs/2608.18319) and [Can Scale Save Us From Plasticity Loss](https://arxiv.org/abs/2606.24752) diagnose only intrinsic spectrum/rank decay; `L4W16` provides the orthogonal attribution test between intrinsic and world-induced plasticity loss.
- **Cheapest first test:** 2×2 world crossing {intrinsic spectral collapse present/absent} × {heavy guard pinning present/absent}. Compare `SingularClip` alone, `L3W24` alone, both always-on, and diagnostic-routed `L4W16`. Kill if running `SingularClip` + `L3W24` blindly matches `L4W16` at equal friction and compute cost across all 4 cells.
- **Old-task retention:** Verify fast $C$-recovery in all 4 cells without unnecessary external friction (when collapse is intrinsic) or un-suppressed failures (when collapse is extrinsic).

### L4W17 · Time-bounded pinning leases with mandatory renewal
- **Mechanism:** Even if a failure mode $F$ becomes genuinely obsolete in the world, a missing external guard leaves its internal pin locked forever, leaking plasticity permanently. Attach a finite *pinning lease* $\tau_F$ to every active pin: upon lease expiry, run a lightweight extinction/re-arming probe; renew the pin from $B_{\text{pin}}$ only if $F$ is still live *and* external guards remain absent, otherwise expire the pin and reclaim the subspace.
- **Nearest prior / gap:** Combines `LW02`'s obsolescence check with `L3W24`'s finite pinning budget, preventing "zombie pins" from fossilizing a long-lived continual learner.
- **Cheapest first test:** 25-task stream where 8 pinned failures become truly obsolete mid-stream (world stops generating their triggers) while 4 remain live. Compare permanent `L3W12`, `L3W24` without leases, shrink-and-perturb, and leased `L4W17`. Kill if `L3W24` without leases reclaims obsolete-failure capacity equally fast without un-suppressing the 4 live failures.
- **Old-task retention:** Verify zero escapes on the 4 live failures, reclaimed plasticity from the 8 obsolete ones, and intact $A/B$ tasks.

### L4W18 · Dual-variable (Lagrangian) plasticity-floor shadow-price controller
- **Mechanism:** A hard static pinning budget $B_{\text{pin}}$ is arbitrary across architectures and task difficulties. Instead, enforce a *new-task learning-velocity floor* $v_C \ge v_{\min}$ via a dual shadow price $\mu_t \ge 0$ updated online: $\mu_{t+1} = [\mu_t + \eta(v_{\min} - v_C)]_+$. Every pinned failure pays rent $\mu_t \cdot \text{rank}(V_F)$ in the joint objective; as $\mu_t$ rises, re-arming guards whose cost $\kappa_F < \mu_t \cdot \text{rank}(V_F)$ triggers automatically without hand-tuning $B_{\text{pin}}$.
- **Nearest prior / gap:** Converts `L3W24`'s static budget cap into an adaptive Lagrangian price of plasticity, directly linking measured continual-learning slowdown to external re-arming expenditure.
- **Cheapest first test:** Stream with shifting task difficulty (easy tasks tolerate 70% pinned rank; hard tasks stall at 30% pinned rank). Compare fixed-$B_{\text{pin}}$ `L3W24` (tuned at 30% or 70%), unbounded `L3W12`, shrink-and-perturb, and dual-price `L4W18`. Kill if a single fixed $B_{\text{pin}}$ matches `L4W18` across both easy and hard task phases without over-spending friction or stalling.
- **Old-task retention:** Verify $v_C \ge v_{\min}$ across both phases, zero unguarded escapes, and preserved $A/B$ accuracy.

## Section C · Joint `L3W12 × L3W24` primitives: coupled stiffness, budget & world-redundancy dynamics (`L4W19`–`L4W26`)

### L4W19 · Pre-emptive stiffness-to-rearming feedback law (joint optimal control)
- **Mechanism:** Running `L3W12` and `L3W24` independently waits until $g_t(F) \to 0$ (full complacency, maximum stiffness, budget hit) before spending re-arming effort—when human skills have already atrophied (`2609.38459`) and re-arming is most expensive. Couple them in a continuous control law: as soon as $g_t(F)$ dips below $g_{\text{warn}}$ *and* the plasticity shadow price $\mu_t$ is positive, apply gentle preventive maintenance (low-dose friction / micro-handover) to keep $g_t \in [0.5, 0.8]$, avoiding both full pinning and expensive cold re-arming.
- **Nearest prior / gap:** [Maintaining Human Verification Capacity](https://arxiv.org/abs/2609.38459) and [Adaptive Complementarity](https://arxiv.org/abs/2609.07001) model skill decay as nonlinear (cheap to maintain, costly to rebuild). Coupling that nonlinearity to `L3W12`'s continuous stiffness and `L3W24`'s shadow price $\mu_t$ creates a strict advantage over reactive threshold budgeting.
- **Cheapest first test:** Nonlinear guard-atrophy simulator where maintaining $g_t \ge 0.5$ costs $1\times$ friction while rebuilding from $g_t = 0$ costs $5\times$ friction. Compare independent `L3W12 + L3W24` (reactive), `L3W14` friction alone, unbounded `L3W12`, and pre-emptive `L4W19`. Kill if reactive `L3W12 + L3W24` achieves the same total friction + plasticity loss over 50 steps.
- **Old-task retention:** Measure total friction, new-task learning speed, zero unguarded escapes, and $A/B$ retention over 50 steps.

### L4W20 · Task-demand-driven selective re-arming (unpin only what blocks task $C$)
- **Mechanism:** Not every pinned subspace hurts the *current* new task $C$: a pinned prevention $V_{F_1}$ orthogonal to $\nabla \mathcal{L}_C$ imposes *zero* real plasticity loss on $C$, whereas a pinned $V_{F_2}$ with high cosine alignment $|\langle \nabla \mathcal{L}_C, V_{F_2} \rangle|$ directly stalls $C$. Spend `L3W24`'s re-arming budget *exclusively* on pins with high gradient conflict against the active task stream, leaving non-conflicting pins cheaply protected by `L3W12` at zero human friction.
- **Nearest prior / gap:** `L3W24` alone triggers re-arming from aggregate pinned capacity; `L4W20` conditions re-arming on *live gradient interference* with incoming tasks, cutting external friction dramatically when most pins are benignly orthogonal.
- **Cheapest first test:** 10-pin world where only 2 pinned subspaces collide with incoming task $C$'s gradients and 8 are orthogonal. Compare aggregate-budget `L3W24`, `L4W11` static knapsack, unbounded `L3W12`, shrink-and-perturb, and conflict-driven `L4W20`. Kill if aggregate `L3W24` or static knapsack matches $C$-learning speed at equal human friction spend.
- **Old-task retention:** Verify all 10 preventions remain safe (8 via `L3W12`, 2 via re-armed guards), $C$ learns at near-unconstrained speed, and $A/B$ stay intact.

### L4W21 · Escrow-gated stiffness release during guard re-arming
- **Mechanism:** When `L3W24` spends budget to re-arm guard $F$ so task $C$ can use subspace $V_F$, releasing `L3W12` stiffness immediately—before the external guard actually re-arms—creates a *transitional vulnerability window* where $F$ is neither internally pinned nor externally guarded. Hold `L3W12` stiffness in *escrow* until decoy heartbeats confirm $g_t(F) \ge g_{\text{target}}$ on two consecutive checks, ramping stiffness down smoothly only in lockstep with verified guard recovery.
- **Nearest prior / gap:** [The Handover Problem](https://arxiv.org/abs/2610.10352) identifies transition gaps during autonomy shifts; escrow gating makes the `L3W24` $\to$ `L3W12` handoff provably gap-free during continual updates.
- **Cheapest first test:** World with a 10-step lag between issuing a re-arming request and actual external guard activation while task $C$ trains continuously. Compare instant-release `L3W12 + L3W24`, fixed-delay wait, unbounded `L3W12`, and escrow-gated `L4W21`. Kill if a simple fixed-delay timer matches `L4W21` when re-arming latency varies across guards (2–20 steps).
- **Old-task retention:** Verify zero transitional $F$-escapes during variable-latency re-arming, with minimal delay to $C$-convergence and intact $A/B$.

### L4W22 · Correlated human-attention-pool budgeting (preventing simultaneous guard collapse)
- **Mechanism:** Multiple pinned failures often rely on the *same* human oversight pool (e.g. one on-call team or PR reviewer group, cf. `2603.14225`, `2610.27801`). If `L3W24` tries to re-arm 5 failures sharing one human pool simultaneously, cognitive overload causes *all 5 guards to collapse together*, spiking `L3W12` stiffness across all 5 subspaces at once. Model shared external attention capacity $A_{\text{pool}}$ as a coupled constraint in `L3W24`, staggering re-arming across independent guard pools (automated checkers vs. distinct human teams) and keeping excess failures internally pinned when a pool is saturated.
- **Nearest prior / gap:** ["I'm Not Reading All of That"](https://arxiv.org/abs/2603.14225) and [AI Agents Push Humans Out of the Loop](https://arxiv.org/abs/2608.23642) document cognitive overload in human oversight. Modeling shared attention pools inside `L3W24` prevents re-arming actions from *causing* the very guard collapse they aim to cure.
- **Cheapest first test:** Simulator with 6 failures sharing 1 finite-capacity human reviewer pool (which saturates and drops to $g_t=0$ if $>2$ failures demand active friction concurrently) plus 2 independent software guards. Compare pool-unaware `L3W24`, `L3W14` friction alone, unbounded `L3W12`, and attention-pool-aware `L4W22`. Kill if pool-unaware `L3W24` avoids overload collapse equally well.
- **Old-task retention:** Verify zero overload-induced multi-guard collapse, higher sustained $C$-plasticity, and full $A/B$ retention.

### L4W23 · Interior shared-responsibility equilibrium (hybrid stiffness–guard floor)
- **Mechanism:** Operating at the extremes—either $g_t = 0$ (learner bears 100% stiffness, high ossification) or $g_t = 1$ (external guard bears 100%, high friction)—is suboptimal when total escape risk is multiplicative: $R_{\text{escape}}(F) = (1 - p_{\text{learner}}(\lambda_F)) \cdot (1 - g_t(F)) \le \epsilon$. Optimize the interior pair $(\lambda_F^*, g_t^*)$ that minimizes `plasticity_loss`$(\lambda_F) + \text{friction\_cost}(g_t)$ subject to the joint escape cap $\epsilon$, letting moderate `L3W12` stiffness and moderate external guard readiness share the load.
- **Nearest prior / gap:** [Adaptive Complementarity](https://arxiv.org/abs/2609.07001) and [Careful Judge](https://arxiv.org/abs/2610.09043) study static or decision-level complementarity; `L4W23` extends complementarity into *weight-space consolidation*, trading partial forgetting against partial external vigilance.
- **Cheapest first test:** Convex cost world where both stiffness-induced plasticity loss and friction-induced human cost are superlinear near 100%, with escape cap $\epsilon = 0.01$. Compare 100%-pinned `L3W12`, 100%-rearmed `L3W24`, binary `L2W22`, and interior-equilibrium `L4W23`. Kill if either corner solution (100% pinned or 100% re-armed) achieves equal or lower total plasticity + friction cost at $\epsilon = 0.01$.
- **Old-task retention:** Verify empirical escape rate stays $\le \epsilon$ across 20 tasks while strictly improving joint $C$-learning speed + friction cost and preserving $A/B$.

### L4W24 · Fast-reacquisition rehearsal for budget-evicted pins
- **Mechanism:** When `L3W24` re-arms an external guard and evicts a pin from `L3W12` to free plasticity for task $C$, the learner's weights will gradually forget $F$. Keep a lightweight, low-memory `LW02` recovery drill *specifically for evicted pins* (periodic 1-step gradient check or meta-initialized fast-adaptation anchor) so that if the re-armed guard unexpectedly fails again, the learner reacquires $F$-prevention in $O(1)$ steps rather than suffering a prolonged unprotected window.
- **Nearest prior / gap:** Bridges depth-1 `LW02` (self-suppressed rehearsal) back to depth-3 `L3W12 × L3W24`: evicted pins are the exact failure modes most likely to be overwritten *and* most dangerous if their external guard relapses.
- **Cheapest first test:** World where `L3W24` evicts 4 pins to learn tasks $C_1 \dots C_5$, followed by a sudden relapse of 2 external guards ($g_t: 1 \to 0$). Compare `L3W12 + L3W24` without eviction drills, unbounded `L3W12`, uniform replay at equal bytes, and eviction-drill `L4W24`. Kill if standard `L3W12 + L3W24` re-learns $F$ equally fast after relapse at equal replay budget.
- **Old-task retention:** Verify $O(1)$-step $F$-reacquisition after relapse while preserving $C_1 \dots C_5$ and $A/B$ accuracy.

### L4W25 · Anti-free-riding pinning quotas (incentive-compatible external guards)
- **Mechanism:** In multi-team deployments, if downstream teams observe that `L3W12` automatically pins learner weights whenever they turn off their own validators, rational teams will *free-ride* on the learner's pinning budget—deliberately dropping guards to save their own maintenance cost and starving everyone else's continual learning. Assign explicit per-team/per-domain pinning quotas out of $B_{\text{pin}}$ and surface quota exhaustion directly (throttling that domain's new-task updates until its guards re-arm) so guard maintenance remains incentive-compatible.
- **Nearest prior / gap:** Extends performative prediction / strategic classification to *organizational free-riding on continual-learning plasticity*: a tragedy-of-the-commons failure mode unique to multi-user `L3W12 + L3W24` systems.
- **Cheapest first test:** 4-team strategic simulator where each team chooses guard investment $g_i$ to minimize own maintenance cost + own task-adaptation delay. Compare shared-pool `L3W24` (no quotas), unbounded `L3W12`, and per-team quota `L4W25`. Kill if shared-pool `L3W24` without quotas does not suffer a tragedy-of-the-commons collapse in equilibrium guard readiness.
- **Old-task retention:** Verify equilibrium $g_i$ stays above threshold across all 4 teams, preventing global ossification while keeping zero unguarded escapes and intact $A/B$.

### L4W26 · Minimal co-evolutionary plasticity-pinning state tuple
- **Mechanism:** Distill the coupled `L3W12 + L3W24` machinery into the smallest sufficient per-failure state tuple:
  $$S_F = \big(\text{basis } V_F,\; \text{anchor } \theta_F^*,\; \text{LCB readiness } \underline{g}_t(F),\; \text{causal source } c_F \in \{\text{endo, exo}\},\; \text{re-arm cost } \kappa_F,\; \text{lease } \tau_F\big)$$
  plus one global scalar (plasticity shadow price $\mu_t$). Every mechanism in Sections A–C reduces to an update rule on $(S_F, \mu_t)$; ablate each field one by one to find the minimal viable subset.
- **Nearest prior / gap:** Provides a clean architectural bottleneck and falsifiable ablation ladder so the depth-3 line cannot sprawl into unmeasurable complexity.
- **Cheapest first test:** Full-loop continual world combining endogenous + exogenous guard drops, variable re-arming costs, obsolete failures, and conflicting new tasks $C_1 \dots C_{15}$. Ablate each of the 6 fields in $S_F$ and $\mu_t$ against Fisher EWC, shrink-and-perturb, and `L3W12` alone. Kill any field whose removal does not degrade either new-task learning speed, friction cost, or old-prevention retention.
- **Old-task retention:** Verify that the surviving minimal tuple preserves all live preventions, hits the target new-task velocity floor, and maintains $A/B$ accuracy.
