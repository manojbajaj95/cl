# Root: collective agents. Can a population's shared skills, memories or weights keep improving without collapse?

Parent: none (new root). Requested as a fresh root far from the optimizer-state lines (park crossings, inward service, repair-reveal, route-merged folds and their children), which the reviewer found yield only narrow variants. No card here uses optimizer slots, fold codes, return crossings or service schedules.

**Node question.** Many agents work at once. Each sees its own slice of a changing world, and all of them read and write one shared artifact: a skill library, a memory bank, an adapter, or trunk weights. Over a long run that artifact should get better, and an agent's old tasks should keep working. Collapse is what usually happens instead. Can we find *primitives*, meaning new objects or operations on the shared state, that turn "many agents learning" into a process whose shared state converges toward the world rather than toward itself?

## Root cause: a population counts its own echoes as evidence

Every way a shared artifact collapses has one root. Information reaches it from two sources: reality (an agent's fresh, verified interaction) and the population itself (an agent acting on, copying or distilling what the artifact already says). Existing write rules weight these two sources the same way. In the closed loop, the population's own output grows to dominate the input. Five failure modes follow, and the first test of any card must name which of them it targets:

| Collapse mode | What is measured | Known evidence |
|---|---|---|
| C1 homogenization | Pairwise functional disagreement between agents on a fixed probe set goes to 0 | Diversity collapse in post-training (2604.16027); networked self-consuming fixed points (2610.09409) |
| C2 self-referential drift | Accuracy against the world falls while agreement with the artifact rises | Model collapse as lossy transmission (2611.06022); self-contamination law (ledger, PR #4, piloting) |
| C3 rare-knowledge loss | Coverage of low-frequency facts or skills across generations | Rare knowledge is lost first (2611.06022, Henrich); Rogers' paradox in a changing world |
| C4 shared-write interference | Old-task accuracy of the agent whose skill a peer's write overwrote | Federated CL forgetting (FedWeIT, TARGET, FedSEAM 2610.33496) |
| C5 cascades | Fraction of agents that adopt a planted wrong item | LLM herding is stronger than in humans and does not self-correct (2610.30769); conformity (2605.10721) |

The reviewer's lesson from PR #116 and PR #124 applies to the whole root: **a central learner with the same data, actuators and budget can simulate any population.** So a population result only counts if it is measured under a binding constraint, enforced on every arm, including the central control:

- **K1 locality:** raw trajectories and labels stay with the agent that produced them; only the artifact, deltas or messages cross.
- **K2 bandwidth:** a fixed byte budget per sync.
- **K3 asynchrony:** writes land without a global lock or a global order.
- **K4 closed loop:** agents' outputs re-enter as training signal, for themselves or for peers. Without K4 there is no collapse to prevent, and the card is ordinary federated CL.
- **R reality budget:** a fixed number of ground-truth queries (verifier calls, labels, fresh human data) per round for the whole population. Every known collapse fix spends this budget (2611.06022); a card wins only if it does better *at the same R*.

## Common first-test protocol (CPU, no GPU)

- **FleetWorld-tab (minutes on CPU).** 16 agents, each a logistic-regression or 2-layer MLP learner, or a word-trigram LM for transmission cards. A stream of 40 synthetic tasks with Zipf frequencies (the 10 rarest tasks are the rare-knowledge probe) and a world-change rate ρ (a fraction of labels flip per round, for Rogers-style cards). Each agent sees a private slice (K1). The shared artifact is either a rule bank, a shared linear head, or a shared low-rank delta. K4: each round, 50% of each agent's training data are labels produced by the current artifact or by peers; R ground-truth labels are spread across the population.
- **FleetWorld-LLM (CPU, llama-server).** 8 Qwen2.5-0.5B agents with a shared text lesson bank on a rule-switching or tool-use stream, served with the `llama-server --parallel 16` setup on the box. Only for cards whose object is text memory.
- **Controls every card must beat or tie at equal K1–K4 and R:** (a) independent agents with no sharing; (b) one central learner under the same constraints; (c) FedAvg or union memory; (d) **fresh-data mixing**: spend R on uniform fresh labels mixed into every agent's data, the standard collapse fix; (e) dependence-aware truth discovery (2611.04805) for claim-like items; (f) TIES/FedSEAM-style agreement merging for weight-like items; (g) GEM across agents' registered probes.
- **Every first test reports:** world accuracy of the artifact, each of C1–C5, new-task gain at equal steps, and the **old-task retention check**: each agent's accuracy on a fixed held-out set from its own first 10 tasks, plus the population's rare-task accuracy, before and after 50 rounds of closed-loop learning. Seeds ≥ 5, paired across arms. A card that improves world accuracy but drops old-task retention by more than its CI does not pass.

## Idea cards

Each card names its mechanism, why it might be new against the nearest prior art, the cheapest first test, and the old-task retention check. **P** = primitive (a new object or operation others could build on), **I** = improvement.

### A. Count evidence, not echoes

1. **Independent-evidence mass (P).** **Mechanism:** every shared item (a skill, a rule, a delta) carries a provenance set: the IDs of the fresh reality events that support it. An agent that re-endorses an item after using it adds nothing, because its support is already in the set; only fresh events not yet in the set add mass. Read weight and survival follow mass, not endorsement count. **Novelty vs prior:** truth discovery with source dependence (2611.04805) and reputation memory (2609.19502) estimate dependence after the fact from agreement patterns. Here dependence is *known by construction* from provenance and enforced at write time, so echoes cannot accumulate. The surprisingly-popular fleet memory (ledger, falsified) is unrelated: it needed meta-predictions. **Cheapest first test:** FleetWorld-tab rule bank with one planted wrong rule seeded on 2 agents; compare endorsement count, control (e), and evidence mass at equal R. **Retention check:** rare-task rules supported by one fresh event must not be evicted by many-echo common rules; report rare-task accuracy.
2. **Echo-cancelling update (P).** **Mechanism:** an agent's write to shared weights is g(own data) − g(the same inputs labelled by the current shared model). The second term removes the part of the update the artifact would have produced from its own outputs, so self-consumed data contribute zero gradient in expectation. **Novelty vs prior:** collapse fixes add fresh or dreamed data or change sample selection (2610.30009, 2606.13732); none subtract the self-predicted gradient, a control-variate view of self-consumption. **Cheapest first test:** a networked linear-Gaussian model in the 2610.09409 framework (closed form), then FleetWorld-tab; measure variance shrinkage (C1) and bias (C2) over 50 rounds at equal R. **Retention check:** the subtraction must not erase genuine old-task signal that happens to agree with the model; report old-task accuracy against control (d).
3. **Ancestry-discounted averaging (P).** **Mechanism:** when agent weights or deltas are merged, weight each by the fresh data it has seen since its last common ancestor with the others in the merge, not by its total data. Two agents that both copied one checkpoint count once for the shared history. This is item 1's rule applied to weights. **Novelty vs prior:** FedAvg weights by sample count; PBT copies winners; merging methods weight by task or norm. None discount shared lineage, so cloned or copied lineages dominate merges. **Cheapest first test:** 16 agents where 8 are copies of one agent at round 10; measure how far the merged model drifts toward the copied lineage (C1, C2). **Retention check:** old tasks held only by the non-copied minority keep their accuracy after the merge.
4. **Generation-depth discount (I).** **Mechanism:** every datum or lesson carries a generation count (0 = reality, k = produced by a model trained on generation k−1). Training weights each example by λ^k, with λ fitted to the measured per-generation copy loss. **Novelty vs prior:** 2611.06022 measures loss per generation; watermark filtering is binary. A continuous discount set by measured fidelity is the step. **Cheapest first test:** the trigram lineage from 2611.06022 on CPU; compare discount, binary filtering and control (d). **Retention check:** rare-word coverage after 20 generations.
5. **Inductive-bias firewall (P).** **Mechanism:** a population of agents with *different architectures* (linear, MLP, k-NN, trigram) that exchange only functions (labels or distillation targets), never weights. An echo artifact one architecture fits idiosyncratically cannot be reproduced by the others, so it dies at the boundary. **Novelty vs prior:** heterogeneous FL by codistillation (2310.02549) aims at architecture flexibility, not collapse. The claim is that architectural diversity sets a measurable ceiling on C2 propagation. **Cheapest first test:** FleetWorld-tab with 4 architectures × 4 agents vs 16 of one type at equal parameters. **Retention check:** each agent's own old tasks after it distils from peers of another type.

### B. Keep independence alive

6. **Commit-then-reveal learning (P).** **Mechanism:** an agent may read the shared artifact for a task only after it has written its own independent attempt to a sealed log. The artifact learns from the sealed attempts, and the agent acts on the merged answer. Independence of the evidence is guaranteed by protocol order. **Novelty vs prior:** Music-Lab herding (2610.30769) and wisdom-of-crowds independence are diagnoses; pre-registration is a human practice. As a learning protocol with a measurable cost (one extra attempt) it is untried. **Cheapest first test:** FleetWorld-LLM with a planted wrong lesson; compare read-first, commit-first and read-only-after-k-rounds on C5 at equal calls. **Retention check:** agents' old tasks under commit-first, where the agent sometimes ignores a correct shared lesson.
7. **Island populations with validated migration (P).** **Mechanism:** split the population into islands, each with its own artifact. An item migrates to another island only if it improves that island's held-out tasks; it is never copied by consensus. **Novelty vs prior:** island-model GAs migrate the fittest individuals; Music Lab used independent worlds as a measuring device. Using held-out-gated migration as the anti-collapse primitive for shared learned state is new. **Cheapest first test:** 4 islands × 4 agents vs one pool of 16 at equal R, with a world change at round 25. **Retention check:** an island's old items replaced by a migrant must keep their tasks passing.
8. **Learned sharing graph (P).** **Mechanism:** treat who-reads-whom as a parameter: meta-learn edge weights of the sharing graph to maximise long-run world accuracy under a C1 floor. **Novelty vs prior:** 2610.09409 proves convergence conditions for *fixed* graphs; gossip learning uses fixed or random topologies. Optimising the topology against collapse is the open step. **Cheapest first test:** closed-form linear ecosystem where graph spectra predict the fixed point; compare learned, ring, complete and random graphs. **Retention check:** agents cut off by the learned graph must not lose their old tasks.
9. **Adaptive social-to-individual ratio (P).** **Mechanism:** each round a controller sets the fraction of agents that learn from reality (paying R) versus from the artifact, estimating world-change rate ρ online from the disagreement between fresh and copied answers. **Novelty vs prior:** Rogers' paradox and critical social learners (Enquist) are theory; 2501.10476 revisits it for humans and AI. A controller run inside a learning population is untried. **Cheapest first test:** FleetWorld-tab with ρ switched between 0.01 and 0.1; compare a fixed ratio, the controller and the oracle ratio. **Retention check:** old tasks unaffected by the world change keep accuracy when the controller raises individual learning.
10. **Re-derivation leases (P).** **Mechanism:** a shared item survives only while some agent re-derives it from reality within a window; otherwise it is demoted to an archive that agents can read but not inherit. Copies keep it alive but do not renew the lease. **Novelty vs prior:** expiry-based memory (2611.25235, ledger "programmable half-life") expires by time; this expires by absence of independent confirmation, which directly targets stale copies. **Cheapest first test:** FleetWorld-tab with drifting facts; compare time expiry, usage expiry and leases at equal R. **Retention check:** rarely used but still true items, which a lease may demote, must still be readable from the archive at equal accuracy.
11. **Fresh-reality allocation (P).** **Mechanism:** treat R as the population's scarcest resource and spend it where copied knowledge is most likely stale or lossy: on items with high copy-depth, low independent-evidence mass, or rising fresh-vs-copy disagreement. **Novelty vs prior:** active learning picks uncertain inputs for one model; collapse fixes spend R uniformly. Allocating reality checks to where the *population's* transmission is weakest is the step. **Cheapest first test:** compare uniform, uncertainty-based and transmission-weakness allocation at equal R on C2/C3. **Retention check:** items never selected for a check must not lose accuracy.

### C. Preserve rare and minority knowledge

12. **Rare-first transmission (I).** **Mechanism:** agents estimate population frequency of each item or token with a shared count-min sketch (K2-cheap) and up-weight transmission of items in proportion to inverse frequency, offsetting the neutral drift that removes rare variants first. **Novelty vs prior:** 2611.06022 predicts rare-word loss from drift but does not counter it; frequency reweighting is old. The sketch makes it computable under K1/K2. **Cheapest first test:** trigram lineages with and without the reweighting. **Retention check:** common-item accuracy must not fall by more than the rare gain.
13. **Extinction vault (P).** **Mechanism:** keep a tiny behavioural fingerprint (a few input-output pairs) for every skill that ever existed in any agent. A periodic test detects *population-level extinction*, a skill no agent still passes, and revives it from the vault by distillation. Per-agent forgetting is tolerated. **Novelty vs prior:** replay and coreset methods protect per-model retention; PR #116's holders protect copies. Triggering only on population extinction is a different accounting, with far fewer bytes. **Cheapest first test:** FleetWorld-tab at equal bytes vs per-agent replay. **Retention check:** the population's rare-task accuracy and the revival's effect on the revived agent's other tasks.
14. **Consensus-plus-residual deltas (I).** **Mechanism:** decompose each agent's delta into the component that at least k agents agree on (sign and direction), which goes to the shared state, and an idiosyncratic residual that stays private. Lone-agent errors never enter the artifact, and minority knowledge is not averaged away. **Novelty vs prior:** close to FedSEAM agreement merging (2610.33496), TIES sign election, FedSAIL (2609.32485). New only if k is adapted per subspace from measured echo rates; otherwise it is control (f). **Cheapest first test:** shared low-rank delta in FleetWorld-tab against control (f). **Retention check:** private residuals must keep each agent's own old tasks when the shared part changes.
15. **Two-key trunk writes (I).** **Mechanism:** a coordinate of the shared trunk moves only if gradients from two agents with disjoint data agree in sign on it (an AND-mask across agents). **Novelty vs prior:** AND-mask (Parascandolo 2020) and Fishr seek invariance across environments in one model; across agents in a continual closed loop it acts as an anti-overwrite rule. **Cheapest first test:** FleetWorld-tab with a planted idiosyncratic shift on one agent. **Retention check:** C4 on the other 15 agents' old tasks.
16. **Per-agent influence cap (I).** **Mechanism:** cap any one agent's cumulative influence on the shared state per window (user-level clipping as in DP-FedAvg), so one agent's distribution shift cannot overwrite the population. **Novelty vs prior:** user-level clipping is privacy prior art; as a C4/C5 guard it is an application. Kept as a strong control for group C. **Cheapest first test:** one agent with a large shifted stream. **Retention check:** old tasks of the agents not shifted.
17. **Diversity floor by a determinantal term (I).** **Mechanism:** keep the determinant of the agents' output-similarity kernel on a probe set above a floor while learning continually. **Novelty vs prior:** DvD-ES (Parker-Holder 2020) uses this for exploration in RL; the continual-learning floor is an extension. Kept as the C1 control. **Cheapest first test:** FleetWorld-tab C1 curve. **Retention check:** the forced diversity must not cost old-task accuracy.
18. **Diversity homeostasis (I).** **Mechanism:** a controller raises agents' private exploration (temperature, private learning rate) when C1 falls below a floor and syncs more often when it rises. **Novelty vs prior:** adaptive mutation and PBT schedules; an improvement and a control for cards 6–9. **Cheapest first test:** FleetWorld-tab. **Retention check:** old-task accuracy during high-exploration phases.

### D. Concurrent writes to shared state

19. **Conflict-free replicated learned state (P).** **Mechanism:** parameterise the shared adapter so that concurrent writes commute exactly: a grow-only set of per-agent rank-1 slots plus max-registers for gates, as in CRDTs. Asynchronous agents converge to the same state in any order with no lock (K3), and no agent's slot is ever overwritten. A periodic compaction folds slots into a dense delta under a function-preservation test. **Novelty vs prior:** CRDTs (Shapiro 2011) replicate data, Hogwild tolerates races, FedAvg needs rounds. A learned state whose updates are commutative by construction, plus a learned compaction, is a new object. **Cheapest first test:** 16 asynchronous agents with random delays; compare against locked sequential writes and FedAvg at equal bytes. **Retention check:** each agent's old tasks immediately after compaction; compaction is where forgetting can enter.
20. **Conflict-fork merge (P).** **Mechanism:** when two deltas disagree in function space (on probe inputs they predict differently), the merge does not average them. It stores both as a branch keyed by a small learned discriminator of the disagreement region, as a three-way merge does for text conflicts. **Novelty vs prior:** Git-Theta versions weights but merges by averaging or by hand; TIES/DARE resolve conflicts per parameter; MoE routes by input, learned jointly. Detecting conflicts in function space and keeping both sides is new for weights. **Cheapest first test:** two agents trained on contradictory labels in one region and compatible labels elsewhere; compare averaging, TIES and the fork. **Retention check:** both agents' old tasks after the merge, plus bytes added by forks.
21. **Rebase operator for learned deltas (P).** **Mechanism:** an agent trained a delta against base B0 while the shared base moved to B1. Rebase transforms the delta so that its function change on the agent's probe set is preserved on B1, then pushes it. **Novelty vs prior:** task-vector re-basing (2503.20110) and LoRA-X transfer skills across bases offline. Making rebase the routine sync operation of an asynchronous population, with a conflict signal when no rebase preserves the change, is the step. **Cheapest first test:** stale-delta pushes in FleetWorld-tab with staleness 1–10 rounds; compare naive push, rebase and resync-and-retrain at equal compute. **Retention check:** other agents' old tasks after each rebased push.
22. **Transitive retraction (P).** **Mechanism:** shared skills record which items they were derived from. When an item is found false, the retraction propagates to every derived item, which is re-validated or removed. **Novelty vs prior:** SISA-style unlearning removes training data from one model; Skill-V (2610.11781) verifies skills one at a time. Retraction over a population's derivation graph targets C2 chains. **Cheapest first test:** a planted false root rule with 3 levels of derived rules in FleetWorld-LLM; compare single-item deletion and full re-validation at equal calls. **Retention check:** items with one false parent and one true parent must survive.
23. **Population-randomised rollout (I).** **Mechanism:** every shared write first goes to a random half of the agents; the other half is the control group, and the write is promoted, scoped or rolled back from the measured difference. **Novelty vs prior:** canary deploys and randomised playbook curation (2610.18427, ledger) exist; using the population itself as a continuous control group for every write is an improvement. Kept as the strongest control for groups A and D. **Cheapest first test:** FleetWorld-LLM. **Retention check:** old-task accuracy in both halves.
24. **Living shared exam (P).** **Mechanism:** agents co-maintain a probe set that grows with every failure any agent finds. Every local write is gated against the exam, and items retire when every agent passes them on fresh paraphrases, to avoid Goodhart. **Novelty vs prior:** regression suites and dynamic benchmarks exist; a population-grown, self-retiring exam as the shared retention object (rather than shared skills) is new. **Cheapest first test:** FleetWorld-tab; compare a fixed exam and no exam at equal probe bytes. **Retention check:** the exam is the retention check; report held-out old tasks *not* in the exam too.

### E. Division of labour in time and in the stream

25. **Stationarity by routing (P).** **Mechanism:** route incoming tasks to agents so that each agent's own stream is as close to stationary as possible: minimise each agent's distribution shift, not its loss. The population absorbs the non-stationarity, and each agent sees a quasi-stationary stream. **Novelty vs prior:** SEED and MoE route by expertise or loss. A routing objective that minimises per-learner drift is new, and K1 plus bounded per-agent capacity is the constraint the central-learner control must also obey. **Cheapest first test:** 8 agents, 16 rotating tasks; compare loss-based routing, random routing and drift-minimising routing at equal capacity. **Retention check:** population old-task accuracy and each agent's own old tasks.
26. **Population sleep (P).** **Mechanism:** agents take turns going offline to consolidate population traffic into the shared slow state while the others serve. Fast agents act as hippocampus and the shared state as cortex, split across agents in time. **Novelty vs prior:** complementary learning systems (CLS) and DualNet split one model. Rotating the consolidation role across a serving population is untried. **Cheapest first test:** rotating consolidation vs all-online vs a central consolidator at equal compute. **Retention check:** old tasks after each consolidation shift.
27. **Timescale-diverse population (P).** **Mechanism:** agents run at different learning rates, from fast explorers to slow keepers, and information moves from fast to slow only by agreement across several fast agents. The population is a Benna–Fusi cascade made of agents. **Novelty vs prior:** multi-timescale synapses and LR mixtures live in one model; the ledger's rational-forgetting fix must already beat Benna–Fusi. The agent-level cascade adds the agreement gate. **Cheapest first test:** FleetWorld-tab against a single-model Benna–Fusi learner at equal parameters. **Retention check:** old-task retention curve vs time since learning.
28. **Rotating peer teacher (I).** **Mechanism:** in self-distillation, each agent distils from a peer that rotates each round, never from itself or from the mean. **Novelty vs prior:** co-teaching and deep mutual learning (1706.00384) use fixed peers; teacher-refresh schedules were killed as prior art (CGTR 2606.03532). Rotation as a C1 guard is an improvement. **Cheapest first test:** FleetWorld-tab C1/C2. **Retention check:** old-task accuracy.
29. **Skill speciation (I).** **Mechanism:** the shared library splits into species when its usage graph shows incompatible clusters; there is no cross-merging between species, and new agents inherit one species. **Novelty vs prior:** NEAT speciation, quality-diversity archives (DIVE 2608.12486). An improvement unless the split rule predicts C4 before it happens. **Cheapest first test:** FleetWorld-LLM with two incompatible task families. **Retention check:** old tasks of the minority family.
30. **Teach-back fidelity gate (P).** **Mechanism:** an item enters the artifact only if a fresh agent, with no access to its author, can reconstruct the behaviour from the item alone and pass the author's tests. Transmission fidelity becomes a measured property of each item. **Novelty vs prior:** Henrich's lossy copying is theory; Skill-V verifies the skill, not its transmissibility; iterated learning (ledger #17, killed with fix) must beat one agent refining at equal compute. This gate is the measurement iterated learning lacked. **Cheapest first test:** FleetWorld-LLM, gated vs ungated library, equal calls. **Retention check:** old tasks served from gated items after 20 rounds.
31. **Learnability-optimised compaction (P).** **Mechanism:** periodically rewrite the library into the form a *fresh* agent learns fastest from, scored by the newcomer's learning curve, not by length or by the authors' accuracy. **Novelty vs prior:** compression by length or MDL (ledger: MDL lesson scoring killed at proposal); iterated learning favours learnability implicitly. Making newcomer speed the objective is the step. **Cheapest first test:** FleetWorld-LLM, newcomer accuracy after k reads. **Retention check:** existing agents' old tasks with the rewritten library.
32. **Collapse early warning (I, risky).** **Mechanism:** use critical slowing down in population disagreement (rising lag-1 autocorrelation and variance of C1) as a leading indicator of collapse, and trigger card 11's reality spending. **Novelty vs prior:** early-warning signals are standard in ecology. The ledger has killed memory-loop Lyapunov and edge-of-chaos predictors, so this must beat the trivial rule "spend R when C1 falls". **Cheapest first test:** FleetWorld-tab, 10 seeds, lead time vs the trivial rule. **Retention check:** old-task accuracy under triggered vs scheduled spending.

## Deeper questions, ranked by chance of a new primitive

1. **Can evidence accounting make a closed-loop population a consistent estimator?** Cards 1–4 and 11. Is there a write rule (provenance mass, ancestry discounting, echo cancelling) under which the artifact's error falls with total fresh evidence regardless of how much the population copies itself, and does it reach a given world accuracy with fewer reality queries R than fresh-data mixing? Start with the closed-form linear ecosystem of 2610.09409, where the fixed point can be computed. Dead if fresh-data mixing at equal R ties on C2 and C3.
2. **Is there conflict-free learned state?** Cards 19–21. Can a shared adapter whose updates commute by construction, plus a learned compaction, keep every agent's old tasks under asynchronous writes (K3) at bytes comparable to FedAvg? The hard part is compaction: dead if compaction forgets as much as averaging does.
3. **Can a population make each learner's stream stationary?** Cards 25–27. Under K1 and bounded per-agent capacity, does drift-minimising routing give population retention that a single learner of the same total size cannot reach? This is the clearest candidate for a population effect the central-learner control cannot simulate, because the constraint is per-agent capacity and locality, not parameter count.
4. **What sets the social-learning ratio a population needs?** Cards 6, 9, 10. Can a population find the right split between copying and fresh learning online, from its own fresh-vs-copy disagreement, in a world that changes at an unknown rate? Dead if a fixed ratio tuned once matches it across ρ.

## Prior-art and exclusion screen

- **Collective skill and memory systems (the baselines, not novelty):** SkillClaw (2604.08377) aggregates trajectories across users and syncs a shared skill repository; Federation over Harness (2610.24007) evolves client and server harnesses for a shared insight library from self-generated reflections; FederatedSkill (2606.03143); MASkills (2609.02094); XferAgent (2610.19581); EpiCon (2609.37923) shared multimodal memory; cross-user memory sharing (2609.32511); SkillsVote (2605.18401); Skill-V (2610.11781); skill misevolution (2608.12851). None of these meters evidence independence, cancels echoes, commutes concurrent writes or treats R as a budget. Several learn only from self-generated signals, which is exactly the K4 regime the cards target.
- **Collapse theory:** 2611.06022 (lossy transmission and Rogers' paradox: every working remedy imports outside information), 2610.09409 (networked self-consuming fixed points), 2609.11146 (dominant supplier), 2605.29267 (curation under multi-model loops), 2610.30009, 2606.13732. Herding and conformity: 2610.30769, 2605.10721, 2608.02758.
- **Federated and decentralized CL:** FedWeIT, TARGET, FOT, FedSEAM (2610.33496), FedSAIL (2609.32485), CF-LoRA (2609.36986), ReSCENE (2609.38833), CoDeC (2303.15378), decentralized lifelong collaborative learning (2403.06535). Codistillation (2010.02838) and mutual learning (1706.00384) are controls for cards 5 and 28.
- **Weight versioning and merging:** Git-Theta (2306.04529), MergeKit, TIES, task-vector re-basing (2503.20110), audit-before-merge (2611.10684).
- **Ledger exclusions (do not resurrect):** surprisingly-popular fleet memory H1/H1b, bootstrap writers (bagging), coded or redundant memory fragments, Matthew-effect libraries, social-choice shared memory, median-of-means cohort gating, Fleet Q2–Q4 obsolescence forecasts, HW1 convergent-edit promotion, iterated learning as stated (#17, needs the fix above), memory-loop Lyapunov and edge-of-chaos predictors, teacher-refresh α*. The self-contamination law (PR #4) is piloting on its own line; card 2 is a write rule, not a law, and must not be scored as its replication. PR #116's holder replication and PR #124's internal markets are conceded: any card here that a central learner under K1–K4 and R can simulate is an improvement at best.
- **Screen scope:** alphaXiv searches on collective skill evolution, multi-agent collapse, federated LoRA CL, shared agent memory and herding, population evolution and cultural accumulation, gossip and decentralized CL, codistillation, quality-diversity skill libraries, social learning and weight version control; full text read for the six nearest papers. This is a nearest-neighbour screen, not proof of novelty. No experiments were run for this node.
