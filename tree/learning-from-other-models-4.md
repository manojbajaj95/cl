# Learning from other models 4: Bug-compensation purging and native witness re-grounding

Child of [PR #361](https://github.com/manojbajaj95/cl/pull/361) ([depth-2 node](learning-from-other-models-3.md)) · Depth 3 · 27 candidate primitives · Ideas only; no experiments run

**Thesis.** Standard model-upgrade engineering treats any behavioral difference between an old adapted model $M_0$ and a new base $B_1$ as a regression ("negative flip") to suppress. In continual learning across strengthening bases, that reflex is half-wrong: it locks in **bug-compensating rules** that only existed because $B_0$ was broken (**L3-16**), and it drags $B_0$'s obsolete conventions forward through adapters or bridges instead of letting $B_1$ execute its own cleaner version (**L3-13**). A non-degenerating upgrade operator must do the opposite of blanket backward compatibility: (1) **catch and purge** migrated rules that double-correct once $B_1$ fixes $B_0$'s bug—without falsely deleting genuine private conventions; and (2) **re-ground** genuinely needed dependent skills directly onto $B_1$'s native upstream outputs so old conventions die at the upgrade boundary rather than compounding across generations.

**Scope.** Deepens only **L3-16** (catching a migrated rule that only compensated for the old base's bug) and **L3-13** (re-grounding a dependent skill on the new base's own version), the two directions kept from [PR #361](https://github.com/manojbajaj95/cl/pull/361) in the latest [flood-triage](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-triage.md) row. Excludes PR #361's collapsed proxy-variation cards (`L3-01`–`L3-10`), standalone probe-budget / covering-array / subspace-projection variants, and PR #358–#359's dropped lines. Every card must beat strong named controls—including Positive-Congruent Training (PCT), MetaDD-style cross-architecture distillation, GRAFT/Trans-LoRA per-task transport, keeping the old skill, interface bridges (L3-12), independent per-skill triage, and random pairwise probes—at matched probes, bytes, and updates.

**Shared first-test contract.** All tests below are CPU-first proposals on tiny models (MLP, gated MLP, tiny transformer, or symbolic/rule-routing agents); no experiments were run. Every **L3-16** test constructs a base upgrade $B_0 \to B_1$ containing (i) retired slices $s_1$ where $B_1$ strictly fixes a $B_0$ bug, (ii) downstream migrated rules $s_2^{\text{comp}}$ that only compensated for $B_0$'s bug in $s_1$, and (iii) genuine private conventions $s_2^{\text{priv}}$ (including rare task $B$) that look superficially similar on single-skill evals; success requires purging $s_2^{\text{comp}}$ while retaining $s_2^{\text{priv}}$ and $B_1$'s fix on $s_1$. Every **L3-13** test constructs an upgrade where $B_1$ absorbs upstream $s_1$ with higher standalone accuracy (e.g. 95% vs 80%) but a shifted format/convention, while downstream $s_2$ depends on $s_1$; success requires matching or beating composed $s_1 \circ s_2$ accuracy *while preserving $B_1$'s improved standalone $s_1$*. Common controls apply alongside each card's named control: L2-17 drop–migrate only, independent per-skill triage, LM30, PCT backward-compatible training, GRAFT/Trans-LoRA per-task transport, MetaDD-style independent distillation, keep-old-$s_1$, L3-12 seam bridge, raw $M_0$ trajectory distillation, and random pairwise probes at equal budget.

## A · Catching and resolving bug-compensating rules on base upgrades (L3-16)

### L4-01 · Signed double-correction detector (overshoot vs orthogonal convention)
- **Mechanism:** On every (retired $s_1$, migrated $s_2$) composition probe, measure the *signed direction* of $s_2$'s effect relative to $B_1$'s improvement vector $(B_1 - B_0)$ on $s_1$: flag $s_2$ as a bug-compensation specifically when $B_1 + s_2$ **overshoots past the ground truth along the same correction axis** as $(B_1 - B_0)$, rather than shifting along an orthogonal private-rule axis.
- **Nearest prior / gap:** [RAGFlip](https://arxiv.org/abs/2610.07266) and [Item-Level LLM API Regressions](https://arxiv.org/abs/2608.17719) count unsigned negative flips; L3-16 flagged any $s_1 \circ s_2$ degradation. Checking *signed overshoot along the $(B_1 - B_0)$ fix axis* separates double-correction compensations from genuine private rules that merely have a convention mismatch.
- **Cheapest first test:** Upgrade world with 6 bug-compensating offsets (same axis as $B_1 - B_0$), 6 convention-mismatched private rules (orthogonal axis), and 6 clean private rules; compare unsigned L3-16 flagging, independent triage, and signed overshoot detection at equal probes. Kill if unsigned L3-16 achieves the same precision on compensations vs private rules.
- **Old-task retention:** Verify all 12 genuine private rules (including rare $B$) survive without false retirement while all 6 bug-compensations are purged.

### L4-02 · Counterfactual $B_0$-bug-injection proof of compensation
- **Mechanism:** To prove causally that migrated rule $s_2$ is a bug-compensation without needing extra ground-truth labels on $s_2$, run a two-arm counterfactual on $B_1 + \Delta^{\text{mig}}_{s_2}$: feed (a) $B_1$'s fixed $s_1$ output vs (b) $B_0$'s old buggy $s_1$ output into $s_2$. If $s_2$ *recovers accuracy when handed $B_0$'s bug* and fails on $B_1$'s fix, $s_2$ is causally certified as a bug-compensation.
- **Nearest prior / gap:** [Positive-Congruent Training](https://arxiv.org/abs/2011.09161) and [UpgradeBench](https://arxiv.org/abs/2608.20918) never intervene on upstream base outputs; L3-16 relied on end-to-end $B_1$ probes alone. *Injecting $B_0$'s old bug into $B_1 + s_2$* gives a direct causal witness that distinguishes a bug-compensation from an ordinary $B_1$ failure.
- **Cheapest first test:** Mixed upgrade world where 5 migrated rules fail on $B_1$ due to bug-compensation and 5 fail due to $B_1$ capacity/migration error; compare end-to-end L3-16, GRAFT/Trans-LoRA transport, and counterfactual $B_0$-bug injection at equal forward passes. Kill if end-to-end $B_1$ error alone separates the two failure classes equally well.
- **Old-task retention:** Ensure the 5 migration-error private rules (including rare $B$) are repaired rather than retired, while the 5 bug-compensations are retired cleanly.

### L4-03 · Partial-compensation peeling (strip the bug-offset, keep the private core)
- **Mechanism:** When a single migrated rule $s_2$ blends a genuine private requirement with a compensation for $B_0$'s bug in $s_1$, do not make a binary retire/migrate decision. Isolate the *private core* by taking the difference between $M_0$'s desired $s_1 \circ s_2$ target and $B_1$'s native $s_1$ output, and migrate only that non-zero residual—peeling off the obsolete bug-offset automatically.
- **Nearest prior / gap:** L3-16 made a binary retire-or-migrate call on $s_2$; [From Migration to Calibration](https://arxiv.org/abs/2609.35149) recalibrates whole agents. *Intra-rule residual peeling* handles hybrid rules where retiring $s_2$ loses the private requirement and migrating $s_2$ verbatim double-corrects.
- **Cheapest first test:** 8 hybrid rules (each = private format/policy + offset compensating $B_0$'s $s_1$ bias); compare binary retire, binary migrate, L3-16 binary flag, and partial-compensation peeling at equal updates. Kill if migrating $s_2$ + equal-step fine-tuning on $B_1$ achieves the same joint accuracy.
- **Old-task retention:** Score both the private core (including rare $B$) and $B_1$'s fixed $s_1$ accuracy after peeling.

### L4-04 · Silent over-conservatism detector for defensive workaround rules
- **Mechanism:** Some bug-compensating rules never fail a correctness verifier on $B_1$—for example, a defensive "abstain / retry / hedge" rule $s_2$ learned because $B_0$ frequently hallucinated on $s_1$. Detect these *silent compensations* by comparing $s_2$'s abstention/hedging/cost rate on $B_1$'s fixed $s_1$ against $B_1$'s actual error rate on $s_1$, retiring $s_2$ when its defensive trigger fires on inputs $B_1$ now answers cleanly.
- **Nearest prior / gap:** Negative-flip benchmarks ([RAGFlip](https://arxiv.org/abs/2610.07266), [Item-Level Regressions](https://arxiv.org/abs/2608.17719)) and L3-16 only catch accuracy drops. Auditing *unnecessary abstention / defensive overhead* catches silent workarounds that silently cap $B_1$'s coverage.
- **Cheapest first test:** $B_0$ has 40% hallucination on $s_1$ so $M_0$ learned an abstain-on-$s_1$ rule $s_2$; $B_1$ solves $s_1$ at 96%. Compare accuracy-only L3-16, PCT, and coverage/cost-audited compensation detection. Kill if standard accuracy-plus-coverage eval on standalone $s_1$ catches $s_2$ without joint probing.
- **Old-task retention:** Verify genuine safety/abstention rules for *still-broken* cohorts (rare $B$) remain active while obsolete $s_1$ hedges are retired.

### L4-05 · Compensation-exempt Positive-Congruent Training (selective backward compatibility)
- **Mechanism:** Modify Positive-Congruent Training (PCT) during $B_0 \to B_1$ migration so its no-negative-flip distillation penalty is **masked off** on any slice flagged by L3-16 as a retired-bug compensation, while staying active on confirmed private conventions—preventing PCT from freezing $B_0$-era bug hacks into $B_1$.
- **Nearest prior / gap:** [Positive-Congruent Training](https://arxiv.org/abs/2011.09161), [Margin-Preserving Negative-Flip Mitigation](https://arxiv.org/abs/2511.08322), and [NLP Gated-Fusion](https://arxiv.org/abs/2302.02080) penalize *every* prediction flip from $M_0$. Masking PCT by L3-16 compensation flags reconciles negative-flip protection with bug-workaround retirement.
- **Cheapest first test:** Upgrade with 10 private rules + 6 bug compensations; compare blanket PCT, unconstrained migration, GRAFT/Trans-LoRA, and compensation-exempt PCT. Kill if unconstrained migration + L3-16 retirement incurs zero extra negative flips on rare private rule $B$.
- **Old-task retention:** Measure negative-flip rate on private rules ($A$ and rare $B$) alongside positive-flip rate on retired bug compensations.

### L4-06 · Iterative fixed-point unwinding for multi-layer workaround stacks
- **Mechanism:** When $M_0$ accumulated a stack of nested hacks ($s_2$ compensated for $B_0$'s bug in $s_1$, and $s_3$ patched a side-effect of $s_2$), a single-pass L3-16 check misses $s_3$. Unwind iteratively: retire $s_1$, probe and retire exposed compensations $s_2$, then re-probe remaining migrated rules against the updated model to expose and retire $s_3$ until no further double-corrections fire.
- **Nearest prior / gap:** L3-16 ran a single pairwise pass between retired $s_1$ and migrated $s_2$; [UpgradeBench](https://arxiv.org/abs/2608.20918) has no multi-layer dependency model. Fixed-point unwinding clears *nested workaround debt* in one upgrade.
- **Cheapest first test:** Plant 3 two-layer workaround stacks ($s_1 \to s_2 \to s_3$) alongside 6 genuine chained private rules; compare 1-pass L3-16, migrate-all, and iterative fixed-point unwinding at equal total probes. Kill if 1-pass L3-16 catches $s_3$ directly via $s_1 \circ s_3$ probes.
- **Old-task retention:** Verify all 6 genuine private chains (including rare $B$) survive unwinding while both layers of the workaround stacks are purged.

### L4-07 · Regional compensation gating for half-fixed base bugs
- **Mechanism:** When $B_1$ fixes $B_0$'s bug on the *common sub-region* of $s_1$ but leaves the bug unfixed on a *rare sub-region* of $s_1$, neither retire $s_2$ globally nor migrate $s_2$ globally. Partition $s_1$'s input space by $B_1$'s residual error and gate $s_2$ to fire *only* on the unfixed sub-region—retiring $s_2$ where $B_1$ succeeded while keeping it where $B_1$ still needs it.
- **Nearest prior / gap:** Binary retirement (L3-16) breaks the unfixed tail; binary migration (GRAFT / [Trans-LoRA](https://arxiv.org/abs/2405.17258)) double-corrects the fixed bulk. *Error-region-gated partial retirement* handles realistic partially fixed base bugs cleanly.
- **Cheapest first test:** $B_1$ fixes $B_0$'s $s_1$ bug on 80% of inputs but still fails on 20% edge cases; compare global retire, global migrate, L3-16 binary flag, and regional compensation gating. Kill if global retire + fine-tuning $B_1$ directly on the 20% edge cases ties at equal updates.
- **Old-task retention:** Report $s_1 \circ s_2$ accuracy separately on the 80% fixed bulk and the 20% unfixed edge cases, plus untouched rare $B$.

### L4-08 · Calibration-hack detector for confidence-recalibrating adapters
- **Mechanism:** Detect migrated rules $s_2$ whose hidden job was recalibrating $B_0$'s overconfident/underconfident logits on $s_1$ (e.g., shifting decision thresholds or temperature): even when top-1 accuracy on $s_1 \circ s_2$ looks fine, flag $s_2$ as a calibration compensation whenever $B_1 + s_2$ worsens Brier score / ECE on $s_1 \circ s_2$ relative to bare $B_1$.
- **Nearest prior / gap:** [From Migration to Calibration](https://arxiv.org/abs/2609.35149) recalibrates agents post-migration; L3-16 checked only task accuracy. Auditing *calibration degradation on retired slices* catches soft logit-level compensations invisible to accuracy probes.
- **Cheapest first test:** $B_0$ is systematically overconfident on $s_1$ so $M_0$ learned a soft-damping rule $s_2$; $B_1$ is already well-calibrated on $s_1$. Compare accuracy-only L3-16, PCT, and ECE/Brier compensation detection. Kill if post-hoc temperature scaling on $B_1 + s_2$ matches bare $B_1$'s calibration without retiring $s_2$.
- **Old-task retention:** Check ECE/Brier and accuracy on $s_1 \circ s_2$, standalone $s_1$, and calibrated private rules $A/B$.

### L4-09 · Historical error-covariance pre-screening for cheap L3-16 probing
- **Mechanism:** Before running $O(|R| \cdot |M|)$ pairwise (retired, migrated) probes on $B_1$, score every migrated rule $s_2$ by its historical *update covariance with $B_0$'s errors on retired $s_1$* (computed from $M_0$'s lightweight error-trigger summary), and spend L3-16 composition probes on the highest-covariance pairs first.
- **Nearest prior / gap:** Random pairwise probing wastes budget on unrelated skills; L3-16 probed all pairs exhaustively. *Error-covariance screening* targets the exact subset of migrated rules that were born when $B_0$ failed $s_1$.
- **Cheapest first test:** 10 retired slices $\times$ 15 migrated rules (150 pairs) with 5 planted bug-compensations; cap probes at 20. Compare random 20 probes, activation-overlap screening (L3-15), and $B_0$-error-covariance screening. Kill if L3-15 activation overlap matches recall at 20 probes.
- **Old-task retention:** Measure recall of the 5 bug-compensations and zero false retirement of the 10 genuine private rules ($A/B$).

### L4-10 · Disjoint stress-set dominance proof before irreversible retirement
- **Mechanism:** Never retire a L3-16-flagged rule $s_2$ on a single probe verdict. Require bare $B_1$ to strictly dominate (or tie with lower cost) $B_1 + s_2$ on a *disjoint rare-cohort stress split* of $s_1 \circ s_2$—preventing false retirement of a genuine rare private rule $B$ that happened to disagree with $B_1$ on common probes.
- **Nearest prior / gap:** [One Verdict Is Not Enough](https://arxiv.org/abs/2610.41130) argues against single-verdict regression gating; L3-16 retired immediately on one probe. Adding a *disjoint cohort dominance gate* protects rare private rules from aggressive purging.
- **Cheapest first test:** Plant 4 true bug-compensations + 2 deceptive rare private rules that agree with a bug-compensation on common inputs but diverge on rare cohort $B$; compare single-probe L3-16 vs disjoint stress-set dominance gating at matched total probes. Kill if single-probe L3-16 with balanced cohort sampling ties.
- **Old-task retention:** Primary metric is false-retirement rate on deceptive rare rule $B$ plus true-retirement rate on the 4 compensations.

## B · Re-grounding dependent skills onto the new base's native version (L3-13)

### L4-11 · Semantic-invariant filter for regenerated $B_1$ witness prefixes
- **Mechanism:** When L3-13 regenerates the $s_1$-dependent prefix of $s_2$'s teaching witnesses using $B_1$'s native $s_1$, run an automated *semantic-equivalence check* between $M_0$'s old $s_1$ output and $B_1$'s regenerated $s_1$ output before relabeling: accept convention/format shifts, but reject and quarantine any witness where $B_1$'s $s_1$ silently altered the underlying semantic facts (which would corrupt $s_2$'s label).
- **Nearest prior / gap:** L3-13 blindly regenerated prefixes with $B_1$; [MetaDD](https://arxiv.org/abs/2410.05103) and raw trajectory distillation assume clean labels. *Semantic-invariant filtering* prevents label poisoning during native witness re-grounding.
- **Cheapest first test:** $B_1$ is 92% accurate on $s_1$ with a new format (8% semantic errors); compare unfiltered L3-13 re-grounding, keep-old-$s_1$, L3-12 seam bridge, and semantic-filtered re-grounding. Kill if unfiltered L3-13 is naturally robust to 8% corrupted prefixes at equal updates.
- **Old-task retention:** Score composed $s_1 \circ s_2$, standalone $s_1$, and rare $B$ on $B_1$ after filtered vs unfiltered re-grounding.

### L4-12 · Latent-activation re-grounding for non-verbalized internal dependencies
- **Mechanism:** L3-13 assumes the $s_1 \to s_2$ seam is an explicit text/output prefix. When $s_2$ depends on an *internal, non-verbalized representation* of $s_1$, re-ground $s_2$ by running $s_1 \circ s_2$ inputs through *frozen* $B_1$ to harvest $B_1$'s native hidden states, and training $s_2$'s migrated adapter/head strictly on top of those frozen $B_1$ states—never touching $B_1$'s native $s_1$ weights.
- **Nearest prior / gap:** [GRAFT](https://arxiv.org/abs/2611.18638) and [Trans-LoRA](https://arxiv.org/abs/2405.17258) map old weights/activations from $B_0$ into $B_1$; [Multi-modal Knowledge Preserving Adapter](https://arxiv.org/abs/2609.16875) aligns new embeddings to old ones. *Frozen-$B_1$ latent re-grounding* adapts $s_2$ to $B_1$'s native internal geometry instead of warping $B_1$ back toward $B_0$.
- **Cheapest first test:** Non-verbalized 2-step feature composition $s_1 \circ s_2$ across two distinct MLP/transformer backbones where $B_1$ already learned $s_1$ in a rotated basis; compare GRAFT/Trans-LoRA transport, L3-12 bridge, raw distillation, and frozen-$B_1$ latent re-grounding. Kill if GRAFT/Trans-LoRA matches $s_1 \circ s_2$ without hurting $B_1$'s standalone $s_1$.
- **Old-task retention:** Score $B_1$'s untouched standalone $s_1$ alongside composed $s_1 \circ s_2$ and migrated rare $B$.

### L4-13 · Topological wave re-grounding for multi-hop chains ($s_1 \to s_2 \to s_3$)
- **Mechanism:** For a multi-hop chain where $B_1$ absorbed $s_1$ and must migrate both $s_2$ and $s_3$, re-ground in *topological waves*: first regenerate $s_2$'s witnesses with $B_1(s_1)$ and commit $s_2^{(B_1)}$, then regenerate $s_3$'s witnesses through the *already re-grounded* $B_1 + s_2^{(B_1)}$—eliminating stale $M_0$ intermediate conventions at every hop of the chain.
- **Nearest prior / gap:** Parallel per-task migration ([GRAFT](https://arxiv.org/abs/2611.18638), [Trans-LoRA](https://arxiv.org/abs/2405.17258), single-hop L3-13) migrates $s_2$ and $s_3$ independently from $M_0$'s old intermediates, breaking $s_2^{(B_1)} \to s_3$. Topological wave re-grounding keeps multi-hop compositions coherent.
- **Cheapest first test:** 3-hop chain $s_1 \to s_2 \to s_3$ where $B_1$ shifts $s_1$'s format (which shifts $s_2$'s intermediate format); compare simultaneous L3-13, keep-old-$s_1$, L3-12 bridges, and topological wave re-grounding at equal total updates. Kill if simultaneous L3-13 matches 3-hop $s_1 \circ s_2 \circ s_3$ accuracy.
- **Old-task retention:** Test standalone $s_1$, 2-hop $s_1 \circ s_2$, 3-hop $s_1 \circ s_2 \circ s_3$, and rare $B$ on $B_1$.

### L4-14 · Multi-hop debt test: hop-by-hop re-grounding vs stacked bridges ("when the bill falls")
- **Mechanism:** Across a 3-generation base chain $B_0 \to B_1 \to B_2 \to B_3$ where each new base shifts $s_1$'s convention slightly, apply L3-13 native re-grounding at every hop and compare directly against stacking L3-12 seam bridges or carrying $M_0$'s old $s_1$—testing whether immediate re-grounding keeps multi-hop error and byte cost flat while bridges compound.
- **Nearest prior / gap:** [When the Bill Falls](https://arxiv.org/abs/2611.20702) proved bridge/adapter deferral fails over complete *embedding* migrations; this tests the exact same phenomenon for *continual skill upgrades* across 3 base generations.
- **Cheapest first test:** 4-base chain $B_0 \to B_1 \to B_2 \to B_3$ with progressive format drift on absorbed $s_1$ and dependent $s_2$; compare keep-$B_0$-$s_1$, stacked L3-12 bridges, raw trajectory distillation, and hop-by-hop L3-13 re-grounding at matched per-hop compute. Kill if stacked L3-12 bridges maintain equal $s_1 \circ s_2$ accuracy and standalone $s_1$ gain at $B_3$.
- **Old-task retention:** Track standalone $s_1$, composed $s_1 \circ s_2$, and generation-0 rare $B$ across $B_1, B_2, B_3$.

### L4-15 · Prior-anchored re-grounding to protect $B_1$'s standalone $s_1$
- **Mechanism:** When training $B_1$ on $s_2$'s re-grounded witnesses $(x, B_1(s_1(x)), y_{s_2})$, add a KL/logit anchor on standalone $s_1$ prefixes so gradient flow from $s_2$ does not distort $B_1$'s native $s_1$ distribution back toward $M_0$'s weaker $s_1$.
- **Nearest prior / gap:** [Weight-Interpolation Backward Compatibility](https://arxiv.org/abs/2301.10546) anchors toward the *old* model; here we anchor toward the *new base's* native $s_1$ while migrating $s_2$.
- **Cheapest first test:** Coupled $s_1 \circ s_2$ where $B_1$ scores 95% on standalone $s_1$ (vs $M_0$'s 80%); compare unconstrained L3-13 re-grounding, keep-old-$s_1$, and prior-anchored L3-13 at equal updates. Kill if unconstrained L3-13 causes zero drop on standalone $s_1$ (including OOD $s_1$ inputs not appearing in $s_2$).
- **Old-task retention:** Score both in-domain and OOD standalone $s_1$ on $B_1$ alongside composed $s_1 \circ s_2$ and rare $B$.

### L4-16 · Multi-sample stochastic re-grounding for high-entropy native $B_1$ skills
- **Mechanism:** When $B_1$'s native $s_1$ is richer and more diverse than $M_0$'s rigid $s_1$ (emitting multiple valid phrasings/paths), regenerate $k$ diverse $B_1(s_1)$ samples per $s_2$ witness (e.g., $k=4$ at deployment temperature) instead of a single greedy decode, so the re-grounded $s_2$ generalizes across $B_1$'s full native distribution.
- **Nearest prior / gap:** Deterministic witness regeneration (naive L3-13) and single-trajectory distillation overfit $B_1$'s greedy decode, causing silent composition breaks at non-zero sampling temperature.
- **Cheapest first test:** Evaluate $B_1 + s_2$ at deployment sampling temperature $T > 0$ on $s_1 \circ s_2$; compare greedy-decode L3-13, raw $M_0$ distillation, L3-12 bridge, and $k=4$ stochastic re-grounding at matched total witness tokens. Kill if greedy-decode L3-13 ties at $T > 0$.
- **Old-task retention:** Measure $s_1 \circ s_2$ pass@1 and variance at $T > 0$, plus standalone $s_1$ and rare $B$.

### L4-17 · Span-slot re-grounding across tokenizer and length shifts
- **Mechanism:** When $B_1$ changes both the tokenizer and $s_1$'s verbosity/length, represent each $s_2$ witness with explicit semantic slot boundaries `[UPSTREAM_S1] -> [DOWNSTREAM_S2]` so $B_1$'s regenerated $s_1$ span drops cleanly into the slot without breaking token-index masks or loss-mask alignment.
- **Nearest prior / gap:** [Heirloom](https://arxiv.org/abs/2611.00650) flags vocabulary/tokenizer shifts as a barrier to adapter migration; naive token-prefix swapping corrupts loss masks when $B_1$'s $s_1$ changes token count. Slot-level witness re-grounding makes L3-13 tokenizer-agnostic.
- **Cheapest first test:** Two tiny LMs with mismatched BPE tokenizers where $B_1$'s $s_1$ outputs are 1.5x longer than $M_0$'s; compare raw trajectory distillation, token-offset prefix swap, and slot-aligned re-grounding. Kill if simple string-concatenation fine-tuning without slot loss-masking ties on $s_1 \circ s_2$ and standalone $s_1$.
- **Old-task retention:** Check standalone $s_1$ (length/quality), composed $s_1 \circ s_2$, and rare $B$ across the tokenizer jump.

### L4-18 · Post-re-grounding editability gate (amendment check after native rebuild)
- **Mechanism:** After re-grounding $s_2$ onto $B_1$'s native $s_1$, run a bounded 3-step *held-out amendment* on $s_2$ inside $B_1$ (connecting L3-13 to flood-triage row 495's PBX2): reject any re-grounding that achieves high static $s_1 \circ s_2$ accuracy only by brittle memorization of $B_1$'s exact $s_1$ tokens and fails to accept the amendment.
- **Nearest prior / gap:** L3-13 scored re-grounding only on static post-upgrade outputs; [Identity-Preserving Agents](https://arxiv.org/abs/2611.10628) tests static persona match. Scoring *post-re-grounding editability* ensures $s_2$ remains a live continual skill on $B_1$, not a frozen patch.
- **Cheapest first test:** Compare high-epoch (memorized) vs regularized L3-13 re-grounding vs L3-12 seam bridge on $B_1$, then apply a 3-step rule amendment $s_2 \to s_2'$. Kill if static $s_1 \circ s_2$ accuracy already predicts post-amendment accuracy perfectly.
- **Old-task retention:** Measure $B_1$'s accuracy on amended $s_1 \circ s_2'$, untouched old rule $A$, and standalone $s_1$.

### L4-19 · Information-sufficiency gate for lossy absorbed $s_1$ (when re-grounding is impossible)
- **Mechanism:** Before running L3-13, check whether $B_1$'s native $s_1$ actually *preserves the information* $s_2$ needs (by probing whether $s_2$'s target is still predictable from $B_1(s_1)$ via a cheap linear/probe classifier). If $B_1$'s $s_1$ passes standalone accuracy yet drops a fine-grained field that $s_2$ requires, abort bare re-grounding and migrate *only the missing field* as a minimal $s_1$ augmentation.
- **Nearest prior / gap:** L3-13 assumed $B_1$'s native $s_1$ is always information-complete for $s_2$; [When the Bill Falls](https://arxiv.org/abs/2611.20702) assumes the new encoder is strictly richer. An *information-sufficiency gate* catches lossy absorptions where bare re-grounding would silently cap $s_2$'s ceiling.
- **Cheapest first test:** $B_1$ scores 96% on standalone $s_1$ (higher than $M_0$'s 82%) but rounds/omits a secondary attribute that $s_2$ reads; compare bare L3-13, keep-all-$s_1$, L3-12 bridge, and sufficiency-gated minimal-field augmentation. Kill if bare L3-13 recovers $s_2$ from the raw input $x$ without needing the field from $s_1$.
- **Old-task retention:** Score standalone $s_1$ (must keep $B_1$'s 96%), composed $s_1 \circ s_2$, and rare $B$.

### L4-20 · Lazy traffic-driven re-grounding with temporary cold-slice bridges
- **Mechanism:** When $M_0$ carries hundreds of dependent skills, avoid blocking the $B_0 \to B_1$ cutover on offline regeneration of every witness: deploy lightweight L3-12 bridges only on cold slices at cutover, and lazily run L3-13 native re-grounding on each slice as live traffic hits it—retiring each temporary bridge as soon as its re-grounded slice passes verification.
- **Nearest prior / gap:** Offline L3-13 pays full regeneration cost up front; permanent L3-12 bridges accumulate multi-hop debt ([When the Bill Falls](https://arxiv.org/abs/2611.20702)). *Lazy traffic-driven re-grounding* pays re-grounding compute only for skills that are actually used in production while still eliminating bridge debt on active paths.
- **Cheapest first test:** 40 dependent skills with Zipfian live traffic (top 8 skills get 85% of queries); compare full offline L3-13, permanent L3-12 bridges, and lazy traffic-driven re-grounding at fixed cutover latency and total compute budget. Kill if full offline L3-13 fits inside the same compute budget with lower total error.
- **Old-task retention:** Track both hot-slice re-grounded accuracy and cold-slice bridge accuracy (including rare $B$ when it finally arrives).

## C · Unified compensation-purge + native re-grounding loop (L3-16 + L3-13)

### L4-21 · Strict two-phase upgrade order: purge compensations *before* re-grounding
- **Mechanism:** Enforce a strict causal ordering in the upgrade compiler: execute L3-16 retire–migrate compensation purging *first*, and run L3-13 native witness re-grounding *only on surviving rules*. Test the failure mode of reversing the order—where re-grounding a bug-compensating rule onto $B_1$'s fixed $s_1$ bakes a nonsensical transformation into $B_1$'s native convention and hides it from later detection.
- **Nearest prior / gap:** L3-16 and L3-13 were proposed as independent cards in PR #361. Proving *phase-ordering non-commutativity* turns them into a single ordered upgrade operator.
- **Cheapest first test:** Upgrade world containing both 5 bug-compensations and 5 convention-dependent private rules; compare (i) purge-then-reground, (ii) reground-then-purge, (iii) simultaneous joint migration, and (iv) GRAFT/Trans-LoRA. Kill if reground-then-purge achieves the same final accuracy on both sets.
- **Old-task retention:** Score purged compensations (must not double-correct), re-grounded private rules (including rare $B$), and standalone $s_1$ on $B_1$.

### L4-22 · Unified re-grounding collapse test: one probe to separate "hack" from "dependent rule"
- **Mechanism:** Unify L3-16 and L3-13 into a single witness operation: substitute $B_1$'s native $s_1$ output into $s_2$'s witness and check whether $s_2$'s required transformation **collapses to the identity/no-op** (meaning $s_2$ was merely compensating for $B_0$'s bug $\to$ **retire**), versus remaining a **non-trivial well-defined rule** on $B_1(s_1)$ ($\to$ **re-ground and migrate**).
- **Nearest prior / gap:** L3-16 and L3-13 ran separate probe pipelines; [MetaDD](https://arxiv.org/abs/2410.05103) and [UpgradeBench](https://arxiv.org/abs/2608.20918) have no target-collapse test. One *identity-collapse check* on $B_1$-substituted witnesses classifies and prepares the repair simultaneously.
- **Cheapest first test:** 12 downstream rules (6 pure bug-compensations, 6 genuine convention-dependent rules) on $B_0 \to B_1$; compare separate L3-16 + L3-13 pipelines vs unified collapse test at half the probe budget. Kill if the unified test misclassifies genuine subtle private rules (small non-zero deltas) as no-ops more often than separate L3-16.
- **Old-task retention:** Report precision/recall on subtle private rule $B$ alongside composed $s_1 \circ s_2$ accuracy on $B_1$.

### L4-23 · Monotonic debt-shrinkage invariant across 3+ base generations
- **Mechanism:** Combine L3-16 compensation purging + L3-13 native re-grounding at every hop of a 4-base ladder $B_0 \to B_1 \to B_2 \to B_3$ (where each generation absorbs more skills, fixes more bugs, and shifts conventions), and track total carried adapter/packet bytes and latency. Test whether carried adaptation debt *shrinks monotonically* for legacy skills instead of growing or plateauing.
- **Nearest prior / gap:** [ReLoRA](https://arxiv.org/abs/2606.02606), [Heirloom](https://arxiv.org/abs/2611.00650), and [When the Bill Falls](https://arxiv.org/abs/2611.20702) study 1-hop migrations or index deferral. Testing the *multi-hop debt-shrinkage curve* verifies whether L3-16 + L3-13 actually solves generational bloat.
- **Cheapest first test:** 4-generation chain with 6 new tasks per hop, 3 bugs fixed per hop, and 3 skills absorbed per hop; compare migrate-all, L3-12 bridge-stacking, PCT, and L3-16 + L3-13 at each generation. Kill if a fixed-byte reservoir replay buffer matches accuracy and debt at $B_3$.
- **Old-task retention:** Measure generation-0 private rare rule $B$, generation-1/2 skills, and $B_3$'s native bug-fixes at the end of the chain.

### L4-24 · Selective backward-compatibility lock: PCT on private rules, free upgrade on retired/absorbed slices
- **Mechanism:** Partition $B_1$'s upgrade objective into three loss zones: (1) **private-rule lock** (apply PCT / margin-preserving negative-flip loss on confirmed private conventions), (2) **free improvement zone** (zero backward-compatibility penalty on L3-16 retired bug compensations), and (3) **re-grounded seam zone** (L3-13 native re-grounding on absorbed-dependent compositions).
- **Nearest prior / gap:** [Positive-Congruent Training](https://arxiv.org/abs/2011.09161) and [Margin-Preserving Negative-Flip Mitigation](https://arxiv.org/abs/2511.08322) apply one global flip penalty across all examples. *Zoned backward compatibility* captures PCT's zero-regression benefit on private rules without blocking bug fixes or native convention upgrades.
- **Cheapest first test:** Mixed upgrade with 8 private rules, 6 absorbed-dependent pairs, and 6 bug-compensations; compare global PCT, unconstrained L3-16 + L3-13, and zoned backward compatibility at equal updates. Kill if unconstrained L3-16 + L3-13 already achieves near-zero negative flips on rare private rule $B$.
- **Old-task retention:** Report negative-flip rate on private rules ($A/B$), positive-flip rate on retired hacks, and $s_1 \circ s_2$ accuracy on re-grounded seams.

### L4-25 · Write-time factored witness templates $(x, \text{slot}_{s_1}, \text{rule}_{s_2})$ for zero-rehearsal re-grounding
- **Mechanism:** Instead of paying heavy living-model rehearsal tax (L2-25) during $M_0$'s life, simply store each dependent teaching witness at write time in *factored slot form*—recording the raw input $x$, the upstream $s_1$ output slot, and the downstream $s_2$ target separately—so any future $B_1$ can run L4-02 counterfactual bug-injection and L3-13 native re-grounding in one pass with zero living bequest tax.
- **Nearest prior / gap:** Living rehearsal (L2-25) modifies $M_0$'s weights (incurring a living accuracy tax); raw trajectory logs glue $s_1$ and $s_2$ together. *Write-time factored witness storage* tests whether cheap structural logging beats living-weight regularization for L3-16 + L3-13.
- **Cheapest first test:** Compare living convention-jittered rehearsal (L3-21, with living tax) vs unregularized $M_0$ + write-time factored witness templates + L3-16/L3-13 at upgrade time, on upgrade to unseen $B_1$. Kill if living rehearsal beats factored templates + L3-13 on $B_1$ by more than its living accuracy tax.
- **Old-task retention:** Report $M_0$'s living $A/B$ accuracy (zero tax) alongside $B_1$'s post-upgrade $s_1 \circ s_2$ and rare $B$ accuracy.

### L4-26 · Post-upgrade packet hygiene: re-pack cleaned native witnesses for $B_1 \to B_2$
- **Mechanism:** Immediately after $B_1$ purges L3-16 compensations and completes L3-13 native re-grounding, discard $M_0$'s legacy witnesses and compile a fresh cross-architecture teaching packet (MetaDD-style or coreset) strictly from $B_1$'s *cleaned, natively re-grounded* witnesses—guaranteeing zero $B_0$-era conventions or bug hacks survive into $B_1$'s bequest for $B_2$.
- **Nearest prior / gap:** [MetaDD](https://arxiv.org/abs/2410.05103) and [Heirloom](https://arxiv.org/abs/2611.00650) never sanitize legacy witnesses between generations. *Post-upgrade packet hygiene* prevents fossilized $B_0$ artifacts from resurfacing two generations later.
- **Cheapest first test:** 3-generation chain $B_0 \to B_1 \to B_2$ across 3 architectures; compare carrying $M_0$'s original packet forward vs post-upgrade sanitized MetaDD re-packing at $B_1$. Kill if carrying $M_0$'s filtered packet (with retired IDs dropped) matches $B_2$'s accuracy without re-packing.
- **Old-task retention:** Score generation-0 private rules ($A$ and rare $B$), generation-1 skills, and $B_2$'s native skills at generation 2.

### L4-27 · Cold-quarantine rollback ledger for reversible purging and re-grounding
- **Mechanism:** Whenever L3-16 retires a suspected bug-compensation or L3-13 replaces an old witness with a $B_1$-re-grounded one, archive the original $M_0$ witness and its triage proof in a tiny read-only *cold quarantine*. If production monitoring later reveals a rare cohort where $s_2$ was actually a genuine private rule (or $B_1$'s $s_1$ had a hidden corner-case regression), surgically restore that single rule without rolling back $B_1$.
- **Nearest prior / gap:** Standard model upgrades roll back the entire base model on post-launch regression ([When the Model Retires](https://arxiv.org/abs/2609.31288)); irreversible purging risks permanent loss of rare exceptions. *Cold-quarantine restoration* makes aggressive L3-16 purging and L3-13 re-grounding operationally safe.
- **Cheapest first test:** Deliberately inject 2 rare-cohort exceptions that fool L3-16/L3-13 during offline upgrade $B_0 \to B_1$; compare full rollback to $M_0$, plain online fine-tuning on live failures, and single-rule cold-quarantine restoration at equal updates. Kill if online fine-tuning on the live failure logs recovers both exceptions with equal retention of $B_1$'s other skills.
- **Old-task retention:** Verify surgical restoration recovers the 2 rare exceptions with zero regression on all other purged compensations and re-grounded seams.

## Ranked deeper questions

1. **Can counterfactual $B_0$-bug injection (L4-02) and signed overshoot detection (L4-01) cleanly separate obsolete bug-compensations from genuine private conventions without false-retiring rare rule $B$?**
   Build a controlled $B_0 \to B_1$ benchmark containing pure bug-compensations, hybrid rules (private core + bug offset, L4-03), silent over-conservatism hedges (L4-04), and deceptive rare private rules (L4-10). Compare L3-16 unsigned probes, counterfactual $B_0$-bug injection (L4-02), signed overshoot (L4-01), Positive-Congruent Training (PCT), and GRAFT/Trans-LoRA per-task transport at equal probe budgets. Drop the L3-16 line if simple single-skill evaluation on $B_1$ or blanket PCT + fine-tuning matches precision/recall without joint probing.
2. **Does native witness re-grounding (L3-13 / L4-11–L4-16) genuinely beat keeping the old skill, L3-12 seam bridges, and raw $M_0$ distillation across 2–3 base upgrades ("when the bill falls")?**
   Run a 3-hop base chain $B_0 \to B_1 \to B_2 \to B_3$ where $s_1$ improves in standalone accuracy and shifts convention/tokenizer at every hop, while dependent $s_2$ (and 3-hop $s_3$) must remain accurate and editable (L4-18). Compare keep-old-$s_1$, stacked L3-12 bridges, raw $M_0$ distillation, GRAFT/Trans-LoRA, and hop-by-hop L3-13 re-grounding (with L4-11 semantic filtering and L4-19 information-sufficiency gating). Drop re-grounding if stacked L3-12 bridges maintain equal $s_1 \circ s_2$ accuracy and standalone $s_1$ gains at $B_3$.
3. **Does write-time factored witness logging (L4-25) + post-upgrade L3-16/L3-13 beat living-model upgrade rehearsal (L2-25 / L3-21) on the living-tax vs upgrade-quality Pareto frontier?**
   Test an unregularized predecessor that logs factored $(x, \text{slot}_{s_1}, \text{rule}_{s_2})$ witnesses (zero living bequest tax) plus purge-then-reground at upgrade time against a predecessor trained with living simulated-upgrade rehearsal (L2-25 / L3-21) and against post-hoc MetaDD cross-architecture distillation, across multiple unseen successor architectures $B_1^{(1..4)}$. This directly tests whether expensive living-weight regularization is even needed once upgrade-time purging and native re-grounding work.
4. **Does zoned backward compatibility (L4-24: PCT locked on private rules, unconstrained on purged hacks and re-grounded seams) dominate both blanket PCT and unconstrained migration?**
   Measure both *negative-flip rate* on confirmed private rules (especially rare $B$) and *positive-flip rate* on retired bug-compensations and improved $s_1$ skills across $B_0 \to B_1$. Keep L4-24 only if unconstrained L3-16 + L3-13 actually suffers measurable negative flips on rare private rules that zoned PCT eliminates without re-introducing double-corrections.
