# Node: learning without gradients at inference

Question: What can a continual learner do with forward execution that a learner relying on backprop cannot?

Tree path: gradient-trained continual learning → **learning without gradients at inference**. Neighbors: [forward-only CL](https://github.com/manojbajaj95/cl/blob/3b9604ed302732a97c69c07aa2be837b0fe421a5/tree/model-forward-only.md), [model-guided edits](https://github.com/manojbajaj95/cl/blob/cc73d2bd2fc66f055675667970f91ecc0d851bd8/tree/model-guided-edits.md), and [forward operations](https://github.com/manojbajaj95/cl/blob/c0084af5659fc412d7f31966fc75bf20b3776faa/tree/rl-forward-operations.md). Ideation and analytic examples only.

## Root cause: a gradient describes the current program, not the outcomes of programs it did not run

A conventional CL update differentiates a loss on the current execution graph, then uses replay, a penalty, or a projection to limit changes to old behavior. That is useful when the task and the collateral damage are visible to a differentiable proxy. It stops being enough when the deciding signal is behind a hard dispatch, returned by a sealed evaluator, or available only at a particular time. A derivative of the current path contains neither the outcome of an unexecuted branch nor the verdict of a missing evaluator. More replay on the same path does not supply that missing evidence. A frozen hypernetwork, an in-context writer, or a larger model looking at the weights can propose a branch to try; none can infer an independently chosen outcome bit without an observation.

The research bet is to make **which experiment the learner can run next** part of what it learns and retains. The primitive would acquire access to useful contrasts as well as commit useful edits; it would still update after the source of supervision or the legal experiment changes. The relevant costs are not just FLOPs: an outcome query can consume a reset, an expiring label, permission to exercise an old task, or a nonrenewable event.

### A precise separation: outcome queries vs. exact local derivatives

At round `t`, an independent fair bit `b_t ∈ {-1,+1}` defines a new task. The deployment exposes one writable gate `w_t`, initialized to zero. Its hard action is `sgn(w_t)` (zero means abstain), and the sealed loss is `L_t(w_t) = 1[sgn(w_t) ≠ b_t]`. Old tasks read their own already committed gates, whose writes are disabled in this round. Both learners have the same candidate writes, initial loss, memory, and prior. There is no side-channel label.

- **Exact derivative-only access:** Every nonzero query returns zero, and zero returns “undefined” for both bits. This is true even if the learner chooses derivative query locations adaptively, restarts, or uses arbitrary computation and randomness. Its transcript is independent of the bit, so the probability of solving the new task is at most 1/2 and of solving all `T` independent tasks is at most `2^-T`. Abstention does not count as success.
- **Scalar forward outcome access:** Evaluate candidate `+1` in a sandbox once. If it passes, commit it; otherwise commit `-1`. New-task success is 1 and earlier decisions are unchanged, exactly. This uses one outcome query per round and one persisted gate per task; it claims neither bounded memory for independent bits nor retention in a shared network.

This is a separation between **observation interfaces**, not a universal advantage for forward-only learning over backprop. Give the derivative-only learner the same off-path outcome and it can make the same decision. A differentiable relaxation, a straight-through estimator that gets the target, or policy-gradient exploration that sees rewards changes the interface or the information available; include these as controls when feasible. Backprop through an accessible smooth surrogate can then be the fastest way to consolidate. Conversely, without structure, even forward tests have a hard limit: with one uniformly hidden passing candidate among `N` and equality-only verdicts, `q < N` distinct probes and a final untested guess succeed with probability at most `(q+1)/N`. Replacing gradients with opaque scores does not by itself buy usable credit or old-task retention.

### What not to rediscover

- [PR #6: idea ledger](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/idea-ledger.md), [flood triage](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-triage.md), [flood top 10](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-top10.md): no logged IS/DR as a substitute for fresh truth; no promptable checkpoints, generic ISA, seed-log undo, or one more edit-equivalence quotient. For language prompts, rule identity needs same-length filler and an entropy/temperature-matched control, not just a blank prompt.
- [Self-WSP](https://arxiv.org/abs/2611.28833), [self-rewriting](https://arxiv.org/abs/2611.21885), [SelfWrite](https://arxiv.org/abs/2611.29513) and [WSP writes ICL](https://arxiv.org/abs/2611.26841) already span big-model edits and compilation from context; give the same candidate menu to matched random/scripted search and covariance-aware rank-1 repair. MEND, MALMEN and RLEdit are baselines for writing weights, not new primitives by themselves.
- [ES at Scale](https://arxiv.org/abs/2509.24372), [EGGROLL](https://arxiv.org/abs/2511.16652), and [SOMA](https://arxiv.org/abs/2609.37899) already show useful weight optimization without end-to-end backprop. Effective dimension limits search ([2611.29795](https://arxiv.org/abs/2611.29795)); control update norm ([2608.01624](https://arxiv.org/abs/2608.01624)) and actual acquisition before comparing forgetting.

## Raw ideas (unfiltered)

Each first test is CPU-sized. “New” is a claim to test against the named neighbor, not a priority claim. Unless a row says otherwise, score old tasks after multiple new commits, on untouched normal inputs, without giving the evaluator's answer to the learner.

| 5. ### Learn across verdicts that have no common scale

| 19. | 21. | 23. Portable exclusion stencil | From executable interventions, fit a sparse mask over *allowed experimental actions* that transfers to new hosts after calibration, not over the weights it will update. | Safe exploration and shielding prune rollouts; this targets cross-host reuse of discovery constraints across different candidate weight parameterizations. | Repeat the same hard task with permuted and rotated hosts; compare a fixed safety shield and fresh calibration. | Hold old regression frequency fixed and measure missed viable old fixes caused by incorrect exclusions. |

## Deeper sub-questions (ranked by chance of a new primitive)

1. **Can a learner acquire an experiment it could not run before, so that it can learn later skills from fewer or cheaper observations?** (1–4) The candidate primitive is a write that changes the available observation channels rather than the answer. Charge the write upfront; require savings on structurally new tasks over an exact or strong active learner given the same unlock options. If exposing a named flag solves everything, there is no learned primitive.
2. **Can a learned representation substitute or transport experiments without transporting the answer or the verdict scale?** (5–8) A reusable comparison channel would make learning survive evaluator replacement. Test a held-out reversal of old vs. new judge preferences and require calibrated abstention on edits whose ranking does not transport.
3. **What is the minimum capability needed to learn safely from evidence that cannot be reset?** (13–18) Formalize which combinations of resumable state, atomic writes and pre-commit observations allow acquisition without ever violating an old constraint. Compare a planner with the same access; if the optimal policy is always a fixed shield or a fully resettable simulator is required, move on.
4. **Can any of the experiment-state advantages survive distilling a temporary edit into a shared, capacity-limited host?** (19–24) Compare a frozen lookup and real backprop plus the same outcomes against in-context or hypernetwork writes. The bar is held-out composition and old-task retention after the temporary writer and its diagnostic scaffolding are removed, not merely successful installation.

**First joint test:** a sealed finite-state stream alternating new random gates, changed judge interfaces, and returns to original tasks. Use the exact derivative-only model only for the analytic sanity case; for a useful comparison share all acquired observations with a first-order hybrid and give every method the same candidate/commit API. Compare a fixed menu, a learned menu, exact active planning on tiny instances, and matched random or ES search. Budget calls, resets, online forward/backward compute, writer pretraining, and persistent bytes separately. Report acquisition, worst old-task regression, and total cost at matched acquisition. If the gains vanish when the controls get the same experiments, the result is about access to evidence, not the optimizer.
