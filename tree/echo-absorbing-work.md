# Echo-absorbing work: use required C batches, protect the live clipping norm

Child of [Slot echo](slot-echo.md) ([PR #229][parent]). This follows its two [score-3 review cards][triage]: #02, make C's required truthful minibatches contract the optimizer-slot difference before the first sensitive step, including drift from order-dependent gradients; #06, admit a writeback pair only if both orders execute the same clipping branch and update, without hiding a live norm input. Ideas and paper fixtures only; no pilot or GPU work.

**Bet.** Ordinary work for a useful new skill C can reduce an echo faster than the same work without echo shaping. At a fixed clipping policy, a C feature used by the actual norm computation might then buy more lawful swaps than an equally useful C with a separate norm check. These are independent bets. **Verdict.** Two untested primitive candidates: a task-funded transition that absorbs order residuals before a hard deadline, and a joint direction/norm binding for a real clipping consumer. Neither plain decay nor seeing equal clip flags is a win. The combined claim must beat the best affordable stack of the two controls.

## What would count

- **Freeze the workload.** Begin from the same reachable joint state in both orders. Freeze payloads, prefix obligations, actual C batch identities, lawful timing, first sensitive step and later admitted consumers before fitting. C must improve a real held-out task using truthful targets; an auxiliary loss on development pairs is allowed but may not use blind pairs or future gradients as oracle inputs. Run necessary C updates at their real times even in the controls. No no-op inserts, reset, cherry-picked arrival delay, replacing truth with synthetic anti-gradients, or changing the definition of an old-task success. If a step reads sensitive state earlier, meet its original contract or decline the swap.
- **Include the forcing term.** For a carried EMA with a shared clock, the exact first-moment difference obeys `Δm' = β₁ Δm + (1−β₁)Δg`; the second moment has `Δ(g²) = (g₊+g₋)⊙Δg` componentwise. The same truthful minibatch can give different gradients because its inputs, weights or features differ by order. Bound the *combined* map on reachable paired states, including bias correction, weight drift, second moments, adaptive denominators and finite precision as applicable. When a bound takes the form `D' ≤ ρD + b`, account for the forcing floor as well as the initial residual and verify the actual native transition. Smaller raw differences do not grant a pass if the first consumer still takes different updates.
- **Protect the statistic as well as the branch.** Declare the exact effective clip input and where it is computed (raw gradients, preconditioned direction, group reduction, etc.), threshold/state, comparison including its tie convention, dtype and accumulation. C must supply a statistic used by the live clip kernel, with the original norm semantics; a surrogate confidence score is not the norm. When using an enclosure, include both operands and every legal continuation in scope. For a fixed positive threshold and a strict `n > τ` clip rule, both upper bounds below `τ` or both lower bounds above `τ` suffice for branch agreement on finite values, not update agreement. Deal with ties/nonfinite values by checking actual semantics or refusing. Check the executed updates in native arithmetic, the norm value according to its contract if externally read, and any later state such as an adaptive threshold that consumes it. A later norm read that can recover the supposedly hidden component voids the claim in that scope.
- **Use fallbacks honestly.** Fork the two actual orders as the cheap reference, including common RNG/data when legal and genuine order-dependent gradients. Compare direction-only slot echo, equal C without shaping, clock-matched decay, OSR11's lawful batch-order receipt, paired realignment and the existing clip policy checked in each order. Slot reset, plain SGD and no clipping are diagnostics when they change the service contract. A fixed threshold is a fair comparator only where it is lawful; otherwise use it to isolate branch behavior. Price safe serialization, no-admission and exact two-order checks; charge speculation, proof cost, rejection, latency, scratch and persistent state, rather than crediting swaps that never do useful work.
- **Old tasks in every test.** The named checks below are additions to a common floor: held-out A/B, their rare route-sensitive inputs and useful C at matched starting margins, scored after acquisition, at required prefixes, immediately after the first sensitive step and through the declared tail. Include rejected-pair fallback traffic with the same deadlines. Following the [ledger][ledger], a tie with a simple matched control or an engineered threshold win is not evidence for a primitive. “Primitive candidate” below identifies a reusable object or operation; improvements are proposed audits or comparators, not standalone pilots. Prior-art links are comparisons, not a systematic novelty clearance.

## Two paper fixtures (not evidence for a primitive)

**E1 · One useful batch can reduce, erase or amplify an echo.** Use an Adam-like slot update `m'=(m+g)/2`, `v'=(v+g²)/2`. After two frozen writebacks the first coordinate has `m₊=1`, `m₋=−1`, and `v₊=v₋=1`. In both states the weight is zero. C predicts `θ−αm` on a required example with truthful target zero and regards the carried slot as fixed when differentiating the squared error divided by two. Thus `g=−αm` on this example, `|Δm'|=|1−α|`, and `v'=(1+α²)/2` in both orders. At `α=0` the ordinary decay leaves a gap of 1; at `α=1/2` it leaves 1/2; at `α=1` the slots tie; at `α=4` the gap grows from 2 to 3 with reversed sign. A second coordinate on the same minibatch, with prediction zero, target 1, `m=0` and `v=1` in both states, supplies a common nonzero update. An immediate coordinate reader **before** this batch can still tell the orders apart. The hand-picked `α=1` is an analytic comparator, not a learning result. The fixture says nothing about subsequent batches at changed weights or whether the echo-bearing feature is needed by held-out C.

**E2 · A direction tie and a branch tie are each too weak.** Let the declared clip site scale the published direction `p=1` by `min(1,2/n)`, where `n` is the Euclidean norm of the live two-coordinate input *before* selecting the published coordinate. Inputs `(1,0)` and `(1,2)` have the same `p` but squared norms `1` and `5`: the branches split and the outputs are `1` and `2/√5`. Inputs `(1,2)` and `(1,3)` both clip, but now the outputs are `2/√5` and `2/√10`. Inputs `(1,2)` and `(1,−2)` tie the norm, branch and update at this site; a lawful later norm of the input plus `(0,1)` has squared values `10` and `2`, and splits at the same threshold. Dropping the second axis to make the toy pass would change the clip contract, not protect it. This is an exact-real fixture; native equality and branch thresholds must still be checked in the deployed arithmetic.

## Idea cards

### 01. Learn a corrective gradient from useful C work — primitive candidate (#229 #02)
**Mechanism.** Fit a slot-conditioned C predictor on truthful targets and penalize the paired residual after its required update. The reusable operation is the C update itself; perturb the common signal to show it still reaches the real optimizer. **Novelty vs nearest prior art.** [Adam][adam] decays moments and [SGD stability][hardt] studies trajectories; here a real task learns corrective gradient dependence with the optimizer and deadline held fixed. **Cheapest first test.** Fit a nonlinear E1 receiver on a tiny regression family; hold out writeback pairs, initial moments and batch slopes. **Same-budget control.** Fixed analytic correction where available, plus equally useful C without a residual loss at the same clock. **Old-task retention.** Include examples relying on the common moment that an indiscriminate dampener would erase.

### 02. Absorb the second moment without freezing it — primitive candidate
**Mechanism.** Fit a block feature of C whose required gradients co-steer both `m` and `v`; make the certificate track signed and squared innovations jointly instead of assuming that first-moment contraction fixes the denominator. **Novelty vs nearest prior art.** [Adam][adam] processes both innovations; the new object would be a task-funded coupled transfer for two carried states, not a new EMA. **Cheapest first test.** Enumerate a two-coordinate grid with unequal initial `v` and a near-zero denominator coordinate; test a held-out third gradient. **Same-budget control.** First-moment-only shaping with exact per-order denominator computation, and paired realignment. **Old-task retention.** Probe a rare low-variance old coordinate whose step size is sensitive to the denominator.

### 03. Compose useful batches with complementary effects — primitive candidate
**Mechanism.** Learn two normal C feature routes whose required batches reduce different residual directions, so their composed map is safe even if neither map contracts every direction alone. Fix batch order when prescribed, or certify all legal orders. **Novelty vs nearest prior art.** [Gradient matching][condensation] optimizes surrogate examples and [OSR11][receipts] ships the order of named truthful batches; the candidate trains their effects, not their targets or permutation. **Cheapest first test.** Use two truthful nonlinear batch types; exhaust both orders and hold out residual mixtures. **Same-budget control.** Best lawful permutation with an equally useful unshaped C, including its direct checks. **Old-task retention.** Check a required old read between the two batches even when the final residual ties.

### 04. Absorb on the task predicate that already chooses the route — primitive candidate
**Mechanism.** Let a public C feature needed for class prediction select a residual correction route before each required minibatch. Neither route sees the order identity. Certify jumps at route boundaries, rather than averaging contraction across examples. **Novelty vs nearest prior art.** [Switch Transformers][switch] route examples to experts; here the same routing serves as a paired-state transfer with a verifiable deadline and lawful route decisions. **Cheapest first test.** Fit a piecewise two-regime C regression with an unseen regime crossover between writebacks and the reader. **Same-budget control.** Fixed task router plus a per-regime analytic map, or direct paired checks using the same experts. **Old-task retention.** Test rare A/B examples near the switch, including an allowed interleaving whose route must not change.

### 05. Carry a residual bound through a coupled weight drift — primitive candidate
**Mechanism.** Learn C features with a joint slot/weight transfer bound; a decrease in the slot component cannot count as absorption if it stores the difference in weights and regenerates it at the next batch. **Novelty vs nearest prior art.** [SGD stability][hardt] already bounds trajectories; the candidate is the C-trained joint transition furnishing a deadline-specific certificate, not the use of a norm bound. **Cheapest first test.** Use a 2D quadratic with an off-diagonal term; hold out couplings whose first slot step shrinks but whose later gradient amplifies the difference. **Same-budget control.** Equally useful C with clock-matched decay plus a direct paired rollout. **Old-task retention.** Probe an old feature that reads the weight displacement before it returns through the optimizer.

### 06. Absorb only what an already-declared consumer can hear — primitive candidate
**Mechanism.** Train the required batches to reduce the actual residual in the coordinates a fixed consumer will read next; carry the complementary residual with a bound on when it can reenter the read path. Do not retire any old reader. **Novelty vs nearest prior art.** [OGD][ogd] protects old gradients by projection and [Slot echo][parent] proposes a sufficient direction; this attempts to change the live residual through useful C work, not hide it at the port. **Cheapest first test.** Exhaust two successive readers with rotated axes, including one rotation that invalidates admission. **Same-budget control.** Direction-only binding plus exact raw-state audit and best lawful serialization. **Old-task retention.** Keep the rotating rare reader in the service profile and score its fallback.

### 07. Make the deadline an adversarial input — improvement
**Mechanism.** Interleave an immediate sensitive read, the earliest read after one required batch, and the scheduled last permissible read. Compare the minimum legal work to reach a valid transition, never “contraction after waiting.” **Novelty vs nearest prior art.** [Safe order families][orders] and the [review][triage] already demand legal continuations; this is a falsifier for a deadline-independent claim. **Cheapest first test.** Exhaust a three-event schedule with unequal durations and one always-early read. **Same-budget control.** Exact paired execution on the same menu, with best lawful same-deadline fallback. **Old-task retention.** A deadline miss on the earliest rare A service counts as failure even if the late task score is perfect.

### 08. Certify absorption despite skipped optimizer steps — primitive candidate
**Mechanism.** Train C's useful feature so a public transfer certificate can handle lawful missing updates without pretending that a skipped step advanced a slot clock. Cover native overflow and legitimate no-step events separately; reject if their flags differ. **Novelty vs nearest prior art.** [Mixed Precision Training][mixed] already uses loss scaling and adaptive optimizers track clocks; the candidate is a transferable absorption certificate indexed by actual productive updates. **Cheapest first test.** Enumerate a tiny loss-scale model with at most one lawful skip and a fixed early consumer. **Same-budget control.** Match clocks and loss scaling, use unshaped C and a paired checker. **Old-task retention.** Test B down an overflow-adjacent path and C at the shortest admissible schedule.

### 09. Amortize the bound across independent repair pairs — primitive candidate
**Mechanism.** Train one C transfer whose certificate is indexed by lawful pre-write context and a bounded pair descriptor, not a table of seen pair IDs. A verifier checks that the descriptor covers both actual starting states before using it. **Novelty vs nearest prior art.** [OSR11][receipts] retains an executable batch-order witness; this instead tries to reuse a verified closed-loop transition across unseen payload pairs. **Cheapest first test.** Withhold all pairs involving one repair family on a tiny shared route, and measure checked coverage and amortization when that family first arrives. **Same-budget control.** Memoized direct two-order checks plus unshaped C and exact per-pair verification. **Old-task retention.** Hold out old inputs specific to the withheld family, with no extra replay for the candidate.

### 10. Learn the common norm without deleting a legal contribution — primitive candidate (#229 #06)
**Mechanism.** Fit C to supply an actual clip-kernel input representation whose direction and total norm agree across safely admitted pairs. Require the learned feature to matter for truthful C and perturb a hidden axis to ensure the norm kernel still sees it. **Novelty vs nearest prior art.** [Gradient clipping][clip] changes the update by magnitude and [OGD][ogd] protects a projected read; neither makes a learned shared input binding with a two-order branch-and-update contract. **Cheapest first test.** Add a truthful nonlinear C target to E2, then hold out hidden-axis gains and signs. **Same-budget control.** Direction-only binding plus the full norm recomputed in both orders under the same policy. **Old-task retention.** Include A/B cases where clipping is required for correct old behavior; an always-inactive gate fails.

### 11. Bind the group reduction, not just the loudest group — primitive candidate
**Mechanism.** Let a necessary C feature produce live per-group norm contributions for a fixed reduction. Certify both the global branch and any exposed or subsequently consumed group statistics; total-energy equality cannot stand in for live per-group values. **Novelty vs nearest prior art.** [Adaptive group clipping][group] stabilizes groups; the candidate is a shared two-order binding for group reductions without changing their thresholds or semantics. **Cheapest first test.** Exhaust a two-group grid where total energy ties but a live group later crosses its threshold. **Same-budget control.** Native group norm recomputation for both orders, with a reproducible reduction if needed. **Old-task retention.** Include a low-volume B group whose norm is masked by aggregate metrics.

### 12. Preserve a live adaptive threshold trace — primitive candidate
**Mechanism.** Train C's shared input to keep the clip norm's actual threshold-state update compatible as well as the immediate branch. Check the whole fixed clip recurrence, including the next threshold read. **Novelty vs nearest prior art.** [Adaptive Gradient Clipping][agc] uses a weight-relative threshold; adaptive policies already exist. The proposed object binds both the live norm stream and its threshold consumer across orders. **Cheapest first test.** Use a fixed EMA threshold policy; plant equal first branch and executed update but different below-threshold norms, then trigger a split on the next common batch. **Same-budget control.** Exact per-order norm and threshold-state checks; fixed threshold as a diagnostic, not a replacement. **Old-task retention.** Probe the next rare A step at the moving threshold and keep its original policy.

### 13. Export a branch certificate for one declared native kernel — primitive candidate
**Mechanism.** Attach a compact pair witness to C's live direction and norm binding, enclosing the actual branch operands and checking the update at native precision. Reuse it across declared inputs, not across unchecked kernels or different reduction trees. **Novelty vs nearest prior art.** [Reproducible summation][repsum] stabilizes the arithmetic; the new object would be a portable witness across held-out pairs under one unchanged kernel. **Cheapest first test.** Emulate low-precision threshold neighbors, including ties and a reduction-order change that invalidates reuse. **Same-budget control.** Deterministic native reduction plus exact per-order evaluation at equal accepted coverage. **Old-task retention.** Check rare old updates at each side of the seam and those refused because of the arithmetic profile.

### 14. Seek useful swaps with clipping genuinely active — improvement
**Mechanism.** Stratify proposals by the original policy's both-active, both-inactive and split cases before fitting. In both-active cases require the full applied update, not just two matching flags or scale proxies; preserve the live norm contract separately. **Novelty vs nearest prior art.** [Gradient clipping][clip] already distinguishes magnitude effects; this audit prevents a selective no-clipping result from masquerading as protection. **Cheapest first test.** Extend E2 with a same-branch/different-scale grid and compare coverage at unchanged thresholds. **Same-budget control.** Direct two-order run with an equally useful C and the same branch stratification. **Old-task retention.** Include an old high-gradient outlier for which clipping is essential.

### 15. Close the norm leak under a shared tail — primitive candidate
**Mechanism.** Train C to preserve the norm-relevant invariants under declared lawful future gradient additions, not just under the current reduction. Admit a suffix only if its norm and native update checks follow from the binding; decline the scope if an old legal suffix separates the states. **Novelty vs nearest prior art.** [Scalable commutativity][scr] already quantifies over continuations; the candidate is a task-trained norm-preserving transfer, not a new equivalence definition. **Cheapest first test.** Use E2's sign pair and hold out rotations and affine tail increments, including the planted norm leak. **Same-budget control.** Direction-only C plus exact norm recomputation along every tested suffix. **Old-task retention.** Keep the planted old tail as a required service, not a disposable counterexample.

### 16. Choose a tight norm enclosure from an ordinary C feature — primitive candidate
**Mechanism.** Use a task-relevant C feature to partition reachable paired clip inputs into groups with certified correlated bounds, so a cheap checker can avoid costly paired recomputation on more cases. Use exact recomputation when the enclosure intersects the guard. **Novelty vs nearest prior art.** [Affine arithmetic][affine] already preserves correlations; the bet is a learned C feature that yields reusable partitions at lower total cost, not a learned replacement norm. **Cheapest first test.** Compare box and correlated bounds on signed two-group inputs with a held-out covariance change. **Same-budget control.** Fixed analytic partitions using the same bound representation, plus memoized direct checks. **Old-task retention.** Rate rare cross-group arrivals and their paid fallback at an unchanged deadline.

### 17. Share a clipping guard across callers without sharing their replies — primitive candidate
**Mechanism.** Train C to produce one live reduction contribution usable for two legally co-called repairs. Share the certificate only for the common actual clip site; audit payloads and replies per caller in both orders. **Novelty vs nearest prior art.** [Commuting writebacks][writes] already require caller-indexed equivalence; the candidate is the reuse of a truthful task feature and a clip proof at a shared nonlinear consumer. **Cheapest first test.** Enumerate two calls with distinct responses and one common clip site, then add a caller that requires a pre-reduction norm read. **Same-budget control.** Cache full norm computations under lawful invalidation and compare against separate clip checks. **Old-task retention.** Keep the rare pre-reduction caller live and score its unchanged reply and latency on fallback.

### 18. Let a productive batch pay down the clipping deficit — primitive candidate (joint)
**Mechanism.** Train C's required update to change the paired state in a way that both reduces the live slot residual and removes the next norm discrepancy; verify the branch and executed update separately. The candidate is one productive transfer that serves both contracts at once. **Novelty vs nearest prior art.** [Adam][adam] and [gradient clipping][clip] compose existing mechanisms; this claims an interaction, not their composition by itself. **Cheapest first test.** Couple E1 and E2, crossing absorption shaping on/off with norm shaping on/off; hold out a pair where each alone fails and test whether the shared route is necessary. **Same-budget control.** Best stack of lawful clock-matched correction or realignment and exact native norm checking, with matched C utility. **Old-task retention.** Keep a rare example that needs both usable moments and its original clipped update.

### 19. Certify a prefix that pays for the next pair — primitive candidate (joint)
**Mechanism.** Carry a bound on residual debt and on clip-relevant state across alternating required C work and pairs. A certificate must close over every admitted mixture of orders, not just two uniform traces. Declare a limit and decline further swaps when the bound expires. **Novelty vs nearest prior art.** [Slot echo][parent] already budgets rounding slack across bursts; this spends only productive C updates on a joint slot-and-clip obligation and tests the actual next clipped transition. **Cheapest first test.** Enumerate three pairs with a mixed-order-only clipping split, then vary the number of useful batches without delaying any deadline. **Same-budget control.** Exact finite reachability plus the best separate contraction and clipping checks. **Old-task retention.** Check a rare middle-burst reader and all service at the first refused pair.

### 20. Pay for cheap checks with work needed for C anyway — primitive candidate (joint)
**Mechanism.** Reuse a feature computed in the actual required minibatch to construct a small verifiable witness covering both residual contraction and the next native clip update. The feature is not itself authority: if the witness fails, perform the original exact check or serialize. **Novelty vs nearest prior art.** [OSR11][receipts] carries a legal batch-order receipt, and the [ledger][ledger] finds direct comparisons hard to beat; the candidate reuses task work to replace redundant proof computation, not to predict away safety. **Cheapest first test.** Tabulate verifier invocations, wall time and bytes on a tiny stream with rare safe pairs, costing both forming and checking the witness. **Same-budget control.** Best memoized paired checker and cheap fixed heuristic at equal useful coverage, plus lawful serialization. **Old-task retention.** Include rare high-cost A/B calls so saving mean verification time cannot hide a deadline regression.

## Ranked deeper questions

1. **Can mandatory truthful updates beat decay before the first sensitive step?** Start with 01–05 and E1. Require nontrivial useful C and test held-out gradient drift, second moments and exact early cutoffs. An analytic map or equally useful C plus plain decay/OSR11 at the same clock tying the actual consumer ends the learned claim.
2. **Can C protect the *real* norm while buying safe service in active clipping cases?** Use 10–15 and E2, with held-out seams, next norm reads and a planted leak. Measure separately branch agreement, native update agreement, exposed norm compliance and accepted useful pairs; exact per-order recomputation or the direction-only stack tying at the same cost is a negative result.
3. **Does one task feature do both jobs more cheaply than the best stack?** Run the factorial in 18 before the reuse ideas in 19–20. Compare on common reachable pairs and dispatch deadlines, include each single-shaping arm and the best feasible stacked control, and ablate the shared feature at matched C utility. A win only after extending the window, changing the clip policy or dropping a live reader does not count.
4. **What can be certified before timing, callers or arithmetic change?** Start with 07–09, 13 and 17. Compare blind transfers against direct paired tests, record the first contract violation or certificate expiry and price every fallback. If the real old tasks force an early read or a norm consumer that voids most swaps, report that scope limit rather than narrowing the benchmark after seeing it.
