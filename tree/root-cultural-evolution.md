# Root: Continual Learning as Cultural Evolution

Root node (depth 0) · 32 candidate primitives · Ideas only; no experiments run

**Thesis.** A continuing learner needs to know not just what worked, but what an experience licenses it to change. A ruling can change which distinctions count. An amendment can constrain how later amendments take effect. Contact between dialects can create a construction neither community had. An apprentice can inherit a way to decide when a demonstration does **not** apply. These are changes to the objects that generate future behavior and future learning, not better scores for selecting from a fixed memory.

The implementation surface is a learner with an editable policy, rule interpreter, or grammar and a fixed executor; this can be the whole agent or a scaffold around a frozen model. An incoming episode can teach the learner a condition, action, or operation on either. The same executor then faces unlabelled novel episodes. Nothing here requires editing weights. Nor does a better external interpreter establish that the model has internalized a skill.

## Scope and first-test rules

The [idea ledger](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/idea-ledger.md) and [flood triage](https://github.com/manojbajaj95/cl/blob/devin/1795531716-reviewer-verdicts/reviews/flood-triage.md) rule out several tempting shortcuts. No optimizer-state carriers, meters or observability primitives, token retirement, teaching markets, relearnability, synonymous-code writes or gauge orbits, or hysteresis. No reconstructing lost skills from family trees (economics flood E30), copy-error correction (E32), or private memory-language compression. Culture here is a succession of shared practices and rules that can change, not an excuse to count how far a message spreads.

**Literature check.** Targeted searches in Hugging Face Papers and on the web, followed by checks against linked publisher/arXiv abstracts and available text. These are closest comparisons found, not priority claims. In particular, [Governance in Motion](https://aclanthology.org/2025.emnlp-main.869/) already co-evolves constitutions and agents, and [Artificial Generational Intelligence](https://arxiv.org/abs/2406.00392) already combines exploration with cross-generation cultural accumulation, including single-lifetime controls. Neither repeated constitution editing nor teaching a successor is itself a candidate primitive.

**Shared protocol.** For each card first enumerate a finite world or run an exact tabular learner on CPU; none of these tests has been run. Learn old tasks A and B, with B rare; stream in new task C and, where named, a second novelty D. Evaluate on held-out ordinary A/B inputs at baseline, after C, and after D or handoff, without task IDs, old snapshots, or tune-on-test. Give all arms the same legitimate input cues, supervision opportunities, action and update budget, and retained bytes (including interpreters and transcripts); charge intervention calls even when they fail. Match old retention at comparable new-task success and report per-task and worst-task drops, not a pooled average. The retention line on each card adds a specific old failure to look for; it never replaces A/B. Include append-and-retrieve or a flat decision list at equal budget where applicable. If an equally informed interpreter with the same resources ties, or the claimed distinction is encoded in the task generator as an answer, the first test has not supported a new learning mechanism.

## A · Precedent: learn when a decision binds

### CE01 · A precedent that teaches a new distinction
- **Mechanism:** A ruling writes both an outcome and a computable predicate not previously available to the learner. Its binding region is expressed in the expanded vocabulary; the predicate is then available in future disputes, even those unrelated to the original outcome.
- **Nearest prior / gap:** [Horty's reason model](https://www.cambridge.org/core/journals/legal-theory/article/abs/rules-and-reasons-in-the-theory-of-precedent/3B7697D8BD95470F3A814ACA72C5A2F9) constrains later cases using factor sets. [Abstraction-refinement program synthesis from demonstrations](https://dl.acm.org/doi/full/10.1145/3763070) already refines a vocabulary. The candidate is a vocabulary write backed by a binding case, tested for reuse in selecting an unrelated future ruling, not merely a better partition of C.
- **Cheapest first test / control:** Boolean cases with one hidden conjunction that separates C exceptions and is also useful on D. Compare overseen feature induction plus an ordinary case reasoner with exactly the same examples, expression budget and conjunction search; no credit if it matches.
- **Old-task retention:** Check old cases on both sides of the new predicate where it is irrelevant, including B.

### CE02 · Precedent on how to distinguish precedent
- **Mechanism:** Record a successful distinction as a rewrite on a *class of case comparisons*, not an exception to one decision. Its second use changes which precedent a later learner can cite even when the older examples have different actions and predicates.
- **Nearest prior / gap:** [When Precedents Clash](https://arxiv.org/abs/2410.10567) formalizes precedence under temporal and court structure. The candidate learns a reusable rule for comparing reasons (e.g. when a relationship defeats mere co-occurrence) rather than importing a fixed hierarchy.
- **Cheapest first test / control:** Rule graph with two disjoint vocabularies encoding the same reason-conflict shape; adjudicate one, then test the other. Compare few-shot retrieval of the first adjudication and a learned fixed-size comparator using the same graph inputs and labels.
- **Old-task retention:** Preserve old conflict resolutions in a third shape where the new comparison rewrite should not fire.

### CE03 · Overrule an inference, leave its verdict standing
- **Mechanism:** A correction invalidates a specific use of a conclusion as a reason for another conclusion. The originally decided action can remain correct and citable for other purposes. The editable unit is a typed citation edge, not a fact.
- **Nearest prior / gap:** [Datalog provenance](https://arxiv.org/abs/2202.10766) represents how outputs derive from premises. The gap to test is whether learning which *use* of a still-true conclusion is licensed transfers across later decisions better than learning exceptions or recalculating proofs.
- **Cheapest first test / control:** One true recommendation is used to authorize two distinct workflows; a new case rebuts one kind of authorization. Compare incremental Datalog with the same edge predicates and labels, and a flat exception learner. If typed Datalog ties, this is that operation applied to CL, not a new logic.
- **Old-task retention:** Retain ordinary predictions depending on the original conclusion and the unrebuked citation, including ones with both citations present.

### CE04 · A dissent with an activation test
- **Mechanism:** In a case where two derivations predict the same action, store a rival derivation and a distinguishing intervention it predicts. A subsequent ordinary case containing that intervention can establish the rival as a binding reason within its supported region without re-adjudicating the original outcome.
- **Nearest prior / gap:** [Causal Confusion in Imitation Learning](https://proceedings.neurips.cc/paper_files/paper/2019/hash/947018640bf36a2bb609d3557a285329-Abstract.html) distinguishes policy hypotheses through interventions; [Horty](https://www.cambridge.org/core/journals/legal-theory/article/abs/rules-and-reasons-in-the-theory-of-precedent/3B7697D8BD95470F3A814ACA72C5A2F9) separates reasons from results. The claimed operation is deciding what later decisions inherit from the same verdict once an ambiguity resolves, not simply keeping a version space.
- **Cheapest first test / control:** Two rules agree on initial cases, then one naturally occurring feature intervention separates them for C, with D sharing just the same type of derivation. Compare a live two-hypothesis learner plus scoped replay given the same intervention.
- **Old-task retention:** Check A/B cases supporting the first rule elsewhere and ordinary cases in which the two reasons still agree.

### CE05 · Learn a rule of referral through disagreement
- **Mechanism:** Two specialist policies can return valid but conflicting decisions. A resolved case creates a referral production that rewrites a *pair of incompatible claims* into a new question to a third policy; later an answer can resolve whole classes of similar conflicts.
- **Nearest prior / gap:** [A Modal Logic for Temporal and Jurisdictional Classifier Models](https://arxiv.org/abs/2510.13691) formalizes classifier authority across jurisdictions. Here the learnable object is a translation into the resolving jurisdiction's question, not a winner label or a confidence gate.
- **Cheapest first test / control:** Two toy domains dispute classification and a third answers a relation query. Learn one shared question schema and test novel paired facts; compare a direct joint classifier or router with identical access to the third policy.
- **Old-task retention:** Verify old single-policy calls and pre-existing cross-policy cases do not change just because a new referral is possible.

### CE06 · Split a precedent without deciding a new result
- **Mechanism:** Replace one broad reason with two linked holdings when both explain the same old verdicts but have different conditions of future applicability. Later changes can amend one holding without reopening the other, including in combinations not seen during the split.
- **Nearest prior / gap:** [Belief base revision for Datalog+/-](https://knowledge-representation.org/j.z.pan/pub/WPZL*2013.pdf) revises inconsistent bases by kernel incision. The proposed split happens before a contradiction and gives future corrections independent targets; it risks reducing to ordinary rule factorization.
- **Cheapest first test / control:** A shared fallback action has two demonstrably different grounds. Stream a corroboration of one ground, then C rebuts the other. Compare a factorized decision list with the same evidence, size and edit language; test previously unseen cases using both grounds.
- **Old-task retention:** Preserve B cases supported only by the unamended holding and A cases with redundant support.

## B · Amendment: learn rules for applying the next change

### CE07 · Give a learned amendment a translation clause
- **Mechanism:** An amendment can change the predicates in which proposals are written and supply a partial translation for proposals already under consideration. Translated proposals are validated under the new rules; ambiguous ones remain unresolved, rather than being rejected or guessed.
- **Nearest prior / gap:** [Symmetric Edit Lenses](https://repository.upenn.edu/cgi/viewcontent.cgi?article=3300&context=edissertations) transport edits between connected formats; [Governance in Motion](https://aclanthology.org/2025.emnlp-main.869/) revises constitutional principles. The hypothesis is a learned migration of *pending policy changes*, whose validity is judged after transport.
- **Cheapest first test / control:** Split one learned category into two while two pending exceptions overlap it differently. Compare a hand-specified schema lens where available, and a learned mapping composed with resubmission and ordinary validation on the same evidence and bytes. Score accepted changes on held-out tasks, not translation fidelity alone.
- **Old-task retention:** Test already-resolved old cases in both successor categories and old queued cases whose scope was not amended.

### CE08 · An amendment that cannot license itself
- **Mechanism:** Maintain a distinction between an active validation rule and a proposed successor. Learn changes to the validation language, but a pending change must satisfy the active rule before the new rule can judge any later proposal. A valid amendment thus changes the future space of valid learning operations.
- **Nearest prior / gap:** [Suber's paradox of self-amendment](https://legacy.earlham.edu/~peters/writing/psaessay.htm) already frames this; [Governance in Motion](https://aclanthology.org/2025.emnlp-main.869/) learns principles from failures. The CL candidate is induction of a useful successor validator from outcomes without letting a proposal manufacture its own label.
- **Cheapest first test / control:** Finite grammar with a restrictive rule that can validly be replaced in one step, and a nearly identical invalid shortcut. Compare a versioned two-phase validator with the same hypothesis class, and a fixed validator given the same admissible edits.
- **Old-task retention:** Score old cases whose appeal and decision path must remain valid under the successor, including B's unusual path.

### CE09 · Prospective amendment tied to a live commitment
- **Mechanism:** Learn a replacement workflow together with a migration procedure for open obligations. One invocation can be governed partly by the old promise and partly by the new rule; the unit of continuity is a specific obligation, not the whole old policy or all requests before a date.
- **Nearest prior / gap:** [Abstractions for Network Update](https://reitblatt.com/downloads/consistent-updates-sigcomm12.pdf) gives consistent per-packet updates; [commitment protocols](https://www.csc2.ncsu.edu/faculty/mpsingh/papers/mas/aamas-02-protocols.pdf) represent conditional obligations. The candidate learns which substate can migrate without violating a promise, rather than pinning every in-flight interaction to one version.
- **Cheapest first test / control:** Synthetic booking game with open two-step requests when C changes one step. Compare version pinning, and a commitment automaton with equally expressive guarded state migration learned at the same cost. Test mixed old/new execution on unseen requests.
- **Old-task retention:** Finish open A/B requests and execute fresh held-out A/B episodes with promises unchanged where C does not apply.

### CE10 · A narrow amendment can rewrite a definition, not every use
- **Mechanism:** An amendment names a term and a class of normative roles in which its meaning changes (e.g. eligibility, but not appeal standing). A shared interpreter applies the revised meaning to future clauses written in those roles without an enumeration of consumers at change time.
- **Nearest prior / gap:** [Constitutive Norms in the Design of Normative Multiagent Systems](https://icr.uni.lu/leonvandertorre/papers/clima05.pdf) gives context-sensitive institutional facts. The candidate is a learned role-sensitive semantic update that applies to later-authored clauses, not an edit to individual rule outputs.
- **Cheapest first test / control:** Teach a changed eligibility term using two contexts; introduce D with unseen clauses using the term in both roles. A typed predicate per role, learned with the same samples and storage, is the strong null.
- **Old-task retention:** Score old eligibility outcomes outside the intended change and old appeal outcomes inside and outside it.

### CE11 · Ratify the incompatibility rule before the amendment
- **Mechanism:** Two modifications can both be valid alone but not jointly. A preliminary decision learns how to resolve a type of incompatibility and is binding on both proposals *and subsequent proposals of that type*. The outcome of ratification is therefore a new operator on proposed edits, not a priority number on a document.
- **Nearest prior / gap:** [Verified Three-Way Program Merge](https://www.microsoft.com/en-us/research/publication/verified-three-way-program-merge/) checks merges against parent changes; [When Precedents Clash](https://arxiv.org/abs/2410.10567) handles conflicting precedent. The gap is transferring a learned resolution operator to changes neither original author proposed.
- **Cheapest first test / control:** Enumerate two edits whose instances overlap only compositionally, then test new colliding edits. Compare a three-way merge with a learned resolver over the same conflict representation and approval supervision; a tie means the idea is that resolver.
- **Old-task retention:** Test unaffected old compositions plus A/B instances resembling the conflict where both earlier commitments remain in force.

### CE12 · Severability that can preserve a different justification
- **Mechanism:** Learn a re-derivation procedure attached to a composite amendment. If a constituent is later invalidated, use remaining authoritative reasons to derive a narrower surviving rule, rather than dropping the whole clause or retaining an unexplained residual.
- **Nearest prior / gap:** [Horn belief-base dynamics](https://arxiv.org/abs/1501.06206) uses immutable rules, abduction and minimal change for updates. The proposed extra object is a learned recipe for viable descendants attached before the failure, which can only use currently legitimate support.
- **Cheapest first test / control:** Grant a toy capability under two grounds with overlapping scopes, then remove one on C and test novel inputs. Compare exact recomputation from valid grounds and prioritized minimal revision, charging the recipe and any stored facts; only a cost/generalization gap is plausible.
- **Old-task retention:** Retest old B cases supported entirely by the surviving ground, and old A cases independent of the entire clause.

## C · Creolization and language change: contact can teach a new operation

“Creolization” here is a design prompt for contact-induced construction, not a claim about a universal origin of creole languages. [Senghas et al.](https://www.science.org/doi/10.1126/science.1100199) study changes in the expression of motion across cohorts of Nicaraguan Sign Language, a different historical phenomenon. The relevant analogy is that a new cohort can systematize distinctions rather than only imitate them.

### CE13 · Build a construction neither parent grammar can express
- **Mechanism:** Fit a contact construction that takes an operator from each of two independently learned task grammars and binds their arguments in one execution (e.g. “do X, otherwise perform Y under the first branch's promise”). Its value is an executable compositional meaning, not a new name for the same message.
- **Nearest prior / gap:** [Learning Translations](https://ijcai.org/proceedings/2024/0005.pdf) uses emergent communication pretraining for cooperative language acquisition; [Emergent Translation](https://arxiv.org/abs/1710.06922) communicates across distinct vocabularies. The candidate must learn a productive operation not representable by translating a complete utterance into either parent grammar.
- **Cheapest first test / control:** Two tabular action languages independently learn fallback and promise handling. Teach a joint operation on two combinations, test unseen arguments. Compare bilingual translation plus an equally expressive synthesis system over the union of primitives, with both charged for new productions.
- **Old-task retention:** Connect each old dialect partner through ordinary traffic and test each parent operator alone, including a rare fallback never used by C.

### CE14 · Grammaticalize a recurring repair
- **Mechanism:** When conversational repair repeatedly supplies the same missing relational role, learn a construction in which that role is a first-class argument. Future tasks can bind a novel value without repeating the repair or memorizing a stock exchange.
- **Nearest prior / gap:** [Clark and Brennan](https://web.stanford.edu/~clark/1990s/Clark%2C%20H.H.%20_%20Brennan%2C%20S.E.%20_Grounding%20in%20communication_%201991.pdf) model the evidence interlocutors need to ground contributions; [computational construction grammar](https://pmc.ncbi.nlm.nih.gov/articles/PMC11268157/) already learns form–meaning patterns. The specific hypothesis is that the contrast made explicit by repair supplies a reusable argument structure unavailable in successful unrepaired examples alone.
- **Cheapest first test / control:** Exchange instructions with an initially implicit recipient; ambiguity prompts relational corrections. Match total turns and annotations to explicit role labelling, and compare ordinary grammar induction from those same repairs. Reject if an ordinary optional slot ties.
- **Old-task retention:** Test commands where the old default recipient is correct, including ambiguous-looking commands with independent evidence for the default.

### CE15 · Borrow a distinction and let it govern new composition
- **Mechanism:** One community treats two outcomes as a single category; a partner distinguishes them in action. In a discrepant cooperative episode, learn a split predicate and let later rules quantify over the split in entirely different tasks, without adopting the partner's vocabulary.
- **Nearest prior / gap:** [Compositional structure under iterated learning](https://www.pnas.org/doi/10.1073/pnas.0707835105) develops through transmission across learners; [seeded iterated learning](https://arxiv.org/abs/2003.12694) counters drift from a seeded language. The candidate transports a causal distinction into a policy ontology rather than preserving or aligning a language.
- **Cheapest first test / control:** Partner routes items by substrate, while local rules use one category. Reveal one discrepancy and test a later task whose learned ordering reuses substrate; compare joint feature induction with all the same observations and interaction budget.
- **Old-task retention:** Preserve local decisions where substrate never mattered, including held-out legacy items of both substrates.

### CE16 · A loan carries an exception to how it composes
- **Mechanism:** One imported construction expands to native operations almost everywhere, but switches one compositional rule when nested under a specified operator. Learn the override from contact and run it under deeper unseen nesting; a loan is a scoped inference rule, not a learned alias.
- **Nearest prior / gap:** [Emergent Linguistic Phenomena in Multi-Agent Communication Games](https://arxiv.org/abs/1901.08706) studies emergent conventions in games, and [computational construction grammar](https://www.cambridge.org/core/journals/language-and-cognition/article/computational-learning-of-construction-grammars/43E9BA63CD01CB2912029FF32721076E) represents form–meaning units. The candidate uses a learned boundary on inherited composition, with no gain if ordinary typed semantic parsing already captures it.
- **Cheapest first test / control:** Train shallow expressions where native and borrowed “until” differ only inside a conditional, then execute deep mixed trees. Compare an equally expressive parser with a lexical marker and learned per-construction semantics.
- **Old-task retention:** Check native nesting of the same operators at the same depths and the old dialect's unnested usage.

### CE17 · Reanalysis changes the argument structure, not the dictionary
- **Mechanism:** Adopt a new parse of an established expression while preserving its meaning in observed contexts. Only later evidence distinguishes the parses; the winning analysis licenses new expressions that require binding the reanalyzed segment to different arguments.
- **Nearest prior / gap:** [The proper treatment of language acquisition and change in a population setting](https://ncbi.nlm.nih.gov/pmc/articles/PMC2691386/) models language acquisition and change across generations. The CL candidate treats a parse reanalysis as a reusable policy edit with out-of-support operational consequences, not as simple linguistic drift or an equivalent encoding.
- **Cheapest first test / control:** In a finite command language, a fixed phrase adjoining an action can be reanalyzed as taking an object argument. Provide late examples disambiguating scope and test withheld recombinations. Compare online Bayesian grammar induction maintaining both parses with the same prior and evidence; expect a tie unless the explicit reanalysis yields a cheaper compositional update.
- **Old-task retention:** Preserve idiomatic legacy uses whose intended interpretation would be lost by applying the new parse everywhere.

## D · Oral tradition: inherit structure through performance

### CE18 · Pass down a disagreement that a performance can settle
- **Mechanism:** Two successors hear contrasting performances plus a shared condition under which their differences would matter. They transfer the question by staging the contrast for the next learner, even if they have never encountered the resolving context. What survives a handoff is an operational ambiguity, not two votes.
- **Nearest prior / gap:** [Artificial Generational Intelligence](https://arxiv.org/abs/2406.00392) accumulates exploration and knowledge over generations; [query-efficient active imitation](https://arxiv.org/abs/1912.13037) solicits labels for informative cases. This combines persistent disagreement with transmission by enactment: a lineage can preserve a future test without transmitting policies or accessing the answer.
- **Cheapest first test / control:** Two grid policies agree except under a door layout first seen by generation three. Give all arms the same pre-door rollouts and handoff bandwidth; compare compressed hypothesis pairs with an active query chosen on arrival. Reject if a simple query descriptor or mixed replay ties.
- **Old-task retention:** After transfer and resolution, evaluate ordinary old routes where either original performance applied.

### CE19 · Teach the repair that reveals the invariant
- **Mechanism:** Transmit a performance deliberately perturbed at one step and then repaired while leaving the corresponding goal invariant. The receiver learns a repair operator it can instantiate after different disturbances, not an offset to the original trajectory.
- **Nearest prior / gap:** [Interactive Imitation Learning in Robotics](https://ar5iv.labs.arxiv.org/html/2211.00600) covers corrections and expert interactions; [Counterfactual Behavior Cloning](https://arxiv.org/abs/2505.10760) uses counterfactual learning from imperfect demonstrations. The candidate specifically transmits invariance via an executed perturbation/repair pair and must transfer to unseen disturbances.
- **Cheapest first test / control:** In a finite sorting world, stage one swapped ordering followed by a corrective splice. Compare ordinary imitation with paired expert corrections and inverse planning from the same traces, at equal intervention count. Test unseen disturbances, not replay of the swap.
- **Old-task retention:** Check undisturbed sorting and the other old rule whose superficially similar swap should not be repaired the same way.

### CE20 · Transmit a checkpoint as a predicate two actors can realize
- **Mechanism:** A performer stops on a condition at which another actor can resume using a different implementation. Demonstrating two legal realizations induces a handoff predicate usable to splice later procedures; the successor need not copy either route or see the final goal during training.
- **Nearest prior / gap:** [Constructing Skill Trees by Demonstration](https://all.cs.umass.edu/pubs/2011/konidaris_k_g_b_11a.pdf) segments demonstrations into reusable skills. The candidate learns an interchange condition from a joint performance, using cross-actor replacement rather than a supplied boundary or a shared embedding alone.
- **Cheapest first test / control:** Two grid actors place interchangeable supplies using different paths. Learn the handoff on two pairs and splice a novel third routine. Compare learned options with termination predicates and a program synthesizer given the same handoffs and trajectories.
- **Old-task retention:** Preserve uninterrupted old skills, plus old handoffs at lookalike states missing one required condition.

### CE21 · Inherit a reconstruction exercise instead of a solution
- **Mechanism:** A chain transmits an exercise with a success criterion and carefully chosen affordances, not a narrative of the answer. A learner that solves it can adapt the exercise before passing it on, provided doing so still identifies the underlying rule rather than a shortcut.
- **Nearest prior / gap:** [Models of Cooperative Teaching and Learning](https://martin.zinkevich.org/publications/zilles11a.pdf) and [recursive teaching dimension](https://jmlr.org/papers/volume15/doliwa14a/doliwa14a.pdf) use teaching sets to identify hypotheses. The proposed exercise is an interactive generator of evidence whose successor may reinstantiate it under changed affordances.
- **Cheapest first test / control:** Two rules agree on supplied input/output pairs but disagree under one permissible manipulation. Compare a teachable executable task against an optimal demonstration set and an equivalently parameterized environment curriculum at equal oracle and action budget.
- **Old-task retention:** After two handoffs, verify old rules in ordinary environments without the exercise's diagnostic affordance, including B where that affordance would teach the wrong rule.

### CE22 · The chorus performs the constraint, the soloist varies the skill
- **Mechanism:** A role split separates fixed responses from interchangeable candidate actions. The transmitted object is a turn-taking routine that determines which action substitutions can be tried without breaking coordination, not a majority recollection of the last performance.
- **Nearest prior / gap:** [Robust Real-Time Cultural Transmission](https://arxiv.org/abs/2203.00715) learns to infer and recall expert behavior; [Off-Belief Learning](https://proceedings.mlr.press/v139/hu21c.html) derives conventions for coordination. Here community enactment supplies a constraint on counterfactual substitutions that a later actor can carry to a new action repertoire.
- **Cheapest first test / control:** A finite call-and-response game where only a subset of new solo moves preserve a responder's obligation. Compare a role-conditioned policy or explicit protocol synthesized from exactly the same traces; do not treat knowing the chorus rule as extra supervision.
- **Old-task retention:** Play both old roles with the original partners, including a rare refrain where the soloist may not improvise.

## E · Apprenticeship: transfer scope, not just expert actions

### CE23 · Let an apprentice observe what the expert checks in order to stop checking it
- **Mechanism:** The expert demonstrates an information-gathering action and then demonstrates why an independently available witness can replace it. The apprentice inherits a conditional substitution of checks, including when it must still perform the older one.
- **Nearest prior / gap:** [Cognitive apprenticeship](https://www.isls.org/research-topics/cognitive-apprenticeship/) makes tacit decisions visible through modelling and coaching; [causal imitation](https://proceedings.neurips.cc/paper_files/paper/2019/hash/947018640bf36a2bb609d3557a285329-Paper.pdf) uses interventions to disambiguate expert behavior. The candidate is an executable substitution learned from paired evidence, not a tapering assistance schedule or a confidence score.
- **Cheapest first test / control:** In a simple diagnosis puzzle, show two checks agree conditionally and one shortcut outside the condition fails. Compare feature acquisition learned from the same queries and causal imitation with the same interventions; test a new puzzle with similar conditional structure.
- **Old-task retention:** Check old decisions where only the slower check works, as well as cases where both witnesses agree.

### CE24 · Learn the repair from which the master hands back control
- **Mechanism:** The apprentice first acts, then the master repairs only until a state in which the apprentice's rule is valid again. Learn the *condition for safe continuation by the learner's policy* and a way to reach it, independent of which terminal action the master would have taken.
- **Nearest prior / gap:** [BlenDAgger](https://arxiv.org/abs/2609.37599) blends expert and learner controls; [selective imitation](https://arxiv.org/abs/2605.09183) learns when to stop under dynamics shifts. The proposed portable object is an expert-to-apprentice return condition, not the initial trigger or a blend coefficient.
- **Cheapest first test / control:** Modify a small puzzle midway so the expert takes over and returns the task; on D use a different expert policy. Compare interactive imitation using the same takeover and return labels, and a learned recovery option with the same termination class and trace budget.
- **Old-task retention:** Verify old paths where no takeover is needed and old B recoveries to which the new return condition does not apply.

### CE25 · Learn which part of a mentor's objective is yours to replace
- **Mechanism:** Two mentors demonstrate legitimate completions while independently changing their preferences. The apprentice learns an executable specification with a goal slot it may fill and a condition that limits substitution. It can then accept a new local goal rather than imitate either mentor or inherit a fixed compromise reward.
- **Nearest prior / gap:** [Multi-task inverse constraint learning](https://arxiv.org/abs/2309.00711) infers shared constraints from demonstrations; [set-valued action supervision](https://arxiv.org/abs/2502.07645) learns acceptable action regions from corrections. The proposed object distinguishes a transferable right to substitute a goal from a fixed feasible-action set: on the new task the apprentice must work out what remains admissible for that goal.
- **Cheapest first test / control:** In tile placement, mentors vary the layout objective while respecting a nonlocal rule about which tiles can be moved together. Introduce a novel objective that forces the apprentice to test that rule on a sequence not used during coaching. Compare inverse constraint learning followed by replanning and a parameterized specification learner, with the same traces, objectives and correction budget.
- **Old-task retention:** Test the original goals and an old rare layout where an apparently discretionary change would break the nonlocal rule.

### CE26 · Teach a novice how to correct its own next apprentice
- **Mechanism:** During a supervised turn, the novice must articulate an observable distinction that would let a future student catch one plausible misapplication, and demonstrate both branches. Retain the resulting correction procedure, not just a maxim or the expert's evaluation of the novice.
- **Nearest prior / gap:** [Learning few-shot imitation as cultural transmission](https://www.nature.com/articles/s41467-023-42875-2) learns the capacity to imitate from demonstrations; [Models of Cooperative Teaching and Learning](https://martin.zinkevich.org/publications/zilles11a.pdf) studies helpful selection of examples. The candidate learns a reusable correction on a student's *mistake class*, tested on a different student rather than on copying accuracy.
- **Cheapest first test / control:** Train a tabular procedure with two rival shortcuts; a new apprentice has a third shortcut of the same class. Compare equally long contrastive demonstrations and a case library of errors with the same allowed interventions. Do not compare self-generated and teacher-generated replay as if authorship were the mechanism.
- **Old-task retention:** Retest the first apprentice's ordinary A/B performance after becoming a teacher and the next apprentice's A/B performance after receiving the new correction.

### CE27 · Withhold a step whose legitimacy depends on who performs it
- **Mechanism:** The master reveals a tempting action but demonstrates that a novice and a qualified actor can execute identical motions with different institutional results. Learn a transformation of the procedure that obtains a legitimate substitute result under the novice role, not merely “abstain if novice.”
- **Nearest prior / gap:** [An account of institutional actions](https://people.lu.usi.ch/fornaran/papers/AC2004FornaraViganoColombetti.pdf) distinguishes physical actions from institutional effects, and [interactive imitation](https://ar5iv.labs.arxiv.org/html/2211.00600) gets corrective demonstrations. The candidate learns a substitution of a witnessed procedure when its performer lacks a role, testable across different actions.
- **Cheapest first test / control:** A novice cannot finalize a toy request but can ask a different actor to validate a receipt serving the same end. Train on one request family, test another. Compare role-conditioned program induction and a fixed substitution library given the same roles and examples; a hardcoded task-specific workflow is not evidence.
- **Old-task retention:** Score old tasks under both roles, including B where the novice may finish directly and delegation would change the result.

## F · Institutions: learn what a practice makes possible

### CE28 · One event can be evidence without constituting a decision
- **Mechanism:** Learn separate update rules for an act's informational and institutional effects. A witnessed recommendation can improve prediction without counting as authorization; a later learned “counts as” rule changes which events actually create commitments, without discarding their informational value.
- **Nearest prior / gap:** [Constitutive Norms](https://icr.uni.lu/leonvandertorre/papers/clima05.pdf) already models events counting as institutional facts. The candidate is online induction of such a rule from binding and nonbinding acts, with the factual learner shared across the boundary.
- **Cheapest first test / control:** Stream advisory and binding signatures with identical text but observable procedural differences. Compare a role-conditioned predictor plus a fixed institutional automaton and an automaton induced from the same traces. Perturb where factual and normative authority disagree; a tie eliminates the distinct learning claim.
- **Old-task retention:** Check historical recommendations still inform old predictions and prior duly authorized decisions remain actionable.

### CE29 · Pass an office without passing a policy
- **Mechanism:** Define an office's unfinished duties as obligations callable by their counterparties. A successor actor independently implements a new policy satisfying them; its demonstrations teach later successors a translation from remaining obligations to possible continuations, not how to imitate the prior officer.
- **Nearest prior / gap:** [Modeling Agent Institutions](https://www.iiia.csic.es/media/filer_public/71/7b/717b3d62-b595-44be-abb7-1fca185bd5dd/4848.pdf) specifies roles and role compatibility; [commitment protocols](https://www.csc2.ncsu.edu/faculty/mpsingh/papers/mas/aamas-02-protocols.pdf) formalize execution through social commitments. The test is whether a learned continuation template survives changes in actor capabilities better than passing the role and commitments alone.
- **Cheapest first test / control:** Replace a dispatcher during two kinds of incomplete delivery. Train two office transitions, then change permissible actions on a third. Compare a generic planner given the same obligations, capabilities and handoff bytes, and predecessor-policy transfer. No gain if planning from the contract already ties.
- **Old-task retention:** Finish old pending deliveries and handle fresh old jobs under the new officer without reviving the predecessor's actions.

### CE30 · Learn a treaty that delegates a question but not its consequences
- **Mechanism:** One institution learns to accept another's answer to a specific subquestion as authoritative while retaining its own rules about what follows. Authority is a typed import that can later be composed with new local rules, rather than trust in the complete foreign plan.
- **Nearest prior / gap:** [Virtual Organizations as Normative Multiagent Systems](https://icr.uni.lu/leonvandertorre/papers/hicss05b.pdf) represents roles with authority and duties; [temporal and jurisdictional classifiers](https://arxiv.org/abs/2510.13691) model multiple authorities. The candidate learns a limited interface between evolving local policies, with different legitimate downstream behavior on each side.
- **Cheapest first test / control:** Two rule sets agree to import a common certification while differing on downstream eligibility. Compare an explicit role-typed facts API with the same learned mapping, and end-to-end joint classification with the same facts and supervision. Test after both sides add unshared rules.
- **Old-task retention:** Preserve old local exceptions and old imports in unrelated questions; check one foreign decision the local agent must still decline to treat as binding.

### CE31 · A grievance teaches standing before it teaches a new rule
- **Mechanism:** Exceptions raised by affected parties first teach which *relationship to a decision* allows a challenge. Later cases can reopen a decision using this relation even when its subject, parties and eventual result differ. The write changes which episodes can furnish amendment evidence, not their weights after admission.
- **Nearest prior / gap:** [Democracy-in-Silico](https://arxiv.org/abs/2508.19562) varies institutional rules as a design input; [Evolving Interpretable Constitutions](https://arxiv.org/abs/2602.00755) searches priority-bearing behavioral rules. The gap is induction of a reusable evidence-admission relation from the effect of a decision, with the appeal outcome trained separately.
- **Cheapest first test / control:** A dispute over shared inventory reveals when a non-owner has a contingent stake. Learn from cases that include successful and unsuccessful admissible challenges, then test new allocation roles. Compare learned eligibility followed by a separate adjudicator using exactly the same relational features and counterexamples; if it ties, this is supervised composition.
- **Old-task retention:** Preserve old valid challenges including unsuccessful ones, and hold-out ordinary old decisions that similar but unrelated requests must not reopen.

### CE32 · A repeated practice becomes binding only with reciprocal uptake
- **Mechanism:** Learn a rule from a sequence in which both parties begin relying on a recurring act and then recognize an obligation it entails. Represent the newly created obligation separately from both the observed frequency and the parties' expectations; apply it even on a rare future case where imitation predicts otherwise.
- **Nearest prior / gap:** [Feldman and Pentland](https://journals.sagepub.com/doi/10.2307/3556620) distinguish abstract routines from situated performances; [Evolving Interpretable Constitutions](https://arxiv.org/abs/2602.00755) evolves rules to improve collective outcomes. The proposed operator learns a new constitutive convention from reciprocal commitments, not what most actors do or what rule improves reward.
- **Cheapest first test / control:** Give two groups identical histories of turn-taking but different observable acknowledgments of responsibility. After an exception, compare an equally expressive learned commitment automaton and a frequency-based norm learner with the same messages. If acknowledgment is supplied as a gold binding label, or if the automaton ties, no distinct primitive is shown.
- **Old-task retention:** Test old standing routines with reciprocal uptake and superficially identical habits that never created obligations.

## Ranked deeper questions

1. **Can the learner expand its vocabulary of binding reasons without rewriting old verdicts?** Start with CE01–CE03. Use one ruling that changes the predicate vocabulary, then a different conflict resolved by a learned comparison between reasons. Against feature induction plus a case reasoner and typed Datalog, does retention hold when old rulings and their admissible uses come apart? A gain confined to new feature induction is not enough.
2. **Can the language of learning change while changes written in the old language are still pending?** Start with CE07–CE08. Require an update to validity, an already-pending proposal needing transport, and a fresh proposal depending on the new validator. The benchmark should permit an equally powerful lens and versioned validator to win; a separation is interesting only if they need more supervision or state at the same old-task floor.
3. **When does contact create a productive operation rather than a translator or a joint parser?** Start with CE13–CE16. Train parents independently, score withheld mixed executions that neither can express alone, and compare with union-language synthesis given exactly the same traces. Verify each old partner still completes its work after contact; fluent mixed strings are not evidence.
4. **What can a learner inherit through performance that demonstrations or a planner can't already supply?** Start with CE18 and CE21. Use an unanticipated change in affordances several handoffs later: can a received exercise or enacted contrast teach the relevant condition without carrying the answer, beyond an optimal teaching set or version-space summary at equal cost? Measure A/B in each successor as well as final C/D success.
5. **Can authority and evidence be learned independently enough to survive succession?** Start with CE28–CE30. Hold the underlying observations fixed while changing who may commit whom, then replace actors with differently capable successors. Compare an induced institutional automaton plus a planner over explicit commitments. A surviving result should show lawful new continuations and unchanged ordinary factual inference, not just agreement with a charter.
