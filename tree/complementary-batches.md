# Complementary batches: two routes close the slot gap, one step pays the norm debt

Child of [Echo-absorbing work](echo-absorbing-work.md) ([PR #238][parent]). The [score-3 review][triage] points to #03, two ordinary C routes whose required batches contract different directions of the leftover optimizer-slot difference, and #18, one productive C step that shrinks that gap and removes the next norm discrepancy. Ideas and exact arithmetic only; no pilot or GPU work.

**Bet.** Some useful C tasks demand two kinds of work that together absorb an order echo neither can absorb alone. Separately, one useful C update may be able to close both a slot gap and a live norm gap where splitting the work costs more. **Verdict.** Two untested candidates. The first must beat a strong single-route or unshaped two-route C. The second must beat the best affordable stack of slot correction and norm handling, not just each half.

## What would count

- **Freeze before fitting.** Start both writeback orders at the same reachable state. Freeze required truthful C examples and route obligations, lawful timings and permutations, prefix readers, the first sensitive update, and the later reader family. Learn on development pairs; hold out writeback pairs, C examples and continuations. Match useful C progress (including both routes), starting A/B margins, updates, examples, clocks, parameters and total compute. Charge routing, checks, speculation, storage and fallback. No idle waiting, extra repair batches, synthetic targets, or slot reset in the candidate.
- **Test the composed transition, not two favorable snapshots.** An optimizer's first moment obeys `Δm' = β₁Δm + (1−β₁)Δg` at a common clock; second-moment forcing contains `(g₊+g₋)⊙Δg`. Run the actual second batch on the rewritten weights and slots from the first. Include clocks, second moments, weight drift and numerical error where live. Check prescribed order or each legal order, and original prefix obligations throughout. Solo-route counterfactuals run with the same time/batch budget (useful alternate work where required); a deadline missed in actual service is a refusal, not a win. Smaller slot distance is not a safety certificate: check the first sensitive consumer under its original contract.
- **Score four observables separately.** Report slot-gap reduction, the discrepancy of the *next live norm*, the native clipping predicate (including ties), and the native executed update. Fix the norm input, reduction, scaling rule, thresholds and precision; retain real norm contributions and any downstream norm reads. A branch tie can hide different scales; a norm and branch tie can hide different published directions. Include active clipping and a planted case where slot repair alone leaves a norm discrepancy. Use separate one-objective arms and the best affordable stack; no clipping, fixed threshold where not lawful, and slot reset are diagnostic ablations, not service-equivalent wins.
- **Retention floor.** Every card below adds a targeted check to held-out A/B (including rare inputs), both C subskills, required prefix service and the next sensitive update plus declared tail. Report both orders and fallback traffic, not only accepted pairs. In the [ledger's][ledger] terms, a tied simple baseline is a negative result; a primitive candidate names a reusable operation or object, while improvements are audits or comparators. Prior-art comparisons are local, not novelty clearance.

## Two exact fixtures (not evidence of learning)

**B1 · Two maps expand the test gap alone and contract it together.** On a two-coordinate first-moment difference use `P = diag(1/4, 3/2)`, `Q = diag(3/2, 1/4)`, and start at `d = (1,1)`. Each map has one expanding axis; each yields squared Euclidean gap `37/16 > 2`. Both compositions are `(3/8)I`, so either legal order yields squared gap `9/32`. Using P twice instead gives `1297/256 > 2`. These are idealized gap maps, not evidence that truthful batches realize them; the double-P case is a negative control for the blanket claim that any two useful updates suffice.

**B2 · One productive toy step closes the norm gap; branch agreement alone does not.** Take a first-moment-only optimizer, `m'=(m+g)/2`. The two incoming slots are `(8,4)` and `(−8,0)`, with equal weights `θ=(0,0)`. On its required toy regression example C predicts `θ+(−15m₁/16,3m₂)` for target `(0,8)`, treating the carried slot as fixed during differentiation and using half squared error. The gradients are `(−15/2,4)` and `(15/2,−8)`, so the new slots are `(1/4,4)` and `(−1/4,−4)`. The squared slot gap falls from `272` to `257/4`. Updating `θ ← θ−m'/4` strictly lowers the example loss in both orders when evaluated at the respective incoming (fixed) features; this is not a held-out C or prefix-safety result.

The next toy consumer reads the live norm `n = ||(3,m₂)||₂`, tests `n > 2` and publishes `3·min(1,2/n)`. Before C, both clip, but the norms are `5,3` and the published updates are `6/5,2`. After C, the norms are `5,5`; both still clip and both publish `6/5`. A prefix requiring the actual C weight update to match would refuse this pair, and a later norm read of `(3,m₂+1)` still distinguishes the resulting slots (squared norms `34,18`). Thus the fixture isolates the stated *next* consumer, not a lawful whole-service swap. B1 and B2 values checked with Python's exact `Fraction` arithmetic.

## Idea cards

### 01. Learn a jointly contractive route pair — primitive candidate (#238 #03)
**Mechanism.** Learn two truthful C feature routes against the terminal paired residual, permitting each to leave or amplify a direction the other must remove. The reusable object is a pair of required updates with a joint safety scope. **Novelty vs nearest prior art.** [Slot echo][slot] #02 learns single-route washout; [gradient matching][condensation] fits surrogate examples rather than complementary effects of mandatory data. **Cheapest first test.** Fit two tiny regressors on a non-diagonal B1 variant; hold out mixed gap directions and include a pair whose composition expands. **Same-budget control.** Single shaped route given both update slots, and ordinary two-route C with tuned lawful decay and the same checks. **Old-task retention.** Test A/B on each amplified axis and at the handoff.

### 02. Learn to hand off a surviving direction — primitive candidate
**Mechanism.** Let the first C batch redirect an otherwise persistent gap into a direction the second task already damps; neither route has to span the original gap. **Novelty vs nearest prior art.** [Kaczmarz][kaczmarz] cycles row projections; the handoff here is learned in a useful transition with a frozen downstream route. **Cheapest first test.** Freeze the second regressor; compare a rotated first route against one with the same singular values but the wrong output axes. **Same-budget control.** Analytic preconditioning plus ordinary C. **Old-task retention.** Check an A/B input that depends on the first route's redirected axis, including before the second batch.

### 03. Train for the worse lawful order — improvement
**Mechanism.** Backpropagate the larger terminal discrepancy over both mandatory permutations, leaving the dispatch rule untouched. **Novelty vs nearest prior art.** [Switched-system stability][switch] already distinguishes common and order-dependent stability; this tests whether learning both permutations is worthwhile rather than restating that distinction. **Cheapest first test.** Use noncommuting two-dimensional stages for which only one order initially passes; validate on unseen paired states. **Same-budget control.** Ordinary C plus direct two-order checks or a prescribed order if service already requires one. **Old-task retention.** Score the A/B query due after whichever batch runs first.

### 04. Borrow an expansion only across an existing prefix guard — primitive candidate
**Mechanism.** Train the first transition to spend room in an already-live prefix observable while carrying a larger latent gap the next batch retires. Bind the permission to that actual observable, not just a terminal norm. **Novelty vs nearest prior art.** [Slot echo][slot] #02 watches a deadline; [commutativity][scr] constrains prefixes, but neither trains one required transition to supply a bounded intermediate state to another. **Cheapest first test.** Put two real prefix readers in a two-axis regression: one blind to the expanded axis and one that hears it. Require rejection of the latter. **Same-budget control.** Independently bounded routes plus exact prefix checks. **Old-task retention.** Compare both scheduled A/B replies at original deadlines.

### 05. Carry a residual across a feature switch — primitive candidate
**Mechanism.** Make route P's useful update change which C feature Q will use; require Q to absorb the gap in the feature actually selected in each order. **Novelty vs nearest prior art.** [Mixture-of-experts routing][moe] selects task features; composition here has a dependency between the learned changes in two reachable optimizer histories. **Cheapest first test.** A two-cell ReLU toy where a fixed-route approximation predicts contraction but one trajectory crosses the kink. **Same-budget control.** Frozen gate plus two independently shaped routes and native paired checks. **Old-task retention.** Include old examples on both sides of the moved gate.

### 06. Contract a numerator now, repair its denominator next — primitive candidate
**Mechanism.** Train P to reduce the first-moment gap and Q to remove the second-moment discrepancy that would otherwise amplify it in the next adaptive update. Q sees P's real gradient and can reintroduce either gap. **Novelty vs nearest prior art.** [Adam][adam] reads both moments; [Slot echo][slot] #03 binds them through a preconditioner. Here different mandatory batches perform complementary repairs without changing that preconditioner. **Cheapest first test.** Exhaust a two-axis Adam toy including a P/Q pair that lowers both raw gaps but worsens the normalized update. **Same-budget control.** Single joint moment objective on both batches plus direct replay of both orders. **Old-task retention.** Probe rare old coordinates with small denominators after Q.

### 07. Use a third required example to distinguish joint repair from favorable forcing — improvement
**Mechanism.** Replay P and Q on altered paired starts and add an already-required C suffix to test whether their apparent complementarity only cancels one particular incoming gradient difference. **Novelty vs nearest prior art.** [Trajectory matching][mtt] fits finite traces; [Echo-absorbing work][parent] #05 already accounts for drift. This is a falsifier for narrow training-trace wins. **Cheapest first test.** Train on one mixture of same-sign residuals, then reverse one difference and try a held-out Q gradient. **Same-budget control.** Random matched two-order rollouts. **Old-task retention.** Check A/B after the held-out suffix even when the P/Q boundary passed.

### 08. Learn positive pairs and deliberate mispairs — primitive candidate
**Mechanism.** Teach route families a partner interface: each required batch leaves a bounded reachable set that more than one separately trained partner can absorb; mismatched partners must fail the verifier. **Novelty vs nearest prior art.** [Switched stability][switch] supplies sufficient composition rules, not trained interchangeability of useful batch effects. **Cheapest first test.** Train three narrow regressors per family on a partial pairing matrix, then try unseen pairings including two that amplify the same coordinate. **Same-budget control.** Per-pair training or a single universal shaped route with matched state and compute. **Old-task retention.** Hold out A/B inputs aligned with the missing direction of each mispair and exercise fallback.

### 09. Learn what remains from a task feature, not a slot dump — primitive candidate
**Mechanism.** Reuse a feature already exposed by P's useful C computation to condition Q's corrective gradient; validate which residual families the small feature can distinguish. **Novelty vs nearest prior art.** [Echo-absorbing work][parent] #20 reuses task features to verify; here the feature affects the next real gradient, not the cost of checking it. **Cheapest first test.** Fit a one-scalar bridge on two dimensions, then present two distinct residuals with the same bridge value and opposing requirements. **Same-budget control.** Equal-byte projected slot summary or separate Q without a bridge. **Old-task retention.** Test an A/B direction absent from the bridge and verify the corresponding refusals.

### 10. Make both routes indispensable in ordinary service — improvement
**Mechanism.** Select a C workload with two held-out subskills that both need to improve, and intervene on each route while matching total C utility to detect one genuine route plus one disguised repair batch. **Novelty vs nearest prior art.** [Gradient matching][condensation] already evaluates task utility for data selection; this is an identifiability check on #238 #03's claim of required work. **Cheapest first test.** Replace P or Q with a true batch of the other type and compare the two per-skill learning curves. **Same-budget control.** Balanced ordinary curriculum and an independently tuned single route over the same data. **Old-task retention.** Check B inputs that share features with the weaker C subskill, not only aggregate A/B.

### 11. Retire slot and norm debt in one needed step — primitive candidate (#238 #18)
**Mechanism.** Fit one truthful C transition on both paired residuals, so a common C feature affects the carried slots and the actual next norm input. Verify branch and update as separate outcomes. **Novelty vs nearest prior art.** [Slot echo][slot] #02 and #06 supply the separate operations; the candidate needs a measurable interaction rather than merely applying both. **Cheapest first test.** Extend B2 with a fit rather than hand-set coefficients; cross the two shaping objectives on/off and hold out slot-only repair, equal-norm/unequal-update and near-threshold pairs. **Same-budget control.** Best affordable stack of single-purpose repair and exact norm handling plus ordinary C, with singleton arms. **Old-task retention.** Include an A/B example that requires both intact moments and the original clipped update.

### 12. Learn a norm shell without flattening useful directions — primitive candidate
**Mechanism.** Train C's needed gradient to land the two histories on the same live norm shell while keeping the published direction and old reader outputs intact. Hidden vectors may differ only if those differences are lawful. **Novelty vs nearest prior art.** [OGD][ogd] protects old functions with projections; active [clipping][clip] is nonlinear and a direction-only constraint does not fix the norm. **Cheapest first test.** Extend B2 to include a third coordinate that changes the norm without changing the published axis, then retain a reader for that coordinate. **Same-budget control.** Ordinary C plus analytic null-space projection and exact norm comparison. **Old-task retention.** Test old examples reading both signs of the hidden coordinate.

### 13. Spend one gradient on a shared repair direction — primitive candidate
**Mechanism.** Learn C features where a single attainable gradient change reduces the slot gap and next norm discrepancy together. Use finite-step validation; aligned local derivatives are not enough at a clip seam. **Novelty vs nearest prior art.** [Multi-task optimization][pareto] finds common descent directions; the proposed reusable object is a shared *reachable transition* under truthful updates and a fixed live consumer. **Cheapest first test.** On a tiny quadratic, map attainable paired changes and hold out a case with no common improvement direction. **Same-budget control.** Weighted sum or alternating objectives with the same native checks. **Old-task retention.** Check rare A/B samples whose gradients oppose the apparent common direction.

### 14. Track the next scale as well as the threshold comparison — improvement
**Mechanism.** Force evaluation on equal branch flags with unequal scales, and on equal scales with unequal published directions, before claiming a productive batch removed the norm discrepancy. **Novelty vs nearest prior art.** [Echo-absorbing work][parent] E2 already separates branch and direction; this audit applies it specifically before and after the dual-purpose step. **Cheapest first test.** Exhaust a tiny rational grid around B2 in both clip regions and on the equality boundary. **Same-budget control.** Exact native two-order execution, versus logging branch bits and recomputing only disagreements. **Old-task retention.** Report effective old-task step sizes for rare inputs just above and below the seam.

### 15. Close the next norm at the next weights, not at the old weights — primitive candidate
**Mechanism.** Fit a C transition against the norm of a subsequent ordinary gradient computed at the actual updated weights. Jointly reduce slot discrepancy without training against the future blind batch at deployment. **Novelty vs nearest prior art.** [Trajectory matching][mtt] matches future weights; the object here is a current task step that binds the next nonlinear consumer over an admitted unseen reader family. **Cheapest first test.** Use two quadratic tails where a frozen-weight norm ties but recomputation splits for one. **Same-budget control.** Short unrolled weight matching plus independent live norm and update checks. **Old-task retention.** Probe A/B on the tail with largest gradient change under the C update.

### 16. Give the common-mode signal an independent knob — primitive candidate
**Mechanism.** Learn a C step that damps the antisymmetric slot gap but still responds to changes shared by both orders, and binds the next norm without clamping either response. **Novelty vs nearest prior art.** [Adam][adam] decays both kinds of signal; [Echo-absorbing work][parent] E1 adds a common nonzero coordinate, but does not test independent sensitivity to fresh common signal in the repaired coordinates. **Cheapest first test.** Add the same momentum or target perturbation to both B2 starts, then separately vary the antisymmetric gap. **Same-budget control.** Tuned decay plus ordinary C, or independent projection and norm checks. **Old-task retention.** Test old tasks that need a large common signal just after the joint repair.

### 17. Pay the norm debt across contributions that really sum — primitive candidate
**Mechanism.** Use one required update to shrink the slot gap while redistributing live per-group squared contributions so the global norm ties; do not claim safety for any group norm that is independently read. **Novelty vs nearest prior art.** [Echo-absorbing work][parent] #11 binds the group reduction directly; this ties it as a consequence of a productive transition that must also meet the slot obligation. **Cheapest first test.** Create two groups with opposing discrepancies and turn on an actual group-level reader that must veto a global-only pass. **Same-budget control.** Independent per-group shaping and exact global comparison at equal steps. **Old-task retention.** Check A/B using a small group whose loss could be masked by the larger group.

### 18. Ask where a single truthful step cannot pay both debts — improvement
**Mechanism.** Enumerate the attainable transitions from the frozen batch or model family. Separate lack of any slot-and-norm feasible direction from failure to fit a feasible one. **Novelty vs nearest prior art.** [Multi-task Pareto search][pareto] already formalizes feasibility trade-offs; this sets a negative control for rollout claims, not a new optimizer. **Cheapest first test.** Exhaust a one-parameter two-axis toy with an interior exact intersection and a second instance with disjoint feasible sets. **Same-budget control.** Grid search over the same model family plus exact paired checking. **Old-task retention.** Include A/B constraints in the feasible set and report if they—not the norm—exclude the intersection.

### 19. Let one route prepare the single-step intersection — primitive candidate
**Mechanism.** Train P to place paired states where Q's ordinary C update can jointly contract the leftover slot gap and remove the upcoming norm discrepancy. P neither waits nor runs Q's repair early. **Novelty vs nearest prior art.** [Echo-absorbing work][parent] #03 composes slot maps and #18 repairs both debts in one step; this claims an interaction only if P creates a feasible Q transition unavailable otherwise. **Cheapest first test.** Cross P shaping and Q joint shaping on/off, then replace P by an equally contractive map whose output makes Q miss the norm. **Same-budget control.** Best stack of #03 and #18 trained separately plus exact checks, with equal C and latency. **Old-task retention.** Test A/B at P's handoff and through the first actual clipped step after Q.

### 20. Learn a one-step repair whose norm tie survives a declared next read — primitive candidate
**Mechanism.** Shape the productive update against the current clip contract and the finite family of subsequent live norm transforms, rejecting a state if any admitted transform can reopen the discrepancy. **Novelty vs nearest prior art.** [Echo-absorbing work][parent] #15 checks a shared tail; here the productive repair itself must establish a restricted invariant while still contracting the slot gap. **Cheapest first test.** Extend B2 by a finite set of translated norm reads; hold out one translation that reveals a reflected hidden component. **Same-budget control.** Separate slot repair plus exact depth-two native checks, or serialization when infeasible. **Old-task retention.** Keep the sensitive translated A/B read live and verify refusal instead of removing it.

## Ranked deeper questions

1. **Do two indispensable C routes produce more lawful contractions than one strong route at the same cost?** Start with 01, 02 and 10. Freeze timing and readers, hold out mixed residuals, and test the actual composition and wrong partner. A tie with ordinary C plus decay or the single-route control kills the learned-complementarity claim.
2. **Does the single productive update beat the best stack in active clipping?** Start with 11, 14 and 15. Run the factorial and report all four observables, using native execution and a planted slot-only repair. A gain only on branch flags, only at one hand-set threshold, or only from extra work is a loss.
3. **When does the first route make joint repair feasible instead of just making both gaps smaller?** Use 18 and 19 to find a reachable state that permits Q's dual-purpose step and a matched alternative that does not. Test both orders if scheduling allows them; a tie with independently trained stages ends the interaction claim.
4. **How much service survives real prefix and tail reads?** Try 04, 08 and 20 on a fixed reader family, including an early refusal and a delayed norm leak. Compare accepted *useful* pairs, fallback cost and A/B retention against direct two-order checking and serialization; report the limits rather than shrinking the family.
